   - Preserve node text completely; do not simplify.

   - Remove `<REF>` and `</REF>` tags.
   - Remove the `RESULT` keyword.

**Input data**:
{structure_json}

**Generation strategy**:
1. Generate a unique node id for each command, such as n1, n2, n3.
2. Extract text from the `text` field and preserve it completely.
3. Use solid arrows `-->` for main flow.
4. Use labeled arrows `-->|condition|` for branches.
5. Use dotted arrows `-.->` for exception flow.
6. Represent parallel nodes with separate edges.
7. Do not translate original node text.
8. Never generate self-connections such as `n1 --> n1`.
9. Avoid isolated nodes when possible.
10. Avoid subgraph.
11. Use single braces for diamond decision nodes.

**Output format**: output Mermaid code only; no markdown fences.
