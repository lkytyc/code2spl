The code defines a `Server` class that keeps track of a whitelist of allowed addresses and stores the most recent sent and received message data.

- On creation, it initializes:
  - `white_list` as an empty list
  - `send_struct` and `receive_struct` as empty dictionaries

- `add_white_list(addr)`:
  - Adds an address to the whitelist if it is not already present.
  - Returns `False` if the address is already listed.
  - Otherwise returns the updated whitelist.

- `del_white_list(addr)`:
  - Removes an address from the whitelist if it exists.
  - Returns `False` if the address is not in the list.
  - Otherwise returns the updated whitelist.

- `recv(info)`:
  - Expects `info` to be a dictionary containing both `"addr"` and `"content"`.
  - If the input is not a valid dictionary in that shape, it returns `-1`.
  - If the address is not on the whitelist, it returns `False`.
  - If the address is allowed, it stores the received address/content in `receive_struct` and returns the received content.

- `send(info)`:
  - Expects a dictionary with `"addr"` and `"content"`.
  - If the structure is invalid, it returns the message `"info structure is not correct"`.
  - If valid, it stores the address/content in `send_struct`.
  - It does not return anything on success.

- `show(type)`:
  - If `type` is `"send"`, it returns the stored sent message structure.
  - If `type` is `"receive"`, it returns the stored received message structure.
  - For any other value, it returns `False`.

Overall, the class acts as a simple message handler with whitelist checking and basic storage for the latest sent and received records.
