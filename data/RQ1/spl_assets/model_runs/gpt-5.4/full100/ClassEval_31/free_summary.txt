This code defines a utility class, `DataStatistics4`, with four static methods for basic statistical calculations on numeric data.

- `correlation_coefficient(data1, data2)`: Takes two equally sized lists of numbers and returns the Pearson correlation coefficient between them. It computes the means of both lists, then uses deviations from the means to form the numerator and denominator. If the denominator is zero, it returns `0` instead of dividing by zero.

- `skewness(data)`: Takes one list of numbers and returns a skewness measure for the distribution. It calculates the mean, variance, and standard deviation, then computes a skewness formula based on the third power of centered values. If the standard deviation is zero, it returns `0`.

- `kurtosis(data)`: Takes one list of numbers and returns excess kurtosis. It computes the mean and standard deviation, returns `math.nan` if all values are identical, otherwise calculates the fourth central moment and subtracts `3` to produce excess kurtosis.

- `pdf(data, mu, sigma)`: Takes a list of values plus a normal distribution mean `mu` and standard deviation `sigma`, and returns a list of probability density values for each input value under that normal distribution.

The class does not store any state; all methods are independent static helpers.
