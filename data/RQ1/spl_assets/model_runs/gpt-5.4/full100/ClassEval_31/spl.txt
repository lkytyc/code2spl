# CLASS DataStatistics4

[DEFINE_WORKER: "Computes the Pearson-style correlation coefficient between two indexed datasets by centering each dataset around its mean and dividing the summed cross-deviations by the product of their deviation magnitudes, returning 0 when the denominator is zero." correlation_coefficient]
    [INPUTS]
        <REF> data1 </REF>: sequence[number] "The first numeric dataset, whose length defines the iteration range and divisor for both mean calculations."
        <REF> data2 </REF>: sequence[number] "The second numeric dataset, expected to be indexable for every index from 0 to len(data1) - 1 and summed using the same divisor as data1."
    [END_INPUTS]

    [OUTPUTS]
        <REF> result </REF>: number "The correlation coefficient computed as numerator divided by denominator, or 0 when the denominator equals 0."
    [END_OUTPUTS]

    [MAIN_FLOW]
        [SEQUENTIAL_BLOCK]
            [COMMAND Set n to the length of data1. RESULT n]
            [COMMAND Compute mean1 as the sum of all elements in data1 divided by n. RESULT mean1]
            [COMMAND Compute mean2 as the sum of all elements in data2 divided by the same n. RESULT mean2]
            [COMMAND Compute numerator as the sum over each index i from 0 to n - 1 of (data1[i] - mean1) multiplied by (data2[i] - mean2). RESULT numerator]
            [COMMAND Compute denominator as the square root of the sum over each index i from 0 to n - 1 of (data1[i] - mean1) squared, multiplied by the square root of the sum over each index i from 0 to n - 1 of (data2[i] - mean2) squared. RESULT denominator]
            [COMMAND If denominator is not equal to 0, return numerator divided by denominator. RESULT result]
        [END_SEQUENTIAL_BLOCK]
    [END_MAIN_FLOW]

    [ALTERNATIVE_FLOW: denominator is equal to 0]
        [SEQUENTIAL_BLOCK]
            [COMMAND Return 0 instead of performing the division. RESULT result]
        [END_SEQUENTIAL_BLOCK]
    [END_ALTERNATIVE_FLOW]

[END_WORKER]

[DEFINE_WORKER: "Compute the sample skewness of a numeric dataset using the mean, population variance, and a zero-division guard that returns 0 when the standard deviation is zero." skewness]
    [INPUTS]
        <REF> data </REF>: sequence of numbers "Input dataset used to compute skewness."
    [END_INPUTS]

    [OUTPUTS]
        <REF> result </REF>: number "The computed skewness value, or 0 when standard deviation is zero."
    [END_OUTPUTS]

    [MAIN_FLOW]
        [SEQUENTIAL_BLOCK]
            [COMMAND Compute n as the length of data. RESULT n]
            [COMMAND Compute mean as the sum of data divided by n. RESULT mean]
            [COMMAND Compute variance as the average of squared deviations from mean over data using divisor n. RESULT variance]
            [COMMAND Compute std_deviation as the square root of variance. RESULT std_deviation]
            [COMMAND If std_deviation is not equal to 0, compute skewness as sum of cubed deviations from mean over data, multiplied by n and divided by ((n - 1) * (n - 2) * std_deviation ** 3); otherwise set skewness to 0. RESULT skewness]
            [COMMAND Return skewness. RESULT result]
        [END_SEQUENTIAL_BLOCK]
    [END_MAIN_FLOW]

[END_WORKER]

[DEFINE_WORKER: "Computes the population excess kurtosis of a numeric dataset using the fourth central moment, returning NaN when the standard deviation is zero." kurtosis]
    [INPUTS]
        <REF> data </REF>: sequence of numbers "Input values used to compute kurtosis."
    [END_INPUTS]

    [OUTPUTS]
        <REF> result </REF>: number "The excess kurtosis value, or NaN when standard deviation is zero."
    [END_OUTPUTS]

    [MAIN_FLOW]
        [SEQUENTIAL_BLOCK]
            [COMMAND Compute the number of input items as n from the length of data. RESULT n]
            [COMMAND Compute the arithmetic mean of data by summing all values and dividing by n. RESULT mean]
            [COMMAND Compute the population standard deviation by summing squared deviations from the mean over data, dividing by n, and taking the square root. RESULT std_dev]
            [COMMAND If std_dev equals 0, return NaN immediately. RESULT math.nan]
            [COMMAND Create centered_data by subtracting mean from each value in data. RESULT centered_data]
            [COMMAND Compute fourth_moment as the average of the fourth powers of values in centered_data using division by n. RESULT fourth_moment]
            [COMMAND Compute kurtosis_value as fourth_moment divided by std_dev to the fourth power, then subtract 3. RESULT kurtosis_value]
            [COMMAND Return kurtosis_value. RESULT result]
        [END_SEQUENTIAL_BLOCK]
    [END_MAIN_FLOW]

    [ALTERNATIVE_FLOW: When std_dev is 0 after the standard deviation calculation, the method stops before kurtosis computation.]
        [SEQUENTIAL_BLOCK]
            [COMMAND Return NaN instead of continuing to the centered-data and fourth-moment calculations. RESULT math.nan]
        [END_SEQUENTIAL_BLOCK]
    [END_ALTERNATIVE_FLOW]

    [EXCEPTION_FLOW: When data is empty, division by zero occurs while computing mean or later averages.]
        [LOG "Input length is zero, so the method cannot divide by n."]
        [THROW ZeroDivisionError "Raised by division using n equal to zero."]
    [END_EXCEPTION_FLOW]

[END_WORKER]

[DEFINE_WORKER: "Computes the normal probability density value for each input datum using the given mean and standard deviation." pdf]
    [INPUTS]
        <REF> data </REF>: list "Input values to evaluate against the Gaussian density."
        <REF> mu </REF>: number "Mean of the normal distribution."
        <REF> sigma </REF>: number "Standard deviation of the normal distribution; must be nonzero."
    [END_INPUTS]

    [OUTPUTS]
        <REF> result </REF>: list "List of Gaussian PDF values corresponding to each input element."
    [END_OUTPUTS]

    [MAIN_FLOW]
        [SEQUENTIAL_BLOCK]
            [COMMAND For each value x in data, compute the Gaussian density using 1 / (sigma * sqrt(2 * pi)) multiplied by exp(-0.5 * ((x - mu) / sigma) ** 2). RESULT pdf_values]
            [COMMAND Return the computed list of density values. RESULT pdf_values]
        [END_SEQUENTIAL_BLOCK]
    [END_MAIN_FLOW]

    [EXCEPTION_FLOW: sigma is zero, causing division by zero during density calculation.]
        [LOG "The standard deviation cannot be zero because the formula divides by sigma."]
        [THROW ZeroDivisionError "Raised when sigma is zero."]
    [END_EXCEPTION_FLOW]

[END_WORKER]
