This code defines a small text-processing utility class that uses NLTK to clean, tokenize, part-of-speech tag, and lemmatize a sentence.

At startup, it downloads three NLTK resources: the averaged perceptron POS tagger, the Punkt tokenizer data, and the WordNet data used by the lemmatizer.

The `Lemmatization` class creates a `WordNetLemmatizer` instance when initialized.

It provides three methods:

- `remove_punctuation(sentence)`: removes all punctuation characters from the input string and returns the cleaned sentence.
- `get_pos_tag(sentence)`: removes punctuation, splits the sentence into tokens, applies NLTK part-of-speech tagging, and returns a list containing only the POS tag strings for each token.
- `lemmatize_sentence(sentence)`: removes punctuation, tokenizes the sentence, tags each token with a part of speech, and then lemmatizes each word. It uses the POS tags to choose the lemmatizer mode for verbs, adjectives, and adverbs; all other words use the default lemmatization behavior. It returns a list of lemmatized words.

The main interaction between methods is that both `get_pos_tag` and `lemmatize_sentence` call `remove_punctuation` first. The lemmatization method also depends on the POS tagging result to decide how each word should be reduced to its lemma.
