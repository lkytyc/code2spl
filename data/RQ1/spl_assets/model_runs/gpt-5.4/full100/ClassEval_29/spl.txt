# CLASS DataStatistics

[DEFINE_WORKER: "Compute the arithmetic mean of the input data by dividing its sum by its length, round the result to 2 decimal places, and return it." mean]
    [INPUTS]
        <REF> data </REF>: sequence "A collection of values whose elements are summed and counted to compute the arithmetic mean."
    [END_INPUTS]

    [OUTPUTS]
        <REF> result </REF>: number "The arithmetic mean of the input data rounded to 2 decimal places."
    [END_OUTPUTS]

    [MAIN_FLOW]
        [SEQUENTIAL_BLOCK]
            [COMMAND Compute the sum of all elements in data. RESULT total_sum]
            [COMMAND Compute the number of elements in data. RESULT data_length]
            [COMMAND Divide total_sum by data_length to calculate the arithmetic mean. RESULT mean_value]
            [COMMAND Round mean_value to 2 decimal places. RESULT rounded_mean]
            [COMMAND Return rounded_mean. RESULT result]
        [END_SEQUENTIAL_BLOCK]
    [END_MAIN_FLOW]

[END_WORKER]

[DEFINE_WORKER: "Compute the median of the input data by sorting it first and then returning either the rounded average of the two middle values for even-sized data or the middle value for odd-sized data." median]
    [INPUTS]
        <REF> self </REF>: object "Instance reference."
        <REF> data </REF>: iterable "Input data to be sorted and measured for the median."
    [END_INPUTS]

    [OUTPUTS]
        <REF> result </REF>: number "The median value, rounded to 2 decimal places for even-length data."
    [END_OUTPUTS]

    [MAIN_FLOW]
        [SEQUENTIAL_BLOCK]
            [COMMAND Sort the input data into a new sequence without modifying the original input, then store the result in sorted_data. RESULT sorted_data]
            [COMMAND Compute the number of elements in sorted_data and store it in n. RESULT n]
            [COMMAND Check whether n is even by evaluating n % 2 == 0. RESULT parity_check]
            [COMMAND If n is even, compute middle as n // 2, then return the rounded average of sorted_data[middle - 1] and sorted_data[middle] using round(..., 2). RESULT result]
            [COMMAND If n is odd, compute middle as n // 2, then return sorted_data[middle] as the median value. RESULT result]
        [END_SEQUENTIAL_BLOCK]
    [END_MAIN_FLOW]

    [ALTERNATIVE_FLOW: If data is empty, sorting produces an empty sequence and n becomes 0; the even-length branch then attempts to access middle elements that do not exist.]
        [SEQUENTIAL_BLOCK]
            [COMMAND Proceed through the even-length median path with n = 0, which requires accessing sorted_data[-1] and sorted_data[0]. RESULT runtime_error]
        [END_SEQUENTIAL_BLOCK]
    [END_ALTERNATIVE_FLOW]

    [EXCEPTION_FLOW: If data is not iterable or contains mutually incomparable elements, sorting fails before n is assigned or before median selection completes.]
        [LOG "sorted(data) cannot complete because the input cannot be ordered."]
        [THROW TypeError "Raised when the input cannot be sorted due to invalid or non-comparable elements."]
    [END_EXCEPTION_FLOW]

[END_WORKER]

[DEFINE_WORKER: "Compute the most frequent values in the input sequence and return all values tied for the highest frequency." mode]
    [INPUTS]
        <REF> data </REF>: sequence "Input collection of items to count."
    [END_INPUTS]

    [OUTPUTS]
        <REF> result </REF>: list "A list of all items whose occurrence count equals the maximum count."
    [END_OUTPUTS]

    [MAIN_FLOW]
        [SEQUENTIAL_BLOCK]
            [COMMAND Build a frequency counter from the input data. RESULT counter]
            [COMMAND Find the largest value among the counter frequencies. RESULT mode_count]
            [COMMAND Collect every key whose frequency equals the largest frequency into a list. RESULT mode]
            [COMMAND Return the list of most frequent values. RESULT mode]
        [END_SEQUENTIAL_BLOCK]
    [END_MAIN_FLOW]

    [ALTERNATIVE_FLOW: If the input data is empty, the frequency counter has no values and computing the maximum frequency fails.]
        [SEQUENTIAL_BLOCK]
            [COMMAND Attempting to compute the maximum frequency from an empty counter has no valid result. RESULT mode_count]
        [END_SEQUENTIAL_BLOCK]
    [END_ALTERNATIVE_FLOW]

[END_WORKER]
