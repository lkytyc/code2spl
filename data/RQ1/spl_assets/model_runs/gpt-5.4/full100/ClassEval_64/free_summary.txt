This code defines a `NumberConverter` class that groups together six static utility methods for converting numbers between decimal, binary, octal, and hexadecimal forms.

- `decimal_to_binary(decimal_num)`: takes a decimal integer and returns its binary representation as a string, without the `0b` prefix.
- `binary_to_decimal(binary_num)`: takes a binary string and converts it to a decimal integer.
- `decimal_to_octal(decimal_num)`: takes a decimal integer and returns its octal representation as a string, without the `0o` prefix.
- `octal_to_decimal(octal_num)`: takes an octal string and converts it to a decimal integer.
- `decimal_to_hex(decimal_num)`: takes a decimal integer and returns its hexadecimal representation as a string, without the `0x` prefix.
- `hex_to_decimal(hex_num)`: takes a hexadecimal string and converts it to a decimal integer.

The methods do not use or modify any instance state; they simply perform conversions and return the converted value.
