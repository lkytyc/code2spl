This class converts number words in English into digit strings.

When a `Words2Numbers` object is created, its initializer builds lookup tables for:
- basic numbers from “zero” to “nineteen”
- tens like “twenty”, “thirty”, etc.
- large scale words like “hundred”, “thousand”, “million”, and so on
- a small set of irregular ordinal words such as “first”, “second”, and “twelfth”
- ordinal suffix rules so words ending in things like “th” or “ieth” can be mapped back to their base number word

The main method, `text2int(textnum)`, takes a string input. It first treats hyphens as spaces, so something like a hyphenated number can be read as separate words. It then processes the text word by word.

As it reads words:
- If a word is a recognized ordinal special case, it adds that numeric value to the current number being built.
- Otherwise, it tries to normalize ordinal endings, for example turning forms like “twentieth” into the base word “twenty”.
- If the resulting word is a known number word, it updates the current numeric value using the stored scale/increment rules.
- If the word is not recognized as part of a number, the method ends any number currently being built, appends its numeric value to the output text, then appends the unrecognized word unchanged.

This means the method does not require the entire input to be only a number. It can replace number-word sequences inside a larger sentence and leave other words alone. The return value is a string, not an integer.

Examples of behavior implied by the code:
- number phrases are converted into digits
- ordinal words can also be converted
- non-number words are preserved in place
- if a number sequence ends at the end of the input, it is appended to the output then

The `is_valid_input(textnum)` method checks whether every word in the input can be interpreted as a number word. It applies the same hyphen handling and ordinal normalization as `text2int`, but instead of converting, it returns:
- `True` if all words are recognized as valid number-related words
- `False` as soon as it finds a word that is not recognized

The two methods share the same internal dictionaries and ordinal-handling rules prepared in `__init__`.
