This code defines a `MovieTicketDB` class that manages a simple movie ticket database using SQLite.

When an instance is created, it takes a database file name as input, opens a connection to that SQLite database, creates a cursor, and immediately ensures that a `tickets` table exists. That table stores one row per ticket with these fields: an integer `id` as the primary key, plus `movie_name`, `theater_name`, `seat_number`, and `customer_name`.

The class provides these behaviors:

- `create_table()`: Creates the `tickets` table if it does not already exist, then saves the change.
- `insert_ticket(movie_name, theater_name, seat_number, customer_name)`: Adds a new ticket record with the provided movie, theater, seat, and customer values, then commits the insert.
- `search_tickets_by_customer(customer_name)`: Looks up all ticket rows whose `customer_name` exactly matches the given value, fetches all matching records, and returns them.
- `delete_ticket(ticket_id)`: Removes the ticket row whose `id` matches the provided ticket ID, then commits the deletion.

The main interaction pattern is that the constructor sets up the database connection and table, and the other methods reuse the same cursor and connection to insert, query, or delete ticket records. The query method returns the matching rows, while the insert and delete methods only perform database updates.
