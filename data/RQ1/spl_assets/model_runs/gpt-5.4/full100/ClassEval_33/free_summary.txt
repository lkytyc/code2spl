This code defines a `DiscountStrategy` class that represents a customer order and calculates its total price and final amount due, optionally applying a promotion.

When an instance is created, it takes:
- `customer`: expected to be a dictionary containing at least a `'fidelity'` value
- `cart`: expected to be a collection of item dictionaries, where each item has at least `'quantity'`, `'price'`, and sometimes `'product'`
- `promotion`: an optional callable that accepts the order object and returns a discount amount

The class stores those inputs and immediately calculates the order total.

Main behavior:
- `total()` computes the sum of `quantity * price` for every item in the cart, stores it internally, and returns it.
- `due()` calculates the final amount to pay. If no promotion was provided, the discount is zero. Otherwise, it calls the promotion function with the current order object and subtracts the returned discount from the stored total.

The class also includes three static promotion methods that can be passed in as the `promotion` argument:
- `FidelityPromo(order)`: gives a 5% discount on the whole order if the customer’s fidelity score is at least 1000.
- `BulkItemPromo(order)`: gives a 10% discount on each cart line whose quantity is 20 or more.
- `LargeOrderPromo(order)`: gives a 7% discount on the whole order if the cart contains 10 or more distinct products.

Important interactions:
- Promotions are not applied automatically; one of the static methods must be passed in explicitly as the `promotion`.
- The promotion functions receive the order object and use its data and methods, especially `order.total()`, `order.customer`, and `order.cart`, to determine the discount.
- The total is cached in a private attribute, but some promotions recalculate it by calling `total()` again.
