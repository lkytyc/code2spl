This code defines an `EncryptionUtils` class that groups together three different text-encryption methods.

When an object is created, it stores a `key` value on the instance. That stored key is only used by the Vigenère cipher method.

The class methods are:

- `caesar_cipher(plaintext, shift)`  
  Takes a text string and an integer shift. It processes each character one by one:
  - Alphabetic characters are shifted forward through the alphabet by the given amount, wrapping around from `z` to `a` or `Z` to `A`.
  - Uppercase and lowercase letters are preserved as uppercase or lowercase.
  - Non-letter characters are left unchanged.
  It returns the resulting encrypted string.

- `vigenere_cipher(plain_text)`  
  Takes a text string and encrypts it using the instance’s stored `key`.
  - For each alphabetic character, it calculates a shift amount from the corresponding key character (`a` = 0, `b` = 1, etc.).
  - The key advances only when a letter in the input is processed; non-letter characters do not consume key characters.
  - The encryption is done alphabetically with wraparound.
  - The original case of each letter is preserved.
  - Non-letter characters are copied unchanged.
  It returns the encrypted string.

- `rail_fence_cipher(plain_text, rails)`  
  Takes a text string and a number of rails, then applies a rail fence transposition:
  - It lays out the characters in a zigzag pattern across the specified number of rows.
  - After placing all characters, it reads the rows from top to bottom to build the encrypted text.
  - Unlike the other two methods, this one does not treat letters specially; it places every character as-is.
  It returns the rearranged encrypted string.

Overall, the class provides three independent encryption routines: a shift-based Caesar cipher, a key-based Vigenère cipher that uses the object’s stored key, and a rail fence transposition cipher that uses a caller-provided rail count.
