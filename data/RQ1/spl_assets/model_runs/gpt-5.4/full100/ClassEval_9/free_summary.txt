This code defines a `BigNumCalculator` class with three static methods for doing arithmetic on whole numbers represented as strings: `add`, `subtract`, and `multiply`.

It does not rely on creating one calculator object; the methods are called directly on the class. Each method takes two string inputs, where each string is expected to contain digits of a non-decimal integer, and each method returns the result as a string.

`add(num1, num2)` performs manual digit-by-digit addition. It first pads the shorter string with leading zeroes so both inputs have the same length. Then it works from right to left, adding corresponding digits plus any carry from the previous step. It stores each output digit and, if there is a carry left at the end, puts that at the front. The returned value is the full sum as a string.

`subtract(num1, num2)` performs manual subtraction and can produce a negative result. It first decides which number is larger by comparing lengths and, when lengths match, comparing the strings directly. If the second number is larger, it swaps the inputs and remembers that the final answer should be negative. It then pads both strings to equal length and subtracts from right to left, using borrowing when needed. Afterward it removes leading zeroes from the result, leaving at least one digit. If the original operation should be negative, it adds `-` to the front. The returned value is the difference as a string.

`multiply(num1, num2)` performs grade-school multiplication. It creates a list of zeroes large enough to hold the maximum possible number of digits in the product. It then multiplies every digit of the first number by every digit of the second, from right to left, and accumulates the partial results into the proper positions in the result list while handling carries. Once all digit pairs have been processed, it skips leading zeroes and returns the remaining digits joined together as a string.

The methods are independent of each other; none of them call the others.
