This code defines an `EmailClient` class that models a simple email inbox with a storage limit.

- Each client is created with an email address and a capacity, and starts with an empty inbox.
- `send_to(recv, content, size)` tries to send an email from one client to another:
  - It checks whether the recipient can fit the new email using `is_full_with_one_more_email(size)`.
  - If there is space, it creates an email record containing sender, receiver, content, size, timestamp, and a `"unread"` state, then appends it to the recipient’s inbox and returns `True`.
  - If there is not enough space, it calls `clear_inbox(size)` on the sender object and returns `False`.
- `fetch()` looks through the client’s inbox for the first unread email:
  - If the inbox is empty, it returns `None`.
  - Otherwise, it marks the first unread email as `"read"` and returns that email.
  - If all emails are already read, it returns `None`.
- `is_full_with_one_more_email(size)` checks whether adding an email of the given size would exceed the inbox capacity.
- `get_occupied_size()` sums the sizes of all emails currently in the inbox.
- `clear_inbox(size)` removes emails from the front of the inbox until at least the requested amount of space has been freed, or the inbox becomes empty. It does nothing if the client’s address string is empty.

The code uses `datetime.now()` only to store a formatted timestamp on sent emails.
