This code defines a utility class, `SQLQueryBuilder`, with four static methods that build SQL command strings.

- `select(table, columns='*', where=None)`: returns a `SELECT` query for the given table. If `columns` is not `'*'`, it joins the provided column names with commas. If a `where` dictionary is supplied, it adds conditions joined with `AND`, using each key as a column name and each value as a quoted string.
- `insert(table, data)`: returns an `INSERT INTO` statement using the dictionary keys as column names and the dictionary values as quoted values.
- `delete(table, where=None)`: returns a `DELETE FROM` statement, optionally adding a `WHERE` clause built from a dictionary in the same way as `select`.
- `update(table, data, where=None)`: returns an `UPDATE` statement that sets each column in `data` to its quoted value, and optionally adds a `WHERE` clause from a dictionary.

All methods take plain Python values and return SQL query strings; none of them execute the queries or interact with a database directly.
