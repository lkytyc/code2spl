This code defines a `URLHandler` class that stores a URL string and provides several helper methods to extract common parts of that URL.

When an instance is created, it takes one input: a URL string, which it saves in `self.url`.

The methods behave as follows:

- `get_scheme()` looks for `://` and, if found, returns everything before it as the scheme, such as `http` or `https`. If that separator is missing, it returns `None`.

- `get_host()` also looks for `://`. If present, it removes the scheme portion, then returns the text up to the next `/` as the host. If there is no `/`, it returns the rest of the string after the scheme. If no scheme separator exists, it returns `None`.

- `get_path()` again requires `://`. It removes the scheme, finds the first `/` after the host, and returns the path starting with that slash. If no path exists, or if the scheme separator is missing, it returns `None`.

- `get_query_params()` looks for a `?` and a `#`. If a `?` exists, it takes the substring after `?` up to `#`, splits it into `key=value` pairs using `&`, and builds a dictionary from those pairs. Only pairs with exactly one `=` are included. It returns that dictionary, which may be empty if the query string exists but has no valid pairs. If there is no `?`, it returns `None`.

- `get_fragment()` looks for `#` and, if found, returns everything after it as the fragment. If there is no fragment marker, it returns `None`.

There is no interaction with other classes or external libraries. Each method works independently by parsing the same stored URL string using simple string searches and splits.
