This code defines a `StockPortfolioTracker` class for managing a simple stock portfolio and cash balance.

- **Initialization:** It starts with an empty `portfolio` list and a provided `cash_balance`.
- **Adding stocks:** `add_stock` inserts a stock into the portfolio, or if a stock with the same `name` already exists, it increases that stock’s `quantity`.
- **Removing stocks:** `remove_stock` tries to decrease the quantity of a matching stock. If the quantity drops to zero, that stock is removed from the portfolio. It returns `True` when successful and `False` otherwise.
- **Buying stocks:** `buy_stock` checks whether there is enough cash to pay `price * quantity`. If not, it returns `False`. If there is enough, it adds the stock to the portfolio and subtracts the cost from cash, then returns `True`.
- **Selling stocks:** `sell_stock` first removes the stock quantity from the portfolio. If that fails, it returns `False`. If it succeeds, it adds the sale proceeds (`price * quantity`) to cash and returns `True`.
- **Portfolio value:** `calculate_portfolio_value` returns the total of the cash balance plus the current value of all stocks in the portfolio.
- **Summary:** `get_portfolio_summary` returns a tuple containing the total portfolio value and a list of per-stock summaries, where each entry includes the stock `name` and its computed value.
- **Stock value helper:** `get_stock_value` computes `price * quantity` for a single stock.

The methods work together by updating the shared `portfolio` and `cash_balance` state.
