This code defines a `Warehouse` class that keeps track of product inventory and customer orders using two dictionaries stored on the instance.

When a `Warehouse` object is created, it starts with:
- `inventory`: maps each product ID to a record containing the product name and current quantity
- `orders`: maps each order ID to a record containing the product ID, ordered quantity, and order status

The main behaviors are:

- `add_product(product_id, name, quantity)`: adds a new product to inventory if the product ID is not already present. If it already exists, it increases that product’s quantity instead of replacing the record.
- `update_product_quantity(product_id, quantity)`: adjusts the quantity of an existing product by adding the provided amount, which can increase or decrease stock. If the product ID is missing, nothing happens.
- `get_product_quantity(product_id)`: returns the current quantity for a product if it exists; otherwise returns `False`.
- `create_order(order_id, product_id, quantity)`: checks whether enough stock is available for the requested product by calling `get_product_quantity`. If enough quantity exists, it reduces inventory by calling `update_product_quantity` with a negative amount, then stores a new order with status `"Shipped"`. If there is not enough stock, it returns `False`.
- `change_order_status(order_id, status)`: updates the status of an existing order. If the order does not exist, it returns `False`.
- `track_order(order_id)`: returns the current status of an order if found; otherwise returns `False`.

Important interactions between methods:
- `create_order` depends on `get_product_quantity` to check stock before fulfilling an order.
- `create_order` also uses `update_product_quantity` to subtract the ordered amount from inventory.

Overall, the class provides a simple in-memory warehouse system for adding products, adjusting stock, creating shipped orders when inventory is sufficient, updating order status, and checking order status.
