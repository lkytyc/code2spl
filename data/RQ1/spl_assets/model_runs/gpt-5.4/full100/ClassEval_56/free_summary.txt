This code defines a `MetricsCalculator` class for binary classification evaluation.

- It keeps running counts of:
  - true positives
  - false positives
  - false negatives
  - true negatives

- The `update(predicted_labels, true_labels)` method compares two sequences of labels pairwise using `zip(...)` and increments those counters based on each predicted/true label combination. It assumes labels are `1` for positive and `0` for negative.

- The metric methods all take `predicted_labels` and `true_labels` as input:
  - `precision(...)` updates the counts, then returns `TP / (TP + FP)`, or `0.0` if there are no predicted positives.
  - `recall(...)` updates the counts, then returns `TP / (TP + FN)`, or `0.0` if there are no actual positives.
  - `f1_score(...)` updates the counts, then computes precision and recall and returns their harmonic mean, or `0.0` if both are zero.
  - `accuracy(...)` updates the counts, then returns `(TP + TN) / total`, or `0.0` if no examples have been counted.

Important interaction detail: each metric method calls `update(...)`, so calling them repeatedly with the same data will keep increasing the stored counters rather than recomputing from scratch.
