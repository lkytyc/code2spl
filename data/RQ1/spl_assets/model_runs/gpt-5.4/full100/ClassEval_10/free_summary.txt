This class takes a string that is supposed to contain binary digits and processes it in a few ways.

- When an instance is created, it stores the input string and immediately removes every character that is not `0` or `1`.
- It can then report basic binary statistics:
  - how many `0`s and `1`s there are as fractions of the total cleaned length
  - the total bit length
- It can also convert the cleaned binary string into text:
  - it groups the bits into 8-bit chunks
  - each chunk is interpreted as a base-2 integer
  - the resulting bytes are decoded either as ASCII or UTF-8

Important interactions:
- `__init__` calls `clean_non_binary_chars` automatically.
- Both conversion methods assume the remaining binary string can be read in 8-bit pieces and that the decoded bytes form valid ASCII or UTF-8 text.

The methods return:
- a dictionary for `calculate_binary_info`
- a decoded string for `convert_to_ascii`
- a decoded string for `convert_to_utf8`
