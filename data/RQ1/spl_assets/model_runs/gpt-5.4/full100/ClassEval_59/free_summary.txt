This code defines a `MovieBookingSystem` class that stores movies, their showtimes, ticket price, and a square seat layout for each movie.

When a `MovieBookingSystem` object is created, it starts with an empty list of movies.

The `add_movie` method adds a new movie to that list. It takes:
- a movie name,
- a price,
- a start time string in `HH:MM` format,
- an end time string in `HH:MM` format,
- and `n`, which determines the seat grid size.

It converts the start and end times into `datetime` objects and creates an `n x n` NumPy array filled with zeros to represent seats. A zero means unbooked.

The `book_ticket` method tries to book seats for a movie by name. It searches through the stored movies until it finds one with the matching name. It then checks each requested seat position from `seats_to_book`, which is expected to contain row/column index pairs. If a seat is currently `0`, it changes it to `1` to mark it booked. If any requested seat is already booked, it immediately returns `"Booking failed."` If all requested seats are successfully marked, it returns `"Booking success."` If no movie with that name exists, it returns `"Movie not found."`

The `available_movies` method returns a list of movie names whose showtimes fall entirely within a given time window. It takes a start time and end time as `HH:MM` strings, converts them to `datetime` objects, and includes any movie whose start time is at or after the requested start and whose end time is at or before the requested end.

Important interactions:
- All movie data is stored in `self.movies` as dictionaries.
- `add_movie` creates those dictionaries and initializes the seat matrix.
- `book_ticket` reads and updates the seat matrix for a matching movie.
- `available_movies` reads the stored start and end times to filter movies by schedule.
