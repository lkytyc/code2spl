This code defines a `BankAccount` class that stores and updates an account balance.

- When a `BankAccount` is created, it takes an optional starting `balance`, which defaults to `0`.
- The `deposit(amount)` method adds money to the account. If the amount is negative, it raises a `ValueError` with the message `"Invalid amount"`. Otherwise, it updates the balance and returns the new balance.
- The `withdraw(amount)` method removes money from the account. It raises a `ValueError` if the amount is negative, and also raises a `ValueError` with `"Insufficient balance."` if the amount is greater than the current balance. If the withdrawal is valid, it subtracts the amount and returns the new balance.
- The `view_balance()` method returns the current balance without changing it.
- The `transfer(other_account, amount)` method moves money from one account object to another by first calling `withdraw(amount)` on the current account and then calling `deposit(amount)` on `other_account`.

The main interaction between methods is in `transfer`, which reuses the existing withdrawal and deposit logic instead of directly changing balances. This means transfer automatically follows the same validation rules as those methods. The transfer method does not return a value.
