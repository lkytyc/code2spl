This code defines a `StudentDatabaseProcessor` class for working with a SQLite database file given at construction time.

- `__init__(database_name)` stores the database filename.
- `create_student_table()` opens the database and creates a `students` table if it does not already exist. The table has columns for `id` (primary key), `name`, `age`, `gender`, and `grade`.
- `insert_student(student_data)` inserts one student record into the `students` table using values taken from a dictionary with keys `name`, `age`, `gender`, and `grade`.
- `search_student_by_name(name)` looks up all rows in `students` whose `name` matches the given value exactly, and returns the matching rows as a list.
- `delete_student_by_name(name)` deletes all rows in `students` whose `name` matches the given value exactly.

Each method opens its own SQLite connection, uses a cursor to run the SQL command, commits changes when needed, and closes the connection afterward.
