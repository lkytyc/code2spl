This code defines a class named `Interpolation` that provides two static utility methods for estimating values between known data points.

The class itself does not store any state. Its constructor does nothing, and both interpolation methods can be called without creating an instance.

`interpolate_1d(x, y, x_interp)` performs 1-dimensional linear interpolation:
- `x` is a sequence of known x-coordinates.
- `y` is a sequence of known y-values corresponding to `x`.
- `x_interp` is a sequence of x-values where interpolated y-values are wanted.
- For each target value in `x_interp`, the method searches through adjacent pairs in `x` to find the interval that contains it.
- Once it finds a matching interval, it computes the corresponding y-value by linear interpolation between the two surrounding points and adds that result to the output list.
- It returns a list of interpolated y-values.
- If a target x-value does not fall inside any interval, nothing is added for that value.

`interpolate_2d(x, y, z, x_interp, y_interp)` performs 2-dimensional bilinear interpolation:
- `x` and `y` are sequences defining grid coordinates in each dimension.
- `z` is a 2D grid of known values indexed by the x and y positions.
- `x_interp` and `y_interp` are sequences of target coordinates, used in pairs.
- The method processes each `(xi, yi)` pair from `zip(x_interp, y_interp)`.
- For each pair, it finds the x-interval and y-interval that contain the target point.
- It then uses the four surrounding grid values from `z` to compute an interpolated value with the bilinear interpolation formula.
- The result is appended to the output list, which is returned at the end.
- As with the 1D method, if a point is outside the covered intervals, no value is added for that point.

Important interaction details:
- There is no interaction between the two interpolation methods; they are independent.
- The 2D method relies on `z[i][j]`, `z[i][j+1]`, `z[i+1][j]`, and `z[i+1][j+1]` matching the structure implied by `x` and `y`.
- Both methods assume the coordinate lists are ordered so interval checks like `x[i] <= value <= x[i+1]` work correctly.
