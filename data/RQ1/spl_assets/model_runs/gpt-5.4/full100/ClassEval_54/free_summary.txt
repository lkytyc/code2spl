This code defines a `MahjongConnect` class for a simple tile-matching board game.

- When created, it takes a board size and a list of icons, then builds a 2D board filled with random icons.
- `create_board()` makes the random board.
- `is_valid_move(pos1, pos2)` checks whether two positions:
  - are inside the board,
  - are not the same cell,
  - contain the same icon,
  - and are connected by a valid path according to the game’s path rule.
- `has_path(pos1, pos2)` searches from the first position using depth-first search through adjacent cells (up, down, left, right), but only moves through cells with the same icon as the current cell.
- `remove_icons(pos1, pos2)` clears the two selected positions by replacing their contents with a space character.
- `is_game_over()` returns true only when every cell on the board has been cleared.

Overall, the class stores the board state, checks whether a pair of matching tiles can be connected, removes matched tiles, and detects when the board is empty.
