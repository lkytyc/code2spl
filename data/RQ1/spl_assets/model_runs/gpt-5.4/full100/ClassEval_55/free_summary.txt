This class stores an input string and provides a way to return its longest palindromic substring.

How it works:

- `__init__(input_string)` saves the original string on the instance.
- `palindromic_length(center, diff, string)` is a recursive helper that measures how far a palindrome extends around a given center position in a string.
  - It compares characters equally far to the left and right of `center`.
  - If it reaches the edge of the string or finds a mismatch, it stops and returns `0`.
  - Otherwise, it counts that matching pair and recurses outward, returning the total number of matching expansion steps.

Main method:

- `palindromic_string()` builds and returns the longest palindrome found in the stored input.
  - It first creates a modified version of the input by inserting `|` characters between adjacent characters. This lets the code treat even-length and odd-length palindromes in a similar way.
  - It then checks every position in that modified string as a possible palindrome center.
  - For each center, it calls `palindromic_length(...)` to get how many matching layers extend outward.
  - It tracks the center with the greatest palindrome length found.
  - After that, it slices the corresponding palindromic region from the modified string, removes the inserted `|` separators, and returns the result.

Inputs and outputs:

- Input: a string passed when creating the `Manacher` object.
- Output: `palindromic_string()` returns a string representing the longest palindromic substring found.

Important interactions:

- `palindromic_string()` is the public-facing method and repeatedly uses `palindromic_length()` as its helper.
- The helper does not use the original input directly; it works on the separator-augmented string created inside `palindromic_string()`.

Behavior notes visible from the code:

- The search is based on expanding around each possible center.
- The method keeps only one longest palindrome; if multiple have the same length, it keeps the first one that achieved the maximum.
- The code assumes the input string is non-empty, because it accesses the last character when building the modified string.
