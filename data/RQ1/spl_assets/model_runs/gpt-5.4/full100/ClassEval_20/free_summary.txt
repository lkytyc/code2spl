This code defines a `Chat` class that manages a simple in-memory messaging system between users.

The class stores users in a dictionary where each username maps to a list of message records.

Behavior of the methods:

- `__init__` initializes an empty user store.
- `add_user(username)` adds a new user with an empty message list. It returns `True` if the user was added, or `False` if that username already exists.
- `remove_user(username)` deletes an existing user. It returns `True` if the user was removed, or `False` if the username is not present.
- `send_message(sender, receiver, message)` sends a message from one user to another. It first checks that both sender and receiver already exist; if either does not, it returns `False`. If both exist, it creates a message record containing the sender, receiver, message text, and a timestamp formatted as `YYYY-MM-DD HH:MM:SS`. That same record is appended to both the sender’s and receiver’s message lists, and the method returns `True`.
- `get_messages(username)` returns the stored message list for a user. If the user does not exist, it returns an empty list.

Important interactions:

- `send_message` depends on users having already been added with `add_user`.
- Messages are stored per user, but the same message record is placed in both participants’ histories.
- Removing a user only deletes that user’s entry; it does not remove message records already stored in other users’ lists.

Inputs are usernames and message text as method arguments. Outputs are booleans for success/failure in user and message operations, and a list of message dictionaries when retrieving messages.
