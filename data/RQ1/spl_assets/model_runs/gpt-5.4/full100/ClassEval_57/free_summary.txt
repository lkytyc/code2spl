This code defines a class, `MetricsCalculator2`, with two static utility methods for evaluating ranked results: `mrr` and `map`.

Both methods expect either:
- a single tuple of the form `(sub_list, total_num)`, or
- a list of such tuples.

In each tuple:
- `sub_list` is treated like a ranked list of binary relevance values, where nonzero entries represent relevant items and zeros represent non-relevant items.
- `total_num` is the total number of relevant items for that case.

General behavior:
- If the input is neither a list nor a tuple, the method raises an exception.
- If the input is empty, the method returns `(0.0, [0.0])`.
- For a single tuple, the method returns:
  - the metric value for that one case, and
  - a one-element list containing that same value.
- For a list of tuples, the method computes the metric for each tuple, returns:
  - the mean across all cases, and
  - the list of per-case metric values.

`mrr(data)`:
- Computes reciprocal rank.
- For each ranked list, it builds rank weights `1, 1/2, 1/3, ...`.
- It multiplies those weights by the relevance array and finds the first positive result, which corresponds to the first relevant item’s reciprocal rank.
- If `total_num` is zero, it returns `0.0` for that case.

`map(data)`:
- Computes average precision.
- For each ranked list, it again builds rank weights `1, 1/2, 1/3, ...`.
- It creates a list where each relevant item is assigned its running count among relevant items seen so far, while non-relevant items get `0`.
- It multiplies that list by the reciprocal rank weights, sums the result, and divides by `total_num` to get average precision.
- If `total_num` is zero, it returns `0.0` for that case.

Class and method interactions:
- The class has no stored state; `__init__` does nothing.
- Both metric methods are independent static methods and do not call each other.
- NumPy is used for array conversion, elementwise multiplication, summation, and averaging.
