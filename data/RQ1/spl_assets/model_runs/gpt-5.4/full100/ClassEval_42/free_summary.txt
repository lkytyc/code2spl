This code defines a `Hotel` class that tracks room availability and simple bookings by room type.

When a `Hotel` object is created, it takes:
- `name`: the hotel’s name
- `rooms`: a dictionary mapping room types to how many of that type are available, such as `{'single': 5, 'double': 3}`

The object stores:
- `available_rooms`: the current count of available rooms for each room type
- `booked_rooms`: a nested dictionary that records bookings by room type and guest name, storing how many rooms that guest booked

Main behavior:

- `book_room(room_type, room_number, name)`:
  - Checks whether the requested room type exists in `available_rooms`.
  - If enough rooms of that type are available, it records the booking under the guest’s name, reduces the available count, and returns `"Success!"`.
  - If the requested number is more than available but some rooms still remain, it returns the number still available for that type.
  - If the room type does not exist or none are available, it returns `False`.

- `check_in(room_type, room_number, name)`:
  - Verifies that the guest has a booking for that room type.
  - If the requested check-in count is greater than what the guest booked, it returns `False`.
  - If it matches exactly, it removes that guest’s booking entry for that room type.
  - If it is less than the booked amount, it reduces the stored booked count for that guest.
  - This method does not return a success value when the operation succeeds.

- `check_out(room_type, room_number)`:
  - Adds the given number of rooms back into `available_rooms` for that room type.
  - If the room type was not already present, it creates it with that count.

- `get_available_rooms(room_type)`:
  - Returns the current available count for the given room type.

Important interactions:
- `book_room` decreases `available_rooms` and writes into `booked_rooms`.
- `check_in` only changes `booked_rooms`; it does not affect `available_rooms`.
- `check_out` increases `available_rooms` without checking `booked_rooms`.
