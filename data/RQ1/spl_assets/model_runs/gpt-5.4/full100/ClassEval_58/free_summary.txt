This code defines a `MinesweeperGame` class that creates and manages a simple square Minesweeper-style game board.

When a game object is created, it takes two inputs:
- `n`: the width and height of the board, making an `n x n` grid
- `k`: the number of mines to place

During initialization, it creates:
- `minesweeper_map`: the hidden board containing mines and neighbor counts
- `player_map`: the visible board for the player, initially filled with `'-'`
- `score`: starts at `0`

The hidden board is generated by `generate_mine_sweeper_map()`. It starts as a grid of zeros, then places mines randomly using `random.randint`. Each mine is marked as `'X'`, and the method increases the count in each surrounding cell, as long as that surrounding cell is within bounds and is not itself a mine. It checks all eight neighboring positions individually.

One important detail is that mine positions are chosen independently each time without checking whether a mine was already placed there. That means repeated random picks can overwrite the same cell, so the final board may contain fewer than `k` distinct mines.

The player-visible board is generated by `generate_playerMap()`, which returns an `n x n` grid of `'-'` characters.

The `sweep(x, y)` method is the main action method. It checks the hidden board at the given position:
- If the selected cell contains a mine (`'X'`), it returns `False`
- Otherwise, it reveals that cell on `player_map`, increases `score` by 1, and checks whether the player has won
- If all non-mine cells have been revealed, it returns `True`
- If the game is still in progress, it returns the updated `player_map`

Winning is determined by `check_won(map)`. It scans the provided map and returns `True` only if every non-mine cell in the hidden board has been revealed. If any safe cell is still `'-'`, it returns `False`.

In summary, the class builds a random Minesweeper board, keeps a separate hidden and visible grid, lets the caller reveal one cell at a time, tracks score, and reports whether the move hit a mine, won the game, or simply updated the current player view.
