This code defines an `ImageProcessor` class that wraps a few basic image-editing operations using Pillow.

The class stores a single image in `self.image`, which starts as `None`.

Its methods work as follows:

- `load_image(image_path)`: opens an image file from the given path and stores it as the current image.
- `save_image(save_path)`: saves the current image to the given path, but only if an image has already been loaded.
- `resize_image(width, height)`: changes the current image to the specified width and height, if an image is loaded.
- `rotate_image(degrees)`: rotates the current image by the given number of degrees, if an image is loaded.
- `adjust_brightness(factor)`: changes the brightness of the current image by creating a Pillow brightness enhancer for the current image and replacing the stored image with the adjusted result, if an image is loaded.

The methods that modify the image update `self.image` in place by replacing it with the transformed version. The code imports `Image`, `ImageEnhance`, and `ImageChops`, but `ImageChops` is not used anywhere in the class.
