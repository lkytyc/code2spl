This code defines a `PersonRequest` class that stores three pieces of input data: `name`, `sex`, and `phoneNumber`.

When an object is created, the constructor immediately validates each value through helper methods before saving them to the instance.

Validation rules:
- `name` must be non-empty and no longer than 33 characters.
- `sex` must be exactly one of `"Man"`, `"Woman"`, or `"UGM"`.
- `phoneNumber` must be non-empty, must contain exactly 11 characters, and must consist only of digits.

If any value fails validation, the corresponding field is set to `None`; otherwise the original value is stored. The class does not return anything or perform any other actions beyond these validations and assignments.
