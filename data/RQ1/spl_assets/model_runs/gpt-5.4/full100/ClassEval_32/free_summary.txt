This code defines a `DecryptionUtils` class for decoding text with three classic ciphers.

- The class is initialized with a `key`, which is stored for later use by the Vigenère decoder.
- `caesar_decipher(ciphertext, shift)` takes an encrypted string and a numeric shift, and returns the Caesar-decoded text. It shifts only alphabetic characters backward by the given amount, preserves uppercase/lowercase, and leaves non-letters unchanged.
- `vigenere_decipher(ciphertext)` takes an encrypted string and uses the instance’s stored key to decode it with the Vigenère cipher. It applies key-based shifts only to letters, preserves case, and leaves non-letters unchanged.
- `rail_fence_decipher(encrypted_text, rails)` takes an encrypted string and a number of rails, reconstructs the rail-fence zigzag pattern, and returns the recovered plaintext. It uses an internal 2D grid to mark positions, fill in the ciphertext, and then read the text back in zigzag order.

Overall, the class provides three separate decryption methods and does not perform any input/output beyond returning decrypted strings.
