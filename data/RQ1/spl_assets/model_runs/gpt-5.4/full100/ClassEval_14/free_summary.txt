This code defines a `BookManagementDB` class that manages a simple book database using SQLite.

When an instance is created, it takes a database file name as input, opens a connection to that SQLite database, creates a cursor, and immediately ensures that a `books` table exists. The table has four columns: `id` as the primary key, `title`, `author`, and `available`, which is stored as an integer.

The class provides methods to modify and read the table:

- `add_book(title, author)` inserts a new book record with the given title and author, and marks it as available by setting `available` to `1`.
- `remove_book(book_id)` deletes the book whose `id` matches the given value.
- `borrow_book(book_id)` updates the matching book so its `available` value becomes `0`, indicating it is not available.
- `return_book(book_id)` updates the matching book so its `available` value becomes `1`, indicating it is available again.
- `search_books()` retrieves all rows from the `books` table and returns them as a list of records.

Each method that changes the database commits the transaction immediately. The methods interact through the shared database connection and cursor stored on the class instance.
