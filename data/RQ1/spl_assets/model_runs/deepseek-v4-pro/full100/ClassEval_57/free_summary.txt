This code defines a class called `MetricsCalculator2` that computes two information retrieval metrics: Mean Reciprocal Rank (MRR) and Mean Average Precision (MAP).

**Input format:** Both methods accept either a single tuple `(sub_list, total_num)` or a list of such tuples. Each tuple contains:
- `sub_list`: A sequence of binary values (0s and 1s) indicating whether each item in a ranked list is relevant (1) or not (0)
- `total_num`: The total number of relevant items for that query

**MRR method:** Calculates the reciprocal rank—the inverse of the position of the first relevant item. For a single tuple, it returns that reciprocal rank value. For a list of tuples, it returns the mean reciprocal rank across all queries plus a list of individual reciprocal rank values.

**MAP method:** Calculates average precision for each query by computing precision at each relevant item position and averaging those values. For a single tuple, it returns that average precision. For a list of tuples, it returns the mean average precision across all queries plus a list of individual average precision values.

**Edge cases handled:** Empty input returns 0.0 with a list containing 0.0. If `total_num` is 0, the metric is 0.0. Invalid input types (not list or tuple) raise an exception.

Both methods are static and use NumPy for array operations to compute ranking weights and multiply them against relevance indicators.
