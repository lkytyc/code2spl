This code defines a `DocFileHandler` class that manages reading from and writing to Microsoft Word (.docx) files. It takes a file path when initialized and provides methods to:

- **Read text**: Extract all paragraph text from the document and return it as a single string with paragraphs separated by newlines.
- **Write text**: Create a new document with the given content, optionally setting font size and text alignment (left, center, or right), then save it to the file path. Returns success/failure.
- **Add heading**: Open an existing document, add a heading with a specified level (default level 1), and save. Returns success/failure.
- **Add table**: Open an existing document, add a table using a 2D list of data (converting each cell value to string), and save. Returns success/failure.

All write operations use try-except blocks to return `True` on success or `False` if any error occurs. The alignment helper method converts text alignment strings to Word's internal alignment constants, defaulting to left alignment if an invalid option is provided.
