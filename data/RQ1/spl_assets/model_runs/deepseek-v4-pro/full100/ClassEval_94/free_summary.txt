This code defines a `VendingMachine` class that simulates a basic vending machine.

**State:**
- It tracks an inventory of items, where each item has a name, price, and quantity.
- It also tracks the current balance of money inserted by the user.

**Methods and behavior:**
- `add_item`: Adds a new item to the inventory if it doesn’t already exist. If the item already exists, it does nothing (because `restock_item` would handle existing items).
- `insert_coin`: Adds a given amount to the machine’s balance and returns the new balance.
- `purchase_item`: Attempts to buy an item. If the item exists, is in stock, and the balance is sufficient, it deducts the price from the balance, decreases the item’s quantity by one, and returns the remaining balance. Otherwise, it returns `False`.
- `restock_item`: Increases the quantity of an existing item. Returns `True` if the item was found and restocked, otherwise `False`.
- `display_items`: Returns a string listing all items with their prices and quantities, each on a new line. If the inventory is empty, it returns `False`.

**Inputs and outputs:**
- Inputs are method arguments: item names, prices, quantities, and coin amounts.
- Outputs are return values: updated balance, `True`/`False` for restocking, `False` for failed purchases or empty display, or a formatted string of inventory items.
