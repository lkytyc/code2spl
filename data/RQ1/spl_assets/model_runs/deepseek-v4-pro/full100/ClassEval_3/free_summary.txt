This code defines a class called `ArrangementCalculator` that works with a collection of items to calculate and generate arrangements (permutations) of those items.

**Inputs:**  
The class is initialized with a list of items (`datas`). Methods can also take an optional integer `m` specifying how many items to arrange at a time.

**Outputs:**  
- `count(n, m)` returns the number of possible arrangements of `n` items taken `m` at a time. If `m` is not provided or equals `n`, it returns the factorial of `n`.  
- `count_all(n)` returns the total number of arrangements for all possible lengths from 1 to `n`.  
- `select(m)` returns a list of all permutations of the stored items taken `m` at a time. If `m` is not given, it defaults to the total number of items.  
- `select_all()` returns a list of all permutations for every possible length from 1 to the total number of stored items.  
- `factorial(n)` is a helper that computes the factorial of `n`.

**Important interactions:**  
`select` uses Python’s `itertools.permutations` to generate the arrangements. `select_all` repeatedly calls `select` for each possible length and combines the results. The counting methods rely on `factorial` to compute values mathematically rather than generating the arrangements.
