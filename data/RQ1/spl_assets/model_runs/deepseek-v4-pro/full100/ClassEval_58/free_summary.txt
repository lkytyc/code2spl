This code implements a Minesweeper game. The `MinesweeperGame` class is initialized with a board size `n` and a number of mines `k`. It generates a hidden board (`minesweeper_map`) where mines are randomly placed as `'X'`, and adjacent cells are incremented to show the count of neighboring mines. It also creates a visible player board (`player_map`) initially filled with `'-'` to represent unrevealed cells, and tracks a score.

The `sweep` method lets a player reveal a cell at coordinates `(x, y)`. If the cell contains a mine, it returns `False` (game over). Otherwise, it reveals the number of adjacent mines on the player board, increments the score, and checks if the player has won by revealing all non-mine cells. If won, it returns `True`; otherwise, it returns the updated player board. The `check_won` method verifies that every unrevealed cell on the player board corresponds to a mine on the hidden board.
