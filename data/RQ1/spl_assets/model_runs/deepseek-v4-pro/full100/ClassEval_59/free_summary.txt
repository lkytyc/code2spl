This code defines a `MovieBookingSystem` class that manages movies and seat bookings.

**Data storage:**  
Each movie is stored as a dictionary containing its name, ticket price, start time, end time, and a 2D numpy array representing seats (0 = available, 1 = booked).

**Methods:**

- `add_movie(name, price, start_time, end_time, n)`  
  Adds a new movie with the given name, price, show times (in `HH:MM` format), and creates an `n` by `n` grid of available seats.

- `book_ticket(name, seats_to_book)`  
  Attempts to book a list of seats for a movie by name. Each seat is identified by row and column indices. If any requested seat is already booked, the method returns `"Booking failed."` and does not complete the booking. If all seats are available, they are marked as booked and the method returns `"Booking success."`. If the movie name is not found, it returns `"Movie not found."`.

- `available_movies(start_time, end_time)`  
  Returns a list of movie names whose show times fall entirely within the given time window (inclusive of the start and end boundaries).
