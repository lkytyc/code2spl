The `PageUtil` class provides pagination and search functionality for a list of data.

**Constructor:**  
It takes a list of items (`data`) and a `page_size` (number of items per page). It stores the data, calculates the total number of items, and computes the total number of pages by dividing the total items by the page size (rounding up).

**`get_page(page_number)`:**  
Returns the items for a given page number. If the requested page is out of range (less than 1 or greater than total pages), it returns an empty list. Otherwise, it slices the data to return only the items belonging to that page.

**`get_page_info(page_number)`:**  
Returns a dictionary with metadata about the requested page. If the page number is invalid, it returns an empty dictionary. For valid pages, it includes the current page number, items per page, total pages, total items, booleans indicating whether there is a previous or next page, and the actual page data.

**`search(keyword)`:**  
Searches the entire dataset for items whose string representation contains the given keyword. It returns a dictionary with the keyword, the total number of matching results, the number of pages needed to display those results (based on the same page size), and the list of matching items.
