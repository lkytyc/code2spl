The `DecryptionUtils` class provides three classical cipher decryption methods, initialized with a key used by the Vigenère deciphering method.

- **`caesar_decipher(ciphertext, shift)`**  
  Takes a ciphertext string and an integer shift. It shifts each alphabetic character backward by the given amount, preserving case and leaving non-alphabetic characters unchanged. Returns the decrypted plaintext.

- **`vigenere_decipher(ciphertext)`**  
  Uses the key stored in the instance to decrypt the ciphertext. It processes only alphabetic characters, advancing through the key for each letter, and preserves the original case of each character. Non-alphabetic characters are copied as-is. Returns the decrypted text.

- **`rail_fence_decipher(encrypted_text, rails)`**  
  Decrypts text that was encrypted with a rail fence cipher using the specified number of rails. It reconstructs the zigzag pattern, fills it with the encrypted characters, and then reads along the pattern to recover the plaintext. Returns the decrypted string.
