This code implements an expression calculator that evaluates mathematical expressions given as strings.

**Input:** A string containing a mathematical expression with numbers, operators (`+`, `-`, `*`, `/`, `%`), and parentheses.

**Output:** A floating-point number representing the result of evaluating the expression.

**How it works:**

1. **Transform** (`transform` method): Cleans the input by removing whitespace and trailing equals signs. It then handles unary minus signs by replacing them with a tilde (`~`) marker when they appear at the start of the expression or after operators or opening parentheses. If the expression starts with a negative number in parentheses (like `-(...)`), it prepends a `0` to make it `0-(...)`.

2. **Prepare** (`prepare` method): Converts the infix expression to postfix (Reverse Polish Notation) using a stack-based algorithm. It processes operators according to their precedence, handles parentheses, and builds a postfix stack of tokens (numbers and operators).

3. **Calculate** (`calculate` method): Evaluates the postfix expression. It pops tokens from the postfix stack, pushes numbers onto a result stack, and when encountering an operator, pops two operands, performs the operation using `Decimal` arithmetic (via the `_calculate` method), and pushes the result back. The final result is converted to a float and returned.

**Key components:**
- `postfix_stack`: Stores the postfix expression tokens.
- `operat_priority`: Array mapping operator characters to precedence levels.
- `is_operator`: Static method to check if a character is an operator.
- `compare`: Compares operator precedence for the postfix conversion.
- `_calculate`: Performs arithmetic operations using `Decimal` for precision.

The class uses `Decimal` internally for calculations to maintain precision, but returns the final result as a float.
