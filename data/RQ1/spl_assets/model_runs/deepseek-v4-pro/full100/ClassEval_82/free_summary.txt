This code defines a `StockPortfolioTracker` class that manages a stock portfolio and cash balance.

**Initialization:**  
The constructor takes an initial cash balance and sets up an empty portfolio list.

**Inputs and Outputs:**  
- Stocks are represented as dictionaries with keys for name, price, and quantity.
- Methods return booleans for success/failure, numeric values for calculations, or tuples containing portfolio value and a summary list.

**Key behaviors:**  
- `add_stock` adds a new stock to the portfolio or increases the quantity if the stock already exists.
- `remove_stock` decreases the quantity of a stock if enough shares are held, removing it entirely when quantity reaches zero. Returns `True` on success, `False` otherwise.
- `buy_stock` checks if there is enough cash to cover the purchase; if so, it adds the stock and deducts the cost from cash. Returns `True` or `False`.
- `sell_stock` attempts to remove the stock; if successful, it adds the sale proceeds to cash. Returns `True` or `False`.
- `calculate_portfolio_value` sums the cash balance plus the market value of all held stocks.
- `get_portfolio_summary` returns the total portfolio value and a list of summaries showing each stock’s name and current value.
- `get_stock_value` calculates the value of a single stock position (price × quantity).

**Interactions:**  
`buy_stock` uses `add_stock`; `sell_stock` uses `remove_stock`; `get_portfolio_summary` uses `get_stock_value` and `calculate_portfolio_value`.
