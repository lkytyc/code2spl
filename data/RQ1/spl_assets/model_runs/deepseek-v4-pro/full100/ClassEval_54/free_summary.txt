This code implements a simplified Mahjong Connect game board. It creates a grid of randomly placed icons, checks whether two selected positions form a valid move, removes matched icon pairs, and determines when the board is cleared.

**Inputs:**  
- `BOARD_SIZE`: a tuple specifying the number of rows and columns.  
- `ICONS`: a collection of symbols used to fill the board.

**Outputs / Behavior:**  
- `create_board()` fills the grid with randomly chosen icons.  
- `is_valid_move(pos1, pos2)` returns `True` if both positions are within bounds, are different, contain the same icon, and a path exists between them.  
- `has_path(pos1, pos2)` performs a depth-first search through adjacent cells that contain the same icon to see if the two positions are connected.  
- `remove_icons(pos1, pos2)` replaces the icons at both positions with blank spaces.  
- `is_game_over()` returns `True` when all cells are blank.

**Important interactions:**  
- `is_valid_move()` relies on `has_path()` to confirm connectivity before allowing a match.  
- `remove_icons()` assumes the move has already been validated.  
- The game ends only when every cell has been cleared.
