This code defines a `PDFHandler` class that works with PDF files using the PyPDF2 library.

**Initialization:** When creating a `PDFHandler` instance, you provide a list of file paths to PDF files. The class opens each PDF and stores reader objects for later use.

**Key methods:**

1. **`merge_pdfs(output_filepath)`**: Combines all the PDFs into a single PDF file. It iterates through every page of every PDF in the order they were provided, adds each page to a new PDF writer, and saves the result to the specified output path. Returns a confirmation message with the output location.

2. **`extract_text_from_pdfs()`**: Extracts text from every page of all PDFs. Returns a list where each element is the text content of one page, in the order the PDFs and pages appear.

**Inputs:** File paths to PDF files (provided at initialization), and an output file path for merging.

**Outputs:** A merged PDF file (from `merge_pdfs`) or a list of extracted text strings (from `extract_text_from_pdfs`).
