This code defines a Gomoku game (a five-in-a-row board game) with the following behavior:

**Class: GomokuGame**

**Initialization:**
- Takes a `board_size` parameter to create a square board of that dimension
- Creates an empty board filled with spaces (' ')
- Sets the first player as 'X'

**Methods:**

1. **`make_move(row, col)`**
   - Input: Row and column coordinates for placing a piece
   - Checks if the specified cell is empty
   - If empty: places the current player's symbol ('X' or 'O') at that position, switches the current player to the other symbol, and returns `True`
   - If occupied: returns `False` without making any changes

2. **`check_winner()`**
   - Scans the entire board for any five consecutive identical symbols
   - Checks four directions: horizontal, vertical, and two diagonals
   - Returns the winning symbol ('X' or 'O') if found, otherwise returns `None`

3. **`_check_five_in_a_row(row, col, direction)`** (helper method)
   - Input: Starting position and a direction to check
   - Counts consecutive matching symbols from the starting position in the given direction
   - Returns `True` if exactly five matching symbols are found in a row, `False` otherwise
   - Stops checking if it goes out of bounds or encounters a different symbol

The game alternates between 'X' and 'O' players, with 'X' always starting first.
