This code defines a class called `KappaCalculator` with two static methods for calculating inter-rater agreement statistics.

**`kappa(testData, k)`** calculates Cohen's kappa coefficient from a confusion matrix. It takes a square matrix of observed counts (where rows and columns represent the ratings of two raters) and the number of categories `k`. It computes the observed agreement (`P0`) from the diagonal elements, the expected agreement by chance (`Pe`) from the row and column totals, and returns Cohen's kappa as `(P0 - Pe) / (1 - Pe)`.

**`fleiss_kappa(testData, N, k, n)`** calculates Fleiss' kappa for measuring agreement among multiple raters. It takes a matrix where each row represents a subject and each column represents a category, with cell values being the number of raters who assigned that category to that subject. The parameters are: `N` (number of subjects), `k` (number of categories), and `n` (number of raters per subject). It computes the observed agreement (`P0`) by summing the squared category counts per subject, adjusts for the number of raters, and calculates the expected agreement (`Pe`) from the overall category proportions. It returns Fleiss' kappa as `(P0 - Pe) / (1 - Pe)`.

Both methods return a single floating-point value representing the respective kappa statistic.
