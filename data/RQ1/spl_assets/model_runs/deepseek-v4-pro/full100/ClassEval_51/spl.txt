# CLASS KappaCalculator

[DEFINE_WORKER: "Computes Cohen's kappa coefficient from a matrix by accumulating the diagonal elements as observed agreement and deriving expected agreement from the total and marginal sums." kappa]
    [INPUTS]
        <REF> testData </REF>: array-like "The input data converted to a NumPy matrix."
        <REF> k </REF>: int "The number of diagonal elements to include, controlling the loop range from 0 to k-1."
    [END_INPUTS]

    [OUTPUTS]
        <REF> cohens_coefficient </REF>: float "The computed Cohen's kappa coefficient."
    [END_OUTPUTS]

    [MAIN_FLOW]
        [SEQUENTIAL_BLOCK]
            [COMMAND Convert testData into a NumPy matrix and assign it to dataMat. RESULT dataMat]
            [COMMAND Initialize P0 to the float constant 0.0. RESULT P0]
            [COMMAND Within the for loop over i in range(k), add dataMat[i, i] multiplied by 1.0 to P0. RESULT P0]
            [COMMAND Compute xsum as the row sums of dataMat using np.sum(dataMat, axis=1). RESULT xsum]
            [COMMAND Compute ysum as the column sums of dataMat using np.sum(dataMat, axis=0). RESULT ysum]
            [COMMAND Compute sum as the total sum of all elements in dataMat using np.sum(dataMat). RESULT sum]
            [COMMAND Compute Pe by converting the element-wise product of ysum and xsum to float, then performing left-to-right division by sum twice. RESULT Pe]
            [COMMAND Update P0 to float(P0 / sum * 1.0). RESULT P0]
            [COMMAND Compute cohens_coefficient as float((P0 - Pe) / (1 - Pe)). RESULT cohens_coefficient]
            [COMMAND Return cohens_coefficient. RESULT cohens_coefficient]
        [END_SEQUENTIAL_BLOCK]
    [END_MAIN_FLOW]

[END_WORKER]

[DEFINE_WORKER: "Compute Fleiss' kappa statistic from an N-by-k count matrix by calculating observed agreement P0 and expected agreement Pe, then returning (P0 - Pe) / (1 - Pe)." fleiss_kappa]
    [INPUTS]
        <REF> testData </REF>: array-like or matrix "N by k matrix of classification counts."
        <REF> N </REF>: int "Number of rows/items in testData."
        <REF> k </REF>: int "Number of columns/categories in testData."
        <REF> n </REF>: int "Number of raters used to normalize per-item agreement."
    [END_INPUTS]

    [OUTPUTS]
        <REF> fleiss_kappa_statistic </REF>: float "Fleiss' kappa statistic as a scalar floating-point value."
    [END_OUTPUTS]

    [MAIN_FLOW]
        [SEQUENTIAL_BLOCK]
            [COMMAND Convert testData into a NumPy matrix dataMat with float dtype. RESULT dataMat]
            [COMMAND Create a k by 1 column vector oneMat filled with 1.0. If k is negative, this construction is invalid. RESULT oneMat]
            [COMMAND Initialize scalar accumulator sum to 0.0. RESULT sum]
            [COMMAND Initialize scalar accumulator P0 to 0.0. RESULT P0]
            [COMMAND For each row index i from 0 to N-1 inclusive, start an outer loop iteration and set temp to 0.0. If N is less than or equal to 0, skip the outer loop body entirely. RESULT temp]
            [COMMAND Within the outer loop over i, for each column index j from 0 to k-1 inclusive, add dataMat[i, j] to sum. If k is less than or equal to 0, skip the inner loop body but still execute the remaining outer loop body. RESULT sum]
            [COMMAND Within the same inner loop over j, for each column index j, add 1.0 * dataMat[i, j] ** 2 to temp. RESULT temp]
            [COMMAND Within the outer loop over i, after the inner loop over j completes, subtract n from temp, divide temp by (n - 1) * n, and add the result to P0. RESULT P0]
            [COMMAND After the outer loop completes, compute P0 = 1.0 * P0 / N. If N is zero, this division is undefined or raises a zero-division error depending on the runtime. RESULT P0]
            [COMMAND Compute ysum as the sum of dataMat along axis 0, producing a 1 by k row vector of column totals. RESULT ysum]
            [COMMAND For each i from 0 to k-1 inclusive, update ysum[0, i] = (ysum[0, i] / sum) ** 2. If k is less than or equal to 0, skip this loop. If sum is zero, the division is undefined or raises a zero-division error depending on the runtime. RESULT ysum]
            [COMMAND Compute Pe as the matrix product ysum * oneMat * 1.0, yielding a 1 by 1 matrix. RESULT Pe]
            [COMMAND Compute ans = (P0 - Pe) / (1 - Pe). If Pe equals 1, the denominator is zero and the result is undefined or infinite. RESULT ans]
            [COMMAND Return ans[0, 0] as the computed Fleiss kappa statistic. RESULT return_value]
        [END_SEQUENTIAL_BLOCK]
    [END_MAIN_FLOW]

[END_WORKER]
