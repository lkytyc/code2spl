This code defines a utility class called `IpUtil` that provides three static methods for working with IP addresses:

1. **`is_valid_ipv4`** - Takes an IP address string and returns `True` if it's a valid IPv4 address, or `False` if it's not.

2. **`is_valid_ipv6`** - Takes an IP address string and returns `True` if it's a valid IPv6 address, or `False` if it's not.

3. **`get_hostname`** - Takes an IP address string and attempts to resolve it to a hostname using reverse DNS lookup. Returns the hostname as a string if successful, or `None` if the lookup fails.

All methods use Python's built-in `socket` module for validation and resolution. The validation methods use `inet_pton` to check address format, while the hostname method uses `gethostbyaddr` for reverse DNS resolution.
