This code defines an `EncryptionUtils` class that provides three classical encryption methods. It is initialized with a key used by the Vigenère cipher.

- **`caesar_cipher(plaintext, shift)`**  
  Takes a plaintext string and an integer shift. It shifts each alphabetic character by the given amount, preserving case, while leaving non-alphabetic characters unchanged. Returns the encrypted string.

- **`vigenere_cipher(plain_text)`**  
  Takes a plaintext string and uses the instance’s key to encrypt it. Each alphabetic character is shifted based on the corresponding letter of the key (repeating the key as needed). The case of the original character is preserved, and non-alphabetic characters are left unchanged. Returns the encrypted string.

- **`rail_fence_cipher(plain_text, rails)`**  
  Takes a plaintext string and a number of rails. It arranges the characters in a zigzag pattern across the specified number of rails, then reads them row by row to produce the encrypted text. Returns the encrypted string.
