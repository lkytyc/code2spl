This code defines a `SQLGenerator` class that builds SQL query strings for a specific database table.

**Initialization:**  
The class is initialized with a table name, which is stored and used in all generated queries.

**Main methods:**  
- `select`: Generates a `SELECT` statement. It accepts optional lists of fields and a condition. If no fields are given, it selects all columns (`*`). If a condition is provided, it appends a `WHERE` clause.  
- `insert`: Takes a dictionary of column-value pairs and creates an `INSERT` statement, wrapping all values in single quotes.  
- `update`: Takes a dictionary of column-value pairs and a condition, then builds an `UPDATE` statement with a `SET` clause and a `WHERE` clause.  
- `delete`: Takes a condition and generates a `DELETE` statement with a `WHERE` clause.

**Specialized query helpers:**  
- `select_female_under_age`: Builds a `SELECT` query for records where `age` is less than a given number and `gender` is `'female'`.  
- `select_by_age_range`: Builds a `SELECT` query for records where `age` falls between two given values.

All methods return the generated SQL as a string ending with a semicolon.
