This code defines a `RegexUtils` class that provides a collection of utility methods for working with regular expressions in Python.

**Core regex operations:**
- `match`: Checks if a pattern matches at the beginning of a text string, returning `True` or `False`.
- `findall`: Returns all non-overlapping matches of a pattern in a text.
- `split`: Splits text using a pattern as the delimiter.
- `sub`: Replaces occurrences of a pattern in text with a replacement string.

**Pattern generators:**
- `generate_email_pattern`: Returns a regex pattern for matching email addresses.
- `generate_phone_number_pattern`: Returns a regex pattern for matching phone numbers in the format `XXX-XXX-XXXX`.
- `generate_split_sentences_pattern`: Returns a regex pattern for identifying sentence boundaries (periods, exclamation marks, or question marks followed by spaces and a capital letter).

**Higher-level convenience methods:**
- `split_sentences`: Uses the sentence-splitting pattern to split a text into sentences.
- `validate_phone_number`: Checks if a given phone number string matches the phone number pattern.
- `extract_email`: Finds and returns all email addresses present in a given text.

The class essentially wraps Python's `re` module functions and provides pre-built patterns for common use cases like email extraction, phone number validation, and sentence splitting.
