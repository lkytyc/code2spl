This code implements a "24 Point" card game. Here's what it does:

**Purpose:** The game generates four random numbers (1-9) and challenges the player to create a mathematical expression using those numbers that evaluates to 24.

**Key Components:**

- **`__init__`**: Initializes an empty list to store the four card numbers.

- **`_generate_cards`**: Randomly generates four numbers between 1 and 9 and stores them in the `nums` list.

- **`get_my_cards`**: Clears any existing numbers, generates a new set of four random numbers, and returns them to the player.

- **`answer`**: Takes a mathematical expression as a string. If the player passes, it deals new cards. Otherwise, it validates that the expression only uses the available numbers (checking digit frequency against the dealt cards). If the expression uses valid numbers, it evaluates the expression to check if it equals 24.

- **`evaluate_expression`**: Safely evaluates the mathematical expression using Python's `eval()` function and returns `True` if the result is 24, `False` otherwise (including if evaluation fails).

**Flow:** The player gets four random numbers, constructs an expression using those numbers, and submits it. The game verifies the expression uses only the given numbers and correctly evaluates to 24.
