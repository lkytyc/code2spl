This code defines an `ExcelProcessor` class that reads and writes Excel files using the `openpyxl` library.

- **`read_excel(file_name)`** opens an Excel file, reads all rows from the active sheet, and returns them as a list of tuples. If the file cannot be read, it returns `None`.

- **`write_excel(data, file_name)`** creates a new Excel workbook, writes the provided rows into the active sheet, saves it to the given file name, and returns `1` on success or `0` on failure.

- **`process_excel_data(N, save_file_name)`** reads an existing Excel file, checks that the column index `N` is valid, and then processes each row: if the value in column `N` is not a digit, it appends an uppercase version of that value to the end of the row; if it is a digit, it appends the original value. The modified data is saved to a new file with `_process` added to the original file name. It returns a tuple containing the write success indicator (`1` or `0`) and the new file name, or just `0` if the input file could not be read or the column index is out of range.
