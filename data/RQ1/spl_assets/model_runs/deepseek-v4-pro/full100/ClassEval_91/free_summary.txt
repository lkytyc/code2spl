This code defines a `UrlPath` class that manages URL path segments. It can build a path by adding individual segments or by parsing a full path string.

Key behaviors:
- The class stores path segments in a list and tracks whether the original path ended with a trailing slash.
- The `add` method appends a single segment after stripping leading/trailing slashes.
- The `parse` method takes a full path string and a character encoding, splits it by `/`, URL-decodes each segment using the given charset, and stores the decoded segments. It also records whether the path ended with `/`.
- The static `fix_path` method removes leading and trailing slashes from a path string, returning an empty string if the input is empty.

Inputs: path strings (either full paths or individual segments) and a charset for URL decoding.
Outputs: No direct return values; the class maintains internal state (segments list and trailing-slash flag) accessible to other code.
