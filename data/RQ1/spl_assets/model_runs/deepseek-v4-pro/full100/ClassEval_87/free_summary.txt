This code defines a `TimeUtils` class that provides various time and date manipulation utilities. When instantiated, it captures the current date and time. The class offers methods to:

- Get the current time formatted as hours, minutes, and seconds.
- Get the current date formatted as year, month, and day.
- Add a specified number of seconds to the stored datetime and return the new time.
- Convert a string in the format "YYYY-MM-DD HH:MM:SS" into a datetime object.
- Convert a datetime object into a string with the same format.
- Calculate the difference in minutes between two datetime strings.
- Format a specific date and time (given year, month, day, hour, minute, second) into a string.

The class relies on Python's `datetime` module for parsing, formatting, and arithmetic operations.
