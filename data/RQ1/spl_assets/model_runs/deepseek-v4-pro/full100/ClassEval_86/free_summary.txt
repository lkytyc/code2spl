This code implements a simple Tic-Tac-Toe game. It creates a 3x3 board initialized with empty spaces, and tracks whose turn it is (starting with 'X'). Players can place their mark on an empty cell using the `make_move` method, which returns `True` if the move was valid and `False` if the cell was already occupied. After each valid move, the current player switches between 'X' and 'O'. The `check_winner` method examines all rows, columns, and diagonals to see if either player has three marks in a row, returning the winning player's symbol or `None` if there's no winner yet. The `is_board_full` method checks whether every cell has been filled, which would indicate a draw if no winner exists.
