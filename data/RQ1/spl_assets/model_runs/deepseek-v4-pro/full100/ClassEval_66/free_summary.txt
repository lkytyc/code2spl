This code defines a class that converts numeric HTML/XML character entities (like `&#65;` or `&#x41;`) into their corresponding Unicode characters.

**Input:** A string that may contain numeric character entities.

**Output:** A new string where recognized numeric entities have been replaced by the characters they represent. Unrecognized or malformed entities are left as-is.

**How it works:**
- The `replace` method scans the input string looking for the pattern `&#` followed by digits (decimal) or `x`/`X` followed by hexadecimal digits, and terminated by a semicolon.
- When it finds a valid entity, it parses the numeric value (as decimal or hexadecimal) and converts it to the corresponding character using `chr()`.
- If the entity is malformed (e.g., missing semicolon, invalid digits, or conversion error), the method stops processing and returns the output accumulated so far.
- Characters that are not part of a valid entity are copied to the output unchanged.

**Key methods:**
- `replace(string)`: Main method that performs the unescaping.
- `is_hex_char(char)`: Static helper that checks whether a character is a valid hexadecimal digit (0-9, a-f, A-F).
