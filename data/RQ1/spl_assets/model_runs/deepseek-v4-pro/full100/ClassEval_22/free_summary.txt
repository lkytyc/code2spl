This code implements a class registration system that manages students and their class enrollments.

**Inputs and Outputs:**
- `register_student(student)`: Takes a student (dictionary with name and major) and adds them to the system. Returns 1 if the student was added, 0 if they already exist.
- `register_class(student_name, class_name)`: Takes a student's name and a class name, adds the class to that student's registration list, and returns the student's updated list of registered classes.
- `get_students_by_major(major)`: Takes a major and returns a list of student names who have that major.
- `get_all_major()`: Takes no arguments and returns a list of all unique majors among registered students.
- `get_most_popular_class_in_major(major)`: Takes a major and returns the class name that is most frequently registered by students in that major.

**Important interactions:**
- The system maintains two data structures: a list of student dictionaries (`self.students`) and a dictionary mapping student names to lists of their registered classes (`self.students_registration_classes`).
- `register_student` only adds students to the student list; it does not initialize their class registration entry.
- `register_class` creates a new entry in the registration dictionary if the student hasn't registered for any classes yet, or appends to their existing list.
- `get_most_popular_class_in_major` assumes that every student in the given major has at least one registered class; it collects all classes from students in that major and finds the most frequently occurring one.
