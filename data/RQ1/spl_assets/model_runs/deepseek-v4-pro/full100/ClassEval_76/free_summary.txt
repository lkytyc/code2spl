This code defines a `SignInSystem` class that manages user registration and sign-in status.

- **`__init__`**: Initializes an empty dictionary mapping usernames to their sign-in status (boolean).

- **`add_user(username)`**: Adds a new user with a default signed-out status. Returns `True` if the user was added, or `False` if the username already exists.

- **`sign_in(username)`**: Marks an existing user as signed in. Returns `True` if successful, or `False` if the user does not exist.

- **`check_sign_in(username)`**: Returns `True` if the user exists and is currently signed in; otherwise returns `False`.

- **`all_signed_in()`**: Returns `True` only if every registered user is signed in; otherwise returns `False`.

- **`all_not_signed_in()`**: Returns a list of usernames for all registered users who are currently not signed in.

The system tracks each user’s sign-in state and provides queries about individual or collective sign-in status.
