[DEFINE_WORKER: "Computes piecewise linear interpolation for each requested x value by scanning consecutive x intervals and appending one interpolated y value per matched interval." interpolate_1d]
    [INPUTS]
        <REF> x </REF>: array of numbers "Ordered x-coordinate array that defines interpolation intervals."
        <REF> y </REF>: array of numbers "Array of y-values corresponding to each x-coordinate."
        <REF> x_interp </REF>: array of numbers "Array of target x-values for which interpolated y-values are computed."
    [END_INPUTS]

    [OUTPUTS]
        <REF> y_interp </REF>: array of numbers "List of linearly interpolated y-values for target x values that fall within an x interval; may be shorter than x_interp if some target values do not match any interval."
    [END_OUTPUTS]

    [MAIN_FLOW]
        [SEQUENTIAL_BLOCK]
            [COMMAND Initialize `y_interp` as a new empty list. RESULT y_interp]
            [COMMAND For each target value `xi` in `x_interp`, perform the inner interval scan over consecutive `x` intervals. RESULT result]
            [COMMAND Within the outer loop over `xi`, for each interval index `i` from 0 to `len(x) - 2` inclusive, as produced by `range(len(x) - 1)`, check whether `xi` lies inclusively within the interval `[x[i], x[i+1]]` using the condition `x[i] <= xi <= x[i+1]`. RESULT result]
            [COMMAND Within the inner loop, when the interval condition is true, compute `yi = y[i] + (y[i+1] - y[i]) * (xi - x[i]) / (x[i+1] - x[i])`, append `yi` to `y_interp`, and break out of the inner `i` loop only. RESULT yi]
            [COMMAND Within the outer loop over `xi`, if no interval index satisfies the inclusive interval condition after the inner loop completes, do not append a value for this `xi`; continue with the next `xi` in `x_interp`. RESULT result]
            [COMMAND After the outer loop finishes, return the accumulated `y_interp` list. RESULT y_interp]
        [END_SEQUENTIAL_BLOCK]
    [END_MAIN_FLOW]

[END_WORKER]

[DEFINE_WORKER: "Performs bilinear interpolation for each paired point in x_interp and y_interp over the grid defined by x, y, and z, returning the list of interpolated values." interpolate_2d]
    [INPUTS]
        <REF> x </REF>: list "1D array of x grid coordinate values sorted in ascending order."
        <REF> y </REF>: list "1D array of y grid coordinate values sorted in ascending order."
        <REF> z </REF>: list "2D array of function values with shape len(x) by len(y)."
        <REF> x_interp </REF>: list "1D array of x query coordinates to interpolate."
        <REF> y_interp </REF>: list "1D array of y query coordinates to interpolate, paired positionally with x_interp."
    [END_INPUTS]

    [OUTPUTS]
        <REF> z_interp </REF>: list "A list of bilinearly interpolated values for each paired query point that falls within a grid interval; points outside all intervals are skipped."
    [END_OUTPUTS]

    [MAIN_FLOW]
        [SEQUENTIAL_BLOCK]
            [COMMAND Initialize an empty list z_interp to collect interpolated values. RESULT z_interp]
            [COMMAND For each paired query point (xi, yi) obtained by iterating over x_interp and y_interp simultaneously with zip, perform the following interval search and interpolation steps. RESULT current_point]
            [COMMAND Within the current paired point iteration, iterate i from 0 to len(x)-2 and find the first i where x[i] <= xi <= x[i+1]; if no such i exists, skip the current point and continue with the next paired point. RESULT i]
            [COMMAND Within the found x interval i, iterate j from 0 to len(y)-2 and find the first j where y[j] <= yi <= y[j+1]; if no such j exists, break out of the current i loop and skip the current point. RESULT j]
            [COMMAND Within the found grid cell (i, j), retrieve the four surrounding z-values: z00 = z[i][j], z01 = z[i][j+1], z10 = z[i+1][j], and z11 = z[i+1][j+1]. RESULT z00_z01_z10_z11]
            [COMMAND Within the found grid cell (i, j), compute zi = (z00 * (x[i+1] - xi) * (y[j+1] - yi) + z10 * (xi - x[i]) * (y[j+1] - yi) + z01 * (x[i+1] - xi) * (yi - y[j]) + z11 * (xi - x[i]) * (yi - y[j])) / ((x[i+1] - x[i]) * (y[j+1] - y[j])). RESULT zi]
            [COMMAND Append the computed value zi to z_interp. RESULT z_interp]
            [COMMAND Break out of the current y-interval loop, then break out of the current x-interval loop, and continue the outer paired-point loop with the next (xi, yi). RESULT next_point]
            [COMMAND After all paired query points have been processed, return the accumulated list z_interp. RESULT return_z_interp]
        [END_SEQUENTIAL_BLOCK]
    [END_MAIN_FLOW]

[END_WORKER]
