This code defines a utility class called `SQLQueryBuilder` that generates SQL query strings for basic database operations.

The class provides four static methods:

1. **select**: Builds a SELECT query. It takes a table name, optional columns (either '*' for all columns or a list of column names), and optional WHERE conditions as a dictionary. It returns a SELECT statement string with the specified columns and any filtering conditions joined with AND.

2. **insert**: Builds an INSERT query. It takes a table name and a dictionary of column-value pairs. It returns an INSERT statement that specifies the columns and their corresponding values.

3. **delete**: Builds a DELETE query. It takes a table name and optional WHERE conditions as a dictionary. It returns a DELETE statement with any filtering conditions joined with AND.

4. **update**: Builds an UPDATE query. It takes a table name, a dictionary of column-value pairs to update, and optional WHERE conditions as a dictionary. It returns an UPDATE statement that sets the specified values and applies any filtering conditions.

All methods return the generated SQL as a string. The WHERE conditions are always formatted as `column='value'` pairs joined with AND. The class doesn't execute queries—it only constructs the SQL text.
