This code defines a `MovieTicketDB` class that manages a SQLite database for storing movie ticket information.

**Initialization:** When creating an instance, you provide a database filename. The class connects to that SQLite database, creates a cursor for executing SQL commands, and ensures a `tickets` table exists with columns for ticket ID, movie name, theater name, seat number, and customer name.

**Methods:**

- `insert_ticket`: Adds a new ticket record with the given movie name, theater name, seat number, and customer name. The ticket ID is auto-generated.

- `search_tickets_by_customer`: Retrieves all ticket records matching a given customer name and returns them as a list of tuples.

- `delete_ticket`: Removes a ticket record based on its ID.

All database changes are committed immediately after execution.
