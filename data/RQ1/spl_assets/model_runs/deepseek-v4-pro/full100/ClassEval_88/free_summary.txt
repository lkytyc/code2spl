This code defines a `TriCalculator` class that computes trigonometric functions (cosine, sine, and tangent) for angles given in degrees.

- **`cos(x)`** returns the cosine of `x` degrees, rounded to 10 decimal places. It uses a Taylor series expansion with 50 terms.

- **`factorial(a)`** computes the factorial of a positive integer `a` using a simple loop.

- **`taylor(x, n)`** is a helper method that approximates the cosine of `x` degrees using an `n`-term Taylor series. It converts degrees to radians internally and alternates adding/subtracting even-powered terms.

- **`sin(x)`** returns the sine of `x` degrees, rounded to 10 decimal places. It uses an iterative series expansion that stops when the next term is smaller than a very small threshold (1e-15).

- **`tan(x)`** returns the tangent of `x` degrees, rounded to 10 decimal places, by dividing `sin(x)` by `cos(x)`. If `cos(x)` is zero, it returns `False` instead of a numeric value.

The class has no meaningful state; all methods are self-contained and rely only on their inputs.
