This code defines a `URLHandler` class that parses and extracts components from a URL string.

**Input:** A URL string passed to the constructor.

**Methods and outputs:**

- `get_scheme()`: Returns the protocol/scheme portion of the URL (e.g., "http", "https") or `None` if no `://` is present.
- `get_host()`: Returns the host/domain portion (everything between the scheme and the first `/`), or `None` if no scheme exists.
- `get_path()`: Returns the path portion starting from the first `/` after the host (including the leading `/`), or `None` if no scheme or no path exists.
- `get_query_params()`: Returns a dictionary of query parameters parsed from the URL (everything after `?` and before `#`). Keys and values are split on `=`. Returns `None` if no `?` is present. Ignores malformed pairs that don't contain exactly one `=`.
- `get_fragment()`: Returns the fragment portion after `#`, or `None` if no `#` is present.

**Interactions:** Each method independently parses the stored URL string using string operations like `find` and `split`. There is no shared state between method calls beyond the original URL. The class does not validate URL format beyond checking for the presence of certain delimiters (`://`, `/`, `?`, `#`, `&`, `=`).
