This code implements Manacher’s algorithm to find the longest palindromic substring in a given input string.

- The class is initialized with an input string.
- The `palindromic_length` method recursively checks how far a palindrome extends around a given center by comparing characters at equal distances to the left and right. It returns the number of matching character pairs (excluding the center itself).
- The `palindromic_string` method first transforms the original string by inserting a `"|"` separator between every character. This allows palindromes of both even and odd length to be handled uniformly.
- It then iterates over each character position in the transformed string, treating each as a potential center, and uses `palindromic_length` to measure the palindrome radius.
- It keeps track of the center with the greatest radius.
- Finally, it extracts the substring from the transformed string corresponding to that longest palindrome, removes the `"|"` separators, and returns the resulting plain-text palindrome.

The output is the longest palindromic substring found in the original input.
