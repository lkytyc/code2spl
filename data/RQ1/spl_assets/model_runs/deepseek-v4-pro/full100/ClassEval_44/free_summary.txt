This code provides a utility class for processing HTML text, primarily to clean it up and extract code blocks.

**Main purpose:** It converts HTML content into plain text while preserving some structure and marking special elements, and it can extract code snippets from `<pre>` and `<blockquote>` tags.

**Key behaviors:**

1. **HTML to text conversion (`format_line_html_text`):**
   - Takes HTML text as input and returns cleaned plain text.
   - Replaces `<pre>` and `<blockquote>` content with a placeholder marker (`-CODE-`).
   - Converts list items (`<li>`) into bullet-point format like `[-] item text`, adding punctuation if missing.
   - Processes paragraphs (`<p>`) by adding a period at the end if no punctuation exists, or a colon if followed by a code block.
   - Decodes HTML entities and normalizes multiple newlines to single newlines.

2. **Code extraction (`extract_code_from_html_text`):**
   - Takes HTML text as input and returns a list of strings containing the text content of all `<pre>` and `<blockquote>` elements.
   - First converts the HTML to text using the formatting method to check if any code markers exist.
   - If no code blocks are found, returns an empty list.
   - Otherwise, parses the original HTML, finds all code tags, and extracts their text content.

**Inputs/Outputs:**
- `format_line_html_text`: Input is HTML string (or None/empty), output is cleaned plain text string.
- `extract_code_from_html_text`: Input is HTML string, output is a list of code block strings.

**Important interactions:** The code extraction method depends on the formatting method to detect whether code blocks exist, but then re-parses the original HTML to get the actual code content.
