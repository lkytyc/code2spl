This code defines a `BigNumCalculator` class that performs arithmetic on numbers represented as strings, allowing calculations on numbers larger than standard numeric types can handle.

**Inputs:** All methods take two string arguments (`num1`, `num2`) representing non-negative integer values.

**Outputs:** Each method returns a string representing the result of the arithmetic operation.

**Methods:**

- **`add`**: Adds two numbers digit by digit from right to left, handling carry values. Returns the sum as a string.

- **`subtract`**: Subtracts the smaller number from the larger one. It first determines which number is larger (by length, then lexicographically) and swaps them if needed, tracking whether the result should be negative. Then performs digit-by-digit subtraction with borrowing, removes leading zeros, and prepends a minus sign if the result is negative.

- **`multiply`**: Multiplies two numbers using the standard grade-school multiplication algorithm. It creates a result array sized to hold the maximum possible digits, iterates through each digit pair from right to left, accumulates products into the correct positions, handles carries, then strips leading zeros and returns the product as a string.

**Interactions:** The class contains only static methods—no instance state or constructor is used. Each method is independent and can be called directly on the class without instantiation.
