This code implements a simplified Blackjack card game. It creates a standard 52-card deck, shuffles it, and manages hands for both a player and a dealer.

The main class, `BlackjackGame`, initializes with a shuffled deck and empty hands for the player and dealer. The `create_deck` method builds the deck using four suits and thirteen ranks, then shuffles it randomly.

The `calculate_hand_value` method computes the total value of a hand, treating number cards at face value, face cards as 10, and aces as 11 (with logic to reduce aces to 1 if the total exceeds 21).

The `check_winner` method compares the player's and dealer's hand values to determine the winner. It handles cases where both bust (over 21), where only one busts, and where neither busts. In the case of both busting or both being under 21, the lower hand value wins (which is unusual for standard Blackjack rules, but that's what the code specifies). The method returns a string indicating either "Player wins" or "Dealer wins".
