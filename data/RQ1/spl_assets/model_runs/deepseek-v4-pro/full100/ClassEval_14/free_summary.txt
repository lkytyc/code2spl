This code defines a `BookManagementDB` class that manages a simple book inventory stored in a SQLite database.

- **Initialization**: When an instance is created with a database filename, it connects to that SQLite database and ensures a `books` table exists. The table stores each book’s ID, title, author, and availability status (1 for available, 0 for borrowed).

- **Adding a book**: The `add_book` method inserts a new book with the given title and author, setting its availability to available by default.

- **Removing a book**: The `remove_book` method deletes a book from the database using its ID.

- **Borrowing a book**: The `borrow_book` method marks a book as unavailable by setting its availability to 0, based on the book’s ID.

- **Returning a book**: The `return_book` method marks a book as available again by setting its availability to 1.

- **Searching/listing books**: The `search_books` method retrieves and returns all rows from the `books` table, providing a full list of books and their details.

All database changes are committed immediately after each operation.
