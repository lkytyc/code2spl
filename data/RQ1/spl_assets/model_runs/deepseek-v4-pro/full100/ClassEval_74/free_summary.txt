This code defines a `Server` class that manages a whitelist of addresses and handles sending/receiving structured messages.

**Inputs and outputs:**

- `add_white_list(addr)`: Adds an address to the whitelist. Returns `False` if the address is already present; otherwise returns the updated whitelist.
- `del_white_list(addr)`: Removes an address from the whitelist. Returns `False` if the address is not present; otherwise returns the updated whitelist.
- `recv(info)`: Accepts a dictionary with `"addr"` and `"content"` keys. Returns `-1` if the input is not a valid dictionary or lacks required keys. Returns `False` if the address is not whitelisted. If valid and whitelisted, stores the message in `receive_struct` and returns the content.
- `send(info)`: Accepts a dictionary with `"addr"` and `"content"` keys. Returns an error string if the input is invalid. Otherwise stores the message in `send_struct` (no explicit return value).
- `show(type)`: Returns the stored `send_struct` or `receive_struct` based on the `type` argument (`"send"` or `"receive"`). Returns `False` for any other type.

**Key interactions:**

- The whitelist controls which addresses are allowed to be received from.
- `send_struct` and `receive_struct` are instance variables that store the most recent sent and received messages, respectively.
- The `recv` method only updates `receive_struct` when the address is whitelisted; otherwise it returns `False` without storing anything.
