This code defines a class called `LongestWord` that helps find the longest word from a predefined list that appears in a given sentence.

**Key components:**

- **`__init__`**: Initializes an empty list called `word_list` to store words.

- **`add_word`**: Adds a word to the `word_list`.

- **`find_longest_word`**: Takes a sentence as input, converts it to lowercase, removes punctuation, and splits it into individual words. It then checks each word in the sentence against the `word_list`. If a word is in the list and is longer than the current longest word found, it updates the longest word. Finally, it returns the longest matching word (or an empty string if no match is found).

**Inputs/Outputs:**
- Input to `add_word`: a single word (string).
- Input to `find_longest_word`: a sentence (string).
- Output of `find_longest_word`: the longest word from `word_list` that appears in the sentence, or an empty string if none match.
