This code defines a class called `SplitSentence` that processes text to find the sentence with the most words.

It has three methods:

1. **`split_sentences`** takes a string of text and splits it into individual sentences using a regular expression. The regex looks for sentence-ending punctuation (`.` or `?`) followed by whitespace, while avoiding splits after common abbreviations like "e.g." or a single capital letter followed by a period (e.g., "Mr.").

2. **`count_words`** takes a single sentence, removes all characters except letters and whitespace, then splits the remaining text by whitespace and returns the number of words.

3. **`process_text_file`** takes a full text string, splits it into sentences using `split_sentences`, then iterates through each sentence, counts its words using `count_words`, and returns the highest word count found among all sentences.

In short, the class’s main purpose is to determine the maximum number of words in any sentence from a given text.
