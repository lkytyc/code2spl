This code defines a small helper class for working with URL-like path strings.

`UrlPath` stores two pieces of state:
- `segments`: a list of path segments
- `with_end_tag`: a boolean flag that records whether the original path ended with a trailing `/`

### Behavior

- When a `UrlPath` object is created, it starts with no segments and `with_end_tag` set to `False`.
- `add(segment)` takes one path segment, strips leading and trailing `/` characters from it, and appends the cleaned result to `segments`.
- `parse(path, charset)` takes a full path string and a character encoding:
  - If the path is non-empty and ends with `/`, it sets `with_end_tag` to `True`.
  - It removes leading and trailing `/` from the whole path.
  - It splits the cleaned path on `/` into individual segments.
  - Each segment is URL-decoded using `urllib.parse.unquote` with the provided `charset`, and the decoded value is appended to `segments`.
- `fix_path(path)` is a static helper that returns an empty string for empty input, otherwise strips leading and trailing `/` characters.

### Inputs and outputs

- Inputs are path strings and a charset name.
- The class does not return parsed paths directly; instead, it stores the result in its instance fields.
- The main output of `parse` is the updated `segments` list and the `with_end_tag` flag.

### Interaction between methods

- Both `add` and `parse` use `fix_path` to normalize path strings by removing surrounding slashes.
- `parse` additionally decodes each segment from URL encoding before storing it.
