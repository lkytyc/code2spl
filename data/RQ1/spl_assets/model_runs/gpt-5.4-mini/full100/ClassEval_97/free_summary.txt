This code defines a `Words2Numbers` class that helps convert English number words into integers, or check whether a string is made only of number words.

The class is initialized with lookup tables for:
- basic number words like “zero” through “nineteen”
- tens like “twenty”, “thirty”, etc.
- scale words like “hundred”, “thousand”, “million”, “billion”, and “trillion”
- a few irregular ordinal words such as “first”, “second”, “third”, “fifth”, “eighth”, “ninth”, and “twelfth”
- simple ordinal endings such as “th” and “ieth”

Its `text2int(textnum)` method takes a text string and converts any recognized number phrase in it into digits. It:
- treats hyphens as spaces
- parses words one by one
- handles special ordinal words and ordinal suffixes
- accumulates numeric values according to the scale words
- preserves any non-number words in the output
- returns a string where recognized number phrases have been replaced by their numeric values

For example, it is designed to turn something like “twenty one cats” into “21 cats”, and it can also handle ordinals like “first” or “twentieth” when they appear in the input.

Its `is_valid_input(textnum)` method checks whether every word in the input is recognized as part of a number expression. It:
- also treats hyphens as spaces
- accepts the known number words, ordinal words, and words that match supported ordinal endings
- returns `False` as soon as it finds an unrecognized word
- returns `True` if all words are valid number-related words

In short, the class provides word-to-number conversion for mixed text and a validation check for number-word strings.
