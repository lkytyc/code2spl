This code defines an `AssessmentSystem` class for storing student records and basic course scores.

It starts with an empty student registry, stored as a dictionary keyed by student name. Each student record contains the student’s name, grade, major, and another dictionary of course scores.

The class provides these behaviors:

- `add_student(name, grade, major)`: adds a new student record with the given name, grade, and major, and initializes an empty set of course scores.
- `add_course_score(name, course, score)`: if the student already exists, stores or updates that student’s score for the given course.
- `get_gpa(name)`: returns the average of that student’s recorded course scores if the student exists and has at least one course; otherwise returns `None`. It does not use any weighting or special GPA conversion, just a plain arithmetic average.
- `get_all_students_with_fail_course()`: returns a list of student names for students who have at least one course score below 60. Each student appears at most once in the result, even if they failed multiple courses.
- `get_course_average(course)`: computes the average score for the specified course across all students who have a score for that course and that score is not `None`. If no valid scores exist, it returns `None`.
- `get_top_student()`: finds and returns the name of the student with the highest GPA as computed by `get_gpa`. If no student has any course scores, it returns `None`.

Overall, the methods interact through the shared `students` dictionary, and the GPA and top-student methods depend on the course scores that were previously added.
