This code defines a `ShoppingCart` class that stores cart contents in a dictionary called `items`.

Behavior and methods:
- When a `ShoppingCart` object is created, it starts with an empty `items` dictionary.
- `add_item(item, price, quantity=1)` adds an entry for the given item name. It stores the item’s `price` and `quantity` in the dictionary. If the item already exists, it still overwrites that entry with the new price and quantity.
- `remove_item(item, quantity=1)` checks whether the item exists in the cart. If it does, it subtracts the given quantity from the stored quantity. If the item is not present, it does nothing.
- `view_items()` returns the current `items` dictionary.
- `total_price()` calculates and returns the total cost of all items by summing each item’s `price × quantity`.

Inputs and outputs:
- Inputs are item names, prices, and quantities passed to `add_item` and `remove_item`.
- `view_items()` outputs the internal dictionary of cart contents.
- `total_price()` outputs a numeric total price for the cart.

Method interaction:
- `add_item` and `remove_item` both modify the shared `items` dictionary.
- `view_items` and `total_price` read from that same dictionary to report the cart’s state and total cost.
