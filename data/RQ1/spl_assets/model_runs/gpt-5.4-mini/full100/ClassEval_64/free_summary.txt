This code defines a utility class called `NumberConverter` that provides simple static methods for converting numbers between decimal, binary, octal, and hexadecimal forms.

Behavior and interactions:
- `decimal_to_binary(decimal_num)` takes a decimal integer and returns its binary representation as a string, without the `0b` prefix.
- `binary_to_decimal(binary_num)` takes a binary string and returns its decimal integer value.
- `decimal_to_octal(decimal_num)` takes a decimal integer and returns its octal representation as a string, without the `0o` prefix.
- `octal_to_decimal(octal_num)` takes an octal string and returns its decimal integer value.
- `decimal_to_hex(decimal_num)` takes a decimal integer and returns its hexadecimal representation as a string, without the `0x` prefix.
- `hex_to_decimal(hex_num)` takes a hexadecimal string and returns its decimal integer value.

All methods are marked `@staticmethod`, so they are used directly on the class and do not depend on instance state. The class itself stores no data; it is just a collection of conversion helpers built on Python’s built-in `bin`, `oct`, `hex`, and `int(..., base)` functions.
