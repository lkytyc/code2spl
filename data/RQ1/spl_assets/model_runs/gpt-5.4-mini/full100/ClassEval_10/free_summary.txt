This code defines a `BinaryDataProcessor` class for working with a string of binary digits.

When an instance is created, it takes one input: `binary_string`. The constructor stores that string and immediately removes any characters that are not `0` or `1`, so the object always works with a cleaned binary-only string afterward.

The class provides three main behaviors:

- `clean_non_binary_chars()`: filters the stored string so only `0` and `1` remain.
- `calculate_binary_info()`: counts how many `0`s and `1`s are in the cleaned string, computes each as a fraction of the total length, and returns a dictionary with:
  - the proportion of zeroes,
  - the proportion of ones,
  - the total bit length.
- `convert_to_ascii()` and `convert_to_utf8()`: both interpret the cleaned binary string in 8-bit chunks, convert each chunk from binary to a byte value, build a byte array, and decode that byte array as either ASCII or UTF-8 text.

Important interaction: the conversion methods rely on the cleaned string produced by the constructor. They process the binary data sequentially in 8-bit groups and return a decoded text string.
