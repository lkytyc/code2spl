This class provides a simple text unescaper for numeric character entities.

It has one main method, `replace(string)`, which scans an input string left to right and tries to convert sequences like `&#65;` or `&#x41;` into their corresponding Unicode characters. It recognizes:

- decimal entities of the form `&#...;`
- hexadecimal entities of the form `&#x...;` or `&#X...;`

How it works:
- It builds a new output string incrementally.
- When it sees `&` followed by `#`, it checks whether the next character indicates hexadecimal (`x` or `X`).
- It then consumes as many valid digits as possible, depending on the base.
- If the sequence ends with a semicolon and the number can be parsed, it converts the numeric value with `chr(...)` and appends the resulting character to the output.
- If parsing fails or the pattern is incomplete, it stops processing and returns the output collected so far.
- Any text that is not part of a valid numeric entity is copied through unchanged.

The class also includes a helper, `is_hex_char(char)`, which returns whether a character is a decimal digit or one of `a` through `f` in either case. This helper is used while scanning entity contents.

The constructor does nothing special.
