This code defines an `ExpressionCalculator` class that evaluates arithmetic expressions given as strings.

What it accepts:
- A text expression containing numbers and the operators `+`, `-`, `*`, `/`, `%`, and parentheses.
- It also ignores whitespace.
- It removes a trailing `=` if present.

How it works:
- `transform()` preprocesses the input string:
  - strips spaces,
  - removes a final `=`,
  - rewrites some `-` signs as `~` to mark unary minus, such as at the start of an expression or after another operator or an opening parenthesis.
  - If the expression starts with a unary minus before a parenthesized expression, it prefixes `0` so it can be treated as subtraction.
- `prepare()` converts the transformed infix expression into postfix form using a stack and operator precedence rules.
  - It stores the postfix tokens in `self.postfix_stack`.
  - Parentheses are handled by pushing/popping operators until matching parentheses are found.
- `calculate()` evaluates the postfix expression:
  - It processes tokens from `self.postfix_stack`.
  - Numbers are pushed onto a result stack.
  - When an operator is found, it pops two values, computes the result with `_calculate()`, and pushes the result back.
  - Unary-minus markers `~` are converted back to `-` before evaluation.
  - The final result is returned as a `float`.

Important class/method interactions:
- `calculate()` calls `transform()` first, then `prepare()`, then evaluates the postfix output.
- `prepare()` uses `is_operator()` and `compare()` to decide when to push or pop operators.
- `_calculate()` performs the actual arithmetic using `Decimal` for `+`, `-`, `*`, `/`, and `%`.

Output:
- A floating-point numeric result of the expression.

Notes on behavior:
- The code uses `Decimal` for intermediate arithmetic, but the final value is converted to `float`.
- It assumes the expression is syntactically valid enough for stack-based evaluation; it does not include explicit error handling for malformed expressions beyond raising a `ValueError` for an unexpected operator.
