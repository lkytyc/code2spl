This code defines a small Blackjack game model in Python.

It creates a `BlackjackGame` class that manages:
- a shuffled deck of cards,
- the player’s hand,
- the dealer’s hand.

When an instance is created, it:
- builds a standard 52-card deck using four suits (`S`, `C`, `D`, `H`) and ranks from Ace through King,
- shuffles the deck randomly,
- initializes empty player and dealer hands.

The class provides these main behaviors:

- `create_deck()`: builds and shuffles the deck, returning a list of card strings like `AS` or `10H`.
- `calculate_hand_value(hand)`: computes the Blackjack value of a hand.
  - Number cards count as their numeric value.
  - J, Q, and K count as 10.
  - Aces count as 11 at first, but can be reduced to 1 if the hand would otherwise go over 21.
- `check_winner(player_hand, dealer_hand)`: compares the two hands and returns either `'Player wins'` or `'Dealer wins'`.
  - If one hand is over 21, the other wins.
  - If both are over 21, it compares their values and returns the result based on the lower value.
  - Otherwise, it compares the hand values directly, and the higher value wins; if tied, the dealer wins because the code returns `'Dealer wins'` when the player’s value is less than or equal to the dealer’s.

The code does not include gameplay steps like dealing cards or taking turns; it only provides the deck setup, hand scoring, and winner determination logic.
