This code defines a `SQLGenerator` class that builds SQL query strings for a specific table name supplied when the object is created.

Behavior and methods:

- `__init__(table_name)`: stores the table name for later use.
- `select(fields=None, condition=None)`: returns a `SELECT` statement for the stored table.
  - If `fields` is omitted, it selects all columns using `*`.
  - If `fields` is provided, it joins the field names with commas.
  - If `condition` is provided, it adds a `WHERE` clause.
  - Always returns the query as a string ending with a semicolon.
- `insert(data)`: builds an `INSERT INTO` statement from a dictionary.
  - Uses the dictionary keys as column names.
  - Uses the dictionary values as quoted SQL values.
  - Returns the SQL string with a semicolon.
- `update(data, condition)`: builds an `UPDATE` statement.
  - Turns the dictionary into `column = 'value'` assignments joined by commas.
  - Adds a `WHERE` clause using the given condition.
  - Returns the SQL string with a semicolon.
- `delete(condition)`: builds a `DELETE FROM` statement with a `WHERE` clause and returns it as a string.
- `select_female_under_age(age)`: creates a condition for rows where `age` is less than the given value and `gender` is `'female'`, then calls `select` to generate the query.
- `select_by_age_range(min_age, max_age)`: creates a condition for rows where `age` is between the two values, then calls `select`.

Inputs and outputs:
- Inputs are table name, field names, dictionaries of column/value pairs, and condition strings or age values.
- Outputs are SQL command strings, not executed queries.

Important interactions:
- The specialized methods `select_female_under_age` and `select_by_age_range` both rely on the general `select` method to produce the final SQL.
- No database connection or execution logic is included; the class only formats SQL text.
