This code defines a `Server` class that keeps track of a whitelist of allowed addresses and stores the most recent sent and received message data.

- When a `Server` object is created, it starts with:
  - an empty `white_list`
  - an empty `send_struct`
  - an empty `receive_struct`

- `add_white_list(addr)` adds an address to the whitelist if it is not already present.
  - If the address is already in the list, it returns `False`.
  - Otherwise, it appends the address and returns the updated whitelist.

- `del_white_list(addr)` removes an address from the whitelist if it exists.
  - If the address is not present, it returns `False`.
  - Otherwise, it removes the address and returns the updated whitelist.

- `recv(info)` handles incoming data.
  - It expects `info` to be a dictionary with keys `"addr"` and `"content"`.
  - If `info` is not a dictionary or is missing either key, it returns `-1`.
  - If the address is not on the whitelist, it returns `False`.
  - If the address is allowed, it saves `{"addr": addr, "content": content}` into `receive_struct` and returns the received content.

- `send(info)` handles outgoing data.
  - It also expects a dictionary with `"addr"` and `"content"`.
  - If the structure is invalid, it returns the string `"info structure is not correct"`.
  - If valid, it stores the address and content in `send_struct`.
  - It does not return anything when successful.

- `show(type)` returns one of the stored message structures.
  - If `type` is `"send"`, it returns `send_struct`.
  - If `type` is `"receive"`, it returns `receive_struct`.
  - For any other value, it returns `False`.

Overall, the class is a simple stateful container for whitelist management and for storing the latest send/receive message information, with `recv` enforcing whitelist access before accepting content.
