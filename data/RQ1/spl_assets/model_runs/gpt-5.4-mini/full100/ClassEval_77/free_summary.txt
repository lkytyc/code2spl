This code defines a `Snake` class for a simple snake-game style model.

The class is initialized with the screen width, screen height, block size, and the current food position. It starts the snake at the center of the screen with length 1, score 0, and stores the food location.

Main behavior:
- `move(direction)`: moves the snake one block in the given direction, where `direction` is a two-value vector like `(1, 0)` or `(0, -1)`.
  - Movement wraps around the screen edges using modulo arithmetic.
  - If the new head position matches the food position, the snake eats the food.
  - If the new head collides with its own body (excluding the first two positions), the snake resets.
  - Otherwise, the new head position is added to the front of the position list, and the tail is removed if the snake is longer than its current length.

- `random_food_position()`: chooses a new food location at a random grid cell, repeating until the food is not placed on any part of the snake’s body.

- `reset()`: restores the snake to its initial state, with length 1, centered position, and score 0, then places new food somewhere not occupied by the snake.

- `eat_food()`: increases the snake’s length by 1, adds 100 points to the score, and moves the food to a new random valid position.

Overall, the class tracks the snake’s body positions, score, growth, collision with itself, and food placement.
