This code defines a `VendingMachine` class that tracks stocked items and the money inserted.

- When a `VendingMachine` is created, it starts with an empty `inventory` and a `balance` of 0.
- `add_item(item_name, price, quantity)` adds a new item to the machine. It first tries to restock the item; if the item is already in inventory, it increases its quantity instead of creating a new entry. If the item is not already present, it stores the item’s price and quantity.
- `insert_coin(amount)` adds the given amount to the current balance and returns the updated balance.
- `purchase_item(item_name)` attempts to buy one unit of the named item. It succeeds only if the item exists, has at least one in stock, and the current balance is enough to cover the item’s price. On success, it deducts the price from the balance, decreases the item quantity by 1, and returns the new balance. Otherwise, it returns `False`.
- `restock_item(item_name, quantity)` increases the quantity of an existing item and returns `True`. If the item is not already in inventory, it returns `False`.
- `display_items()` returns a formatted multiline string listing each item with its price and quantity. If the inventory is empty, it returns `False`.

Overall, the class supports adding stock, inserting money, buying items, and viewing the current inventory state.
