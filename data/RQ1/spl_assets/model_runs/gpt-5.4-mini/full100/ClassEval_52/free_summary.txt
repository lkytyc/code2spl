This code defines a small text-processing utility built on NLTK for lemmatizing sentences and extracting part-of-speech tags.

It first downloads three NLTK resources when the module is loaded: the averaged perceptron tagger, the Punkt tokenizer data, and WordNet. These are needed for tokenization, POS tagging, and lemmatization.

The main class, `Lemmatization`, creates a `WordNetLemmatizer` instance in its constructor and provides three methods:

- `remove_punctuation(sentence)`: removes all standard punctuation characters from the input string and returns the cleaned string.
- `lemmatize_sentence(sentence)`: takes a sentence string, removes punctuation, tokenizes it into words, tags each word with its part of speech, and then lemmatizes each word based on the tag. Verbs are lemmatized as verbs, adjectives as adjectives, adverbs as adverbs, and everything else uses the default lemmatization. It returns a list of the lemmatized words in order.
- `get_pos_tag(sentence)`: takes a sentence string, removes punctuation, tokenizes it, tags each word with its part of speech, and returns a list of the POS tag strings.

So the inputs are sentence strings, and the outputs are either a list of lemmatized tokens or a list of POS tags. The methods share the same preprocessing steps: punctuation removal, tokenization, and POS tagging.
