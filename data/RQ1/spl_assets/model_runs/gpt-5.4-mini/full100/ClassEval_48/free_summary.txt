This code defines a utility class for working with IP addresses.

`IpUtil` contains three static methods:

- `is_valid_ipv4(ip_address)`: takes a string representing an IP address and checks whether it is a valid IPv4 address. It uses `socket.inet_pton` with the IPv4 family. If the address can be parsed, it returns `True`; otherwise it returns `False`.

- `is_valid_ipv6(ip_address)`: takes a string representing an IP address and checks whether it is a valid IPv6 address, again using `socket.inet_pton`, but with the IPv6 family. It returns `True` for a valid IPv6 address and `False` if parsing fails.

- `get_hostname(ip_address)`: takes an IP address string and tries to look up the host name associated with it using `socket.gethostbyaddr`. If the reverse lookup succeeds, it returns the first hostname from the result. If the lookup fails with a host lookup error, it returns `None`.

The class does not maintain any state; all methods are independent helpers that operate directly on the input IP address string.
