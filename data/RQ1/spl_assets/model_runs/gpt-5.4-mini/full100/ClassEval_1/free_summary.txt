This code defines a class called `AreaCalculator` for computing several geometry-related measures based on a stored radius.

The class is initialized with one input, `radius`, which is saved on the instance and used by most of the methods.

It provides these calculations:
- `calculate_circle_area()` returns the area of a circle using the stored radius.
- `calculate_sphere_area()` returns the surface area of a sphere using the stored radius.
- `calculate_cylinder_area(height)` returns the total surface area of a cylinder, using the stored radius and a required `height` argument.
- `calculate_sector_area(angle)` returns the area of a sector based on the stored radius and an `angle` argument.
- `calculate_annulus_area(inner_radius, outer_radius)` returns the area of a ring-shaped annulus from the two provided radii.

The class uses `math.pi` for the formulas where needed, and each method returns the computed numeric result directly.
