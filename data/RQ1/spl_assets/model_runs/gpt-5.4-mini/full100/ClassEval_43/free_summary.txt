This code defines an `HRManagementSystem` class that stores employee records in an internal dictionary.

- When an instance is created, it starts with an empty `employees` collection.
- `add_employee(employee_id, name, position, department, salary)` adds a new employee record if the ID is not already present. It stores the employee’s name, position, department, and salary under that ID. It returns `True` on success and `False` if the ID already exists.
- `remove_employee(employee_id)` deletes an employee record by ID if it exists. It returns `True` if the employee was removed and `False` otherwise.
- `update_employee(employee_id, employee_info)` looks up the employee by ID using `get_employee`. If the employee does not exist, it returns `False`. If the employee exists, it checks that every key in `employee_info` already exists in the stored employee record; if any key is unknown, it returns `False`. Otherwise, it updates those fields and returns `True`.
- `get_employee(employee_id)` returns the stored employee dictionary for that ID if it exists, or `False` if it does not.
- `list_employees()` builds and returns a new dictionary containing all employees. For each employee, it includes the employee ID under the key `"employee_ID"` along with the stored fields.

Overall, the class provides basic in-memory create, read, update, and delete operations for employee records, with simple success/failure return values.
