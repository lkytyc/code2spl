This code defines a `BigNumCalculator` class with three static methods for doing arithmetic on numbers represented as strings.

- `add(num1, num2)`: Adds two non-negative integer strings digit by digit from right to left, using carry handling. It pads the shorter string with leading zeroes so both have the same length, then returns the sum as a string.

- `subtract(num1, num2)`: Subtracts one integer string from another using digit-by-digit borrowing. It first decides which input is larger so it can subtract the smaller from the larger and remember whether the final result should be negative. It pads with leading zeroes, performs the subtraction from right to left, removes unnecessary leading zeroes from the result, and adds a `-` sign if the result is negative.

- `multiply(num1, num2)`: Multiplies two non-negative integer strings using the standard long multiplication approach. It stores intermediate values in a list sized to hold the full product, accumulates partial products from right to left, removes any leading zeroes in the final list, and returns the product as a string.

All three methods are static, so they are called directly on the class rather than on an instance, and all of them take string inputs and return a string output.
