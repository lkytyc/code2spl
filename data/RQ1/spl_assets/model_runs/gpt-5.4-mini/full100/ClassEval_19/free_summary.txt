This code defines a class that generates all prime numbers up to a given limit.

- **Input:** The class is initialized with one number, `n`.
- **Main behavior:** When an instance is created, it immediately computes all prime numbers from 2 through `n` using a sieve-style algorithm.
- **How it works:**  
  - If `n` is less than 2, there are no primes, so it stores an empty list.
  - Otherwise, it creates a boolean list representing numbers from 0 to `n`, initially assuming they are all prime.
  - It marks 0 and 1 as not prime.
  - It then checks each number `p` starting from 2 while `p * p <= n`. For each `p` still marked prime, it marks all multiples of `p` starting at `p * p` as not prime.
  - After that, it collects every number still marked prime into a list.
- **Output:** The computed prime numbers are stored in `self.primes`.
- **Method interaction:**  
  - `__init__` calls `generate_primes()` and saves the result.
  - `get_primes()` simply returns the stored list of primes.

So, the class is a prime-number generator that precomputes primes up to the provided upper bound and lets callers retrieve them afterward.
