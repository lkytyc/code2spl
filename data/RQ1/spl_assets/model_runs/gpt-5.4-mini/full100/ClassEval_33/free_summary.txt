This code defines a `DiscountStrategy` class that represents an order-like purchase with an optional promotion discount.

### What it stores
When you create a `DiscountStrategy` object, you pass in:
- `customer`: expected to be a mapping with at least a `'fidelity'` value
- `cart`: a collection of items, where each item is expected to be a mapping with `'quantity'`, `'price'`, and `'product'`
- `promotion`: an optional function to calculate a discount

The object immediately calculates and stores the cart total in a private attribute.

### Main behavior
- `total()`: computes the total cost of the cart by adding up `quantity * price` for every item, stores that value internally, and returns it.
- `due()`: returns the amount to pay after discount. If no promotion is provided, the discount is 0. If a promotion is provided, it is called with the current `DiscountStrategy` instance, and its result is subtracted from the stored total.

### Promotion methods
The class also defines three static methods that can be used as promotion functions:

- `FidelityPromo(order)`: gives a 5% discount on the order total if the customer’s `'fidelity'` value is at least 1000; otherwise it gives no discount.
- `BulkItemPromo(order)`: gives 10% off for each cart item whose quantity is at least 20, based on that item’s own quantity and price.
- `LargeOrderPromo(order)`: gives a 7% discount on the order total if the cart contains at least 10 distinct products.

### Interaction between methods
The promotions are designed to be passed into `promotion`. When `due()` is called, it uses that promotion function to compute the discount based on the current object’s customer and cart, then subtracts it from the total.
