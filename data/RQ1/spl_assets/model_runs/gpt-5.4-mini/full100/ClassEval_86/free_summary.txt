This code defines a simple `TicTacToe` class for a 3×3 game board.

- When a `TicTacToe` object is created, it builds a board filled with spaces to represent empty squares, and sets the first player to `'X'`. The constructor accepts an `N` argument, but the board is still created with 3 rows and 3 columns.
- `make_move(row, col)` tries to place the current player’s mark at the given board position. If that square is empty, it writes `'X'` or `'O'`, then switches to the other player and returns `True`. If the square is already occupied, it leaves the board unchanged and returns `False`.
- `check_winner()` examines the board for a winning line:
  - any complete row,
  - any complete column,
  - either diagonal.
  If it finds three matching non-space marks in a line, it returns that mark (`'X'` or `'O'`). If there is no winner, it returns `None`.
- `is_board_full()` checks whether there are any empty spaces left. It returns `True` only if every square is occupied, otherwise `False`.

The methods work together to manage turn-taking, place moves, detect a winner, and determine when the board is full.
