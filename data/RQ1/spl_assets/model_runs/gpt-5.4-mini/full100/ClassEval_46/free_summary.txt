This code defines a small `Interpolation` class that provides two static methods for linear interpolation.

- `__init__` does nothing; the class has no stored state.
- `interpolate_1d(x, y, x_interp)`:
  - Takes:
    - `x`: a sequence of x-values, assumed to be ordered
    - `y`: corresponding y-values
    - `x_interp`: x-values where new y-values should be estimated
  - For each value in `x_interp`, it finds the interval in `x` that contains it and computes a linearly interpolated y-value from the two neighboring points.
  - Returns a list of interpolated y-values, in the same order as the input interpolation points.
  - It only adds a result when the interpolation point falls inside one of the intervals it checks; otherwise that point is skipped.

- `interpolate_2d(x, y, z, x_interp, y_interp)`:
  - Takes:
    - `x`: x-axis coordinates, assumed ordered
    - `y`: y-axis coordinates, assumed ordered
    - `z`: a 2D grid of values indexed by `x` and `y`
    - `x_interp`, `y_interp`: matching sequences of x and y coordinates for points to interpolate
  - For each paired `(xi, yi)` from `zip(x_interp, y_interp)`, it finds the grid cell in `x` and `y` that contains that point and performs bilinear interpolation using the four surrounding `z` values.
  - Returns a list of interpolated `z` values, one for each successfully matched point.
  - Like the 1D version, points outside the checked ranges are skipped.

The two methods are independent and are used only as utility functions; the class itself does not hold any data.
