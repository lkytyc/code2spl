This file defines a small utility class, `MetricsCalculator2`, for computing two ranking-based evaluation metrics using NumPy: mean reciprocal rank (`mrr`) and mean average precision (`map`).

Both methods are static and accept either:

- a single tuple of the form `(sub_list, total_num)`, or
- a list of such tuples.

`sub_list` is treated like a sequence of labels or indicators, and `total_num` is used as the denominator or a guard against division by zero. If the input is not a list or tuple, the methods raise an exception. If the input is empty, they return `0.0` and a list containing `0.0`.

Behavior of `mrr`:
- For a single tuple, it looks through `sub_list` in order and finds the first positive entry.
- It computes the reciprocal of that position, using positions starting at 1.
- If no positive entry is found, or `total_num` is `0`, the result is `0.0`.
- It returns a pair: the metric value and a one-element list containing that value.
- For a list of tuples, it computes the same value for each tuple separately, then returns the mean of those values plus the per-item list of results.

Behavior of `map`:
- For a single tuple, it walks through `sub_list` and assigns increasing ranks only to nonzero entries.
- It then computes the sum of those ranks divided by their positions, normalized by `total_num`.
- If `total_num` is `0`, the result is `0.0`.
- It returns the metric value and a one-element list containing it.
- For a list of tuples, it computes the metric for each tuple, returns the mean across all tuples, and also returns the list of individual results.

The class has an `__init__` method, but it does nothing.
