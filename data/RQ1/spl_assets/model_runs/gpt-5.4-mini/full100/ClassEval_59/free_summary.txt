This code defines a simple movie booking system that keeps track of movies, their show times, and a seat grid for each movie.

It has one class, `MovieBookingSystem`, with these behaviors:

- **Initialization**
  - Creates an empty list to store movie records.

- **Adding a movie**
  - `add_movie(name, price, start_time, end_time, n)` adds a movie to the system.
  - It stores:
    - the movie name,
    - the price,
    - the start and end times converted from `"HH:MM"` strings into `datetime` objects,
    - a seat matrix of size `n x n` filled with zeros, using NumPy.
  - Each seat is represented by a number in this matrix, where `0` means unbooked.

- **Booking tickets**
  - `book_ticket(name, seats_to_book)` searches for a movie by name.
  - If the movie is found, it checks each requested seat coordinate in `seats_to_book`.
  - If every requested seat is currently unbooked, it marks them as booked by setting the seat value to `1` and returns `"Booking success."`
  - If any requested seat is already booked, it stops and returns `"Booking failed."`
  - If no movie with the given name exists, it returns `"Movie not found."`

- **Finding available movies**
  - `available_movies(start_time, end_time)` takes two time strings in `"HH:MM"` format.
  - It returns a list of movie names whose show times fit entirely within the given time range.
  - A movie is included only if its start time is at or after the input start time and its end time is at or before the input end time.

Overall, the class manages a collection of movies, allows seat booking by seat coordinates, and can list movies that fall within a requested time window.
