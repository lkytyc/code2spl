This code defines a small SQLite-backed book database manager class called `BookManagementDB`.

When an instance is created, it takes a database filename, opens a connection to that SQLite database, creates a cursor, and then makes sure a `books` table exists. The table stores four fields: an integer `id` as the primary key, `title`, `author`, and an `available` flag stored as an integer.

The class provides methods to manage book records:

- `add_book(title, author)` inserts a new book with the given title and author, and marks it as available by setting `available` to 1.
- `remove_book(book_id)` deletes the book row with the matching `id`.
- `borrow_book(book_id)` updates the matching book so its `available` value becomes 0, indicating it is not available.
- `return_book(book_id)` updates the matching book so its `available` value becomes 1 again.
- `search_books()` retrieves all rows from the `books` table and returns them as a list of results.

Each write operation commits changes to the database immediately.
