This code defines a `Hotel` class that tracks room availability and bookings by room type.

- When a `Hotel` object is created, it takes a hotel `name` and a `rooms` dictionary. That dictionary is stored as `available_rooms`, where each room type maps to the number of available rooms. It also initializes `booked_rooms`, a nested dictionary used to record which guest has booked how many rooms of each type.

- `book_room(room_type, room_number, name)` attempts to reserve rooms for a guest:
  - If the requested room type does not exist in `available_rooms`, it returns `False`.
  - If the requested number of rooms is available, it records the booking under that room type and guest name, decreases the available count, and returns `"Success!"`.
  - If not enough rooms are available but some remain, it returns the number still available.
  - If no rooms of that type remain, it returns `False`.

- `check_in(room_type, room_number, name)` looks up an existing booking for a guest:
  - If the room type has no bookings, it returns `False`.
  - If the guest has a booking and tries to check in with more rooms than were booked, it returns `False`.
  - If the number matches the booked amount, the booking is removed.
  - If the number is smaller, it reduces that guest’s booked amount by the amount checked in.
  - This method does not return anything on successful partial or full check-in.

- `check_out(room_type, room_number)` increases the number of available rooms for that room type by the given amount. If the room type was not already present, it adds it.

- `get_available_rooms(room_type)` returns the current available count for the requested room type.

Overall, the class provides simple bookkeeping for hotel room inventory and guest reservations using dictionaries.
