This code defines a class named `KappaCalculator` with two static methods for computing inter-rater agreement statistics based on a contingency table of counts.

- `kappa(testData, k)`: computes Cohen’s kappa for a square `k x k` table.
  - **Input:** `testData` is converted into a NumPy matrix, and `k` is the number of categories.
  - **Behavior:** It sums the diagonal entries to get observed agreement, computes row and column totals, calculates expected agreement by chance, then applies the Cohen’s kappa formula.
  - **Output:** returns a single numeric kappa coefficient.

- `fleiss_kappa(testData, N, k, n)`: computes Fleiss’ kappa for multiple raters.
  - **Input:** `testData` is treated as an `N x k` matrix of category counts, where `N` is the number of items, `k` is the number of categories, and `n` is the number of ratings per item.
  - **Behavior:** For each item, it calculates the degree of agreement from the category counts, averages this observed agreement across all items, then computes expected agreement from overall category frequencies and applies the Fleiss’ kappa formula.
  - **Output:** returns a single numeric kappa value.

Both methods use NumPy matrix operations and are marked `@staticmethod`, so they are called directly on the class without creating an instance.
