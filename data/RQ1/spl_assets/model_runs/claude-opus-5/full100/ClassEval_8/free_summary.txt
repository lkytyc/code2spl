`BankAccount` models a simple bank account with a single float/int balance.

**Construction:** Takes an optional starting balance (defaults to 0).

**Deposits and withdrawals:** Both reject negative amounts with a `ValueError`. Withdrawals additionally reject amounts exceeding the current balance. Both update `self.balance` and return the new balance.

**View balance:** Returns the current balance without modifying it.

**Transfer:** Moves a given amount from one account to another by calling `withdraw` on the source and `deposit` on the destination. It does not handle partial failure — if `withdraw` raises (e.g. insufficient funds), `deposit` is never called, which is safe. However, if `deposit` somehow raised after a successful `withdraw`, the source account would already be debited with no rollback.

No persistence, no currency handling, no transaction history, and no concurrency protection are present.
