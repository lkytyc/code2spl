The `Manacher` class finds the longest palindromic substring of a given input string using a modified approach.

**Initialization**: The class takes an input string and stores it.

**`palindromic_length(center, diff, string)`**: A recursive helper that measures how far a palindrome extends from a given center position. Starting at distance `diff` from the center, it checks whether the characters equidistant on both sides match. It returns 0 as soon as a boundary is hit or a mismatch is found, otherwise returns `1 + recursive call with diff + 1`, effectively counting the number of matching pairs around the center.

**`palindromic_string()`**: The main method. It first transforms the input by inserting `|` pipe characters between every letter (e.g., `"abc"` → `"a|b|c"`). This separator trick lets the algorithm treat both odd- and even-length palindromes uniformly through a single center-based scan.

It then iterates over every position in the transformed string, calling `palindromic_length` for each as a potential center. It tracks the position with the greatest palindrome length found so far. After scanning, it extracts the substring centered at that position, strips out all `|` characters, and returns the result.

**Output**: The method returns the longest palindromic substring as a plain string without separators. If there are ties, it returns the first one encountered due to the strict `<` comparison used when updating the maximum.

One notable constraint: the recursion in `palindromic_length` is unbounded by Python's default recursion limit, so very long palindromes in a large string could raise a `RecursionError`.
