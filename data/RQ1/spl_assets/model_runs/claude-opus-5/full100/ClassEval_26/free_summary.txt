`CSVProcessor` is a simple class for reading, writing, and doing a basic transformation on CSV files. Here's what each part does:

**Reading (`read_csv`)** — Opens a CSV file, separates the first row as a header (`title`), collects the remaining rows into a list, and returns both.

**Writing (`write_csv`)** — Takes a list of rows and writes them to a file. Returns `1` on success, `0` if any exception occurs.

**Processing (`process_csv_data`)** — Reads a given file, extracts a single column by index `N` from every data row, uppercases each value in that column, then writes a new two-row CSV: the original header row followed by the extracted (uppercased) column values as a single row. The output file gets the same base name as the input with `_process` appended before the extension.

A few things worth noting about the behavior:

- The header is preserved in the output, but only the one requested column's data appears under it — all other columns are discarded.
- The result is a two-row file: one header row, one data row (not one row per original record).
- The bare `except` in `write_csv` silently swallows all errors, returning `0` without any detail about what failed.
- `split('.')[0]` for building the output filename will break on paths containing dots other than the extension.
