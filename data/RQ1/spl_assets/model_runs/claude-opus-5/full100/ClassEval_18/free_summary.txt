`CamelCaseMap` is a dict-like container that automatically normalizes its keys into camelCase before storing or retrieving values.

When you set, get, or delete an entry, the key goes through `_convert_key`, which passes string keys to `_to_camel_case` and leaves non-string keys alone. The conversion splits a string on underscores and rejoins it by title-casing every segment after the first — so `"my_key_name"` becomes `"myKeyName"`. Non-string keys pass through unchanged.

The class also supports `len()` and iteration, both delegating directly to the internal `_data` dict. It does not inherit from `dict` or `MutableMapping`, so it only exposes the five dunder methods explicitly defined.

The practical effect is that callers can write keys in either snake_case or camelCase and get consistent lookups, since both forms normalize to the same camelCase key internally.
