`UrlPath` is a small utility for building and parsing URL path strings.

**State:** Each instance holds a list of path segments (`segments`) and a boolean flag (`with_end_tag`) that tracks whether the original path ended with a trailing slash.

**`add(segment)`** manually appends a single segment after stripping leading and trailing slashes via `fix_path`.

**`parse(path, charset)`** takes a raw path string and a character encoding, then:
1. Checks for a trailing slash and sets `with_end_tag` if present.
2. Strips leading/trailing slashes from the whole path.
3. Splits on `/` to get individual segments.
4. Percent-decodes each segment using the given charset (e.g. `utf-8`) and appends it to `segments`.

**`fix_path(path)`** is a static helper that just strips leading and trailing slashes, returning an empty string for falsy input.

**Notable behavior:** The class records whether the path ended with a slash, but never uses that information internally — it's left on the object for callers to consume. There is no method to reconstruct the full path string from segments, and no validation of segment content beyond stripping slashes.
