`UserLoginDB` is a small class that wraps a SQLite database connection to manage a `users` table with `username` and `password` columns.

The constructor takes a database filename, opens a connection, and holds both the connection and a cursor as instance state.

It exposes four operations:

- `insert_user` — writes a new username/password row and commits.
- `search_user_by_username` — returns the first matching row for a given username, or `None` if not found.
- `delete_user_by_username` — removes the row with the matching username and commits.
- `validate_user_login` — calls `search_user_by_username` internally, then checks whether the returned row's second column matches the supplied password. Returns `True` on a match, `False` otherwise.

A few things worth noting: passwords are stored and compared in plaintext with no hashing. The class also never closes the connection, so callers are responsible for cleanup. There's no table-creation logic here, so the `users` table is assumed to already exist.
