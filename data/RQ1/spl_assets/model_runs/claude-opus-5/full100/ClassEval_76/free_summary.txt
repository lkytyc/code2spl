`SignInSystem` manages a simple registry of users and tracks whether each one has signed in.

On creation, it holds an empty dictionary mapping usernames to a boolean sign-in status.

`add_user` registers a new username with a default status of not signed in. It rejects duplicates, returning `False` if the username already exists and `True` on success.

`sign_in` marks an existing user as signed in. It returns `False` if the username isn't in the registry, `True` otherwise.

`check_sign_in` returns the current sign-in status of a user — `False` if the user doesn't exist or isn't signed in, `True` if they are.

`all_signed_in` returns `True` only when every registered user has signed in, using `all()` over the status values. Returns `False` if any user hasn't, or if the registry is empty (since `all()` on an empty iterable is `True` — worth noting as a potential edge case).

`all_not_signed_in` returns a list of usernames whose status is still `False`. If everyone has signed in, it returns an empty list.

There's no sign-out mechanism, no password or authentication of any kind, and no persistence — the state lives entirely in memory for the lifetime of the object.
