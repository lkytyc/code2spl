`BitStatusUtil` is a utility class for managing a set of flags packed into a single integer using bitwise operations. All methods are static.

The integer is treated as a collection of binary flags, where each active flag corresponds to a power-of-two bit being set. Before any operation, `check` validates that all inputs are non-negative and even — meaning only powers of two (2, 4, 8, 16, …) and zero are valid flag values.

The three operations:

- `add(states, stat)` — turns on a flag in `states` by OR-ing it with `stat`. Returns the new combined value.
- `has(states, stat)` — tests whether a flag is currently active by AND-ing and comparing the result to `stat`. Returns a boolean.
- `remove(states, stat)` — turns off a flag by XOR-ing it out, but only if it is currently set (checked via `has`). If the flag is absent, `states` is returned unchanged.

The even-number constraint in `check` means the class only accepts values where exactly one bit is set (powers of two) or zero. Odd numbers like 1, 3, or 7 raise a `ValueError`, which rules out flags that aren't clean single-bit values. Negative values are also rejected outright.
