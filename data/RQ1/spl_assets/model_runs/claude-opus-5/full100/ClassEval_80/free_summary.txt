`SQLQueryBuilder` is a utility class with four static methods that each construct and return a SQL query string for a given operation.

`select` builds a `SELECT` query against a named table. Columns default to `*` but can be passed as a list, which gets joined into a comma-separated string. An optional `where` dict adds `AND`-joined equality conditions.

`insert` builds an `INSERT INTO` query from a dict whose keys become column names and whose values become the inserted values. All values are wrapped in single quotes.

`delete` builds a `DELETE FROM` query with the same optional `where` logic as `select`.

`update` builds an `UPDATE ... SET` query from a dict of column-to-value pairs, again with optional `WHERE` conditions.

All four methods inline values directly into the query string using f-strings and single-quote wrapping, with no parameterization or escaping. This means any user-controlled input passed to these methods would be vulnerable to SQL injection.
