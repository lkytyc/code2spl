`LongestWord` is a utility class for finding the longest word in a sentence that also appears in a predefined word list.

**Setup:** You instantiate the class and populate its internal word list by calling `add_word` one word at a time. The list starts empty.

**Finding the longest word:** `find_longest_word` takes a sentence string and does three things to normalize it before searching: converts it to lowercase, strips all punctuation, then splits on spaces. It walks each token and checks two conditions — the word must exist in the stored word list, and it must be longer than the current longest match. The first word that satisfies both becomes the new candidate, and so on through the sentence.

**Output:** It returns the longest matching word as a string, or an empty string if nothing in the sentence matches the word list.

A few behavioral details worth noting: the word list comparison is case-sensitive after the sentence is lowercased, so words added to the list should be lowercase to match. Ties go to whichever match appears first, since a later word must be strictly longer to replace the current best. The sentence is split only on single spaces, so multiple consecutive spaces would produce empty-string tokens that silently fail the list lookup.
