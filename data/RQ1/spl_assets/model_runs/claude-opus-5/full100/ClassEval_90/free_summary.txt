`URLHandler` is a class that parses a URL string into its component parts. It takes a URL string in its constructor and exposes five read methods.

`get_scheme` extracts the protocol (e.g. `https`) by finding the `://` separator and returning everything before it.

`get_host` strips the scheme, then returns the portion between `://` and the first `/`. If no path slash is present, the entire remaining string is treated as the host.

`get_path` works similarly to `get_host` but returns everything from the first `/` onward after the scheme. If no slash exists, it returns `None`.

`get_query_params` finds the `?` marker and parses the query string into a dict of key-value pairs split on `&` and `=`. It uses the `#` position as the end boundary to exclude any fragment. Pairs that don't split into exactly two parts are silently skipped. Returns `None` if there's no `?`.

`get_fragment` returns everything after the first `#`, or `None` if absent.

All five methods return `None` when the expected delimiter isn't found. The class does no URL validation or encoding/decoding — it relies entirely on string searching, so malformed or unusual URLs may produce unexpected results.
