`NumberConverter` is a utility class with six static methods that convert numbers between decimal, binary, octal, and hexadecimal representations.

Each method takes a single input — either an integer (for decimal inputs) or a string (for binary, octal, or hex inputs) — and returns the converted result. The decimal-to-X methods use Python's built-in `bin()`, `oct()`, and `hex()` functions, then strip the leading prefix characters (`0b`, `0o`, `0x`) with `[2:]` to return just the digits. The X-to-decimal methods use `int()` with the appropriate base argument (2, 8, or 16) to parse the string back into an integer.

There's no input validation, no error handling, and no instance state — the class is essentially a namespace grouping six independent conversion functions. Negative numbers and non-string/non-integer inputs are not handled and would produce unexpected output or raise exceptions.
