The `Chat` class manages a simple in-memory messaging system between named users.

**State:** A single `users` dictionary maps each username to a list of message records they're involved in.

**Methods:**

- `add_user(username)` — registers a new user. Returns `False` if the username already exists, `True` otherwise.
- `remove_user(username)` — deletes a user and their message history. Returns `True` on success, `False` if the user wasn't found.
- `send_message(sender, receiver, message)` — creates a timestamped message record and appends it to both the sender's and receiver's lists. Returns `False` if either party isn't registered. The timestamp is generated at call time using the local system clock.
- `get_messages(username)` — returns the full list of message records for a user, or an empty list if the user doesn't exist.

**Key behaviors to note:** Messages are stored by reference — the same dictionary object is appended to both the sender's and receiver's lists. There's no deduplication, pagination, or filtering by sender/receiver within `get_messages`. The class has no persistence; all data is lost when the object is discarded.
