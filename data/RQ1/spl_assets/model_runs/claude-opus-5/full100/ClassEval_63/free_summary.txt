`NLPDataProcessor2` is a small text-analysis class that takes a list of strings, cleans them, and returns the five most frequent words.

**`process_data(string_list)`** — takes a list of raw strings. For each one it strips anything that isn't a letter or whitespace (using a regex), lowercases the result, then splits on whitespace into a list of words. Returns a list of those word lists, one per input string.

**`calculate_word_frequency(words_list)`** — takes the output of `process_data`. Uses a `Counter` to tally every word across all the inner lists, sorts the results by frequency descending, then slices off the top five entries and returns them as a plain dict.

**`process(string_list)`** — the public entry point. Chains the two methods above: cleans the input, counts frequencies, and returns the top-5 dict. Callers only need this one method.

The class has no state — every method operates purely on its arguments. There's no stopword removal, stemming, or handling for non-ASCII/Unicode text beyond stripping non-Latin characters entirely.
