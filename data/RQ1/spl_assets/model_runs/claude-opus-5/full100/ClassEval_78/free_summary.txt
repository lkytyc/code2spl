The `SplitSentence` class provides three methods for working with text:

**`split_sentences(sentences_string)`** — takes a string of text and splits it into a list of sentences. The regex uses two negative lookbehinds to avoid false splits on abbreviations (like "e.g." or "Dr."), and splits only after a period or question mark followed by whitespace.

**`count_words(sentence)`** — takes a single sentence, strips all non-alphabetic characters (punctuation, numbers, etc.), splits on whitespace, and returns the word count as an integer.

**`process_text_file(sentences_string)`** — the main entry point. It splits the input string into sentences using `split_sentences`, then iterates over them to find and return the word count of the longest sentence (by word count, after punctuation is stripped).

The class has no constructor or state — all three methods are stateless and operate purely on their inputs. There's no actual file I/O despite the method name `process_text_file`; it just accepts a plain string.
