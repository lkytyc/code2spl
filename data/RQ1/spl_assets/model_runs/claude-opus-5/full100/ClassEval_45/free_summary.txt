`ImageProcessor` is a class that wraps a single PIL `Image` object and provides a small set of in-place operations on it.

**Lifecycle:** You call `load_image` with a file path to open an image into memory, and `save_image` with a destination path to write it back out. The internal image reference is `None` until loaded, and every method silently does nothing if it hasn't been loaded yet.

**Transformations:** Three mutations are available:
- `resize_image` replaces the image with a new version scaled to the given pixel dimensions.
- `rotate_image` replaces it with a rotated copy at the specified degree angle.
- `adjust_brightness` uses PIL's `ImageEnhance.Brightness` to scale luminosity by a numeric factor — values below 1.0 darken, above 1.0 brighten.

Each operation overwrites `self.image` in place, so transformations are cumulative and there's no undo. The class holds no history, no original copy, and no metadata beyond the current image state.
