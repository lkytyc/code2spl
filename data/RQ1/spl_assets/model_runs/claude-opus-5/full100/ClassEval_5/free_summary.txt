`AutomaticGuitarSimulator` takes a string of text representing guitar chords and tunes, parses it, and optionally displays each parsed segment.

**Construction:** The class is initialized with a string (`play_text`) that represents the full input to be parsed.

**`interpret(display=False)`:** This is the main method. If the input string is empty or only whitespace, it returns an empty list. Otherwise, it splits the string on spaces, treating each space-separated token as one "segment." For each segment, it scans from the left to find where leading alphabetic characters end — that prefix becomes the chord name, and everything after it becomes the tune value. Each segment is stored as a dict with `'Chord'` and `'Tune'` keys, and the full list of these dicts is returned. If `display` is `True`, it calls `display()` for each segment as it goes.

**`display(key, value)`:** Formats and returns a string like `"Normal Guitar Playing -- Chord: X, Play Tune: Y"`. Note that it only *returns* the string — it doesn't print it — so the display call inside `interpret` actually has no visible side effect.

**Key nuance:** The parsing assumes chords are purely alphabetic and that numeric or symbolic characters immediately follow them. A segment like `"Am7"` would yield chord `"Am"` and tune `"7"`. A segment with no alphabetic prefix (e.g., `"7"`) would produce an empty chord string.
