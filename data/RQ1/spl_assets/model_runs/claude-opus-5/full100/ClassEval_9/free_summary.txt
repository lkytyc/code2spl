`BigNumCalculator` is a utility class with three static methods that perform arithmetic on arbitrarily large non-negative integers represented as plain digit strings (e.g., `"12345"`), bypassing Python's native integer type entirely.

**add(num1, num2)**
Pads both strings to equal length with leading zeros, then iterates right-to-left summing corresponding digits plus a running carry. Any remaining carry after the loop is prepended. Returns the result as a string.

**subtract(num1, num2)**
First determines which operand is larger by comparing lengths, then lexicographic order for equal-length strings, swapping them and setting a `negative` flag if needed so the subtraction always proceeds larger minus smaller. It then iterates right-to-left, borrowing from the next position when a digit difference goes negative. Leading zeros are stripped from the result, and a `'-'` is prepended if the result should be negative. Returns the result as a string.

**multiply(num1, num2)**
Uses the classic grade-school digit-by-digit algorithm. Allocates a result array of length `len1 + len2`, then for each pair of digits multiplies them and accumulates into the appropriate two positions, handling carries inline. Leading zeros are stripped before returning the result as a string.

All three methods are pure functions — no state, no I/O, no mutation of inputs. They handle numbers of any size limited only by string/memory constraints. There is no input validation, so non-digit characters or empty strings would cause errors.
