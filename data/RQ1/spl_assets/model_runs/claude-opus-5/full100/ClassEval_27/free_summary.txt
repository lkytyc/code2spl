`CurrencyConverter` is a simple currency conversion utility that holds a fixed set of exchange rates relative to USD as a base.

On initialization it seeds an internal dictionary with seven currencies (USD, EUR, GBP, JPY, CAD, AUD, CNY) and their rates against USD 1.0.

The four methods:

- `convert(amount, from_currency, to_currency)` — converts a numeric amount between two currencies. It first short-circuits if both currencies are the same. If either currency is missing from the rate table it returns `False`. Otherwise it normalizes the amount to USD by dividing by the source rate, then multiplies by the target rate to produce the converted value.

- `get_supported_currencies()` — returns the current rate-table keys as a list, reflecting any currencies added at runtime.

- `add_currency_rate(currency, rate)` — inserts a new currency/rate pair. Returns `False` (without modifying anything) if that currency already exists; otherwise silently adds it.

- `update_currency_rate(currency, new_rate)` — replaces the rate for an existing currency. Returns `False` if the currency is not already in the table; otherwise silently updates it.

One thing worth noting: `convert` returns either a float or the boolean `False` on error, which makes caller error-checking easy to accidentally skip since `False` is falsy but not an exception. The add and update methods also return `False` on failure but return `None` on success, so callers have to remember which return value signals which outcome.
