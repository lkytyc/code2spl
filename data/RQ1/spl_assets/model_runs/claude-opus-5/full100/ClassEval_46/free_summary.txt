The `Interpolation` class provides two static methods for linear interpolation, requiring no instance state (the constructor does nothing).

`interpolate_1d` takes a known set of x/y data points and a list of query x values (`x_interp`). For each query value, it walks the known x array to find the segment it falls within, then applies the standard linear interpolation formula to estimate the corresponding y. Results are collected into a list and returned. Points outside the known x range are silently skipped — no extrapolation occurs and no error is raised.

`interpolate_2d` extends this to a 2D grid. It takes x and y axis arrays, a 2D z value grid, and paired lists of query x/y coordinates. For each query point it finds the enclosing cell in the x and y axes, then performs bilinear interpolation using the four corner z values of that cell. The formula weights each corner by its area-proportion relative to the query point. Results are returned as a flat list. Like the 1D case, query points outside the defined grid are silently dropped.

Both methods assume the input axis arrays are sorted in ascending order and that the query points fall within the data range — neither condition is validated. The class structure adds no real value here since both methods are static and share no state; they could equivalently be module-level functions.
