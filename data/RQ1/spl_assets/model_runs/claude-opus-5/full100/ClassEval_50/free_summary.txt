`JSONProcessor` is a class that reads, writes, and edits JSON files on disk.

`read_json` takes a file path and returns the parsed JSON content as a Python object. If the file doesn't exist it returns `0`; if any other error occurs during reading or parsing it returns `-1`.

`write_json` takes a Python object and a file path, serializes the object to JSON, and writes it to that file. Returns `1` on success, `-1` on failure.

`process_json` ties the two together. It reads a JSON file, then removes a specified key from the top-level object if that key is present, writes the modified data back to the same file, and returns `1`. If the file was missing or unreadable, or if the key wasn't found, it returns `0` without writing anything.

One thing worth noting: the return values from `read_json` (`0` for missing, `-1` for error) collide with valid JSON values — a JSON file containing the integer `0` or `-1` would be misidentified as an error state by `process_json`.
