`VectorUtil` is a stateless utility class with four static methods for working with numerical vectors.

`similarity` takes two vectors and returns their cosine similarity as a scalar between -1 and 1. It delegates normalization to gensim's `unitvec` and uses a dot product.

`cosine_similarities` takes a single vector and a 2D array of vectors, then returns an array of cosine similarity scores between the single vector and each row. It does the normalization manually with `numpy` norms rather than using gensim, which makes it more efficient for batch comparisons.

`n_similarity` compares two *lists* of vectors rather than individual vectors. It averages each list down to a single representative vector and then computes cosine similarity between those two averages. It raises `ZeroDivisionError` if either list is empty.

`compute_idf_weight_dict` takes a total document count and a dictionary mapping keys (typically words or tokens) to their document frequency counts. It applies smoothed IDF — `log((total_num + 1) / (count + 1))` — to each count and returns a new dictionary mapping the same keys to their IDF weight. The smoothing prevents division by zero when a term appears in every document. An intermediate index-to-key map is built to align numpy array positions back to the original keys after the vectorized log operation.
