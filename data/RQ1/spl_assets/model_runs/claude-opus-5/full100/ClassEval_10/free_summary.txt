`BinaryDataProcessor` is a class that takes a binary string as input, cleans it, and offers three operations on it.

**Construction and cleaning**

When instantiated, it immediately strips any characters that aren't `0` or `1` from the input string, so callers don't need to pre-sanitize it.

**`calculate_binary_info`**

Counts the zeros and ones, then returns a dict with three keys: the proportion of zeros (`Zeroes`), the proportion of ones (`Ones`), and the total bit length after cleaning. The proportions are raw floats between 0 and 1, not percentages despite the variable names suggesting otherwise. There's a latent division-by-zero risk if the cleaned string ends up empty.

**`convert_to_ascii` and `convert_to_utf8`**

Both methods do the same thing structurally: they walk the cleaned binary string in 8-bit chunks, convert each chunk from binary to an integer, build a `bytearray`, then decode it. The only difference is the codec — `ascii` vs `utf-8`. Since ASCII is a strict subset of UTF-8, `convert_to_utf8` is a more permissive version of the same operation. Neither method handles a string whose length isn't a multiple of 8, which would silently produce a truncated or malformed last byte.
