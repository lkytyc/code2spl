`DecryptionUtils` is a Python class that implements three classical cipher decryption methods. It takes a key string at construction time, used by the Vigenère method.

**`caesar_decipher(ciphertext, shift)`**
Reverses a Caesar cipher by shifting each alphabetic character backward by the given amount, wrapping around with modulo 26. Case is preserved; non-alphabetic characters pass through unchanged.

**`vigenere_decipher(ciphertext)`**
Reverses a Vigenère cipher using the instance's key. Each alphabetic character is shifted back by the value of the corresponding key character (cycling through the key as needed). The key index only advances on alphabetic characters, so punctuation and spaces don't consume key positions. Case is preserved in output; non-alphabetic characters pass through unchanged.

**`rail_fence_decipher(encrypted_text, rails)`**
Reverses a rail fence (zigzag) cipher given the number of rails used during encryption. It works in two passes: first it reconstructs the zigzag pattern to mark which positions in the output belong to which rail, then it fills each rail's positions with the corresponding slice of the encrypted input, and finally it reads back along the zigzag to recover the original order.

The three methods are independent of each other — `caesar_decipher` and `rail_fence_decipher` don't use the instance key. The class stores the key solely for `vigenere_decipher`.
