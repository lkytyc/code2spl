`Statistics3` is a utility class containing seven static methods for descriptive statistics. It takes no constructor arguments and holds no state — every method operates independently on the data passed to it.

**Inputs and outputs by method:**

`mean(data)` — takes a list of numbers, returns their arithmetic mean, or `None` if the list is empty.

`median(data)` — sorts the input list, then returns the middle value for odd-length inputs or the average of the two middle values for even-length inputs.

`mode(data)` — counts occurrences of each value, then returns a list of all values tied for the highest count. Always returns a list, even when there's a single mode.

`standard_deviation(data)` — computes the sample standard deviation (divides by n−1). Returns `None` if the input has fewer than two elements. Internally calls `mean`.

`z_score(data)` — standardizes each value in the list by subtracting the mean and dividing by the standard deviation. Returns `None` if the standard deviation is zero or undefined (i.e., fewer than two elements). Internally calls both `mean` and `standard_deviation`.

`correlation(x, y)` — computes the Pearson correlation coefficient between two equal-length sequences. Returns `None` if the denominator is zero, which happens when either sequence has no variance.

`correlation_matrix(data)` — takes a 2D list where each row is an observation and each column is a variable. Returns a square matrix where entry [i][j] is the Pearson correlation between column i and column j. Internally calls `correlation` for every column pair, including each column with itself (which always yields 1.0).

**Notable interactions:** `z_score` depends on `mean` and `standard_deviation`; `correlation_matrix` depends on `correlation`. The rest are self-contained. There's no input validation beyond the `None`-return guards, so passing mismatched lengths to `correlation`, or non-numeric values, would raise a runtime error.
