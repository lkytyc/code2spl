`RegexUtils` is a utility class that wraps Python's `re` module and provides both general-purpose regex operations and some domain-specific helpers.

**Core operations** (thin wrappers around `re`):
- `match` — checks whether a pattern matches at the start of `text`, returning a boolean
- `findall` — returns all non-overlapping matches of a pattern in `text`
- `split` — splits `text` on occurrences of a pattern
- `sub` — replaces all matches of a pattern in `text` with a replacement string

**Pattern generators** (return raw pattern strings):
- `generate_email_pattern` — produces a pattern for email addresses in the format `user@domain.tld`
- `generate_phone_number_pattern` — produces a pattern for US-style phone numbers in the format `###-###-####`
- `generate_split_sentences_pattern` — produces a pattern that matches sentence-ending punctuation (`.`, `!`, `?`) followed by one or two spaces and an uppercase letter

**Higher-level methods** that combine a pattern generator with a core operation:
- `split_sentences` — uses the sentence pattern to split a block of text into individual sentences
- `validate_phone_number` — uses the phone pattern to check whether a given string is a valid phone number (boolean result)
- `extract_email` — uses the email pattern to find and return all email addresses in a text

One behavioral note: `match` uses `re.match`, which only checks from the start of the string, not anywhere within it. This means `validate_phone_number` will only match if the phone number appears at the very beginning of the input, which could be a subtle bug depending on intent.
