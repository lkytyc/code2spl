`DataStatistics4` is a utility class with four independent static methods, each performing a different descriptive or probabilistic calculation on numeric data.

`correlation_coefficient(data1, data2)` measures the linear relationship between two equal-length sequences. It computes the Pearson correlation coefficient: the covariance of the two datasets divided by the product of their standard deviations. Returns a value between -1 and 1, or 0 if the denominator is zero.

`skewness(data)` quantifies the asymmetry of a dataset's distribution. It uses the adjusted Fisher-Pearson formula, factoring in sample size corrections via `n / ((n-1) * (n-2))`. Returns 0 if the standard deviation is zero.

`kurtosis(data)` measures the "tailedness" of a distribution. It computes the population fourth central moment divided by the fourth power of the population standard deviation, then subtracts 3 to produce excess kurtosis relative to a normal distribution. Returns `math.nan` if the standard deviation is zero.

`pdf(data, mu, sigma)` evaluates the Gaussian (normal) probability density function at each point in `data`, given a mean `mu` and standard deviation `sigma`. Returns a list of density values, one per input point.

A few things worth noting: `skewness` uses population variance to derive its standard deviation but applies a sample-size correction in the numerator, which is a mix of population and sample formulas. `kurtosis` uses strictly population-based moments throughout. Neither method validates input length or guards against division by zero in all cases (e.g., `pdf` would raise a `ZeroDivisionError` if `sigma` is 0).
