The `BalancedBrackets` class checks whether the bracket characters in a string are properly nested and matched.

**Setup (`__init__`):** Takes an expression string and stores it alongside an internal stack and two lists defining the opening and closing bracket types: `(`, `{`, `[` and their counterparts.

**Filtering (`clear_expr`):** Strips the expression down to only bracket characters, discarding everything else.

**Core check (`check_balanced_brackets`):** Calls `clear_expr` first, then walks the filtered string character by character. Opening brackets are pushed onto the stack. When a closing bracket is encountered, the top of the stack is popped and compared — if the pair doesn't match (e.g., `[` paired with `)`), the method returns `False`. After the full pass, if the stack is empty all brackets were matched and it returns `True`; a non-empty stack means there were unclosed openers, so it returns `False`.

One thing worth noting: if a closing bracket is encountered while the stack is empty, `stack.pop()` will raise an `IndexError` rather than gracefully returning `False`. That's a latent bug for inputs like `")("`.
