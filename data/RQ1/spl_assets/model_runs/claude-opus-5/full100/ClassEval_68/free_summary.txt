`PageUtil` is a Python class that wraps a list of data and provides pagination and search functionality over it.

**Construction:** Takes a `data` list and a `page_size` integer. It immediately computes the total item count and total page count using ceiling division.

**`get_page(page_number)`:** Returns a plain slice of the data for the requested page. Returns an empty list if the page number is out of bounds (below 1 or above the total). The slice uses `page_size` directly as the end index, so the last page may contain fewer items without any special handling needed.

**`get_page_info(page_number)`:** Does the same bounds check and slicing, but returns a dictionary with richer metadata: current page number, items per page, total pages, total items, booleans for whether a previous or next page exists, and the page's data. It correctly clamps the end index to `total_items` to avoid overshoot in the reported slice.

**`search(keyword)`:** Scans every item in the full dataset, converting each to a string and checking if the keyword is a substring. It collects all matches, computes a page count for them using the same `page_size`, and returns a dictionary with the keyword, match count, computed page count, and the full flat list of matching items. It does not paginate the results itself — it just reports how many pages they would span and hands back the complete result list.

One subtle difference between `get_page` and `get_page_info`: `get_page` slices with a raw `end_index` that can exceed the list length (Python handles this silently), while `get_page_info` explicitly clamps with `min(..., total_items)`. Both produce the same data; the difference is only in how the end index is computed before slicing.
