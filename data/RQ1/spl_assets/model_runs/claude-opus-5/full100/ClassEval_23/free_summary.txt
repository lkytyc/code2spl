`CombinationCalculator` is a utility class that generates combinations from a list of string items.

**Constructor and data:** It takes a list of strings on initialization and stores them as the pool to draw from.

**Static counting methods:**
- `count(n, m)` returns the number of ways to choose `m` items from `n` using the standard combinatorics formula C(n, m). It short-circuits the factorial math when `m` is 0 or equals `n`.
- `count_all(n)` returns the total number of non-empty subsets of a set with `n` elements, which is `2ⁿ - 1`. It rejects negative or excessively large inputs (above 63) by returning `False`, and handles the edge case of exactly 63 by returning infinity instead of computing a large bit shift.

**Combination generation:**
- `select(m)` returns all combinations of exactly `m` items drawn from the stored list, preserving order relative to the original list but not repeating elements. It delegates to the private recursive method `_select`.
- `select_all()` returns every possible non-empty combination — size 1, 2, 3, up to the full length — by calling `select` for each size and concatenating the results.
- `_select` is the recursive backtracking engine. It fills a fixed-length result slot one position at a time, advancing the data index forward to avoid reuse and prevent duplicate orderings. When the slot is full, it appends a copy to the accumulator list.

**Summary:** The class separates counting (how many combinations exist) from enumeration (what those combinations actually are), and uses recursive backtracking to enumerate without generating redundant or repeated groupings.
