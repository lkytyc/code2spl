`DatabaseProcessor` is a simple class that wraps SQLite operations for a single named database.

**Constructor** takes a database filename and stores it.

**`create_table`** creates a table (if it doesn't already exist) with three columns: an auto-incrementing integer primary key, a TEXT column, and an INTEGER column. The column names for the last two are passed in as arguments, but the types are hardcoded.

**`insert_into_database`** takes a list of dicts and inserts each one as a row, always pulling `name` (TEXT) and `age` (INTEGER) keys — the column names are hardcoded here regardless of what was passed to `create_table`.

**`search_database`** queries all columns from a given table where the `name` column matches a provided string, returning the rows if found or `None` if not.

**`delete_from_database`** removes all rows from a table where `name` matches the provided string.

A few things worth noting: every method opens and closes its own connection, so there's no connection pooling or shared state. The `pandas` import is present but never used. The `create_table` method accepts generic column name parameters, but `insert_into_database` ignores them and hardcodes `name`/`age`, which would break if the table was created with different column names. The table and column names in `create_table` are interpolated directly into the SQL string, which is a SQL injection risk.
