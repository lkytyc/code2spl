The code defines an `IPAddress` class that wraps a single IPv4 address string and provides three operations on it.

**Construction and validation.** The class is instantiated with a string. `is_valid` checks whether that string is a well-formed IPv4 address: it splits on dots, requires exactly four parts, and verifies that each part is a non-negative integer no greater than 255. It does not guard against leading zeros (e.g., `"010"` would pass).

**Octet retrieval.** `get_octets` returns the four parts as a list of strings if the address is valid, or an empty list otherwise.

**Binary conversion.** `get_binary` converts a valid address to its dotted binary representation — each octet becomes an 8-character zero-padded binary string, joined with dots (e.g., `"192.168.1.1"` → `"11000000.10101000.00000001.00000001"`). It returns an empty string for invalid addresses.

All three methods are self-contained; `get_octets` and `get_binary` both call `is_valid` internally, so no external validation step is required before using them.
