`JobMarketplace` is a simple in-memory job board. It holds two lists: job listings and resumes, both starting empty.

**Posting and removing:** `post_job` creates a dict with a title, company name, and a list of requirements, then appends it to `job_listings`. `remove_job` pulls a matching job dict back out. `submit_resume` and `withdraw_resume` do the same for the resumes list, where each resume stores a name, a skills list, and an experience value.

**Searching jobs:** `search_jobs` takes a plain string and does a case-insensitive check against every listing's title and each individual requirement. Any listing that matches either gets collected and returned.

**Finding applicants for a job:** `get_job_applicants` walks every stored resume and delegates to the static helper `matches_requirements`. That helper iterates over every skill in the resume and returns `False` the moment it finds one not present in the job's requirements list. If all skills clear that check it returns `True`. Only passing resumes get added to the applicants result.

One notable behavior: `matches_requirements` checks that every resume skill exists in the requirements list, but it does not check the reverse — a resume with no skills at all will always return `True` and match every job.
