`ChandrasekharSieve` is a class that finds all prime numbers up to a given integer `n` using the Sieve of Eratosthenes algorithm.

On construction, it takes a single integer `n` and immediately runs the sieve, storing the result internally.

The sieve works by allocating a boolean array of size `n+1`, initializing all entries to `True`, then marking `False` for index 0 and 1. It then iterates from `p = 2` up to the square root of `n`. For each `p` that is still marked `True` (i.e., still considered prime), it marks all multiples of `p` starting from `p²` as `False`. After this pass, the indices still marked `True` are collected into a list of primes.

If `n` is less than 2, the method returns an empty list immediately without running the sieve.

The public interface has one method, `get_primes()`, which simply returns the pre-computed list of prime integers. There is no lazy evaluation — the sieve runs at construction time and the result is cached in `self.primes`.
