The `Calculator` class evaluates mathematical expressions given as strings, supporting addition, subtraction, multiplication, division, and exponentiation (`^`).

**How it works:**

It uses the classic two-stack (operand and operator) approach — a variant of the shunting-yard algorithm — to handle operator precedence without building a full parse tree.

The `calculate` method scans the expression character by character:
- Digits and decimal points are buffered to form multi-character or floating-point numbers, then pushed onto the operand stack.
- When an operator is encountered, any pending operators on the operator stack with equal or higher precedence are applied first (via `apply_operator`), then the new operator is pushed. This enforces correct precedence ordering.
- Parentheses are handled by pushing `(` onto the operator stack and, on `)`, flushing all operators down to the matching `(`.
- After the full expression is scanned, any remaining operators are applied in order.

The `precedence` method assigns ranks: `+`/`-` → 1, `*`/`/` → 2, `^` → 3.

The `apply_operator` method pops the top operator and the top two operands, applies the corresponding lambda from the `operators` dict, and pushes the result back. The `^` branch handles exponentiation but is structurally identical to the other operators — both pop two values in the same order, so the distinction is vestigial.

**Inputs:** A string expression with digits, `.`, `+`, `-`, `*`, `/`, `^`, `(`, `)`. No whitespace handling or unary minus is present, so those would cause incorrect behavior.

**Output:** A single `float` result, or `None` if the operand stack is empty after evaluation.

**Notable gaps:** No error handling for division by zero, mismatched parentheses, or invalid characters. The `^` branch in `apply_operator` is identical to the `else` branch, so the operator distinction there has no effect.
