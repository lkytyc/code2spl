`BookManagement` is a simple in-memory inventory manager for books. The inventory is stored as a dictionary keyed by book title, with integer quantities as values.

There are four methods:

- `add_book(title, quantity=1)` — increments the count for a title if it already exists, otherwise adds it with the given quantity. Defaults to adding one copy.
- `remove_book(title, quantity)` — subtracts the given quantity from a title's count. Raises `False` (notably misusing `raise` with a non-exception value) if the title doesn't exist or if the requested quantity exceeds what's in stock. If the count reaches zero, the title is removed from the dictionary entirely.
- `view_inventory()` — returns the entire inventory dictionary directly, with no copy or formatting applied.
- `view_book_quantity(title)` — returns the current count for a specific title, or 0 if it isn't in the inventory.

There are no interactions with external systems, persistence, or other classes. One notable bug: `remove_book` raises `False` instead of a proper exception, which would cause a `TypeError` at runtime since only exception instances or classes can be raised.
