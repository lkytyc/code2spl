`DataStatistics2` is a simple statistics utility that wraps a numeric dataset and exposes six read-only computations on it.

**Construction:** Takes any array-like input and converts it to a NumPy array on initialization. No validation or transformation beyond that.

**Methods:**

- `get_sum` — returns the total of all elements.
- `get_min` / `get_max` — return the smallest and largest values respectively.
- `get_variance` — returns the population variance, rounded to 2 decimal places.
- `get_std_deviation` — returns the population standard deviation, rounded to 2 decimal places.
- `get_correlation` — passes the data to `np.corrcoef` with `rowvar=False`, treating each column as a variable. This is meaningful when the input is 2D (multiple variables across rows); on a 1D array it just returns a 1×1 matrix with the value 1.0.

All methods operate directly on `self.data` with no side effects. The class holds no other state and has no update or mutation methods.
