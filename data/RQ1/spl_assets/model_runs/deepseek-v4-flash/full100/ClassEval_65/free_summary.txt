NumberWordFormatter converts a numeric value into an English word representation, similar to check-writing format. The main `format` method returns an empty string for `None`; otherwise it converts the value to a string and delegates to `format_string`. That method splits the input into an integer part and an optional decimal part, groups the integer digits into threes from the right, and uses helper methods `trans_three` and `trans_two` to spell out each group. Large-number scale words such as thousand, million, and billion are supplied by `parse_more`. If there is a decimal part, it is appended as an “AND CENTS ...” phrase, and the result ends with “ONLY”. When the integer part is empty or all zero, the function returns “ZERO ONLY”.
