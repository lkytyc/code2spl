URLHandler stores a URL string and provides methods to parse different parts of it. `get_scheme` returns the substring before `://`, or `None` if `://` is absent. `get_host` returns the substring after `://` up to the next `/`, or the remainder after `://` if there is no slash; it returns `None` if `://` is not present. `get_path` returns the substring starting at the first `/` after the host, or `None` if no such slash exists. `get_query_params` parses text after `?` as URL query parameters, splitting on `&` and `=`, and returns a dictionary of keys to values; it returns `None` if there is no `?`, and an empty dictionary for an empty query string. `get_fragment` returns the substring after `#`, or `None` if there is no `#`.
