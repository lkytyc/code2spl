ExpressionCalculator evaluates arithmetic expression strings. The `calculate` method takes a string expression, removes spaces and an optional trailing `=`, rewrites unary minus signs using a placeholder, converts the expression from infix to postfix notation, and then evaluates the postfix tokens. It supports `+`, `-`, `*`, `/`, `%`, and parentheses. Intermediate arithmetic is done with `Decimal` to avoid floating-point precision issues, then the final numeric result is returned as a float. The class uses helper methods for operator precedence, token classification, postfix preparation, and the actual arithmetic operations.
