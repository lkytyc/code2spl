This code defines a `BookManagementDB` class for managing a SQLite database of books. The constructor opens a connection to a specified database file and ensures a `books` table exists with columns for ID, title, author, and availability. The `add_book` method inserts a new book with availability set to 1. `remove_book` deletes a book by its ID. `borrow_book` and `return_book` update the availability status to 0 or 1 for a given book ID. `search_books` fetches and returns all book records from the table. Each operation is committed to the database.
