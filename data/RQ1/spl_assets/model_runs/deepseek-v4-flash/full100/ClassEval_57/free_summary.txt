The `MetricsCalculator2` class provides two static ranking metrics: MRR (Mean Reciprocal Rank) and MAP (Mean Average Precision). Each method accepts either a single tuple `(relevance_list, total_relevant_count)` or a list of such tuples. The relevance list is expected to contain binary/indicator values, where nonzero values mark relevant items. If the input is a single tuple, each method returns a pair `(score, [score])`; if a list is given, it computes per-query scores and returns `(mean_score, list_of_scores)`. Empty input or a `total_relevant_count` of zero yields `0.0` (and `[0.0]`). Non-list/tuple inputs raise an exception. MRR finds the reciprocal rank of the first relevant item, while MAP calculates average precision by dividing the sum of precision-at-relevant-ranks by the total number of relevant items.
