The `CookiesUtil` class manages cookie persistence for HTTP-like response and request dictionaries. It is initialized with a JSON file path for storing cookies. `get_cookies(response)` extracts cookies from a response dictionary, stores them on the instance, and saves them to the file. `load_cookies()` reads and returns the saved cookies from the JSON file, returning an empty dictionary if the file does not exist. `_save_cookies()` writes the current cookies to the file and returns `True` on success or `False` on failure. `set_cookies(request)` formats the stored cookies as a semicolon-separated `key=value` string and assigns it to the `'cookies'` key of the provided request dictionary.
