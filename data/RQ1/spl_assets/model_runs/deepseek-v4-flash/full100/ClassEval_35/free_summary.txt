This class implements an 8-puzzle solver. It stores the starting board and a fixed goal board with tiles 1 through 8 and a blank space represented by 0. It provides methods to locate the blank tile, compute valid blank moves, and return a new board state after moving the blank up, down, left, or right. The solve method performs a breadth-first search from the initial state, tracking visited states, and returns the list of moves needed to reach the goal state, or None if no solution is found.
