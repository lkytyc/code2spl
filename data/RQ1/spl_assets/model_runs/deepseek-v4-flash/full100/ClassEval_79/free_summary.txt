The `SQLGenerator` class creates SQL query strings for a specified database table. Its constructor takes a table name and stores it. Methods build different SQL statements: `select` generates a SELECT query with optional field list and WHERE condition; `insert` creates an INSERT statement from a dictionary of column-value pairs; `update` produces an UPDATE statement with a SET clause from a dictionary and a WHERE condition; `delete` constructs a DELETE statement with a WHERE condition. Values are inserted into the SQL string as quoted text, assuming they are already formatted correctly. Two convenience methods, `select_female_under_age` and `select_by_age_range`, build predefined WHERE conditions for those common queries and delegate to the `select` method. All methods return complete SQL strings ending with a semicolon; they do not execute the queries.
