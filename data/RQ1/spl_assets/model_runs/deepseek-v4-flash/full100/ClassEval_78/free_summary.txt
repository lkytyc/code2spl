The `SplitSentence` class provides basic text analysis utilities. Its `split_sentences` method divides an input string into sentences using regex, splitting after periods or question marks followed by whitespace, while avoiding incorrect splits after common abbreviations and initials. The `count_words` method removes punctuation and non-letter characters from a sentence, then returns the number of words it contains. The `process_text_file` method combines these by splitting the input string into sentences, counting the words in each sentence, and returning the maximum word count among all sentences.
