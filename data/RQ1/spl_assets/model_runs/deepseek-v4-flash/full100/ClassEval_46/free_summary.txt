The `Interpolation` class provides two static methods for interpolating data on regular grids. `interpolate_1d` takes known x and y coordinates plus a list of query x values, and returns linearly interpolated y values for each query point. `interpolate_2d` takes known x, y, and a 2D z grid plus lists of query x and y coordinates; for each paired query point it performs bilinear interpolation using the surrounding grid cell and returns the resulting z values. Both methods assume the query points lie within the provided coordinate ranges and process points in the order given.
