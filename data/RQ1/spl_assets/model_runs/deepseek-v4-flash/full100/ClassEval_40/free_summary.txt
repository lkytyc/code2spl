The `FitnessTracker` class stores a person’s height, weight, age, and sex. It calculates body mass index (BMI) as weight divided by height squared, then classifies the condition by comparing the BMI to sex-specific normal ranges: males 20–25, females 19–24. The judgment returns `1` if above the range, `-1` if below, and `0` if within the range. It also estimates daily calorie intake by first computing basal metabolic rate (BMR) using sex-specific formulas based on weight, height, and age, then multiplying the BMR by an activity factor determined by the condition judgment: `1.2` for overweight, `1.6` for underweight, and `1.4` for normal weight. The class exposes `get_BMI`, `condition_judge`, and `calculate_calorie_intake` methods to provide these outputs.
