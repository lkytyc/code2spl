The code defines a `KappaCalculator` class with two static methods for computing inter-rater agreement metrics using NumPy.

- `kappa(testData, k)` computes **Cohen’s kappa coefficient** from a square confusion matrix. It takes the observed data matrix and the number of categories `k`, calculates the observed agreement from the diagonal entries and the expected agreement from row/column totals, then returns the kappa value as a float.

- `fleiss_kappa(testData, N, k, n)` computes **Fleiss’ kappa** for multiple raters. It takes the rating matrix, number of subjects `N`, number of categories `k`, and number of raters per subject `n`. It calculates observed agreement per subject, aggregates it, computes expected agreement from category totals, and returns the Fleiss kappa coefficient as a float.

Both methods assume the input data is structured to match standard formulas for these agreement measures and rely on NumPy matrix operations.
