This class manages a movie booking system with showtimes and seat reservations. Movies are added with a title, ticket price, start and end times (provided as HH:MM strings), and a square seat grid of size n×n initially marked as available. Booking tickets requires a movie name and a list of seat coordinates; the system marks each requested seat as occupied, but if any seat is already taken, the entire booking fails. It returns "Booking success." on success, "Booking failed." if a selected seat is unavailable, and "Movie not found." if the movie name does not exist. A separate method takes a start and end time as HH:MM strings and returns the names of movies whose showtimes fall completely within that time window.
