The `SQLQueryBuilder` class provides static utility methods that generate SQL query strings from simple Python inputs without executing them. The `select` method builds a `SELECT` query for a given table, accepting either `'*'` or a list of column names, and optionally adds a `WHERE` clause from a dictionary of equality conditions joined by `AND`. The `insert` method constructs an `INSERT INTO` statement from a table name and a dictionary of column-value pairs. The `delete` method creates a `DELETE FROM` query, optionally filtered by a `WHERE` dictionary. The `update` method builds an `UPDATE` statement using a data dictionary for `SET` assignments and an optional `WHERE` dictionary. All method-generated queries wrap values in single quotes, and none of the methods execute or validate the SQL; they simply return the constructed query strings.
