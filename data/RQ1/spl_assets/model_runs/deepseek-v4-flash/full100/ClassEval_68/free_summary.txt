PageUtil is a pagination helper class. Its constructor takes a data list and a page_size, then calculates the total number of items and total pages. `get_page(page_number)` returns the slice of items for a valid 1-based page number, or an empty list if the page is out of range. `get_page_info(page_number)` returns a dictionary containing the current page, per-page size, total pages, total items, booleans indicating whether a previous or next page exists, and the page’s data; returns an empty dictionary for invalid page numbers. `search(keyword)` filters the data by checking if the keyword appears in the string representation of each item, then returns a dictionary with the keyword, total result count, total pages based on the configured page size, and the full filtered results list.
