The `ExcelProcessor` class provides basic Excel file handling using `openpyxl`. `read_excel(file_name)` loads the active sheet of an Excel workbook, reads all rows as tuples of cell values, returns them as a list of rows, or returns `None` if an error occurs. `write_excel(data, file_name)` creates a new workbook, writes each row in `data` to the active sheet, saves the file, and returns `1` on success or `0` on failure.

`process_excel_data(N, save_file_name)` reads an Excel file, then builds a new dataset by copying each row and appending an extra value to it: if the value in column index `N` of the row is not a digit, it appends the uppercase version of that value; otherwise, it appends the value unchanged. It writes the result to a new file named by inserting `_process` before the `.xlsx` extension, and returns a tuple containing the write success flag and the new file name. If reading fails or `N` is out of range relative to the first row’s column count, it returns `0`.
