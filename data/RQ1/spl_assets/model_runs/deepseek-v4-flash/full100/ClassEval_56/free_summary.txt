The `MetricsCalculator` class computes binary classification metrics by comparing predicted labels with true labels. It maintains cumulative counts of true positives, false positives, false negatives, and true negatives. The `update` method increments these counts for each pair of predicted and true labels. The `precision`, `recall`, and `accuracy` methods update these counts with the provided label lists and return the corresponding metric as a float, with zero returned when the denominator is zero. The `f1_score` method also updates the counters, then calls `precision` and `recall` to compute the F1 score. Because each metric method re-applies `update` on the same label lists, repeated or nested calls accumulate counts; in particular, `f1_score` counts the provided labels multiple times through its calls to `precision` and `recall`.
