Defines a `MinesweeperGame` class for a simple Minesweeper game. The constructor takes board size `n` and number of mines `k`, then creates two `n x n` grids: `minesweeper_map` randomly places `k` mines (marked `'X'`) and fills other cells with counts of adjacent mines, while `player_map` is initialized with `'-'` to hide the board. The `check_won` method returns `True` if all non-mine cells have been revealed. The `sweep` method takes coordinates `x`, `y`; if the selected cell contains a mine it returns `False` for a loss, otherwise it reveals the cell's count on `player_map`, increments `score`, and returns `True` if won or the updated `player_map` if not. Note that `sweep` treats `x` as the row index while the map generation treats `y` as the row, and duplicate mine placements are not prevented.
