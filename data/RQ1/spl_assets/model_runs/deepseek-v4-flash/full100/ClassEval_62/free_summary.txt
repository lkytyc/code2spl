The `NLPDataProcessor` class defines a simple text-processing routine. It has a method to create a fixed stop-word list containing `a`, `an`, and `the`. Its `remove_stop_words` method takes a list of strings and a stop-word list, splits each string into individual words, and removes words found in the stop-word list. The main `process` method ties this together: it builds the stop-word list, passes the input list of strings through stop-word removal, and returns a list where each original string is represented as a list of remaining words. Note that the removal is done while iterating over the split word list, so duplicate stop words are not guaranteed to all be removed.
