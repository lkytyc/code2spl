This class implements a simplified Blackjack game setup. When initialized, it creates a shuffled 52-card deck with cards represented as rank-plus-suit strings, and initializes empty hands for the player and dealer. `create_deck()` builds and shuffles that deck. `calculate_hand_value(hand)` computes the total value of a hand: number cards count as their face value, J/Q/K count as 10, and Aces count as 11 but are reduced to 1 when necessary to avoid busting. `check_winner(player_hand, dealer_hand)` compares both hands and returns either `'Player wins'` or `'Dealer wins'`. Its winner logic is unconventional: if both hands bust, the lower total wins (ties go to the player); if exactly one busts, the non-busted hand wins; and if neither busts, the higher total wins (ties go to the dealer). The class provides deck creation, hand scoring, and win determination, but does not implement the full gameplay loop.
