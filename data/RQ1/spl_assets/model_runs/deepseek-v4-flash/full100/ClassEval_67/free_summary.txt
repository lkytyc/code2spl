The `Order` class tracks a menu with available stock, a list of selected dishes, and a sales multiplier dictionary. `add_dish` checks whether the requested dish exists in `menu` and whether enough stock is available; if stock is insufficient, it returns `False`; otherwise it decreases the menu stock, appends the dish to `selected_dishes`, and returns `True`. Note that if the dish is not in the menu at all, it is still appended and `True` is returned. `calculate_total` computes the total by multiplying each selected dish’s price, count, and the corresponding sales multiplier from `sales`; this will fail with a `KeyError` if a selected dish has no sales entry. `checkout` returns `False` if no dishes are selected; otherwise it calculates the total, clears the selected dishes, and returns the total.
