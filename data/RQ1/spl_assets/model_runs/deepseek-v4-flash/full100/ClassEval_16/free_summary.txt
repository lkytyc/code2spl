The Calculator class evaluates arithmetic expressions given as strings. The `calculate` method takes an expression containing decimal numbers, parentheses, and the binary operators `+`, `-`, `*`, `/`, and `^` (exponentiation). It parses the expression left-to-right using an operand stack and an operator stack. Numbers are built from digit and decimal-point characters, then converted to floats. Operators are applied according to precedence levels defined in `precedence`: `^` has highest precedence, then `*` and `/`, then `+` and `-`. Parentheses are supported by pushing `(` onto the operator stack and, when `)` is reached, applying operators until the matching `(` is removed. The `apply_operator` method pops one operator and two operands, performs the operation using the `operators` dictionary, and pushes the result back onto the operand stack. After the entire expression is processed, any remaining operators are applied and the final value is returned. If the operand stack is empty, `calculate` returns `None`.
