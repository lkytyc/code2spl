This class implements a simplified version of the 24-point card game. It generates four random numbers from 1 to 9 as the player's cards. The `get_my_cards` method resets and returns a new set of four numbers. The `answer` method checks whether a submitted expression is valid for the current cards: it verifies that every digit in the expression was drawn and used exactly once. If the expression is the string `'pass'`, it returns new cards instead. For a valid expression, it evaluates the mathematical result and returns `True` if the value equals 24, otherwise `False`. Invalid expressions or evaluation errors also return `False`.
