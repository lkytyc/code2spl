The `VendingMachine` class manages a product inventory and a monetary balance. It stores items with their price and quantity, and tracks the user’s inserted coins. `add_item` creates a new item listing unless the item already exists, in which case it restocks the existing item’s quantity while ignoring any new price. `insert_coin` adds to the balance and returns the updated balance. `purchase_item` checks whether the item exists, is in stock, and the balance is sufficient; if so, it deducts the price, reduces the quantity, and returns the new balance, otherwise it returns `False`. `restock_item` increases the quantity of an existing item and returns `True`, or returns `False` if the item is not present. `display_items` returns a formatted list of all available items with price and quantity, or `False` if there are no items.
