The `Server` class manages a whitelist of addresses and stores the most recent sent and received message structures. `add_white_list` adds an address to the whitelist if not already present, returning the updated list or `False` for duplicates. `del_white_list` removes an address from the whitelist, returning the updated list or `False` if the address is not found. `recv` expects a dictionary with `"addr"` and `"content"` keys; it rejects invalid input with `-1`, rejects addresses not in the whitelist with `False`, otherwise stores the message in `receive_struct` and returns the content. `send` expects a similar dictionary, storing it in `send_struct` and returning `None`; invalid input returns an error string. `show` returns either the stored send or receive structure depending on the type argument, or `False` for an invalid type.
