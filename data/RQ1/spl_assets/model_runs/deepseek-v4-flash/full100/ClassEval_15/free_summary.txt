The `BoyerMooreSearch` class stores a `text` string and a `pattern` string. It provides helper methods to support pattern matching: `match_in_pattern` returns the rightmost position of a given character in the pattern, or -1 if the character is absent; `mismatch_in_text` checks the pattern against the text at a given alignment and returns the text index of the rightmost mismatching character, or -1 if the pattern matches at that position.

The main method `bad_character_heuristic` returns a list of starting indices in `text` where the complete pattern appears. It iterates over all possible alignment positions, checking for a match and appending the position when one is found. Although it uses a bad-character-style shift calculation, the shift is assigned to the loop variable inside a `for` loop, so it does not actually affect the loop iteration. As a result, the search behaves like a straightforward scan of every possible alignment rather than skipping positions.
