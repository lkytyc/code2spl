The `PushBoxGame` class implements a simple grid-based push-box puzzle. Its constructor stores the map and then scans the grid to locate the player (`O`), target cells (`G`), and boxes (`X`). The `move` method takes a direction string (`"w"`, `"s"`, `"a"`, or `"d"`) and attempts to move the player one cell in that direction. If the adjacent cell is not a wall (`#`), the player moves there. If that cell contains a box, the box is pushed one cell further in the same direction, provided the cell behind the box is also not a wall; otherwise neither the player nor the box moves. After each move, `check_win` is called, which sets `is_game_over` to `True` if every box is on a target cell, and the result of that check is returned as the move outcome.
