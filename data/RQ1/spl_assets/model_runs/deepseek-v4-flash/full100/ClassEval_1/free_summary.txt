The `AreaCalculator` class is initialized with a radius value and provides methods to compute geometric areas. Each method returns the area for a specific shape using the stored radius, with additional parameters where needed:

- `calculate_circle_area()` returns the area of a circle (πr²).
- `calculate_sphere_area()` returns the surface area of a sphere (4πr²).
- `calculate_cylinder_area(height)` returns the total surface area of a cylinder given its height (2πr(r + height)).
- `calculate_sector_area(angle)` returns the area of a circular sector given an angle in radians (r²·angle/2).
- `calculate_annulus_area(inner_radius, outer_radius)` returns the area of a ring/annulus between two radii (π(outer_radius² - inner_radius²)), ignoring the stored radius.

The class encapsulates radius as its core state and uses `math.pi` for calculations.
