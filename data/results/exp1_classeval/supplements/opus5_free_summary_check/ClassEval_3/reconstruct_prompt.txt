`ArrangementCalculator` is a utility class for counting and generating ordered arrangements (permutations) from a list of items.

**Construction:** You initialize it with a list (`datas`) that serves as the pool of items to arrange.

**Counting arrangements (static methods):**
- `count(n, m)` returns the number of ordered arrangements of `m` items chosen from `n` — equivalent to the permutation formula P(n, m) = n! / (n-m)!. If `m` is omitted or equals `n`, it returns `n!` (all full arrangements).
- `count_all(n)` sums P(n, 1) + P(n, 2) + ... + P(n, n), giving the total number of arrangements of any length from 1 up to `n`.
- `factorial(n)` is a plain iterative factorial, used internally by the counting methods.

**Generating arrangements (instance methods):**
- `select(m)` returns all ordered arrangements of exactly `m` items drawn from `self.datas`, each as a list. If `m` is omitted, it uses the full length of `datas`.
- `select_all()` returns every arrangement of every length from 1 up to the full length of `datas`, concatenated into one list.

The generation methods delegate to `itertools.permutations`, while the counting methods use direct factorial arithmetic. The two sides are independent — the static counting methods work on plain integers and don't interact with `self.datas` at all.
