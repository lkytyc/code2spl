Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

# Class: DataStatistics4

## correlation_coefficient(data1: list of numbers, data2: list of numbers) → number
Summary: Computes the Pearson correlation coefficient between two equal-length numeric datasets, returning 0 when the denominator is zero.
#   data1: list of numbers — First numeric dataset.
#   data2: list of numbers — Second numeric dataset with the same length as data1.
#   → correlation_coefficient: number — The Pearson correlation coefficient, or 0 when the denominator is zero.
1. Set n to the length of data1. → n
2. Compute mean1 as the sum of data1 divided by n. → mean1
3. Compute mean2 as the sum of data2 divided by n. → mean2
4. For i from 0 to n-1, accumulate the product of (data1[i] - mean1) and (data2[i] - mean2), and set numerator to the accumulated sum. → numerator
5. For i from 0 to n-1, accumulate the square of (data1[i] - mean1), then multiply its square root by the square root of the analogous sum of squares for data2; set denominator to that product. → denominator
6. If denominator is not equal to 0, return the result of numerator divided by denominator. → correlation_coefficient
   ? Return 0.

## kurtosis(data: iterable) → float
Summary: Computes the population excess kurtosis of a numeric dataset by subtracting 3 from the normalized fourth central moment, returning math.nan if the population standard deviation is zero.
#   data: iterable — Non-empty iterable of numeric values representing the dataset.
#   → kurtosis_value: float — Excess kurtosis of the input data, or math.nan when the population standard deviation is zero.
1. Set n to the number of elements in data. → n
2. Set mean to the sum of data divided by n. → mean
3. Set std_dev to the square root of the sum of the squared differences between each data element and mean, divided by n. → std_dev
4. Create centered_data as a list in which each element is the corresponding data element minus mean. → centered_data
5. Set fourth_moment to the sum of each centered_data element raised to the fourth power, divided by n. → fourth_moment
6. Set kurtosis_value to fourth_moment divided by std_dev raised to the fourth power, minus 3. → kurtosis_value
7. Return kurtosis_value. → kurtosis_value
   ? Return math.nan.

## pdf(data: iterable of numeric values, mu: numeric, sigma: numeric) → list of numeric values
Summary: Computes the probability density function of a normal distribution with mean mu and standard deviation sigma for each element in data.
#   data: iterable of numeric values — The input values at which to evaluate the normal PDF.
#   mu: numeric — The mean of the normal distribution.
#   sigma: numeric — The standard deviation of the normal distribution; must be nonzero.
#   → pdf_values: list of numeric values — The computed normal density values for each element in data.
1. In a list comprehension over data, for each x in data compute 1 / (sigma * math.sqrt(2 * math.pi)) * math.exp(-0.5 * ((x - mu) / sigma) ** 2) and collect each result in pdf_values. → pdf_values
2. Return pdf_values. → pdf_values

## skewness(data: list) → float
Summary: Computes the sample skewness of a numeric dataset, returning 0 when the standard deviation is zero.
#   data: list — Numeric data values used to compute skewness.
#   → skewness: float — The computed skewness value, or 0 if the standard deviation is zero.
1. Compute n as the number of elements in data. → n
2. Compute mean as the sum of data divided by n. → mean
3. Compute variance as the sum over each x in data of (x - mean) squared, divided by n. → variance
4. Compute std_deviation as the square root of variance using math.sqrt. → std_deviation
5. Compute skewness as follows: if std_deviation is not equal to 0, evaluate sum((x - mean) ** 3 for x in data) * n / ((n - 1) * (n - 2) * std_deviation ** 3); otherwise assign skewness to 0. → skewness
6. Return skewness. → skewness
