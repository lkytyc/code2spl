Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

# Class: ShoppingCart
# Fields: items

## __init__()
Summary: Initializes a new instance by setting its items attribute to an empty dictionary.
1. Initialize self.items as a new empty dictionary. → self.items

## add_item(item: object, price: object, quantity: int)
Summary: Unconditionally stores the given price and quantity under item in self.items, overwriting any existing entry.
#   item: object — The dictionary key under which the item data is stored.
#   price: object — The price value to store in the item entry.
#   quantity: int — The quantity to store in the item entry; defaults to 1.
1. Check whether item is present as a key in self.items. → _item_present
2. Set self.items[item] to the dictionary {'price': price, 'quantity': quantity}. → self.items

## remove_item(item: object, quantity: int)
Summary: Decrements the stored quantity for an item in self.items by the given quantity if the item exists, and does nothing otherwise.
#   item: object — Key to look up in self.items; it must be a hashable dictionary key.
#   quantity: int — Amount to subtract from the item's quantity; defaults to 1.
1. Check whether item exists as a key in self.items. → item_exists
2. If item_exists is true, subtract quantity from the value at self.items[item]['quantity'] and assign the result back to self.items[item]['quantity']. → self.items
   ? Do nothing and continue.

## total_price() → float
Summary: Computes the total price by multiplying each item's quantity by its price and summing the resulting subtotals.
#   → result: float — The total price computed as the sum of quantity times price for all items in self.items.
1. Access the items collection from self.items and obtain its values view. → item_values
2. For each item in item_values, read item['quantity'] and item['price'], multiply them to compute the item subtotal, and collect all subtotals into a list. → subtotals
3. Sum the subtotals; if the list is empty, treat the sum as 0. → total
4. Return total as the method result. → return_value

## view_items() → dict
Summary: Returns the current items dictionary stored on the view.
#   → items: dict — The stored items dictionary.
1. Return the stored items dictionary to the caller. → self.items
