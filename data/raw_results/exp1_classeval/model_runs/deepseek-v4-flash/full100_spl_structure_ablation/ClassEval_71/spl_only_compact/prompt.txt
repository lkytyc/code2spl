Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

# Class: PushBoxGame
# Fields: boxes, map, target_count, targets, player_col, is_game_over, player_row
# Calls: __init__→init_game, move→check_win

## __init__(map: object)
Summary: Initializes the game state by storing the given map, resetting the player position, targets, boxes, target count, and game-over flag, and then invoking init_game() to perform any remaining setup.
#   map: object — The game map object to be stored as self.map.
1. Store the incoming map reference in self.map. → self.map
2. Set self.player_row to 0. → self.player_row
3. Set self.player_col to 0. → self.player_col
4. Initialize self.targets as an empty list. → self.targets
5. Initialize self.boxes as an empty list. → self.boxes
6. Set self.target_count to 0. → self.target_count
7. Set self.is_game_over to False. → self.is_game_over
8. Call self.init_game() to perform additional game initialization. → self

## check_win(self: object)
Summary: Counts how many boxes are on target cells and, if the count equals the total target count, sets the game-over flag; returns the game-over flag.
#   self: object — Game state containing self.boxes, self.targets, self.target_count, and self.is_game_over.
1. Initialize box_on_target_count to 0. → box_on_target_count
2. For each occurrence of box in self.boxes, if box is contained in self.targets, increment box_on_target_count by 1. → box_on_target_count
3. If box_on_target_count equals self.target_count, set self.is_game_over to True. → self.is_game_over
4. Return the current value of self.is_game_over. → self.is_game_over

## init_game(self: object)
Summary: Scans the 2D game map in row-major order and initializes the player position, target list and target count, and box list from cells marked O, G, and X respectively.
#   self: object — Game instance containing self.map as a list of strings or lists; the attributes self.targets, self.target_count, and self.boxes must already exist before this method is called.
1. Iterate over each row index row from 0 through len(self.map)-1. → row_index
2. Within the outer row loop, iterate over each column index col from 0 through len(self.map[row])-1. → col_index
3. Within the nested row and column loops, inspect the current cell self.map[row][col] and branch on its character value. → current_cell
4. Within the nested row and column loops, if self.map[row][col] == "O", set self.player_row = row and self.player_col = col, overwriting any previously stored player position. → player_position
5. Within the nested row and column loops, else if self.map[row][col] == "G", append the tuple (row, col) to self.targets and increment self.target_count by 1. → target_recorded
6. Within the nested row and column loops, else if self.map[row][col] == "X", append the tuple (row, col) to self.boxes. → box_recorded
7. Within the nested row and column loops, if none of the previous conditions matched, ignore the current cell. → ignored_cell

## move(direction: string) → bool
Summary: Attempts to move the player one step in the requested direction, pushes a box when possible, and returns the win-check result.
#   direction: string — Movement direction: 'w' (up), 's' (down), 'a' (left), or 'd' (right).
#   → check_win_result: bool — Result returned by self.check_win() after the movement attempt.
1. Set new_player_row to self.player_row. → new_player_row
2. Set new_player_col to self.player_col. → new_player_col
3. If direction equals 'w', decrement new_player_row by 1. → new_player_row
4. Else if direction equals 's', increment new_player_row by 1. → new_player_row
5. Else if direction equals 'a', decrement new_player_col by 1. → new_player_col
6. Else if direction equals 'd', increment new_player_col by 1. → new_player_col
7. If self.map[new_player_row][new_player_col] equals '#', make no state changes and skip to the final return. → state_unchanged
8. If self.map[new_player_row][new_player_col] is not '#', continue to the movement and box-push logic. → target_not_wall
9. If (new_player_row, new_player_col) is in self.boxes, set new_box_row to new_player_row plus (new_player_row minus self.player_row). → new_box_row
10. Within the same box-present branch, set new_box_col to new_player_col plus (new_player_col minus self.player_col). → new_box_col
11. Within the box-present branch, if self.map[new_box_row][new_box_col] equals '#', make no box or player position changes. → state_unchanged
12. Within the box-present branch, if self.map[new_box_row][new_box_col] is not '#', remove (new_player_row, new_player_col) from self.boxes, append (new_box_row, new_box_col) to self.boxes, set self.player_row to new_player_row, and set self.player_col to new_player_col. → box_and_player_updated
13. If (new_player_row, new_player_col) is not in self.boxes, set self.player_row to new_player_row and self.player_col to new_player_col. → player_position_updated
14. Return self.check_win(). → check_win_result
