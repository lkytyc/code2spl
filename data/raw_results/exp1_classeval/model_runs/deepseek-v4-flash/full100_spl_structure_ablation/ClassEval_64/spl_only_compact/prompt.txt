Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

## decimal_to_binary(decimal_num: int) → str
Summary: Converts an integer to a binary string by removing the '0b' prefix from Python's bin() output, without special handling for negative numbers.
#   decimal_num: int — Integer value to convert to a binary string.
#   → binary_num: str — Binary representation of decimal_num without the '0b' prefix for non-negative inputs; negative inputs produce an invalid representation beginning with 'b'.
1. Convert decimal_num by calling bin(decimal_num), remove the first two characters '0b' using slice [2:], and assign the resulting string to binary_num. → binary_num
2. Return binary_num as the method's output. → binary_num

## decimal_to_hex(decimal_num: integer) → string
Summary: Converts an integer decimal_num to a lowercase hexadecimal string without the leading '0x' prefix by calling hex() and removing the first two characters.
#   decimal_num: integer — Integer-compatible value to be converted to hexadecimal.

1. Convert decimal_num with the built-in hex() function, remove the first two characters using [2:], and assign the resulting string to hex_num (for negative decimal_num this leaves a leading 'x' because the '-' occupies the first character and is sliced off). → hex_num

## decimal_to_octal(decimal_num: int or object implementing __index__) → str
Summary: Converts a decimal integer to an octal string by using Python's oct() function and removing the leading '0o' prefix; negative inputs produce a string with a leading 'o' because slicing also removes the minus sign.
#   decimal_num: int or object implementing __index__ — The decimal integer value to convert. A float or an object without __index__ causes TypeError.
#   → octal_num: str — The resulting octal string. For non-negative values it is the expected octal digit string; for negative values it is 'o' followed by the digit characters (e.g., decimal -10 -> 'o12').

Compute the octal string representation of decimal_num by calling oct(decimal_num), then slice the result with [2:] to remove the first two characters, and assign the resulting string to octal_num. For non-negative inputs this yields the standard octal digits; for negative inputs, oct(-10) returns '-0o12' and the slice leaves 'o12'. → octal_num
2. Return octal_num. → return_value
   ! log: "oct() conversion failed because decimal_num is not an integer or an object implementing __index__."
   ! raise: TypeError "Raised by oct(decimal_num) when decimal_num is not a valid integer type."
