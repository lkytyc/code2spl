Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

Class specification:

# Class: Calculator
# Fields: operators
# Calls: calculate→precedence, calculate→apply_operator

## __init__()
Summary: Initializes an object's arithmetic operator mapping by storing a dictionary that associates '+', '-', '*', '/', and '^' with lambda functions for addition, subtraction, multiplication, division, and exponentiation.
1. Assign to self.operators a literal dictionary with the keys '+', '-', '*', '/', and '^'; map each key to a lambda function taking x and y: addition returns x + y, subtraction returns x - y, multiplication returns x * y, division returns x / y, and exponentiation returns x ** y. → self.operators

## apply_operator(self: object, operand_stack: list, operator_stack: list) → tuple
Summary: Pops the top operator from operator_stack and two operands from operand_stack, applies the operator implementation from self.operators to the operands, pushes the result back onto operand_stack, and returns the updated stacks.
#   self: object — Instance providing the operators mapping used to resolve operator tokens to callable implementations.
#   operand_stack: list — Stores the operands used in the operation; mutated by popping two operands and appending the result.
#   operator_stack: list — Stores the operator tokens; mutated by popping the current operator from the top.
#   → return_value: tuple — A tuple containing the mutated operand_stack and operator_stack after the operator has been applied.
1. Pop the top item from operator_stack and bind it to operator; operator_stack is mutated by removing that item. This step requires operator_stack to be non-empty. → operator
2. Within the if/else construct on operator == '^', whose branches are identical, pop the top item from operand_stack and bind it to operand2. This step requires operand_stack to be non-empty. → operand2
3. Within the same if/else construct and shared branch body, pop the next top item from operand_stack and bind it to operand1. This step requires operand_stack to have at least two items at this point. → operand1
4. Within the same shared branch body, look up the callable associated with operator in self.operators, call it with (operand1, operand2), and bind the returned value to result. → result
5. Within the same shared branch body, push result onto operand_stack. → operand_stack
6. Return the tuple (operand_stack, operator_stack) after the branch body completes. → return_value

## calculate(expression: string) → float or None
Summary: Evaluates an infix arithmetic expression using the shunting-yard algorithm with explicit operator-precedence handling and returns the numeric result, or None if no operands are present.
#   expression: string — Infix arithmetic expression to evaluate; digits and '.' build numbers, supported operators are +, -, *, /, ^, and parentheses are handled as grouping symbols.
#   → result: float or None — The evaluated numeric result, or None when the expression contains no complete operand.
1. Initialize operand_stack as an empty list, operator_stack as an empty list, and num_buffer as an empty string. → _init_state
2. Start iterating over each character char in expression with the outer for loop. → _loop_start
3. Within the outer for loop, if char is a digit or '.', append char to num_buffer. → _num_buffer
4. Within the outer for loop, when char is not a digit or '.', first check if num_buffer is truthy; if so, convert float(num_buffer), append it to operand_stack, and reset num_buffer to an empty string. → _flushed_number
5. Within the outer for loop, after flushing any pending number, if char is one of '+', '-', '*', '/', '^', then while operator_stack is non-empty and its top element is not '(' and self.precedence(operator_stack[-1]) >= self.precedence(char), assign operand_stack and operator_stack from the result of self.apply_operator(operand_stack, operator_stack). → _reduced_operators
6. Within the outer for loop, after the precedence-reducing while loop for an operator char, append char to operator_stack. → _pushed_operator
7. Within the outer for loop, if char is '(', append '(' to operator_stack. → _pushed_left_paren
8. Within the outer for loop, if char is ')', while operator_stack is non-empty and its top element is not '(', assign operand_stack and operator_stack from the result of self.apply_operator(operand_stack, operator_stack); then pop the '(' from operator_stack. → _resolved_right_paren
9. Within the outer for loop, if char is not a digit, '.', operator, '(' or ')', ignore it after the pending-number flush has been performed. → _ignored_char
10. After the outer for loop completes, if num_buffer is truthy, convert float(num_buffer), append it to operand_stack, and reset num_buffer to an empty string. → _final_number_flush
11. After the final number flush, while operator_stack is non-empty, assign operand_stack and operator_stack from the result of self.apply_operator(operand_stack, operator_stack). → _drained_operators
12. If operand_stack is non-empty, return operand_stack[-1]; otherwise return None. → _return_value

## precedence(operator: string) → integer
Summary: Returns the precedence level for a given arithmetic operator, defaulting to 0 when the operator is not recognized.
#   operator: string — The operator symbol whose precedence level is requested.
#   → result: integer — The precedence level: 1 for '+' or '-', 2 for '*' or '/', 3 for '^', or 0 for an unknown operator.
1. Create a precedences dictionary mapping '+' and '-' to 1, '*' and '/' to 2, and '^' to 3. → precedences
2. Look up operator in the precedences dictionary and return the mapped precedence. → precedence_value
   ? Return the default precedence value 0.
