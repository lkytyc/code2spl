Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

## get_pos_tag(self: object, sentence: string) → list of strings
Summary: Removes punctuation from a sentence, tokenizes it, performs part-of-speech tagging, and returns a list of POS tags for the tokens.
#   self: object — Instance of the class providing the remove_punctuation method.
#   sentence: string — Input sentence to be processed.
#   → pos_tags: list of strings — List of POS tags corresponding to each token in the cleaned sentence.
1. Initialize pos_tags as an empty list. → pos_tags
2. Remove punctuation from sentence by calling self.remove_punctuation(sentence) and assign the result back to sentence. → sentence
3. Tokenize the cleaned sentence using word_tokenize(sentence) and assign the result to words. → words
4. Tag the tokenized words with part-of-speech tags by calling pos_tag(words) and assign the result to tagged_words. → tagged_words
5. For each tagged_word in tagged_words, append tagged_word[1] (the POS tag) to pos_tags. → pos_tags
6. Return pos_tags. → pos_tags

## lemmatize_sentence(sentence: string) → list of strings
Summary: Removes punctuation from a sentence, tokenizes it, part-of-speech tags each token, and lemmatizes each word using verb, adjective, adverb, or default lemmatization based on the tag prefix.
#   sentence: string — The input sentence to be cleaned, tokenized, and lemmatized.
#   → lemmatized_words: list of strings — The lemmatized forms of the input words, in the same order as the tokenized sentence.
1. Initialize lemmatized_words as an empty list to hold the lemmatized token results. → lemmatized_words
2. Call self.remove_punctuation(sentence) and overwrite sentence with the punctuation-free returned string. → sentence
3. Tokenize the cleaned sentence by calling word_tokenize(sentence) and store the resulting list as words. → words
4. Part-of-speech tag words by calling pos_tag(words) and store the list of (word, tag) pairs as tagged_words. → tagged_words
5. For each (word, tag) pair in tagged_words, choose the lemmatization mode by checking the tag prefix: if tag starts with 'V' use the verb POS flag 'v'; else if tag starts with 'J' use the adjective POS flag 'a'; else if tag starts with 'R' use the adverb POS flag 'r'; otherwise use the default lemmatization by calling self.lemmatizer.lemmatize(word) without a POS flag. Assign the lemmatized result to lemmatized_word. → lemmatized_word
6. Within the same loop over tagged_words, after lemmatized_word has been computed for the current (word, tag), append lemmatized_word to lemmatized_words. → lemmatized_words
7. Return lemmatized_words as the final method result. → lemmatized_words

## remove_punctuation(sentence: str) → str
Summary: Removes all ASCII punctuation characters from the input sentence by applying a translation table and returns the cleaned string.
#   sentence: str — The input string from which punctuation characters will be removed.
#   → result: str — A new string with all ASCII punctuation characters removed.
1. Create a translation table using str.maketrans('', '', string.punctuation) so that every punctuation character maps to None for deletion. → translation_table
2. Apply the translation table to sentence using sentence.translate(translation_table) to remove punctuation characters and store the resulting new string. → result
3. Return the resulting punctuation-free string. → return_value
