Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

# Class: XMLProcessor
# Fields: root, file_name
# Calls: process_xml_data→write_xml

## __init__(file_name: string)
Summary: Initializes a new instance by storing the provided file name and setting the root attribute to None.
#   file_name: string — The file name to be stored in the instance attribute self.file_name.
1. Assign the value of the input file_name to the instance attribute self.file_name. → self.file_name
2. Set the instance attribute self.root to None. → self.root

## find_element(element_name: string) → list
Summary: Finds all child elements under self.root matching the given element_name and returns them as a list.
#   element_name: string — The tag name or XPath-like pattern used to select matching child elements.
#   → elements: list — List of matching child elements; empty if no matches were found.
1. Call findall on self.root with element_name to retrieve all matching child elements, and assign the resulting list to elements. → elements
2. Return the elements list. → elements

## process_xml_data(file_name: str) → object
Summary: Uppercases the text content of every descendant <item> element in the XML tree, then returns the result of writing the modified XML to the specified file.
#   file_name: str — Name or path of the XML file to write after the transformation.
#   → return_value: object — Result returned by self.write_xml(file_name).
1. Iterate through every descendant element named 'item' produced by self.root.iter('item') in document order. → element
2. Within the loop over item elements, store the current text content of element as text. → text
3. Within the loop over item elements, set element.text to the uppercase version of text by calling text.upper(). → element.text
4. After the loop completes, call self.write_xml(file_name) with the modified XML tree and return its result. → return_value

## read_xml(self: object) → Element or None
Summary: Parses the XML file specified by self.file_name, stores the root element in self.root, and returns it, or returns None if parsing fails.
#   self: object — The object instance whose file_name attribute contains the path to the XML file.
#   → result: Element or None — The parsed XML root element, or None if an exception occurs.
1. Parse the XML file located at self.file_name using ET.parse. → tree
2. Retrieve the root element from the parsed tree using tree.getroot(). → root
3. Set self.root to the retrieved root element. → self.root
4. Return self.root. → return_value
   ? Return None to indicate that the XML could not be parsed or read.

## write_xml(file_name: str) → bool
Summary: Writes the XML tree rooted at self.root to the specified file and returns True on success, or False if an exception occurs.
#   file_name: str — The path of the file to which the XML tree should be written.
#   → result: bool — True if the XML file was written successfully; False if an exception occurred.
1. Build an ElementTree object from self.root and assign it to tree. → tree
2. Write the XML tree to the file specified by file_name. → None
3. Return True after a successful write. → True
   ? Catch the exception and return False.
