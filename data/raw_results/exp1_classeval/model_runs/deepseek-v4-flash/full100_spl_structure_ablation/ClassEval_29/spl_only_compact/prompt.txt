Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

# Class: DataStatistics

## mean(data: iterable of numeric values) → float
Summary: Computes the arithmetic mean of the numeric values in data and rounds the result to two decimal places.
#   data: iterable of numeric values — External input iterable of numeric values; must be non-empty or a ZeroDivisionError occurs.
#   → result: float — The mean of data rounded to 2 decimal places.
1. Compute the sum of all elements in data using sum(data). → total
2. Compute the number of elements in data using len(data). → count
3. Compute the arithmetic mean by dividing total by count. → average
4. Round the average to 2 decimal places using Python's round(average, 2). → rounded_average
5. Return rounded_average as the result of the method. → mean_result

## median(self: object, data: iterable) → float or input element type
Summary: Computes the median of an iterable of values by sorting them and returning the middle element for odd length or the rounded average of the two middle elements for even length.
#   self: object — The object instance on which the median method is invoked.
#   data: iterable — The iterable of values whose median is to be computed.
#   → result: float or input element type — The median value. For even-length data, the average of the two middle sorted values rounded to 2 decimal places. For odd-length data, the middle sorted value.
1. Create a new list sorted_data by sorting the input data. → sorted_data
2. Set n to the length of sorted_data. → n
3. Evaluate whether n is even using n % 2 == 0 and select the corresponding median branch. → parity_check
   ? Within the even-length branch, compute middle as n // 2.
   ? Within the even-length branch, return round((sorted_data[middle - 1] + sorted_data[middle]) / 2, 2).
   ? Within the odd-length branch, compute middle as n // 2.
   ? Within the odd-length branch, return sorted_data[middle].

## mode(data: iterable) → list
Summary: Counts occurrences of each element in the input iterable and returns all elements with the maximum frequency.
#   data: iterable — Input iterable whose mode values are to be computed.
#   → mode: list — List of all distinct elements that occur with the maximum frequency.
1. Count the frequency of every element in data using collections.Counter. → counter
2. Compute the maximum frequency by taking the maximum of counter.values(). → mode_count
3. Build the list of elements x for each (x, count) in counter.items() where count equals mode_count. → mode
4. Return mode as the result of the method. → mode
   ! log: "max() is called on an empty counter.values(), which raises ValueError"
   ! raise: ValueError "Cannot compute the mode of an empty iterable because there is no maximum frequency."
