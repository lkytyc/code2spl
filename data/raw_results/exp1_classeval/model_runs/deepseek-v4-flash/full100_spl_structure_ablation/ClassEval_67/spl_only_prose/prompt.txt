Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

## add_dish(self: object, dish: dict) → bool
Summary: Adds a dish to selected_dishes after decrementing the matching menu item's count when sufficient stock exists, or returns False immediately if a matching menu item has insufficient count.
#   self: object — The object whose menu list and selected_dishes list are accessed.
#   dish: dict — Dictionary containing the dish name under the key 'dish' and the requested count under the key 'count'.
#   → result: bool — True if the dish was appended to selected_dishes; False if a matching menu_dish had insufficient count and caused an early return.
1. Start a for loop over each menu_dish in self.menu. → menu_dish
2. Within the for loop, compare dish['dish'] with menu_dish['dish'] to determine whether the dish names match. → dish_name_matches
3. If dish_name_matches is false, continue to the next iteration of the for loop. → next_menu_dish
4. Inside the matching-name branch, if menu_dish['count'] is greater than or equal to dish['count'], subtract dish['count'] from menu_dish['count'] and break out of the for loop. → updated_menu_dish
5. After the for loop ends, append dish to self.selected_dishes. → selected_dishes
6. Return True from add_dish. → true_result
   ? Return False from add_dish immediately without modifying selected_dishes or continuing the loop.

## calculate_total(self: object) → numeric
Summary: Calculates the total cost of selected dishes by summing each dish's price times its count times the corresponding sales multiplier.
#   self: object — Object exposing selected_dishes, an iterable of dish dictionaries, and sales, a mapping from dish name to a numeric multiplier.
#   → result: numeric — The accumulated total computed as the sum over each dish in self.selected_dishes of dish['price'] * dish['count'] * self.sales[dish['dish']].
1. Initialize total to the constant integer 0. → total
2. For each dish in self.selected_dishes, in iteration order, run the accumulation block. → dish
3. Within the loop over dish, use dish['dish'] as the key to look up the sales multiplier in self.sales. → sales_multiplier
4. Within the loop over dish, compute dish['price'] * dish['count'] * sales_multiplier and add the product to total. → total
5. Return total as the final result. → total

## checkout() → numeric or boolean

#   → result: numeric or boolean — Returns the calculated total after clearing selected_dishes, or False if selected_dishes was empty.
