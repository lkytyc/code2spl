Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

## format_string(x: string) → string
Summary: Formats a dot-separated decimal string into an English check-amount phrase by converting the integer part with trans_three/parse_more and cents with trans_two, returning 'ZERO ONLY' when the integer part is blank.
#   x: string — Input decimal amount string; only the first two dot-separated components are used.
#   → result: string — English amount phrase ending in 'ONLY', or 'ZERO ONLY' if the integer part is blank.
1. Split x on '.' and pad the resulting list with '' so it has at least two elements; take the first two elements as lstr and rstr. → lstr,
2. Reverse lstr and store the result as lstrrev. → lstrrev
3. Initialize a as a list of 5 empty strings. → a
4. If len(lstrrev) % 3 == 1, append '00' to lstrrev; else if len(lstrrev) % 3 == 2, append '0' to lstrrev; otherwise leave lstrrev unchanged. → lstrrev
5. Initialize lm as an empty string. → lm
6. For each i from 0 to len(lstrrev) // 3 - 1, set a[i] to the reverse of lstrrev[3*i:3*i+3]; if a[i] != '000', prepend self.trans_three(a[i]) + ' ' + self.parse_more(i) + ' ' to lm; otherwise append self.trans_three(a[i]) to lm. → lm
7. If rstr is truthy, set xs to 'AND CENTS ' concatenated with self.trans_two(rstr) and a trailing space; otherwise set xs to an empty string. → xs
8. If lm.strip() is empty, return 'ZERO ONLY'; otherwise return the string formed by concatenating lm.strip(), a space, xs, and the suffix 'ONLY'. → return_value

## trans_three(s: string) → string
Summary: Converts a three-digit numeric string into its English word equivalent, delegating leading-zero cases to trans_two and using 'HUNDRED' with 'AND' only when a nonzero hundred part is followed by a nonzero two-digit part.
#   s: string — A three-character numeric string representing a number from 000 to 999.
#   → result: string — The English phrase for the number; leading-zero numbers use the two-digit conversion, exact hundreds include only the hundred word, and general three-digit numbers include 'AND' before the two-digit portion.
1. Check whether the first character of s is '0'. → has_leading_zero
2. If has_leading_zero is true, return the result of calling trans_two with the substring s[1:]. → leading_zero_result
3. If has_leading_zero is false, check whether the substring s[1:] equals '00'. → is_exact_hundred
4. If has_leading_zero is false and is_exact_hundred is true, return the value from the NUMBER dictionary for int(s[0]) followed by ' HUNDRED'. → exact_hundred_result
5. If has_leading_zero is false and is_exact_hundred is false, return the value from the NUMBER dictionary for int(s[0]) followed by ' HUNDRED AND ' and the result of calling trans_two with s[1:]. → general_three_digit_result

## trans_two(s: str) → str
Summary: Converts a numeric string from 0 to 99 into its English word representation by zero-padding it to two digits and branching on the tens and ones digits.
#   s: str — Numeric string representing an integer from 0 to 99.
#   → return_value: str — English word representation of the numeric value described by s.
1. Zero-pad the input numeric string s to at least two characters with leading zeros by executing s = s.zfill(2); use this zero-padded value for all later checks. → s
2. Evaluate the if/elif/else chain on the zero-padded string s in order and execute the first matching branch; each branch returns immediately, so later branches are skipped. → return_value
   ? Return self.NUMBER[int(s[-1])], using the last character of s as the index into the NUMBER word list.
   ? Return self.NUMBER_TEEN[int(s) - 10], converting the entire zero-padded string to an integer and subtracting 10.
   ? Return self.NUMBER_TEN[int(s[0]) - 1], using the tens digit minus 1 as the index into the NUMBER_TEN word list.
   ? Return self.NUMBER_TEN[int(s[0]) - 1] + " " + self.NUMBER[int(s[-1])], constructing the tens word and the ones word separated by a space.
