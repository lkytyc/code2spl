Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

# Class: PageUtil
# Fields: page_size, data, total_items, total_pages

## __init__(data: collection, page_size: int)
Summary: Initializes pagination state by storing the data collection and page size, then deriving total_items and total_pages using ceiling division.
#   data: collection — Input collection whose length can be obtained with len().
#   page_size: int — Number of items per page; must be a positive integer for a valid page count.
1. Assign the data parameter directly to self.data. → self.data
2. Assign the page_size parameter directly to self.page_size. → self.page_size
3. Compute the total number of items as len(data) and assign it to self.total_items. → self.total_items
4. Compute total_pages as (self.total_items + self.page_size - 1) // self.page_size and assign it to self.total_pages. → self.total_pages

## get_page(page_number: int) → list
Summary: Returns the slice of data for a one-based page number, or an empty list when the requested page is outside the valid range.
#   page_number: int — The one-based page number to retrieve.
#   → page_data: list — The slice of self.data for the requested page, or an empty list when the page number is invalid or out of range.
1. After confirming that page_number is at least 1 and at most self.total_pages, compute start_index as (page_number - 1) * self.page_size. → start_index
2. Compute end_index as start_index + self.page_size. → end_index
3. Return the slice self.data[start_index:end_index]. → page_data
   ? Return an empty list.

## get_page_info(page_number: int, page_size: int, total_pages: int, total_items: int, data: list or sliceable sequence) → dict
Summary: Returns a dictionary containing the requested page's items and pagination metadata, or an empty dictionary when the requested page number is out of range.
#   page_number: int — The one-based page number to retrieve; valid values are from 1 through self.total_pages inclusive.
#   page_size: int — Instance attribute self.page_size; the number of items per page.
#   total_pages: int — Instance attribute self.total_pages; the total number of pages.
#   total_items: int — Instance attribute self.total_items; the total number of items in self.data.
#   data: list or sliceable sequence — Instance attribute self.data; the collection from which the page slice is extracted.
#   → return_value: dict — The page_info dictionary with keys current_page, per_page, total_pages, total_items, has_previous, has_next, and data, or an empty dictionary for an invalid page_number.
1. Compute the zero-based start_index for the requested page as (page_number - 1) * self.page_size. → start_index
2. Compute end_index as the minimum of start_index + self.page_size and self.total_items; this is the exclusive upper bound for the page slice. → end_index
3. Extract page_data by slicing self.data from start_index (inclusive) to end_index (exclusive). → page_data
4. Assemble page_info with current_page = page_number, per_page = self.page_size, total_pages = self.total_pages, total_items = self.total_items, has_previous = (page_number > 1), has_next = (page_number < self.total_pages), and data = page_data. → page_info
5. Return page_info. → return_value
   ? Return an empty dictionary {} immediately.

## search(keyword: str) → dict
Summary: Filters the object's data items by substring presence of the keyword in their string representation, counts the matching items, computes the total number of pages using ceiling division over the page size, and returns a dictionary containing the keyword, totals, and filtered results.
#   keyword: str — The substring to search for within the string representation of each item in self.data.
#   → search_info: dict — A dictionary containing the keyword, total_results, total_pages, and the filtered results list.
1. Filter self.data into a list of items where keyword is a substring of str(item), preserving the original item order. → results
2. Set num_results to the length of the results list. → num_results
3. Compute num_pages as integer ceiling division of num_results by self.page_size using (num_results + self.page_size - 1) // self.page_size. → num_pages
4. Create search_info dictionary with keys keyword, total_results, total_pages, and results, assigned from keyword, num_results, num_pages, and results respectively. → search_info
5. Return search_info. → search_info
