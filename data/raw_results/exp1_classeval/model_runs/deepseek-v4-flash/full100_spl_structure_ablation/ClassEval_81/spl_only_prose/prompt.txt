Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

## correlation(x: list of numbers, y: list of numbers) → float or None
Summary: Computes Pearson's correlation coefficient between two numeric sequences x and y, returning None when the denominator is zero.
#   x: list of numbers — First numeric sequence; its length determines n.
#   y: list of numbers — Second numeric sequence to correlate with x.
#   → result: float or None — Pearson correlation coefficient, or None if the denominator is zero.
1. Set n to the length of x. → n
2. Compute mean_x as the sum of x divided by n. → mean_x
3. Compute mean_y as the sum of y divided by n. → mean_y
4. Compute numerator as the sum of (xi - mean_x) * (yi - mean_y) for each pair (xi, yi) yielded by zip(x, y), noting that zip stops at the shorter input sequence. → numerator
5. Compute denominator as math.sqrt(sum((xi - mean_x) ** 2 for xi in x) * sum((yi - mean_y) ** 2 for yi in y)). → denominator
6. Return numerator divided by denominator. → result
   ? Return None as the correlation result.
   ! log: "Cannot compute correlation for empty input: division by zero while calculating the mean."
   ! raise: ZeroDivisionError "Mean_x or mean_y divides by zero because n is zero."

## correlation_matrix(data: list of lists of numbers) → list of lists of floats
Summary: Builds a square correlation matrix by computing the correlation between each pair of columns in the input 2D data using Statistics3.correlation.
#   data: list of lists of numbers — Non-empty rectangular input data where each inner list is a row and each column position represents a variable or series.
#   → matrix: list of lists of floats — Correlation matrix of size len(data[0]) x len(data[0]); matrix[i][j] is the correlation between column i and column j of data.
1. Initialize matrix as an empty list. → matrix
2. For each i from 0 to len(data[0]) - 1, run the outer loop over column indices i. → i
3. Within the outer loop over i, initialize row as an empty list. → row
4. Within the outer loop over i, for each j from 0 to len(data[0]) - 1, run the inner loop over column indices j. → j
5. Within the outer loop over i and inner loop over j, collect the value at index i from every row of data to form column1. → column1
6. Within the outer loop over i and inner loop over j, collect the value at index j from every row of data to form column2. → column2
7. Within the outer loop over i and inner loop over j, compute correlation using Statistics3.correlation with column1 and column2. → correlation
8. Within the outer loop over i and inner loop over j, append correlation to row. → row
9. Within the outer loop over i, after the inner loop finishes, append row to matrix. → matrix
10. Return matrix as the final result. → matrix

## mode(data: iterable) → list
Summary: Computes the mode(s) of a collection by counting occurrences and returning every value that appears with the maximum frequency.
#   data: iterable — Collection of values to analyze for the mode.

4. Build mode_values as a list containing every value from counts whose count is equal to max_count. → mode_values
5. Return mode_values as the result of the function. → return_value

   ! raise: ValueError "Raised by max() when counts is empty because data contained no elements."

## standard_deviation(data: iterable of numeric values) → float or None
Summary: Computes the sample standard deviation of a numeric data collection, returning None when there are fewer than two data points.
#   data: iterable of numeric values — The collection of numeric values for which to calculate the sample standard deviation.
#   → result: float or None — The sample standard deviation as a float, or None if data contains fewer than two elements.
1. Set n to the number of elements in data using len(data). → n
2. Check if n is less than 2; if true, use the alternative flow to return None immediately; otherwise continue. → is_n_less_than_2
3. Compute mean_value by calling Statistics3.mean(data). → mean_value
4. Compute variance by summing (x - mean_value) ** 2 for each x in data and dividing by (n - 1). → variance
5. Return math.sqrt(variance) as the final sample standard deviation. → result
   ? Return None because sample standard deviation is undefined with fewer than two data points.
