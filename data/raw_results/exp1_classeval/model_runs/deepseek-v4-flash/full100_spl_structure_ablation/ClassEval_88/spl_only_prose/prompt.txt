Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

# Class: TriCalculator
# Calls: cos→taylor, tan→cos, tan→sin, taylor→factorial

## cos(self: object, x: numeric) → float
Summary: Computes the cosine of x by calling taylor(x, 50) and rounding the resulting value to 10 decimal places.
#   self: object — The current object providing the taylor method and any internal state used by the Taylor approximation.
#   x: numeric — The input value for which the cosine is approximated.
#   → result: float — The Taylor-series cosine approximation rounded to 10 decimal places.
1. Call self.taylor(x, 50) to compute the Taylor-series approximation of cosine at x using 50 terms. → taylor_result
2. Round taylor_result to 10 decimal places with round(). → rounded_result
3. Return rounded_result as the result of the cos method. → result

## factorial(a: number) → number
Summary: Computes the factorial of a positive integer a by accumulating the product in b while decrementing a until a equals 1, then returns b; a value of 1 immediately returns 1.
#   a: number — The value whose factorial is computed. For positive integers greater than 1, the loop terminates and returns a!. The value 1 skips the loop and returns 1. Values less than or equal to 0, as well as non-integral values that never become exactly 1, cause the loop to run indefinitely.
#   → b: number — The accumulated product of all integers from a down to 2 for positive integer a; equal to a! when a > 0. The method does not return for non-terminating edge cases.
1. Initialize b to the constant integer 1. → b
2. While a is not equal to 1, multiply b by the current value of a, then decrement a by 1. If the initial a is 1, the loop body is skipped; if a is less than or equal to 0 or a non-integral value that never becomes exactly 1, this loop does not terminate. → b_and_a
3. Return the value of b as the computed factorial. → return_value

## sin(x: number) → number
Summary: Computes the sine of an angle in degrees using a Taylor series expansion, stopping when the absolute value of the current term is below 1e-15, and returns the result rounded to 10 decimal places.
#   x: number — Input angle in degrees.
#   → result: number — Sine of x computed to 10 decimal places.
1. Convert the input angle x from degrees to radians by computing x = x / 180 * pi and replacing x with the radian value. → x
2. Initialize accumulator g to 0. → g
3. Initialize Taylor term t to the current radian value of x. → t
4. Initialize term counter n to 1. → n
5. Evaluate the pre-test loop condition fabs(t) >= 1e-15; while it is true, execute the following loop-body steps and then re-evaluate the condition. → loop_condition
6. Inside the while loop, add the current term t to the accumulator g. → g
7. Inside the while loop, increment the term counter n by 1. → n
8. Inside the while loop, with n already incremented, compute the next term t as -t * x * x / (2 * n - 1) / (2 * n - 2). → t
9. After the while loop exits, return round(g, 10) as the computed sine value. → result

## tan(x: numeric) → float or bool
Summary: Returns the tangent of x as sin(x)/cos(x) rounded to 10 decimal places when cos(x) is nonzero, and returns False when cos(x) is zero.
#   x: numeric — Angle in radians for which to compute the tangent.
#   → return_value: float or bool — Rounded tangent value when cos(x) is nonzero; False when cos(x) is zero.
1. Evaluate self.cos(x) and assign the value to cos_x. → cos_x
2. Check if cos_x is not equal to 0. → condition_met
3. If condition_met is true, compute result = self.sin(x) / self.cos(x), calling self.cos(x) again as in the original code. → result
4. Return round(result, 10). → rounded_result
   ? Return False.

## taylor(x: numeric, n: integer) → numeric
Summary: Converts the input angle x from degrees to radians and computes an alternating series of even powers divided by corresponding factorials, starting from 1 and iterating k from 1 to n-1, with odd-count iterations subtracting and even-count iterations adding.
#   x: numeric — Input angle in degrees used in the series evaluation.
#   n: integer — Loop upper bound; the series iterates over k from 1 to n-1 inclusive.
#   → result: numeric — The accumulated alternating-series value.
1. Initialize accumulator a to 1. → a
2. Convert x from degrees to radians by computing x = (x / 180) * pi. → x
3. Initialize count to 1 to control alternating signs. → count
4. Iterate k over range(1, n), so k takes values 1 through n-1; if n <= 1, skip the loop body entirely. → k
5. Within the for loop over k, if count is odd, subtract (x ** (2 * k)) / self.factorial(2 * k) from a; otherwise, add (x ** (2 * k)) / self.factorial(2 * k) to a. → a
6. Within the for loop over k, after updating a, increment count by 1. → count
7. Return the accumulated value a. → result
