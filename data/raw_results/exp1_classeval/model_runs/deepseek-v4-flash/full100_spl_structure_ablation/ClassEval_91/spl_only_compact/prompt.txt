Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

## fix_path(path: str) → str
Summary: Normalizes an input path by returning an empty string for falsy inputs and stripping all leading and trailing forward slashes otherwise.
#   path: str — Input path to be normalized. Falsy values such as an empty string or None cause an early empty-string return.
#   → result: str — The normalized path with all leading and trailing forward slashes removed, or an empty string if the input path is falsy.
1. When path is not falsy, remove all leading and trailing forward slash characters from path by calling path.strip('/') and assign the result to segment_str. → segment_str
2. Return segment_str. → result
   ? Return an empty string immediately.

## parse(path: string, charset: string)
Summary: Parses a non-empty path by noting whether it originally ended with '/', normalizing it with fix_path, splitting it into slash-delimited segments, URL-decoding each segment, and appending the decoded segments to self.segments.
#   path: string — Path string to parse; if falsy, parsing is skipped.
#   charset: string — Character encoding used for URL-decoding each path segment.
1. Check whether path is truthy; if path is falsy, skip all remaining parsing steps. → path
2. Within the outer if path truthy, check whether path ends with '/' and, if so, set self.with_end_tag to True. → self.with_end_tag
3. Within the outer if path truthy, call self.fix_path(path) and assign the normalized result back to path. → path
4. Within the outer if path truthy, check whether the normalized path is truthy; if it is, split path on every '/' character into a list named split, preserving empty segments from leading, trailing, or consecutive slashes. → split
5. Within the outer if path truthy and the inner if normalized path truthy, iterate over each segment seg in split in order. → seg
6. Within the outer if path truthy, the inner if normalized path truthy, and the for loop over split, URL-decode seg using charset and append the decoded result to self.segments. → self.segments
