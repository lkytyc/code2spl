Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

## check_winner() → str or None
Summary: Scans the Tic-Tac-Toe board for a winning line in rows, columns, or diagonals and returns the winning symbol, or None if no winner exists.
#   → result: str or None — The winning player's symbol if a row, column, or diagonal contains three identical non-blank values; otherwise None.
1. For each row in self.board, check whether row[0], row[1], and row[2] are equal and not equal to a space. If they are, return row[0] immediately and skip all remaining checks. → winner_row
2. If the row check did not return, for each column index col from 0 to 2 inclusive, check whether self.board[0][col], self.board[1][col], and self.board[2][col] are equal and not equal to a space. If they are, return self.board[0][col] immediately and skip all remaining checks. → winner_column
3. If the column check did not return, check whether self.board[0][0], self.board[1][1], and self.board[2][2] are equal and not equal to a space. If they are, return self.board[0][0] immediately and skip all remaining checks. → winner_main_diagonal
4. If the main diagonal check did not return, check whether self.board[0][2], self.board[1][1], and self.board[2][0] are equal and not equal to a space. If they are, return self.board[0][2] immediately. → winner_anti_diagonal
5. If no winning row, column, or diagonal was found, return None. → no_winner

## is_board_full(self: object) → bool
Summary: Returns True if no row of the board contains a space, and False as soon as any row contains a space.
#   self: object — The board object that owns the board attribute being inspected.
#   → result: bool — True when the board is full because every row lacks spaces; False when any row contains a space.

2. Within the for loop over row in self.board, check whether the string ' ' is present in row. → contains_space
3. Within the for loop over row in self.board, if contains_space is true, immediately exit the loop and the function by returning False. → early_return_false
4. After the for loop over row in self.board has finished without finding a space in any row, return True. → final_return_true

## make_move(row: int, col: int) → bool
Summary: Attempts to place the current player's mark in an empty cell of the board, switches the active player, and returns True on success; returns False if the cell is already occupied.

3. If cell_is_empty is true, toggle current_player to O if it is currently X, and to X otherwise. → current_player_updated
4. If cell_is_empty is true, return True to indicate that the move was successful. → return_value
