Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of the same class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

    This class provides to build SQL queries, including SELECT, INSERT, UPDATE, and DELETE statements. 
    """

    def select(table, columns='*', where=None):
        """
        Generate the SELECT SQL statement from the given parameters.
        :param table: str, the query table in database.
        :param columns: list of str, ['col1', 'col2'].
        :param where: dict, {key1: value1, key2: value2 ...}. The query condition.
        return query: str, the SQL query statement.
        >>> SQLQueryBuilder.select('table1', columns = ["col1","col2"], where = {"age": 15})
        "SELECT col1, col2 FROM table1 WHERE age='15'"
        """

    @staticmethod
    def insert(table, data):
        """
        Generate the INSERT SQL statement from the given parameters.
        :param table: str, the table to be inserted in database.
        :param data: dict, the key and value in SQL insert statement
        :return query: str, the SQL insert statement.
        >>> SQLQueryBuilder.insert('table1', {'name': 'Test', 'age': 14})
        "INSERT INTO table1 (name, age) VALUES ('Test', '14')"
        """

    @staticmethod
    def delete(table, where=None):
        """
        Generate the DELETE SQL statement from the given parameters.

        >>> SQLQueryBuilder.delete('table1', {'name': 'Test', 'age': 14})

## select(table: str, columns: str or Iterable[str], where: dict or None) → str
Summary: Builds a SQL SELECT query string from a table name, an optional column list or '*', and an optional dictionary of equality conditions.
#   table: str — The table name or SQL table expression to select from.
#   columns: str or Iterable[str] — The columns to select. Defaults to the literal '*'. If not '*', the value is treated as an iterable of column names and joined with ', '.

#   → result: str — The generated SQL SELECT query string.

2. Construct the base query by formatting the current columns value and table value into the template `SELECT {columns} FROM {table}` and assign it to query. → query
3. If where is truthy, iterate over where.items(), format each key-value pair as an equality predicate `{k}='{v}'`, join all predicates with ' AND ', append ' WHERE ' plus the joined predicates to query, and assign the resulting string back to query. → query
4. Return query as the method result. → query

## update(table: string, data: dict, where: dict or None) → string

3. Return query as the final result. → query
