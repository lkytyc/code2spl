Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

# Class: SQLQueryBuilder

## delete(table: str, where: Optional[dict]) → str
Summary: Builds a SQL DELETE statement for a given table, appending equality conditions from the where dictionary joined by AND when where is provided.
#   table: str — Name of the table to delete from.
#   where: Optional[dict] — Dictionary mapping column names to values for WHERE equality conditions. If None or empty, no WHERE clause is added.
#   → query: str — Constructed SQL DELETE query string.
1. Build the initial query string by interpolating table into the literal text 'DELETE FROM '. → query
2. Check whether where is truthy (not None and not empty). If truthy, execute the alternative flow 'where is truthy' to append the WHERE clause; otherwise leave query unchanged. → query
3. Return query. → query
   ? For each key-value pair in where.items() in insertion order, format the pair as column='value' and collect the formatted condition strings.
   ? Join all formatted condition strings with ' AND ' to produce the where_clause.
   ? Append ' WHERE ' followed by where_clause to query.

## insert(table: string, data: dict) → string
Summary: Constructs an SQL INSERT statement by turning dictionary keys into a comma-separated column list and dictionary values into a comma-separated list of single-quoted values.
#   table: string — Name of the target database table.
#   data: dict — Dictionary whose keys are column names and whose values are the values to insert.
#   → result: string — Generated SQL INSERT statement.
1. Create keys by joining the keys of data with ', '. → keys
2. Create values by converting each value in data.values() to a single-quoted string and joining them with ', '. → values
3. Return the formatted SQL INSERT statement using table, keys, and values. → result

## select(table: str, columns: str or Iterable[str], where: dict or None) → str
Summary: Builds a SQL SELECT query string from a table name, an optional column list or '*', and an optional dictionary of equality conditions.
#   table: str — The table name or SQL table expression to select from.
#   columns: str or Iterable[str] — The columns to select. Defaults to the literal '*'. If not '*', the value is treated as an iterable of column names and joined with ', '.
#   where: dict or None — Optional mapping of column names to values used to build equality predicates. Each value is converted to a string and wrapped in single quotes without SQL escaping.
#   → result: str — The generated SQL SELECT query string.
1. If columns is not the literal string '*', join the elements of columns with ', ' and assign the resulting string back to columns. → columns
2. Construct the base query by formatting the current columns value and table value into the template `SELECT {columns} FROM {table}` and assign it to query. → query
3. If where is truthy, iterate over where.items(), format each key-value pair as an equality predicate `{k}='{v}'`, join all predicates with ' AND ', append ' WHERE ' plus the joined predicates to query, and assign the resulting string back to query. → query
4. Return query as the method result. → query

## update(table: string, data: dict, where: dict or None) → string
Summary: Builds a SQL UPDATE statement string from a table name, a dictionary of column-value pairs, and an optional WHERE condition dictionary.
#   table: string — Name of the table to update.
#   data: dict — Mapping of column names to values for the SET clause.
#   where: dict or None — Optional mapping of column names to values for the WHERE clause; defaults to None and is ignored if falsy.
#   → query: string — The generated SQL UPDATE query string.
1. For each key-value pair in data, format the pair as f"{k}='{v}'", join all formatted strings with ', ', and assign the result to update_str. → update_str
2. Compose the query as f"UPDATE {table} SET {update_str}" and assign it to query. → query
3. Return query as the final result. → query
   ? Within the if where truthy branch, format each key-value pair in where.items() as f"{k}='{v}'", join the formatted pairs with ' AND ', append ' WHERE ' plus that joined string to query, and assign the result back to query.
   ? Return the updated query as the final result.
