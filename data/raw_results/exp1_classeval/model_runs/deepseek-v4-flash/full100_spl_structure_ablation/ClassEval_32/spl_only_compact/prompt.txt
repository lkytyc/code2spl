Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

## caesar_decipher(ciphertext: string, shift: int) → string
Summary: Deciphers a Caesar cipher string by shifting each alphabetic character backward by the given shift while preserving case and leaving all non-alphabetic characters unchanged.
#   ciphertext: string — The encrypted text to be deciphered.
#   shift: int — The number of alphabet positions to shift each letter backward; modulo 26 wrapping is applied.
#   → plaintext: string — The deciphered string produced by shifting letters and preserving non-alphabetic characters.
1. Initialize plaintext to an empty string. → plaintext
2. For each character char in ciphertext, execute the loop body. → char
3. Within the for loop over char, test whether char.isalpha() is true. → is_alpha
4. Within the for loop over char, if char is alphabetic and char.isupper() is true, set ascii_offset to 65. → ascii_offset
5. Within the for loop over char, if char is alphabetic and char.isupper() is false, set ascii_offset to 97. → ascii_offset
6. Within the for loop over char, for an alphabetic char, compute shifted_char as chr((ord(char) - ascii_offset - shift) % 26 + ascii_offset). → shifted_char
7. Within the for loop over char, for an alphabetic char, append shifted_char to plaintext. → plaintext
8. Within the for loop over char, if char is not alphabetic, append char to plaintext unchanged. → plaintext
9. After the for loop completes, return plaintext. → plaintext

## rail_fence_decipher(encrypted_text: string, rails: integer) → string
Summary: Reconstructs plain text from a Rail Fence cipher by marking a zigzag rail grid, filling the marked cells from the ciphertext in row-major order, then reading the grid along the zigzag path.
#   encrypted_text: string — The encrypted text to decipher.
#   rails: integer — The number of rails used in the Rail Fence cipher.
#   → plain_text: string — The deciphered plain text reconstructed from the rail-fence grid.
1. Initialize fence as a list of rails rows, where each row contains len(encrypted_text) copies of the newline sentinel '\n'; initialize direction to -1 and row, col to 0, 0. → fence
2. Loop exactly len(encrypted_text) times using an unused loop variable. At each iteration, if row == 0 or row == rails - 1, set direction = -direction; then set fence[row][col] = ''; increment col by 1; and update row by row += direction. → fence
3. Initialize index to 0. → index
4. For each row i from 0 to rails - 1, and within that row for each column j from 0 to len(encrypted_text) - 1, if fence[i][j] == '', assign fence[i][j] = encrypted_text[index] and increment index by 1. → fence
5. Initialize plain_text to an empty string, direction to -1, and row, col to 0, 0. → plain_text
6. Loop exactly len(encrypted_text) times. At each iteration, if row == 0 or row == rails - 1, set direction = -direction; append fence[row][col] to plain_text; increment col by 1; and update row by row += direction. → plain_text
7. Return plain_text as the final deciphered result. → plain_text

## vigenere_decipher(ciphertext: string) → string
Summary: Decrypts a Vigenere ciphertext string by shifting each alphabetic character backward according to the repeated key, while passing non-alphabetic characters through unchanged and preserving original case.
#   ciphertext: string — The encrypted text to decrypt.
#   → decrypted_text: string — The decrypted plaintext string.
1. Initialize decrypted_text to an empty string. → decrypted_text
2. Initialize key_index to 0. → key_index
3. For each character char in ciphertext, iterate through the string in order. → char
4. Within the for loop over ciphertext, check whether char.isalpha() is true. → is_alpha
5. If char is alphabetic, compute shift by taking self.key[key_index % len(self.key)].lower() and subtracting ord('a') from its ord value. → shift
6. If char is alphabetic, compute decrypted_char as chr((ord(char.lower()) - ord('a') - shift) % 26 + ord('a')). → decrypted_char
7. If char is alphabetic, append to decrypted_text either decrypted_char.upper() if char.isupper() is true, or decrypted_char otherwise, so the original case is preserved. → decrypted_text
8. If char is alphabetic, increment key_index by 1. → key_index
9. If char is not alphabetic, append char unchanged to decrypted_text and do not increment key_index. → decrypted_text
10. After the loop completes, return decrypted_text. → decrypted_text
