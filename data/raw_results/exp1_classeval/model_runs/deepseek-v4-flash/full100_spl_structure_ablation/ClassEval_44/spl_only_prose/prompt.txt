Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

## extract_code_from_html_text(self: object, html_text: str) → list[str]
Summary: Formats the input HTML text and, when the code marker is present, extracts and returns the non-empty text contents of all pre and blockquote elements.
#   self: object — Instance providing format_line_html_text and the CODE_MARK constant.
#   html_text: str — HTML string to inspect and parse for code blocks.
#   → code_list: list[str] — Non-empty extracted text from pre and blockquote tags, or an empty list when the code marker is missing.
1. Call self.format_line_html_text(html_text) and assign the returned string to text_with_code_tag. → text_with_code_tag
2. Check whether self.CODE_MARK is contained in text_with_code_tag and store the boolean result in has_code_mark. → has_code_mark
3. If has_code_mark is false, return an empty list using the alternative flow; otherwise continue. → has_code_mark
4. Set code_index_start to the integer constant 0. → code_index_start
5. Parse the original html_text with BeautifulSoup(html_text, 'lxml') and assign the parsed document to soup. → soup
6. Call soup.find_all(name=['pre', 'blockquote']) and assign the resulting list of elements to code_tag. → code_tag
7. Count the non-overlapping occurrences of self.CODE_MARK in text_with_code_tag and assign the count to code_count. → code_count
8. Initialize code_list as an empty list. → code_list
9. For code_index from code_index_start inclusive to code_index_start + code_count exclusive, retrieve code_tag[code_index].get_text() as code; if code is truthy, append code to code_list. → code_list
10. Return code_list. → code_list
   ? Return an empty list.

## format_line_html_text(html_text: str or bytes) → str
Summary: Converts raw HTML into formatted text by replacing pre/blockquote content with a code marker, normalizing list items and paragraphs with punctuation, decoding HTML entities, and applying line-feed normalization.
#   html_text: str or bytes — Raw HTML content to parse and format.
#   → return_value: str — Formatted text with code markers, normalized list items, punctuated paragraphs, decoded HTML entities, and normalized line feeds.
1. Parse html_text into a BeautifulSoup DOM using the lxml parser and assign the result to soup. → soup
2. Find all pre and blockquote descendants in soup and assign the ResultSet to code_tag. → code_tag
3. For each tag in code_tag, set tag.string to self.CODE_MARK. → soup
4. Find all ul and ol descendants in soup and assign the ResultSet to ul_ol_group. → ul_ol_group
5. For each ul_ol_item in ul_ol_group, collect all li descendants as li_group; for each li_item in li_group, get stripped text as li_item_text; if li_item_text is empty, skip it; if its last character is in string.punctuation, set li_item.string to '[-]' plus li_item_text; otherwise set li_item.string to '[-]' plus li_item_text plus '.'. → soup
6. Find all p descendants in soup and assign the ResultSet to p_group. → p_group
7. For each p_item in p_group, extract stripped text as p_item_text; if p_item_text is truthy: if its last character is in string.punctuation, set p_item.string to p_item_text and continue; otherwise find the next sibling; if next_sibling exists and self.CODE_MARK appears in next_sibling.get_text(), set p_item.string to p_item_text plus ':' and continue; otherwise set p_item.string to p_item_text plus '.'. → soup
8. Extract all text from soup with soup.get_text(), decode HTML entities with gensim.utils.decode_htmlentities, and assign the decoded string to clean_text. → clean_text
9. Return self.__format_line_feed(clean_text). → return_value
   ? Return an empty string.
