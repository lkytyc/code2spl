Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

# Class: BoyerMooreSearch
# Fields: textLen, text, patLen, pattern
# Calls: bad_character_heuristic→mismatch_in_text, bad_character_heuristic→match_in_pattern

## __init__(text: string, pattern: string)
Summary: Initializes the instance by storing the provided text and pattern and computing their character lengths.
#   text: string — The text to store in self.text and from which self.textLen is computed.
#   pattern: string — The pattern to store in self.pattern and from which self.patLen is computed.
1. Assign the input text value to the instance attribute self.text. → self.text
2. Assign the input pattern value to the instance attribute self.pattern. → self.pattern
3. Compute the length of the input text and store it in the instance attribute self.textLen. → self.textLen
4. Compute the length of the input pattern and store it in the instance attribute self.patLen. → self.patLen

## bad_character_heuristic(self: object) → list
Summary: Scans every possible alignment of the pattern against the text, records starting indices where a full match is found, and returns them; the bad-character skip is attempted on mismatch but has no effect because the for loop overwrites i.
#   self: object — State object carrying text, textLen, patLen and the helper methods mismatch_in_text(i) and match_in_pattern(character).
#   → positions: list — Starting indices i in self.text where mismatch_in_text(i) returned -1, meaning the pattern matched at that alignment.
1. Initialize positions as an empty list to collect matching starting indices. → positions
2. For each i in range(self.textLen - self.patLen + 1), a half-open range equivalent to i = 0, 1, ..., self.textLen - self.patLen inclusive; if self.textLen - self.patLen < 0, the range is empty. Compute mismatch_index = self.mismatch_in_text(i). → mismatch_index
3. Use mismatch_index to select one of the two alternative paths: match branch if mismatch_index == -1, otherwise mismatch branch. → mismatch_index
4. After the loop finishes, return positions. → positions
   ? Append the current starting index i to positions.
   ? Compute match_index = self.match_in_pattern(self.text[mismatch_index]).
   ? Assign i = mismatch_index - match_index. The enclosing for loop overwrites i with the next value from range at the start of the next iteration, so this assignment does not alter the loop traversal.

## match_in_pattern(self: object, char: string) → integer
Summary: Searches self.pattern from right to left for char and returns the index of its rightmost occurrence, or -1 when char is absent.
#   self: object — Object exposing the pattern and its length patLen.
#   char: string — Character whose rightmost occurrence in self.pattern is to be found.
#   → result: integer — Rightmost index of char in self.pattern, or -1 if char is not present.
1. Initialize index i to self.patLen - 1, the rightmost position of self.pattern. → i
2. For each i from self.patLen - 1 down to 0 inclusive, compare char with self.pattern[i]. → char_matches
3. Within the backward loop, if char_matches is true, return i immediately. → i
4. After the loop completes with no match, return -1. → not_found

## mismatch_in_text(currentPos: int) → int
Summary: Scans the pattern from right to left at a given text alignment and returns the rightmost position in the text where a mismatch occurs, or -1 if all characters match.
#   currentPos: int — Starting alignment position in the text where the pattern is compared.
#   → result: int — Rightmost text index where a mismatch occurs, or -1 if the entire pattern matches at currentPos.
1. Start with the pattern aligned to the text at currentPos. → alignment
2. Iterate over pattern indices i from self.patLen - 1 down to 0 inclusive, stepping by -1. → i
3. For each i, compare self.pattern[i] with self.text[currentPos + i]. → characters_equal
4. If self.pattern[i] does not equal self.text[currentPos + i], immediately return currentPos + i as the mismatch position. → mismatch_position
5. If the loop completes without finding a mismatch, return -1. → result
