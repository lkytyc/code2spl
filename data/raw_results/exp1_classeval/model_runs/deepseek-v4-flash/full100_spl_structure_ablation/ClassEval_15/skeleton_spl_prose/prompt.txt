## match_in_pattern(self: object, char: string) → integer
Summary: Searches self.pattern from right to left for char and returns the index of its rightmost occurrence, or -1 when char is absent.
#   self: object — Object exposing the pattern and its length patLen.
#   char: string — Character whose rightmost occurrence in self.pattern is to be found.
#   → result: integer — Rightmost index of char in self.pattern, or -1 if char is not present.
1. Initialize index i to self.patLen - 1, the rightmost position of self.pattern. → i
2. For each i from self.patLen - 1 down to 0 inclusive, compare char with self.pattern[i]. → char_matches
3. Within the backward loop, if char_matches is true, return i immediately. → i
4. After the loop completes with no match, return -1. → not_found

## mismatch_in_text(currentPos: int) → int
Summary: Scans the pattern from right to left at a given text alignment and returns the rightmost position in the text where a mismatch occurs, or -1 if all characters match.
#   currentPos: int — Starting alignment position in the text where the pattern is compared.
#   → result: int — Rightmost text index where a mismatch occurs, or -1 if the entire pattern matches at currentPos.
1. Start with the pattern aligned to the text at currentPos. → alignment
2. Iterate over pattern indices i from self.patLen - 1 down to 0 inclusive, stepping by -1. → i
3. For each i, compare self.pattern[i] with self.text[currentPos + i]. → characters_equal
4. If self.pattern[i] does not equal self.text[currentPos + i], immediately return currentPos + i as the mismatch position. → mismatch_position
5. If the loop completes without finding a mismatch, return -1. → result
