Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

## interpolate_1d(x: array[number], y: array[number], x_interp: array[number]) → array[number]
Summary: Performs piecewise linear interpolation on the given x/y data to estimate y values for each coordinate in x_interp, returning a list of estimates for coordinates that fall inside the data range.
#   x: array[number] — Independent coordinate values; the code expects them to be sorted in ascending order, len(x) >= 2, and no duplicate consecutive values.
#   y: array[number] — Dependent values paired with x; y must contain at least as many elements as x.
#   x_interp: array[number] — Query coordinates for which interpolated y values are requested.
#   → y_interp: array[number] — Interpolated y values, one for each x_interp value that falls inside an interval [x[i], x[i+1]]. x_interp values outside the range of x are not included in the returned list.
1. Initialize y_interp as an empty list. → y_interp
2. For each xi in x_interp, process it in order. → xi
3. For the current xi, loop over segment indexes i from 0 to len(x)-2 inclusive, in increasing order. → i
4. Within the current xi and segment index i, evaluate whether x[i] <= xi <= x[i+1]. The comparison is inclusive of both endpoints. If true, select this i as the matching interval and do not consider later i values; because segments are checked left to right, the first matching interval is used when xi lies on a shared boundary. → i
5. Using the selected interval i, compute yi = y[i] + (y[i+1] - y[i]) * (xi - x[i]) / (x[i+1] - x[i]). → yi
6. Append yi to y_interp and break out of the inner segment loop for the current xi. → y_interp
7. If no segment i satisfies the inclusive condition for the current xi, do not append any value for that xi and continue with the next xi. → y_interp
8. After all xi values in x_interp have been processed, return y_interp. → y_interp

## interpolate_2d(x: List[float], y: List[float], z: List[List[float]], x_interp: Sequence[float], y_interp: Sequence[float]) → List[float]
Summary: Performs bilinear interpolation on a 2D grid for each (x, y) query point and returns the interpolated values for points that fall inside the grid.
#   x: List[float] — Grid x-coordinates, assumed to be sorted; used to define x intervals.
#   y: List[float] — Grid y-coordinates, assumed to be sorted; used to define y intervals.
#   z: List[List[float]] — 2D grid values where z[i][j] corresponds to (x[i], y[j]).
#   x_interp: Sequence[float] — x-coordinates of the query points, paired element-wise with y_interp.
#   y_interp: Sequence[float] — y-coordinates of the query points, paired element-wise with x_interp.
#   → z_interp: List[float] — Interpolated z values, one for each query point that lies within the grid; points outside the grid are omitted.
1. Initialize z_interp as an empty list to accumulate interpolated values. → z_interp
2. For each pair (xi, yi) from zip(x_interp, y_interp), process one interpolation point. → xi_yi_pair
3. Within the outer loop over (xi, yi), iterate i from 0 to len(x)-2 to search for the first x interval containing xi. → i
4. Within the outer loop over (xi, yi) and the i loop, test whether x[i] <= xi <= x[i+1]. → x_interval_matched
5. Within the i loop when the x-interval condition is true, iterate j from 0 to len(y)-2 to search for the first y interval containing yi. → j
6. Within the i loop and j loop, test whether y[j] <= yi <= y[j+1]. → y_interval_matched
7. Within the i loop and j loop when both interval conditions are true, read z00 = z[i][j], z01 = z[i][j+1], z10 = z[i+1][j], and z11 = z[i+1][j+1]. → corner_values
8. Within the matched grid cell, compute zi using the bilinear interpolation formula: (z00*(x[i+1]-xi)*(y[j+1]-yi) + z10*(xi-x[i])*(y[j+1]-yi) + z01*(x[i+1]-xi)*(yi-y[j]) + z11*(xi-x[i])*(yi-y[j])) / ((x[i+1]-x[i])*(y[j+1]-y[j])). → zi
9. Within the matched grid cell, append zi to z_interp and break out of the j loop. → z_interp
10. After exiting the j loop for a matched x interval, break out of the i loop; this terminates the x interval search even if no y interval matched. → i_loop_terminated
11. After processing all (xi, yi) pairs, return z_interp. → z_interp
