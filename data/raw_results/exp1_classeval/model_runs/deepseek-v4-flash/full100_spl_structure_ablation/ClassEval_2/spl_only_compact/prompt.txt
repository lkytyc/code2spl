Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

Class specification:

# Class: ArgumentParser
# Fields: arguments, required, types
# Calls: parse_arguments→_convert_type

## __init__()
Summary: Initializes the instance attributes arguments, required, and types as empty collections.
1. Initialize self.arguments to an empty dictionary. → self.arguments
2. Initialize self.required to an empty set. → self.required
3. Initialize self.types to an empty dictionary. → self.types

## _convert_type(arg: string, value: any) → any
Summary: Converts the provided value using the type associated with the arg key, preserving the original value if the type lookup fails or conversion raises ValueError.
#   arg: string — Key used to look up the target type in self.types.
#   value: any — Value to be converted to the registered type.
#   → result: any — The converted value if conversion succeeds; otherwise the original value.
1. Look up self.types[arg] to get the target type for the given argument. → target_type
2. Call target_type(value) to convert the value to the target type. → converted_value
3. Return converted_value. → result
   ? Catch the ValueError or KeyError and keep the original value.
   ? Return the original value.

## add_argument(arg: object, required: bool, arg_type: type)
Summary: Registers an argument name with an optional required flag and a type, storing the required marker in self.required and the type mapping in self.types.
#   arg: object — The argument name to register.
#   required: bool — Whether to mark the argument as required; defaults to False.
#   arg_type: type — The type to associate with the argument; defaults to str.
1. If required is True, add arg to the required set. → self.required
2. Register arg_type as the type of arg by setting self.types[arg] to arg_type. → self.types

## get_argument(key: object) → object
Summary: Returns the value associated with the given key from the arguments dictionary, or None if the key is not present.
#   key: object — The key whose associated argument value is to be returned.
#   → value: object — The value associated with key in the arguments dictionary, or None if key is not present.
1. Call get on the current instance's arguments dictionary with the supplied key and return the resulting value, which is None when the key is absent. → value

## parse_arguments(command_string: str)
Summary: Parses the tokens after the first token in command_string into long and short options, populates self.arguments with converted values or True flags, and returns whether all required arguments are present.
#   command_string: str — Raw command string whose first token is the command name and is ignored; remaining tokens are parsed as options.
1. Split command_string on whitespace and, if the resulting list is non-empty, discard its first token; store the remaining tokens as args. → args
2. For each index i from 0 to len(args)-1, assign arg = args[i]. → arg
3. Within the loop over i, if arg starts with '--', strip the leading '--' from arg and split the remainder by '=' to form key_value. → key_value
4. Within the loop over i, if arg starts with '--' and key_value has exactly two elements, set self.arguments[key_value[0]] to self._convert_type(key_value[0], key_value[1]). → self.arguments
5. Within the loop over i, if arg starts with '--' and key_value does not have exactly two elements, set self.arguments[key_value[0]] to True. → self.arguments
6. Within the loop over i, if arg does not start with '--' but starts with '-', set key = arg[1:]. → key
7. Within the loop over i, for a short option, if i + 1 < len(args) (short-circuit) and args[i + 1] does not start with '-', set self.arguments[key] to self._convert_type(key, args[i + 1]). → self.arguments
8. Within the loop over i, for a short option, if the next-token condition is false, set self.arguments[key] to True. → self.arguments
9. Within the loop over i, if arg does not start with '-', perform no action for that token. → None
10. After the loop, compute missing_args = self.required - set(self.arguments.keys()). → missing_args
11. If missing_args is empty, return (True, None). → return_value
   ? Return (False, missing_args).
