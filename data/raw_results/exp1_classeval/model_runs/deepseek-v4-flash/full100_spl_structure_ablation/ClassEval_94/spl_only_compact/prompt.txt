Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

# Class: VendingMachine
# Fields: balance, inventory
# Calls: add_item→restock_item

## __init__()
Summary: Initializes a new object's inventory as an empty dictionary and balance as zero.
1. In the __init__ method, initialize self.inventory to a new empty dictionary. → self.inventory
2. In the __init__ method, initialize self.balance to the integer 0. → self.balance

## add_item(item_name: string, price: number, quantity: integer)
Summary: Tries to restock the requested item; if the restock call returns a falsey value, it falls back to directly setting the item's inventory entry to the supplied price and quantity.
#   item_name: string — The name of the inventory item to add or update.
#   price: number — The price to store for the item.
#   quantity: integer — The quantity to store for the item.
1. Call self.restock_item(item_name, quantity) and store the returned value as restock_result. → restock_result
2. If restock_result is falsey, meaning the restock attempt failed, set self.inventory[item_name] to a dictionary containing price and quantity. → self.inventory

## display_items(self: object) → string or boolean
Summary: Returns a newline-separated string of inventory item details in the format 'name - $price [quantity]', or False when the inventory is empty.
#   self: object — Object instance containing an inventory dictionary attribute.
#   → result_string: string or boolean — Newline-separated formatted inventory listing, or False when inventory is empty.
1. Evaluate the truthiness of self.inventory. → inventory_truthiness
2. On the else path, with self.inventory truthy, initialize an empty list named items. → items
3. For each item_name and item_info in self.inventory.items(), process one inventory entry. → inventory_entry
4. Within the for loop over inventory entries, create the formatted line f"{item_name} - ${item_info['price']} [{item_info['quantity']}]". → formatted_line
5. Within the for loop over inventory entries, append formatted_line to items. → items
6. After the for loop completes, join items with the newline separator "\n" and return the resulting string. → result_string
   ? Return False immediately.

## insert_coin(amount: numeric) → numeric
Summary: Adds the specified amount to the instance balance and returns the updated balance.
#   amount: numeric — The value to add to the balance.
#   → balance: numeric — The updated balance after adding the amount.
1. Load the current value of self.balance. → current_balance
2. Add amount to current_balance and assign the result back to self.balance. → self.balance
3. Return the updated self.balance. → return_value

## purchase_item(self: object, item_name: str) → number_or_boolean
Summary: Attempts to purchase the named item by verifying it exists, has stock, and is affordable; on success it deducts the price, decrements stock, and returns the new balance, otherwise it returns False.
#   self: object — The instance with inventory (dict) and balance (number) attributes.
#   item_name: str — The name/key of the item to purchase in self.inventory.
#   → return_value: number_or_boolean — The updated balance after a successful purchase, or False if the item is not in inventory, has no stock, or the balance is insufficient.
1. Evaluate whether item_name is a key in self.inventory. → outer_condition
2. If outer_condition is True, retrieve item = self.inventory[item_name]. → item
3. If outer_condition is True, evaluate inner_condition as item['quantity'] > 0 and self.balance >= item['price']; short-circuit after item['quantity'] > 0 when that is False. → inner_condition
4. If outer_condition and inner_condition are True, subtract item['price'] from self.balance. → self.balance
5. If outer_condition and inner_condition are True, decrement item['quantity'] by 1. → item['quantity']
6. If outer_condition and inner_condition are True, return self.balance. → return_value
   ? Return False without modifying self.balance or item['quantity'].
   ? Return False without modifying self.balance or item['quantity'].

## restock_item(item_name: string, quantity: numeric) → boolean
Summary: Restocks an existing inventory item by increasing its quantity and returns True, or returns False without changes if the item is not present.
#   item_name: string — Name of the inventory item to restock.
#   quantity: numeric — Amount to add to the item's current quantity.
#   → result: boolean — True if the item exists and its quantity was increased; False if the item does not exist.
1. Check whether item_name exists as a key in self.inventory. → item_exists
   ? Increase self.inventory[item_name]['quantity'] by quantity.
   ? Return True to indicate that the item was restocked.
   ? Return False to indicate that the item was not restocked.
