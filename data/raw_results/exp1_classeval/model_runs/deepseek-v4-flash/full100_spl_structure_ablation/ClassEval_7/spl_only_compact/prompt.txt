Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

# Class: BalancedBrackets
# Fields: right_brackets, stack, left_brackets, expr
# Calls: check_balanced_brackets→clear_expr

## __init__(expr: str)
Summary: Initializes the bracket-matching state with an empty stack, the three opening/closing bracket lists, and the expression to validate.
#   expr: str — The expression string to be validated for balanced brackets.
1. Initialize self.stack to an empty list. → self.stack
2. Set self.left_brackets to the list of opening brackets: '(', '{', '['. → self.left_brackets]
3. Assign the expr parameter to self.expr. → self.expr

## check_balanced_brackets() → boolean
Summary: Checks whether the brackets in self.expr are balanced and correctly nested by pushing opening brackets onto a stack and validating every closing bracket against the top of the stack, returning False on the first mismatch or if any brackets remain after the loop.
#   → result: boolean — Returns True if all brackets in self.expr are balanced and properly nested, otherwise returns False.
1. Clear the current expression state by calling self.clear_expr(). → self
2. For each character Brkt in self.expr, begin iterating through the expression. → Brkt
3. Within the for loop over Brkt, test whether Brkt is in self.left_brackets. → is_left_bracket
4. Within the for loop over Brkt, if is_left_bracket is true, push Brkt onto self.stack. → self.stack
5. Within the for loop over Brkt, if is_left_bracket is false, pop the top value from self.stack into Current_Brkt. → Current_Brkt
6. Within the non-left-bracket branch of the for loop, if Current_Brkt is '(' and Brkt is not ')', return False immediately. → False_return
7. Within the non-left-bracket branch of the for loop, if Current_Brkt is '{' and Brkt is not '}', return False immediately. → False_return
8. Within the non-left-bracket branch of the for loop, if Current_Brkt is '[' and Brkt is not ']', return False immediately. → False_return
9. After the for loop completes, if self.stack is non-empty, return False. → False_return
10. After the for loop completes, if self.stack is empty, return True. → True_return

## clear_expr()
Summary: Filters self.expr to retain only characters contained in self.left_brackets or self.right_brackets, then assigns the filtered string back to self.expr.
1. Read the current value of self.expr as the input string. → old_expr
2. For each character c in old_expr, test whether c is in self.left_brackets or c is in self.right_brackets. → kept_chars
3. Concatenate all kept characters in their original order using an empty string as the separator. → filtered_expr
4. Assign filtered_expr to self.expr, replacing the previous value. → self.expr
