Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

# Class: KappaCalculator

## fleiss_kappa(N: int, k: int, n: int) → float
Summary: Computes Fleiss' kappa inter-rater agreement coefficient from a matrix of rating counts by comparing observed agreement with expected agreement.
#   N: int — Number of subjects, corresponding to the number of rows in testData.
#   k: int — Number of categories, corresponding to the number of columns in testData.
#   n: int — Number of raters per subject, used in normalizing row-level agreement.
#   → ans: float — The resulting Fleiss' kappa coefficient, returned as ans[0, 0].
1. Convert testData to a floating-point matrix named dataMat using np.mat. → dataMat
2. Create a k x 1 column vector of ones named oneMat using np.ones. → oneMat
3. Initialize sum to 0.0. → sum
4. Initialize P0 to 0.0. → P0
5. For each i from 0 to N-1, reset temp to 0.0 at the start of the outer loop. → temp
6. Within the outer loop over i, for each j from 0 to k-1, add dataMat[i, j] to sum and add 1.0 * dataMat[i, j] ** 2 to temp. → temp
7. After the inner loop over j, for each i from 0 to N-1, set temp = (temp - n) / ((n - 1) * n) and add temp to P0. → P0
8. After the outer loop over i, scale P0 by 1.0 and divide by N, assigning the result to P0. → P0
9. Compute ysum as the column-wise sum of dataMat along axis 0 using np.sum. → ysum
10. For each i from 0 to k-1, set ysum[0, i] to (ysum[0, i] / sum) ** 2. → ysum
11. Compute Pe by multiplying ysum by oneMat and then by 1.0. → Pe
12. Compute ans as (P0 - Pe) / (1 - Pe). → ans
13. Return ans[0, 0]. → ans

## kappa(k: int) → float
Summary: Computes Cohen's kappa coefficient from a square confusion/agreement matrix by summing diagonal observed agreement, deriving expected agreement from row and column totals, and normalizing by the chance-corrected maximum.
#   k: int — Number of classes or categories; the loop range end, exclusive, for summing diagonal entries.
#   → cohens_coefficient: float — Computed Cohen's kappa coefficient.
1. Convert testData to a NumPy matrix and assign it to dataMat. → dataMat
2. Initialize P0 to 0.0. → P0
3. For each i from 0 to k-1 inclusive, accumulate dataMat[i, i] * 1.0 into P0. → P0
4. Compute xsum as the row sums of dataMat using np.sum(dataMat, axis=1). → xsum
5. Compute ysum as the column sums of dataMat using np.sum(dataMat, axis=0). → ysum
6. Compute sum as the total scalar sum of all entries in dataMat using np.sum(dataMat). → sum
7. Compute Pe as float(ysum * xsum) / sum / sum. → Pe
8. Reassign P0 as float(P0 / sum * 1.0). → P0
9. Compute cohens_coefficient as float((P0 - Pe) / (1 - Pe)). → cohens_coefficient
10. Return cohens_coefficient. → return_value
