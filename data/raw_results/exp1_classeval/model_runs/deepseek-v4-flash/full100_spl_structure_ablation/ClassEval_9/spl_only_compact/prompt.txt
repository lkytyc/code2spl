Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

11. Return the string formed by joining the elements of result with an empty separator. → return_value

## multiply(num1: string, num2: string) → string
Summary: Multiplies two non-negative integers represented as decimal strings using digit-by-digit long multiplication with carry handling, then returns the product as a decimal string without leading zeros.
#   num1: string — String of decimal digits representing a non-negative integer.
#   num2: string — String of decimal digits representing a non-negative integer.
#   → result: string — Product of num1 and num2 as a decimal string without leading zeros, or '0' if the product is zero.
1. Assign len1 = len(num1) and len2 = len(num2). → len1_len2
2. Initialize result = [0] * (len1 + len2), a list of zeros with length len1 + len2. → result
3. Start outer loop: for i in range(len1 - 1, -1, -1), so i visits each index from len1 - 1 down to 0 inclusive. → i
4. Within the outer loop over i, start inner loop: for j in range(len2 - 1, -1, -1), so j visits each index from len2 - 1 down to 0 inclusive. → j
5. Within the outer loop over i and the inner loop over j, compute mul = int(num1[i]) * int(num2[j]). → mul
6. Within the outer loop over i and the inner loop over j, set p1 = i + j and p2 = i + j + 1. → p1_p2
7. Within the outer loop over i and the inner loop over j, compute total = mul + result[p2]. → total
8. Within the outer loop over i and the inner loop over j, update result[p1] += total // 10 and set result[p2] = total % 10. → result
9. After both loops finish, set start = 0. → start
10. While start < len(result) - 1 and, with short-circuit evaluation, result[start] == 0, increment start by 1 to skip leading zeros but preserve at least one digit. → start
11. Return ''.join(map(str, result[start:])), converting the remaining digit list to a decimal string. → product

## subtract(num1: string, num2: string) → string
Summary: Subtracts two non-negative decimal integers represented as strings using digit-by-digit borrowing and returns the signed decimal result as a string.
#   num1: string — Non-negative decimal integer as a string.
#   num2: string — Non-negative decimal integer as a string.
#   → result: string — The signed decimal result of subtracting num2 from num1, as a string without leading zeros.
1. If len(num1) < len(num2), swap num1 and num2 and set negative to True; else if len(num1) > len(num2), set negative to False; else, when the lengths are equal, if num1 < num2 then swap num1 and num2 and set negative to True; otherwise set negative to False. → num1,
2. Set max_length to the maximum of len(num1) and len(num2). → max_length
3. Zero-pad num1 and num2 to length max_length using left padding. → num1,
4. Initialize borrow to 0 and result to an empty list. → borrow,
5. For each i from max_length - 1 down to 0 inclusive, compute digit_diff = int(num1[i]) - int(num2[i]) - borrow; if digit_diff < 0, add 10 to digit_diff and set borrow to 1, otherwise set borrow to 0; then insert str(digit_diff) at the beginning of result. → borrow,
6. While len(result) > 1 and result[0] == '0', remove the first element of result. → result
7. If negative is True, insert '-' at the beginning of result. → result
8. Return the string obtained by joining all elements of result. → result
