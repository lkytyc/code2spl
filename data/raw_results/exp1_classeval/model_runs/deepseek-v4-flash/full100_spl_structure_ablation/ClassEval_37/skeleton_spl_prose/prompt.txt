Skeleton Role:

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of the same class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

## rail_fence_cipher(plain_text: string, rails: integer) → string
Summary: Encrypts plain_text using a rail-fence cipher by writing characters into a zigzag pattern across the given number of rails and reading the non-placeholder cells row by row to produce the ciphertext.
#   plain_text: string — The plaintext string to encrypt.
#   rails: integer — The number of rails, or rows, used in the rail-fence zigzag pattern.
#   → encrypted_text: string — The resulting ciphertext string.
1. Create a 2D list fence with rails rows and len(plain_text) columns, filling every cell with the newline character, and assign it to fence. → fence
2. Set direction to -1, row to 0, and col to 0. → direction,
3. For each character char in plain_text, if row is 0 or rails - 1, reverse direction; then place char at fence[row][col], increment col by 1, and increase row by direction. → fence
4. Initialize encrypted_text to an empty string. → encrypted_text
5. For each row i from 0 through rails - 1 and each column j from 0 through len(plain_text) - 1, if fence[i][j] is not the newline character, append fence[i][j] to encrypted_text. → encrypted_text
6. Return encrypted_text. → encrypted_text
