`HtmlUtil` is a utility class for cleaning and extracting content from HTML strings. Here's what it does:

**Initialization**

The constructor defines a set of placeholder strings (like `-CODE-`, `-URL-`, `-NUMBER-`) that act as sentinel markers for different content types, though in practice only `-CODE-` is actively used by the two public methods.

**`format_line_html_text(html_text)`**

This is the main cleaning method. It takes raw HTML and returns a normalized plain-text version by doing the following in sequence:

1. Replaces the content of `<pre>` and `<blockquote>` tags with the `-CODE-` marker, effectively erasing code block content while preserving their position in the text.
2. Reformats list items (`<li>`) by prepending `[-]` to each item's text. If the item doesn't already end with punctuation, it appends a period.
3. Normalizes paragraph (`<p>`) text: if a paragraph doesn't end with punctuation, it appends a period. As a special case, if the next sibling element contains the `-CODE-` marker, it appends a colon instead — indicating the paragraph is likely a lead-in to a code block.
4. Extracts all text from the modified soup, decodes any remaining HTML entities via gensim, and collapses multiple consecutive newlines into one.

**`extract_code_from_html_text(html_text)`**

This method extracts the raw text content of code blocks from the original HTML. It calls `format_line_html_text` to count how many `-CODE-` markers appear in the cleaned output, then goes back to the original parsed HTML to pull the actual text from the corresponding `<pre>`/`<blockquote>` tags in order, returning them as a list. If no code blocks are present, it returns an empty list.

The two methods are designed to be complementary: one gives you clean readable text with code replaced by a placeholder, and the other gives you just the code that was stripped out.
