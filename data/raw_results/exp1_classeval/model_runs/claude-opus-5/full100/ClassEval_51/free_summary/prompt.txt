The module provides two static methods for computing inter-rater agreement statistics using numpy matrices.

**`kappa(testData, k)`** — Cohen's Kappa

Takes a square confusion matrix `testData` and the number of classes `k`. It sums the diagonal (observed agreement `P0`), then computes expected agreement `Pe` from the outer product of row and column sums divided by the total count squared. Returns the classic Cohen's kappa coefficient `(P0 - Pe) / (1 - Pe)`, a scalar float.

**`fleiss_kappa(testData, N, k, n)`** — Fleiss' Kappa

Takes a ratings matrix `testData` with `N` subjects, `k` categories, and `n` raters per subject. For each subject it computes the proportion of agreeing rater pairs, accumulates them into `P0` (mean observed agreement), then derives `Pe` (expected agreement by chance) from the squared relative frequencies of each category across all ratings. Returns `(P0 - Pe) / (1 - Pe)` as a scalar float.

Both methods return values on roughly the same scale: 0 means agreement no better than chance, 1 means perfect agreement, and negative values indicate agreement worse than chance. The key difference is scope — Cohen's kappa is for two raters, Fleiss' kappa generalizes to any fixed number of raters across multiple subjects.
