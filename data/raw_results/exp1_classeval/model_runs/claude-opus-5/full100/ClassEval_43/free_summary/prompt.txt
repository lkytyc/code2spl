`HRManagementSystem` is a simple in-memory HR record manager. It stores employee data in a plain dictionary keyed by employee ID.

**Methods and behavior**:

- `remove_employee` — deletes an employee by ID. Returns `True` on success, `False` if the ID is not found.

- `get_employee` — returns the employee's data dict if found, or `False` if not. This `False` return (instead of `None` or an exception) is worth noting because `update_employee` depends on it.

Only after passing both checks does it apply all updates, returning `True`. This means partial writes don't happen: either all keys are valid and all changes apply, or nothing changes.

- `list_employees` — returns a new dict of all employees. Each entry is a copy of the original fields with the employee ID added as `"employee_ID"`. If there are no employees, it returns an empty dict.

**Notable characteristics**: there is no persistence — all data lives in memory for the lifetime of the instance. There is also no type validation on field values; salary, for example, could be any value the caller passes in.
