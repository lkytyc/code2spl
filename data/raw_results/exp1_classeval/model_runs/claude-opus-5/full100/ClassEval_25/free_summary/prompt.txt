`CookiesUtil` is a small helper class for persisting and applying HTTP cookies through a JSON file.

**Construction:** Takes a file path as input and stores it, with `cookies` starting as `None`.

**Key behaviors:**

- `get_cookies(response)` — pulls the `cookies` key out of a response dict and immediately writes it to disk via `_save_cookies()`.

- `load_cookies` loads from the file but never assigns to `self.cookies`, so the in-memory state and the file can drift out of sync depending on call order.
- The bare `except` in `_save_cookies` will silently eat unexpected errors like `TypeError` if `self.cookies` isn't serializable.
