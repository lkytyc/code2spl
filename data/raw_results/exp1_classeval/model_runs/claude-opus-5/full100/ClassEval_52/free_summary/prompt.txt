The code provides POS-aware lemmatization for English text using NLTK.

The `Lemmatization` class wraps three operations:

**`lemmatize_sentence(sentence)`** is the main method. It strips punctuation, tokenizes the sentence into words, then tags each word with its part of speech. The POS tag drives which lemmatizer form is used — verbs get lemmatized as verbs, adjectives as adjectives, adverbs as adverbs, and everything else defaults to the noun form. It returns a list of lemmatized word strings.

**`get_pos_tag(sentence)`** strips punctuation, tokenizes, and returns only the raw POS tags (e.g. `NN`, `VBZ`) for each word, without lemmatizing.

**`remove_punctuation(sentence)`** is a helper that strips all standard punctuation characters from a string using `str.maketrans`. It's called internally by both public methods before tokenization.

On module load, three NLTK resources are downloaded if not already present: the averaged perceptron tagger (for POS tagging), punkt (for tokenization), and wordnet (for lemmatization).

The key design choice is using the POS tag to select the right lemmatizer mode — without this, the default WordNet lemmatizer assumes nouns, which produces incorrect forms for verbs and adjectives (e.g. "running" stays "running" instead of becoming "run").
