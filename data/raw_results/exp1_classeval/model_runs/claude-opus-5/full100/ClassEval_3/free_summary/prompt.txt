`ArrangementCalculator` is a utility class for computing permutations — both counting them and generating them — from a list of items.

**Construction and state**
It takes a list (`datas`) at construction time and holds it as instance state for use by the non-static methods.

**Counting permutations**
- `count(n, m)` returns the number of ordered arrangements of `m` items chosen from `n` — i.e., P(n, m) = n! / (n-m)!. If `m` is omitted or equals `n`, it returns n! (all full permutations).
- `count_all(n)` sums P(n, 1) + P(n, 2) + ... + P(n, n), giving the total number of ordered arrangements of any non-zero length from `n` items.
- `factorial(n)` is a plain iterative factorial helper used by both counting methods.

**Generating permutations**
- `select(m)` produces all ordered arrangements of `m` items drawn from `self.datas`, using `itertools.permutations` internally. If `m` is omitted, it defaults to the full length of the list. Each arrangement is returned as a list, and the result is a list of those lists.
- `select_all()` generates every arrangement of every possible length (1 through the full length), concatenating all the results from repeated calls to `select`.

The counting methods are static and work purely on integers; they have no dependency on the instance. The generating methods operate on whatever data was passed at construction. There is no input validation — negative numbers or out-of-range `m` values are not handled.
