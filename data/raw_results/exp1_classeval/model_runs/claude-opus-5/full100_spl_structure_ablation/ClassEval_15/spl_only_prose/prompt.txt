Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

## bad_character_heuristic(self: object) → list
Summary: Searches for all occurrences of the pattern in the text using the Boyer-Moore bad-character heuristic, returning a list of starting positions where the pattern fully matches.
#   self: object — Instance providing textLen (length of text), patLen (length of pattern), text (the string being searched), mismatch_in_text(i) which returns the text index of the first mismatch when aligning the pattern at position i or -1 on a full match, and match_in_pattern(char) which returns the rightmost index of char in the pattern or a value causing a safe shift when absent
#   → positions: list — List of integer starting indices in the text at which the pattern was found to fully match
1. Initialize positions as an empty list → positions
2. Iterate i over the integer range from 0 up to and including textLen - patLen (i.e., range(textLen - patLen + 1)), covering every valid alignment position where the pattern fits without overrunning the text → loop_i
3. Within the loop, call mismatch_in_text(i) to obtain the text index of the first character that does not match the pattern when aligned at position i, or -1 if the entire pattern matches; store the result → mismatch_index
4. Within the loop, if mismatch_index equals -1 (full match), append i to positions → positions
5. Within the loop, if mismatch_index is not -1 (mismatch occurred), call match_in_pattern with the character text[mismatch_index] to obtain the rightmost occurrence index of that character in the pattern, then assign i = mismatch_index - match_index as the intended bad-character shift; NOTE: this assignment has no effect in a Python for-loop because the loop variable is rebound from the iterator at the start of each iteration, so the skip is never applied and the loop always advances by 1 → match_index
6. After the loop completes, return positions → positions
   ? Call mismatch_in_text(0); if it returns -1, positions contains [0]; otherwise positions remains empty
   ? Return positions as an empty list immediately
