Task:
Complete the Python class from the ClassEval skeleton, using the compact class specification as an implementation contract.

Skeleton Role:
- The skeleton controls imports, class name, constructor shape, field names, method names, and method signatures.
- Preserve the skeleton API if skeleton and specification disagree.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of the same class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Match each specification method section to its skeleton method by method name.

Step 2: Treat the skeleton as the public API contract and the specification as the implementation contract for method bodies.

Step 3: Build a class-level behavior map:
- constructor fields and shared state;
- method inputs, outputs, and side effects;
- cross-method calls from `# Calls:` and inside steps;
- data flow from step `→` result names;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 4: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become if/elif/else blocks;
- `! raise:` steps become try/except or explicit raise only when entailed;
- `→` result names become local variables, fields, calls, or returned values.

Step 5: Keep the implementation minimal and executable. Do not add unrelated APIs or behavior outside the skeleton plus specification contract.

Reconstruction Rules:

class Calculator:
    """
    This is a class for a calculator, capable of performing basic arithmetic calculations on numerical expressions using the operators +, -, *, /, and ^ (exponentiation).
    """

    def __init__(self):
        """
        Initialize the operations performed by the five operators'+','-','*','/','^'
        """
        self.operators = {
            '+': lambda x, y: x + y,
            '-': lambda x, y: x - y,
            '*': lambda x, y: x * y,
            '/': lambda x, y: x / y,
            '^': lambda x, y: x ** y
        }

    def calculate(self, expression):
        """
        Calculate the value of a given expression
        :param expression: string, given expression
        :return:If successful, returns the value of the expression; otherwise, returns None
        >>> calculator = Calculator()
        >>> calculator.calculate('1+2-3')
        0.0
        """


    def precedence(self, operator):
        """
        Returns the priority of the specified operator, where the higher the priority, the greater the assignment. The priority of '^' is greater than '/' and '*', and the priority of '/' and '*' is greater than '+' and '-'
        :param operator: string, given operator
        :return: int, the priority of the given operator, otherwise return 0
        >>> calculator = Calculator()
        >>> calculator.precedence('+')
        1
        >>> calculator.precedence('^')
        3
        """


    def apply_operator(self, operand_stack, operator_stack):
        """
        Use the operator at the top of the operator stack to perform the operation on the two numbers at the top of the operator stack, and store the results at the top of the operator stack
        :param operand_stack:list
        :param operator_stack:list
        :return: the updated operand_stack and operator_stack
        >>> calculator = Calculator()
        >>> calculator.apply_operator([1, 2, 3], ['+', '-'])
        ([1, -1], ['-'])
        """

Summary: Pops two operands and an operator from their respective stacks, applies the operator function to the operands in left-to-right order, pushes the result back onto the operand stack, and returns both stacks.
#   operand_stack: list — Stack of numeric or evaluated operands; top element is the right-hand operand
#   operator_stack: list — Stack of operator symbols; top element is the operator to apply
#   → operand_stack: list — Operand stack after popping two operands and pushing the computed result

## calculate(expression: str) → float or None
Summary: Evaluates an infix arithmetic expression string containing numbers, operators (+, -, *, /, ^), and parentheses using the Shunting-Yard algorithm with two stacks to return the computed numeric result.
#   expression: str — Infix arithmetic expression string containing digits, decimal points, operators (+, -, *, /, ^), and parentheses
#   → result: float or None — The computed numeric result of the expression, or None if the operand stack is empty after evaluation
1. Initialize operand_stack as an empty list, operator_stack as an empty list, and num_buffer as an empty string → operand_stack,
2. Iterate over each character char in expression one at a time, consuming all characters without early exit → char
3. Within the for loop: if char is a digit (0-9) or a decimal point '.', append char to num_buffer to accumulate a multi-character numeric token → num_buffer
4. Within the for loop, in the else branch (char is not a digit or dot): if num_buffer is non-empty, convert num_buffer to float and push it onto operand_stack, then reset num_buffer to empty string → operand_stack,
5. Within the for loop else branch: if char is one of the operators in '+-*/^', enter the precedence-climbing while loop — while operator_stack is non-empty AND the top of operator_stack is not '(' AND self.precedence(top operator) >= self.precedence(char), call self.apply_operator(operand_stack, operator_stack) and update both stacks with the returned values; after the while loop exits, push char onto operator_stack → operand_stack,
6. Within the for loop else branch: if char is '(', push '(' onto operator_stack as a precedence-barrier sentinel → operator_stack
7. Within the for loop else branch: if char is ')', run a while loop — while operator_stack is non-empty AND the top of operator_stack is not '(', call self.apply_operator(operand_stack, operator_stack) and update both stacks; after the while loop exits, pop the '(' sentinel off operator_stack → operand_stack,
8. After the for loop completes: if num_buffer is non-empty, convert num_buffer to float and push it onto operand_stack (handles a trailing number at the end of the expression that was never flushed during the loop) → operand_stack
9. Drain any remaining operators: while operator_stack is non-empty, call self.apply_operator(operand_stack, operator_stack) and update both stacks with the returned values → operand_stack,
10. Return operand_stack[-1] (the top and only remaining element, which is the final result) if operand_stack is non-empty, otherwise return None → result
   ? All characters are digits or dots and are accumulated entirely into num_buffer during the for loop; num_buffer is flushed to operand_stack in the post-loop trailing-number check; the operator-drain while loop body never executes; operand_stack[-1] is returned directly
   ? The for loop iterates zero times or all characters are non-numeric non-operator characters that produce no operands; operand_stack remains empty after all phases; return None
   ! log: "Mismatched parenthesis: operator_stack is empty when attempting to pop the expected '(' sentinel after processing a ')' character"
   ! raise: IndexError "Raised implicitly by list.pop() on an empty operator_stack when the expression contains an unmatched closing parenthesis"
   ! log: "Insufficient operands on operand_stack when apply_operator attempts to pop two values for a binary operator"
   ! raise: IndexError "Raised implicitly when operand_stack underflows during apply_operator due to a malformed expression"
