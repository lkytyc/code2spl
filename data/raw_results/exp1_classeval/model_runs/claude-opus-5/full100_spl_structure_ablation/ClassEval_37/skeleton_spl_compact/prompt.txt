## rail_fence_cipher(plain_text: string, rails: integer) → string
Summary: Encrypts a plaintext string using the rail fence cipher by distributing characters across a zigzag grid of the specified number of rails and then reading them off row by row.
#   plain_text: string — The plaintext string to encrypt
#   rails: integer — The number of rails (rows) in the fence grid; must be at least 1
#   → encrypted_text: string — The ciphertext produced by reading the fence grid row by row, skipping unfilled sentinel cells

2. Set direction to -1, and set both row and col to 0 to establish the starting position and initial traversal direction for the zigzag write pass → direction,
3. For each char in plain_text: if row equals 0 or row equals rails-1 (inclusive boundary check on both the top and bottom rails), negate direction to reverse the zigzag; then write char into fence[row][col], increment col by 1, and add direction to row → fence
4. Initialize encrypted_text to an empty string to accumulate the cipher output → encrypted_text
5. For each i from 0 to rails-1, and within that loop for each j from 0 to len(plain_text)-1: if fence[i][j] is not equal to '\n', append fence[i][j] to encrypted_text → encrypted_text
6. Return encrypted_text as the final ciphertext → encrypted_text
