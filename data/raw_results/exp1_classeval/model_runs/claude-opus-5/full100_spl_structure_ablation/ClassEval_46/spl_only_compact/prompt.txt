Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

## interpolate_1d(x: list of numeric, y: list of numeric, x_interp: list of numeric) → list of numeric
Summary: Performs piecewise linear interpolation by finding, for each query point, the bracketing segment in the known data and computing the proportionally weighted output value between the two segment endpoints.
#   x: list of numeric — Sorted array of known input knot positions; must contain at least two elements and define len(x)-1 segments
#   y: list of numeric — Array of known output values corresponding element-by-element to x; must be the same length as x
#   x_interp: list of numeric — Array of query points at which interpolated output values are requested
#   → y_interp: list of numeric — Array of linearly interpolated output values, one entry per query point in x_interp that falls within a valid segment; query points outside all segments produce no entry
1. Initialize y_interp as an empty list to accumulate interpolated results → y_interp
2. Begin outer loop: iterate over each query point xi in x_interp → xi
3. Within the outer loop over xi, begin inner loop: iterate over segment index i from 0 through len(x)-2 inclusive, covering all len(x)-1 consecutive segments → i
4. Within the inner loop over i, evaluate the inclusive-on-both-ends boundary condition: check whether x[i] <= xi <= x[i+1]; this is a closed-interval test using Python chained comparison so a query point exactly on a knot matches the first qualifying segment → segment_found
5. When the condition is true, compute the linearly interpolated value yi using the formula yi = y[i] + (y[i+1] - y[i]) * (xi - x[i]) / (x[i+1] - x[i]), which scales the value range by the fractional position of xi within the segment [x[i], x[i+1]] → yi
6. Append the computed yi to y_interp → y_interp
7. Break out of the inner loop immediately after appending, ensuring exactly one interpolated value is produced per query point and preventing a knot-boundary point from matching a second adjacent segment → None
8. After all query points have been processed, return y_interp → y_interp
   ? The inner loop exhausts all segments without finding a match; no value is appended to y_interp for this xi, so the output list will contain fewer entries than x_interp

## interpolate_2d(x: list, y: list, z: list[list], x_interp: list, y_interp: list) → list
Summary: Performs bilinear interpolation on a 2D grid by locating the enclosing grid cell for each query point via linear scan and computing a weighted average of the four surrounding corner values.
#   x: list — Sorted 1D list of grid x-coordinates (grid column boundaries)
#   y: list — Sorted 1D list of grid y-coordinates (grid row boundaries)
#   z: list[list] — 2D list of grid values where z[i][j] is the value at grid point (x[i], y[j])
#   x_interp: list — List of x-coordinates of query points to interpolate
#   y_interp: list — List of y-coordinates of query points to interpolate, paired element-wise with x_interp
#   → z_interp: list — List of interpolated z-values for each query point that falls within the grid bounds; points outside the grid are silently omitted, so the output may be shorter than the input lists
1. Initialize z_interp as an empty list to accumulate interpolated results. → z_interp
2. Begin outer loop: iterate over each query point by pairing corresponding elements from x_interp and y_interp using zip, binding the current query coordinates to xi and yi. → xi,
3. Within the outer loop over (xi, yi), begin inner loop over i from 0 to len(x)-2 inclusive, scanning x-intervals left-to-right to find the interval containing xi. → i
4. Within the loop over i, check the inclusive boundary condition x[i] <= xi <= x[i+1] using Python chained comparison; if false, continue to the next i. → x_interval_found
5. When x[i] <= xi <= x[i+1] is satisfied, begin inner loop over j from 0 to len(y)-2 inclusive, scanning y-intervals to find the interval containing yi. → j
6. Within the loop over j, check the inclusive boundary condition y[j] <= yi <= y[j+1] using Python chained comparison; if false, continue to the next j. → y_interval_found
7. When y[j] <= yi <= y[j+1] is satisfied, retrieve the four corner values of the enclosing grid cell: z00 = z[i][j], z01 = z[i][j+1], z10 = z[i+1][j], z11 = z[i+1][j+1]. → z00,
8. Compute the bilinearly interpolated value zi using area-weighted averaging: zi = (z00 * (x[i+1] - xi) * (y[j+1] - yi) + z10 * (xi - x[i]) * (y[j+1] - yi) + z01 * (x[i+1] - xi) * (yi - y[j]) + z11 * (xi - x[i]) * (yi - y[j])) divided by ((x[i+1] - x[i]) * (y[j+1] - y[j])); each corner weight is proportional to the area of the diagonally opposite sub-rectangle. → zi
9. Append zi to z_interp. → z_interp
10. Execute break to exit the j loop immediately after the matching y-interval is found and processed, skipping remaining y-intervals for this query point. → j_loop_exited
11. Execute break to exit the i loop immediately after the matching x-interval is found and processed, skipping remaining x-intervals for this query point. → i_loop_exited
12. After all query points have been processed, return z_interp. → z_interp
   ? The i loop or j loop completes without a matching interval, no break fires, nothing is appended to z_interp, and execution continues silently with the next query point; no error or placeholder is emitted for this out-of-bounds point.
