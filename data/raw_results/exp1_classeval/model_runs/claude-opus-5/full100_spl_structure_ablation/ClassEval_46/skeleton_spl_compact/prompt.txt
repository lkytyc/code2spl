2. Begin outer loop: iterate over each query point xi in x_interp → xi
3. Within the outer loop over xi, begin inner loop: iterate over segment index i from 0 through len(x)-2 inclusive, covering all len(x)-1 consecutive segments → i
4. Within the inner loop over i, evaluate the inclusive-on-both-ends boundary condition: check whether x[i] <= xi <= x[i+1]; this is a closed-interval test using Python chained comparison so a query point exactly on a knot matches the first qualifying segment → segment_found

6. Append the computed yi to y_interp → y_interp
7. Break out of the inner loop immediately after appending, ensuring exactly one interpolated value is produced per query point and preventing a knot-boundary point from matching a second adjacent segment → None

4. Within the loop over i, check the inclusive boundary condition x[i] <= xi <= x[i+1] using Python chained comparison; if false, continue to the next i. → x_interval_found
5. When x[i] <= xi <= x[i+1] is satisfied, begin inner loop over j from 0 to len(y)-2 inclusive, scanning y-intervals to find the interval containing yi. → j
