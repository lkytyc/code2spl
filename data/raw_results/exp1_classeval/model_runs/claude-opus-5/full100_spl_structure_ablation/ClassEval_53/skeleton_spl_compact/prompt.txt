Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of the same class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

## find_longest_word(self: object, sentence: string) → string
Summary: Finds and returns the longest word from a sentence that exists in the instance's word list, after normalizing the input to lowercase and stripping ASCII punctuation.
#   self: object — Instance containing word_list, a collection of valid vocabulary words used for membership testing
#   sentence: string — Raw input sentence to search; must be a non-None string or .lower() will raise AttributeError
#   → longest_word: string — The first vocabulary word in the tokenized sentence with the strictly greatest length; returns empty string if no vocabulary word is found
1. Initialize longest_word to empty string as the sentinel baseline; any non-empty vocabulary word found later will strictly exceed its length of zero → longest_word
2. Overwrite sentence with its lowercase form by calling sentence.lower(); the original casing is permanently lost after this step → sentence
3. Overwrite sentence by applying re.sub with pattern '[%s]' % re.escape(string.punctuation) and replacement '' to strip all ASCII punctuation characters; Unicode punctuation is not affected → sentence
4. Overwrite sentence by calling re.split(' ', sentence) to tokenize on a single literal space, producing a list of word strings; consecutive spaces will produce empty string tokens in the list, and sentence changes type from string to list → sentence
5. Iterate over each word in sentence (the token list); for each word, evaluate the short-circuit compound condition: first check word in self.word_list (membership test, left clause); only if true, check len(word) > len(longest_word) (strict greater-than, exclusive boundary, right clause) → loop_iteration
6. Within the for loop over sentence, when both clauses of the compound condition are true, overwrite longest_word with the current word; ties are broken in favor of the first qualifying occurrence because the boundary is strict and later equal-length words do not satisfy len(word) > len(longest_word) → longest_word
7. Return longest_word after the loop completes; if no word in sentence passed both conditions, the returned value is the initial empty string → return
