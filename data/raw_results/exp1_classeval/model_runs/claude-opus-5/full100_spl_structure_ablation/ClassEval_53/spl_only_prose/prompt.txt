Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

Class specification:

# Class: LongestWord
# Fields: word_list
# Calls: find_longest_word→word_list

## __init__()
Summary: Initializes a new instance by setting up an empty word list as the sole instance attribute.
1. Initialize the instance attribute word_list as an empty list on self → self.word_list

## add_word(word: any)
Summary: Appends the given word to the instance's word list.
#   word: any — The word to be appended to the word list
1. Append word to self.word_list using the list's append method → self.word_list

## find_longest_word(self: object, sentence: string) → string
Summary: Finds and returns the longest word from a sentence that exists in the instance's word list, after normalizing the input to lowercase and stripping ASCII punctuation.
#   self: object — Instance containing word_list, a collection of valid vocabulary words used for membership testing
#   sentence: string — Raw input sentence to search; must be a non-None string or .lower() will raise AttributeError
#   → longest_word: string — The first vocabulary word in the tokenized sentence with the strictly greatest length; returns empty string if no vocabulary word is found
1. Initialize longest_word to empty string as the sentinel baseline; any non-empty vocabulary word found later will strictly exceed its length of zero → longest_word
2. Overwrite sentence with its lowercase form by calling sentence.lower(); the original casing is permanently lost after this step → sentence
3. Overwrite sentence by applying re.sub with pattern '[%s]' % re.escape(string.punctuation) and replacement '' to strip all ASCII punctuation characters; Unicode punctuation is not affected → sentence
4. Overwrite sentence by calling re.split(' ', sentence) to tokenize on a single literal space, producing a list of word strings; consecutive spaces will produce empty string tokens in the list, and sentence changes type from string to list → sentence
5. Iterate over each word in sentence (the token list); for each word, evaluate the short-circuit compound condition: first check word in self.word_list (membership test, left clause); only if true, check len(word) > len(longest_word) (strict greater-than, exclusive boundary, right clause) → loop_iteration
6. Within the for loop over sentence, when both clauses of the compound condition are true, overwrite longest_word with the current word; ties are broken in favor of the first qualifying occurrence because the boundary is strict and later equal-length words do not satisfy len(word) > len(longest_word) → longest_word
7. Return longest_word after the loop completes; if no word in sentence passed both conditions, the returned value is the initial empty string → return
