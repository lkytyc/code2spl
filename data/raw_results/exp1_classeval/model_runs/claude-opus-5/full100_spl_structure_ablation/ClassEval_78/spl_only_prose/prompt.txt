Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

## count_words(sentence: str) → int
Summary: Strips all non-alphabetic, non-whitespace characters from a sentence using a regex substitution, then splits the cleaned string on whitespace and returns the number of resulting tokens.
#   sentence: str — The input string to count words in; may contain letters, digits, punctuation, whitespace, or Unicode characters
#   → result: int — The count of whitespace-delimited alpha-only tokens remaining after punctuation and non-letter characters are removed; returns 0 for empty, whitespace-only, or purely non-alphabetic input
1. Apply re.sub with pattern '[^a-zA-Z\s]' and replacement '' to sentence, rebinding sentence to the resulting string with all non-ASCII-letter, non-whitespace characters removed; digits, punctuation, and non-ASCII Unicode characters are stripped while letters and whitespace are preserved → sentence
2. Call sentence.split() with no arguments on the cleaned sentence value, splitting on any whitespace sequence and discarding all leading, trailing, and consecutive whitespace, yielding a list of alpha-only tokens with no empty strings → words
3. Return len(words), the integer count of tokens in the words list → return_value
   ? re.sub produces an empty string or the same whitespace-only string; sentence.split() then returns []; len([]) evaluates to 0 and is returned
   ? re.sub strips all characters, producing an empty string; sentence.split() returns []; len([]) evaluates to 0 and is returned
   ? re.sub strips non-ASCII characters because the pattern '[^a-zA-Z\s]' matches only ASCII letters; for example 'é' is removed, leaving only the ASCII-letter portion of each word; the partially stripped tokens are then split and counted

## process_text_file(sentences_string: string) → integer
Summary: Splits an input string into sentences, then returns the word count of the longest sentence.
#   sentences_string: string — Raw text input to be split into individual sentences
#   → max_count: integer — The highest word count found across all sentences; returns 0 if the input produces no sentences
1. Call self.split_sentences with sentences_string as the argument and store the returned list of sentence strings in sentences → sentences
2. Initialize max_count to the integer literal 0, establishing the floor value for the running maximum before any comparisons occur → max_count
3. Begin iterating over every element in sentences; for each iteration bind the current element to sentence — no early exit exists, so every sentence is always visited → sentence
4. Within the for loop over sentences, call self.count_words with sentence as the argument unconditionally on each iteration and store the result in count → count
5. Within the for loop over sentences, evaluate the strict greater-than condition count > max_count; if and only if count strictly exceeds max_count (ties preserve the existing incumbent), update max_count to count → max_count
6. After the loop completes, return max_count as the final result; if sentences was empty the loop never executed and max_count retains the value 0 → max_count

## split_sentences(self: object, sentences_string: str) → list[str]
Summary: Splits a raw string into a list of sentence substrings by breaking on whitespace that follows a period or question mark, while using negative lookbehinds to avoid splitting on common abbreviations and title prefixes.
#   self: object — The enclosing class instance; not used within the method body.
#   sentences_string: str — A plain string containing one or more sentences to be split; must be defined by the caller before this method is invoked.
#   → sentences: list[str] — A list of sentence-like substrings extracted from sentences_string; contains the whole string as a single element when no split point matches, or a one-element list containing an empty string when the input is empty.
1. Apply re.split to sentences_string using a pattern that requires all three of the following conditions to be true at the split point: (1) positive lookbehind asserting the immediately preceding character is '.' or '?'; (2) negative lookbehind asserting the four characters before the split point do not match the pattern \w\.\w followed by any character, to avoid splitting inside abbreviations such as e.g. or i.e.; (3) negative lookbehind asserting the three characters before the split point do not match an uppercase letter followed by a lowercase letter followed by a period, to avoid splitting after title abbreviations such as Mr. or Dr.; consume exactly one whitespace character (\s) at the split point, which is removed from all output tokens. → sentences
2. Return sentences to the caller. → return
   ? re.split finds no split points and returns a list containing one empty string; assign that single-element list to sentences and return it.
   ? re.split returns a single-element list containing the entire original string unchanged; assign that to sentences and return it.
   ? The positive lookbehind (?<=\.|\?) never matches at that position, so no split occurs there; the exclamation-mark or semicolon-terminated segment is merged with the next sentence in the output list.
   ? \s matches exactly one whitespace character; only that one character is consumed as the delimiter, leaving any additional leading whitespace attached to the start of the following token in sentences.
