Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

## rail_fence_decipher(encrypted_text: string, rails: integer) → string
Summary: Deciphers a rail fence cipher by reconstructing the zigzag grid pattern from the encrypted text and reading characters back in diagonal traversal order to recover the original plaintext.
#   encrypted_text: string — The ciphertext string to be deciphered; its length determines the number of columns in the rail fence grid.
#   rails: integer — The number of rails (rows) used in the rail fence cipher; must be at least 2 for a valid zigzag pattern.
#   → plain_text: string — The recovered plaintext string produced by reading the populated rail fence grid in zigzag traversal order.
1. Initialize a 2D list 'fence' of dimensions rails × len(encrypted_text), filling every cell with the newline character '\n' as an unvisited sentinel placeholder; set 'direction' to -1, and set both 'row' and 'col' to 0. → fence,
2. Iterate exactly len(encrypted_text) times: at the start of each iteration, if row equals 0 or row equals rails - 1 (inclusive boundary check on both ends), negate 'direction' to reverse the zigzag; then overwrite fence[row][col] with an empty string '' to mark that position as a slot belonging to the zigzag path; increment col by 1; add 'direction' to 'row' to advance the cursor diagonally. → fence
3. Initialize 'index' to 0 as a read cursor into encrypted_text. → index
4. Iterate over each rail i from 0 to rails - 1 (outer loop); for each i, iterate over each column j from 0 to len(encrypted_text) - 1 (inner loop); if fence[i][j] equals '' (the slot marker set in the pattern-marking pass), assign encrypted_text[index] to fence[i][j] and increment index by 1; cells that do not equal '' are skipped with no action. → fence,
5. Initialize 'plain_text' to an empty string ''; reset 'direction' to -1; reset both 'row' and 'col' to 0. → plain_text,
6. Iterate exactly len(encrypted_text) times: at the start of each iteration, if row equals 0 or row equals rails - 1 (inclusive boundary check on both ends), negate 'direction'; then append fence[row][col] to 'plain_text'; increment col by 1; add 'direction' to 'row'. → plain_text
7. Return plain_text as the deciphered output. → plain_text

## vigenere_decipher(self: object, ciphertext: string) → string
Summary: Decrypts a Vigenère-ciphered string by reversing the cyclic key-based Caesar shifts for each alphabetic character while passing non-alphabetic characters through unchanged and preserving the original case of every letter.
#   self: object — Instance providing the decryption key via self.key, a non-empty string used cyclically during decryption
#   ciphertext: string — The encrypted input string whose alphabetic characters will be decrypted; may contain any mix of letters, digits, whitespace, and punctuation
#   → decrypted_text: string — The fully decrypted string with the same length and non-alphabetic structure as the input, with each letter shifted back by the corresponding cyclic key character and original case restored
1. Initialize accumulator variable decrypted_text to an empty string to hold the growing decrypted output → decrypted_text
2. Initialize cursor variable key_index to integer 0 to track the current position within the key, starting at the first key character → key_index
3. Iterate over each character char in ciphertext one at a time, processing the entire string from start to finish with no early exit → char
4. Within the for loop over ciphertext, test whether char is an alphabetic character using char.isalpha(); if true, execute the decryption path; if false, execute the passthrough path → is_alpha_branch
5. Within the for loop, on the decryption path (char.isalpha() is true), compute shift as the 0-based integer offset of the current key character by evaluating ord(self.key[key_index % len(self.key)].lower()) - ord('a'), where key_index % len(self.key) wraps cyclically through the key so the key repeats indefinitely → shift
6. Within the for loop, on the decryption path, compute decrypted_char as the character obtained by reversing the shift: evaluate chr((ord(char.lower()) - ord('a') - shift) % 26 + ord('a')), where subtracting shift and applying mod 26 correctly wraps through alphabet boundaries in both directions, yielding a lowercase letter → decrypted_char
7. Within the for loop, on the decryption path, append decrypted_char to decrypted_text in its original case: append decrypted_char.upper() if char.isupper() is true, otherwise append the lowercase decrypted_char as-is → decrypted_text
8. Within the for loop, on the decryption path, increment key_index by 1 to advance to the next key character; this increment occurs only for alphabetic characters so non-alphabetic characters do not consume a key position → key_index
9. Within the for loop, on the passthrough path (char.isalpha() is false), append char to decrypted_text unchanged without advancing key_index → decrypted_text
10. After the loop has processed all characters in ciphertext, return decrypted_text as the final decrypted result → return
