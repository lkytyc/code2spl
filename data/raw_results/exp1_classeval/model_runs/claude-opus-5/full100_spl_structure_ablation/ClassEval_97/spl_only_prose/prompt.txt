Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

## __init__()
Summary: Initializes the number-word parser by building a registry mapping English numeric words and the conjunction 'and' to (multiplier, offset) tuples, and by setting up two-tier ordinal handling with an irregular-word dictionary and an ordered suffix-stripping list.
1. Initialize self.numwords as an empty dict to serve as the central registry mapping word strings to (multiplier, offset) tuples → self.numwords
2. Initialize self.units as a list of 20 strings representing zero through nineteen, index-aligned so units[0] == 'zero' and units[19] == 'nineteen' → self.units
3. Initialize self.tens as a list of 10 strings where indices 0 and 1 are empty string placeholders and meaningful values begin at index 2 with 'twenty' through index 9 with 'ninety' → self.tens
4. Initialize self.scales as a list of 5 strings: ['hundred', 'thousand', 'million', 'billion', 'trillion'], indexed 0 through 4 → self.scales
5. Assign self.numwords['and'] = (1, 0) as a neutral pass-through sentinel entry — multiplier 1 and additive offset 0 — making it the first entry in the previously empty registry → self.numwords["and"]
6. For each (idx, word) in enumerate(self.units), assign self.numwords[word] = (1, idx) so that each unit word maps to a tuple with multiplier 1 and additive offset equal to its list index → self.numwords
7. For each (idx, word) in enumerate(self.tens), assign self.numwords[word] = (1, idx * 10) so that each tens word maps to a tuple with multiplier 1 and additive offset equal to its index times 10; note that indices 0 and 1 map to empty strings and produce offsets 0 and 10 respectively but are not meaningful entries → self.numwords
8. For each (idx, word) in enumerate(self.scales), assign self.numwords[word] = (10 ** (idx * 3 or 2), 0); because idx * 3 evaluates to 0 when idx == 0, the expression uses 'or 2' so 'hundred' at index 0 gets multiplier 10 ** 2 == 100 rather than 10 ** 0 == 1; subsequent scales get 10 ** 3 == 1000, 10 ** 6, 10 ** 9, and 10 ** 12 respectively, all with additive offset 0 → self.numwords
9. Initialize self.ordinal_words as a dict mapping the 7 irregular English ordinal strings to their integer values: 'first'->1, 'second'->2, 'third'->3, 'fifth'->5, 'eighth'->8, 'ninth'->9, 'twelfth'->12; regular ordinals are intentionally absent because they are handled by suffix stripping → self.ordinal_words
10. Initialize self.ordinal_endings as an ordered list of two (suffix, replacement) pairs: [('ieth', 'y'), ('th', '')]; the longer suffix 'ieth' is placed first so that words like 'twentieth' are correctly stripped to 'twenty' before the shorter 'th' rule can misfire and produce 'twentie' → self.ordinal_endings

## is_valid_input(self: object, textnum: string) → boolean
Summary: Validates whether a text string consists entirely of recognizable number words by normalizing hyphens to spaces, skipping known ordinal words, attempting to strip ordinal suffixes from remaining tokens, and returning false immediately if any token cannot be resolved to a known number word.
#   self: object — Instance providing ordinal_words (set of recognized ordinal word strings), ordinal_endings (list of (ending, replacement) tuples for suffix normalization), and numwords (set or mapping of recognized number word strings)
#   textnum: string — The text representation of a number to validate, potentially containing hyphen-separated tokens such as 'one-hundred-twenty'
#   → result: boolean — True if every token in the normalized input resolves to a recognized number word or ordinal word; False if any token fails resolution
1. Replace all occurrences of '-' with ' ' in textnum and rebind textnum to the resulting string, unconditionally normalizing hyphen-separated tokens into space-separated tokens → textnum
2. Split textnum on whitespace to produce the list of tokens to validate, then begin iterating over each token as 'word' → word_iterator
3. For each word in the token list: check whether word is a member of self.ordinal_words; if it is, skip all remaining processing for this word and advance to the next token via continue → ordinal_skip_decision
4. For each word not in self.ordinal_words: iterate over every (ending, replacement) pair in self.ordinal_endings; for each pair, check whether word ends with that ending string → suffix_match_decision
5. Within the suffix-matching inner loop, if word ends with the current ending, rewrite word to the concatenation of word[:-len(ending)] and replacement, then continue iterating over the remaining endings without breaking (soft first-match: the rewritten word may still be tested against further endings) → word
6. After the inner endings loop completes for the current word (whether or not any suffix was matched and word was rewritten), check whether the current value of word is absent from self.numwords; if it is absent, immediately return False, terminating the entire function → early_return_false
7. If all tokens have been processed without triggering an early return, return True to indicate the entire input is composed of valid number words → return_true
   ? str.replace returns the original string unchanged; textnum is rebound to an equal string and processing continues normally with no effect on subsequent token splitting
   ? The outer for loop body never executes; control falls through directly to the return True statement at the end of the method
   ? The inner loop continues past the first match without a break, so the rewritten word is tested against subsequent endings; if another ending matches, word is rewritten again; the final value of word after the loop completes is then checked against self.numwords

## text2int(textnum: string) → string
Summary: Converts a string containing spelled-out number words (including ordinal forms) into a string where those numeric spans are replaced by their integer equivalents, leaving non-numeric words in place.
#   textnum: string — Input string potentially containing spelled-out numbers, ordinal words, ordinal-suffixed tokens (e.g. '21st'), and arbitrary non-numeric text, with hyphenated number forms permitted.
#   → curstring: string — Reconstructed string in which each contiguous span of recognized number words has been replaced by its integer value as a string literal; non-numeric words are preserved with a trailing space, and the final numeric value (if the string ends mid-number) is appended without a trailing space.
1. Replace every hyphen character in textnum with a space so that hyphenated compound number words such as 'twenty-one' are treated as two separate tokens during subsequent splitting. → textnum
2. Initialize numeric accumulators: set current to 0 and result to 0 via chained assignment. Initialize curstring to the empty string as the output buffer. Initialize onnumber to False as the boolean mode flag tracking whether the parser is currently inside a numeric word sequence. → current,
3. Split textnum on whitespace to produce a list of tokens, then iterate over each token as word. → word
4. Within the outer for loop: check whether word is a key in self.ordinal_words (the table of pure ordinal words such as 'first', 'third'). If it is, retrieve the corresponding value as increment, set scale to 1, update current by computing current * scale + increment (which simplifies to current + increment because scale is always 1 in this branch), and set onnumber to True. Then advance to the next token. → current,
5. Within the outer for loop, in the else branch (word was not found in self.ordinal_words): iterate over every (ending, replacement) pair in self.ordinal_endings. For each pair, if word ends with that ending, rewrite word by stripping the ending suffix and appending replacement in its place. No break is issued, so all pairs are tested; in practice the endings are mutually exclusive. This normalizes tokens such as '21st' into a form that can be looked up in self.numwords. → word
6. Still within the else branch, after the ordinal-suffix normalization loop: check whether the (possibly rewritten) word is absent from self.numwords. If it is absent, the token is non-numeric text: if onnumber is True, flush the accumulated number by appending repr(result + current) followed by a space to curstring; then append word followed by a space to curstring; reset result to 0, current to 0, and onnumber to False. Then advance to the next token. → curstring,
7. Still within the else branch, in the inner else (word was found in self.numwords): retrieve (scale, increment) from self.numwords[word]. Apply the scale-and-increment accumulation: update current by computing current * scale + increment. If scale is greater than 100 (indicating a large-magnitude word such as 'thousand' or 'million'), add current into result and reset current to 0. Set onnumber to True. Then advance to the next token. → current,
8. After the outer for loop ends: if onnumber is True (the string ended while a numeric sequence was still open), append repr(result + current) to curstring with no trailing space. → curstring
9. Return curstring as the final transformed string. → curstring
