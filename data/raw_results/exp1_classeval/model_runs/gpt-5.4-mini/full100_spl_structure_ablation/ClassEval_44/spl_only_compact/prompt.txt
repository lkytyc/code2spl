Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

## extract_code_from_html_text(html_text: str) → list[str]
Summary: Extract code text from HTML by parsing pre and blockquote elements, then return the non-empty texts corresponding to detected code markers.
#   html_text: str — HTML content to inspect and extract code snippets from.
#   → result: list[str] — A list of extracted non-empty code texts, or an empty list when no code marker is present.
1. Format the input HTML text with self.format_line_html_text(html_text) and store the result in text_with_code_tag. → text_with_code_tag
2. Check whether self.CODE_MARK is absent from text_with_code_tag; if it is absent, return an empty list immediately. → []
3. Initialize code_index_start to 0, parse html_text with BeautifulSoup using the 'lxml' parser, collect all pre and blockquote elements into code_tag, count occurrences of self.CODE_MARK in text_with_code_tag as code_count, and initialize code_list as an empty list. → code_index_start,
4. Within the outer for loop over code_index from code_index_start to code_index_start + code_count exclusive, get the text of code_tag[code_index] and store it in code. → code
5. Within the same loop, if code is truthy, append it to code_list. → code_list
6. After the loop finishes, return code_list. → code_list

## format_line_html_text(html_text: string) → string
Summary: Parse HTML text, normalize code blocks, lists, and paragraphs into plain text with consistent punctuation, then decode HTML entities and format line breaks.
#   html_text: string — Input HTML content to normalize and convert into formatted text.
#   → result: string — Formatted plain-text output after HTML normalization, entity decoding, and line-feed processing.
1. If html_text is None or has length 0, return an empty string immediately. → ''
2. Parse html_text with BeautifulSoup using the lxml parser to create soup. → soup
3. Find all pre and blockquote elements in soup, then for each matched tag set its string content to self.CODE_MARK. → code_tag
4. Find all ul and ol elements in soup, then for each list container find all descendant li elements. → ul_ol_group
5. Within the outer loop over each ul or ol element, for each li element get its stripped text; if the text is empty, skip that item. → li_item_text
6. Within the nested list-item loop, if the stripped li text ends with punctuation, replace the item string with [-] followed by the original text and continue to the next li item. → li_item.string
7. Within the nested list-item loop, if the stripped li text does not end with punctuation, replace the item string with [-] followed by the text and a trailing period. → li_item.string
8. Find all p elements in soup, then for each paragraph get its stripped text and process only non-empty paragraphs. → p_group
9. Within the paragraph loop, if the paragraph text already ends with punctuation, leave it unchanged and continue to the next paragraph. → p_item.string
10. Within the paragraph loop, if the next sibling exists and its text contains self.CODE_MARK, append a colon to the paragraph text and continue to the next paragraph. → next_sibling
11. Within the paragraph loop, if the text is non-empty and does not end with punctuation and the next sibling does not indicate code, append a period to the paragraph text. → p_item.string
12. Extract the full text from soup and decode HTML entities with gensim.utils.decode_htmlentities to produce clean_text. → clean_text
13. Return the result of passing clean_text to self.__format_line_feed. → result
