Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

Class specification:

# Class: SplitSentence
# Calls: process_text_file→split_sentences, process_text_file→count_words

## count_words(self: object, sentence: string) → integer
Summary: Remove all non-letter and non-whitespace characters from the input sentence, split the cleaned text into words, and return the number of resulting tokens.
#   self: object — Instance reference used to access the method.
#   sentence: string — Input text to sanitize and count words from.
#   → result: integer — The number of whitespace-delimited words remaining after filtering.
1. Remove every character from sentence except uppercase letters, lowercase letters, and whitespace by applying the regular expression substitution with pattern [^a-zA-Z\s]. → sentence
2. Split the sanitized sentence on default whitespace to produce the list of words. → words
3. Return the number of words in the list. → result
   ? Treat the cleaned sentence as empty text after substitution.
   ? Split the empty text on whitespace, producing no words.
   ? Return zero as the word count.

## process_text_file(sentences_string: string) → integer
Summary: Split the input text into sentences, count the words in each sentence, and return the maximum word count found.
#   sentences_string: string — Input text to be split into sentences and analyzed.
#   → result: integer — The largest word count among all extracted sentences, or 0 if no sentence produces a larger count.
1. Split the input text into sentences using self.split_sentences(sentences_string). → sentences
2. Initialize max_count to 0 as the starting boundary value for the running maximum. → max_count
3. For each sentence in sentences, count the words in the current sentence using self.count_words(sentence). → count
4. Within the outer for loop over sentences, if count is strictly greater than max_count, update max_count to count. → max_count
5. After all sentences have been processed, return max_count. → result

## split_sentences(self: object, sentences_string: string) → list of strings
Summary: Split an input string into sentences using a regular expression that avoids common abbreviation patterns and splits only after periods or question marks followed by whitespace.
#   self: object — The instance owning the method.
#   sentences_string: string — The text to be split into a list of sentence fragments.
#   → result: list of strings — The list of sentence fragments produced by the regular-expression split.
1. Apply a regular-expression split to sentences_string using the pattern that avoids splitting after dotted abbreviations and short capitalized abbreviations, and splits only when a period or question mark is followed by whitespace. → sentences
2. Return the split sentence list. → sentences
