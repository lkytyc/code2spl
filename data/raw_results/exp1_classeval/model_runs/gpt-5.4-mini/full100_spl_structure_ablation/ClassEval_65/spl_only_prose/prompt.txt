Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

## format_string(self: object, x: string) → string
Summary: Formats a numeric string into a spoken zero-and-cents phrase by splitting the input around a decimal point, converting the integer part in three-digit groups, optionally converting the cents part, and returning 'ZERO ONLY' when the whole value is zero.
#   self: object — Instance providing trans_three, parse_more, and trans_two conversion helpers.
#   x: string — Input value to format; may contain a decimal point separating whole and fractional parts.
#   → result: string — Formatted phrase ending with ONLY, or ZERO ONLY when the whole-number portion is blank after processing.
1. Split the input string on the first decimal point, keep the first two parts only, and assign the whole-number part to lstr and the cents part to rstr, using an empty fallback when the decimal part is missing. → lstr,
2. Reverse the whole-number part into lstrrev so it can be processed in three-digit groups from least significant to most significant digits. → lstrrev
3. Initialize a five-element list a with empty strings as a working buffer for processed three-digit chunks. → a
4. If the length of lstrrev leaves remainder 1 when divided by 3, append "00" so the length becomes divisible by 3. → lstrrev
5. Else if the length of lstrrev leaves remainder 2 when divided by 3, append "0" so the length becomes divisible by 3. → lstrrev
6. Set lm to the empty string as the accumulator for the formatted whole-number phrase. → lm
7. Within the outer loop over i from 0 up to but not including len(lstrrev) // 3, extract the three-character chunk starting at 3 * i, reverse that chunk, and store it in a[i]. → a[i]
8. Within the same loop, if a[i] is not "000", prepend to lm the translated three-digit chunk, a space, the result of parse_more(i), another space, and the previous lm. → lm
9. Within the same loop, if a[i] is "000", append only the translated three-digit chunk to lm. → lm
10. Compute xs as "AND CENTS " followed by trans_two(rstr) and a trailing space when rstr is truthy; otherwise set xs to the empty string. → xs
11. If lm is empty after trimming whitespace, return "ZERO ONLY" immediately. → result
12. Otherwise, return the trimmed whole-number phrase, followed by xs, and then "ONLY". → result

## trans_three(self: object, s: string) → string
Summary: Converts a three-digit numeric string into words by handling a leading zero, exact hundreds, or hundreds with a remainder.
#   self: object — Instance providing the NUMBER lookup and the trans_two helper.
#   s: string — Three-character numeric string to convert.
#   → result: string — Spelled-out representation of the input as a hundred-based number phrase.

3. If neither previous condition matches, return the word for the first digit from NUMBER followed by " HUNDRED AND " and the result of trans_two on s[1:]. → result

## trans_two(s: str) → str
Summary: Convert a zero-padded two-digit string into its English number-word representation by handling leading zero, teen, exact tens, and mixed tens-and-ones cases.
#   s: str — A numeric string that is left-padded with zeros to at least two characters before conversion.
#   → result: str — The English word representation of the two-digit number.
1. Pad the input string on the left with zeros to ensure it is at least 2 characters long. → s
2. If the first character of the padded string is 0, return the word for the last digit from NUMBER. → result
3. Else if the first character of the padded string is 1, return the teen word from NUMBER_TEEN using int(s) - 10 as the index. → result
4. Else if the second character of the padded string is 0, return the tens word from NUMBER_TEN using int(s[0]) - 1 as the index. → result
5. Otherwise, return the tens word from NUMBER_TEN using int(s[0]) - 1, followed by a space, followed by the ones word from NUMBER using int(s[-1]) as the index. → result
