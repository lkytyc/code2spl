Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

# Class: Statistics3

## correlation(x: sequence of numbers, y: sequence of numbers) → number or null
Summary: Compute the Pearson correlation coefficient between two numeric sequences using mean-centered sums, returning None when the denominator is zero.
#   x: sequence of numbers — First input sequence used to compute the mean and x-side variance-like sum.
#   y: sequence of numbers — Second input sequence used to compute the mean and y-side variance-like sum.
#   → result: number or null — The correlation coefficient as numerator divided by denominator, or None if the denominator is zero.
1. Compute n as the length of x. → n
2. Compute mean_x as the sum of x divided by n. → mean_x
3. Compute mean_y as the sum of y divided by n. → mean_y
4. Compute numerator as the sum over paired elements from x and y of (xi - mean_x) * (yi - mean_y) using zip(x, y). → numerator
5. Compute denominator as the square root of the product of the x-side centered sum of squares and the y-side centered sum of squares. → denominator
6. If denominator is zero, return None. → None
7. Otherwise, return numerator divided by denominator. → result
   ? Return None instead of dividing.
   ! log: "Division by zero occurs during mean calculation because x is empty."
   ! raise: ZeroDivisionError "Raised when dividing by n while n equals 0."

## correlation_matrix(data: list) → list
Summary: Build a square correlation matrix by computing the pairwise correlation of every column in the input data against every other column.
#   data: list — A two-dimensional collection of rows where each row contains column values.
#   → result: list — A square matrix of correlation values, one row per input column.
1. Initialize matrix as an empty list to hold the completed correlation rows. → matrix
2. For each column index i from 0 up to, but not including, len(data[0]), create a new empty row for the current output row. → row
3. Within the outer for loop over i, for each column index j from 0 up to, but not including, len(data[0]), collect column1 as the values at index i from every row in data and collect column2 as the values at index j from every row in data. → column1,
4. Within the nested loops over i and j, compute the correlation of column1 and column2 using Statistics3.correlation. → correlation
5. Within the nested loops over i and j, append the computed correlation to the current row. → row
6. After finishing all j iterations for the current i, append the completed row to matrix. → matrix
7. After all outer loop iterations complete, return matrix. → result

## mean(data: iterable of numeric values) → numeric or null
Summary: Return None for an empty input list, otherwise compute and return the arithmetic mean of the data.
#   data: iterable of numeric values — Input collection whose average is computed, or which may be empty.
#   → result: numeric or null — The arithmetic mean of the input data, or None when the input is empty.
1. Check whether the input data has length equal to 0. → empty_check
2. If the input is empty, return None immediately as a guard clause. → None
3. Otherwise, compute the sum of all values in data and divide it by len(data) to produce the arithmetic mean. → mean

## median(data: sequence) → number
Summary: Return the median of the input data by sorting it first, then selecting the middle element for odd lengths or averaging the two middle elements for even lengths.
#   data: sequence — Input collection of values to be sorted and used for median calculation.
#   → result: number — The median value of the input data, returned as the middle element or the average of the two middle elements.
1. Create a new sorted sequence from the input data without modifying the original collection. → sorted_data
2. Compute the length of the sorted sequence so the total number of elements is available for parity checking. → n
3. Check whether n is odd by evaluating n % 2 == 1. → parity_check
   ? Within the odd-length branch, return the element at index n // 2 from the sorted sequence as the single middle value.
   ? Within the even-length branch, return the average of the elements at indices n // 2 - 1 and n // 2 from the sorted sequence as the median.

## mode(data: sequence) → list
Summary: Return all input values that occur with the highest frequency in the data sequence.
#   data: sequence — Iterable of values to count and analyze for the most frequent value(s).
#   → result: list — A list of all values whose count matches the maximum frequency in the input data.
1. Initialize an empty dictionary named counts to store frequency totals for each input value. → counts
2. Iterate through each value in data and increment that value's entry in counts by 1, using 0 as the default when the value is first seen. → counts
3. Compute max_count as the maximum of all frequency values currently stored in counts. → max_count
4. Build mode_values as a list of every key from counts whose associated count is equal to max_count. → mode_values
5. Return mode_values as the final result. → mode_values
   ! log: "max() cannot be applied to an empty counts collection."
   ! raise: ValueError "Raised by max() when no frequency values are available."

## standard_deviation(data: sequence of numbers) → number or null
Summary: Computes the sample standard deviation of the input data by returning None for fewer than two values, otherwise calculating the mean, sample variance, and square root of the variance.
#   data: sequence of numbers — Input collection used to compute the sample standard deviation.
#   → result: number or null — The sample standard deviation, or None when the input has fewer than two elements.
1. Compute the number of items in data and store it in n. → n
2. If n is less than 2, return None immediately. → None
3. Compute the mean of data using Statistics3.mean and store it in mean_value. → mean_value
4. For each x in data, compute the squared deviation (x - mean_value) ** 2, sum all squared deviations, and divide by n - 1 to obtain the sample variance. → variance
5. Compute the square root of variance using math.sqrt and return the result. → result

## z_score(data: sequence of numbers) → list of numbers or null
Summary: Computes the z-score for each value in the input data using the dataset mean and standard deviation, returning None when the standard deviation is missing or zero.
#   data: sequence of numbers — Input dataset used to compute the mean, standard deviation, and standardized values.
#   → result: list of numbers or null — A list of z-score values for each input item, or None if standard deviation is None or 0.
1. Compute the mean of the input data using Statistics3.mean(data). → mean
2. Compute the standard deviation of the input data using Statistics3.standard_deviation(data). → std_deviation
3. If std_deviation is None or std_deviation equals 0, return None immediately. → None
4. Otherwise, return a list containing (x - mean) / std_deviation for each x in data. → result
