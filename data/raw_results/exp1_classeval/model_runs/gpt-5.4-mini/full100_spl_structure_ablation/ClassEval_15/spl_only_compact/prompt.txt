Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

## bad_character_heuristic()
Summary: Scan each valid text alignment, record positions where no mismatch is found, and otherwise attempt to compute a shifted alignment from the mismatch character.
1. Initialize an empty list named positions to collect matching start indices. → positions
2. For each i from 0 through self.textLen - self.patLen inclusive, call self.mismatch_in_text(i) to find the first mismatch position for the current alignment. → mismatch_index
3. Within the outer for loop, if mismatch_index equals -1, append the current i to positions because the pattern matches at this alignment. → positions
4. Within the outer for loop, if mismatch_index is not -1, look up the current text character with self.text[mismatch_index] and pass it to self.match_in_pattern(...) to obtain a pattern index. → match_index
5. Within the outer for loop, if mismatch_index is not -1, assign i to mismatch_index - match_index as an attempted bad-character shift, even though changing i inside a Python for loop does not affect the next range value. → i
6. After all loop iterations complete, return positions. → positions

## match_in_pattern(self: object, char: character) → integer
Summary: Search backward through the pattern for the rightmost occurrence of the given character and return its index, or return -1 if no match is found.
#   self: object — Object containing the pattern sequence and its length.
#   char: character — Character to search for in the pattern.
#   → result: integer — The index of the first match found when scanning from the end, or -1 if the character is not present.
1. Within the reverse for loop over i from self.patLen - 1 down to 0 inclusive, compare char with self.pattern[i]. → comparison_result
2. If char equals self.pattern[i], return i immediately as the rightmost matching index. → i
3. If the loop completes without finding any match, return -1. → -1

## mismatch_in_text(self: object, currentPos: integer) → integer
Summary: Scans the pattern from end to start and returns the text index of the first mismatching character, or -1 if the pattern fully matches.
#   self: object — Instance providing pattern, text, and patLen.
#   currentPos: integer — Starting position in text to compare against the pattern.
#   → result: integer — The index in text of the first mismatch, or -1 if no mismatch is found.
1. Initialize a reverse loop over pattern indices from self.patLen - 1 down to 0, inclusive, stepping by -1. → loop_started
2. Within the reverse loop, compare self.pattern[i] with self.text[currentPos + i]. → comparison_result
3. Within the reverse loop, if the two values differ, return currentPos + i immediately as the first mismatch position. → mismatch_index
4. If the reverse loop completes without any mismatch, return -1. → -1
