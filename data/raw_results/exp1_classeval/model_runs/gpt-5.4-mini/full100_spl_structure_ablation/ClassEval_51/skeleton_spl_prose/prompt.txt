## fleiss_kappa(N: int, k: int, n: numeric) → numeric matrix scalar
Summary: Computes Fleiss' kappa from a matrix of categorical ratings by accumulating per-item agreement, normalizing by item count, estimating expected agreement, and returning the final kappa value.
#   N: int — Number of items (outer-loop iterations and normalization divisor).
#   k: int — Number of categories/columns and the size of the one-vector.
#   n: numeric — Number of ratings per item used in the per-row agreement normalization.
#   → result: numeric matrix scalar — The Fleiss' kappa value returned as the single element at position [0, 0] of ans.

2. Initialize the running total sum and the accumulated agreement value P0 to 0.0. → sum,
3. For each i from 0 to N - 1, initialize temp to 0.0 and then, for each j from 0 to k - 1, add dataMat[i, j] to sum and add 1.0 * dataMat[i, j] ** 2 to temp. → sum,
4. Within the outer for loop over i, after the inner loop completes, subtract n from temp, divide temp by (n - 1) * n, and add the result to P0. → P0
5. After processing all rows, divide P0 by N using floating-point arithmetic. → P0
6. Compute ysum as the column-wise sum of dataMat along axis 0. → ysum
7. For each i from 0 to k - 1, replace ysum[0, i] with (ysum[0, i] / sum) ** 2. → ysum
8. Compute Pe as ysum multiplied by oneMat and then multiplied by 1.0. → Pe
9. Compute ans as (P0 - Pe) / (1 - Pe). → ans
10. Return ans[0, 0]. → result

## kappa(k: integer) → float
Summary: Computes Cohen's kappa coefficient from a confusion matrix by accumulating diagonal agreement, deriving expected agreement from row and column totals, and returning the normalized agreement score.
#   k: integer — Number of leading diagonal entries to include when summing observed agreement.
#   → result: float — The computed Cohen's kappa coefficient.
1. Convert testData into a NumPy matrix and initialize P0 to 0.0. → dataMat,
2. For each i from 0 up to but not including k, add dataMat[i, i] multiplied by 1.0 to P0. → P0
3. Compute the row-wise sum of dataMat with axis 1. → xsum
4. Compute the column-wise sum of dataMat with axis 0. → ysum
5. Compute the total sum of all elements in dataMat. → sum
6. Compute Pe as float(ysum * xsum) divided by sum and divided by sum again. → Pe
7. Overwrite P0 with float(P0 divided by sum multiplied by 1.0). → P0
8. Compute cohens_coefficient as float((P0 - Pe) divided by (1 - Pe)). → cohens_coefficient
9. Return cohens_coefficient. → cohens_coefficient
