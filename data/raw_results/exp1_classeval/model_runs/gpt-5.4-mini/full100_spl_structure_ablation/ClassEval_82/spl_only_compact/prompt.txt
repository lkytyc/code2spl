Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

## add_stock(stock: dict)

#   stock: dict — A stock record containing at least name and quantity fields.

4. If the loop finishes without finding a matching name, append the incoming stock to self.portfolio. → portfolio_appended

## buy_stock(stock: dict) → bool
Summary: Checks whether the stock purchase cost exceeds the available cash balance, and either rejects the purchase or adds the stock and deducts the cost.
#   stock: dict — A stock record containing at least price and quantity values used to compute the purchase cost.
#   → result: bool — Returns False when the stock cost is greater than the cash balance, otherwise returns True after updating holdings and cash.
1. Evaluate the total purchase cost as stock['price'] multiplied by stock['quantity']. → purchase_cost
2. Compare the purchase cost to self.cash_balance using a strict greater-than check. → is_too_expensive
3. If purchase_cost is greater than self.cash_balance, return False immediately without modifying holdings or cash. → rejected_purchase
4. Otherwise, add the stock by calling self.add_stock(stock). → updated_holdings
5. Within the accepted-purchase branch, subtract the same purchase cost from self.cash_balance. → updated_cash_balance
6. Return True to indicate the stock purchase succeeded. → successful_purchase

## calculate_portfolio_value(self: object) → number
Summary: Calculates the total portfolio value by starting with the cash balance and adding the market value of each stock position.
#   self: object — The instance containing cash balance and portfolio holdings.
#   → result: number — The total portfolio value including cash and all stock positions.
1. Initialize the running total from self.cash_balance. → total_value
2. Within the loop over self.portfolio, add each stock's price multiplied by its quantity to the running total. → total_value
3. Return the final accumulated total value. → total_value

## get_portfolio_summary() → tuple

#   → result: tuple — A tuple containing the total portfolio value and the list of per-stock summary dictionaries.

## get_stock_value(stock: mapping) → number

## remove_stock(self: object, stock: dict) → bool
Summary: Search through the portfolio for the first matching stock entry with sufficient quantity, subtract the requested amount, remove the entry if its quantity reaches zero, and return true on success or false if no match is found.
#   self: object — The owning object that contains the portfolio list.
#   stock: dict — The stock record to remove, expected to provide name and quantity fields.
#   → result: bool — True when a matching portfolio item is found and updated; otherwise false.

2. Within the portfolio iteration, check whether pf['name'] equals stock['name'] and pf['quantity'] is greater than or equal to stock['quantity'], using the inclusive boundary that allows equality. → match_and_sufficient_quantity

4. Within the successful match path, if pf['quantity'] becomes 0 after subtraction, remove pf from self.portfolio. → portfolio_updated
5. After updating the matching portfolio item, return true immediately so that only the first qualifying entry is modified. → true
6. If the loop finishes without finding any portfolio item that matches the name and has enough quantity, return false. → false

## sell_stock(stock: dict) → bool
Summary: Sells the given stock by first removing it from inventory, then adding its total sale value to the cash balance and returning success only if the removal succeeds.
#   stock: dict — Stock record containing at least price and quantity fields.
#   → result: bool — Returns False if stock removal fails; otherwise returns True after updating cash balance.
1. Call self.remove_stock(stock) and compare the result to False. → removal_failed
2. If removal_failed is true, return False immediately without changing cash_balance. → False
3. Otherwise, compute stock['price'] * stock['quantity'] and add the product to self.cash_balance. → updated_cash_balance
4. Return True to indicate the stock was sold successfully. → True
   ? Stop execution early and return False.
