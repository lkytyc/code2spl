Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

## add_dish(self: object, dish: dict) → bool
Summary: Checks the menu for a matching dish, rejects the request if the available count is too small, otherwise subtracts the requested count from the first matching menu item and records the dish as selected.
#   self: object — The instance containing the menu and selected dishes state.
#   dish: dict — The requested dish data, including at least a dish name under 'dish' and a requested quantity under 'count'.
#   → result: bool — Returns False if a matching menu dish has insufficient count; otherwise returns True after updating the menu and appending the dish to selected_dishes.
1. Iterate through each menu_dish in self.menu, preserving the original order. → menu_dish
2. Within the loop, compare dish["dish"] with menu_dish["dish"] to find the first menu item with the same dish name. → name_match
3. When a matching dish name is found, compare menu_dish["count"] with dish["count"] to determine whether the available count is less than the requested count. → enough_count_check
4. If menu_dish["count"] is less than dish["count"], return False immediately without changing self.menu or self.selected_dishes. → False
5. Otherwise, subtract dish["count"] from menu_dish["count"] to consume the requested quantity from the first matching menu item. → updated_count
6. Break out of the loop after the first successful update so no later menu items with the same name are modified. → loop_exit
7. After the loop finishes without an early failure, append dish to self.selected_dishes. → selected_dishes
8. Return True to indicate the dish was accepted and recorded. → True

## calculate_total(self: object) → number
Summary: Computes the total sales amount by summing each selected dish's price multiplied by its count and its corresponding sales factor.
#   self: object — An object containing selected_dishes and sales data.
#   → result: number — The computed total sales amount.
1. Initialize total to 0. → total
2. For each dish in self.selected_dishes, add dish["price"] times dish["count"] times self.sales[dish["dish"]] to total. → total
3. Return the final total. → total

## checkout(self: object) → bool or numeric
