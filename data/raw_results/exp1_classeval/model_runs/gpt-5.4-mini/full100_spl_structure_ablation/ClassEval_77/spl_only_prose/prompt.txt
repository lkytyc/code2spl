Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

#   SCREEN_WIDTH: number — Screen width used to store the playfield size and compute the initial centered position.
#   SCREEN_HEIGHT: number — Screen height used to store the playfield size and compute the initial centered position.
#   BLOCK_SIZE: number — Block size copied directly into the instance.
#   food_position: any — Initial food position assigned directly to the instance.
1. Set the instance length to the fixed default value 1. → self.length
2. Copy SCREEN_WIDTH into the instance screen width field. → self.SCREEN_WIDTH
3. Copy SCREEN_HEIGHT into the instance screen height field. → self.SCREEN_HEIGHT
4. Copy BLOCK_SIZE into the instance block size field. → self.BLOCK_SIZE
5. Initialize the instance positions list with one centered coordinate computed as SCREEN_WIDTH / 2 and SCREEN_HEIGHT / 2. → self.positions
6. Set the instance score to the fixed default value 0. → self.score
7. Assign the provided food_position directly to the instance food position field. → self.food_position

## eat_food(self: object) → null
Summary: Increments the snake's length and score, then triggers a new food position to be generated.
#   self: object — The game or snake instance whose length, score, and food position are updated.
#   → result: null — This method does not return a value.
1. Increase self.length by 1 to reflect that food was eaten. → self.length
2. Increase self.score by 100 to award points for eating the food. → self.score
3. Call self.random_food_position() to update the food location after consumption. → self.random_food_position()

## move(direction: tuple[int, int]) → None
Summary: Move the current position by one block in the given direction with screen wraparound, then handle food collection, self-collision reset, and body growth or trimming.
#   direction: tuple[int, int] — A two-element movement vector unpacked into x and y components.
#   → result: None — This method updates the object state in place and does not return a value.
1. Read the current head position from self.positions[0] and unpack the movement direction into x and y. → cur,
2. Compute the next wrapped position by adding x times self.BLOCK_SIZE to the current x-coordinate modulo self.SCREEN_WIDTH, and y times self.BLOCK_SIZE to the current y-coordinate modulo self.SCREEN_HEIGHT. → new
3. If the computed position equals self.food_position, call self.eat_food() before any body update logic. → food_checked
4. If self.positions has more than 2 elements and the new position appears in self.positions[2:], call self.reset() to handle self-collision. → collision_checked
5. Otherwise, insert the new position at the front of self.positions. → self.positions
6. Within the same non-collision path, if len(self.positions) is greater than self.length, remove the last position with pop() to keep the body within its maximum length. → self.positions

## random_food_position()
Summary: Repeatedly selects a random grid-aligned food position until it is not already occupied by an existing position.
1. While the current food position is present in self.positions, generate a new random grid-aligned coordinate for self.food_position using independent random integers for x and y within the inclusive range from 0 to SCREEN_WIDTH // BLOCK_SIZE - 1 and 0 to SCREEN_HEIGHT // BLOCK_SIZE - 1, then multiply each coordinate by BLOCK_SIZE. → self.food_position

## reset()
Summary: Reset the game state to a one-segment snake positioned at the screen center, clear the score, and place food at a new random location.
1. Set self.length to 1 to initialize the snake to its default size. → self.length
2. Set self.positions to a single-element list containing the centered starting position computed as self.SCREEN_WIDTH / 2 and self.SCREEN_HEIGHT / 2. → self.positions
3. Set self.score to 0 to reset the score to its default starting value. → self.score
4. Call self.random_food_position() to generate a new food position after resetting the game state. → self.random_food_position()
