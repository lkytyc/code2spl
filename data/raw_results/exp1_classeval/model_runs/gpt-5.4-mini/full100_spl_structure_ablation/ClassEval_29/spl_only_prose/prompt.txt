Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

Class specification:

# Class: DataStatistics

## mean(data: sequence of numeric values) → float
Summary: Computes the arithmetic mean of the input data and rounds the result to two decimal places.
#   data: sequence of numeric values — Collection of numbers to average.
#   → result: float — The rounded average of the input values to two decimal places.
1. Compute the sum of all numeric elements in data. → total
2. Compute the number of elements in data. → count
3. Divide total by count to obtain the arithmetic mean. → average
4. Round the average to 2 decimal places and return the rounded value. → result
   ! log: "Division by zero while computing the average from an empty data sequence."
   ! raise: ZeroDivisionError "Raised when attempting to divide the sum of data by zero elements."

## median(data: sequence of numbers) → number
Summary: Sort the input data, then return the median as the middle element for odd-length data or the rounded average of the two middle elements for even-length data.
#   data: sequence of numbers — Input values to be sorted and evaluated for the median.
#   → result: number — The median value of the input data, rounded to 2 decimal places only when the length is even.
1. Create a new sorted sequence from the input data without modifying the original input. → sorted_data
2. Compute the length of the sorted sequence. → n
3. Check whether n is even by testing n % 2 == 0. → parity_check
4. If n is even, set middle to n // 2, then return round((sorted_data[middle - 1] + sorted_data[middle]) / 2, 2) as the median. → result
5. If n is odd, set middle to n // 2, then return sorted_data[middle] as the median. → result

## mode(data: iterable) → list
Summary: Return all values that occur with the highest frequency in the given data.
#   data: iterable — Input collection whose element frequencies are counted.
#   → result: list — A list of all elements tied for the maximum frequency.
1. Build a frequency counter from the input data. → counter
2. Compute the highest occurrence count from the counter values. → mode_count
3. Collect every key in the counter whose count equals the highest occurrence count. → mode
4. Return the list of most frequent elements. → mode
