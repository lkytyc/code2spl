Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

# Class: DataStatistics4

## correlation_coefficient(data1: sequence of numbers, data2: sequence of numbers) → number
Summary: Compute the Pearson correlation coefficient from two input sequences by calculating their means, covariance numerator, and standard-deviation-based denominator, then return the ratio or 0 when the denominator is zero.
#   data1: sequence of numbers — First input sequence used to compute the mean, deviation sum, and one side of the denominator.
#   data2: sequence of numbers — Second input sequence used to compute the mean, deviation sum, and the other side of the denominator.
#   → result: number — The Pearson correlation coefficient, or 0 when the denominator is zero.
1. Compute n as the length of data1. → n
2. Compute mean1 as the sum of data1 divided by n. → mean1
3. Compute mean2 as the sum of data2 divided by n. → mean2
4. For each index i from 0 to n - 1, compute the product of data1[i] minus mean1 and data2[i] minus mean2, then sum all products into numerator. → numerator
5. For each index i from 0 to n - 1, compute the squared deviation of data1[i] from mean1 and sum the values; take the square root of that sum. → data1_scale
6. For each index i from 0 to n - 1, compute the squared deviation of data2[i] from mean2 and sum the values; take the square root of that sum. → data2_scale
7. Multiply the two square-root results to form the denominator. → denominator
8. If the denominator is not zero, return numerator divided by denominator; otherwise return 0. → result
   ? Return 0 instead of dividing by zero.

## kurtosis(data: sequence of numbers) → number
Summary: Compute the population kurtosis of the input data by calculating the mean, standard deviation, and fourth central moment, returning NaN when the standard deviation is zero.
#   data: sequence of numbers — Input values used to compute kurtosis.
#   → result: number — The excess kurtosis of the input data, or NaN when all values are identical.
1. Compute the number of elements in data and store it as n. → n
2. Compute the arithmetic mean of data by dividing the sum of data by n, and store it as mean. → mean
3. Compute the population standard deviation from the squared deviations of data around mean, dividing by n and taking the square root, then store it as std_dev. → std_dev
4. If std_dev is equal to 0, return math.nan immediately. → math.nan
5. Create centered_data by subtracting mean from each element of data. → centered_data
6. Compute fourth_moment as the average of the fourth powers of the values in centered_data, dividing by n. → fourth_moment
7. Compute kurtosis_value as (fourth_moment divided by std_dev raised to the fourth power) minus 3. → kurtosis_value
8. Return kurtosis_value. → kurtosis_value
   ? Return math.nan without computing centered_data, fourth_moment, or kurtosis_value.

## pdf(data: sequence of numbers, mu: number, sigma: number) → list of numbers
Summary: Compute and return the Gaussian probability density value for each input data point using the given mean and standard deviation.
#   data: sequence of numbers — Input values to evaluate with the normal density formula.
#   mu: number — Mean parameter used as the center of the Gaussian distribution.
#   sigma: number — Standard deviation parameter used as the scale of the Gaussian distribution.
#   → result: list of numbers — A list of Gaussian probability density values corresponding to each element in data.
1. For each value x in data, compute the Gaussian density using 1 / (sigma * sqrt(2 * pi)) multiplied by exp(-0.5 * ((x - mu) / sigma) squared). → pdf_values
2. Return the computed list of density values. → pdf_values
   ? Iterate over no elements and produce an empty result list.
   ? Return the empty list.
   ! log: "A division by zero occurs while evaluating the Gaussian density expression."
   ! raise: ZeroDivisionError "Raised when sigma is zero during normalization or inside the exponent term."

## skewness(data: sequence of numbers) → number
Summary: Compute the sample skewness of a numeric dataset using the mean, variance, and standard deviation, returning zero when the standard deviation is zero.
#   data: sequence of numbers — Input dataset used to compute the skewness statistic.
#   → result: number — The computed skewness value, or 0 when the standard deviation is zero.
1. Compute n as the length of data. → n
2. Compute mean as the sum of data divided by n. → mean
3. Compute variance as the average of squared deviations from mean over all values in data. → variance
4. Compute std_deviation as the square root of variance. → std_deviation
5. If std_deviation is not zero, compute skewness as the sum of cubed deviations from mean times n divided by (n - 1) * (n - 2) * std_deviation cubed; otherwise set skewness to 0. → skewness
6. Return skewness. → skewness
   ? Set skewness to 0 to avoid division by zero.
