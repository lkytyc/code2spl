Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

# Fields: sex, height, BMI_std, age, weight

#   sex: any — Sex value to store on the object.

## calculate_calorie_intake(self: object) → number
Summary: Calculate a calorie intake estimate by computing BMR from sex, weight, height, and age, then applying an activity-based multiplier.
#   self: object — Instance containing sex, weight, height, age, and a condition_judge method.
#   → result: number — The calculated calorie intake value.
1. Check whether self.sex is equal to "male". → sex_check
2. If self.sex is "male", compute BMR as 10 * self.weight + 6.25 * self.height - 5 * self.age + 5; otherwise compute BMR as 10 * self.weight + 6.25 * self.height - 5 * self.age - 161. → BMR
3. Evaluate self.condition_judge() for the first activity classification test. → condition_value
4. If self.condition_judge() equals 1, set calorie_intake to BMR * 1.2. → calorie_intake
5. Otherwise, evaluate self.condition_judge() again for the second activity classification test. → condition_value
6. If self.condition_judge() equals -1, set calorie_intake to BMR * 1.6; otherwise set calorie_intake to BMR * 1.4. → calorie_intake
7. Return calorie_intake. → result

## condition_judge(self: object) → int
Summary: This method computes a BMI value, selects the appropriate BMI range based on sex, and returns 1, -1, or 0 depending on whether the BMI is above, below, or within that range.
#   self: object — Instance providing get_BMI(), sex, and BMI_std.
#   → result: int — 1 if BMI is above the upper bound, -1 if below the lower bound, otherwise 0.
1. Call self.get_BMI() and store the returned value in BMI. → BMI
2. Check whether self.sex is exactly "male"; if it is, select self.BMI_std[0]["male"] as BMI_range, otherwise select self.BMI_std[1]["female"]. → BMI_range
3. Compare BMI against BMI_range[1]; if BMI is strictly greater than the upper bound, return 1 to indicate the BMI is too high. → 1
4. Otherwise, compare BMI against BMI_range[0]; if BMI is strictly less than the lower bound, return -1 to indicate the BMI is too low. → -1
5. Otherwise, return 0 to indicate the BMI is within the inclusive range from BMI_range[0] to BMI_range[1]. → 0

## get_BMI(self: object) → number
Summary: Returns the body mass index by dividing self.weight by self.height squared.
#   self: object — Object instance providing weight and height fields.
#   → result: number — The computed BMI value from weight divided by height squared.
1. Read self.weight as the numerator value. → weight
2. Read self.height and square it to produce the denominator value. → height_squared
3. Divide weight by height_squared and return the computed value immediately. → result
   ! log: "Division by zero occurs while computing BMI from weight and height squared."
   ! raise: ZeroDivisionError "Raised when the height value is zero."
