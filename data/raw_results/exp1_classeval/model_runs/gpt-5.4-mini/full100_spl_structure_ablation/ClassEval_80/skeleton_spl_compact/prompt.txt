Skeleton Role:
- The skeleton controls imports, class name, constructor shape, field names, method names, and method signatures.
- Preserve the skeleton API if skeleton and specification disagree.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of the same class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Step 1: Match each specification method section to its skeleton method by method name.

Step 2: Treat the skeleton as the public API contract and the specification as the implementation contract for method bodies.

Step 3: Build a class-level behavior map:

Step 4: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become if/elif/else blocks;
- `! raise:` steps become try/except or explicit raise only when entailed;
- `→` result names become local variables, fields, calls, or returned values.

Step 5: Keep the implementation minimal and executable. Do not add unrelated APIs or behavior outside the skeleton plus specification contract.

class SQLQueryBuilder:

    This class provides to build SQL queries, including SELECT, INSERT, UPDATE, and DELETE statements. 
    """


    @staticmethod
    def select(table, columns='*', where=None):
        """
        Generate the SELECT SQL statement from the given parameters.
        :param table: str, the query table in database.
        :param columns: list of str, ['col1', 'col2'].
        :param where: dict, {key1: value1, key2: value2 ...}. The query condition.
        return query: str, the SQL query statement.
        >>> SQLQueryBuilder.select('table1', columns = ["col1","col2"], where = {"age": 15})
        "SELECT col1, col2 FROM table1 WHERE age='15'"
        """

    @staticmethod
    def insert(table, data):
        """
        Generate the INSERT SQL statement from the given parameters.
        :param table: str, the table to be inserted in database.
        :param data: dict, the key and value in SQL insert statement
        :return query: str, the SQL insert statement.
        >>> SQLQueryBuilder.insert('table1', {'name': 'Test', 'age': 14})
        "INSERT INTO table1 (name, age) VALUES ('Test', '14')"
        """

    @staticmethod
    def delete(table, where=None):
        """
        Generate the DELETE SQL statement from the given parameters.
        :param table: str, the table that will be excuted with DELETE operation in database

        :return query: str, the SQL delete statement.
        >>> SQLQueryBuilder.delete('table1', {'name': 'Test', 'age': 14})
        "DELETE FROM table1 WHERE name='Test' AND age='14'"

    def update(table, data, where=None):
        """
        Generate the UPDATE SQL statement from the given parameters.
        :param table: str, the table that will be excuted with UPDATE operation in database

#   table: string — Target table name to insert into.

## select(table: any, columns: any, where: any) → string
Summary: Build a SQL SELECT query string from the given table name, optional column list, and optional WHERE conditions.
#   table: any — Table name to query from.
#   columns: any — Columns to select; defaults to '*' and is joined with commas if not wildcard.
#   where: any — Optional mapping of equality conditions to append with AND.
#   → result: string — A SQL SELECT query string.

2. Construct the base query string as SELECT followed by the resolved columns and the table name. → query
3. If a where mapping is provided and is truthy, append a WHERE clause made from each key-value pair formatted as key='value' and joined with ' AND '. → query
4. Return the final query string. → query

## update(table: any, data: dict, where: dict or null) → string
Summary: Build an SQL UPDATE statement from a table name, a dictionary of column values, and an optional dictionary of WHERE conditions.
#   table: any — Table name to update.
#   data: dict — Mapping of columns to new values.

3. If where is provided and is truthy, append " WHERE " followed by all where items formatted as "key='value'" and joined with " AND ". → query
4. Return the final SQL query string. → query
