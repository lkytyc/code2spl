Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

## insert(table: string, data: mapping) → string
Summary: Builds an SQL INSERT statement from a table name and mapping by joining the mapping keys and quoting each value.
#   table: string — Target table name to insert into.
#   data: mapping — Mapping whose keys become column names and whose values become inserted values.
#   → result: string — An SQL INSERT statement composed from the table name, comma-joined keys, and single-quoted values.
1. Extract the keys from the input mapping and join them into a comma-separated column list. → keys
2. Extract the values from the input mapping, wrap each value in single quotes, and join them into a comma-separated value list. → values
3. Format and return an SQL INSERT statement using the table name, the column list, and the value list. → result

## select(table: any, columns: any, where: any) → string
Summary: Build a SQL SELECT query string from the given table name, optional column list, and optional WHERE conditions.
#   table: any — Table name to query from.
#   columns: any — Columns to select; defaults to '*' and is joined with commas if not wildcard.
#   where: any — Optional mapping of equality conditions to append with AND.
#   → result: string — A SQL SELECT query string.
1. If columns is not the wildcard '*', join the column values with ', ' to form the SELECT column list. → columns
2. Construct the base query string as SELECT followed by the resolved columns and the table name. → query
3. If a where mapping is provided and is truthy, append a WHERE clause made from each key-value pair formatted as key='value' and joined with ' AND '. → query
4. Return the final query string. → query

## update(table: any, data: dict, where: dict or null) → string
Summary: Build an SQL UPDATE statement from a table name, a dictionary of column values, and an optional dictionary of WHERE conditions.
#   table: any — Table name to update.
#   data: dict — Mapping of columns to new values.
#   where: dict or null — Optional mapping of columns to filter rows to update.
#   → result: string — Constructed SQL UPDATE query string.

3. If where is provided and is truthy, append " WHERE " followed by all where items formatted as "key='value'" and joined with " AND ". → query
4. Return the final SQL query string. → query
