Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

# Fields: items

## __init__()
Summary: Initializes the instance by creating an empty dictionary to store items.
1. Assign a new empty dictionary to self.items to initialize the items storage for the instance. → self.items

## add_item(self: object, item: any, price: any, quantity: any)
Summary: Add or replace an item entry in self.items with the given price and quantity, using quantity defaulting to 1.
#   self: object — Instance containing the items mapping.
#   item: any — Item key to add or update in the items mapping.
#   price: any — Price value to store for the item.
#   quantity: any — Quantity to store for the item, defaulting to 1.
1. Check whether item exists as a key in self.items. → item_exists
2. Assign self.items[item] to a dictionary containing the provided price and quantity, regardless of whether the item already existed. → self.items[item]

## remove_item(self: object, item: any, quantity: number)
Summary: Reduce the stored quantity for an existing item in self.items by the requested amount and do nothing when the item is missing.
#   self: object — Instance containing the items collection.
#   item: any — Item key to remove quantity from if present.
#   quantity: number — Amount to subtract from the item's stored quantity; defaults to 1.
1. Check whether item exists as a key in self.items. → item_present
2. If item is present in self.items, subtract quantity from self.items[item]['quantity']. → updated_quantity
3. If item is not present in self.items, take no action. → no_change

## total_price() → float
Summary: Compute and return the sum of quantity times price for every item stored in self.items.
#   → result: float — The sum of quantity multiplied by price across all items; returns 0 when self.items is empty.
1. Iterate over all values in self.items. → item
2. For each item, multiply item['quantity'] by item['price'] to produce that item's contribution. → item_total
3. Sum all item contributions together. → total_price
4. Return the computed total price. → total_price

## view_items() → dict
Summary: Return the current value of the instance attribute self.items without modification.
#   → result: dict — The current value stored in self.items, returned without any transformation.
1. Read the current value of the instance attribute self.items. → items_value
2. Return items_value directly to the caller. → return_value
