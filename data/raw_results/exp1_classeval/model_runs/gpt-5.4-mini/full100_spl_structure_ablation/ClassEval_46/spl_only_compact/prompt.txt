Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

## interpolate_1d(x: sequence, y: sequence, x_interp: sequence) → list
Summary: Performs piecewise linear interpolation for each target x value by finding the containing interval in the source x array and computing the corresponding y value.
#   x: sequence — Ordered source x-coordinates that define interpolation intervals.
#   y: sequence — Source y-coordinates paired with x and used for linear interpolation.
#   x_interp: sequence — Target x values to interpolate.
#   → result: list — A list of interpolated y values for the target x values that fall within at least one source interval.
1. Initialize an empty list to collect interpolated y values. → y_interp
2. For each target value xi in x_interp, scan the adjacent index pairs in x from 0 to len(x) - 2. → loop_xi_and_i
3. Within the inner scan for each xi, if x[i] <= xi <= x[i+1], compute yi by linear interpolation using y[i] + (y[i+1] - y[i]) * (xi - x[i]) / (x[i+1] - x[i]). → yi
4. Within the same matched interval for xi, append the computed yi to y_interp. → y_interp
5. Within the same matched interval for xi, break out of the inner loop so only the first matching interval is used. → inner_loop_break
6. After processing all target values, return y_interp. → y_interp

## interpolate_2d(x: list, y: list, z: list, x_interp: list, y_interp: list) → list
Summary: Perform bilinear interpolation for each paired target coordinate by locating the containing grid cell and computing the interpolated z value from its four corner values.
#   x: list — Ordered grid coordinates along the x axis.
#   y: list — Ordered grid coordinates along the y axis.
#   z: list — 2D grid of corner values indexed by x and y positions.
#   x_interp: list — Target x coordinates to interpolate.
#   y_interp: list — Target y coordinates to interpolate.
#   → result: list — List of interpolated z values, one for each paired target coordinate that falls within a grid cell.
1. Initialize an empty list to collect interpolated z values. → z_interp
2. For each paired target coordinate (xi, yi) produced by zipping x_interp and y_interp, search for the first x interval that contains xi using the inclusive boundary check x[i] <= xi <= x[i+1]. → matching_x_index
3. Within the selected x interval search, for each y interval index j from 0 to len(y) - 2, find the first interval that contains yi using the inclusive boundary check y[j] <= yi <= y[j+1]. → matching_y_index
4. Within the matched x and y intervals, read the four surrounding corner values z00 = z[i][j], z01 = z[i][j+1], z10 = z[i+1][j], and z11 = z[i+1][j+1]. → corner_values
5. Within the matched cell, compute the bilinear interpolation value zi using the weighted corner formula and the denominator (x[i+1] - x[i]) * (y[j+1] - y[j]). → zi
6. Append the computed zi to z_interp and stop searching the current y interval list and the current x interval list for this point using the two breaks. → z_interp
7. After all paired target coordinates have been processed, return z_interp. → z_interp
