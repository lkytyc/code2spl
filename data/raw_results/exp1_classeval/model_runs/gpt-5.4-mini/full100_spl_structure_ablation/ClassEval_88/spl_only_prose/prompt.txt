Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

## factorial(self: object, a: integer) → integer
Summary: Compute the factorial-like product of the input value by initializing an accumulator to 1 and repeatedly multiplying it by the current counter while decrementing the counter until it reaches 1.
#   self: object — Instance reference.

2. While a is not equal to 1, multiply b by the current value of a and then decrement a by 1. → b,
3. Return b as the final product. → result

## sin(self: object, x: number) → number
Summary: Convert the input angle from degrees to radians, then approximate its sine by summing a series until the term magnitude falls below 1e-15, and return the result rounded to 10 decimal places.
#   self: object — Instance reference used to call the method.
#   x: number — Input angle in degrees.
#   → result: number — The sine approximation of the input angle, rounded to 10 decimal places.
1. Convert the input angle from degrees to radians by updating x to x / 180 * pi. → x
2. Initialize the accumulator g to 0. → g
3. Initialize the current series term t to the converted x value. → t
4. Initialize the term index n to 1. → n
5. While the absolute value of t is at least 1e-15, add the current term t to g, increment n by 1, and update t to -t * x * x / (2 * n - 1) / (2 * n - 2). → g
6. Return g rounded to 10 decimal places. → result

## tan(self: object, x: number)
Summary: Compute the tangent-like ratio sin(x) / cos(x) rounded to 10 decimal places when cosine is nonzero, otherwise return False to avoid division by zero.
#   self: object — Instance providing cos(x) and sin(x) methods.
#   x: number — Input angle or value passed to cosine and sine calculations.
1. Evaluate whether self.cos(x) is not equal to 0. → condition
2. When the condition is true, compute result as self.sin(x) divided by self.cos(x). → result
3. Return result rounded to 10 decimal places. → return_value
4. When the condition is false, return False immediately without performing the division. → return_value

## taylor(self: object, x: number, n: integer) → number
Summary: Computes an alternating Taylor-series style approximation by converting the input angle from degrees to radians, then accumulating power-and-factorial terms with alternating subtraction and addition based on a parity counter.
#   self: object — Instance providing the factorial method.
#   x: number — Input angle value that is converted from degrees to radians before series evaluation.
#   n: integer — Upper loop boundary; the loop iterates from 1 up to but not including n.
#   → result: number — The accumulated series approximation stored in a.
1. Initialize a to 1, convert x from degrees to radians using x = x / 180 * pi, and initialize count to 1. → a,
2. For each k from 1 up to but not including n, compute the term (x ** (2 * k)) / self.factorial(2 * k). → term
3. Within the loop, if count is odd, subtract the term from a; otherwise, add the term to a. → a
4. Within the same loop iteration, increment count by 1. → count
5. After completing all iterations, return a. → result
