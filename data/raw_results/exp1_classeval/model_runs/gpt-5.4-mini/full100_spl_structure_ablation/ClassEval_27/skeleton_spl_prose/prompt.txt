Skeleton Role:

- Preserve the skeleton API if skeleton and specification disagree.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of the same class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Step 2: Treat the skeleton as the public API contract and the specification as the implementation contract for method bodies.

## convert(amount: number, from_currency: string, to_currency: string) → number or boolean
Summary: Converts an amount from one currency to another using stored exchange rates, returning the original amount when the currencies match, false when either rate is missing, and otherwise the rate-adjusted converted amount.
#   amount: number — The numeric amount to convert.
#   from_currency: string — The source currency code.
#   to_currency: string — The target currency code.
#   → result: number or boolean — The converted amount, the original amount if both currencies are the same, or false if either currency rate is unavailable.
1. Check whether from_currency is equal to to_currency. → currency_match
2. If from_currency equals to_currency, return amount immediately without any conversion. → result
3. Check whether from_currency is missing from self.rates or to_currency is missing from self.rates. → rates_available
4. If either currency is not present in self.rates, return false. → result
5. Look up from_rate from self.rates using from_currency and look up to_rate from self.rates using to_currency. → from_rate_and_to_rate
6. Compute converted_amount as (amount divided by from_rate) multiplied by to_rate. → converted_amount
7. Return converted_amount. → result
   ! log: "Division by zero occurs while computing the normalized amount from amount / from_rate."
   ! raise: ZeroDivisionError "Raised when the source exchange rate is zero and the conversion formula attempts division by it."
