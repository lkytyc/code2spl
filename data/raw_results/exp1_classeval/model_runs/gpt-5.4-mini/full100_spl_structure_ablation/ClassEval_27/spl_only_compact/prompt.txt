Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

2. Set USD to 1.0 as the baseline reference rate. → self.rates['USD']

## add_currency_rate(self: object, currency: any, rate: any) → bool
Summary: Add a new currency rate to the mapping only when the currency is not already present, returning False if it exists.
#   self: object — Object containing the rates mapping.
#   currency: any — Currency key to add if it is not already present.
#   rate: any — Rate value to store for the currency.
#   → result: bool — False when the currency already exists; otherwise the method completes after updating self.rates and returns no explicit value.
1. Check whether the given currency is already present in self.rates. → currency_exists
2. If the currency is already present in self.rates, return False immediately without modifying the mapping. → False
3. Otherwise, store the provided rate in self.rates under the given currency key. → self.rates[currency]
   ? Return False without changing self.rates.

## convert(amount: number, from_currency: string, to_currency: string) → number or boolean
Summary: Converts an amount from one currency to another using stored exchange rates, returning the original amount when the currencies match, false when either rate is missing, and otherwise the rate-adjusted converted amount.
#   amount: number — The numeric amount to convert.
#   from_currency: string — The source currency code.
#   to_currency: string — The target currency code.
#   → result: number or boolean — The converted amount, the original amount if both currencies are the same, or false if either currency rate is unavailable.
1. Check whether from_currency is equal to to_currency. → currency_match
2. If from_currency equals to_currency, return amount immediately without any conversion. → result
3. Check whether from_currency is missing from self.rates or to_currency is missing from self.rates. → rates_available
4. If either currency is not present in self.rates, return false. → result
5. Look up from_rate from self.rates using from_currency and look up to_rate from self.rates using to_currency. → from_rate_and_to_rate
6. Compute converted_amount as (amount divided by from_rate) multiplied by to_rate. → converted_amount
7. Return converted_amount. → result
   ! log: "Division by zero occurs while computing the normalized amount from amount / from_rate."
   ! raise: ZeroDivisionError "Raised when the source exchange rate is zero and the conversion formula attempts division by it."

## get_supported_currencies() → list

2. Convert the keys view into a new list. → supported_currencies
3. Return the list of supported currencies. → supported_currencies

## update_currency_rate(self: object, currency: any, new_rate: any) → bool
Summary: Update the stored exchange rate for a currency when the currency already exists, and return False without changes if it does not.
#   self: object — Instance containing the rates mapping.
#   currency: any — Key identifying the currency rate to update.
#   new_rate: any — New rate value to store for the given currency.
#   → result: bool — Returns False if the currency is not already present; otherwise returns None after updating the mapping.
1. Check whether currency is present in self.rates. → currency_exists
2. If currency is not present in self.rates, return False immediately without modifying any stored rate. → false
3. Otherwise, assign new_rate to self.rates[currency] to update the existing currency rate. → updated_rate
