Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

## rail_fence_decipher(self: object, encrypted_text: string, rails: integer) → string
Summary: Decipher the encrypted text by rebuilding a rail-fence grid, marking zigzag positions, filling the empty slots with ciphertext characters, and then reading the grid again in the same zigzag order to produce the plaintext.
#   self: object — Instance reference used to call the method.
#   encrypted_text: string — Ciphertext to be decoded using the rail-fence pattern.
#   rails: integer — Number of rails used to reconstruct the zigzag grid.
#   → result: string — The deciphered plaintext returned by the method.
1. Initialize a 2D fence grid with rails rows and len(encrypted_text) columns, filling every cell with newline characters, then initialize direction to -1 and row and col to 0. → fence,
2. Within a for loop that runs exactly len(encrypted_text) times, reverse direction whenever row is 0 or rails - 1, mark the current fence cell at [row][col] with an empty string, advance col by 1, and move row by the current direction. → fence
3. Initialize index to 0 before filling the marked fence positions. → index
4. Within nested for loops over i from 0 to rails - 1 and j from 0 to len(encrypted_text) - 1, if fence[i][j] is an empty string, place encrypted_text[index] into that cell and increment index by 1. → fence,
5. Initialize plain_text to an empty string, then reset direction to -1 and row and col to 0 for the decoding traversal. → plain_text,
6. Within a for loop that runs exactly len(encrypted_text) times, reverse direction whenever row is 0 or rails - 1, append fence[row][col] to plain_text, advance col by 1, and move row by the current direction. → plain_text
7. Return plain_text. → result

## vigenere_decipher(ciphertext: string) → string
Summary: Decrypt ciphertext by shifting each alphabetic character backward with a repeating key while preserving case and leaving non-letter characters unchanged.
#   ciphertext: string — The encrypted text to decrypt character by character.
#   → result: string — The decrypted text with original non-alphabetic characters preserved.
1. Initialize decrypted_text as an empty string and key_index as 0. → decrypted_text,
2. For each character char in ciphertext, determine whether char is alphabetic. → char
3. Within the outer loop, if char is alphabetic, compute the repeating key character using key_index modulo the key length and convert it to a shift value from 0 to 25. → shift
4. Within the alphabetic branch, decrypt char by shifting its lowercase form backward by shift positions modulo 26, then convert the result back to uppercase if the original char was uppercase. → decrypted_char
5. Within the alphabetic branch, append the decrypted character to decrypted_text and increment key_index by 1 so only letters consume key characters. → decrypted_text,
6. Within the outer loop, if char is not alphabetic, append char unchanged to decrypted_text and do not change key_index. → decrypted_text
7. After all characters have been processed, return decrypted_text. → result
