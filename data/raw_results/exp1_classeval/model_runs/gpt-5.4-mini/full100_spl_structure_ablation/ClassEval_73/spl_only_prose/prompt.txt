Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

## attack(self: object, other_character: object)
Summary: Calculate the attack damage against another character using attack power minus defense, with a minimum damage of 1, then subtract that damage from the target's HP.
#   self: object — The attacker object providing attack_power.
#   other_character: object — The target character object providing defense and hp.
1. Compute damage as the larger of self.attack_power minus other_character.defense and 1, ensuring damage is never below 1. → damage
2. Subtract the computed damage from other_character.hp. → other_character.hp

## gain_exp(self: object, amount: integer)
Summary: Repeatedly applies experience points until the input amount is fully consumed, leveling up whenever the current experience reaches or exceeds the next level threshold.
#   self: object — The owning object whose experience and level are updated.
#   amount: integer — The amount of experience to apply, which may be reduced across multiple loop iterations until it becomes zero.
1. Initialize processing of the input amount for experience gain. → start
2. Within the outer while loop that continues as long as amount is not equal to 0, check whether self.exp plus amount is greater than or equal to self.level multiplied by 100. → threshold_check
3. If self.exp plus amount is greater than or equal to self.level multiplied by 100, subtract the exact experience needed to reach self.level multiplied by 100 from amount, then call level_up on self, and continue the while loop with any remaining amount. → leveled_up
4. Otherwise, add all remaining amount to self.exp and set amount to 0 to terminate the while loop. → xp_applied_and_finished

## heal(self: object) → int
Summary: Heals the object by increasing hp by 10, capping it at 100, and returning the updated hp value.
#   self: object — The instance whose hp field is updated.
#   → result: int — The updated hp value after healing and optional capping.
1. Increase self.hp by 10. → self.hp
2. If self.hp is greater than 100, set self.hp to 100. → self.hp
3. Return the current value of self.hp. → return_value

## is_alive(self: object) → bool
Summary: Returns whether the object's hp value is greater than zero.
#   self: object — The current instance containing the hp attribute.

## level_up(self: object) → tuple
Summary: Increases the character's level by one when below 100, resets experience, boosts stats, and returns the updated level and attributes.
#   self: object — The instance whose level, experience, hit points, attack power, and defense are updated.

1. Check whether self.level is strictly less than 100. → level_check
2. If self.level is strictly less than 100, increase self.level by 1, reset self.exp to 0, increase self.hp by 20, increase self.attack_power by 5, and increase self.defense by 5. → updated_stats
3. Return the current self.level, self.hp, self.attack_power, and self.defense as a tuple. → result
