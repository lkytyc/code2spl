Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

Class specification:

# Class: PageUtil
# Fields: page_size, total_pages, data, total_items

## __init__(data: sequence, page_size: integer)
Summary: Initializes the object with the provided data and page size, then derives the total item count and the required number of pages using ceiling division.
#   data: sequence — The collection of items to store and paginate.
#   page_size: integer — The number of items allowed per page.
1. Assign the input data to the instance field self.data. → self.data
2. Assign the input page_size to the instance field self.page_size. → self.page_size
3. Compute self.total_items as the length of the input data. → self.total_items
4. Compute self.total_pages using ceiling division: add page_size minus 1 to self.total_items, then perform integer floor division by page_size. → self.total_pages

## get_page(self: object, page_number: integer) → list
Summary: Returns a single page of data for a 1-based page number, or an empty list when the requested page is out of range.
#   self: object — Instance providing total_pages, page_size, and data.
#   page_number: integer — Requested 1-based page number.
#   → result: list — A slice of self.data for the requested page, or an empty list if the page number is invalid.
1. Check whether page_number is less than 1 or greater than self.total_pages. → page_number_validity
2. If page_number is out of range, return an empty list immediately. → []
3. Otherwise, compute start_index as (page_number - 1) * self.page_size to convert the 1-based page number into a zero-based offset. → start_index
4. Compute end_index as start_index + self.page_size so the page slice uses an exclusive upper bound. → end_index
5. Return the slice of self.data from start_index up to but not including end_index. → result
   ? Return an empty list without computing any page indices or slicing data.

## get_page_info(page_number: int) → dict
Summary: Return pagination metadata and the requested page slice when the page number is within range, otherwise return an empty dictionary.
#   page_number: int — Requested 1-based page number.
#   → result: dict — A dictionary containing page metadata and page data, or an empty dictionary when the page number is out of range.
1. Check whether page_number is outside the valid range from 1 through self.total_pages inclusive. → range_check
2. Compute start_index as (page_number - 1) * self.page_size using zero-based pagination. → start_index
3. Compute end_index as the smaller of start_index + self.page_size and self.total_items to prevent slicing past the dataset end. → end_index
4. Slice self.data from start_index to end_index to produce the page contents. → page_data
5. Build page_info with current_page, per_page, total_pages, total_items, has_previous, has_next, and data taken from the computed values. → page_info
6. Return page_info. → page_info
   ? Return an empty dictionary immediately.

## search(self: object, keyword: string) → dict
Summary: Filter the stored data by keyword, count the matches, compute the number of pages using the page size, and return the search details in a dictionary.
#   self: object — Instance containing the data collection and page size.
#   keyword: string — Substring to search for within each item.
#   → search_info: dict — Dictionary containing the keyword, total result count, total page count, and matching results.
1. Filter self.data to collect every item whose string representation contains the keyword, and store the matching items in results. → results
2. Count the number of matching items in results and store the count in num_results. → num_results
3. Compute the total number of pages using ceiling-style integer division with num_results and self.page_size: (num_results + self.page_size - 1) // self.page_size. → num_pages
4. Assemble search_info with the original keyword, the total result count, the total page count, and the filtered results list. → search_info
5. Return search_info. → search_info
