Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

## palindromic_length(self: object, center: integer, diff: integer, string: string) → integer
Summary: Recursively expands a mirrored character comparison around a center index and returns the palindrome radius length, stopping immediately when the expansion goes out of bounds or characters differ.
#   self: object — Instance used to call the recursive method.
#   center: integer — Center index used as the symmetry anchor for expansion.
#   diff: integer — Current offset from the center used to compare mirrored positions.
#   string: string — Input sequence whose symmetric characters are compared.
#   → result: integer — Returns 0 when expansion fails at a boundary or mismatch, otherwise returns 1 plus the recursively computed palindromic length for the next outward offset.
1. Check whether the left mirrored index is before the start of the string, the right mirrored index is at the string length boundary, or the mirrored characters at center - diff and center + diff do not match, using left-to-right short-circuit evaluation. → boundary_or_mismatch_check
2. If any of those failure conditions is true, return 0 immediately to stop the expansion. → 0
3. Otherwise, return 1 plus the result of recursively calling palindromic_length with the same center, diff increased by 1, and the same string. → recursive_length

## palindromic_string() → string
Summary: Build a delimiter-separated version of the input string, find the longest palindrome center using the helper length function, and reconstruct the corresponding palindrome while removing delimiter characters.
#   → result: string — The longest palindromic substring reconstructed without separator characters.
1. Initialize max_length to 0 and create empty strings new_input_string and output_string. → max_length,
2. Build new_input_string by iterating over all characters in self.input_string except the last one, appending each character followed by a pipe separator, then append the final character without a trailing separator. → new_input_string
3. Within the loop over every index i in new_input_string, call self.palindromic_length(i, 1, new_input_string) to compute the palindrome length centered at or expanded from i. → length
4. Within the same loop, if the computed length is strictly greater than max_length, update max_length to that length and record the current index i as start. → max_length,
5. After the scan completes, iterate over the slice of new_input_string from start - max_length through start + max_length inclusive and append every character that is not a pipe separator to output_string. → output_string
6. Return output_string as the final reconstructed palindromic substring. → result
