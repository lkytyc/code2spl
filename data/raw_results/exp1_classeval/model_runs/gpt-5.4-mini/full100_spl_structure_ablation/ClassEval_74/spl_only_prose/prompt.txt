Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

## add_white_list(self: object, addr: any) → bool_or_list
Summary: Add an address to the whitelist only if it is not already present, otherwise reject it by returning False.
#   self: object — The instance containing the white_list attribute.
#   addr: any — The address value to check and possibly add.
#   → result: bool_or_list — Returns False when the address is already in the whitelist; otherwise returns the updated whitelist after appending the address.
1. Check whether addr is already present in self.white_list. → is_duplicate
2. If addr is already present in self.white_list, return False immediately without modifying the whitelist. → false
3. If addr is not present in self.white_list, append addr to self.white_list. → updated_white_list
4. Return the updated self.white_list after appending addr. → updated_white_list

## del_white_list(addr: any) → bool or list
Summary: Remove an address from the whitelist when it is present, and return False if the address is not in the whitelist.
#   addr: any — The address value to check for membership in the whitelist and remove if present.
#   → result: bool or list — Returns False when the address is absent; otherwise returns the updated whitelist after removing the address.
1. Check whether addr is not present in self.white_list. → membership_check
2. If addr is not present in self.white_list, return False immediately. → False
3. Otherwise, remove addr from self.white_list. → updated_white_list
4. Return the updated self.white_list after removal. → result
   ? Return False without modifying self.white_list.

## recv(info: dict) → int or bool or any
Summary: Validate an input dictionary, reject missing fields or unauthorized addresses, store the allowed address and content, and return the content value.
#   info: dict — Input dictionary expected to contain the keys 'addr' and 'content'.
#   → result: int or bool or any — Returns -1 if the input is not a valid dictionary with required keys, False if the address is not whitelisted, or the stored content value when accepted.
1. Check whether info is a dictionary and contains both required keys 'addr' and 'content'; if any of these checks fails, return -1 immediately. → validation_result
2. Read addr from info['addr'] and content from info['content']. → addr,
3. Check whether addr is not present in self.white_list; if it is not allowed, return False immediately. → whitelist_check
4. When addr is allowed, store a dictionary containing addr and content into self.receive_struct. → self.receive_struct
5. Return self.receive_struct['content'] as the final accepted result. → result
   ? Return -1 without reading addr or content.
   ? Return False without modifying self.receive_struct.

## send(info: dict) → string
Summary: Validates that the input is a dictionary containing both required keys and then stores those two fields in self.send_struct without transforming their values.
#   info: dict — Input dictionary expected to contain the keys addr and content.
#   → result: string — Returns an error message when validation fails; otherwise no explicit return value is produced.
1. Check whether info is a dictionary and whether it contains both the addr and content keys. → _validation_ok
2. If validation fails, return the string "info structure is not correct" immediately. → _error_message
3. If validation succeeds, assign self.send_struct to a new dictionary with addr copied from info["addr"] and content copied from info["content"]. → _send_struct
   ? Return the validation error message without performing the assignment to self.send_struct.

## show(self: object, type: string)
Summary: Returns the matching structure for the given type string, using send for 'send', receive for 'receive', and False for any other value.
#   self: object — Instance providing send_struct and receive_struct attributes.
#   type: string — Selector value used to choose which structure to return.
1. Check whether type is exactly "send". → send_branch
2. If type is "send", return self.send_struct immediately. → self.send_struct
3. Otherwise, check whether type is exactly "receive". → receive_branch
4. If type is "receive", return self.receive_struct immediately. → self.receive_struct
5. For any other value of type, return False as the fallback result. → False
