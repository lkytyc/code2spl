Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

# Class: NLPDataProcessor2

## calculate_word_frequency(words_list: iterable) → dict
Summary: Count the occurrences of all items across the input lists, then return the five most frequent entries as an ordered dictionary.
#   words_list: iterable — A collection of word collections to be counted and aggregated.
#   → result: dict — A dictionary containing up to the five highest-frequency words and their counts, ordered from highest to lower frequency.
1. Initialize an empty Counter named word_frequency to accumulate counts. → word_frequency
2. Iterate over each words collection in words_list and update word_frequency with all items from that collection. → word_frequency
3. Sort the items of word_frequency by count in descending order and convert the sorted pairs back into a dictionary named sorted_word_frequency. → sorted_word_frequency
4. Take the first 5 items from sorted_word_frequency and convert them back into a dictionary named top_5_word_frequency. → top_5_word_frequency
5. Return top_5_word_frequency as the final result. → top_5_word_frequency
   ? After sorting word_frequency by descending count, take all existing items if there are fewer than 5 and convert them into top_5_word_frequency.

## process_data(string_list: list of strings) → list of list of strings
Summary: Clean each input string by removing non-letter characters, converting it to lowercase, splitting it into words, and returning a list of word lists.
#   string_list: list of strings — Input strings to be normalized and split into words
#   → result: list of list of strings — A list containing the words extracted from each input string
1. Initialize an empty list to collect per-string word lists. → words_list
2. For each string in string_list, convert the string to lowercase, remove every character except English letters and whitespace using the pattern [^a-zA-Z\s], split the cleaned string on whitespace into words, and append the resulting word list to words_list. → words_list
3. Return the collected list of word lists. → result
