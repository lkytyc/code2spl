This code defines a utility class for turning HTML into cleaned text and for extracting code-like sections from HTML.

The class, `HtmlUtil`, sets up several marker strings in its constructor, but only one of them is actually used in the shown methods: a code marker.

Main behavior:

- `format_line_html_text(html_text)`
  - Takes an HTML string as input.
  - If the input is `None` or empty, it returns an empty string.
  - Parses the HTML with BeautifulSoup using the `lxml` parser.
  - Replaces the contents of all `<pre>` and `<blockquote>` elements with a special code marker.
  - Processes all list elements (`<ul>` and `<ol>`) and rewrites each non-empty `<li>` item into a text form prefixed with `[-]`.
    - If the item already ends with punctuation, it keeps that punctuation.
    - Otherwise it appends a period.
  - Processes all paragraph elements (`<p>`) and rewrites them as plain text:
    - If the paragraph already ends with punctuation, it is left as-is.
    - If the next sibling element contains the code marker, a colon is appended.
    - Otherwise a period is appended.
  - Extracts the resulting text from the modified HTML, decodes HTML entities, and collapses multiple line breaks into single line breaks.
  - Returns the cleaned text.

- `extract_code_from_html_text(html_text)`
  - Takes the same kind of HTML string as input.
  - First calls `format_line_html_text` to see whether the code marker is present.
  - If no code marker is found, it returns an empty list.
  - Otherwise, it parses the original HTML again, finds all `<pre>` and `<blockquote>` elements, and returns a list of their text contents.
  - The number of code sections returned is based on how many code markers were inserted during formatting.

Important interactions:

- `extract_code_from_html_text` depends on `format_line_html_text` to identify whether code-like blocks exist.
- Both methods use BeautifulSoup to parse the HTML.
- The class uses regex only to normalize repeated newlines in the final text.
