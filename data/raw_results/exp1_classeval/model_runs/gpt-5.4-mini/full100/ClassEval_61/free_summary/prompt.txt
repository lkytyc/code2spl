- `set_volume(volume)`: sets the volume only if the given value is between 0 and 100 inclusive. If the value is outside that range, it returns `False`. On success, it updates the `volume` attribute and does not return a value.
- `shuffle()`: randomly reorders the playlist if it is not empty and returns `True`; if the playlist is empty, it returns `False`.
