This code defines a `PageUtil` class that helps paginate and search through a list of data.

### What it takes
- `data`: a list or sequence of items to work with
- `page_size`: how many items should appear on each page

### What it computes on initialization
- `total_items`: the total number of items in `data`
- `total_pages`: the number of pages needed to hold all items, based on `page_size`

### Methods

#### `get_page(page_number)`
Returns the items for a specific page.
- If `page_number` is less than 1 or greater than the total number of pages, it returns an empty list.
- Otherwise, it slices the stored data to return only the items for that page.

#### `get_page_info(page_number)`
Returns a dictionary with page details and the items on that page.
- If the page number is invalid, it returns an empty dictionary.
- Otherwise, it includes:
  - current page number
  - items per page
  - total pages
  - total items
  - whether a previous page exists
  - whether a next page exists
  - the page’s data

#### `search(keyword)`
Searches through all items in `data` and keeps those whose string form contains the given `keyword`.
- Returns a dictionary containing:
  - the search keyword
  - total number of matching items
  - how many pages those matches would occupy using the same `page_size`
  - the full list of matching results

### Overall behavior
The class stores the original data and provides simple pagination helpers plus a basic substring search over the data converted to strings.
