Skeleton Role:
- The skeleton controls imports, class name, constructor shape, field names, method names, and method signatures.
- Preserve the skeleton API if skeleton and specification disagree.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of the same class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

# Class: DataStatistics

## mean(data: sequence) → number
Summary: Compute the arithmetic mean of the input data by dividing its sum by its length, round the result to 2 decimal places, and return it.
#   data: sequence — A collection of values whose elements are summed and counted to compute the arithmetic mean.
#   → result: number — The arithmetic mean of the input data rounded to 2 decimal places.
1. Compute the sum of all elements in data. → total_sum
2. Compute the number of elements in data. → data_length
3. Divide total_sum by data_length to calculate the arithmetic mean. → mean_value
4. Round mean_value to 2 decimal places. → rounded_mean
5. Return rounded_mean. → result

## median(self: object, data: iterable) → number
Summary: Compute the median of the input data by sorting it first and then returning either the rounded average of the two middle values for even-sized data or the middle value for odd-sized data.
#   self: object — Instance reference.
#   data: iterable — Input data to be sorted and measured for the median.
#   → result: number — The median value, rounded to 2 decimal places for even-length data.
1. Sort the input data into a new sequence without modifying the original input, then store the result in sorted_data. → sorted_data
2. Compute the number of elements in sorted_data and store it in n. → n
3. Check whether n is even by evaluating n % 2 == 0. → parity_check
4. If n is even, compute middle as n // 2, then return the rounded average of sorted_data[middle - 1] and sorted_data[middle] using round(..., 2). → result
5. If n is odd, compute middle as n // 2, then return sorted_data[middle] as the median value. → result
   ? Proceed through the even-length median path with n = 0, which requires accessing sorted_data[-1] and sorted_data[0].
   ! log: "sorted(data) cannot complete because the input cannot be ordered."
   ! raise: TypeError "Raised when the input cannot be sorted due to invalid or non-comparable elements."

## mode(data: sequence) → list
Summary: Compute the most frequent values in the input sequence and return all values tied for the highest frequency.
#   data: sequence — Input collection of items to count.
#   → result: list — A list of all items whose occurrence count equals the maximum count.
1. Build a frequency counter from the input data. → counter
2. Find the largest value among the counter frequencies. → mode_count
3. Collect every key whose frequency equals the largest frequency into a list. → mode
4. Return the list of most frequent values. → mode
   ? Attempting to compute the maximum frequency from an empty counter has no valid result.
