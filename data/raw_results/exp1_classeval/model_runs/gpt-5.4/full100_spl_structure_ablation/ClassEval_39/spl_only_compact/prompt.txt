Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

## _calculate(first_value: any, second_value: any, current_op: string) → Decimal
Summary: Compute and return a Decimal arithmetic result for two input values based on a supported operator, or raise an error for an unsupported operator.
#   first_value: any — The first operand value to be converted to Decimal before calculation.
#   second_value: any — The second operand value to be converted to Decimal before calculation.
#   current_op: string — The operator selector expected to be one of '+', '-', '*', '/', or '%'.
#   → result: Decimal — The Decimal result of applying the selected arithmetic operator to the two input values.
1. Check whether current_op is exactly '+'. → is_addition
2. If current_op is exactly '+', convert first_value and second_value to Decimal, add them, and return the sum immediately. → result
3. Check whether current_op is exactly '-'. → is_subtraction
4. If current_op is exactly '-', convert first_value and second_value to Decimal, subtract the second from the first, and return the difference immediately. → result
5. Check whether current_op is exactly '*'. → is_multiplication
6. If current_op is exactly '*', convert first_value and second_value to Decimal, multiply them, and return the product immediately. → result
7. Check whether current_op is exactly '/'. → is_division
8. If current_op is exactly '/', convert first_value and second_value to Decimal, divide the first by the second, and return the quotient immediately. → result
9. Check whether current_op is exactly '%'. → is_modulo
10. If current_op is exactly '%', convert first_value and second_value to Decimal, compute the remainder of the first modulo the second, and return the modulo result immediately. → result
   ! log: "Unexpected operator: {current_op}"
   ! raise: ValueError "Raised when the operator is unsupported."

## calculate(self: object, expression: string) → float
Summary: Evaluate a postfix expression by normalizing negative markers, applying stack-based operator calculations, and returning the final numeric result as a float.
#   self: object — Instance providing prepare, transform, postfix_stack, is_operator, and _calculate behavior.
#   expression: string — Input expression to transform and evaluate.
#   → result: float — The evaluated expression result.
1. Prepare the internal postfix state by passing the transformed expression to self.prepare(self.transform(expression)). → postfix_stack_ready
2. Initialize an empty deque named result_stack. → result_stack
3. Reverse self.postfix_stack so tokens can be processed in pop order. → self.postfix_stack
4. While self.postfix_stack is not empty, pop the next token into current_op. → current_op
5. Within the loop, if current_op is not an operator, replace every '~' with '-' and append the token to result_stack. → result_stack
6. Within the loop, if current_op is an operator, pop second_value and first_value from result_stack. → first_value_and_second_value
7. Within the operator branch, normalize first_value and second_value by replacing every '~' with '-'. → normalized_operands
8. Within the operator branch, compute temp_result by calling self._calculate(first_value, second_value, current_op). → temp_result
9. Within the operator branch, convert temp_result to a string and append it to result_stack. → result_stack
10. After the loop finishes, join result_stack items with '*' and evaluate the expression, then return the float of that value. → final_result

## compare(cur: string, peek: string) → boolean
Summary: Normalize '%' to '/' for both input operator characters, then return whether the normalized peek operator priority is greater than or equal to the normalized cur operator priority using the priority table indexed by character code minus 40.
#   cur: string — The current operator character to normalize if it is '%' and then compare by priority.
#   peek: string — The next operator character to normalize if it is '%' and then compare by priority.
#   → result: boolean — True if the priority value for the normalized peek character is greater than or equal to the priority value for the normalized cur character; otherwise False.
1. If cur is exactly '%', replace cur with '/'. → cur
2. If peek is exactly '%', replace peek with '/'. → peek
3. Compute the priority-table index for peek as ord(peek) minus 40 and retrieve the corresponding priority from self.operat_priority. → peek_priority
4. Compute the priority-table index for cur as ord(cur) minus 40 and retrieve the corresponding priority from self.operat_priority. → cur_priority
5. Return whether peek_priority is greater than or equal to cur_priority. → result

## is_operator(c: character) → boolean
Summary: Return whether the input character is one of the predefined operator or parenthesis symbols.
#   c: character — The input character to test for membership in the operator symbol set.
#   → result: boolean — True if the input character is one of '+', '-', '*', '/', '(', ')', or '%'; otherwise False.
1. Check whether input character c is a member of the fixed set of symbols {'+', '-', '*', '/', '(', ')', '%'}. → membership_check
2. Return the boolean result of that membership check. → result

## prepare(expression: iterable)
Summary: Convert an input expression into postfix components by scanning characters, accumulating operand substrings, and using an operator stack with sentinel and parenthesis handling.
#   expression: iterable — Input expression whose elements are materialized into a list for left-to-right parsing.
1. Initialize op_stack as a deque containing the single sentinel string ',' to act as the base stack boundary. → op_stack
2. Convert expression into a list named arr so each element can be accessed by index during parsing. → arr
3. Initialize current_index to 0 as the starting index of the current operand span. → current_index
4. Initialize count to 0 as the number of consecutive non-operator elements currently accumulated. → count
5. Iterate left to right over arr with enumerate, binding i to the current index and current_op to the current element. → loop_iteration
6. Within the loop, when self.is_operator(current_op) is true, treat the current element as an operator or delimiter and begin operator-processing logic. → operator_branch
7. Within the operator branch, if count > 0, append the pending operand substring formed by joining arr[current_index: current_index + count] onto self.postfix_stack. → pending_operand_appended
8. Within the operator branch after any pending operand append, read the top operator from op_stack using op_stack[-1] and store it in peek_op. → peek_op
9. Within the operator branch, if current_op == ')', repeatedly pop operators from op_stack and append their string forms to self.postfix_stack while op_stack[-1] != '('. → popped_until_open_paren
10. Still within the current_op == ')' path, pop the matching '(' from op_stack without appending it after the loop terminates. → open_paren_removed
11. Within the operator branch, otherwise when current_op is not ')', repeatedly pop and append the top of op_stack while all three conditions hold simultaneously: current_op != '(', peek_op != ',', and self.compare(current_op, peek_op) is true. → precedence_pops
12. Within that same non-')' path, after each pop update peek_op to the new top of op_stack using op_stack[-1] before reevaluating the while condition. → peek_op_refreshed
13. Within the non-')' path after the precedence loop finishes, push current_op onto op_stack. → operator_pushed
14. After completing either operator subpath, reset count to 0 because the current operand span has ended at this operator position. → count_reset
15. After completing either operator subpath, set current_index to i + 1 so the next operand span starts immediately after the operator. → current_index_advanced
16. Within the loop, when self.is_operator(current_op) is false, increment count by 1 to extend the current contiguous non-operator span. → count_incremented
17. After the loop finishes, if count > 1 or if count == 1 and self.is_operator(arr[current_index]) is false, append the trailing operand substring formed by joining arr[current_index: current_index + count] onto self.postfix_stack. → trailing_operand_appended
18. After trailing operand handling, while op_stack[-1] != ',', pop each remaining operator from op_stack, convert it to string, and append it to self.postfix_stack. → remaining_operators_flushed

## transform(expression: string) → string
Summary: Normalizes an expression string by removing whitespace and a trailing equals sign, marks unary minus occurrences with a special token, and rewrites a leading negated parenthesized expression into a zero-prefixed subtraction form before returning the final string.
#   expression: string — Expression text to normalize and transform.
#   → result: string — The transformed expression string after normalization and unary-minus handling.
1. Remove all whitespace characters from expression using a global regular-expression substitution, and store the normalized string back into expression. → expression
2. Remove a trailing '=' from expression if and only if one exists at the end of the string, and store the result back into expression. → expression
3. Convert the final expression string into a character list and store it in arr. → arr
4. Iterate left to right over arr with both index i and current character c from enumerate(arr). → iteration_over_arr
5. Within the loop, process only iterations where c equals '-'; for all other characters, leave arr unchanged for that iteration. → minus_filter
6. Within the loop when c equals '-' and i equals 0, replace arr[i] with '~' to mark a leading unary minus. → arr
7. Within the loop when c equals '-' and i is greater than 0, read the previous character arr[i - 1] into prev_c. → prev_c
8. Within the loop when c equals '-' and i is greater than 0, if prev_c is one of '+', '-', '*', '/', '(', 'E', or 'e', replace arr[i] with '~'; otherwise leave arr[i] unchanged. → arr
9. After the loop, evaluate whether arr[0] equals '~' and, only if that is true, evaluate whether len(arr) is greater than 1 and arr[1] equals '(' using short-circuit logic. → leading_negated_parenthesized_check
10. If the post-loop condition is true, change arr[0] from '~' to '-', join arr into a string, prefix the joined string with '0', and return that value immediately. → result
11. Otherwise, join arr into a string without further modification and return that value immediately. → result
