Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

Class specification:

# Class: SplitSentence

## count_words(sentence: string) → integer
Summary: Removes non-letter and non-whitespace characters from the input sentence, splits the cleaned text into words, and returns the word count.
#   sentence: string — Input text to sanitize and count words in.
#   → result: integer — The number of whitespace-separated words after filtering punctuation and other non-letter characters.
1. Remove every character from sentence except English letters and whitespace using the regular expression r'[^a-zA-Z\s]'. → sentence
2. Split the cleaned sentence on whitespace to produce the words list. → words
3. Return the number of items in words. → result

## process_text_file(sentences_string: string) → integer
Summary: Returns the maximum word count among all sentences produced from the input text.
#   sentences_string: string — Input text that is split into sentences and analyzed.
#   → result: integer — The largest word count found in any sentence, or 0 when no sentence exceeds the initial default.
1. Split the input string into sentences using the internal sentence splitter. → sentences
2. Initialize the running maximum word count to 0 as the boundary default. → max_count
3. Within the loop over each sentence in sentences, count the words in the current sentence. → count
4. Within the same loop, if the current word count is strictly greater than max_count, update max_count to that count. → max_count
5. After processing all sentences, return max_count. → result

## split_sentences(sentences_string: string) → list of strings
Summary: Split an input string into sentences at whitespace following periods or question marks, while avoiding splits inside common abbreviation-like patterns.
#   sentences_string: string — Input text to be split into sentences.
#   → result: list of strings — List of sentence fragments produced by the regex split.
1. Use the fixed regular expression pattern to split sentences_string at whitespace that follows either a period or a question mark, while preserving abbreviation-like patterns protected by negative lookbehinds. → sentences
2. Return the resulting list of sentence fragments. → sentences
