Complete the Python class from the ClassEval skeleton, using the compact class specification as an implementation contract.

Skeleton Role:
- The skeleton controls imports, class name, constructor shape, field names, method names, and method signatures.
- Preserve the skeleton API if skeleton and specification disagree.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of the same class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Match each specification method section to its skeleton method by method name.

Step 2: Treat the skeleton as the public API contract and the specification as the implementation contract for method bodies.

Step 3: Build a class-level behavior map:
- constructor fields and shared state;
- method inputs, outputs, and side effects;
- cross-method calls from `# Calls:` and inside steps;
- data flow from step `→` result names;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 4: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become if/elif/else blocks;
- `! raise:` steps become try/except or explicit raise only when entailed;
- `→` result names become local variables, fields, calls, or returned values.

Step 5: Keep the implementation minimal and executable. Do not add unrelated APIs or behavior outside the skeleton plus specification contract.

Reconstruction Rules:

class Calculator:
    """
    This is a class for a calculator, capable of performing basic arithmetic calculations on numerical expressions using the operators +, -, *, /, and ^ (exponentiation).
    """

    def __init__(self):
        """
        Initialize the operations performed by the five operators'+','-','*','/','^'
        """
        self.operators = {
            '+': lambda x, y: x + y,
            '-': lambda x, y: x - y,
            '*': lambda x, y: x * y,
            '/': lambda x, y: x / y,
            '^': lambda x, y: x ** y
        }

    def calculate(self, expression):
        """
        Calculate the value of a given expression
        :param expression: string, given expression
        :return:If successful, returns the value of the expression; otherwise, returns None
        >>> calculator = Calculator()
        >>> calculator.calculate('1+2-3')
        0.0
        """


    def precedence(self, operator):
        """
        Returns the priority of the specified operator, where the higher the priority, the greater the assignment. The priority of '^' is greater than '/' and '*', and the priority of '/' and '*' is greater than '+' and '-'
        :param operator: string, given operator
        :return: int, the priority of the given operator, otherwise return 0
        >>> calculator = Calculator()
        >>> calculator.precedence('+')
        1
        >>> calculator.precedence('^')
        3
        """


    def apply_operator(self, operand_stack, operator_stack):
        """
        Use the operator at the top of the operator stack to perform the operation on the two numbers at the top of the operator stack, and store the results at the top of the operator stack
        :param operand_stack:list
        :param operator_stack:list
        :return: the updated operand_stack and operator_stack
        >>> calculator = Calculator()
        >>> calculator.apply_operator([1, 2, 3], ['+', '-'])
        ([1, -1], ['-'])
        """

#   operand_stack: stack — Stack of operands used for binary operations.
#   operator_stack: stack — Stack of pending operators.

2. Check whether operator equals '^'. → branch_condition
3. Within either branch, pop operand2 from operand_stack, then pop operand1 from operand_stack. → operand1_operand2
4. Within either branch, compute result by calling the operator function from self.operators for operator with operand1 and operand2. → result
5. Within either branch, append result to operand_stack. → operand_stack
6. Return the updated operand_stack and operator_stack. → operand_stack,

## calculate(expression: string) → number_or_null
Summary: Evaluates an arithmetic expression string by parsing numeric tokens and using operand and operator stacks to apply precedence and parentheses rules, then returns the final numeric result or None if no operand was produced.
#   expression: string — Arithmetic expression text scanned one character at a time.
#   → result: number_or_null — The final computed numeric value from the expression, or None when no operand remains.
1. Initialize operand_stack as an empty list, operator_stack as an empty list, and num_buffer as an empty string. → initialized_state
2. Iterate through each character char in expression. → char_iteration
3. Within the loop for each char, if char.isdigit() is true or char equals '.', append char to num_buffer. → updated_num_buffer
4. Within the same loop, if char is not a digit and not '.', first check whether num_buffer is non-empty; if it is, convert num_buffer to float, append that value to operand_stack, and reset num_buffer to an empty string. → flushed_buffer_to_operand_stack
5. Within the non-numeric branch, if char is one of '+-*/^', repeatedly apply the top stacked operator while operator_stack is non-empty, operator_stack[-1] is not '(', and self.precedence(operator_stack[-1]) is greater than or equal to self.precedence(char), updating both operand_stack and operator_stack from self.apply_operator on each iteration. → precedence_reduced_stacks
6. After finishing any required reductions for an operator char, append char to operator_stack. → operator_pushed
7. Within the non-numeric branch, if char equals '(', append char to operator_stack. → open_parenthesis_pushed
8. Within the non-numeric branch, if char equals ')', repeatedly apply the top stacked operator while operator_stack is non-empty and operator_stack[-1] is not '(', updating both operand_stack and operator_stack from self.apply_operator on each iteration. → parenthesized_operators_reduced
9. After reducing operators for a closing parenthesis, pop the top item from operator_stack to discard the matching '('. → open_parenthesis_removed
10. After the full character loop completes, if num_buffer is non-empty, convert num_buffer to float and append that value to operand_stack. → final_buffer_flushed
11. After any remaining buffered number is flushed, while operator_stack is non-empty, repeatedly call self.apply_operator to update operand_stack and operator_stack until all remaining operators are resolved. → fully_reduced_stacks
12. Return operand_stack[-1] if operand_stack is non-empty; otherwise return None. → result
   ? If num_buffer is non-empty before that character, flush it by converting num_buffer to float, appending it to operand_stack, and resetting num_buffer to an empty string.
   ? Perform no operator-stack or parenthesis action for that character and continue scanning the next character.
   ? Return None instead of a numeric value.
