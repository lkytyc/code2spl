Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

# Class: Calculator
# Fields: operators
# Calls: calculate→precedence

## __init__()
Summary: Initialize the operators lookup table with arithmetic lambda functions for addition, subtraction, multiplication, division, and exponentiation.
1. Create a dictionary and assign it to self.operators with keys for '+', '-', '*', '/', and '^'. → self.operators
2. For '+' map to a lambda that returns x + y, for '-' map to a lambda that returns x - y, for '*' map to a lambda that returns x * y, for '/' map to a lambda that returns x / y, and for '^' map to a lambda that returns x ** y. → operator_functions
   ! log: "The division function in self.operators performs x / y and can fail on zero division."
   ! raise: ZeroDivisionError "Raised by division when the right operand is zero."

## apply_operator(self: object, operand_stack: stack, operator_stack: stack) → tuple
Summary: Pops one operator from the operator stack, pops two operands from the operand stack, applies the selected operator, and pushes the result back before returning both stacks.
#   self: object — Instance providing the operator lookup table.
#   operand_stack: stack — Stack of operands used for binary operations.
#   operator_stack: stack — Stack of pending operators.
#   → result: tuple — Updated operand stack and operator stack.
1. Pop the top operator from operator_stack and store it in operator. → operator
2. Check whether operator equals '^'. → branch_condition
3. Within either branch, pop operand2 from operand_stack, then pop operand1 from operand_stack. → operand1_operand2
4. Within either branch, compute result by calling the operator function from self.operators for operator with operand1 and operand2. → result
5. Within either branch, append result to operand_stack. → operand_stack
6. Return the updated operand_stack and operator_stack. → operand_stack,
   ? Pop operand2 and operand1 from operand_stack.
   ? Apply the '^' operator function from self.operators to operand1 and operand2.
   ? Append result to operand_stack.
   ? Pop operand2 and operand1 from operand_stack.
   ? Apply the operator function from self.operators for the current operator to operand1 and operand2.
   ? Append result to operand_stack.
   ! log: "operator_stack.pop() cannot produce an operator because the stack has no elements."
   ! raise: IndexError "The operator pop fails because the stack is empty."
   ! log: "operand_stack.pop() cannot produce both operands because the stack lacks sufficient values."
   ! raise: IndexError "The operand pops fail because the stack does not contain two values."

## calculate(expression: string) → number_or_null
Summary: Evaluates an arithmetic expression string by parsing numeric tokens and using operand and operator stacks to apply precedence and parentheses rules, then returns the final numeric result or None if no operand was produced.
#   expression: string — Arithmetic expression text scanned one character at a time.
#   → result: number_or_null — The final computed numeric value from the expression, or None when no operand remains.
1. Initialize operand_stack as an empty list, operator_stack as an empty list, and num_buffer as an empty string. → initialized_state
2. Iterate through each character char in expression. → char_iteration
3. Within the loop for each char, if char.isdigit() is true or char equals '.', append char to num_buffer. → updated_num_buffer
4. Within the same loop, if char is not a digit and not '.', first check whether num_buffer is non-empty; if it is, convert num_buffer to float, append that value to operand_stack, and reset num_buffer to an empty string. → flushed_buffer_to_operand_stack
5. Within the non-numeric branch, if char is one of '+-*/^', repeatedly apply the top stacked operator while operator_stack is non-empty, operator_stack[-1] is not '(', and self.precedence(operator_stack[-1]) is greater than or equal to self.precedence(char), updating both operand_stack and operator_stack from self.apply_operator on each iteration. → precedence_reduced_stacks
6. After finishing any required reductions for an operator char, append char to operator_stack. → operator_pushed
7. Within the non-numeric branch, if char equals '(', append char to operator_stack. → open_parenthesis_pushed
8. Within the non-numeric branch, if char equals ')', repeatedly apply the top stacked operator while operator_stack is non-empty and operator_stack[-1] is not '(', updating both operand_stack and operator_stack from self.apply_operator on each iteration. → parenthesized_operators_reduced
9. After reducing operators for a closing parenthesis, pop the top item from operator_stack to discard the matching '('. → open_parenthesis_removed
10. After the full character loop completes, if num_buffer is non-empty, convert num_buffer to float and append that value to operand_stack. → final_buffer_flushed
11. After any remaining buffered number is flushed, while operator_stack is non-empty, repeatedly call self.apply_operator to update operand_stack and operator_stack until all remaining operators are resolved. → fully_reduced_stacks
12. Return operand_stack[-1] if operand_stack is non-empty; otherwise return None. → result
   ? If num_buffer is non-empty before that character, flush it by converting num_buffer to float, appending it to operand_stack, and resetting num_buffer to an empty string.
   ? Perform no operator-stack or parenthesis action for that character and continue scanning the next character.
   ? Return None instead of a numeric value.

## precedence(operator: text) → integer
Summary: Returns the precedence value for a given operator by looking it up in a fixed mapping and defaulting to 0 when the operator is not defined.
#   operator: text — The operator symbol whose precedence should be retrieved.
#   → result: integer — The precedence level for the operator, or 0 if the operator is not present in the mapping.
1. Create a fixed dictionary named precedences that maps '+' to 1, '-' to 1, '*' to 2, '/' to 2, and '^' to 3. → precedences
2. Return the value associated with operator from precedences, using 0 as the default when operator is not a key in the dictionary. → result
