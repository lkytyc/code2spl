Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

Class specification:

# Class: TicTacToe
# Fields: board, current_player

## __init__(N: int)
Summary: Initializes a 3-row game board with N columns filled with spaces and sets the current player to X.
#   N: int — Number of columns used to build each board row; defaults to 3.
1. Create the board as a list containing 3 separate rows, where each row is a new list of length N filled with the space character. → self.board
2. Set the current player to the constant string X. → self.current_player

## check_winner(self: object) → string or null
Summary: Check a 3x3 board for any winning row, column, or diagonal and return the winning symbol, or None if no winner exists.
#   self: object — Object containing a 3x3 board in self.board.
#   → result: string or null — The winning symbol, or None if there is no winner.
1. Iterate through each row in self.board, and if the three entries in the current row are all equal and not a space, return that row's symbol immediately. → row
2. Iterate through columns 0 to 2, and if the three entries in the current column are all equal and not a space, return that column's symbol immediately. → column
3. Check the main diagonal from top-left to bottom-right, and if all three entries are equal and not a space, return the top-left symbol. → main_diagonal_winner
4. Check the anti-diagonal from top-right to bottom-left, and if all three entries are equal and not a space, return the top-right symbol. → anti_diagonal_winner
5. Return None when no row, column, or diagonal contains three matching non-space symbols. → None

## is_board_full(self: object) → bool
Summary: Checks whether every row on the board contains no space characters and returns False immediately when any empty cell is found.
#   self: object — Instance containing the board to inspect.
#   → result: bool — True if the board contains no spaces in any row; otherwise False.
1. Iterate through each row in self.board. → row
2. Within the loop over each row, check whether the row contains a space character ' '. → contains_space
3. If any row contains a space character, return False immediately and stop scanning further rows. → false
4. If the loop completes without finding any space characters, return True. → true

## make_move(row: int, col: int) → bool
Summary: Attempts to place the current player's mark on an empty board cell, switches players, and returns whether the move succeeded.
#   row: int — Row index of the target board cell.
#   col: int — Column index of the target board cell.
#   → result: bool — True if the move was placed on an empty cell, otherwise False.
1. Check whether self.board[row][col] is exactly the space character ' '. → is_empty
2. If the cell is empty, set self.board[row][col] to self.current_player. → board_updated
3. If the cell is empty, toggle self.current_player from 'X' to 'O' or from 'O' to 'X'. → current_player_updated
4. If the cell is empty, return True immediately. → true
   ? Return False immediately without changing the board or current_player.
