Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

# Class: DataStatistics4

## correlation_coefficient(data1: sequence[number], data2: sequence[number]) → number
Summary: Computes the Pearson-style correlation coefficient between two indexed datasets by centering each dataset around its mean and dividing the summed cross-deviations by the product of their deviation magnitudes, returning 0 when the denominator is zero.
#   data1: sequence[number] — The first numeric dataset, whose length defines the iteration range and divisor for both mean calculations.
#   data2: sequence[number] — The second numeric dataset, expected to be indexable for every index from 0 to len(data1) - 1 and summed using the same divisor as data1.
#   → result: number — The correlation coefficient computed as numerator divided by denominator, or 0 when the denominator equals 0.
1. Set n to the length of data1. → n
2. Compute mean1 as the sum of all elements in data1 divided by n. → mean1
3. Compute mean2 as the sum of all elements in data2 divided by the same n. → mean2
4. Compute numerator as the sum over each index i from 0 to n - 1 of (data1[i] - mean1) multiplied by (data2[i] - mean2). → numerator
5. Compute denominator as the square root of the sum over each index i from 0 to n - 1 of (data1[i] - mean1) squared, multiplied by the square root of the sum over each index i from 0 to n - 1 of (data2[i] - mean2) squared. → denominator
6. If denominator is not equal to 0, return numerator divided by denominator. → result
   ? Return 0 instead of performing the division.

## kurtosis(data: sequence of numbers) → number
Summary: Computes the population excess kurtosis of a numeric dataset using the fourth central moment, returning NaN when the standard deviation is zero.
#   data: sequence of numbers — Input values used to compute kurtosis.
#   → result: number — The excess kurtosis value, or NaN when standard deviation is zero.
1. Compute the number of input items as n from the length of data. → n
2. Compute the arithmetic mean of data by summing all values and dividing by n. → mean
3. Compute the population standard deviation by summing squared deviations from the mean over data, dividing by n, and taking the square root. → std_dev
4. If std_dev equals 0, return NaN immediately. → math.nan
5. Create centered_data by subtracting mean from each value in data. → centered_data
6. Compute fourth_moment as the average of the fourth powers of values in centered_data using division by n. → fourth_moment
7. Compute kurtosis_value as fourth_moment divided by std_dev to the fourth power, then subtract 3. → kurtosis_value
8. Return kurtosis_value. → result
   ? Return NaN instead of continuing to the centered-data and fourth-moment calculations.
   ! log: "Input length is zero, so the method cannot divide by n."
   ! raise: ZeroDivisionError "Raised by division using n equal to zero."

## pdf(data: list, mu: number, sigma: number) → list
Summary: Computes the normal probability density value for each input datum using the given mean and standard deviation.
#   data: list — Input values to evaluate against the Gaussian density.
#   mu: number — Mean of the normal distribution.
#   sigma: number — Standard deviation of the normal distribution; must be nonzero.
#   → result: list — List of Gaussian PDF values corresponding to each input element.
1. For each value x in data, compute the Gaussian density using 1 / (sigma * sqrt(2 * pi)) multiplied by exp(-0.5 * ((x - mu) / sigma) ** 2). → pdf_values
2. Return the computed list of density values. → pdf_values
   ! log: "The standard deviation cannot be zero because the formula divides by sigma."
   ! raise: ZeroDivisionError "Raised when sigma is zero."

## skewness(data: sequence of numbers) → number
Summary: Compute the sample skewness of a numeric dataset using the mean, population variance, and a zero-division guard that returns 0 when the standard deviation is zero.
#   data: sequence of numbers — Input dataset used to compute skewness.
#   → result: number — The computed skewness value, or 0 when standard deviation is zero.
1. Compute n as the length of data. → n
2. Compute mean as the sum of data divided by n. → mean
3. Compute variance as the average of squared deviations from mean over data using divisor n. → variance
4. Compute std_deviation as the square root of variance. → std_deviation
5. If std_deviation is not equal to 0, compute skewness as sum of cubed deviations from mean over data, multiplied by n and divided by ((n - 1) * (n - 2) * std_deviation ** 3); otherwise set skewness to 0. → skewness
6. Return skewness. → result
