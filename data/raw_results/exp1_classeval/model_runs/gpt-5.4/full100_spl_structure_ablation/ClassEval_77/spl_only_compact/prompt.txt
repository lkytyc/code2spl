Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

Class specification:

# Class: Snake
# Fields: SCREEN_HEIGHT, food_position, positions, SCREEN_WIDTH, BLOCK_SIZE, length, score
# Calls: eat_food→random_food_position, move→eat_food, move→reset, reset→random_food_position

## __init__(SCREEN_WIDTH: number, SCREEN_HEIGHT: number, BLOCK_SIZE: number, food_position: any) → none
Summary: Initialize a game state with default length, centered starting position, zero score, copied screen settings, and the initial food position.
#   SCREEN_WIDTH: number — Screen width used to store dimensions and compute the starting horizontal position.
#   SCREEN_HEIGHT: number — Screen height used to store dimensions and compute the starting vertical position.
#   BLOCK_SIZE: number — Block size stored on the instance without modification.
#   food_position: any — Initial food position copied directly into the instance.
#   → result: none — This initializer does not return a value.
1. Set the instance length to 1 as the default starting size. → self.length
2. Copy SCREEN_WIDTH into the instance screen width field. → self.SCREEN_WIDTH
3. Copy SCREEN_HEIGHT into the instance screen height field. → self.SCREEN_HEIGHT
4. Copy BLOCK_SIZE into the instance block size field. → self.BLOCK_SIZE
5. Initialize the instance positions list with one centered position computed as SCREEN_WIDTH divided by 2 and SCREEN_HEIGHT divided by 2. → self.positions
6. Set the instance score to 0. → self.score
7. Copy food_position into the instance food position field. → self.food_position

## eat_food()
Summary: Increases the snake length and score, then spawns a new food position.
1. Increment self.length by 1. → length_updated
2. Increment self.score by 100. → score_updated
3. Call self.random_food_position() to generate the next food location. → food_repositioned

## move(self: object, direction: tuple)
Summary: Update the snake head position by applying the movement direction with screen wraparound, then handle food consumption, self-collision reset, or list growth and trimming.
#   self: object — Instance containing positions, food state, size limits, and game configuration.
#   direction: tuple — Two-value movement vector unpacked into x and y components.
1. Read the current head position from self.positions[0] and unpack direction into x and y. → cur,
2. Compute the next position by adding x multiplied by self.BLOCK_SIZE to the current x coordinate and wrapping it by self.SCREEN_WIDTH, and by adding y multiplied by self.BLOCK_SIZE to the current y coordinate and wrapping it by self.SCREEN_HEIGHT. → new
3. If new equals self.food_position, call self.eat_food(). → food_consumed
4. If self.positions has more than 2 elements and new is found in self.positions[2:], reset the state by calling self.reset(). → reset
   ? Insert new at the front of self.positions.
   ? If the updated self.positions length is greater than self.length, remove the last position with pop().

## random_food_position()
Summary: Repeatedly generates a random grid-aligned food position until it no longer collides with any occupied position.
1. Check whether self.food_position is present in self.positions. → collision_check
2. While self.food_position is present in self.positions, generate a new random grid-aligned position for self.food_position using an x coordinate from 0 to self.SCREEN_WIDTH // self.BLOCK_SIZE - 1 multiplied by self.BLOCK_SIZE and a y coordinate from 0 to self.SCREEN_HEIGHT // self.BLOCK_SIZE - 1 multiplied by self.BLOCK_SIZE. → self.food_position
3. Exit the loop once self.food_position is no longer present in self.positions. → updated_food_position

## reset()
Summary: Reinitialize the game state to the starting length, centered snake position, zero score, and a new food position.
1. Set the length to 1. → self.length
2. Initialize the positions list with a single tuple at the screen center using SCREEN_WIDTH / 2 and SCREEN_HEIGHT / 2. → self.positions
3. Set the score to 0. → self.score
4. Call random_food_position to place food for the reset game state. → self.random_food_position()
