Skeleton Role:

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of the same class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

class SQLQueryBuilder:

    This class provides to build SQL queries, including SELECT, INSERT, UPDATE, and DELETE statements. 
    """


    @staticmethod
    def select(table, columns='*', where=None):
        """
        Generate the SELECT SQL statement from the given parameters.
        :param table: str, the query table in database.
        :param columns: list of str, ['col1', 'col2'].
        :param where: dict, {key1: value1, key2: value2 ...}. The query condition.
        return query: str, the SQL query statement.
        >>> SQLQueryBuilder.select('table1', columns = ["col1","col2"], where = {"age": 15})
        "SELECT col1, col2 FROM table1 WHERE age='15'"
        """

    @staticmethod
    def insert(table, data):
        """
        Generate the INSERT SQL statement from the given parameters.
        :param table: str, the table to be inserted in database.
        :param data: dict, the key and value in SQL insert statement
        :return query: str, the SQL insert statement.
        >>> SQLQueryBuilder.insert('table1', {'name': 'Test', 'age': 14})
        "INSERT INTO table1 (name, age) VALUES ('Test', '14')"
        """

    @staticmethod
    def delete(table, where=None):
        """
        Generate the DELETE SQL statement from the given parameters.
        :param table: str, the table that will be excuted with DELETE operation in database
        :param where: dict, {key1: value1, key2: value2 ...}. The query condition.
        :return query: str, the SQL delete statement.
        >>> SQLQueryBuilder.delete('table1', {'name': 'Test', 'age': 14})
        "DELETE FROM table1 WHERE name='Test' AND age='14'"
        """

    @staticmethod
    def update(table, data, where=None):
        """
        Generate the UPDATE SQL statement from the given parameters.
        :param table: str, the table that will be excuted with UPDATE operation in database

        :param where: dict, {key1: value1, key2: value2 ...}. The query condition.

## insert(table: string, data: dict) → string
Summary: Build an SQL INSERT statement from a table name and a data dictionary by joining the dictionary keys as column names and quoting each value.
#   table: string — Target table name to insert into.
#   data: dict — Dictionary of column names and corresponding values.
#   → result: string — Formatted SQL INSERT statement.
1. Join all keys from data with comma and space to form the column list. → keys
2. Join all values from data with comma and space after wrapping each value in single quotes to form the value list. → values
3. Return an INSERT statement using table, keys, and values in the form INSERT INTO {table} ({keys}) VALUES ({values}). → result

## select(table: string, columns: string or iterable, where: dict or null) → string
Summary: Build a SQL SELECT query from the table name, optional column list, and optional WHERE conditions.
#   table: string — Table name to select from.
#   columns: string or iterable — Columns to select, defaulting to all columns with '*'.
#   where: dict or null — Optional mapping of column names to values for equality filters.
#   → result: string — Rendered SQL query string.
1. If columns is not '*', join the column names with ', ' and replace columns with the resulting string. → columns
2. Create the base SQL string in the form SELECT {columns} FROM {table}. → query
3. If where is provided, append a WHERE clause using AND between equality predicates built as {key}='{value}' for each mapping entry. → query
4. Return the final SQL query string. → result

## update(table: any, data: mapping, where: mapping or null) → string
Summary: Build an SQL UPDATE statement string from a table name, a data mapping, and an optional WHERE clause.
#   table: any — Table name to update.
#   data: mapping — Column-value pairs to place in the SET clause.
#   where: mapping or null — Optional column-value pairs to place in the WHERE clause.
#   → result: string — Constructed SQL UPDATE query string.
1. Create the SET clause string by joining each data item as key='value' with ', '. → update_str
2. Build the base query string as UPDATE {table} SET {update_str}. → query
3. If a where mapping is provided, append a WHERE clause joined by ' AND ' with each condition formatted as key='value'. → query
4. Return the final query string. → query
