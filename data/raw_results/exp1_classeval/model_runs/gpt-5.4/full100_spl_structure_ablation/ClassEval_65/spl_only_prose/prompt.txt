Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

## format_string(self: object, x: string) → string
Summary: Formats a numeric string with optional cents into a spelled-out amount, returning ZERO ONLY when the whole-number part is blank or zero.
#   self: object — Instance providing number-to-words conversion helpers.
#   x: string — Input amount string, optionally containing a decimal point.
#   → result: string — Formatted uppercase amount text ending with ONLY.
1. Split x on the first dot, pad with an empty string, and assign the first part to lstr and the second part to rstr; then reverse lstr into lstrrev and initialize a as a list of five empty strings. → lstr,
2. If the length of lstrrev modulo 3 equals 1, append two zeros to lstrrev; otherwise, if the length modulo 3 equals 2, append one zero to lstrrev; otherwise leave it unchanged. → lstrrev
3. Initialize lm as an empty string. → lm
4. Within the loop over i from 0 up to but not including len(lstrrev) // 3, take the 3-character slice at positions 3*i through 3*i+2, reverse it, and store it in a[i]. → a[i]
5. Within the same loop, if a[i] is not equal to 000, prepend the text from self.trans_three(a[i]) and self.parse_more(i) to lm; otherwise append only the text from self.trans_three(a[i]) to lm. → lm
6. Build xs as AND CENTS followed by self.trans_two(rstr) and a trailing space when rstr is nonempty; otherwise set xs to the empty string. → xs
7. If lm is empty or whitespace after stripping, return ZERO ONLY; otherwise return lm.strip(), followed by a space, xs, and ONLY. → result

## trans_three(s: string) → string
Summary: Convert a three-character numeric string into words by delegating leading-zero cases to the two-digit converter, emitting exact hundreds without a suffix, and otherwise appending the translated last two digits after 'HUNDRED AND'.
#   s: string — A three-character numeric string to translate into words.
#   → result: string — The word-form translation of the input numeric string.
1. Check whether the first character of s is equal to "0". → is_leading_zero
2. If is_leading_zero is true, return the result of calling self.trans_two on the substring s[1:] and stop further processing. → result
3. If the first character of s is not "0", check whether the substring s[1:] is exactly equal to "00". → is_exact_hundred
4. If is_exact_hundred is true, convert s[0] to an integer, use it to index self.NUMBER, concatenate the selected word with " HUNDRED", return that string, and stop further processing. → result
5. If the first character of s is not "0" and s[1:] is not "00", convert s[0] to an integer, use it to index self.NUMBER, call self.trans_two on s[1:], concatenate the hundreds word with " HUNDRED AND " and the translated suffix, and return the final string. → result

   ? Return the word for the first digit from self.NUMBER indexed by int(s[0]) followed by " HUNDRED".
   ? Return the word for the first digit from self.NUMBER indexed by int(s[0]) followed by " HUNDRED AND " and the result of self.trans_two called with s[1:].

## trans_two(s: string) → string
Summary: Convert a numeric string into the English word form for its two-digit value by left-padding to width 2 and handling single digits, teens, exact tens, and general tens-plus-ones cases.
#   s: string — Numeric string to convert, expected to contain digits and treated as a two-digit value after left-padding with zeros to length 2.
#   → result: string — English word representation selected from number lookup tables based on the padded two-digit value.

2. If the first character of s is "0", return self.NUMBER indexed by the integer value of the last character of s. → result
3. Otherwise, if the first character of s is "1", return self.NUMBER_TEEN indexed by integer(s) minus 10. → result
4. Otherwise, if the second character of s is "0", return self.NUMBER_TEN indexed by the integer value of the first character of s minus 1. → result
5. Otherwise, return self.NUMBER_TEN indexed by the integer value of the first character of s minus 1, followed by a space, followed by self.NUMBER indexed by the integer value of the last character of s. → result

   ? Treat the value as a teen number from 10 through 19 and return the teen-word lookup using integer(s) minus 10.
   ? Treat the value as an exact multiple of ten and return only the tens-word lookup for the first digit minus 1.
   ? Construct the result as the tens-word lookup, then a single space, then the ones-word lookup.
