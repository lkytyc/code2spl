Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

# Class: IpUtil

## get_hostname(ip_address: string) → string_or_none
Summary: Resolve an IP address to its primary hostname using reverse DNS and return null-equivalent None when the lookup raises a socket.herror.
#   ip_address: string — IP address to resolve to a hostname via reverse DNS lookup
#   → result: string_or_none — Primary hostname for the IP address if reverse lookup succeeds, otherwise None
1. Attempt to perform a reverse DNS lookup for the given ip_address using socket.gethostbyaddr(ip_address). → host_lookup_result
2. From the successful lookup result, take the element at index 0 as the primary hostname. → hostname
3. Return the primary hostname. → result
   ? Return None instead of a hostname.

## is_valid_ipv4(ip_address: string) → boolean
Summary: Checks whether a given string is a valid IPv4 address by attempting an IPv4-specific socket parse and returning a boolean based on whether a socket error occurs.
#   ip_address: string — The candidate IP address string to validate as IPv4.
#   → result: boolean — True if the input can be parsed as a valid IPv4 address; otherwise False.
1. Attempt to parse ip_address as an IPv4 address using socket.inet_pton with the socket.AF_INET address family. → ipv4_parse_attempt
2. If the IPv4 parse attempt succeeds without raising socket.error, return True immediately. → result
   ? Catch the socket.error raised during IPv4 parsing.
   ? Return False as the validation result.

## is_valid_ipv6(ip_address: string) → boolean
Summary: Validate whether the input string is a syntactically valid IPv6 address by attempting an IPv6 socket conversion and returning a boolean result.
#   ip_address: string — The IP address string to validate as an IPv6 address.
#   → result: boolean — True when the input can be parsed as an IPv6 address, otherwise False.
1. Attempt to parse the input ip_address as an IPv6 address by calling socket.inet_pton with socket.AF_INET6 and ip_address. → ipv6_parse_attempt
2. If the IPv6 parse attempt succeeds without raising an exception, return True immediately. → result
   ? Catch the socket.error from the IPv6 parse attempt and return False.
