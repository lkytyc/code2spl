Summary: Compute the Pearson correlation coefficient between two sequences, returning None when the standard deviation product is zero.
#   x: sequence — First numeric sequence used to compute the mean, covariance, and variance term.
#   y: sequence — Second numeric sequence used to compute the mean, covariance, and variance term.
#   → result: number or null — The correlation coefficient, or None if the denominator is zero.
1. Compute n as the length of x. → n
2. Compute mean_x as the sum of x divided by n. → mean_x
3. Compute mean_y as the sum of y divided by n. → mean_y
4. Compute numerator as the sum of (xi - mean_x) * (yi - mean_y) for each paired xi, yi from zip(x, y). → numerator
5. Compute denominator as the square root of the product of the sum of squared deviations of x from mean_x and the sum of squared deviations of y from mean_y. → denominator
6. If denominator equals 0, return None immediately. → None
7. Otherwise, return numerator divided by denominator. → result
   ? Use only paired elements up to the shorter input length when summing covariance terms.
   ? Attempting to compute mean_x or mean_y with n equal to 0 causes a division by zero error.
