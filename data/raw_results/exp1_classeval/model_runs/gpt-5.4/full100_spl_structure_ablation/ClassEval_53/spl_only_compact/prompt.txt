Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

Class specification:

# Class: LongestWord
# Fields: word_list

## __init__(self: object)
Summary: Initialize the instance by setting self.word_list to a new empty list.
#   self: object — The instance whose word_list attribute is being initialized.
1. Assign a fresh empty list to the instance attribute self.word_list. → self.word_list

## add_word(self: object, word: any)
Summary: Append the provided word to the end of the object's existing word list.
#   self: object — Object instance that owns the existing word_list collection.
#   word: any — Value or object reference to append to the end of self.word_list.
1. Append the current value or reference of word to the end of self.word_list, mutating the existing list in place without transforming word. → self.word_list

## find_longest_word(sentence: string) → string
Summary: Normalize an input sentence by lowercasing and removing punctuation, then return the first longest token that appears in self.word_list, or an empty string if none qualify.
#   sentence: string — The input sentence to normalize, sanitize, and split into candidate words.
#   → longest_word: string — The longest word from the processed sentence that is present in self.word_list, or an empty string if no matching word is found.
1. Initialize longest_word to the empty string as the default result when no qualifying word is found. → longest_word
2. Convert sentence to lowercase so later matching against self.word_list is case-insensitive relative to the transformed input. → sentence
3. Remove all punctuation characters from sentence by replacing every character matched by the regex pattern built from re.escape(string.punctuation) with an empty string. → sentence
4. Split sentence on the single-space delimiter ' ' to transform it from a string into a list of tokens. → sentence
5. Iterate over each word in the token list sentence in order. → word
6. Within the loop over each word, check whether word is in self.word_list and, only if that membership test is true, check whether len(word) is strictly greater than len(longest_word). → is_qualifying_longer_word
7. Within the same loop iteration, if both conditions are true, assign longest_word = word; because the comparison is strict '>', equal-length matches do not replace the current value, so the first longest qualifying word is preserved. → longest_word
8. After all tokens have been processed, return longest_word. → longest_word
