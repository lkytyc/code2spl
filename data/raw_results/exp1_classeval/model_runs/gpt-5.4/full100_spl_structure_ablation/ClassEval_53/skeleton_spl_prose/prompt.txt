Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of the same class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

## find_longest_word(sentence: string) → string
Summary: Normalize an input sentence by lowercasing and removing punctuation, then return the first longest token that appears in self.word_list, or an empty string if none qualify.
#   sentence: string — The input sentence to normalize, sanitize, and split into candidate words.

2. Convert sentence to lowercase so later matching against self.word_list is case-insensitive relative to the transformed input. → sentence

5. Iterate over each word in the token list sentence in order. → word
6. Within the loop over each word, check whether word is in self.word_list and, only if that membership test is true, check whether len(word) is strictly greater than len(longest_word). → is_qualifying_longer_word
7. Within the same loop iteration, if both conditions are true, assign longest_word = word; because the comparison is strict '>', equal-length matches do not replace the current value, so the first longest qualifying word is preserved. → longest_word
8. After all tokens have been processed, return longest_word. → longest_word
