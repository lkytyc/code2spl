Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

# Class: BigNumCalculator

## add(num1: string, num2: string) → string
Summary: Add two numbers represented as strings by left-padding them to equal length, summing digits from right to left with carry propagation, and returning the resulting string.
#   num1: string — The first numeric string to add.
#   num2: string — The second numeric string to add.
#   → result: string — The decimal string produced by adding the two input numeric strings.
1. Compute max_length as the larger of len(num1) and len(num2). → max_length
2. Reassign num1 to num1.zfill(max_length) so it is left-padded with zeros to length max_length. → num1
3. Reassign num2 to num2.zfill(max_length) so it is left-padded with zeros to length max_length. → num2
4. Initialize carry to 0. → carry
5. Initialize result as an empty list to accumulate output digits. → result
6. For i from max_length - 1 down to 0 inclusive with step -1, compute digit_sum as int(num1[i]) + int(num2[i]) + carry, update carry to digit_sum // 10, compute digit as digit_sum % 10, and insert str(digit) at index 0 of result. → result_and_carry_after_loop
7. If carry > 0 after the loop, insert str(carry) at index 0 of result. → result
8. Join all elements of result into a single string and return it. → return_value

## multiply(num1: string, num2: string) → string
Summary: Multiplies two numeric strings by simulating digit-by-digit long multiplication into an integer array and then returns the array contents as a string after skipping leading zeros.
#   num1: string — The first numeric string whose characters are expected to be individually convertible to digits.
#   num2: string — The second numeric string whose characters are expected to be individually convertible to digits.
#   → result_string: string — The decimal string formed from the multiplication result array after removing leading zeros while preserving at least one digit.
1. Read num1 and num2, compute len1 = len(num1) and len2 = len(num2), and allocate result as a zero-filled list of length len1 + len2. → len1_len2_result
2. For i from len1 - 1 down to 0 inclusive, iterate backward over every digit position in num1. → outer_loop_i
3. Within the outer loop over i, for j from len2 - 1 down to 0 inclusive, iterate backward over every digit position in num2. → inner_loop_j
4. Within the nested loops for the current i and j, convert num1[i] and num2[j] to integers and compute mul as their product. → mul
5. Within the nested loops for the current i and j, compute p1 = i + j and p2 = i + j + 1 as the carry and digit positions in result. → p1_p2
6. Within the nested loops for the current i and j, compute total = mul + result[p2] to accumulate the new product with any previously stored value at position p2. → total
7. Within the nested loops for the current i and j, add total // 10 to result[p1] and assign total % 10 to result[p2]. → updated_result
8. Initialize start to 0. → start
9. While start < len(result) - 1 and result[start] == 0, increment start by 1 to skip leading zeros without removing the final remaining digit. → trimmed_start
10. Return the string produced by joining the decimal string form of each element in result[start:]. → result_string

## subtract(num1: string, num2: string) → string
Summary: Subtract two non-negative integer strings by normalizing their lengths, performing digit-by-digit subtraction with borrowing, removing leading zeros, and prefixing a minus sign when the result is negative.
#   num1: string — First numeric string operand.
#   num2: string — Second numeric string operand.
#   → result: string — The decimal subtraction result as a string, with a leading minus sign if needed.
1. Compare the lengths of num1 and num2, and if num1 is shorter, swap the two values and mark the result as negative. → negative
2. If num1 is longer than num2, keep the values as they are and mark the result as non-negative. → negative
3. If num1 and num2 have equal length, compare them lexicographically; if num1 is smaller, swap the two values and mark the result as negative, otherwise mark the result as non-negative. → negative
4. Compute max_length as the greater of the lengths of num1 and num2. → max_length
5. Pad num1 on the left with zeros to reach max_length. → num1
6. Pad num2 on the left with zeros to reach max_length. → num2
7. Initialize borrow to 0 and result to an empty list. → borrow,result
8. For each index i from max_length - 1 down to 0 inclusive, compute digit_diff as int(num1[i]) - int(num2[i]) - borrow. → digit_diff
9. Within the backward digit loop, if digit_diff is negative, add 10 to digit_diff and set borrow to 1. → borrow
10. Within the backward digit loop, otherwise set borrow to 0. → borrow
11. Within the backward digit loop, insert the current digit_diff string at the front of result. → result
12. After the digit loop, while result has more than one element and the first element is '0', remove the first element. → result
13. If negative is true, insert '-' at the front of result. → result
14. Join the elements of result into a single string and return it. → return
