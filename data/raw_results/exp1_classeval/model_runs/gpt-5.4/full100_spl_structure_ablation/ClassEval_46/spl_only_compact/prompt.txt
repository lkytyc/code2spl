Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

## interpolate_1d(x: list, y: list, x_interp: list) → list
Summary: Interpolates y values for each target x position by scanning adjacent x intervals and applying inclusive-boundary linear interpolation on the first matching segment.
#   x: list — Ordered source x coordinates used to define adjacent interpolation intervals.
#   y: list — Source y values aligned with x and used to compute interpolated values.
#   x_interp: list — Target x coordinates for which interpolated y values are requested.
#   → y_interp: list — List of interpolated y values for target points that fall within at least one adjacent interval in x.
1. Initialize y_interp as an empty list. → y_interp
2. For each target value xi in x_interp, scan interval indices i from 0 through len(x) - 2. → xi_and_i_iteration
3. Within the loop for the current xi and interval index i, check whether xi lies in the inclusive interval from x[i] to x[i+1] using the condition x[i] <= xi <= x[i+1]. → interval_match_check
4. When the inclusive interval condition is true, compute yi as y[i] + (y[i+1] - y[i]) * (xi - x[i]) / (x[i+1] - x[i]). → yi
5. Append the computed yi to y_interp. → y_interp
6. After appending for the current xi, break out of the inner interval-scanning loop so only the first matching interval contributes a value for that xi. → inner_loop_terminated_for_current_xi
7. If no interval satisfies x[i] <= xi <= x[i+1] for a given xi, append nothing for that xi and continue with the next target value. → no_output_for_unmatched_xi
8. Return y_interp after all target values have been processed. → return_y_interp
   ? Use the first interval encountered during the scan from i = 0 to len(x) - 2 that satisfies x[i] <= xi <= x[i+1].
   ? Compute yi from that first matching interval, append it to y_interp, and break the inner loop without checking later intervals for the same xi.
   ? Perform no interval scans for any xi because there are no adjacent x pairs to define an interpolation segment.
   ? Return the still-empty y_interp list.

## interpolate_2d(x: list, y: list, z: list, x_interp: list, y_interp: list) → list
Summary: Compute bilinearly interpolated z-values for paired target coordinates by locating the containing x and y grid intervals and combining the four surrounding grid values.
#   x: list — Ordered x-axis grid coordinates used to locate horizontal interpolation intervals.
#   y: list — Ordered y-axis grid coordinates used to locate vertical interpolation intervals.
#   z: list — Two-dimensional grid of values indexed by x and y interval endpoints.
#   x_interp: list — Target x coordinates for interpolation, consumed in pairwise order with y_interp.
#   y_interp: list — Target y coordinates for interpolation, consumed in pairwise order with x_interp.
#   → z_interp: list — List of interpolated values produced only for target pairs that reach a matched x interval and matched y interval.
1. Initialize z_interp as an empty list. → z_interp
2. Iterate over paired target coordinates xi and yi from zip(x_interp, y_interp). → paired_target_iteration
3. Within the loop for each xi and yi, iterate i from 0 to len(x) - 2 to search for the first x interval whose inclusive bounds satisfy x[i] <= xi <= x[i+1]. → x_interval_search
4. When an x interval match is found for the current i, iterate j from 0 to len(y) - 2 to search for the first y interval whose inclusive bounds satisfy y[j] <= yi <= y[j+1]. → y_interval_search
5. Within the matched x and y interval context, assign z00 = z[i][j], z01 = z[i][j+1], z10 = z[i+1][j], and z11 = z[i+1][j+1]. → corner_values
6. Compute zi using bilinear interpolation: ((z00 * (x[i+1] - xi) * (y[j+1] - yi)) + (z10 * (xi - x[i]) * (y[j+1] - yi)) + (z01 * (x[i+1] - xi) * (yi - y[j])) + (z11 * (xi - x[i]) * (yi - y[j]))) divided by ((x[i+1] - x[i]) * (y[j+1] - y[j])). → zi
7. Append zi to z_interp and then break out of the j loop so no later y intervals are checked for the current target pair. → z_interp
8. After finishing the y-interval search block for a matched x interval, break out of the i loop unconditionally so no later x intervals are checked for the current target pair. → x_interval_search_terminated
9. After all paired target coordinates have been processed, return z_interp. → z_interp
   ? Do not enter the y interval search, do not compute an interpolated value, do not append anything for that target pair, and continue to the next paired target coordinates.
   ? Do not compute or append an interpolated value for that target pair.
   ? Still execute the unconditional break from the i loop after the y search completes, ending x interval checking for that target pair.
   ? Use the first matching x interval and the first matching y interval encountered because both boundary checks are inclusive and the loop exits on the first successful match.
   ? Process only as many target pairs as zip(x_interp, y_interp) produces, which is limited to the shorter input sequence.
