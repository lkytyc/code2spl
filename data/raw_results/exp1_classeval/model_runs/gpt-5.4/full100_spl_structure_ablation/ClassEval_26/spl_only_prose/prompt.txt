Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

# Class: CSVProcessor

## __init__()
Summary: Initialize the object without performing any additional setup.
1. Create the object and perform no initialization beyond the default constructor behavior. → self

## process_csv_data(N: integer, save_file_name: string) → any
Summary: Reads CSV data, extracts the Nth column from each row, uppercases those values, and writes the result to a new CSV file with a _process suffix.
#   N: integer — Zero-based column index to extract from each row.
#   save_file_name: string — Input CSV file name and base for the output file name.
#   → result: any — Return value from writing the processed CSV data to the output file.
1. Read the CSV data from save_file_name and unpack the returned title and data values. → title,
2. Build a list containing the Nth element from each row in data. → column_data
3. Replace column_data with a new list where every element is converted to uppercase. → column_data
4. Create new_data as a two-item list containing title and the transformed column_data. → new_data
5. Write new_data to a file named by removing the original extension from save_file_name and appending _process.csv. → result

## read_csv(file_name: string) → tuple
Summary: Reads a CSV file, stores all data rows after the header, and returns the header and collected rows.
#   file_name: string — Path to the CSV file to read.
#   → result: tuple — A tuple containing the header row and a list of data rows.
1. Initialize an empty list named data to store CSV rows. → data
2. Open the file at file_name in read mode as file. → file
3. Create a CSV reader from file. → reader
4. Read the first row from reader as the header title. → title
5. For each remaining row in reader, append the row to data. → data
6. Return title and data. → result

## write_csv(data: list, file_name: string) → int
Summary: Writes rows of data to a CSV file and returns 1 on success or 0 if any exception occurs.
#   data: list — Rows of data to write to the CSV file.
#   file_name: string — Path to the output CSV file.
#   → result: int — 1 if the CSV write succeeds, otherwise 0.
1. Try to open file_name in write mode with newline set to an empty string. → file
2. Create a CSV writer for the opened file. → writer
3. Write all rows from data to the CSV file using the writer. → written_rows
4. Close the file automatically when the with-block ends. → file_closed
5. Return 1 to indicate success. → result
   ? Handle the exception by skipping normal completion.
   ? Return 0 to indicate failure.
