Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

## __init__(text: object, pattern: object)

#   text: object — Input text value to store and to measure with len(...).
#   pattern: object — Input pattern value to store and to measure with len(...).

## bad_character_heuristic(self: object) → list
Summary: Scan all valid pattern start positions in the text, collect positions with no mismatch, and otherwise compute a bad-character-style shift value that does not affect the actual Python for-loop progression.
#   self: object — Instance containing text, pattern, their lengths, and helper methods used to detect mismatches and locate characters in the pattern.
#   → positions: list — List of starting indices where the pattern fully matches the text.
1. Initialize an empty list named positions to store successful match start indices. → positions
2. Iterate i over every integer from 0 inclusive to self.textLen - self.patLen inclusive by using range(self.textLen - self.patLen + 1), covering every valid text start position where the pattern can fit. → loop_i
3. Within the for loop for each current i, call self.mismatch_in_text(i) to determine whether the pattern mismatches the text at that start position, where -1 means no mismatch and any other value is a mismatch index in the text. → mismatch_index
4. Within the for loop, if mismatch_index equals -1, append the current i to positions because the pattern fully matches at that start position. → positions
5. Within the same for loop, otherwise when mismatch_index is not -1, read the mismatching text character as self.text[mismatch_index] and call self.match_in_pattern on that character to get match_index. → match_index
6. Within that mismatch branch, assign i = mismatch_index - match_index as a computed bad-character-style shift candidate for the current iteration only. → i
7. Continue through the for loop using the next value produced by range regardless of the reassignment to i, because in Python this inner assignment does not alter future loop iteration values. → for_loop_progression
8. After the loop finishes, return positions. → positions

## match_in_pattern(char: character) → integer
Summary: Searches backward through the pattern and returns the rightmost index of the input character, or -1 if the character does not appear.
#   char: character — The character to search for in the pattern.
#   → result: integer — The rightmost index where the character is found in the pattern, or -1 if no match exists.
1. Iterate index i backward from self.patLen - 1 down to 0 inclusive using step -1. → i
2. Within the backward loop over i, compare char with self.pattern[i]. → is_match
3. If char equals self.pattern[i] within the loop, return i immediately as the result. → result
4. After the loop completes with no match found at any index, return -1. → result
   ? Return the current index i immediately without checking any earlier indices.

## mismatch_in_text(currentPos: integer) → integer
Summary: Scans the pattern against the text from right to left at the given alignment and returns the text index of the first backward-found mismatch, or -1 if all positions match.
#   currentPos: integer — Starting alignment index in self.text where self.pattern is compared.
#   → result: integer — The index in self.text of the first mismatch encountered during backward scanning, or -1 if no mismatch is found.
1. Iterate i in reverse from self.patLen - 1 down to 0 inclusive using range(self.patLen - 1, -1, -1). → i
2. Within the reverse loop for each i, compare self.pattern[i] with self.text[currentPos + i]. → comparison_result
3. Within the reverse loop, if self.pattern[i] is not equal to self.text[currentPos + i], immediately return currentPos + i as the mismatch index in self.text. → result
4. If the loop completes without any mismatch at any index from self.patLen - 1 down to 0, return -1. → result
   ? Return currentPos + i immediately without checking any smaller indices.
