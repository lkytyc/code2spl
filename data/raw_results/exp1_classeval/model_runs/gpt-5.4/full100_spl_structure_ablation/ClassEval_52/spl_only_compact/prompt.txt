Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

## get_pos_tag(sentence: text) → list
Summary: Removes punctuation from an input sentence, tokenizes the cleaned text, tags each token with its part of speech, and returns the list of POS tag labels.
#   sentence: text — The input sentence to clean, tokenize, and part-of-speech tag.
#   → pos_tags: list — A list containing the part-of-speech tag string for each token in the cleaned sentence.
1. Initialize an empty list to accumulate part-of-speech tags. → pos_tags
2. Remove punctuation from the input sentence by calling self.remove_punctuation on the current sentence value and overwrite sentence with the cleaned text. → sentence
3. Tokenize the cleaned sentence into word tokens using word_tokenize. → words
4. Assign part-of-speech tags to the token list using pos_tag. → tagged_words
5. For each tagged_word in tagged_words, append the element at index 1, which is the part-of-speech tag, to pos_tags. → pos_tags
6. Return the accumulated list of part-of-speech tags. → pos_tags

## lemmatize_sentence(sentence: string) → list
Summary: Normalize a sentence by removing punctuation, tokenize and POS-tag its words, then lemmatize each token using POS-specific rules and return the resulting list.
#   sentence: string — Input sentence text to clean, tokenize, tag, and lemmatize.
#   → lemmatized_words: list — List of lemmatized tokens produced from the cleaned and tagged sentence, in original token order.
1. Initialize an empty list to collect lemmatized output tokens. → lemmatized_words
2. Remove punctuation from the input sentence by reassigning sentence to the result of self.remove_punctuation(sentence). → sentence
3. Tokenize the cleaned sentence into words using word_tokenize(sentence). → words
4. Assign part-of-speech tags to the token list using pos_tag(words). → tagged_words
5. For each (word, tag) pair in tagged_words, if tag starts with 'V', lemmatize the word with self.lemmatizer.lemmatize(word, pos='v'); else if tag starts with 'J', lemmatize it with self.lemmatizer.lemmatize(word, pos='a'); else if tag starts with 'R', lemmatize it with self.lemmatizer.lemmatize(word, pos='r'); otherwise lemmatize it with self.lemmatizer.lemmatize(word). → lemmatized_word
6. Within the same loop iteration for each tagged word, append the computed lemmatized_word to lemmatized_words. → lemmatized_words
7. Return the accumulated lemmatized_words list after all tagged words have been processed. → return
   ? Skip all per-token lemmatization and appending because there are no tagged word pairs to process.
   ? Return the still-empty lemmatized_words list.

## remove_punctuation(sentence: string) → string
Summary: Remove all punctuation characters defined by string.punctuation from the input sentence and return the resulting string.
#   sentence: string — Input text to process by removing punctuation characters.
#   → result: string — The input sentence with every character in string.punctuation removed and all other characters preserved.
1. Read the punctuation character set from string.punctuation and create a translation table with str.maketrans('', '', string.punctuation) that marks those characters for deletion without any character substitution. → translation_table
2. Apply sentence.translate(translation_table) to remove all punctuation characters from the input sentence. → result
3. Return the transformed string result. → return
