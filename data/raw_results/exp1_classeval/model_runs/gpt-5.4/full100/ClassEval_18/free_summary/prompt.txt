`CamelCaseMap` is a small mapping-like class that stores values in an internal dictionary while normalizing string keys to camelCase.

When you create an instance, it starts with an empty internal dictionary called `_data`.

Its item access methods work like this:
- Setting a value with `obj[key] = value` converts the key first, then stores the value in `_data`.
- Reading a value with `obj[key]` converts the key the same way, then looks it up in `_data`.
- Deleting with `del obj[key]` also converts the key before removing it.

Key conversion only happens for string keys. Non-string keys are used unchanged.

The string conversion logic changes underscore-separated names into camelCase:
- It splits the string on underscores.
- It keeps the first part as-is.
- It capitalizes each later part and joins them back together.
For example, a key like `my_key_name` becomes `myKeyName`.

The class also supports:
- iteration, which yields the keys stored in the internal dictionary
- `len(...)`, which returns the number of stored entries

An important effect of this design is that different string forms that normalize to the same camelCase key will refer to the same stored entry.
