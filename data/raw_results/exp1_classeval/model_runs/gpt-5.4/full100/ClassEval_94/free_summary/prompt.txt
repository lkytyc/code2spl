This code defines a `VendingMachine` class that keeps track of available items and a current inserted-money balance.

When a machine is created, it starts with an empty inventory and a balance of 0.

The inventory stores each item by name, along with its price and quantity.

Main behaviors:

- `add_item(item_name, price, quantity)`:
  Adds a new item to the machine. It first tries to restock an existing item by calling `restock_item`. If the item is already present, only the quantity is increased and the given price is ignored. If the item is not present, a new inventory entry is created with the provided price and quantity.

- `insert_coin(amount)`:
  Adds the given amount to the current balance and returns the updated balance.

- `purchase_item(item_name)`:
  Attempts to buy an item. If the item exists, has quantity greater than 0, and the current balance is at least the item’s price, the method reduces the balance by the price, decreases the item quantity by 1, and returns the remaining balance. If the item does not exist, is out of stock, or there is not enough balance, it returns `False`.

- `restock_item(item_name, quantity)`:
  If the item already exists in the inventory, it increases that item’s quantity and returns `True`. If the item does not exist, it returns `False`.

- `display_items()`:
  If the inventory is empty, it returns `False`. Otherwise, it returns a newline-separated string listing each item in the format:
  `item_name - $price [quantity]`

Important interactions:
- `add_item` depends on `restock_item` to decide whether to increase the quantity of an existing item or create a new one.
- `purchase_item` uses both the inventory data and the current balance to decide whether a purchase can succeed.

Outputs are simple values:
- updated balance from `insert_coin`
- remaining balance or `False` from `purchase_item`
- `True`/`False` from `restock_item`
- either a formatted item list or `False` from `display_items`
