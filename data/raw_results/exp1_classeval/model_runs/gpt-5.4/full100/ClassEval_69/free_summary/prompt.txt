This code defines a `PDFHandler` class that works with one or more PDF files using the `PyPDF2` library.

When you create a `PDFHandler`, you pass in a list of file paths. The constructor saves that list and immediately creates a `PyPDF2.PdfReader` object for each file, storing all of those reader objects in `self.readers`.

The class provides two main behaviors:

- `merge_pdfs(output_filepath)`:
  - Creates a new PDF writer.
  - Goes through every loaded PDF and then through every page in each PDF.
  - Adds each page, in order, to the writer.
  - Writes the combined result to the given output file path in binary mode.
  - Returns a confirmation string saying where the merged PDF was saved.

- `extract_text_from_pdfs()`:
  - Goes through every loaded PDF and every page in each one.
  - Calls `extract_text()` on each page.
  - Collects the extracted text results into a list.
  - Returns that list, with one entry per page across all input PDFs.

In short, the input is a list of PDF file paths, and the class can either combine all pages into one output PDF file or return the text extracted from all pages. The main interaction is that both methods operate on the `PdfReader` objects prepared during initialization.
