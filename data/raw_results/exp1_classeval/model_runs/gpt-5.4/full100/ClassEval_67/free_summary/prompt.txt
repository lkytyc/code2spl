This code defines an `Order` class that tracks available menu items, dishes selected for the current order, and per-dish sales multipliers.

When an `Order` object is created, it starts with:
- `menu`: a list of dish records, each expected to include a dish name, price, and available count.
- `selected_dishes`: a list of dishes the customer has added to the current order.
- `sales`: a dictionary used during price calculation, keyed by dish name.

The `add_dish` method takes a dish dictionary as input. It looks through the menu for an item with the same dish name. If it finds one:
- If the requested quantity is greater than the available quantity, it returns `False`.
- Otherwise, it reduces the menu’s available count by the requested amount and stops searching.
After that, it adds the dish to `selected_dishes` and returns `True`.

The `calculate_total` method computes the total cost of the currently selected dishes. For each selected dish, it multiplies:
- the dish’s price,
- the selected quantity,
- and the corresponding value in `sales` for that dish name.
It returns the summed total.

The `checkout` method finalizes the current order. If no dishes have been selected, it returns `False`. Otherwise, it calculates the total using `calculate_total`, clears the current `selected_dishes` list, and returns the total amount.

Important interaction details:
- `checkout` depends on `calculate_total`.
- `calculate_total` depends on `sales` containing an entry for every selected dish name.
- `add_dish` updates `menu` inventory and also records the selected dish in `selected_dishes`.
