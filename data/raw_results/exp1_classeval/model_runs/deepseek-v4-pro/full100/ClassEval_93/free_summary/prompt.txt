- **`similarity(vector_1, vector_2)`**  
  Computes the cosine similarity between two vectors by first normalizing each to unit length and then taking their dot product. Returns a scalar similarity score.

  Computes cosine similarity between one vector and a set of vectors. It normalizes all vectors and returns an array of similarity scores, one for each vector in the set.

  Computes cosine similarity between two lists of vectors. It averages the vectors in each list, normalizes the averages, and returns their dot product. Raises a `ZeroDivisionError` if either list is empty.

  Computes inverse document frequency (IDF) weights for terms. It takes the total number of documents and a dictionary mapping terms to their document frequencies. It applies a smoothed IDF formula and returns a dictionary mapping each term to its IDF weight.
