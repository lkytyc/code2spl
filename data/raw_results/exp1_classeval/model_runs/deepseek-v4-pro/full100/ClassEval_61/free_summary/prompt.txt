This code defines a `MusicPlayer` class that simulates basic music playback controls.

**State:**  
Each player instance maintains a playlist (list of songs), a reference to the current song (or `None` if stopped), and a volume level (default 50).

**Inputs and outputs:**  
- `add_song(song)` adds a song to the playlist.  
- `remove_song(song)` removes a song if present; if it was the current song, playback stops.  
- `play()` returns the first song in the playlist if a current song is set, otherwise returns `False`.  
- `stop()` clears the current song and returns `True` if a song was playing, otherwise returns `False`.  
- `switch_song()` moves to the next song in the playlist if possible, returning `True` on success or `False` if at the end or no current song.  
- `previous_song()` moves to the previous song if possible, returning `True` on success or `False` if at the start or no current song.  
- `set_volume(volume)` sets the volume if the given value is between 0 and 100 inclusive; otherwise returns `False`.  
- `shuffle()` randomly reorders the playlist if it is non-empty, returning `True`; otherwise returns `False`.

**Interactions:**  
The current song is tracked separately from the playlist order. Removing the current song stops playback. Navigation methods (`switch_song`, `previous_song`) rely on the current song’s position in the playlist. Volume changes do not affect playback state.
