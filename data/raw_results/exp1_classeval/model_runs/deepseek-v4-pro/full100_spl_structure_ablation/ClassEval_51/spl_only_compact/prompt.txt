Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

# Class: KappaCalculator

## fleiss_kappa(N: int, k: int, n: int) → float
Summary: Compute Fleiss' kappa statistic from an N-by-k count matrix by calculating observed agreement P0 and expected agreement Pe, then returning (P0 - Pe) / (1 - Pe).
#   N: int — Number of rows/items in testData.
#   k: int — Number of columns/categories in testData.
#   n: int — Number of raters used to normalize per-item agreement.
#   → fleiss_kappa_statistic: float — Fleiss' kappa statistic as a scalar floating-point value.
1. Convert testData into a NumPy matrix dataMat with float dtype. → dataMat
2. Create a k by 1 column vector oneMat filled with 1.0. If k is negative, this construction is invalid. → oneMat
3. Initialize scalar accumulator sum to 0.0. → sum
4. Initialize scalar accumulator P0 to 0.0. → P0
5. For each row index i from 0 to N-1 inclusive, start an outer loop iteration and set temp to 0.0. If N is less than or equal to 0, skip the outer loop body entirely. → temp
6. Within the outer loop over i, for each column index j from 0 to k-1 inclusive, add dataMat[i, j] to sum. If k is less than or equal to 0, skip the inner loop body but still execute the remaining outer loop body. → sum
7. Within the same inner loop over j, for each column index j, add 1.0 * dataMat[i, j] ** 2 to temp. → temp
8. Within the outer loop over i, after the inner loop over j completes, subtract n from temp, divide temp by (n - 1) * n, and add the result to P0. → P0
9. After the outer loop completes, compute P0 = 1.0 * P0 / N. If N is zero, this division is undefined or raises a zero-division error depending on the runtime. → P0
10. Compute ysum as the sum of dataMat along axis 0, producing a 1 by k row vector of column totals. → ysum
11. For each i from 0 to k-1 inclusive, update ysum[0, i] = (ysum[0, i] / sum) ** 2. If k is less than or equal to 0, skip this loop. If sum is zero, the division is undefined or raises a zero-division error depending on the runtime. → ysum
12. Compute Pe as the matrix product ysum * oneMat * 1.0, yielding a 1 by 1 matrix. → Pe
13. Compute ans = (P0 - Pe) / (1 - Pe). If Pe equals 1, the denominator is zero and the result is undefined or infinite. → ans
14. Return ans[0, 0] as the computed Fleiss kappa statistic. → return_value

## kappa(k: int) → float
Summary: Computes Cohen's kappa coefficient from a matrix by accumulating the diagonal elements as observed agreement and deriving expected agreement from the total and marginal sums.
#   k: int — The number of diagonal elements to include, controlling the loop range from 0 to k-1.
#   → cohens_coefficient: float — The computed Cohen's kappa coefficient.
1. Convert testData into a NumPy matrix and assign it to dataMat. → dataMat
2. Initialize P0 to the float constant 0.0. → P0
3. Within the for loop over i in range(k), add dataMat[i, i] multiplied by 1.0 to P0. → P0
4. Compute xsum as the row sums of dataMat using np.sum(dataMat, axis=1). → xsum
5. Compute ysum as the column sums of dataMat using np.sum(dataMat, axis=0). → ysum
6. Compute sum as the total sum of all elements in dataMat using np.sum(dataMat). → sum
7. Compute Pe by converting the element-wise product of ysum and xsum to float, then performing left-to-right division by sum twice. → Pe
8. Update P0 to float(P0 / sum * 1.0). → P0
9. Compute cohens_coefficient as float((P0 - Pe) / (1 - Pe)). → cohens_coefficient
10. Return cohens_coefficient. → cohens_coefficient
