Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

Class specification:

# Class: TicTacToe
# Fields: current_player, board

## __init__(self: object, N: int)
Summary: Initialize a three-row board with N columns per row, defaulting N to 3, fill every cell with a blank space, and set the current player to X.
#   self: object — The current object instance being initialized.
#   N: int — Number of columns in each of the three board rows; defaults to 3 when omitted.
1. Assign to self.board a newly created list of 3 rows, where each row is a list of N cells initialized to the single space character ' '; if N is less than or equal to 0, range(N) is empty and each row is an empty list. → self.board
2. Then assign the constant string 'X' to self.current_player. → self.current_player

## check_winner()
Summary: Determines the winner of a 3x3 Tic-Tac-Toe board by checking rows, columns, and both diagonals for three equal non-space marks and returns the winning mark or None.
1. For each row in self.board, if row[0], row[1], and row[2] are all equal and not ' ', set winner to row[0] and return immediately. → winner
2. For each column index col from 0 to 2 inclusive, if self.board[0][col], self.board[1][col], and self.board[2][col] are all equal and not ' ', set winner to self.board[0][col] and return immediately. → winner
3. If self.board[0][0], self.board[1][1], and self.board[2][2] are all equal and not ' ', set winner to self.board[0][0] and return immediately. → winner
4. If self.board[0][2], self.board[1][1], and self.board[2][0] are all equal and not ' ', set winner to self.board[0][2] and return immediately. → winner
5. If none of the preceding row, column, or diagonal checks returned a winner, set winner to None and return it. → winner

## is_board_full() → bool
Summary: Checks whether the board is full by returning False if any row contains a space, otherwise returning True.
#   → is_full_result: bool — True when the board is full; False when any row contains a space.
1. Iterate over each row in self.board. → current_row
2. Within the loop over each row, test whether the current row contains the space character ' '. → row_has_space
3. After the loop completes without finding a row that contains a space, return True. → is_full_result
   ? Return False immediately and stop processing any remaining rows.

## make_move(row: int, col: int) → bool
Summary: Attempts to place the current player's mark at the requested board cell if it is empty, switches the current player on success, and returns a boolean indicating whether the move was accepted.
#   row: int — Row index of the board cell to update.
#   col: int — Column index of the board cell to update.
#   → move_succeeded: bool — True when the cell was empty and the move was applied; False when the cell was already occupied.
1. Check whether self.board[row][col] equals exactly the empty space character ' '. → is_empty_cell
2. If is_empty_cell is true, set self.board[row][col] to self.current_player. → updated_board
3. If is_empty_cell is true, toggle self.current_player: if self.current_player equals 'X', set it to 'O'; otherwise set it to 'X'. → updated_current_player
4. If is_empty_cell is true, return True immediately. → success_return
   ? Return False immediately from the occupied-cell branch.
