Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

Class specification:

# Class: CurrencyConverter
# Fields: rates

## __init__()
Summary: Initializes the instance's currency exchange rate dictionary with seven fixed rates relative to USD.
1. Assign self.rates to a new dictionary containing the fixed currency conversion rates: 'USD': 1.0, 'EUR': 0.85, 'GBP': 0.72, 'JPY': 110.15, 'CAD': 1.23, 'AUD': 1.34, 'CNY': 6.40. → self.rates

## add_currency_rate(currency: hashable key, rate: value)
Summary: Adds a currency exchange rate to the self.rates mapping only when the currency is not already present, and returns False for duplicate currency keys.
#   currency: hashable key — Currency identifier used as a key in self.rates.
#   rate: value — Exchange rate value to store for the currency when it is not already present.
1. Check whether currency is already present as a key in self.rates. → currency_exists
2. If currency is not present in self.rates, assign rate to self.rates[currency]. → self.rates[currency]
   ? Return False immediately without modifying self.rates.

## convert(amount: number, from_currency: string, to_currency: string)
Summary: Converts an amount from one currency to another using exchange rates from self.rates, returning the original amount when the currencies match and False when either currency rate is unavailable.
#   amount: number — The monetary amount to convert.
#   from_currency: string — The source currency code.
#   to_currency: string — The target currency code.
1. If from_currency equals to_currency, return amount immediately without converting. → amount
2. If from_currency is not present in self.rates or to_currency is not present in self.rates, return False immediately. → False
3. Retrieve from_rate from self.rates using from_currency as the key. → from_rate
4. Retrieve to_rate from self.rates using to_currency as the key. → to_rate
5. Compute converted_amount as (amount / from_rate) * to_rate. → converted_amount
6. Return converted_amount. → converted_amount

## get_supported_currencies() → list
Summary: Returns a new list containing the keys of the object's rates dictionary in current insertion order.
#   → currency_list: list — A new list of keys from self.rates; returns an empty list when self.rates is empty. Requires self.rates to be an initialized dictionary-like object.
1. Return a new list created from the keys of self.rates, preserving the dictionary's current insertion order. → currency_list

## update_currency_rate(currency: string, new_rate: number)
Summary: Updates the rate for an existing currency in self.rates and returns False when the currency is not present.
#   currency: string — Currency key to look up in self.rates.
#   new_rate: number — New rate value to store for the currency.
1. Check whether currency exists in self.rates. → currency_exists
2. When currency exists in self.rates, assign new_rate to self.rates[currency]. → self.rates[currency]
   ? Return False.
