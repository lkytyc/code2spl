Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

Summary: Initializes the snake instance by setting its default length and score, copying screen and block configuration, computing the initial centered position, and storing the provided food position.
#   SCREEN_WIDTH: number — External screen width used to compute the initial centered position.
#   SCREEN_HEIGHT: number — External screen height used to compute the initial centered position.
#   BLOCK_SIZE: number — External block size stored unchanged on the instance.
#   food_position: object — External food position propagated directly into instance state.
1. Assign the literal constant 1 to the instance attribute length as the initial snake length. → self.length
2. Copy the parameter SCREEN_WIDTH into the instance attribute SCREEN_WIDTH. → self.SCREEN_WIDTH
3. Copy the parameter SCREEN_HEIGHT into the instance attribute SCREEN_HEIGHT. → self.SCREEN_HEIGHT
4. Copy the parameter BLOCK_SIZE into the instance attribute BLOCK_SIZE. → self.BLOCK_SIZE
5. Compute the initial centered position as ((SCREEN_WIDTH / 2), (SCREEN_HEIGHT / 2)) using true division by 2, wrap that tuple in a list, and assign it to the instance attribute positions. → self.positions
6. Assign the literal constant 0 to the instance attribute score as the initial score. → self.score
7. Store the parameter food_position directly into the instance attribute food_position. → self.food_position

## eat_food()
Summary: Processes a food consumption event by increasing the current object's length by one, adding 100 points to its score, and generating a new random food position.
1. Increase the current object's length attribute by 1. → self.length
2. Increase the current object's score attribute by 100. → self.score
3. Call the method random_food_position on the current object without capturing any returned value. → None

## move(direction: iterable of two numbers)
Summary: Moves the snake by computing a new wrapped head position from direction, eating food when applicable, then either resetting on self-collision or inserting the new head and trimming the tail to the configured length.
#   direction: iterable of two numbers — Movement direction vector; must unpack into exactly two components x and y.
1. Set cur to the current head position, which is the first element of self.positions. → cur
2. Unpack direction into components x and y. → x,
3. Compute new as the 2-tuple ((cur[0] + (x * self.BLOCK_SIZE)) % self.SCREEN_WIDTH, (cur[1] + (y * self.BLOCK_SIZE)) % self.SCREEN_HEIGHT). → new
4. If new equals self.food_position, call self.eat_food(). → none
5. Evaluate the collision condition: len(self.positions) > 2 and new in self.positions[2:]. → collision_condition
   ? Call self.reset().
   ? Insert new at index 0 of self.positions.
   ? Within the else branch of the collision check, if len(self.positions) > self.length, pop the last element from self.positions.

## random_food_position()
Summary: Randomly places food on an unoccupied grid-aligned position by repeatedly generating a new random position while the current position is already occupied.
1. While self.food_position is in self.positions, assign self.food_position to a tuple whose x-coordinate is random.randint(0, self.SCREEN_WIDTH // self.BLOCK_SIZE - 1) * self.BLOCK_SIZE and whose y-coordinate is random.randint(0, self.SCREEN_HEIGHT // self.BLOCK_SIZE - 1) * self.BLOCK_SIZE, using inclusive randint bounds, then re-evaluate the while condition. → self.food_position

## reset()
Summary: Resets the game state by setting length to 1, score to 0, centering the positions list on the screen midpoint, and generating a new random food position.
1. Set self.length to the constant integer value 1. → self.length
2. Set self.positions to a list containing one tuple whose first element is self.SCREEN_WIDTH divided by 2 and whose second element is self.SCREEN_HEIGHT divided by 2. → self.positions
3. Set self.score to the constant integer value 0. → self.score
4. Call self.random_food_position() to generate a new random food position. → self.random_food_position_result
