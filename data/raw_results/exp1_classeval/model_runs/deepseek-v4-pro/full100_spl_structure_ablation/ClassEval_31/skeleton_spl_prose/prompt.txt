#   data1: list[float] — First list of numeric values; its length defines the number of paired elements used.
#   data2: list[float] — Second list of numeric values; it should have the same length as data1 for correct paired computation.

## kurtosis(data: list[float]) → float
Summary: Computes the excess kurtosis of a numeric dataset using the population standard deviation and returns math.nan when the standard deviation is zero.
#   data: list[float] — Input numeric dataset for which excess kurtosis is calculated.
#   → result: float — Excess kurtosis value of the dataset, or math.nan when the population standard deviation is zero.
1. Assign n as the length of data. → n
2. Compute mean as sum(data) divided by n. → mean
3. Compute std_dev as the square root of sum((x - mean) ** 2 for x in data) divided by n. → std_dev
4. When std_dev is not equal to 0, compute centered_data as a list of x - mean for each x in data. → centered_data
5. When std_dev is not equal to 0, compute fourth_moment as sum(x ** 4 for x in centered_data) divided by n. → fourth_moment
6. When std_dev is not equal to 0, compute kurtosis_value as (fourth_moment / (std_dev ** 4)) - 3. → kurtosis_value
7. When std_dev is not equal to 0, return kurtosis_value. → kurtosis_value
   ? Return math.nan.

## pdf(data: iterable of numeric values, mu: numeric, sigma: numeric) → list of numeric values
Summary: Computes the Gaussian probability density function value for each element in data using the supplied mean mu and standard deviation sigma.
#   data: iterable of numeric values — Collection of numeric values at which the PDF is evaluated; the output order and length match this collection.
#   mu: numeric — Mean parameter of the normal distribution.
#   sigma: numeric — Standard deviation parameter of the normal distribution; should be positive and non-zero for valid PDF values.
#   → pdf_values: list of numeric values — List of calculated Gaussian PDF values corresponding to each element in data, preserving the original order.
1. For each x in data, compute 1 / (sigma * sqrt(2 * math.pi)) * exp(-0.5 * ((x - mu) / sigma) ** 2) and collect the results in order into the list pdf_values. → pdf_values
2. Return the computed list pdf_values. → pdf_values

## skewness(data: list[float]) → float
Summary: Compute the skewness of a list of numeric values as the third central moment scaled by n divided by ((n - 1) * (n - 2) * std_deviation^3), returning 0 when the population standard deviation is zero.
#   data: list[float] — Input list of numeric values for which skewness is calculated. An empty list causes a ZeroDivisionError because n is 0.
#   → skewness: float — The computed skewness value, or 0 when the population standard deviation is zero. If n is 2 and std_deviation is not 0, the denominator contains a factor of 0 and a ZeroDivisionError occurs.
1. Compute n as the length of data. → n
2. Compute mean as sum(data) divided by n. → mean
3. Compute variance as sum((x - mean) ** 2 for x in data) divided by n. → variance
4. Compute std_deviation as math.sqrt(variance). → std_deviation
5. If std_deviation != 0, compute skewness as sum((x - mean) ** 3 for x in data) * n / ((n - 1) * (n - 2) * std_deviation ** 3); otherwise set skewness to 0. → skewness
6. Return skewness. → skewness
