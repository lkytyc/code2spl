Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

# Class: MetricsCalculator

## accuracy(predicted_labels: list, true_labels: list) → float
Summary: Computes classifier accuracy after updating confusion matrix counts, returning 0.0 when the total count is zero and otherwise returning the ratio of correct predictions to total predictions.
#   predicted_labels: list — Predicted labels for the samples used to update the confusion matrix counts.
#   true_labels: list — Ground truth labels for the samples used to update the confusion matrix counts.
#   → accuracy: float — Classification accuracy as a float between 0.0 and 1.0, or 0.0 when no samples are counted.
1. Call self.update(predicted_labels, true_labels) to update the true positive, true negative, false positive, and false negative counts. → none
2. Compute total = self.true_positives + self.true_negatives + self.false_positives + self.false_negatives. → total
3. If total is not equal to 0, return (self.true_positives + self.true_negatives) / total. → accuracy
   ? Return 0.0.

## f1_score(predicted_labels: list, true_labels: list) → float
Summary: Computes the F1 score from predicted and true labels by updating internal statistics, deriving precision and recall, and returning the harmonic mean with a zero-denominator safeguard.
#   predicted_labels: list — Predicted labels to evaluate.
#   true_labels: list — Ground truth labels to compare against.
#   → f1_score: float — The computed F1 score, or 0.0 when precision plus recall is zero.
1. Call self.update(predicted_labels, true_labels) to update internal statistics before computing metrics. → update_result
2. Assign precision to the return value of self.precision(predicted_labels, true_labels). → precision
3. Assign recall to the return value of self.recall(predicted_labels, true_labels). → recall
4. Check whether precision + recall equals 0.0; if true, follow the alternative flow for zero denominator and return 0.0. → is_zero_denominator
5. Return (2 * precision * recall) / (precision + recall). → f1_score
   ? Return 0.0.

## precision(predicted_labels: any, true_labels: any) → float
Summary: Updates internal metric counters with the predicted and true labels, then returns precision as true positives divided by the sum of true positives and false positives, or 0.0 when the denominator is zero.
#   predicted_labels: any — Predicted labels used to update internal metric counters.
#   true_labels: any — True labels used to update internal metric counters.
#   → precision_result: float — Computed precision value; returns 0.0 when the sum of true positives and false positives is zero.
1. Call self.update(predicted_labels, true_labels) to update internal true positive and false positive counters. → self
2. After the zero-denominator guard, return self.true_positives / (self.true_positives + self.false_positives) as the precision result. → precision_result
   ? Return 0.0 as the precision result.

## recall(predicted_labels: list, true_labels: list) → float
Summary: Computes the recall metric by updating internal true positive and false negative counts with the provided predicted and true labels, returning 0.0 when the sum of true positives and false negatives is zero and otherwise returning true positives divided by that sum.
#   predicted_labels: list — Predicted labels used to update the internal metric counters.
#   true_labels: list — Ground-truth labels used to update the internal metric counters.
#   → recall_value: float — Recall score computed as true positives divided by the sum of true positives and false negatives, or 0.0 when the denominator is zero.
1. Call self.update(predicted_labels, true_labels) and discard any return value. → discarded_update_result
2. When the denominator guard condition is false, compute and return self.true_positives / (self.true_positives + self.false_negatives) as the recall value. → recall_value
   ? Return 0.0 as the recall value to avoid division by zero.

## update(predicted_labels: Iterable[int], true_labels: Iterable[int])
Summary: Updates the confusion matrix counters on self by iterating over paired predicted and true binary labels and incrementing the matching true positive, false positive, false negative, or true negative counter for each pair.
#   predicted_labels: Iterable[int] — Predicted binary labels to compare element-wise with true labels.
#   true_labels: Iterable[int] — Ground-truth binary labels to compare element-wise with predicted labels.
1. For each predicted and true pair obtained from zip(predicted_labels, true_labels), evaluate the following if/elif conditions sequentially for the current pair and then continue with the next pair; iteration stops at the shorter input length. → current_pair
2. Within the for loop, if predicted == 1 and true == 1, increment self.true_positives by 1. → true_positives_incremented
3. Within the for loop, else if predicted == 1 and true == 0, increment self.false_positives by 1. → false_positives_incremented
4. Within the for loop, else if predicted == 0 and true == 1, increment self.false_negatives by 1. → false_negatives_incremented
5. Within the for loop, else if predicted == 0 and true == 0, increment self.true_negatives by 1. → true_negatives_incremented
6. Within the for loop, if none of the four conditions match because a value is not exactly 0 or 1, do nothing for this pair and continue to the next pair. → no_update_for_non_binary_pair
