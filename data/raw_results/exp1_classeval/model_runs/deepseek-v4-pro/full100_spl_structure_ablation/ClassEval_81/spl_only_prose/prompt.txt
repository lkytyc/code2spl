Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

## correlation(x: sequence of numeric values, y: sequence of numeric values) → float or None
Summary: Compute the correlation-like coefficient numerator divided by denominator for x and y, returning None when the denominator is zero.
#   x: sequence of numeric values — Input sequence; must be sized, non-empty, and contain numeric values.
#   y: sequence of numeric values — Input sequence; must be sized, non-empty, and contain numeric values; should have the same length as x for consistent behavior.
#   → return_value: float or None — The computed ratio numerator / denominator if denominator is not zero; otherwise None.
1. Compute n as len(x). → n
2. Compute mean_x as sum(x) divided by n. → mean_x
3. Compute mean_y as sum(y) divided by n, where n is the length of x from the prior step. → mean_y
4. Compute numerator as the sum over each paired (xi, yi) from zip(x, y) of (xi - mean_x) * (yi - mean_y); only the shorter paired prefix is used if x and y differ in length. → numerator
5. Compute denominator as the square root of (sum((xi - mean_x)**2 for xi in x) * sum((yi - mean_y)**2 for yi in y)). → denominator
6. If denominator is not zero, return numerator divided by denominator. → return_value
   ? Return None.

## correlation_matrix(data: list[list[float]]) → list[list[float]]

#   data: list[list[float]] — A non-empty table of numeric rows where each row represents an observation and each column represents a variable; all rows are assumed to have the same length as the first row.
#   → matrix: list[list[float]] — An n-by-n matrix where matrix[i][j] is the correlation between column i and column j.

2. Let n be len(data[0]), the number of columns based on the first row of data. → n
3. For each i from 0 to n-1 inclusive, do the following. → i
4. Within the outer for loop over i, initialize row to an empty list. → row
5. Within the outer for loop over i, for each j from 0 to n-1 inclusive, do the following. → j
6. Within the inner for loop over j, build column1 by taking the element at index i from each row in data. → column1

## mode(data: list) → list
Summary: Computes the mode values of the input data by counting frequencies, finding the maximum frequency, and returning all values that have that maximum frequency.
#   data: list — Input collection of hashable values whose frequencies are counted.
#   → mode_values: list — List of values that have the maximum frequency in the input data.
1. Initialize an empty dictionary named counts to store the frequency of each value. → counts
2. For each value in the input data, set counts[value] to counts.get(value, 0) + 1, incrementing the frequency count for that value. → counts
3. Compute max_count as the maximum count among all frequency values in counts using max(counts.values()). → max_count
4. Create mode_values as a list comprehension over counts.items(), including each value whose count equals max_count. → mode_values
5. Return mode_values as the list of mode values. → return
   ! log: "Cannot compute mode of an empty collection because max() is called on an empty sequence."
   ! raise: ValueError "max() arg is an empty sequence"

## standard_deviation(data: sequence of numeric values) → number or None
Summary: Computes the sample standard deviation of a numeric dataset, returning None if the dataset has fewer than two values.
#   data: sequence of numeric values — Re-iterable dataset of numeric values for which the sample standard deviation is computed; must support len and multiple iterations.
#   → result: number or None — The sample standard deviation, computed as the square root of the sample variance when data has at least two values; otherwise None.
1. Compute n as the length of data using len(data). → n
2. Compute mean_value by calling Statistics3.mean(data). → mean_value
3. Compute variance as the sum of squared differences between each element x in data and mean_value, divided by (n - 1). → variance
4. Compute the sample standard deviation as the square root of variance using math.sqrt(variance), and return it. → return_value
   ? Return None immediately.

## z_score(data: list[float]) → list[float] or None

3. If std_deviation is not None and std_deviation is not equal to 0, compute a list of z-scores by applying (x - mean) / std_deviation to each x in data. → z_scores
4. Return the computed z_scores list from the function. → return_value
   ? Return None immediately from the function without computing z-scores.
