Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

## interpolate_1d(x: array of numbers, y: array of numbers, x_interp: array of numbers) → array of numbers
Summary: Computes piecewise linear interpolation for each requested x value by scanning consecutive x intervals and appending one interpolated y value per matched interval.
#   x: array of numbers — Ordered x-coordinate array that defines interpolation intervals.
#   y: array of numbers — Array of y-values corresponding to each x-coordinate.
#   x_interp: array of numbers — Array of target x-values for which interpolated y-values are computed.
#   → y_interp: array of numbers — List of linearly interpolated y-values for target x values that fall within an x interval; may be shorter than x_interp if some target values do not match any interval.
1. Initialize `y_interp` as a new empty list. → y_interp
2. For each target value `xi` in `x_interp`, perform the inner interval scan over consecutive `x` intervals. → result
3. Within the outer loop over `xi`, for each interval index `i` from 0 to `len(x) - 2` inclusive, as produced by `range(len(x) - 1)`, check whether `xi` lies inclusively within the interval `[x[i], x[i+1]]` using the condition `x[i] <= xi <= x[i+1]`. → result
4. Within the inner loop, when the interval condition is true, compute `yi = y[i] + (y[i+1] - y[i]) * (xi - x[i]) / (x[i+1] - x[i])`, append `yi` to `y_interp`, and break out of the inner `i` loop only. → yi
5. Within the outer loop over `xi`, if no interval index satisfies the inclusive interval condition after the inner loop completes, do not append a value for this `xi`; continue with the next `xi` in `x_interp`. → result
6. After the outer loop finishes, return the accumulated `y_interp` list. → y_interp

## interpolate_2d(x: list, y: list, z: list, x_interp: list, y_interp: list) → list
Summary: Performs bilinear interpolation for each paired point in x_interp and y_interp over the grid defined by x, y, and z, returning the list of interpolated values.
#   x: list — 1D array of x grid coordinate values sorted in ascending order.
#   y: list — 1D array of y grid coordinate values sorted in ascending order.
#   z: list — 2D array of function values with shape len(x) by len(y).
#   x_interp: list — 1D array of x query coordinates to interpolate.
#   y_interp: list — 1D array of y query coordinates to interpolate, paired positionally with x_interp.
#   → z_interp: list — A list of bilinearly interpolated values for each paired query point that falls within a grid interval; points outside all intervals are skipped.
1. Initialize an empty list z_interp to collect interpolated values. → z_interp
2. For each paired query point (xi, yi) obtained by iterating over x_interp and y_interp simultaneously with zip, perform the following interval search and interpolation steps. → current_point
3. Within the current paired point iteration, iterate i from 0 to len(x)-2 and find the first i where x[i] <= xi <= x[i+1]; if no such i exists, skip the current point and continue with the next paired point. → i
4. Within the found x interval i, iterate j from 0 to len(y)-2 and find the first j where y[j] <= yi <= y[j+1]; if no such j exists, break out of the current i loop and skip the current point. → j
5. Within the found grid cell (i, j), retrieve the four surrounding z-values: z00 = z[i][j], z01 = z[i][j+1], z10 = z[i+1][j], and z11 = z[i+1][j+1]. → z00_z01_z10_z11
6. Within the found grid cell (i, j), compute zi = (z00 * (x[i+1] - xi) * (y[j+1] - yi) + z10 * (xi - x[i]) * (y[j+1] - yi) + z01 * (x[i+1] - xi) * (yi - y[j]) + z11 * (xi - x[i]) * (yi - y[j])) / ((x[i+1] - x[i]) * (y[j+1] - y[j])). → zi
7. Append the computed value zi to z_interp. → z_interp
8. Break out of the current y-interval loop, then break out of the current x-interval loop, and continue the outer paired-point loop with the next (xi, yi). → next_point
9. After all paired query points have been processed, return the accumulated list z_interp. → return_z_interp
