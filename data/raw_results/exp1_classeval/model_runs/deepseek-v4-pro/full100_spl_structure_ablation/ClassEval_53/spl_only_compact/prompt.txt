Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

Class specification:

# Class: LongestWord
# Fields: word_list

## __init__()
Summary: Initializes a new instance by setting the instance attribute self.word_list to an empty list.
1. Assign a new empty list literal to the instance attribute self.word_list. → self.word_list

## add_word(self: object, word: object)
Summary: Appends the given word to the end of the instance attribute word_list, mutating the list in place.
#   self: object — The current object instance, which must already have an initialized list attribute named word_list with an append method.
#   word: object — The item reference to append to the end of self.word_list.
1. Call the append method on self.word_list with word as the argument so that word is added as the new last element in place. → self.word_list

## find_longest_word(sentence: str) → str
Summary: Normalizes a sentence to lowercase, removes punctuation, splits it on literal spaces, and returns the longest word that is also in self.word_list, defaulting to an empty string when no such word is found.
#   sentence: str — The input sentence to normalize, split, and search for the longest known word.
#   → longest_word: str — The longest word from the normalized sentence that exists in self.word_list; returns an empty string if no matching word is found.
1. Initialize longest_word to the empty string as the default sentinel value. → longest_word
2. Convert sentence to lowercase and assign the lowercased string back to sentence. → sentence
3. Remove every punctuation character listed in string.punctuation from sentence by applying re.sub with a regex character class built from re.escape(string.punctuation), and assign the cleaned string back to sentence. → sentence
4. Split the cleaned sentence on each literal space character using re.split(' ', sentence) and assign the resulting list of words to sentence; consecutive spaces can produce empty-string elements, and an empty cleaned sentence yields ['']. → sentence
5. For each word in sentence, iterating sequentially with no break, continue, or early return: if word exists in self.word_list and, due to short-circuit evaluation only when membership holds, len(word) is strictly greater than len(longest_word), set longest_word to word; otherwise leave longest_word unchanged. Strict greater means ties keep the earliest occurrence of the maximum length. → longest_word
6. Return longest_word. → longest_word
