Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

Class specification:

# Class: JSONProcessor
# Calls: process_json→read_json, process_json→write_json

## process_json(file_path: string, remove_key: string) → integer
Summary: Reads JSON data from a file, removes a specified key if present, writes the updated data back to the same file, and returns an integer status indicating success or failure.
#   file_path: string — Path to the JSON file to read and, on successful removal, write.
#   remove_key: string — Key to remove from the JSON data if it is present.
#   → return_value: integer — Returns 1 if the key was removed and the file was written; returns 0 if the read result was 0 or -1 or if the key was not present.
1. Call self.read_json(file_path) and assign the returned value to data. → data
2. If data equals 0 or data equals -1, return 0 immediately. → return_0
3. If data is not 0 or -1 and remove_key is present in data, delete data[remove_key]. → data
4. Within the same remove_key-present branch, call self.write_json(data, file_path) to write the updated data back to the file. → write_result
5. Within the same remove_key-present branch, return 1. → return_1
6. If data is not 0 or -1 and remove_key is not present in data, return 0. → return_0

## read_json(file_path: string)
Summary: Reads a JSON file from file_path and returns the parsed JSON object; returns 0 if the file does not exist and -1 if an exception occurs while opening or parsing the file.
#   file_path: string — Path to the JSON file to read.
1. Check whether file_path exists using os.path.exists(file_path). → file_exists
2. If file_path exists, open file_path in read mode ('r') as file. → file
3. Within the open file context, load JSON content from file using json.load(file) into data. → data
4. Return data. → result
   ? Return integer 0.
   ? Return integer -1.

## write_json(data: object, file_path: string) → integer
Summary: Writes the given data as a JSON document to the specified file path and returns 1 on success or -1 if any error occurs.
#   data: object — Data to serialize and write as JSON
#   file_path: string — Destination file path for the JSON output
#   → return_value: integer — Returns 1 on success and -1 if any exception occurs
1. Open the file at file_path in write mode ('w') and obtain the file handle → file
2. Serialize data to JSON and write it to the file using json.dump(data, file) → dump_result
3. If the open and write operations complete without exception, return 1 → return_value
   ? Catch the exception and return -1
