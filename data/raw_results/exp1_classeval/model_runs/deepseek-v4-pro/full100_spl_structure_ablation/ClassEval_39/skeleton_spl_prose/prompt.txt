## calculate(expression: string) → float
Summary: Evaluates a postfix expression by preparing its transformed input, processing tokens with a stack-based RPN evaluator, and returning the floating-point product of the remaining stack values.
#   expression: string — The expression to be transformed and prepared before postfix evaluation.
#   → calculated_result: float — The floating-point result of multiplying the operands remaining on the result stack after postfix evaluation.
1. Transform the input expression by calling self.transform(expression), then pass the transformed result to self.prepare. → prepared_expression
2. Initialize result_stack as an empty deque. → result_stack
3. Reverse self.postfix_stack in place. → postfix_stack
4. While self.postfix_stack is not empty, pop the next token from self.postfix_stack into current_op. → current_op
5. Within the while loop, if self.is_operator(current_op) is false, replace every occurrence of '~' in current_op with '-' and append the normalized current_op to result_stack. → result_stack
6. Within the while loop, in the else branch when self.is_operator(current_op) is true, pop the top value from result_stack into second_value, then pop the next top value from result_stack into first_value. → second_value_first_value
7. Still within the operator branch, replace every occurrence of '~' in first_value and in second_value with '-'. → first_value_second_value
8. Still within the operator branch, compute temp_result by calling self._calculate(first_value, second_value, current_op). → temp_result
9. Still within the operator branch, append str(temp_result) to result_stack. → result_stack
10. After the while loop completes, join all items in result_stack with '*' and evaluate the resulting multiplication expression, returning its float value. → calculated_result

## compare(cur: string, peek: string) → boolean

4. For each current_op at index i from enumerate(arr), start the left-to-right scan loop. → scan_loop
5. Within the scan loop, if self.is_operator(current_op) is true, take the operator branch; otherwise take the operand branch. → operator_branch_check

7. Within the operator branch, set peek_op to op_stack[-1] after the pending operand flush. → peek_op

3. Convert the updated expression string into a list of its individual characters and assign it to arr. → arr
