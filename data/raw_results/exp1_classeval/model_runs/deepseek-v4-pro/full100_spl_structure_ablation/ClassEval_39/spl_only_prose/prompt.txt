Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

## _calculate(current_op: string) → Decimal
Summary: Selects one of five Decimal arithmetic operations based on current_op and returns the Decimal result, raising ValueError for an unsupported operator.
#   current_op: string — Arithmetic operator; supported values are '+', '-', '*', '/', and '%'.
#   → decimal_result: Decimal — The Decimal result of the selected arithmetic operation.
1. Evaluate current_op against the supported operator branches in order, selecting the first match. → selected_branch
   ? Convert first_value to Decimal and store it as first_decimal.
   ? Convert second_value to Decimal and store it as second_decimal.
   ? Return the Decimal result of first_decimal plus second_decimal.
   ? Convert first_value to Decimal and store it as first_decimal.
   ? Convert second_value to Decimal and store it as second_decimal.
   ? Return the Decimal result of first_decimal minus second_decimal.
   ? Convert first_value to Decimal and store it as first_decimal.
   ? Convert second_value to Decimal and store it as second_decimal.
   ? Return the Decimal result of first_decimal multiplied by second_decimal.
   ? Convert first_value to Decimal and store it as first_decimal.
   ? Convert second_value to Decimal and store it as second_decimal.
   ? Return the Decimal result of first_decimal divided by second_decimal.
   ? Convert first_value to Decimal and store it as first_decimal.
   ? Convert second_value to Decimal and store it as second_decimal.
   ? Return the Decimal result of first_decimal modulo second_decimal.
   ! log: "Unexpected operator: {current_op}"
   ! raise: ValueError "Raised when current_op is not one of the supported arithmetic operators."

## calculate(expression: string) → float
Summary: Evaluates a postfix expression by preparing its transformed input, processing tokens with a stack-based RPN evaluator, and returning the floating-point product of the remaining stack values.
#   expression: string — The expression to be transformed and prepared before postfix evaluation.
#   → calculated_result: float — The floating-point result of multiplying the operands remaining on the result stack after postfix evaluation.
1. Transform the input expression by calling self.transform(expression), then pass the transformed result to self.prepare. → prepared_expression
2. Initialize result_stack as an empty deque. → result_stack
3. Reverse self.postfix_stack in place. → postfix_stack
4. While self.postfix_stack is not empty, pop the next token from self.postfix_stack into current_op. → current_op
5. Within the while loop, if self.is_operator(current_op) is false, replace every occurrence of '~' in current_op with '-' and append the normalized current_op to result_stack. → result_stack
6. Within the while loop, in the else branch when self.is_operator(current_op) is true, pop the top value from result_stack into second_value, then pop the next top value from result_stack into first_value. → second_value_first_value
7. Still within the operator branch, replace every occurrence of '~' in first_value and in second_value with '-'. → first_value_second_value
8. Still within the operator branch, compute temp_result by calling self._calculate(first_value, second_value, current_op). → temp_result
9. Still within the operator branch, append str(temp_result) to result_stack. → result_stack
10. After the while loop completes, join all items in result_stack with '*' and evaluate the resulting multiplication expression, returning its float value. → calculated_result

## compare(cur: string, peek: string) → boolean
Summary: Compares operator precedence between cur and peek after normalizing '%' to '/', returning true when peek's priority is greater than or equal to cur's priority.
#   cur: string — Current operator character whose priority is compared.
#   peek: string — Next operator character whose priority is compared against cur.
#   → result: boolean — True if the priority of peek is greater than or equal to the priority of cur after normalizing '%' to '/'.
1. If cur is exactly '%', assign '/' to cur. → cur
2. If peek is exactly '%', assign '/' to peek. → peek
3. Compute peek_priority as self.operat_priority[ord(peek) - 40]. → peek_priority
4. Compute cur_priority as self.operat_priority[ord(cur) - 40]. → cur_priority
5. Return the boolean result of peek_priority >= cur_priority. → result

## is_operator(c: str) → bool
Summary: Checks whether a given character is one of the supported operator characters: '+', '-', '*', '/', '(', ')', or '%'.
#   c: str — Character to be tested for membership in the operator set.
#   → result: bool — True if c is one of '+', '-', '*', '/', '(', ')', or '%'; otherwise False.
1. Return True if c belongs to the set {'+', '-', '*', '/', '(', ')', '%'}, and return False otherwise. → result

## prepare(expression: str)
Summary: Converts an infix expression into postfix notation by scanning characters, buffering operands, and using a comma-sentinel operator stack to handle precedence, associativity, and parentheses.
#   expression: str — Infix expression to convert into postfix notation.
1. Initialize op_stack as a deque with the sentinel ',' so the stack is never empty and the lowest stopping condition is available. → op_stack
2. Convert expression into arr by applying list(expression), producing a single-character token list. → arr
3. Set current_index to 0 and count to 0, representing the start of the current operand and its length. → current_index_count
4. For each current_op at index i from enumerate(arr), start the left-to-right scan loop. → scan_loop
5. Within the scan loop, if self.is_operator(current_op) is true, take the operator branch; otherwise take the operand branch. → operator_branch_check
6. Within the operator branch, if count > 0, append the joined string from arr[current_index: current_index + count] to self.postfix_stack to flush the pending operand. → flush_pending_operand
7. Within the operator branch, set peek_op to op_stack[-1] after the pending operand flush. → peek_op
8. Within the operator branch, if current_op equals ')', while op_stack[-1] is not '(' append str(op_stack.pop()) to self.postfix_stack, then pop the matching '(' from op_stack without appending it. → right_parenthesis_handling
9. Within the operator branch, otherwise while current_op is not '(' and peek_op is not ',' and self.compare(current_op, peek_op) is true, append str(op_stack.pop()) to self.postfix_stack and update peek_op to op_stack[-1]; after the loop append current_op to op_stack. → operator_handling
10. Within the operator branch, reset count to 0 and set current_index to i + 1 after processing the operator. → reset_after_operator
11. Within the scan loop, if self.is_operator(current_op) is false, increment count by 1 to buffer the current operand character. → buffer_operand_character
12. After the scan loop, if count > 1 or (count == 1 and not self.is_operator(arr[current_index])) with short-circuit evaluation, append the joined string from arr[current_index: current_index + count] to self.postfix_stack as the final pending operand. → final_operand_flush
13. After the final operand flush check, while op_stack[-1] is not equal to ',', append str(op_stack.pop()) to self.postfix_stack to drain remaining operators. → drain_operator_stack

## transform(expression: str) → str
Summary: Normalizes an arithmetic expression by removing whitespace and a trailing equals sign, rewriting unary minus signs as '~', and converting a leading '~(' to '0-(' before returning the transformed string.
#   expression: str — Input arithmetic expression string that may contain whitespace, a trailing equals sign, operators, parentheses, and minus signs.
#   → result: str — Normalized expression string after whitespace removal, trailing '=' removal, unary minus rewriting to '~', and leading '~(' to '0-(' conversion.
1. Remove all whitespace characters from expression using re.sub(r"\s+", "", expression) and assign the result back to expression; if expression is not a string or bytes-like object compatible with re.sub, Python raises TypeError. → expression
2. Remove exactly one trailing '=' character, if present, from expression using re.sub(r"=$", "", expression) and assign the result back to expression. → expression
3. Convert the updated expression string into a list of its individual characters and assign it to arr. → arr
4. Within the for loop over each index i and character c in enumerate(arr), if c equals '-' and i equals 0, set arr[i] to '~'. → arr
5. Within the same for loop over each index i and character c in enumerate(arr), if c equals '-' and i is not 0, read prev_c from the already-modified arr at index i-1; if prev_c is one of '+', '-', '*', '/', '(', 'E', or 'e', set arr[i] to '~'. → arr
6. After the loop, evaluate the final short-circuit condition from left to right: if arr is empty, accessing arr[0] raises IndexError; otherwise, if arr[0] is '~' and len(arr) is greater than 1 and arr[1] is '(', then set arr[0] to '-' and return the string "0" concatenated with the string formed by joining arr with an empty separator. → return_value
7. Otherwise, return the string formed by joining arr with an empty separator. → return_value
