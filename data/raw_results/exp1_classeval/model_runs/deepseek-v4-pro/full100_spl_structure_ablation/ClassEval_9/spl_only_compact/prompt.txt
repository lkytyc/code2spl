Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

# Class: BigNumCalculator

## add(num1: string, num2: string) → string
Summary: Adds two numeric string values digit by digit using zero-padding and carry propagation, returning the sum as a string.
#   num1: string — First numeric string operand.
#   num2: string — Second numeric string operand.
#   → return_value: string — The sum of num1 and num2 represented as a string.
1. Compute max_length as the maximum of the lengths of num1 and num2. → max_length
2. Reassign num1 to num1.zfill(max_length), adding leading zeros so that its length equals max_length. → num1
3. Reassign num2 to num2.zfill(max_length), adding leading zeros so that its length equals max_length. → num2
4. Initialize carry to integer 0. → carry
5. Initialize result to an empty list. → result
6. Within a for loop that runs when max_length is greater than 0, for each i from max_length - 1 down to 0 inclusive with step -1, compute digit_sum = int(num1[i]) + int(num2[i]) + carry. → digit_sum
7. Within the same for loop, update carry to digit_sum // 10. → carry
8. Within the same for loop, compute digit as digit_sum % 10. → digit
9. Within the same for loop, insert str(digit) at position 0 of result. → result
10. After the for loop completes, if carry is greater than 0, insert str(carry) at position 0 of result. → result
11. Return the string formed by joining all elements of result as the final return value. → return_value

## multiply(num1: string, num2: string) → string
Summary: Multiplies two non-negative integers represented as strings using grade-school digit-by-digit multiplication and returns the product string without leading zeros.
#   num1: string — First non-negative integer represented as a string.
#   num2: string — Second non-negative integer represented as a string.
#   → product_str: string — The product of num1 and num2 represented as a string without leading zeros.
1. Set len1 to len(num1) and len2 to len(num2). → len1_len2
2. Initialize result to a list of zeros of length len1 + len2. → result
3. For i from len1 - 1 down to 0 inclusive, iterate over num1 digits from least significant to most significant. → i
4. Within the outer loop over i, for j from len2 - 1 down to 0 inclusive, iterate over num2 digits from least significant to most significant. → j
5. Within the inner loop over j, compute mul = int(num1[i]) * int(num2[j]). → mul
6. Within the inner loop over j, set p1 = i + j and p2 = i + j + 1. → p1_p2
7. Within the inner loop over j, compute total = mul + result[p2]. → total
8. Within the inner loop over j, update result[p1] by adding total // 10, and set result[p2] to total % 10. → result
9. Set start = 0. → start
10. While start < len(result) - 1 and result[start] == 0, increment start by 1 to skip leading zero digits; because the condition uses a short-circuit and, result[start] is not evaluated when start equals len(result) - 1. → start
11. Return the string formed by joining the string representation of each integer in result[start:] as the multiplication result. → product_str

## subtract(num1: str, num2: str) → str
Summary: Subtract two decimal string numbers digit by digit, swapping operands if necessary to ensure a non-negative subtraction, removing leading zeros, and returning the signed decimal string difference.
#   num1: str — First decimal number represented as a string.
#   num2: str — Second decimal number represented as a string.
#   → result: str — The signed decimal string difference between num1 and num2, with leading zeros removed except for a single zero result.
1. Check the lengths of num1 and num2: if len(num1) < len(num2), swap num1 and num2 and set negative to True; else if len(num1) > len(num2), set negative to False; else, if num1 < num2, swap num1 and num2 and set negative to True, otherwise set negative to False. → sign_normalization
2. Compute max_length = max(len(num1), len(num2)); left-pad both num1 and num2 with zeros to max_length using zfill; initialize borrow = 0 and result = []. → initialization
3. For i from max_length - 1 down to 0 inclusive, compute digit_diff = int(num1[i]) - int(num2[i]) - borrow; if digit_diff < 0, add 10 to digit_diff and set borrow = 1, otherwise set borrow = 0; then insert str(digit_diff) at index 0 of result. → digit_subtraction_loop
4. While len(result) > 1 and result[0] == '0', remove result[0]. → leading_zero_removal
5. If negative is True, insert '-' at index 0 of result. → sign_application
6. Return ''.join(result). → return_value
