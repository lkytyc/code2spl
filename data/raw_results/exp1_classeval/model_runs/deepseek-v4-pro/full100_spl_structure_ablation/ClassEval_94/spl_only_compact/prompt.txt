Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

# Class: VendingMachine

## add_item(item_name: string, price: number, quantity: number)
Summary: Adds or updates an inventory item with the given price and quantity when the restock_item call returns a falsy value.
#   item_name: string — Name or key of the inventory item to add or update.
#   price: number — Price to store in the inventory entry.
#   quantity: number — Quantity passed to restock_item and stored in the inventory entry if restock_item returns a falsy value.
1. Call self.restock_item(item_name, quantity) and capture the return value. → restock_result
2. Evaluate `not restock_result` by inverting the truthiness of restock_result; set restock_failed to True when restock_result is falsy (False, None, 0, or an empty container), otherwise set restock_failed to False. → restock_failed
   ? Set self.inventory[item_name] to {'price': price, 'quantity': quantity}.

## display_items()
Summary: Display inventory items and their prices and quantities, returning False when inventory is falsy and a newline-separated formatted string otherwise.
1. Evaluate the condition `not self.inventory` to check whether self.inventory is falsy. → inventory_is_falsy
2. If inventory_is_falsy is true, immediately return the boolean False and terminate without processing items. → early_return
   ? Within the else branch, initialize an empty list named items.
   ? For each item_name and item_info pair from self.inventory.items(), append the exact formatted string "{item_name} - ${item_info['price']} [{item_info['quantity']}]" to the items list.
   ? After the loop completes, join the items list into a single string using newline characters as separators and return that string.

## insert_coin(amount: number) → number
Summary: Adds the provided amount to the instance balance and returns the updated balance.
#   amount: number — The amount to add to the current balance.
#   → updated_balance: number — The updated value of self.balance after adding amount.
1. Add the current self.balance and amount, then assign the result back to self.balance. → updated_balance
2. Return the updated self.balance value. → return_value

## purchase_item(item_name: string) → number or boolean
Summary: Attempts to purchase an item by name if it exists in inventory, has positive stock, and the buyer has enough balance; on success it deducts the price, decrements stock, and returns the updated balance, otherwise it returns False.
#   item_name: string — Name of the item to purchase
#   → purchase_result: number or boolean — Updated balance when the purchase succeeds; False when the item does not exist, stock is zero, or balance is insufficient
1. Check whether item_name exists as a key in self.inventory. → item_exists
2. Within the outer true branch where item_exists is true, retrieve the item record from self.inventory using item_name. → item
3. Within the same outer true branch, check whether item['quantity'] is greater than 0; only if true, check whether self.balance is greater than or equal to item['price']. → purchase_allowed
4. Within the inner true branch where purchase_allowed is true, subtract item['price'] from self.balance and store the result back into self.balance. → updated_balance
5. Within the same inner true branch, decrement item['quantity'] by 1. → updated_quantity
6. Return the updated_balance value as the method result. → purchase_result
   ? Return False from the outer false branch.
   ? Return False from the inner false branch.

## restock_item(item_name: string, quantity: number) → boolean
Summary: Adds the specified quantity to an existing inventory item's quantity and returns True if the item exists, otherwise returns False.
#   item_name: string — Key of the inventory item to restock.
#   quantity: number — Amount to add to the inventory item's current quantity.
#   → result: boolean — True if the inventory item exists and was updated, False otherwise.
1. Check whether item_name exists as a key in self.inventory. → item_exists
2. Within the if branch where item_exists is true, add quantity to self.inventory[item_name]['quantity']. → updated_quantity
3. Within the same if branch, return True. → return_value
   ? Return False.
