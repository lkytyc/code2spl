Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

#   weight: float — Body weight value used to initialize the instance attribute.
#   age: int — Age value used to initialize the instance attribute.
#   sex: string — Sex marker used to initialize the instance attribute and relevant for BMI boundary classification.
1. Assign the instance attribute self.height directly from the input parameter height. → self.height
2. Assign the instance attribute self.weight directly from the input parameter weight. → self.weight

## calculate_calorie_intake() → number
Summary: Calculates daily calorie intake by applying the Mifflin-St Jeor BMR formula based on sex, weight, height, and age, then multiplying by an activity factor determined by condition_judge.
#   → calorie_intake: number — Estimated daily calorie intake based on calculated BMR and activity-level multiplier.
1. If self.sex equals exactly "male" (case-sensitive), compute BMR = 10 * self.weight + 6.25 * self.height - 5 * self.age + 5; otherwise compute BMR = 10 * self.weight + 6.25 * self.height - 5 * self.age - 161. Assign the computed value to BMR. → BMR
2. Call self.condition_judge(). If this first call returns 1, set calorie_intake = BMR * 1.2. → calorie_intake
3. If the first call to self.condition_judge() did not return 1, call self.condition_judge() a second time. If this second call returns -1, set calorie_intake = BMR * 1.6. → calorie_intake
4. If the first call to self.condition_judge() did not return 1 and the second call did not return -1, set calorie_intake = BMR * 1.4. → calorie_intake
5. Return calorie_intake. → calorie_intake

## condition_judge() → int
Summary: Classifies a person's BMI as too fat, too thin, or normal by comparing the value returned by self.get_BMI() against sex-specific BMI standard ranges from self.BMI_std.
#   → return_code: int — Returned classification code: 1 means too fat, -1 means too thin, and 0 means normal.
1. Call self.get_BMI() and assign the returned value to BMI. → BMI
2. If self.sex is exactly "male", assign BMI_range to self.BMI_std[0]["male"]; else assign BMI_range to self.BMI_std[1]["female"]. → BMI_range
3. If BMI is strictly greater than BMI_range[1], return 1 indicating too fat. → return_code
4. Else if BMI is strictly less than BMI_range[0], return -1 indicating too thin. → return_code
5. Else return 0 indicating normal. → return_code

## get_BMI() → float
Summary: Computes and returns the body mass index value by dividing self.weight by the square of self.height.
#   → bmi: float — The computed BMI value from self.weight divided by self.height squared.
1. Compute self.weight divided by self.height squared and return the resulting quotient. → bmi
