Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

## get_pos_tag(sentence: str) → list[str]
Summary: Cleans the input sentence by removing punctuation, tokenizes it, assigns part-of-speech tags, and returns the list of POS tags.
#   sentence: str — Input sentence to clean, tokenize, and POS-tag.
#   → pos_tags: list[str] — List of part-of-speech tags extracted from the tagged tokens.

3. Set words to word_tokenize(sentence). → words
4. Set tagged_words to pos_tag(words). → tagged_words
5. For each tagged_word in tagged_words, append tagged_word[1] to pos_tags. → pos_tags
6. Return pos_tags. → pos_tags

## lemmatize_sentence(sentence: string) → list
Summary: Lemmatizes an input sentence by removing punctuation, tokenizing, part-of-speech tagging, and applying part-of-speech-aware lemmatization with a default fallback before returning the list of lemmatized words.
#   sentence: string — The input sentence to be cleaned, tokenized, tagged, and lemmatized.
#   → lemmatized_words: list — The ordered list of lemmatized words produced from the input sentence.
1. Initialize lemmatized_words as an empty list to collect lemmatized tokens. → lemmatized_words
2. Call self.remove_punctuation with the current sentence and assign the cleaned result back to sentence. → sentence
3. Call word_tokenize on the cleaned sentence and assign the resulting token list to words. → words
4. Call pos_tag on words and assign the resulting tagged token list to tagged_words. → tagged_words
5. For each word and tag in tagged_words, apply the first matching branch exactly once: if tag starts with uppercase 'V', set lemmatized_word to self.lemmatizer.lemmatize(word, pos='v'); elif tag starts with uppercase 'J', set lemmatized_word to self.lemmatizer.lemmatize(word, pos='a'); elif tag starts with uppercase 'R', set lemmatized_word to self.lemmatizer.lemmatize(word, pos='r'); otherwise set lemmatized_word to self.lemmatizer.lemmatize(word). Then append lemmatized_word to lemmatized_words. → lemmatized_words
6. Return the accumulated lemmatized_words list. → lemmatized_words

## remove_punctuation(sentence: str) → str

#   sentence: str — Input string from which punctuation characters are removed.
#   → cleaned_sentence: str — A copy of the input string with all punctuation characters removed.
