Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

# Class: PageUtil
# Fields: data, total_pages, total_items, page_size

## __init__(data: collection, page_size: integer)
Summary: Initializes pagination state by storing the input data and page size, then computing total_items from the data length and total_pages via ceiling division.
#   data: collection — Collection object used to compute total_items via len(data) and stored on self.data.
#   page_size: integer — Positive integer page size used to compute total_pages.
1. Assign self.data to the input parameter data. → self.data
2. Assign self.page_size to the input parameter page_size. → self.page_size
3. Compute self.total_items as len(data). → self.total_items
4. Compute self.total_pages using the formula (self.total_items + page_size - 1) // page_size, performing integer floor division after adding page_size - 1. → self.total_pages

## get_page(page_number: int) → list
Summary: Return a page of data by computing zero-based start and end indices from a 1-based page number, or return an empty list for an out-of-range page number.
#   page_number: int — 1-based page number of the page to retrieve.
#   → result: list — The slice of self.data from start_index inclusive to end_index exclusive for the requested page, or an empty list when page_number is less than 1 or greater than self.total_pages.
1. After the page_number validity check passes, compute start_index as (page_number - 1) * self.page_size. → start_index
2. After the page_number validity check passes, compute end_index as start_index + self.page_size, producing the exclusive upper bound. → end_index
3. Return the slice self.data[start_index:end_index] with end_index exclusive. → result
   ? Return an empty list.

## get_page_info(page_number: integer) → dictionary
Summary: Retrieves one page of paginated data and its associated metadata when the requested page number is within range, returning an empty dictionary otherwise.
#   page_number: integer — 1-based page number to fetch
#   → page_info: dictionary — Pagination metadata and current page data when the page number is valid; otherwise an empty dictionary.
1. For a page_number that satisfies 1 <= page_number <= self.total_pages, compute start_index = (page_number - 1) * self.page_size. → start_index
2. Compute end_index = min(start_index + self.page_size, self.total_items). → end_index
3. Extract page_data = self.data[start_index:end_index]. → page_data
4. Initialize page_info as a dictionary. → page_info
5. Set page_info['current_page'] to page_number. → page_info.current_page
6. Set page_info['per_page'] to self.page_size. → page_info.per_page
7. Set page_info['total_pages'] to self.total_pages. → page_info.total_pages
8. Set page_info['total_items'] to self.total_items. → page_info.total_items
9. Set page_info['has_previous'] based on whether page_number > 1. → page_info.has_previous
10. Set page_info['has_next'] based on whether page_number < self.total_pages. → page_info.has_next
11. Set page_info['data'] to page_data. → page_info.data
12. Return page_info. → return
   ? Return an empty dictionary.

## search(keyword: string) → dict
Summary: Search the instance data for items whose string representation contains the given keyword, count the matching results, compute the total number of pages using page_size, and return a dictionary containing the keyword, totals, and matching results.
#   keyword: string — Search term used to filter self.data by checking whether it is contained in str(item) for each item.
#   → search_info: dict — Dictionary containing the keyword, total_results, total_pages, and the filtered results list.
1. Build results as a new list by iterating over self.data and keeping each item where keyword is contained in str(item). → results
2. Set num_results to len(results). → num_results
3. Set num_pages to the ceiling division of num_results by self.page_size using the formula (num_results + self.page_size - 1) // self.page_size. → num_pages
4. Create search_info as a dictionary with keyword set to keyword, total_results set to num_results, total_pages set to num_pages, and results set to the same results list object by reference. → search_info
5. Return search_info. → search_info
