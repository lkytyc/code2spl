Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

Class specification:

# Class: SplitSentence

## count_words(sentence: string) → integer
Summary: Cleans a sentence by removing all non-ASCII-letter and non-whitespace characters, splits the cleaned text into words, and returns the number of words.
#   sentence: string — The input sentence to clean and count words from.
#   → word_count: integer — The number of words in the cleaned sentence.
1. Remove every character from sentence that is not an ASCII letter or whitespace using regex substitution r'[^a-zA-Z\s]' with empty replacement and store the cleaned string back into sentence. → sentence
2. Split the cleaned sentence on whitespace runs to produce a list of word tokens. → words
3. Return the length of words. → word_count

## process_text_file(sentences_string: text) → integer
Summary: Splits the input text into sentences, counts the words in each sentence, and returns the maximum word count found.
#   sentences_string: text — The input text containing sentences to split and analyze.
#   → max_count: integer — The maximum word count among all sentences; returns 0 when there are no sentences.
1. Call self.split_sentences with sentences_string and store the returned collection in sentences. → sentences
2. Initialize max_count to the integer literal 0. → max_count
3. Start a for loop over each sentence in sentences. → sentence
4. Within the for loop over sentences, call self.count_words with sentence and store the returned value in count. → count
5. Within the for loop over sentences, if count is strictly greater than max_count, set max_count to count. → max_count
6. Return the final max_count value. → max_count

## split_sentences(sentences_string: string) → list
Summary: Splits an input string into sentence segments by splitting on whitespace immediately preceded by a period or question mark while avoiding common abbreviation patterns.
#   sentences_string: string — The input text to be split into sentences.
#   → sentences: list — The list of sentence segments produced by the regex split.
1. Call re.split on sentences_string using the regular expression r'(?<!\w\.\w.)(?<![A-Z][a-z]\.)(?<=\.|\?)\s' to split on whitespace preceded by a period or question mark while negative lookbehinds prevent splitting after abbreviation-like patterns such as Mr., Dr., Mrs., e.g., or U.S.; assign the returned list to sentences. If the regex does not match, re.split returns a list containing the original sentences_string; if sentences_string is empty, it returns a list containing one empty string; a trailing period or question mark followed by whitespace may produce an empty final element. → sentences
2. Return the list sentences as the method result. → sentences
