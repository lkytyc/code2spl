Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

Class specification:

# Class: Calculator
# Fields: operators
# Calls: calculate→precedence, calculate→apply_operator

## __init__()
Summary: Initializes the instance's operators dictionary with arithmetic operator symbols mapped to lambda functions performing addition, subtraction, multiplication, division, and exponentiation.
1. Assign to self.operators a dictionary mapping '+' to addition, '-' to subtraction, '*' to multiplication, '/' to division (which raises ZeroDivisionError when y is 0), and '^' to exponentiation. → self.operators

## apply_operator(self: object, operand_stack: list, operator_stack: list) → tuple
Summary: Pops an operator from operator_stack, applies the corresponding operator function from self.operators to the top two operands from operand_stack, pushes the result back, and returns the updated operand and operator stacks.
#   self: object — The current evaluator instance that owns the operators mapping.
#   operand_stack: list — Stack of operands from which the top two values are popped and to which the computed result is appended.
#   operator_stack: list — Stack of operators from which the top value is popped.
#   → result: tuple — A tuple containing the updated operand_stack and operator_stack.
1. Pop the top element from operator_stack and store it as operator. → operator
2. Evaluate whether operator equals '^'; both the if and else branches contain identical subsequent operations. → operator_is_caret
3. Within either branch, pop the top element from operand_stack and store it as operand2. → operand2
4. Within either branch, pop the next top element from operand_stack and store it as operand1. → operand1
5. Within either branch, compute result by calling self.operators[operator](operand1, operand2). → result
6. Within either branch, append result to operand_stack. → operand_stack
7. Return operand_stack and operator_stack. → result

## calculate(expression: string)
Summary: Evaluate an arithmetic expression string with support for +, -, *, /, ^ and parentheses by using a shunting-yard parser with an operand stack, operator stack, and numeric buffer, and return the final numeric result or None if no operand was produced.
#   expression: string — Arithmetic expression string to evaluate.
1. Initialize operand_stack as an empty list. → operand_stack
2. Initialize operator_stack as an empty list. → operator_stack
3. Initialize num_buffer as an empty string. → num_buffer
4. For each character char in expression, process it from left to right. → char
5. Within the for loop over char, if char is a digit or char equals '.', append char to num_buffer. → num_buffer
6. Within the for loop over char, in the else branch when char is neither a digit nor '.', if num_buffer is non-empty, append float(num_buffer) to operand_stack and then reset num_buffer to an empty string. → operand_stack,
7. Within the for loop over char, in the same else branch after the buffer flush check, if char is one of '+', '-', '*', '/', '^', while operator_stack is non-empty and operator_stack[-1] is not '(' and self.precedence(operator_stack[-1]) is greater than or equal to self.precedence(char), evaluated left-to-right with short-circuit, call self.apply_operator(operand_stack, operator_stack) and assign the returned pair back to operand_stack and operator_stack. → operand_stack,
8. Within the for loop over char, in the same operator branch, after the while loop, append char to operator_stack. → operator_stack
9. Within the for loop over char, in the same else branch, else if char equals '(', append char to operator_stack. → operator_stack
10. Within the for loop over char, in the same else branch, else if char equals ')', while operator_stack is non-empty and operator_stack[-1] is not '(', evaluated left-to-right with short-circuit, call self.apply_operator(operand_stack, operator_stack) and assign the returned pair back to operand_stack and operator_stack. → operand_stack,
11. Within the for loop over char, in the same ')' branch, after the while loop, pop the top '(' from operator_stack. → operator_stack
12. After the for loop, if num_buffer is non-empty, append float(num_buffer) to operand_stack. → operand_stack
13. While operator_stack is non-empty, call self.apply_operator(operand_stack, operator_stack) and assign the returned pair back to operand_stack and operator_stack. → operand_stack,
14. If operand_stack is non-empty, return operand_stack[-1]; otherwise return None. → result

## precedence(operator: string) → integer
Summary: Returns the arithmetic precedence level of a given operator using a predefined dictionary, defaulting to 0 for unknown operators.
#   operator: string — The operator symbol whose precedence is looked up.
#   → result: integer — The integer precedence level for the operator, or 0 if the operator is not in the predefined precedence dictionary.
1. Define a constant dictionary `precedences` mapping '+' and '-' to 1, '*' and '/' to 2, and '^' to 3. → precedences
2. Return the value from `precedences` for the input `operator`, defaulting to 0 when the operator is not present. → result
