Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

#   → result: number — The rounded result of self.taylor(x, 50) to 10 decimal places.

## factorial(a: integer) → integer
Summary: Computes the factorial of a positive integer input by initializing b to 1 and multiplying b by the current value of a while a is not equal to 1, then returning b.
#   a: integer — The input value whose factorial is computed; for values greater than 1 the loop executes, for 1 it is skipped, and for values less than 1 the loop does not terminate.
#   → b: integer — The accumulated product after the loop exits with a equal to 1, equal to the factorial of the input for positive integer inputs.
1. Initialize variable b to the integer constant 1. → b
2. While the condition a is not equal to 1 is true, execute the nested loop body; exit the loop only when a becomes equal to 1. → loop_condition
3. Within the while loop whose condition is a is not equal to 1, multiply b by the current value of a and assign the result back to b. → b
4. Within the same while loop, decrement a by 1. → a
5. Return the final value of b after the loop has exited with a equal to 1. → b

## sin(x: float) → float
Summary: Computes the sine of an angle given in degrees by converting it to radians, summing Taylor series terms until the absolute term is less than 1e-15, and returning the result rounded to 10 decimal places.
#   x: float — Angle in degrees whose sine value is computed.
#   → result: float — The computed sine value rounded to 10 decimal places as a float.
1. Convert the input angle x from degrees to radians by dividing x by 180 and multiplying by pi, storing the result back in x. → x
2. Initialize the accumulator g to 0. → g
3. Set the current term t to the radian value x. → t
4. Initialize the term counter n to 1. → n
5. Evaluate the while loop condition fabs(t) >= 1e-15; if true, enter the loop body, otherwise skip to the return step. → while_condition
6. Within the while loop, add the current term t to the accumulator g. → g
7. Within the while loop, increment n by 1. → n
8. Within the while loop, compute the next term t as -t * x * x / (2 * n - 1) / (2 * n - 2), then return to the while condition check. → t
9. After the while loop exits when the absolute value of t becomes less than 1e-15, round g to 10 decimal places and return it. → result

## tan(x: number)
Summary: Computes the tangent of x as sin(x)/cos(x), rounds it to 10 decimal places when cos(x) is non-zero, and returns False when cos(x) is zero.
#   x: number — Numeric angle input for tangent calculation.
1. Evaluate whether self.cos(x) is not equal to 0. → condition_true
2. If condition_true is true, compute result as self.sin(x) divided by self.cos(x). → result
3. If condition_true is true, return round(result, 10). → return_value
   ? Return False.

## taylor(self: object, x: number, n: integer) → number
Summary: Computes an alternating Taylor series approximation of cosine after converting the input angle from degrees to radians.
#   self: object — The current object instance that provides the factorial method used by the series terms.
#   x: number — The input angle in degrees; it is overwritten with its radian equivalent.
#   n: integer — Upper bound for the loop variable k; the loop runs from k = 1 to n - 1 inclusive, so n controls the highest even power 2 * (n - 1) in the series.
#   → a: number — The accumulated alternating Taylor series value approximating cosine at the converted radian value of x.
1. Initialize a to the integer constant 1. → a
2. Reassign x as (x / 180) * pi, converting the input angle from degrees to radians. → x
3. Initialize count to the integer constant 1. → count
4. For each integer k from 1 to n - 1 inclusive (range(1, n)), execute the following nested steps. → k
5. Within the for loop over k, if count modulo 2 is not equal to 0, subtract (x ** (2 * k)) / self.factorial(2 * k) from a. → a
6. Within the for loop over k, else when count modulo 2 equals 0, add (x ** (2 * k)) / self.factorial(2 * k) to a. → a
7. Within the for loop over k, after the if/else branch, increment count by 1. → count
8. Return the accumulated value a. → a
