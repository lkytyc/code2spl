Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of the same class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

class Order:
    """
    The class manages restaurant orders by allowing the addition of dishes, calculation of the total cost, and checkout.
    """


    def __init__(self):
        """
        Initialize the order management system
        self.menu stores the dishes of resturant inventory
        menu = [{"dish": dish name, "price": price, "count": count}, ...]
        self.selected_dishes stores the dished selected by customer
        selected_dish = {"dish": dish name, "count": count, price: price}
        self.sales stores the sales of each dish
        sales = {dish name: sales}
        """
        self.menu = []
        self.selected_dishes = []
        self.sales = {}


    def add_dish(self, dish):
        """
        Check the self.menu and add into self.selected_dish if the dish count is valid.
        And if the dish has successfully been added, change the count in self.menu.
        :param dish: dict, the information of dish. dish = {"dish": dish name, "count": count, price: price}
        :return: True if successfully added, or False otherwise.
        >>> order = Order()
        >>> order.menu.append({"dish": "dish1", "price": 10, "count": 5})
        >>> order.add_dish({"dish": "dish1", "price": 10, "count": 3})
        True
        """

    def calculate_total(self):
        """
        Calculate the total price of dishes that have been ordered. Multiply the count, price and sales.
        :return total: float, the final total price.
        >>> order = Order()
        >>> order.menu.append({"dish": "dish1", "price": 10, "count": 5})
        >>> order.sales = {"dish1": 0.8}
        >>> order.add_dish({"dish": "dish1", "price": 10, "count": 4})
        True
        >>> order.calculate_total()
        32.0
        """

    def checkout(self):
        """
        Check out the dished ordered. IF the self.selected_dishes is not empty, invoke the calculate_total
        method to check out.

        >>> order = Order()
        >>> order.menu.append({"dish": "dish1", "price": 10, "count": 5})
        >>> order.sales = {"dish1": 0.8}
        >>> order.add_dish({"dish": "dish1", "price": 10, "count": 4})
        True
        >>> order.checkout()
        32.0
        """

## add_dish(dish: object) → boolean
Summary: Deducts the requested count from the first matching menu dish if stock is sufficient, appends the dish to selected_dishes, and returns True; returns False if stock is insufficient.
#   dish: object — The dish to add, containing keys dish and count.
#   → result: boolean — True when the dish was appended successfully; False when the matching menu dish has insufficient stock.
1. Iterate over self.menu and compare dish["dish"] with each menu_dish["dish"] to find the first matching menu item. → matching_menu_dish
2. Within the for loop over self.menu, when a matching menu_dish is found and menu_dish["count"] is greater than or equal to dish["count"], subtract dish["count"] from menu_dish["count"] and break out of the loop. → consume_stock
3. After the for loop completes or breaks without an early return, append dish to self.selected_dishes. → append_dish
4. Return True. → return_value
   ? Return False immediately without modifying self.menu or self.selected_dishes.

## calculate_total() → number
Summary: Calculate the total cost of selected dishes by summing each dish's price multiplied by its count and its sales rate.
#   → total: number — The total cost of selected dishes after applying each dish's price, count, and sales rate.
1. Initialize total to 0. → total
2. For each dish in self.selected_dishes, compute dish['price'] * dish['count'] * self.sales[dish['dish']] and add the product to total. → total
3. Return the final accumulated total as the method result. → total

## checkout() → boolean or numeric

#   → return_value: boolean or numeric — False when selected_dishes is empty; otherwise the total returned by calculate_total() after selected_dishes is cleared.

2. Assign self.selected_dishes to a new empty list. → self.selected_dishes
3. Return total. → return_value
