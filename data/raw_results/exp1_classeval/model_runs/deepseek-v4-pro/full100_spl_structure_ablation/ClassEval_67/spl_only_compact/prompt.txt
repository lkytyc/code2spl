Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

# Class: Order
# Fields: sales, selected_dishes, menu
# Calls: checkout→calculate_total

## __init__()
Summary: Initializes an instance by setting menu and selected_dishes to empty lists and sales to an empty dictionary.
1. Assign an empty list to self.menu, intended to store dish records with keys dish, price, and count. → self.menu
2. Assign an empty list to self.selected_dishes, intended to store selected dish records with keys dish, count, and price. → self.selected_dishes

## add_dish(dish: object) → boolean
Summary: Deducts the requested count from the first matching menu dish if stock is sufficient, appends the dish to selected_dishes, and returns True; returns False if stock is insufficient.
#   dish: object — The dish to add, containing keys dish and count.
#   → result: boolean — True when the dish was appended successfully; False when the matching menu dish has insufficient stock.
1. Iterate over self.menu and compare dish["dish"] with each menu_dish["dish"] to find the first matching menu item. → matching_menu_dish
2. Within the for loop over self.menu, when a matching menu_dish is found and menu_dish["count"] is greater than or equal to dish["count"], subtract dish["count"] from menu_dish["count"] and break out of the loop. → consume_stock
3. After the for loop completes or breaks without an early return, append dish to self.selected_dishes. → append_dish
4. Return True. → return_value
   ? Return False immediately without modifying self.menu or self.selected_dishes.

## calculate_total() → number
Summary: Calculate the total cost of selected dishes by summing each dish's price multiplied by its count and its sales rate.
#   → total: number — The total cost of selected dishes after applying each dish's price, count, and sales rate.
1. Initialize total to 0. → total
2. For each dish in self.selected_dishes, compute dish['price'] * dish['count'] * self.sales[dish['dish']] and add the product to total. → total
3. Return the final accumulated total as the method result. → total

## checkout() → boolean or numeric
Summary: Checks out the selected dishes by returning False when none are selected, otherwise calculating the total, clearing the selected dishes, and returning the total.
#   → return_value: boolean or numeric — False when selected_dishes is empty; otherwise the total returned by calculate_total() after selected_dishes is cleared.
1. When self.selected_dishes is not empty, call self.calculate_total() and assign the returned value to total. → total
2. Assign self.selected_dishes to a new empty list. → self.selected_dishes
3. Return total. → return_value
