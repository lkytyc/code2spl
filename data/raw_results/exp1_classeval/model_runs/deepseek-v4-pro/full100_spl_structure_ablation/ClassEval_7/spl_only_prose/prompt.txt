Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

# Fields: expr, right_brackets, stack, left_brackets

## check_balanced_brackets() → boolean
Summary: Checks whether the brackets in self.expr are balanced by clearing previous expression parsing state, scanning each bracket to push opening brackets onto a stack and matching closing brackets against the stack in LIFO order, returning False on any mismatch or leftover opening bracket and True otherwise.
#   → balanced: boolean — True when every closing bracket matches the top of the stack and no opening brackets remain after scanning; False otherwise.
1. Call self.clear_expr() to clear any previous expression parsing state. → clear_status
2. For each Brkt in self.expr, evaluate whether Brkt is in self.left_brackets. → bracket_check
3. Within the for loop over self.expr, if Brkt is in self.left_brackets, append Brkt to self.stack. → push_result
4. Within the for loop over self.expr, in the else branch where Brkt is not in self.left_brackets, pop the top value from self.stack into Current_Brkt. → popped_bracket
5. Within the for loop over self.expr, in the else branch, if Current_Brkt is '(' and Brkt is not ')', return False. → paren_mismatch_result
6. Within the for loop over self.expr, in the else branch, if Current_Brkt is '{' and Brkt is not '}', return False. → brace_mismatch_result
7. Within the for loop over self.expr, in the else branch, if Current_Brkt is '[' and Brkt is not ']', return False. → square_mismatch_result
8. After the for loop completes, if self.stack is not empty, return False. → leftover_stack_result
9. Return True because no mismatch occurred and self.stack is empty. → balanced_result

## clear_expr()
Summary: Filters self.expr to retain only characters that are present in either self.left_brackets or self.right_brackets.
1. Assign to self.expr the result of joining every character c from the old self.expr where c is in self.left_brackets or c is in self.right_brackets, preserving original character order and duplicates; for each character, the self.right_brackets membership test is evaluated only when the self.left_brackets membership test is false. → self.expr
