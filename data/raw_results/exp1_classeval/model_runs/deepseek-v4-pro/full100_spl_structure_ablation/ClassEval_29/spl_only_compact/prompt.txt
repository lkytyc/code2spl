Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

Class specification:

# Class: DataStatistics

## mean(data: iterable of numeric values) → float
Summary: Computes the arithmetic mean of the input data and returns the result rounded to two decimal places.
#   data: iterable of numeric values — A non-empty sized iterable collection of numeric or addable values whose average is computed.
#   → result: float — The mean of data rounded to two decimal places.
1. Compute the sum of all elements in data. → total_sum
2. Compute the number of elements in data. → data_count
3. Divide total_sum by data_count to obtain the average. → average
4. Round average to 2 decimal places. → rounded_average
5. Return rounded_average. → return_value

## median(data: iterable) → number
Summary: Computes the median of an input dataset by sorting it and returning the middle element for odd lengths or the average of the two middle elements rounded to 2 decimal places for even lengths.
#   data: iterable — Input iterable of comparable elements whose median is computed.
#   → median: number — The median value: middle element for odd length, or rounded average of the two middle elements for even length.
1. Sort the input data in ascending order and store the result in sorted_data. → sorted_data
2. Set n to the number of elements in sorted_data. → n
3. If n is even, set middle to the integer quotient of n divided by 2, compute the average of sorted_data[middle - 1] and sorted_data[middle], round the average to 2 decimal places, and return it. → median
   ? Set middle to the integer quotient of n divided by 2.
   ? Return sorted_data[middle].

## mode(data: iterable) → list
Summary: Computes the mode(s) of the input data by counting element frequencies and returning all values that share the maximum frequency.
#   data: iterable — Input iterable whose elements are counted to determine the mode.
#   → mode: list — List of all values in data that have the highest frequency; if only one value has the highest frequency, the list contains that single value.
1. Create a frequency mapping counter from data using Counter(data). → counter
2. Compute mode_count as the maximum value among counter.values(). If data is empty, counter.values() is empty and this step raises ValueError. → mode_count
3. Within the list comprehension over counter.items(), collect each key x where count equals mode_count. → mode
4. Return mode. → mode
