Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

# Class: TextFileProcessor
# Fields: file_path
# Calls: process_file→read_file, process_file→write_file

## __init__(file_path: str)
Summary: Initializes the instance by storing the provided file_path argument in the file_path attribute.
#   file_path: str — The file path value to assign to the instance attribute.
1. Assign the input parameter file_path to the instance attribute self.file_path. → self.file_path

## process_file() → str
Summary: Reads a file, filters its content to retain only alphabetic characters, writes the filtered content back to the file, and returns it.
#   → content: str — The filtered file content containing only alphabetic characters.
1. Call self.read_file() and assign the returned value to content. → content
2. Reassign content by iterating over each character in the current content, retaining only characters where char.isalpha() is true, and joining the retained characters into one string. → content
3. Call self.write_file(content) with the current filtered content. → content
4. Return content. → content

## read_file() → str
Summary: Reads and returns the entire text content of the file located at self.file_path.
#   → content: str — The complete text content of the file.
1. Within a with-block, open the file at self.file_path in read mode ('r') and bind the file object to file. → file
2. Read the entire contents from file and return them as the method result; the with-block closes the file automatically after returning. → content

## read_file_as_json() → any
Summary: Reads the file at self.file_path, parses its contents as JSON, and returns the parsed data.
#   → data: any — The parsed JSON content read from self.file_path.
1. Open the file at self.file_path in read mode within a with block and assign the file object to file. → file
2. Within the with block, parse the JSON content from file using json.load and assign the result to data. → data
3. Return data. → data

## write_file(content: str)
Summary: Writes the provided string content to the file specified by the instance attribute file_path, overwriting any existing file content.
#   content: str — The string content to write to the file.
1. Open the file at the instance attribute file_path in write mode ('w'), creating the file if it does not exist or truncating it if it does, and bind the resulting file object to file. → file
2. Write the entire content string to the file object file. → write_result
3. Close the file object file automatically when leaving the with block. → close_result
