Task:
Reconstruct one complete executable Python class from the compact class specification.

Spec Concept:
- The compact specification is a code-derived, human-readable behavior map of a class.
- A `# Class:` line names the class, `# Fields:` lists its fields, and `# Calls:` lists cross-method call edges.
- Each method has a `## name(self, ...) → return` section that lists its parameters with types and its numbered implementation steps.
- Numbered steps describe the normal statement order; steps marked `IF`, `RETURN`, or `THROW` describe branches, returns, and raised errors.
- `?` lines describe alternative branches; `! log:` and `! raise:` lines describe exception paths.
- A `→ name` annotation on a step names the value that step produces.

Reconstruction Workflow:
Step 1: Scan the class overview and method sections to infer class name, constructor, field assignments, method names, method signatures, and return behavior.

Step 2: Build a class-level behavior map:
- fields and shared state from `# Fields:` and step result names;
- method contracts from each method signature;
- call graph from `# Calls:` and cross-method calls inside steps;
- branch and exception behavior from `IF`, `?`, and `!` lines.

Step 3: Implement each method from its numbered steps:
- numbered steps become the normal statement order;
- `?` alternative steps become conditional branches;
- `! raise:` steps become try/except or explicit raise only when required;
- `→` result names become local variables, fields, calls, or returned values.

Step 4: Use the simplest valid Python implementation when formatting, style, or exact variable names are omitted.

Step 5: Do not invent unrelated behavior that is not supported by the specification.

Reconstruction Rules:
- Identify the class, constructor, fields, methods, dependencies, return values, and error behavior described by the specification.
- Preserve cross-method calls, field usage, control flow, data flow, return values, and exceptions.
- Output only the complete Python class implementation.
- Do not use markdown fences and do not explain.

# Class: ArgumentParser
# Fields: types, arguments, required
# Calls: parse_arguments→_convert_type

## __init__()
Summary: Initializes a new instance by setting self.arguments and self.types to empty dictionaries and self.required to an empty set.
1. Assign an empty dictionary to the instance attribute self.arguments. → self.arguments
2. Create an empty set by calling the built-in set constructor and assign it to the instance attribute self.required. → self.required
3. Assign an empty dictionary to the instance attribute self.types. → self.types

## _convert_type(arg: object, value: object) → object
Summary: Convert a value by retrieving the converter associated with arg from self.types and calling it with value, falling back to the original value when a ValueError or KeyError occurs.
#   arg: object — Key used to select the converter from self.types.
#   value: object — Value to convert.
#   → result: object — Converted value, or the original value if conversion raises ValueError or KeyError.
1. Retrieve the converter callable from self.types using arg as the key. → converter
2. Call the converter with value. → converted_value
3. Return converted_value as the method result. → result
   ? Return the original value unchanged.

## add_argument(arg: str, required: bool, arg_type: type)
Summary: Registers an argument by adding it to the required set when required is true and always recording its type in the types mapping.
#   arg: str — The argument name or key to register.
#   required: bool — If true, the argument is added to the required set.
#   arg_type: type — The type to associate with the argument.
1. If required is True, add arg to self.required. → self.required
2. Store arg_type into self.types under key arg, overwriting any existing value or inserting a new key-value pair. → self.types

## get_argument(self: object, key: any) → any
Summary: Returns the value associated with the given key from the instance's arguments mapping, or None if the key is absent.
#   self: object — The current instance that owns the arguments mapping.
#   key: any — The key to look up in the arguments mapping.
#   → result: any — The value stored under key in self.arguments, or None if the key is not present.
1. Access the arguments mapping attribute on self. → arguments_map
2. Return the value from arguments_map for key using a mapping get operation with default value None. → result

## parse_arguments(command_string: string) → tuple
Summary: Parses command_string by dropping the first token, then stores long options (--key=value or --flag) and short options (-key value or -key) in self.arguments using _convert_type or True, and returns a boolean success indicator plus missing required arguments.
#   command_string: string — The raw command string whose first token is the command name and whose remaining tokens are arguments to parse.
#   → return_value: tuple — Returns (False, missing_args) when required arguments are missing; otherwise returns (True, None).
1. Split command_string on whitespace, drop the first token, and assign the remaining token list to args. → args
2. For each index i from 0 to len(args) - 1, assign args[i] to arg. → arg
3. Within the for loop over i, if arg starts with '--', remove the leading '--' and split the remainder on '=' into key_value. → key_value
4. Within the long-option branch, if len(key_value) equals 2, assign self.arguments[key_value[0]] = self._convert_type(key_value[0], key_value[1]). → self.arguments[key_value[0]]
5. Within the long-option branch, otherwise (len(key_value) is not 2, including no '=' or multiple '=' signs), assign self.arguments[key_value[0]] = True. → self.arguments[key_value[0]]
6. Within the for loop over i, else if arg starts with '-' and is not a long option, set key = arg[1:]. → key
7. Within the short-option branch, if i + 1 is less than len(args) and args[i + 1] does not start with '-', assign self.arguments[key] = self._convert_type(key, args[i + 1]); do not skip the consumed next argument in the for-loop indexing. → self.arguments[key]
8. Within the short-option branch, otherwise assign self.arguments[key] = True. → self.arguments[key]
9. Within the for loop over i, if arg does not start with '-', leave arg unchanged and continue the loop without storing anything. → arg
10. After the for loop, compute missing_args = self.required - set(self.arguments.keys()). → missing_args
11. If missing_args is empty, return True and None. → return_value
   ? Return False and missing_args.
