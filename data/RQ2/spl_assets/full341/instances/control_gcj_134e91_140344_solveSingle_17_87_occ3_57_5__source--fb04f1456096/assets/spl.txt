[DEFINE_WORKER: "Determines a hidden five-character string by querying positions through Scanner in and eliminating characters A-E according to exact frequency thresholds, then returns the reconstructed string." solveSingle]
    [INPUTS]
        <REF> in </REF>: Scanner "Scanner from which each one-character answer to a printed query position is read."
    [END_INPUTS]

    [OUTPUTS]
        <REF> result </REF>: String "The final accumulated sol string returned by solveSingle."
    [END_OUTPUTS]

    [MAIN_FLOW]
        [SEQUENTIAL_BLOCK]
            [COMMAND Initialize sol as a new empty StringBuilder, chars as a new ArrayList containing characters A, B, C, D, E in that order, and occ5 as a new empty HashMap from Character to ArrayList<Integer>. RESULT initial_state]
            [COMMAND For each character c in chars, add occ5.put(c, new ArrayList<>()) so every current candidate in chars has an empty ArrayList in occ5. RESULT occ5]
            [COMMAND For i from 0 through 118 inclusive, compute c = i * 5 + 1, print c, read the next answer character n from Scanner in, retrieve occ5.get(n), and add c to that list. RESULT occ5]
            [COMMAND Iterate over each entry e5 in occ5.entrySet() in entry-set iteration order. If e5.getValue().size() equals 24, ignore that entry and continue; otherwise append e5.getKey() to sol, remove that character from chars, create a new empty HashMap occ4, and initialize occ4 with an empty ArrayList for every remaining character in chars, repeating this block for each e5 that satisfies the non-24 condition. RESULT occ4]
            [COMMAND Inside each selected e5 non-24 block, for i from 0 through 22 inclusive, compute c = i * 5 + 2, print c, read the next answer character n from Scanner in, retrieve occ4.get(n), and add c to that list. RESULT occ4]
            [COMMAND Inside the same selected e5 block, iterate over each entry e4 in occ4.entrySet() in entry-set iteration order. If e4.getValue().size() equals 6, ignore that entry and continue; otherwise append e4.getKey() to sol, remove that character from chars, create a new empty HashMap occ3, and initialize occ3 with an empty ArrayList for every remaining character in chars, repeating this block for each e4 that satisfies the non-6 condition. RESULT occ3]
            [COMMAND Inside each selected e4 non-6 block, for i from 0 through 4 inclusive, compute c = i * 5 + 3, print c, read the next answer character n from Scanner in, retrieve occ3.get(n), and add c to that list. RESULT occ3]
            [COMMAND Inside the same selected e4 block, iterate over each entry e in occ3.entrySet() in entry-set iteration order. If e.getValue().size() equals 2, ignore that entry and continue; otherwise remove e.getKey() from chars, append e.getKey() to sol, and set askLast to e.getValue().get(0) + 1, repeating this block for each e that satisfies the non-2 condition. RESULT askLast]
            [COMMAND Inside each selected e non-2 block, print askLast, read the next answer character n from Scanner in, scan chars in order and append the first remaining character c such that c != n, breaking immediately after that append, and then append n to sol. RESULT sol]
            [COMMAND Return sol.toString(). RESULT result]
        [END_SEQUENTIAL_BLOCK]
    [END_MAIN_FLOW]

[END_WORKER]
