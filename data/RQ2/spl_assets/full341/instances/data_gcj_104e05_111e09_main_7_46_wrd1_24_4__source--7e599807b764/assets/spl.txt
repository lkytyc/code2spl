    [END_OUTPUTS]

            [COMMAND Inside the outer loop over i, read the next input line and parse it as noOfWords, the number of words in the current test case. RESULT noOfWords]

            [COMMAND Inside the outer loop over i, set c1 to 0. RESULT c1]
            [COMMAND While wrd1.hasNext(), do all of the following at the start of each outer iteration: increment c1 by 1, set c2 to 0, set wordOne to wrd1.next(), and set the local variable result to 0. RESULT wordOne]
            [COMMAND Within the outer while loop over wrd1, while wrd2.hasNext(), increment c2 by 1. Because wrd2 was created before the outer loop and is never reset, this inner loop exhausts wrd2 during the first outer iteration and is skipped for later wordOne values. RESULT c2]
            [COMMAND Within the inner while loop over wrd2, if c1 equals c2, do not advance wrd2 and skip the wordTwo substring matching for that inner iteration. RESULT none]
            [COMMAND Within the inner while loop over wrd2, if c1 does not equal c2, read wordTwo from wrd2.next().             [COMMAND Within the innermost k loop, if the preceding condition is false, break out of the k loop immediately. RESULT none]
            [COMMAND Continue the outer wrd1 loop until wrd1.hasNext() is false; after all test cases complete, the method returns void without producing any output. RESULT void]
        [END_SEQUENTIAL_BLOCK]
    [END_MAIN_FLOW]
