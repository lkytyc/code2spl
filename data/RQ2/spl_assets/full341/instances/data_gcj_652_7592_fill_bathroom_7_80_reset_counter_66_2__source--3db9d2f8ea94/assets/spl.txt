[DEFINE_WORKER: "Simulates placing users into bathroom stalls one by one by choosing the empty stall with the lexicographically maximum pair of min(left distance, right distance) and max(left distance, right distance), updates the left/right empty-distance arrays after each placement, and prints the final selected stall's (max, min) criteria for the given test case." fill_bathroom]
    [INPUTS]
        <REF> n_case </REF>: int "Zero-based test case index used to print the one-based case number as Case #n_case+1."
        <REF> stalls </REF>: int "Number of bathroom stalls; must be valid for allocations and loop bounds. Invalid negative values or allocation failures are not handled."
        <REF> users </REF>: int "Number of users to place into stalls; this is the number of iterations of the main placement loop."
    [END_INPUTS]

    [OUTPUTS]
    [END_OUTPUTS]

    [MAIN_FLOW]
        [SEQUENTIAL_BLOCK]
            [COMMAND Allocate three integer arrays of length stalls named stalls_occupancy, ls, and rs using malloc, and zero-initialize all stalls_occupancy entries with memset; no null-pointer checks are performed. RESULT allocated_arrays]
            [COMMAND Initialize max_crit1 to 0 and max_crit2 to 0. RESULT max_criteria_initialized]
            [COMMAND For i from 0 to stalls-1 inclusive, set ls[i] = i and rs[i] = stalls - i - 1. RESULT initial_distances_set]
            [COMMAND Repeat the following placement procedure users times, with outer loop index i from 0 to users-1 inclusive: reset pos to 0, max_crit1 to 0, and max_crit2 to 0; then for each empty stall j from 0 to stalls-1, compute crit1 = MIN(ls[j], rs[j]) and crit2 = MAX(ls[j], rs[j]); update pos, max_crit1, and max_crit2 when crit1 is greater than the current max_crit1, or when crit1 equals max_crit1 and crit2 is greater than max_crit2. RESULT selected_stall]
            [COMMAND In the same placement iteration, mark the selected stall as occupied by setting stalls_occupancy[pos] = 1. RESULT selected_stall_occupied]
            [COMMAND In the same placement iteration, scan from pos+1 to stalls-1 inclusive, assign ls[i] for each visited i to the current reset_counter starting at 0, increment reset_counter after each assignment, and break at the first already-occupied stall after assigning to it and incrementing reset_counter. RESULT right_distances_updated]
            [COMMAND In the same placement iteration, reset reset_counter to 0, scan from pos-1 down to 0 inclusive, assign rs[i] for each visited i to the current reset_counter, increment reset_counter after each assignment, and break at the first already-occupied stall after assigning to it and incrementing reset_counter. RESULT left_distances_updated]
            [COMMAND After all user placements are finished, free the allocated arrays stalls_occupancy, ls, and rs. RESULT arrays_freed]
            [COMMAND Print to stdout the line in the format 'Case #%d: %d %d\n' using printf, where the first argument is n_case + 1, the next is the final max_crit2, and the last is the final max_crit1. RESULT printf_output]
        [END_SEQUENTIAL_BLOCK]
    [END_MAIN_FLOW]

[END_WORKER]

[DEFINE_WORKER: "Reads a test-case count T from standard input, then for each test case reads stall and user counts and calls fill_bathroom(i, stalls, users), finally returning 0." main]
    [INPUTS]
    [END_INPUTS]

    [OUTPUTS]
        <REF> return_value </REF>: int "Always returns 0 after all test cases have been processed."
    [END_OUTPUTS]

    [MAIN_FLOW]
        [SEQUENTIAL_BLOCK]
            [COMMAND Initialize integer T to 0. RESULT T]
            [COMMAND Read an integer from standard input into T using scanf("%d", &T); if the read fails, T remains 0. RESULT T]
            [COMMAND Start a for loop: initialize i to 0; execute the body for i = 0, 1, ..., T-1 while the condition i < T holds; increment i by 1 after each iteration. RESULT i]
            [COMMAND Within the for loop body for the current i, initialize integers stalls and users to 0. RESULT stalls, users]
            [COMMAND Within the for loop body for the current i, read two integers from standard input into stalls and users using scanf("%d %d", &stalls, &users); if fewer than two values are assigned, the unassigned variable retains its initialized value 0. RESULT stalls, users]
            [COMMAND Within the for loop body for the current i, call fill_bathroom(i, stalls, users) to process the test case. RESULT void]
            [COMMAND After the for loop has completed all iterations, return 0 from main. RESULT return_value]
        [END_SEQUENTIAL_BLOCK]
    [END_MAIN_FLOW]

[END_WORKER]
