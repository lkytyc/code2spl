    [END_INPUTS]

        [SEQUENTIAL_BLOCK]
            [COMMAND While the scanner sc has more input, process the next test case: read integer N and allocate a boolean adjacency matrix R of size (N+1) by (N+1), initially false. RESULT test_case]
            [COMMAND Within the current test case, for each row index i from 1 through N inclusive, read node r and degree k. RESULT row_values]
            [COMMAND For the current row, for each neighbor index j from 0 through k-1 inclusive, read a destination node and set R[r][destination] to true. RESULT adjacency_matrix_R]
            [COMMAND Within the current test case, read integer P; then for each query index i from 0 through P-1 inclusive, execute a query search. RESULT query_loop]
            [COMMAND For each query, read source s, destination d, and initial TTL v. Initialize ans to -1, open to a new PriorityQueue<C0144> containing the single state C0144(s, v, 1) (node s, TTL v, cost 1), and close to an array of C0144 references of length N+1 with all entries null. RESULT query_initial_state]
            [COMMAND While open is not empty, poll a state now from open according to C0144's priority order. Decrement now.ttl by 1; if the decremented now.ttl equals 0, skip the rest of this while-loop iteration and continue to the next loop condition. RESULT polled_state]
            [COMMAND For each node j from 1 through N inclusive, if R[now.now][j] is true, evaluate moving from now.now to j with remaining TTL now.ttl and candidate cost now.c + 1. RESULT candidate_edge_j]
            [COMMAND If close[j] is null: when j equals d, set ans to now.c + 1 if ans is -1, otherwise set ans to the smaller of ans and now.c + 1, and continue to the next j; otherwise enqueue a new C0144(j, now.ttl, now.c + 1) into open and assign a separate new C0144(j, now.ttl, now.c + 1) to close[j]. RESULT unseen_state_handling]
            [COMMAND If close[j] is not null and either now.c + 1 is less than close[j].c or now.ttl is greater than close[j].ttl: when j equals d, update ans in the same min-with-existing manner and continue to the next j; otherwise enqueue a new C0144(j, now.ttl, now.c + 1) into open and replace close[j] with a separate new C0144(j, now.ttl, now.c + 1). If the condition is false, take no action for this j. RESULT improved_state_handling]
            [COMMAND After the open queue is exhausted for the current query, output ans if ans is not negative; otherwise output the string 'NA'. RESULT query_output]
