[DEFINE_WORKER: "Reads N and N point records, precomputes nearest-coordinate costs for every subset mask, enumerates all ternary horizontal/vertical/no-line assignments to minimize the weighted sum for each selected-line count, and prints the minimum values for counts 0 through N." main]
    [INPUTS]
    [END_INPUTS]

    [END_OUTPUTS]

    [MAIN_FLOW]
        [SEQUENTIAL_BLOCK]
            [COMMAND Declare N as int, X, Y, P, a as int arrays of size 20, Z as long[1<<16][16][2], and ans as long[20]; initialize ans[0] to 1L<<60 and ans[1..19] to 0 via the initializer, leaving Z and a uninitialized. RESULT declarations]
            [COMMAND Read one integer from standard input into N using scanf("%d", &N); if the conversion fails, N is not updated. RESULT N]
            [COMMAND For i from 0 through N-1, read three integers from standard input into X[i], Y[i], P[i] using scanf("%d%d%d", X+i, Y+i, P+i), then set ans[i+1] to 1L<<60. RESULT points_and_ans]
            [COMMAND For i from 0 through (1<<N)-1 and for j from 0 through N-1, set Z[i][j][0] to abs(X[j]) and Z[i][j][1] to abs(Y[j]). RESULT Z_defaults]
            [COMMAND Within the i and j loops, for each k from 0 through N-1, if bit k of i is set, update Z[i][j][0] to min(Z[i][j][0], (long)abs(X[j]-X[k])) and Z[i][j][1] to min(Z[i][j][1], (long)abs(Y[j]-Y[k])). RESULT Z_final]
            [COMMAND While a[N] is zero, process the ternary assignment state stored in a; the source declares a without an initializer, so this reads indeterminate values unless the runtime zero-initializes automatic storage, and the intended enumeration assumes a[0..N] starts as all zeros.             [COMMAND Inside the while loop, set h and v to 0; for i from 0 through N-1, if a[i] equals 1 set bit i in h, and if a[i] equals 2 set bit i in v. RESULT masks_h_v]
            [COMMAND Compute t as popcount(h | v), initialize sum to 0, and for i from 0 through N-1 add (long)P[i] * min(Z[h][i][0], Z[v][i][1]) to sum. RESULT t_and_sum]
            [COMMAND Increment the ternary-number state in a: start at index 0, while a[i] equals 2 set a[i] to 0 and advance i, then increment the first digit that is not 2; if all digits 0 through N-1 were 2, this increments the sentinel a[N]. RESULT updated_a]
            [COMMAND Update ans[t] to min(ans[t], sum). RESULT ans_updated]
            [COMMAND After the while loop terminates, for i from 0 through N inclusive, print ans[i] as a long integer followed by a newline using printf("%ld\n", ans[i]). RESULT printed_output]
