[DEFINE_WORKER: "Reads a recipe/transmutation problem from buffered input, repeatedly produces as much of metal 0 as current stock permits, decomposes scarce metals into their component metals, and returns the final quantity of metal 0 as a string." solve]
    [INPUTS]
        <REF> input </REF>: BufferedReader "BufferedReader providing the input lines: first line M, then M pairs of component indices, then M quantity values."
    [END_INPUTS]

    [OUTPUTS]
        <REF> result </REF>: String "String representation of the final quantity of metal 0 after production and decomposition."
    [END_OUTPUTS]

    [MAIN_FLOW]
        [SEQUENTIAL_BLOCK]
            [COMMAND Read the first line from input, parse it as integer M, and allocate int[] part1, int[] part2, and int[] quantities, each of length M. RESULT arrays_initialized]
            [COMMAND For i from 0 to M-1, read a line from input, split it on a single space, parse the first token and second token as integers, subtract 1 from each, and assign the results to part1[i] and part2[i]. RESULT part1_part2_initialized]
            [COMMAND Read the next line from input, split it on a single space, and for i from 0 to M-1 parse nums[i] as an integer and assign it to quantities[i]. RESULT quantities_initialized]
            [COMMAND Create HashMap<Integer,Integer> transmuted, put transmuted[part1[0]] = 1 and transmuted[part2[0]] = 1, and initialize boolean stuck = false. RESULT transmuted_initialized]
            [COMMAND While stuck is false, set min = Integer.MAX_VALUE; for each Map.Entry pair in transmuted, if quantities[pair.getKey()] / pair.getValue() (integer division) is less than min, update min to that quotient. RESULT min_computed]
            [COMMAND In the same while-loop iteration, add min to quantities[0]; then for each Map.Entry pair in transmuted, subtract min * pair.getValue() from quantities[pair.getKey()]. RESULT production_applied]
            [COMMAND In the same while-loop iteration, create newTransmuted as an empty HashMap<Integer,Integer>; then for each Map.Entry pair in transmuted, let metal = pair.getKey() and quantity = pair.getValue(); if quantity > quantities[metal], enter shortage handling. RESULT shortage_detected]
            [COMMAND In the shortage handling for the current entry, if part1[metal] == 0 or part2[metal] == 0 or quantity > 1000000000, set stuck = true and break out of the current entry loop only; otherwise decompose metal: add quantity to newTransmuted for part1[metal] and for part2[metal], add quantities[metal] to quantities[part1[metal]] and quantities[part2[metal]], add -quantity to newTransmuted for metal, and set quantities[metal] = 0. RESULT shortage_branch_executed]
            [COMMAND After the entry loop, for each Map.Entry pair in newTransmuted, merge its value into transmuted under the same key by adding to the existing value, or by inserting it if absent; if the resulting transmuted value is exactly 0, remove that key from transmuted. RESULT transmuted_merged]
            [COMMAND Re-evaluate the while condition; if stuck is true exit the while loop, otherwise repeat from min computation. RESULT while_condition_rechecked]
            [COMMAND Return String.valueOf(quantities[0]). RESULT final_result]
        [END_SEQUENTIAL_BLOCK]
    [END_MAIN_FLOW]

    [ALTERNATIVE_FLOW: In the shortage loop, the current transmuted entry has quantity > quantities[metal] and the metal is decomposable because part1[metal] != 0, part2[metal] != 0, and quantity <= 1000000000.]
        [SEQUENTIAL_BLOCK]
            [COMMAND If newTransmuted already contains part1[metal], add quantity to its existing value; otherwise insert part1[metal] with value quantity. Then add quantities[metal] to quantities[part1[metal]]. RESULT part1_replacement_recorded]
            [COMMAND If newTransmuted already contains part2[metal], add quantity to its existing value; otherwise insert part2[metal] with value quantity. Then add quantities[metal] to quantities[part2[metal]]. RESULT part2_replacement_recorded]
            [COMMAND If newTransmuted already contains metal, subtract quantity from its existing value; otherwise insert metal with value -quantity. Then set quantities[metal] = 0. RESULT metal_replacement_consumed]
        [END_SEQUENTIAL_BLOCK]
    [END_ALTERNATIVE_FLOW]

    [ALTERNATIVE_FLOW: In the shortage loop, the current transmuted entry has quantity > quantities[metal] and the metal is not decomposable because part1[metal] == 0 or part2[metal] == 0 or quantity > 1000000000.]
        [SEQUENTIAL_BLOCK]
            [COMMAND Set stuck = true and break only out of the current entry loop over transmuted. RESULT stuck_set]
            [COMMAND Continue to the later merge loop over newTransmuted so partial newTransmuted updates are still merged into transmuted before the while condition is rechecked. RESULT partial_merge_after_stuck]
        [END_SEQUENTIAL_BLOCK]
    [END_ALTERNATIVE_FLOW]

    [EXCEPTION_FLOW: input.readLine() throws an IOException while reading any input line.]
        [LOG "I/O error occurred while reading from the BufferedReader."]
        [THROW IOException "The solve method declares throws IOException, so the failure propagates to the caller."]
    [END_EXCEPTION_FLOW]

    [EXCEPTION_FLOW: A token supplied on an input line is not a valid integer, or readLine returns null before an expected value so Integer.parseInt(null) is called.]
        [LOG "Malformed or missing integer input encountered."]
        [THROW NumberFormatException "Thrown by Integer.parseInt when a string cannot be parsed as an int."]
    [END_EXCEPTION_FLOW]

[END_WORKER]
