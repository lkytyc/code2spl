            [COMMAND Read integer Q from the input stream ir. RESULT Q]
            [COMMAND Initialize max-heap PriorityQueue f, min-heap PriorityQueue l, long accumulators fsum = 0 and lsum = 0, and long accumulator B = 0. RESULT state]
            [COMMAND Enter a while loop with condition Q-- > 0: compare the current value of Q with 0, then decrement Q; loop iterations happen only when the pre-decrement value is positive. RESULT loop_control]
