[DEFINE_WORKER: "Runs a 100-day vase peeking and stuffing schedule by maintaining a target vase and optional stuffing vase, choosing peeks or the smallest absent token based on last peek times and current minimum vase sizes." solvecase]
    [INPUTS]
    [END_INPUTS]

    [OUTPUTS]
    [END_OUTPUTS]

    [MAIN_FLOW]
        [SEQUENTIAL_BLOCK]
            [COMMAND Initialize vases to [None] plus 20 distinct empty lists, peektime to a 21-element list of zeros, stuffV to None, tokens to 0, and target to 1. RESULT initial_state]
            [COMMAND For each day d from 1 to 100 inclusive, read the next integer dd as a singleton tuple via getints(), assert d == dd, and increment tokens by 1. RESULT day_input_checked]
            [COMMAND Within the outer day loop, choose V and P. If d <= 19, set V = d and P = 100. Else if d == 100, set V = 20 and P = 100. Else if stuffV is not None, set V = stuffV and v = vases[V], write to stderr 'TARGET peektime: %s' followed by a newline with peektime[target]; then if peektime[target] <= d - 5, override V = target and set P = 0 and write to stderr 'PEEK TARGET instead' followed by a newline; else if peektime[V] <= d - 30, set P = 0 and write to stderr 'PEEK instead' followed by a newline; else set P = 1 and repeatedly increment P while P is already present in v, so P becomes the smallest positive integer not in v. Otherwise, when stuffV is None, set V = target and P = 0. RESULT V_P_selection]
            [COMMAND Within the outer day loop, call printflush('{} {}'.format(V, P)) to output the chosen vase and token, then set stuffV = None. RESULT day_output]
            [COMMAND Within the outer day loop, update vase state based on P: if P == 0, read L = getints(), redefine L as [x for x in L[1:] if x < 100], assign vases[V] = L, and set peektime[V] = d; else if P != 100, append P to vases[V] and increment tokens by 1; if P == 100, perform no vase update. RESULT state_updated]
            [COMMAND Within the outer day loop, compute m = min(len(vases[V]) for V in range(1, 21)), the minimum vase size among vases 1 through 20 inclusive. RESULT m]
            [COMMAND Within the outer day loop, write to stderr 'day = %s; m = %s; target = %s' followed by a newline with (d, m, target), and write to stderr 'sizes: %s' followed by a newline with the space-joined lengths of vases 1 through 20. RESULT log_written]
            [COMMAND Within the outer day loop, if len(vases[target]) == m, initialize m2 = 10000 and mtime = 0, then for each V from 1 to 20 inclusive, skipping V == target, if len(vases[V]) < m2 or (len(vases[V]) == m2 and peektime[V] > mtime), set stuffV = V, m2 = len(vases[V]), and mtime = peektime[V]; finally write to stderr 'STUFFING vase %s' followed by a newline with stuffV. RESULT stuffV]
            [COMMAND Within the outer day loop, if len(vases[target]) != m, iterate target over the range 1 to 20 inclusive and stop at the first vase whose length equals m, leaving target as that first minimal vase; then write to stderr 'NEW target = %s' followed by a newline with target. RESULT target]
        [END_SEQUENTIAL_BLOCK]
    [END_MAIN_FLOW]

    [EXCEPTION_FLOW: During the outer day loop, assert(d == dd) fails because the read day number dd does not equal the expected loop day d.]
        [LOG "AssertionError: assert d == dd"]
        [THROW AssertionError "The input day numbers are not sequential as expected."]
    [END_EXCEPTION_FLOW]

[END_WORKER]
