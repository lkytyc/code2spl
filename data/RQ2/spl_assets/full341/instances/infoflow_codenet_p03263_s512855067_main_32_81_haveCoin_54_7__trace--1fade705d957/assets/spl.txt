[DEFINE_WORKER: "Reads a grid of 0/1 cells from standard input and prints the number and coordinates of every unit segment along a row-wise snake traversal that connects each consecutive pair of cells marked 1." main]
    [INPUTS]
    [END_INPUTS]

    [OUTPUTS]
        <REF> return </REF>: int "Always returns 0 to indicate successful completion."
    [END_OUTPUTS]

    [MAIN_FLOW]
        [SEQUENTIAL_BLOCK]
            [COMMAND Declare a static unsigned short array out with 1,000,000 elements and a char array a with 501 elements. RESULT buffers_declared]
            [COMMAND Call gl() twice to read the grid dimensions, storing the results in const int h and const int w; the order of the two calls is unspecified. RESULT dimensions_read]
            [COMMAND Initialize int pos to 0 and char haveCoin to 0, and declare short old_y and old_x which will hold the previous cell coordinates in snake order; old_y and old_x are uninitialized until the first processed cell. RESULT state_initialized]
            [COMMAND For each row i from 1 to h inclusive: read that row into a[1..w] by, for each j from 1 to w, reading one character, subtracting 48 to get t, consuming the following separator character with getchar_unlocked(), and storing t in a[j]; then traverse the row in snake order (if i is odd visit j=1..w, otherwise visit j=w..1) and for each visited cell (i,j): if haveCoin is nonzero, append old_y, old_x, i, j to out at indices 4*pos through 4*pos+3 and increment pos; then toggle haveCoin by XORing it with (a[j] & 1); then set old_y=i and old_x=j. RESULT out_and_state_after_all_rows]
            [COMMAND After the row loop, call pl(pos) to print the number of stored segments, then call putchar_unlocked('\n') to print a newline. RESULT segment_count_printed]
            [COMMAND For each index i from 0 to pos-1 inclusive, print the stored segment coordinates in order: pl(out[4*i]), putchar_unlocked(' '), pl(out[4*i+1]), putchar_unlocked(' '), pl(out[4*i+2]), putchar_unlocked(' '), pl(out[4*i+3]), putchar_unlocked('\n'). RESULT segments_printed]
            [COMMAND Return 0 from main. RESULT return_value]
        [END_SEQUENTIAL_BLOCK]
    [END_MAIN_FLOW]

[END_WORKER]
