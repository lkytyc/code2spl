[DEFINE_WORKER: "Reads a grid for each test case, finds the maximum size of a connected subset of cells for which some pivot has at most one distinct character in each of its four quadrants, and prints that maximum per case." main]
    [INPUTS]
        <REF> args </REF>: String[] "Command-line arguments; not used by the method."
    [END_INPUTS]

    [OUTPUTS]
    [END_OUTPUTS]

    [MAIN_FLOW]
        [SEQUENTIAL_BLOCK]
            [COMMAND Initialize br as a BufferedReader over System.in and pw as a PrintWriter over System.out. RESULT br, pw]
            [COMMAND Read qq as the number of test cases using readInt(). RESULT qq]
            [COMMAND For each test case number casenum from 1 to qq inclusive, process one grid and print its result. RESULT casenum]
            [COMMAND Print the prefix "Case #" + casenum + ": " to pw. RESULT pw]
            [COMMAND Read r and c as the grid dimensions using readInt(). RESULT r, c]
            [COMMAND Initialize ret to 1 as the best valid subset size found so far. RESULT ret]
            [COMMAND Allocate g as a r by c character grid. RESULT g]
            [COMMAND For each row i from 0 to r-1, read the row token s, and for each column j from 0 to c-1 assign g[i][j] = s.charAt(j). RESULT g]
            [COMMAND For each mask from 1 to (1<<(r*c)) - 1 inclusive, enumerate a candidate subset of grid cells in row-major bit order. RESULT mask]
            [COMMAND If Integer.bitCount(mask) is less than or equal to ret, continue to the next mask. RESULT ret]
            [COMMAND Set t to mask, allocate par as a DSU parent array of length r*c initialized so par[i] = i, and allocate use as a r by c boolean grid. RESULT t, par, use]
            [COMMAND Populate use from the bits of t in row-major order: for each cell (i,j), if the low bit of t is 1 set use[i][j] = true, then shift t right by one for the next cell. RESULT use]
            [COMMAND Set numNeed to Integer.bitCount(mask) - 1. RESULT numNeed]
            [COMMAND For each used cell (i,j), if the cell below is used and merge(i*c+j, (i+1)*c+j) succeeds, decrement numNeed; if the cell to the right is used and merge(i*c+j, i*c+j+1) succeeds, decrement numNeed. RESULT numNeed]
            [COMMAND If numNeed is not 0, continue to the next mask because the selected cells are not connected. RESULT numNeed]
            [COMMAND For pivot rows i from 0 to r-1 and pivot columns j from 0 to c-1 while valid is false, test whether every quadrant around (i,j) contains at most one distinct character among selected cells. RESULT valid]
            [COMMAND Within a pivot test, initialize four empty HashSet<Character> objects for quadrants and set good to true. RESULT all, good]
            [COMMAND For each used cell (x,y) while good is true, compute idx = (x > i ? 2 : 0) | (y < j ? 1 : 0), add g[x][y] to all[idx], and set good to false as soon as that quadrant set has size 2 or more. RESULT good]
            [COMMAND Set valid to good after the quadrant scan for the current pivot. RESULT valid]
            [COMMAND If valid is false, continue to the next mask because the subset fails the quadrant-color property. RESULT valid]
            [COMMAND Update ret to Integer.bitCount(mask) because the current subset is larger, connected, and valid. RESULT ret]
            [COMMAND After all masks are processed, print ret to pw for the current test case. RESULT pw]
            [COMMAND After all test cases are processed, close pw. RESULT pw]
        [END_SEQUENTIAL_BLOCK]
    [END_MAIN_FLOW]

[END_WORKER]
