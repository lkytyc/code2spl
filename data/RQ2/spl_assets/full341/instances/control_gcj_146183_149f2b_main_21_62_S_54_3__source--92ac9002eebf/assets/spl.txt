[DEFINE_WORKER: "Reads test cases of integer pairs and prints the count of distinct index orderings produced by sorting injective transformed values A[i][0]*a*c + A[i][1]*b*d for a,b in the coordinate set plus 1 and c,d in {1,2}." main]
    [INPUTS]
        <REF> args </REF>: String[] "Command-line arguments passed to the main method; not referenced in the method body."
    [END_INPUTS]

    [OUTPUTS]
    [END_OUTPUTS]

    [MAIN_FLOW]
        [SEQUENTIAL_BLOCK]
            [COMMAND Set sc to a new Scanner(System.in) and read the next integer as T, the number of test cases. RESULT T]
            [COMMAND Loop test from 1 to T inclusive; for each test, perform the per-test-case processing. RESULT test_loop]
            [COMMAND Within the test-case loop, read integer n from sc and allocate a long[][] array A with n rows and 2 columns, initially zero-filled. RESULT n_A]
            [COMMAND Within the test-case loop, create an empty HashSet S of List<Integer> orderings and an empty HashSet S3 of Long values; add the constant 1L to S3. RESULT S_S3]
            [COMMAND Within the test-case loop, for i from 0 to n-1 inclusive, read A[i][0] and A[i][1] from sc as long values and add both values to S3. RESULT filled_A_S3]
            [COMMAND Within the test-case loop, iterate a over S3, b over S3, c from 1 to 2 inclusive, and d from 1 to 2 inclusive to select the current linear transformation. RESULT abcd_combination_context]
            [COMMAND For the current (a,b,c,d), create an empty ArrayList B of Temp objects, an empty ArrayList C of Integer indices, and an empty HashSet S2 of Long transformed values. RESULT fresh_B_C_S2]
            [COMMAND Within the current (a,b,c,d), for i from 0 to n-1 inclusive, compute value = A[i][0] * a * c + A[i][1] * b * d using long arithmetic; add new Temp(i, value) to B and add value to S2. RESULT B_S2_populated]
            [COMMAND Compare S2.size() with n to determine whether the current transformation is injective. RESULT injectivity_decision]
            [COMMAND If the transformation is injective (S2.size() == n), sort B by Temp's natural ordering on the transformed value, then for each Temp in the sorted B append its idx field to C. RESULT C_sorted]
            [COMMAND Add the completed list C to the set S of distinct index orderings. RESULT S_updated]
            [COMMAND After all a,b,c,d combinations for the current test case, print the string 'Case #' + test + ': ' + S.size() to standard output. RESULT printed_result]
            [COMMAND After the test-case loop has finished, close sc. RESULT sc_closed]
        [END_SEQUENTIAL_BLOCK]
    [END_MAIN_FLOW]

    [ALTERNATIVE_FLOW: Within the current (a,b,c,d) combination, S2.size() != n, so at least two original indices have the same transformed value and the transformation is not injective.]
        [SEQUENTIAL_BLOCK]
            [COMMAND Continue to the next iteration of the d loop, skipping the sorting of B and skipping the addition of C to S for this non-injective transformation. RESULT non_injective_skipped]
        [END_SEQUENTIAL_BLOCK]
    [END_ALTERNATIVE_FLOW]

[END_WORKER]
