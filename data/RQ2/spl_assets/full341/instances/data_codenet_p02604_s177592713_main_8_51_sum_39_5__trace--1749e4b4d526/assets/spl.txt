[DEFINE_WORKER: "Reads N weighted points, precomputes for every subset the minimum X and Y distance from each point to the subset or the axes, then enumerates all ternary assignments to print the minimum weighted cost for each count t from 0 to N." main]
    [INPUTS]
    [END_INPUTS]

    [OUTPUTS]
    [END_OUTPUTS]

    [MAIN_FLOW]
        [SEQUENTIAL_BLOCK]
            [COMMAND Declare integer N, integer arrays X, Y, P, a of size 20, long array Z of size [65536][16][2], and long array ans[20] with ans[0] initialized to 2^60 and ans[1..19] initialized to 0. Read N from standard input. RESULT N]
            [COMMAND For i from 0 to N-1, read three integers from standard input into X[i], Y[i], and P[i], then set ans[i+1] to 2^60. RESULT X, Y, P, ans]
            [COMMAND For each mask i from 0 to (1<<N)-1, and for each j from 0 to N-1, initialize Z[i][j][0] to abs(X[j]) and Z[i][j][1] to abs(Y[j]). RESULT Z]
            [COMMAND Within the same outer mask loop over i and inner point loop over j, for each k from 0 to N-1, if bit k of i is set, update Z[i][j][0] to min(Z[i][j][0], (long)abs(X[j]-X[k])) and Z[i][j][1] to min(Z[i][j][1], (long)abs(Y[j]-Y[k])). RESULT Z]
            [COMMAND While a[N] is zero, enumerate the ternary states of a[0..N-1]: build h with bits set for indices i where a[i]==1 and v with bits set for indices i where a[i]==2; compute t=popcount(h|v); compute sum from 0 to N-1 of (long)P[i] * min(Z[h][i][0], Z[v][i][1]); set ans[t] to min(ans[t], sum); then advance the ternary counter by starting at i=0, while a[i]==2 set a[i++] to 0, and increment a[i]. RESULT ans]
            [COMMAND For i from 0 to N inclusive, print ans[i] on its own line, then return 0. RESULT stdout]
        [END_SEQUENTIAL_BLOCK]
    [END_MAIN_FLOW]

[END_WORKER]
