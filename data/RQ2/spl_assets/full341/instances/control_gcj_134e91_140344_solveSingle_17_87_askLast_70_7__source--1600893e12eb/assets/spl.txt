[DEFINE_WORKER: "Interactively reconstructs a hidden five-character permutation by querying specific positions and eliminating characters whose occurrence counts deviate from expected frequencies." solveSingle]
    [INPUTS]
        <REF> in </REF>: Scanner "Scanner used to read the first character of each answer token to the printed position queries."
    [END_INPUTS]

    [OUTPUTS]
        <REF> result </REF>: String "The reconstructed five-character string assembled in the order determined by the elimination queries."
    [END_OUTPUTS]

    [MAIN_FLOW]
        [SEQUENTIAL_BLOCK]
            [COMMAND Initialize sol as an empty StringBuilder. RESULT sol]
            [COMMAND Initialize chars as an ArrayList containing A, B, C, D, E in that order. RESULT chars]
            [COMMAND Initialize occ5 as an empty HashMap keyed by Character with ArrayList<Integer> values. RESULT occ5]
            [COMMAND For each character c in chars, put c into occ5 mapped to a new empty ArrayList<Integer>. RESULT occ5]
            [COMMAND For i from 0 to 118 inclusive, compute queryPosition = i * 5 + 1, print queryPosition on its own line, read character n from in.next().charAt(0), get curr = occ5.get(n), and add queryPosition to curr. RESULT occ5]
            [COMMAND For each Map.Entry e5 in occ5.entrySet(), if e5.getValue().size() is not equal to 24, append e5.getKey() to sol and remove e5.getKey() from chars; entries whose value size equals 24 are skipped. RESULT sol]
            [COMMAND Within the first non-24 branch, create occ4 as an empty HashMap and put each remaining character c of chars into occ4 with a new empty ArrayList<Integer>. RESULT occ4]
            [COMMAND Within that branch, for i from 0 to 22 inclusive, compute queryPosition = i * 5 + 2, print queryPosition on its own line, read character n from in.next().charAt(0), get curr = occ4.get(n), and add queryPosition to curr. RESULT occ4]
            [COMMAND Within that branch, for each Map.Entry e4 in occ4.entrySet(), if e4.getValue().size() is not equal to 6, append e4.getKey() to sol and remove e4.getKey() from chars; entries whose value size equals 6 are skipped. RESULT sol]
            [COMMAND Within the second non-6 branch, create occ3 as an empty HashMap and put each remaining character c of chars into occ3 with a new empty ArrayList<Integer>. RESULT occ3]
            [COMMAND Within that branch, for i from 0 to 4 inclusive, compute queryPosition = i * 5 + 3, print queryPosition on its own line, read character n from in.next().charAt(0), get curr = occ3.get(n), and add queryPosition to curr. RESULT occ3]
            [COMMAND Within that branch, for each Map.Entry e in occ3.entrySet(), if e.getValue().size() is not equal to 2, remove e.getKey() from chars, append e.getKey() to sol, compute askLast = e.getValue().get(0) + 1, print askLast on its own line, and read character n from in.next().charAt(0). RESULT sol]
            [COMMAND Within the third non-2 branch, scan the remaining chars in order; for the first character c such that c != n, append c to sol and break out of the scan; after the scan, append n to sol. RESULT sol]
            [COMMAND Return sol.toString() as the final reconstructed string. RESULT result]
        [END_SEQUENTIAL_BLOCK]
    [END_MAIN_FLOW]

    [EXCEPTION_FLOW: The Scanner input is exhausted before all required query answers are provided.]
        [LOG "A query position was printed but Scanner.next() could not return the next answer."]
        [THROW NoSuchElementException "Raised by Scanner.next() when no further input tokens are available."]
    [END_EXCEPTION_FLOW]

    [EXCEPTION_FLOW: A returned character is not one of the current expected keys, so occ5.get(n), occ4.get(n), or occ3.get(n) returns null.]

        [THROW NullPointerException "Raised when dereferencing a null curr list obtained from an occurrence map."]
    [END_EXCEPTION_FLOW]

[END_WORKER]
