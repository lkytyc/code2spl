[DEFINE_WORKER: "Performs a layer-by-layer BFS-like traversal on a 10x10 grid, marking cells around successive special points and expanding the frontier through marked neighbors, returning true if all special points are consumed while the frontier is still non-empty, otherwise returning false." bfs]
    [INPUTS]
        <REF> sx </REF>: int "Starting x-coordinate placed in the initial BFS queue."
        <REF> sy </REF>: int "Starting y-coordinate placed in the initial BFS queue."
        <REF> spx </REF>: int[] "Array of special-point x-coordinates; one special point is consumed per BFS generation."
        <REF> spy </REF>: int[] "Array of special-point y-coordinates aligned with spx and accessed at the current spCnt index."
    [END_INPUTS]

    [OUTPUTS]
        <REF> result </REF>: boolean "Returns true if spCnt reaches spx.length while the BFS queue is still non-empty; returns false if the queue empties before all special points are consumed."
    [END_OUTPUTS]

    [MAIN_FLOW]
        [SEQUENTIAL_BLOCK]
            [COMMAND Initialize local state: set size = 10 and spCnt = 0; define dx, dy, dx2, and dy2 exactly as in the method; create a 10x10 boolean array park with all elements false. RESULT initial_state]
            [COMMAND Create empty LinkedLists queueX and queueY, then add sx to queueX and sy to queueY. RESULT initial_queue]
            [COMMAND While queueX is not empty, repeat the outer BFS generation steps described below. RESULT outer_loop]
            [COMMAND At the start of each outer iteration, check whether spCnt == spx.length; if true, take the alternative early-return flow, otherwise continue with the current generation. RESULT early_return_check]
            [COMMAND Within the outer while loop, for i from 0 to dx2.length - 1 inclusive, compute y = spy[spCnt] + dy2[i] and x = spx[spCnt] + dx2[i]; if 0 <= y < size and 0 <= x < size, set park[y][x] = true. The loop uses dx2.length, so the extra trailing element of dy2 is not accessed. RESULT park_marked]
            [COMMAND Within the outer while loop, create new empty LinkedLists nx and ny to hold the next BFS frontier. RESULT next_queues_created]
            [COMMAND Within the outer while loop, drain the current queue: while queueX is not empty, poll x from queueX and y from queueY. For each polled coordinate, loop i from 0 to dx.length - 1 inclusive, compute nextX = x + dx[i] and nextY = y + dy[i]; if 0 <= nextX < 10 and 0 <= nextY < 10 and park[nextY][nextX] is true, add nextX to nx and nextY to ny. RESULT next_frontier]
            [COMMAND Within the outer while loop, after draining the old queue, increment spCnt by 1, reset park to a new boolean[size][size] array all false, assign queueX = nx and queueY = ny, and continue with the next outer iteration if queueX is non-empty. RESULT generation_complete]
            [COMMAND If the outer while loop exits because queueX is empty and the early return was not triggered, return false. RESULT final_false]
        [END_SEQUENTIAL_BLOCK]
    [END_MAIN_FLOW]

    [ALTERNATIVE_FLOW: At the start of an outer while iteration, queueX is non-empty and spCnt equals spx.length.]
        [SEQUENTIAL_BLOCK]
            [COMMAND Return true from bfs immediately, without marking more cells or expanding the current frontier. RESULT return_true]
        [END_SEQUENTIAL_BLOCK]
    [END_ALTERNATIVE_FLOW]

[END_WORKER]
