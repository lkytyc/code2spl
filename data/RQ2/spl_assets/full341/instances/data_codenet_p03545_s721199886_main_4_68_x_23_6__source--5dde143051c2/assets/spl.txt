[DEFINE_WORKER: "Reads an integer, extracts its last four decimal digits, searches the eight plus/minus operator combinations between them for the first expression equal to 7, prints that expression followed by =7, and returns 0." main]
    [INPUTS]
        <REF> n </REF>: int "Integer read from standard input; only its last four decimal digits are used."
    [END_INPUTS]

    [OUTPUTS]
        <REF> printed_expression </REF>: string "The first found expression of the form a op1 b op2 c op3 d = 7 printed to standard output."
        <REF> return_code </REF>: int "The value returned by main; always 0."
    [END_OUTPUTS]

    [MAIN_FLOW]
        [SEQUENTIAL_BLOCK]
            [COMMAND Declare integer variables i, n, a, b, c, d, x, op1, op2, op3 with cnt initialized to 0, and initialize char array op with op[0]='+' and op[1]='-'. RESULT state]
            [COMMAND Read an integer from standard input into n using scanf("%d", &n). RESULT n]
            [COMMAND Extract the last four decimal digits of n: a=(n/1000)%10, b=(n/100)%10, c=(n/10)%10, d=n%10. RESULT digits_a_b_c_d]
            [COMMAND Enter an infinite outer loop. At the start of each outer iteration, reset x=0, op1=0, op2=0, op3=0. RESULT outer_loop]
            [COMMAND Run the inner loop for i=0 to i<3. The body evaluates the operator combination selected by cnt and recomputes x from scratch each pass; because i is unused and no state carries between passes, the final state is equivalent to one body execution. RESULT inner_loop]
            [COMMAND Within the outer loop and the effective inner-loop body, if cnt is less than 3 or cnt equals 4, set x=sum(a,b) and leave op1=0; otherwise set x=sub(a,b) and set op1=1. RESULT x_after_first_operator]
            [COMMAND Within the same context, if cnt is less than 2 or cnt equals 3 or cnt equals 6, set x=sum(x,c) and leave op2=0; otherwise set x=sub(x,c) and set op2=1. RESULT x_after_second_operator]
            [COMMAND Within the same context, if cnt equals 0, 2, 3, or 5, set x=sum(x,d) and leave op3=0; otherwise set x=sub(x,d) and set op3=1. RESULT x_after_third_operator]
            [COMMAND After the inner loop completes, if x equals 7, break out of the infinite outer loop immediately, before cnt is incremented. RESULT break_success]
            [COMMAND If x does not equal 7, increment cnt and continue the outer loop. For cnt values 8 and above, all special-case checks fail, so the expression remains the same as cnt=7, ((a-b)-c)-d; if that value is not 7, the outer loop repeats forever. RESULT next_attempt_or_infinite_loop]
            [COMMAND After the loop exits, print the successful expression using printf("%d%c%d%c%d%c%d=7", a, op[op1], b, op[op2], c, op[op3], d). RESULT printed_expression]
            [COMMAND Return 0 from main. RESULT return_code]
        [END_SEQUENTIAL_BLOCK]
    [END_MAIN_FLOW]

[END_WORKER]
