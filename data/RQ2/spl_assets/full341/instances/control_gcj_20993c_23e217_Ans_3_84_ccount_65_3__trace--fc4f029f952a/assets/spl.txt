[DEFINE_WORKER: "Reads an n by n matrix from standard input, computes its trace and duplicate counts per row and per column using the specified counting rule, derives rmax and cmax by the same adjacent-pair comparison, prints the formatted case line, and returns 0." Ans]
    [INPUTS]
        <REF> x </REF>: long long int "Zero-based case number used only as x+1 in the output line."
    [END_INPUTS]

    [OUTPUTS]
        <REF> result </REF>: int "Always returns 0."
    [END_OUTPUTS]

    [MAIN_FLOW]
        [SEQUENTIAL_BLOCK]
            [COMMAND Declare long long int n, i, j, sum initialized to 0, r, c, and k, then read one long long value from standard input into n using scanf; the return value of scanf is ignored. RESULT n]
            [COMMAND Declare Mat as an n by n variable-length array and count as an n-element array, then read all n*n matrix elements from standard input using outer loop i from 0 to n-1 and inner loop j from 0 to n-1, storing each value into Mat[i][j]. RESULT Mat]
            [COMMAND Compute the trace: for i from 0 to n-1 and j from 0 to n-1, if i equals j, add Mat[i][j] to sum. RESULT sum]
            [COMMAND For each row i from 0 to n-1, set count[i] to 0; then for each j from 0 to n-1 and each k from j+1 to n-1, if Mat[i][j] equals Mat[i][k], set count[i] to count[i]+2 when count[i] is 0, otherwise increment count[i] by 1, and break only the inner k loop after the first such match for that j. RESULT count]
            [COMMAND Initialize rmax to count[0]; then for i from 0 to n-1 and j from 0 to n-1, if count[j] is greater than or equal to count[j+1], assign rmax = count[j]. This repeats the scan n times and may read count[n] when j=n-1; preserve the exact out-of-bounds boundary behavior. RESULT rmax]
            [COMMAND For each column j from 0 to n-1, set ccount[j] to 0; then for each i from 0 to n-1 and each k from i+1 to n-1, if Mat[i][j] equals Mat[k][j], set ccount[j] to ccount[j]+2 when ccount[j] is 0, otherwise increment ccount[j] by 1, and break only the inner k loop after the first such match for that i. RESULT ccount]
            [COMMAND Initialize cmax to ccount[0]; then for i from 0 to n-1 and j from 0 to n-1, if ccount[j] is greater than or equal to ccount[j+1], assign cmax = ccount[j]. This repeats the scan n times and may read ccount[n] when j=n-1; preserve the exact out-of-bounds boundary behavior. RESULT cmax]
            [COMMAND Print the line 'Case #%lld: %lld %lld %lld\n' with arguments x+1, sum, rmax, and cmax, then return 0. RESULT return_value]
        [END_SEQUENTIAL_BLOCK]
    [END_MAIN_FLOW]

[END_WORKER]
