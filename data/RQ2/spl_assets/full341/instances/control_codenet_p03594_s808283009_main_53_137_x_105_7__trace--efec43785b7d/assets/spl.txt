[DEFINE_WORKER: "Reads grid dimensions h and w and a distance parameter d, colors each cell of the h by w grid with the smallest of four color indices 0..3 not already used in any of the four diagonal positions at distance d that are inside the grid, stores -1 when no such color exists, and prints the resulting grid row by row with -1 printed as 'R'." main]
    [INPUTS]
        <REF> args </REF>: String[] "Command-line arguments passed to main; not used by the method body."
    [END_INPUTS]

    [OUTPUTS]
    [END_OUTPUTS]

    [MAIN_FLOW]
        [SEQUENTIAL_BLOCK]
            [COMMAND Read three integers h, w, and d from the input stream `in`. RESULT h_w_d]
            [COMMAND Allocate a two-dimensional int array ans with h rows and w columns, initially zero-filled. RESULT ans]
            [COMMAND For each row i from 0 to h-1, call Arrays.fill(ans[i], -1) so every cell contains the uncolored sentinel -1. RESULT ans]
            [COMMAND For each cell (i, j) in row-major order, where i ranges from 0 to h-1 and j ranges from 0 to w-1, create a fresh boolean array not of length 4 filled with false. RESULT not]
            [COMMAND Within the row-major (i, j) coloring step, start with x = j + d and y = i; while y <= i + d, decrement x and increment y after each iteration; if x >= w or y >= h, skip the cell, otherwise if ans[y][x] != -1, set not[ans[y][x]] = true. RESULT not]
            [COMMAND Within the same row-major (i, j) coloring step, start with x = j + d and y = i; while y >= i - d, decrement x and decrement y after each iteration; if x >= w or y < 0, skip the cell, otherwise if ans[y][x] != -1, set not[ans[y][x]] = true. RESULT not]
            [COMMAND Within the same row-major (i, j) coloring step, start with x = j - d and y = i; while y <= i + d, increment x and increment y after each iteration; if x < 0 or y >= h, skip the cell, otherwise if ans[y][x] != -1, set not[ans[y][x]] = true. RESULT not]
            [COMMAND Within the same row-major (i, j) coloring step, start with x = j - d and y = i; while y >= i - d, increment x and decrement y after each iteration; if x < 0 or y < 0, skip the cell, otherwise if ans[y][x] != -1, set not[ans[y][x]] = true. RESULT not]
            [COMMAND Still within the row-major (i, j) coloring step, choose the smallest z from 0 to 3 such that not[z] is false, assign ans[i][j] = z, and break; if all four entries are true, leave ans[i][j] unchanged. RESULT ans]
            [COMMAND After all coloring loops complete, define a char array c = {'R', 'Y', 'G', 'B'}. RESULT c]
            [COMMAND For each row i from 0 to h-1 and each column j from 0 to w-1, output c[ans[i][j] != -1 ? ans[i][j] : 0] using sop. RESULT printed_characters]
            [COMMAND After finishing each row i, output a newline using sop. RESULT row_separators]
        [END_SEQUENTIAL_BLOCK]
    [END_MAIN_FLOW]

    [EXCEPTION_FLOW: Calling in.nextInt() to read h, w, or d throws an IOException.]
        [LOG "IOException is propagated from the failing input read."]
        [THROW IOException "The method declares throws IOException, allowing input-read failures to propagate."]
    [END_EXCEPTION_FLOW]

[END_WORKER]
