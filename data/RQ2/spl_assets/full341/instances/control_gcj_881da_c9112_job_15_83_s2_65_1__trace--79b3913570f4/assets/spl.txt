[DEFINE_WORKER: "Compresses an input E/S string into consecutive run lengths, adjusts parity according to the state of the first run, and reconstructs and prints the corresponding E/S string with block order and boundaries determined by that parity." job]

    [END_INPUTS]

    [END_OUTPUTS]

            [COMMAND Set ggg to the result of 'E' XOR 'S' (ASCII 22), set goodp to -1, set movesp to 0, and set cur to 'E'. RESULT initial_state]
            [COMMAND Read an integer and a string from standard input into n and in_str using scanf("%d%s", &n, in_str). RESULT raw_input]
            [COMMAND Set n to n * 2 - 2, then set moves[0] to 0. RESULT prepared_values]
            [COMMAND For each integer i from 0 through n - 1 inclusive, compare in_str[i] with cur. If they are equal, increment moves[movesp] by 1, and if ((moves[0] is nonzero and i is odd) or (moves[0] is zero and i is even)), set goodp to movesp. RESULT compressed_moves]
            [COMMAND Set parity to movesp. RESULT parity]
            [COMMAND If moves[0] is not equal to 0, increment parity by 1. RESULT parity_adjusted]
            [COMMAND If parity is even, set En to 0, then for every even i starting at 0 while i <= movesp, add moves[i] to En. RESULT En]
            [COMMAND If parity is even and moves[0] is equal to 0, print 'E' exactly En times, then print 'S' exactly n - En times. RESULT even_parity_E_then_S]
            [COMMAND If parity is even and moves[0] is not equal to 0, print 'S' exactly n - En times, then print 'E' exactly En times. RESULT even_parity_S_then_E]

RESULT odd_sums]

            [COMMAND If parity is odd and moves[0] is not equal to 0, print 'S' for every integer i starting at -1 while i < s1, then print 'E' exactly e1 + e2 times, then print 'S' for every integer i starting at 1 while i < s2. RESULT odd_parity_S_then_E]
