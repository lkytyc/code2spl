[DEFINE_WORKER: "Simulates the Bathroom Stalls process by repeatedly selecting the leftmost stall with the lexicographically largest (min-side, max-side) distance pair, updating distance arrays after each placement, and printing the final selected stall's max and min distances for the test case." fill_bathroom]
    [INPUTS]
        <REF> n_case </REF>: int "Zero-based test case index used to print Case #n_case+1."
        <REF> stalls </REF>: int "Number of stalls in the bathroom."
        <REF> users </REF>: int "Number of people to place into stalls."
    [END_INPUTS]

    [OUTPUTS]
        <REF> stdout </REF>: text "Prints 'Case #N: max min' followed by a newline, where max and min are the MAX(ls,rs) and MIN(ls,rs) distances for the last selected stall."
    [END_OUTPUTS]

    [MAIN_FLOW]
        [SEQUENTIAL_BLOCK]
            [COMMAND Allocate stalls_occupancy as an int array of length stalls, zero it with memset, allocate ls and rs as int arrays of length stalls, and initialize max_crit1 and max_crit2 to 0. RESULT stalls_occupancy, ls, rs, max_crit1, max_crit2]
            [COMMAND For i from 0 to stalls-1 inclusive, set ls[i] = i and rs[i] = stalls - i - 1, representing distances from each stall to the left and right ends respectively. RESULT ls, rs]
            [COMMAND For each user iteration from 0 to users-1 inclusive, initialize pos to 0, max_crit1 to 0, and max_crit2 to 0. RESULT pos, max_crit1, max_crit2]
            [COMMAND Within each user iteration, scan j from 0 to stalls-1 inclusive; if stalls_occupancy[j] == 0, compute crit1 = MIN(ls[j], rs[j]) and crit2 = MAX(ls[j], rs[j]); update pos, max_crit1, and max_crit2 when either crit1 >= max_crit1 && crit2 > max_crit2, or else when crit1 > max_crit1; this selects the leftmost empty stall with the lexicographically largest (crit1, crit2) pair. RESULT pos, max_crit1, max_crit2]
            [COMMAND After the scan, set stalls_occupancy[pos] = 1 to mark the selected stall as occupied. RESULT stalls_occupancy]
            [COMMAND Within the same user iteration, set reset_counter = 0, then for i from pos+1 to stalls-1 inclusive assign ls[i] = reset_counter, increment reset_counter, and break after processing a stall where stalls_occupancy[i] == 1. RESULT ls]
            [COMMAND Within the same user iteration, set reset_counter = 0 again, then for i from pos-1 down to 0 inclusive assign rs[i] = reset_counter, increment reset_counter, and break after processing a stall where stalls_occupancy[i] == 1. RESULT rs]
            [COMMAND After all users have been placed, free stalls_occupancy, ls, and rs. RESULT cleanup]
            [COMMAND Print 'Case #%d: %d %d' followed by a newline using n_case + 1, max_crit2, and max_crit1, where max_crit2 and max_crit1 are the MAX and MIN distances for the last selected stall. RESULT stdout]
        [END_SEQUENTIAL_BLOCK]
    [END_MAIN_FLOW]

[END_WORKER]

[DEFINE_WORKER: "Reads a number of test cases T, then for each test case i from 0 to T-1 reads stall and user counts and invokes fill_bathroom(i, stalls, users), finally returning 0." main]
    [INPUTS]
    [END_INPUTS]

    [OUTPUTS]
        <REF> return_value </REF>: int "Always returns 0 to indicate successful completion."
    [END_OUTPUTS]

    [MAIN_FLOW]
        [SEQUENTIAL_BLOCK]
            [COMMAND Read an integer T from standard input using scanf("%d", &T); if the read fails, T remains 0 because T was initialized to 0. RESULT T]
            [COMMAND Initialize the loop counter i to 0. RESULT i]
            [COMMAND Start a for loop with condition i < T, so iterations execute for i = 0 through T-1; if T <= 0, skip the loop body. RESULT loop_condition]
            [COMMAND Within the for loop (for i = 0; i < T; i++), initialize stalls to 0 and users to 0, then read two integers into stalls and users using scanf("%d %d", &stalls, &users) without checking the return value; if the read fails, stalls and users keep their initialized value 0. RESULT stalls_and_users]
            [COMMAND Within the for loop (for i = 0; i < T; i++), after reading stalls and users, call fill_bathroom(i, stalls, users) with the current loop counter and the two input values. RESULT fill_bathroom_result]
            [COMMAND After the loop body, increment i by 1 (i++) and repeat the loop condition check. RESULT i]
            [COMMAND After the for loop finishes, return 0 from main. RESULT return_value]
        [END_SEQUENTIAL_BLOCK]
    [END_MAIN_FLOW]

[END_WORKER]
