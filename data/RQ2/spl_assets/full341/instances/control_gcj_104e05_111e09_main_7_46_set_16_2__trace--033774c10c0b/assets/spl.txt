[DEFINE_WORKER: "Reads a count of test cases and, for each test case, reads words into a sorted TreeSet, then uses two iterators to find the longest substring of a later sorted word contained in an earlier word but stores it only in dead local variables and produces no output." main]
    [INPUTS]
        <REF> args </REF>: String[] "Command-line arguments; not used by this method."
        <REF> System.in </REF>: InputStream "Standard input stream supplying the test case count, per-test word count, and word lines."
    [END_INPUTS]

    [OUTPUTS]
    [END_OUTPUTS]

    [MAIN_FLOW]
        [SEQUENTIAL_BLOCK]
            [COMMAND Wrap System.in in an InputStreamReader and then in a BufferedReader, assigned to br. RESULT br]
            [COMMAND Read the first line from br and parse it as an int, assigned to tc. RESULT tc]
            [COMMAND For each test case i from 0 to tc-1 inclusive, execute the test-case body described by the following test-case steps. RESULT i]
            [COMMAND Within the test-case body for i, read a line from br and parse it as an int, assigned to noOfWords. RESULT noOfWords]
            [COMMAND Within the test-case body for i, create an empty TreeSet<String>, assigned to set, which will store unique words in sorted order. RESULT set]
            [COMMAND Within the test-case body for i, for each j from 0 to noOfWords-1 inclusive, read a line from br as word and add word to set. RESULT set]
            [COMMAND Within the test-case body for i, create an iterator wrd1 over set. RESULT wrd1]
            [COMMAND Within the test-case body for i, create an iterator wrd2 over set. Note that wrd2 is never reset in the outer loop. RESULT wrd2]
            [COMMAND Within the test-case body for i, initialize c1 to 0. RESULT c1]
            [COMMAND While wrd1.hasNext(), execute the outer comparison loop; at the start of each iteration increment c1. Because wrd2 is consumed during the first outer iteration and never recreated, this loop has a meaningful inner pass only for c1 equal to 1. RESULT c1]
            [COMMAND Inside the outer while loop, initialize c2 to 0. RESULT c2]
            [COMMAND Inside the outer while loop, assign wrd1.next() to wordOne. RESULT wordOne]
            [COMMAND Inside the outer while loop, initialize result to 0. This variable is never read afterward. RESULT result]
            [COMMAND While wrd2.hasNext(), execute the inner comparison loop; at the start of each iteration increment c2. RESULT c2]
            [COMMAND Inside the inner while loop, evaluate c1 != c2. If false, skip the rest of the inner-loop body for this iteration and do not call wrd2.next(). RESULT c1_c2_compare]
            [COMMAND In the true branch of c1 != c2, assign wrd2.next() to wordTwo. RESULT wordTwo]
            [COMMAND In the true branch of c1 != c2, initialize max to 0 and key to an empty string. These are local to this branch and are never used after the branch ends. RESULT max_key]
            [COMMAND In the true branch of c1 != c2, for l from 0 to wordTwo.length()-2 inclusive, execute the outer substring loop over wordTwo. RESULT l]
            [COMMAND Inside the l loop, for k from l+2 to wordTwo.length() inclusive, form the substring wordTwo.substring(l,k). RESULT k]
            [COMMAND Inside the k loop, evaluate the short-circuit condition: wordOne.contains(wordTwo.substring(l,k)) first; only if true compare k-l > max. If the overall condition is true, update max to k-l and key to that substring; otherwise break out of the k loop immediately. RESULT max_key_updated]
        [END_SEQUENTIAL_BLOCK]
    [END_MAIN_FLOW]

    [EXCEPTION_FLOW: br.readLine() fails during any input read because of an I/O error]
        [LOG "IOException propagates from readLine; the method exits through its declared throws IOException."]
        [THROW IOException "Checked exception thrown when an input or output operation fails."]
    [END_EXCEPTION_FLOW]

    [EXCEPTION_FLOW: A line read from br is not a valid decimal integer when either tc or noOfWords is parsed]
        [LOG "NumberFormatException propagates from Integer.parseInt; no catch block handles it."]
        [THROW NumberFormatException "Unchecked exception thrown when input cannot be parsed as an int."]
    [END_EXCEPTION_FLOW]

[END_WORKER]
