[DEFINE_WORKER: "Reads directed graphs until input exhaustion, and for each (source, destination, TTL) query performs a TTL-limited priority-queue search with per-node close states to find the minimum path length, printing NA when unreachable." AOJ0144]
    [INPUTS]
    [END_INPUTS]

    [OUTPUTS]
    [END_OUTPUTS]

    [MAIN_FLOW]
        [SEQUENTIAL_BLOCK]
            [COMMAND While sc.hasNext() is true, begin a test case: read integer N and allocate a boolean adjacency matrix R with dimensions (N+1) by (N+1), initially all false. RESULT N]
            [COMMAND For each row index i from 1 to N inclusive, read row node r and edge count k, then for each edge index j from 0 to k-1 read the next integer as the destination and set R[r][destination] to true. RESULT R]
            [COMMAND Read integer P, the number of queries for this test case. RESULT P]
            [COMMAND Within the current test case, for each query index i from 0 to P-1, read source s, destination d, and initial TTL v; initialize ans to -1. RESULT query]
            [COMMAND Create an empty PriorityQueue open of C0144 states, add a newly constructed initial state new C0144(s, v, 1), and create a C0144 reference array close of length N+1 with all entries initialized to null. RESULT open]
            [COMMAND While open is not empty, poll the next C0144 state as now using C0144's natural ordering; stale states already in open are not filtered out. RESULT now]
            [COMMAND Decrement now.ttl by 1 on the polled state; if now.ttl becomes 0, continue to the next iteration of the while loop and do not expand this state. This decrement does not alter the corresponding close entry because open and close hold separately constructed C0144 objects. RESULT now]
            [COMMAND For each j from 1 to N inclusive, if R[now.now][j] is true, evaluate the transition from now.now to j; otherwise continue with the next j. RESULT j]
            [COMMAND Within the transition evaluation, if close[j] is null and j is the destination d, set ans to now.c+1 if ans is -1, otherwise to the smaller of ans and now.c+1, then continue to the next j without adding d to open or storing close[d]. The continue only skips to the next j; it does not exit the while search loop. RESULT ans]
            [COMMAND Within the transition evaluation, if close[j] is null and j is not d, add a newly constructed state new C0144(j, now.ttl, now.c+1) to open, then store another newly constructed state new C0144(j, now.ttl, now.c+1) in close[j]. RESULT open]
            [COMMAND Within the transition evaluation, if close[j] is not null and the improvement condition (now.c+1 < close[j].c OR now.ttl > close[j].ttl) is true, check whether j is d: if it is, update ans to now.c+1 if ans is -1, otherwise to the smaller of ans and now.c+1, then continue to the next j without replacing close[d]; if it is not, add a newly constructed state new C0144(j, now.ttl, now.c+1) to open and replace close[j] with another newly constructed state new C0144(j, now.ttl, now.c+1). RESULT open]
            [COMMAND After the search loop for the current query finishes, print ans if ans is not negative, otherwise print the literal string NA. RESULT output]
        [END_SEQUENTIAL_BLOCK]
    [END_MAIN_FLOW]

[END_WORKER]
