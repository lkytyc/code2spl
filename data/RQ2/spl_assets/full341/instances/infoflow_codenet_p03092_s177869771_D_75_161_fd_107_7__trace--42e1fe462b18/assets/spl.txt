[DEFINE_WORKER: "Reads a list, maps its values to sorted ranks, repeatedly splits the current list into runs of consecutive ranks and moves misplaced runs into sorted order while accumulating movement costs, then prints the minimum cost found over two identical trials." D]
    [INPUTS]
    [END_INPUTS]

    [OUTPUTS]
    [END_OUTPUTS]

    [MAIN_FLOW]
        [SEQUENTIAL_BLOCK]
            [COMMAND Read n, a, and b from the first LI() call, and read the full list pf from the second LI() call. RESULT input_values]
            [COMMAND Initialize f_ans = float('inf'), l = []; for i in range(n), append pf[i] to l, then sort l. RESULT sorted_l]
            [COMMAND Initialize f as a defaultdict(int); for each value val in pf, set f[val] = l.index(val). RESULT rank_map]
            [COMMAND For each c in range(2), set p = pf.copy() and ans = 0. RESULT outer_state]
            [COMMAND While l != p, begin an iteration by setting d = [] and i = 0. RESULT iteration_start]
            [COMMAND While i < n, set j = i; while j < n-1 and f[p[j+1]] == f[p[j]] + 1, increment j; then append p[i:j+1] to d and set i = j+1. RESULT segments]
            [COMMAND Set m = len(d), build ld as a list containing each segment from d, and sort ld lexicographically. RESULT ld_sorted]
            [COMMAND Initialize fd as a defaultdict(int); for each segment seg in d, set fd[str(seg)] = ld.index(seg). RESULT fd_map]
            [COMMAND Within the while loop, scan i from m-1 down to 0; if d[i] != ld[i], set j = fd[str(d[i])], set x = d[i], and proceed to the move logic. The c == 0 and c != 0 branches are identical. If no such i is found, do not modify d. RESULT misplaced_segment]
            [COMMAND If j > i, compute k as the total length of the segments from d[i+1] through d[j], set the local variable p to len(d[i]) (shadowing the outer p list), add min(b * k, a * p) to ans, remove d[i], insert x at position j, and break out of the reversed scan. RESULT moved_right]
            [COMMAND If j is not greater than i, compute k as the total length of the segments from d[j] through d[i-1], set the local variable p to len(d[i]) (shadowing the outer p list), add min(a * k, b * p) to ans, remove d[i], insert x at position j, and break out of the reversed scan. RESULT moved_left]
            [COMMAND After the reversed scan completes (with or without a move), rebuild p as a list of length n filled with None; flatten d into p by setting p[s+j] = d[i][j] for each segment i and each offset j, advancing s by len(d[i]). RESULT rebuilt_p]
            [COMMAND Keep repeating the while body until l == p; once l == p, set f_ans = min(f_ans, ans). RESULT updated_min]
            [COMMAND After both c iterations finish, print f_ans. RESULT printed_result]
        [END_SEQUENTIAL_BLOCK]
    [END_MAIN_FLOW]

[END_WORKER]
