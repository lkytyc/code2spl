# Structured Description

## Function: MakeCostMinimum(int p, int q, int r)

**Inputs:** Three integer parameters p, q, r.

**Processing:**
1. Computes `minimumcost` as `(q - p) + (r - q)`.
2. If `minimumcost` is negative, multiplies it by -1 (making it positive).
3. If `minimumcost` is zero or positive, no change is made.

**Output:** Prints the resulting `minimumcost` value as an integer followed by a newline.

**Control flow:** One conditional branch (if/else) based on whether the computed value is negative.

## Function: Compare3Figures(int a, int b, int c)

**Inputs:** Three integer parameters a, b, c.

**Processing:** The function attempts to reorder the three values through a series of conditional branches. Each branch swaps values among a, b, and c based on their relative ordering. The branches are evaluated in sequence:

1. If `b < a` AND `a < c`: swap a and b (so a becomes the smaller value, b becomes the middle).
2. Else if `b < a` AND `c < b`: swap a and c (so a becomes the smallest, c becomes the largest).
3. Else if `a < b` AND `c < b` AND `a < c`: swap b and c (so b becomes the middle, c becomes the largest).
4. Else if `a < b` AND `c < a`: rotate values (a becomes c, c becomes b, b becomes the old a).
5. Else if `b < a` AND `b < c` AND `c < a`: rotate values (a becomes b, b becomes c, c becomes the old a).
6. If none of the above conditions match, no changes are made.

**Function call:** After the conditional reordering, calls `MakeCostMinimum(a, b, c)` with the (possibly modified) values.

**Output:** No direct output; output occurs through the called function.

## Function: main(int argc, char *argv[])

**Inputs:** Command-line arguments (not used in the logic). Reads three integer values from standard input.

**Processing:**
1. Initializes three integer variables A, B, C to 0.
2. Uses three separate do-while loops to read values:
   - First loop reads A, repeating until A is between 1 and 100 inclusive.
   - Second loop reads B, repeating until B is between 1 and 100 inclusive.
   - Third loop reads C, repeating until C is between 1 and 100 inclusive.
3. Calls `Compare3Figures(A, B, C)` with the validated input values.

**Output:** No direct output; output occurs through the called functions.

## Data Dependencies

- `main` passes validated A, B, C to `Compare3Figures`.
- `Compare3Figures` may modify its local copies of a, b, c through swaps, then passes them to `MakeCostMinimum`.
- `MakeCostMinimum` computes a cost based on the differences between consecutive values and prints the absolute value of that cost.

## Overall Behavior

The program reads three integers (each between 1 and 100), attempts to sort them in ascending order through a series of conditional swaps, then computes and prints the sum of the differences between consecutive sorted values (which equals the range: largest minus smallest). The printed value is always non-negative.
