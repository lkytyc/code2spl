## Overview
This program reads a graph with n vertices and m edges, processes union operations to form connected components, and then computes a minimum-cost spanning structure based on component counts and vertex weights.

## Inputs
- First line: two integers `n` (number of vertices) and `m` (number of edges)
- Second line: `n` integers representing weights `a[i]` for each vertex
- Following `m` lines: pairs of integers `x` and `y` representing edges between vertices

## Initialization
- Arrays `uni` and `a` are declared with size `n`
- `uni[i]` is initialized to `i` for all vertices (each vertex starts as its own component)
- Vertex weights are read into array `a`

## Union-Find Processing
For each of the `m` edges (x, y):
- If `uni[x] != x` (x is not a root):
  - Save the current root of y as `t`
  - Set `uni[y] = x`
  - Follow the chain from y until reaching a root, then set `uni[y]` to that root
  - Scan all vertices: if a vertex's `uni` value equals the saved `t`, update it to the new root of y
- Otherwise (x is a root):
  - Save the current root of x as `t`
  - Set `uni[x] = y`
  - Follow the chain from x until reaching a root, then set `uni[x]` to that root
  - Scan all vertices: if a vertex's `uni` value equals the saved `t`, update it to the new root of x

## Component Counting
- Count `num` as the number of vertices where `uni[i] == i` (roots/components)

## Decision Branches
1. If `num == 1` (single component): print `0` and exit
2. If `num * 2 - 2 > n`: print `Impossible` and exit
3. If `num * 2 - 2 == n`: print the sum of all vertex weights and exit

## Minimum Cost Calculation
- Initialize arrays `min` and `minn` with `inf` (a large sentinel value)
- For each vertex `i`, if `min[uni[i]] > a[i]`, update `min[uni[i]]` to `a[i]` and `minn[uni[i]]` to `i` (finding minimum weight per component)
- Initialize `ssum` as a long long accumulator
- Set `tnum = num - 2`
- For each component root `i`:
  - If `min[i]` is not the sentinel value, add it to `ssum` and set the corresponding vertex's weight to `inf`
- Sort array `a` in ascending order using `qsort`
- Add the first `tnum` elements of the sorted array to `ssum`

## Output
- Print `ssum` as a long long integer

## Key Data Dependencies
- The union operations modify `uni` array, which determines component membership
- Component membership determines which vertices contribute their minimum weight
- The sorted array `a` provides additional weights after marking component minima as used
- The final sum combines component minima with the smallest remaining weights
