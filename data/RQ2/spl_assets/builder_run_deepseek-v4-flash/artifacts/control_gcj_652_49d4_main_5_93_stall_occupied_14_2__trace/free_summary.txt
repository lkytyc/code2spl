This code solves a bathroom stall placement problem. It simulates placing K people one by one into N stalls, where each new person chooses the stall that maximizes the minimum distance to the nearest occupied stall (with ties broken by maximizing the maximum distance, then by leftmost position). After each placement, it updates the distance metrics for all remaining empty stalls. Finally, for each test case, it outputs the maximum and minimum distances (y and z) for the last person placed.
