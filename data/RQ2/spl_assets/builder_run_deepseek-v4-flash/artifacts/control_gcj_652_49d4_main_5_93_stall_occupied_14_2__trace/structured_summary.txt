## Overview
This program simulates the placement of people into bathroom stalls according to a specific selection rule. It processes multiple test cases, each defining a row of stalls with occupied endpoints, and determines where each of K people will sit based on maximizing comfort distances.

## Input
- First line: an integer T representing the number of test cases
- For each test case: a single line containing two space-separated integers:
  - N: the number of empty stalls between two occupied boundary stalls
  - K: the number of people to place

## Output
For each test case, one line formatted as: `Case #i: y z`
- `i` is the test case number (1-based)
- `y` is the larger of the two distances (left and right) for the K-th person placed
- `z` is the smaller of the two distances for the K-th person placed

## Data Structures
- `stall_occupied`: a boolean list of length N+2, where index 0 and index N+1 are always True (boundary stalls), and indices 1 through N represent the empty stalls
- `Ls`: list tracking the number of consecutive empty stalls to the left of each position
- `Rs`: list tracking the number of consecutive empty stalls to the right of each position
- `Min_s`: list storing the minimum of Ls and Rs for each position
- `Max_s`: list storing the maximum of Ls and Rs for each position

## Initialization
For each test case:
1. Parse N and K from input
2. Create `stall_occupied` with True at both ends and False for all N interior stalls
3. For each position j from 0 to N+1:
   - If occupied: set Ls[j] = -1 and Rs[j] = -1
   - If empty: set Ls[j] = j - 1 (distance to left boundary) and Rs[j] = N - j (distance to right boundary)
   - Compute Min_s[j] and Max_s[j] from these values

## Main Selection Loop (repeated K times)
For each person placement:

### Selection Rule
1. Find the maximum value in `Min_s`
2. If multiple positions share this maximum:
   - Among those positions, find the one with the highest `Max_s` value
   - If still tied, select the leftmost such position
3. If only one position has the maximum `Min_s`, select that position

### Placement and Update
1. Record `y` = max(Ls[idx], Rs[idx]) and `z` = min(Ls[idx], Rs[idx]) for the selected position
2. Mark the selected stall as occupied (set `stall_occupied[idx] = True`)
3. Set Ls[idx], Rs[idx], Min_s[idx], Max_s[idx] all to -1

### Propagate Updates Leftward
Starting from idx-1 and moving left while positions are empty:
- Update Rs[position] to be the distance from that position to the newly occupied stall
- Recompute Min_s and Max_s for that position

### Propagate Updates Rightward
Starting from idx+1 and moving right while positions are empty:
- Update Ls[position] to be the distance from that position to the newly occupied stall
- Recompute Min_s and Max_s for that position

## Final Output
After all K placements, output the y and z values from the K-th (last) placement.

## Dependencies and Notes
- Uses `numpy` for array operations when finding indices of maximum values
- Uses `sys.stderr` for error printing (though no error printing occurs in the main logic)
- The `eprint` function is defined but never called in the main flow
- The program flushes stdout after each test case output
- The selection logic implements a specific tie-breaking rule: prefer larger Max_s, then prefer leftmost position
