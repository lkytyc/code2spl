## Function: gcd

**Inputs:** Two `long long int` parameters, `a` and `b`.

**Output:** Returns the greatest common divisor of `a` and `b` as a `long long int`.

**Behavior:** Computes the remainder of `a` divided by `b`. While this remainder is positive, it reassigns `a` to the old `b`, `b` to the old remainder, and recomputes the remainder. When the remainder becomes zero, it returns the current value of `b`.

## Main Function

### Inputs
- Reads a single `long long int` value `n` from standard input.
- Then reads `n` strings, each stored in a character array `s` of size 100.

### Outputs
- Prints a single `long long int` value `ans` followed by a newline.

### Variable Declarations
- `n`: number of input strings.
- `i`, `j`, `k`: loop counters and temporary indices.
- `s`: character array for reading each input string.
- `a`: array of `long long int` with capacity 200005, used to store processed numeric values.
- `q`: a `long long int` initially set to 100000, later changed to 100000000.
- `b`: array of `long long int` with capacity 10004, used to store divisors.
- `c`: array of `long long int` with capacity 10004, used for counting.
- `min`, `mid`, `max`: variables for binary search.
- `ans`: accumulator for the final result.
- `l`: temporary variable for computed values.

### Processing Input Strings (First Loop)
For each index `i` from 0 to `n-1`:
1. Reads a string into `s`.
2. Initializes `a[i]` to 0 and `k` to 0.
3. Iterates through characters of `s` until the null terminator:
   - If the character is not a decimal point:
     - Updates `a[i]` by multiplying by 10 and adding the digit value.
     - If `k` is greater than 0, increments `k`.
   - If the character is a decimal point, sets `k` to 1.
4. After processing all characters, if `k` is still 0, sets `k` to 1.
5. While `k` is less than 10, multiplies `a[i]` by 10 and increments `k`.

This effectively converts each input string (which represents a decimal number) into an integer scaled by 10^9, preserving up to 9 decimal places.

### Normalization Step
- Sets `q` to 100000.
- For each `i` from 0 to `n-1`:
  - If `a[i]` modulo `q` is greater than 0, sets `a[i]` to -1.
  - Otherwise, divides `a[i]` by `q`.

This checks if each value is divisible by 100000; if not, marks it as invalid (-1).

### Divisor Generation
- Sets `q` to 100000000.
- Initializes `j` to 0.
- First loop: for `i` from 1 while `i*i <= q`:
  - If `q` is divisible by `i`, stores `i` in `b[j]` and increments `j`.
- After this loop, decrements `i` by 1.
- If `i*i` equals `q`, decrements `i` again.
- Second loop: while `i > 0`:
  - If `q` is divisible by `i`, stores `q/i` in `b[j]` and increments `j`.
  - Decrements `i`.

This generates all divisors of 100000000 in ascending order in array `b`.

### Counting and Accumulation
- Initializes all elements of `c` to 0.
- Sets `ans` to 0.
- For each `i` from 0 to `n-1`:
  - If `a[i]` is negative, skips to next iteration.
  - Computes `l` as `q / gcd(q, a[i])`.
  - Performs binary search on array `b` (which is sorted ascending) to find the smallest index `max` such that `b[max] >= l`. The search range is between `min = -1` and `max = j`.
  - Adds `c[max]` to `ans`.
  - For each `k` from 0 to `j-1`:
    - If `a[i]` is divisible by `b[k]`, increments `c[k]`.
