# Structured Description

## Input/Output
- **Input**: Read from standard input. First line contains an integer `qq` (number of test cases). For each test case, two integers `r` and `c` are read, followed by `r` lines each containing a string of length `c` (characters representing a grid).
- **Output**: For each test case, prints `Case #X: Y` where `X` is the 1-based case number and `Y` is the computed result (an integer).

## Global Variables
- `br`: BufferedReader for standard input
- `st`: StringTokenizer for token parsing
- `pw`: PrintWriter for standard output
- `par`: Static integer array used for union-find (disjoint set) operations

## Main Control Flow

### Initialization
- Sets up input/output readers/writers
- Reads number of test cases `qq`

### Per Test Case Loop
For each case from 1 to `qq`:
1. Prints case header
2. Reads grid dimensions `r` and `c`
3. Initializes result `ret` to 1
4. Reads the grid into 2D character array `g`

### Grid Reading
- Nested loops read each row as a string and populate `g[i][j]` character by character

### Main Search Loop
Iterates over all bitmasks from 1 to `(1 << (r*c)) - 1`:
- **Pruning**: If the bit count of the mask is less than or equal to current `ret`, skip this mask
- **Union-Find Initialization**: Creates `par` array with each element pointing to itself
- **Grid Selection**: Converts bitmask to a boolean 2D array `use` where `use[i][j]` is true if the corresponding bit is set
- **Connectivity Check**: 
  - Sets `numNeed` to (bit count of mask) - 1
  - For each selected cell, attempts to merge with right and down neighbors if they are also selected
  - Each successful merge decrements `numNeed`
  - If `numNeed` is not 0 after all merges, the selected cells are not connected; skip this mask

### Validity Check
For each possible "split point" (i, j) in the grid:
- Creates 4 empty sets (one per quadrant)
- For each selected cell (x, y):
  - Determines quadrant index based on position relative to (i, j):
    - If x > i, adds 2 to index
    - If y < j, adds 1 to index
  - Adds the character at that cell to the corresponding quadrant set
  - If any quadrant set has more than 1 distinct character, marks as invalid
- If all selected cells pass this check for some split point, the mask is valid

### Result Update
- If mask is valid (connected and passes quadrant check), updates `ret` to the bit count of the mask

### Output
- Prints the final `ret` value for the test case

## Helper Functions

### find(x)
- Returns the root of the union-find tree containing `x`
- Uses path compression (recursively sets parent to root)

### merge(x, y)
- Finds roots of `x` and `y`
- If same root, returns false (no merge performed)
- Otherwise, sets parent of one root to the other and returns true

### Input Parsing Functions
- `readInt()`: Parses next token as integer
- `readLong()`: Parses next token as long
- `readDouble()`: Parses next token as double
- `nextToken()`: Returns next whitespace-delimited token, reading new line if needed
- `nextLine()`: Reads next line, exits if null

### exitImmediately()
- Closes output writer and terminates program

## Key Data Dependencies
- The result `ret` depends on the maximum bit count of any valid mask found
- Validity requires both: (1) selected cells form a connected component, and (2) there exists a split point such that each quadrant contains at most one distinct character
- The search is exhaustive over all possible subsets of grid cells, with pruning based on current best result
