# Code Structure Description

## Overview
This Python code defines a collection of utility functions and a main program. The main program reads two integers from standard input, repeatedly subtracts the second from the first until the first becomes non-positive, and prints the number of subtractions performed.

## Input/Output Functions

### file()
- Redirects standard input to read from `input.py` and standard output to write to `output.py`.
- No parameters, no return value.

### get_array()
- Reads a line from standard input, splits it by whitespace, converts each token to an integer, and returns the resulting list.

### get_ints()
- Reads a line from standard input, splits it by whitespace, converts each token to an integer, and returns a map object of those integers.

### get_3_ints()
- Reads a line from standard input, splits it by whitespace, converts exactly three tokens to integers, and returns them as a three-value tuple.

## Mathematical Helper Functions

### sod(n)
- Converts input `n` to a string, iterates through each character, sums the integer values of all digits, and returns the digit sum.

### isPrime(n)
- Returns `False` if `n` is less than or equal to 1.
- Returns `True` if `n` is 2 or 3.
- Returns `False` if `n` is divisible by 2 or 3.
- For numbers greater than 3, checks divisibility by numbers of the form `6k ± 1` up to the square root of `n`.
- Returns `True` if no divisor is found.

## Array and Interval Functions

### getFloor(A, x)
- Performs binary search on sorted array `A` to find the largest element less than or equal to `x`.
- Returns the exact match if found.
- Returns `-1` if no element is less than or equal to `x`.
- Tracks the last valid floor candidate during the search.

### chk(aa, bb)
- Takes two lists of intervals (each interval being a pair of values).
- Nested loops compare every interval in `aa` against every interval in `bb`.
- Increments a counter when:
  - Interval `j` is contained within interval `i` (both bounds satisfy containment)
  - Interval `i` is contained within interval `j`
  - The end of one interval equals the start of the other (touching endpoints)
- Returns the total count of all matching pairs.

### maxSumRangeQuery(nums, req)
- Sorts `nums` in descending order.
- Uses a difference array technique to count how many query intervals cover each index position.
- Builds a frequency map from coverage counts to index positions.
- Sorts the frequency map by coverage count.
- Assigns the smallest numbers from `nums` to positions with the highest coverage, and largest numbers to positions with lowest coverage.
- Computes the sum of each query interval using the rearranged array.
- Returns the total sum modulo 10^9 + 7.

## Main Program

### main()
- Initializes a counter `c` to 0.
- Reads two integers `a` and `b` using `get_ints()`.
- Enters a while loop that continues while `a` is greater than 0.
- Inside the loop:
  - Subtracts `b` from `a`
  - Increments counter `c` by 1
- After the loop terminates, prints the value of `c`.

## Program Entry Point
- The `if __name__ == '__main__':` block calls `main()` when the script is executed directly.

## Control Flow Summary
- The main program has a single loop with a simple subtraction operation.
- The utility functions have various branching conditions (if/elif/else) and loops (for, while) as described above.
- No error handling or exception catching is present in any function.
