## Overview
This program processes a sequence of operations involving adding weighted values and querying a current position. It maintains a dynamic set of values with counts and computes a running total based on distances from a current median-like position.

## Input
- First line: integer `q` (number of operations)
- Next `q` lines: each contains either:
  - Type 1: three integers `(1, a, b)` where `a` is a value to add and `b` is a weight increment
  - Type 2: a single integer `2` (query operation)

## Output
- For each type 2 operation, a line containing the current position `x` and the total accumulated distance `xl + xr + bt`

## Initialization
- Reads `q` and all operations into list `aa`
- Sets `bt` to the `b` value from the first operation
- Sets `m` to 2^20 (unused in logic)
- Creates a counter dictionary `c` for tracking value frequencies
- Initializes two heaps: `lq` (max-heap via negation) for values less than current position, `rq` (min-heap) for values greater
- Sets sentinel values at negative and positive infinity with count 1
- Sets initial position `x` to the `a` value from the first operation, with count 1
- Initializes left/right distance accumulators (`xl`, `xr`) and left/right count accumulators (`lc`, `rc`) to 0

## Main Processing Loop
Iterates through operations from index 1 onward (skipping the first operation used for initialization):

### Query Operation (type 2)
- Appends a formatted string with current position `x` and total `xl + xr + bt`

### Add Operation (type 1)
- Extracts `a` and `b` from the operation
- Adds `b` to `bt`
- If `a` equals current position `x`, increments count of `x` and continues to next operation
- Otherwise:
  - Increments count of `a` in dictionary `c`
  - If this is the first occurrence of `a` (count becomes 1):
    - If `a < x`, pushes `-a` onto `lq` (max-heap)
    - If `a > x`, pushes `a` onto `rq` (min-heap)
  - Gets current count `xc` of position `x`

#### Case: `a < x` (adding value to the left)
- Updates left distance: `xl += x - a`
- Increments left count: `lc += 1`
- Computes current total distance `t = xl + xr`
- Looks at candidate new position `nx` = largest value in `lq` (negated)
- Gets count `nc` of `nx`
- Computes distance `s = x - nx`
- Computes new total `nt` if position shifts to `nx`:
  - `nt = xl - lc*s + xr + (rc+xc)*s`
- If `nt <= t` (shifting improves or maintains total):
  - Updates `xl` by subtracting `lc*s`
  - Updates `xr` by adding `(rc+xc)*s`
  - Updates counts: `lc -= nc`, `rc += xc`
  - Pushes old position `x` onto `rq`
  - Sets `x = nx`
  - Pops from `lq`

#### Case: `a > x` (adding value to the right)
- Updates right distance: `xr += a - x`
- Increments right count: `rc += 1`
- Computes current total distance `t = xl + xr`
- Looks at candidate new position `nx` = smallest value in `rq`
- Gets count `nc` of `nx`
- Computes distance `s = nx - x`
- Computes new total `nt` if position shifts to `nx`:
  - `nt = xl + (lc+xc)*s + xr - rc*s`
- If `nt < t` (shifting strictly improves total):
  - Updates `xl` by adding `(lc+xc)*s`
  - Updates `xr` by subtracting `rc*s`
  - Updates counts: `lc += xc`, `rc -= nc`
  - Pushes old position `x` onto `lq` (as `-x`)
  - Sets `x = nx`
  - Pops from `rq`

## Data Dependencies
- Position `x` depends on all previous add operations
- Distance accumulators `xl` and `xr` depend on positions and counts of all added values
- Count accumulators `lc`
