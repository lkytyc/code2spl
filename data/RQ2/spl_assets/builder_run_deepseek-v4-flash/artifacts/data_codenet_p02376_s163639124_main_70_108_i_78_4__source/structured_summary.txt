# Code Description

## Overview
This program implements a maximum flow algorithm on a directed graph with up to 120 vertices and 1200 edges. It reads graph data from standard input, computes flow using a recursive path-finding approach, and outputs either the total flow or an error message.

## Data Structures

### TEdge (Edge)
- `fmax`: maximum capacity of the edge
- `flow`: current flow through the edge
- `n[2]`: array of two vertex indices (source and destination)

### TVertex (Vertex)
- `num`: number of edges incident to this vertex
- `e[1200]`: array of edge indices incident to this vertex

### Global Variables
- `e[1200]`: array of all edges
- `v[120]`: array of all vertices
- `V`: number of vertices
- `E`: number of edges
- `et[120]`: visited/explored flag array for vertices

## Function: route(s, ed, c)
A recursive function that attempts to find augmenting paths from vertex `s` to vertex `ed` with capacity `c`.

### Inputs
- `s`: starting vertex
- `ed`: destination vertex
- `c`: available capacity to send

### Output
- Returns the amount of flow successfully sent from `s` to `ed`

### Control Flow
1. Marks vertex `s` as visited (`et[s]=1`)
2. Iterates through all edges incident to vertex `s`
3. For each edge, checks if `s` is the source vertex (`n[0]==s`):
   - If destination not visited and residual capacity exists:
     - Calculates minimum of available capacity and residual capacity
     - If destination is the target vertex: adds flow directly
     - Otherwise: recursively calls `route` on the destination
     - Updates flow and remaining capacity if recursive call succeeds
4. For edges where `s` is the destination (`n[0]!=s`):
   - Checks if source vertex not visited and flow exists on edge
   - Recursively calls `route` on the source vertex
   - Reduces flow on edge if recursive call succeeds
5. Unmarks vertex `s` as visited (`et[s]=0`)
6. Returns total flow accumulated

### Early Termination
- Returns immediately when accumulated flow reaches or exceeds capacity `c`
- Returns 0 if no path found

## Function: main()

### Input Processing
1. Reads `V` (vertices) and `E` (edges) from standard input
2. Initializes all vertices with zero incident edges
3. For each of `E` edges:
   - Reads source (`a`), destination (`b`), and capacity (`c`)
   - Stores edge with source/destination indices
   - Adds edge to both source and destination vertex adjacency lists
   - Initializes flow to 0
   - If destination is the last vertex (`V-1`), moves edge to front of source's adjacency list and accumulates capacity into `cmax`

### Flow Computation
1. Initializes all visited flags to 0
2. Performs exactly 3 iterations of the `route` function:
   - Calls `route(0, V-1, cmax)` to find augmenting path
   - If result is 0 or negative: prints accumulated flow and exits
   - Otherwise: adds result to total flow

### Output
- Prints total flow if algorithm completes within 3 iterations
- Prints "er" if 3 iterations complete without finding zero flow

## Key Algorithmic Details
- Uses a modified DFS-based approach for finding augmenting paths
- Supports both forward flow (increasing flow on edges) and backward flow (decreasing flow on reverse edges)
- The `MIN` macro selects the smaller of two values
- The algorithm is limited to exactly 3 augmenting path searches
- Edge ordering is modified for edges entering the sink vertex to prioritize them
