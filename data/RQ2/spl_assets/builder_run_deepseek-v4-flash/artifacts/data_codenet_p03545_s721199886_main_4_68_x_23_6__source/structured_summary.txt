## Inputs
- Reads a single integer `n` from standard input using `scanf`.

## Outputs
- Prints an arithmetic expression in the format: `a op1 b op2 c op3 d = 7`, where `a`, `b`, `c`, `d` are digits derived from the input, and `op1`, `op2`, `op3` are either `+` or `-` characters.

## Initialization
- Declares integer variables: `i`, `n`, `a`, `b`, `c`, `d`, `x`, `op1`, `op2`, `op3`, `cnt` (initialized to 0).
- Declares a character array `op` of size 2, initialized with `'+'` and `'-'`.

## Digit Extraction
- `a` = hundreds digit of `n` (thousands place value divided by 1000, then modulo 10).
- `b` = tens digit of `n` (hundreds place value divided by 100, then modulo 10).
- `c` = ones digit of `n` (tens place value divided by 10, then modulo 10).
- `d` = units digit of `n` (modulo 10).

## Main Loop (infinite loop with break condition)
- Resets `x`, `op1`, `op2`, `op3` to 0 at the start of each iteration.
- Runs an inner loop exactly 3 times (i = 0, 1, 2).

### Inner Loop Logic (3 iterations)
The inner loop performs a sequence of arithmetic operations based on the current value of `cnt` (which ranges from 0 upward). The operations build up a result `x` using the digits `a`, `b`, `c`, `d` and the `sum` and `sub` functions.

#### Branch 1: When `cnt < 3` OR `cnt == 4`
- First operation: `x = sum(a, b)` (always addition of `a` and `b`).
- Then, if `cnt < 2`:
  - `x = sum(x, c)` (add `c`).
  - If `cnt == 0`: `x = sum(x, d)` (add `d`), `op3` remains 0.
  - Else (cnt == 1): `x = sub(x, d)` (subtract `d`), `op3` set to 1.
- Else (cnt >= 2, but only cnt == 2 or cnt == 4 reach here):
  - `x = sub(x, c)` (subtract `c`), `op2` set to 1.
  - If `cnt == 2`: `x = sum(x, d)` (add `d`), `op3` remains 0.
  - Else (cnt == 4): `x = sub(x, d)` (subtract `d`), `op3` set to 1.

#### Branch 2: When `cnt >= 3` AND `cnt != 4` (i.e., cnt == 3, 5, 6, 7, ...)
- First operation: `x = sub(a, b)` (subtract `b` from `a`), `op1` set to 1.
- Then, if `cnt == 3` OR `cnt == 6`:
  - `x = sum(x, c)` (add `c`).
  - If `cnt == 3`: `x = sum(x, d)` (add `d`), `op3` remains 0.
  - Else (cnt == 6): `x = sub(x, d)` (subtract `d`), `op3` set to 1.
- Else (cnt == 5 or cnt >= 7):
  - `x = sub(x, c)` (subtract `c`), `op2` set to 1.
  - If `cnt == 5`: `x = sum(x, d)` (add `d`), `op3` remains 0.
  - Else (cnt >= 7): `x = sub(x, d)` (subtract `d`), `op3` set to 1.

### Loop Termination
- After the inner loop completes, if `x == 7`, the outer loop breaks.
- Otherwise, `cnt` is incremented by 1 and the outer loop repeats.

## Final Output
- Prints the expression using the original digits `a`, `b`, `c`, `d` and the operator characters selected by `op1`, `op2`, `op3` (0 maps to `'+'`, 1 maps to `'-'`), followed by `=7`.
