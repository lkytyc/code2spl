# Code Description

## Input
- Reads an integer `N` from standard input
- Then reads `N` integers into array `A` (array size is fixed at 100000)

## Output
- Prints a single integer value (the maximum of two computed sums)

## Main Processing Flow

### Initial Setup
1. Reads `N` and then `N` integers into array `A`
2. If `N == 2`, immediately prints the absolute difference between the two elements and exits

### Sorting
- Sorts array `A` in ascending order using `qsort` with the comparison function `int_sort`

### Array B Construction
- Creates array `B` of size 100000
- Sets middle position `B[pos]` (where `pos = N/2`) to the smallest element `A[0]`
- Uses two pointers: `beg` starting at index 1, `end` starting at `N-1`
- Alternates between two filling modes:
  - Mode 1: Takes elements from the end of sorted array `A` (largest remaining values) and places them at positions `pos-offset` and `pos+offset`
  - Mode 2: Takes elements from the beginning of sorted array `A` (smallest remaining values) and places them at positions `pos-offset` and `pos+offset`
- Continues until all elements are placed (when `end < beg`)

### Array C Construction
- Creates array `C` of size 100000
- Sets middle position `C[pos]` to the largest element `A[N-1]`
- Uses two pointers: `beg` starting at index 0, `end` starting at `N-2`
- Uses the same alternating filling pattern as array B, but with opposite starting mode

### Sum Calculation
- Computes `sumB`: sum of absolute differences between consecutive elements in array `B`
- Computes `sumC`: sum of absolute differences between consecutive elements in array `C`

### Final Output
- Prints the larger of `sumB` and `sumC`

## Key Functions
- `int_sort`: Comparison function for `qsort` that compares two integers (returns -1, 0, or 1)

## Control Flow Branches
- Early exit when `N == 2`
- Two separate while loops for constructing arrays B and C
- Each while loop has conditional branches based on `flag` value (alternating between 0 and 1)
- Break conditions when all elements have been placed
- Final conditional to determine which sum to print

## Data Dependencies
- Array B construction depends on sorted array A
- Array C construction depends on sorted array A
- Both arrays use the same sorted data but with different starting elements and different initial fill modes
- Sum calculations depend entirely on the constructed arrays B and C
