## Overview
This Java program reads a series of test cases, each containing an array of integers, and computes a maximum value based on a recursive selection process. The program outputs the result for each test case in a specified format.

## Input
- First line: an integer `t` representing the number of test cases
- For each test case: an integer `n` followed by `n` integers representing the array `aw`

## Output
- For each test case: a line in the format `Case #X: Y` where X is the test case number (1-based) and Y is the computed maximum value

## Global State
- A static 2D list `table` is used to store intermediate results across recursive calls

## Main Control Flow

### Test Case Loop
- Iterates from 1 to `t` (inclusive)
- For each test case:
  1. Reads `n` and initializes array `aw` of size `n`
  2. Initializes `table` with `n+1` empty ArrayLists (index 0 through n)
  3. Reads `n` integers into `aw`
  4. For each index from 1 to `n`, calls `recurse(aw, i)` and stores the result in `table` at that index
  5. Sets `max` to the size of the result at index `n`

### Single-Element Removal Loop
- For each index `i` from 0 to `n-1`:
  1. Reinitializes `table` with `n` empty ArrayLists
  2. Creates a new array `aww` of size `n-1` by removing element at index `i` from `aw`
  3. For each index from 1 to `n-1`, calls `recurse(aww, ii)` and stores results in `table`
  4. Compares the size of the result at index `n-1` with current `max`, updating `max` if larger

### Double-Element Removal Loop
- For each pair of indices `i` and `j` where `i < j`:
  1. Reinitializes `table` with `n-1` empty ArrayLists
  2. Creates a new array `aww` of size `n-2` by removing elements at indices `i` and `j` from `aw`
  3. For each index from 1 to `n-2`, calls `recurse(aww, ii)` and stores results in `table`
  4. Compares the size of the result at index `n-2` with current `max`, updating `max` if larger

### Output
- Prints the final `max` value for the current test case

## Recursive Function: `recurse(int[] aw, int n)`

### Parameters
- `aw`: the input array
- `n`: the number of elements to consider (1-based index into the array)

### Return Value
- An ArrayList of integers representing selected indices

### Logic
1. **Base case**: If `n == 1`, returns a list containing just `0`

2. **Recursive case** (n > 1):
   - Initializes tracking variables: `maxlength = -1`, `minweight = 100000000`, `goodindex = -1`, `addon = false`
   - Iterates through indices `i` from 0 to `n-1`:
     - Retrieves the previously computed result for index `i` from `table`
     - Skips if the result length is less than current `maxlength`
     - Computes the total weight by summing `aw[ii]` for each index `ii` in the result
     - Checks if adding the current element (at index `n-1`) would keep the total weight ≤ 6 × `aw[n-1]`; if so, increments length and weight, and sets a temporary flag
     - Updates tracking variables based on comparing length and weight:
       - If same length as current max, keeps the one with smaller weight
       - If longer length, updates all tracking variables
   - Builds the result by copying all indices from `table.get(goodindex)`
   - If the `addon` flag is true, appends index `n-1` to the result
   - Returns the result

## Data Dependencies
- The `table` static variable is critical: results for smaller indices must be computed before larger ones
- The main method computes results sequentially from index 1 to n, ensuring dependencies are satisfied
- When arrays are modified (removing elements), the table is reinitialized and recomputed for the new array
