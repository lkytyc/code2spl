## Overview
This program reads multiple test cases from standard input, processes a graph with weighted edges, and outputs a computed count value for each test case. The computation involves finding minimum edge weights in a specific pattern and accumulating values derived from those weights.

## Input
- Multiple test cases are read until end of input
- Each test case begins with an integer `n` (number of nodes)
- If `n` is 0, processing stops
- Next integer `m` specifies number of edges
- Then `m` lines follow, each containing three comma-separated integers: node `a`, node `b`, and edge weight `c`

## Output
- For each test case, a single integer is printed on its own line

## Processing Logic

### Initialization
- A 2D array `cost` of size n×n is created and initialized to `Integer.MAX_VALUE` for all entries
- This represents an adjacency matrix where missing edges have maximum value

### Edge Reading
- For each of the `m` edges:
  - Parse the three comma-separated values
  - Set `cost[a][b] = c` and `cost[b][a] = c` (undirected graph)

### First Pass (Rows 0 to n-2)
- For each row `i` from 0 to n-2:
  - Reset `min` to 0
  - Scan columns `j` from i+1 to n-1:
    - Skip if `cost[i][j]` is `Integer.MAX_VALUE`
    - Track the minimum edge weight found in this row segment
    - Record the row and column indices of this minimum
  - If a minimum was found (`min != 0`):
    - Add `min/100 - 1` to the running `count`
    - Mark both nodes (row and column indices) as "fl" (flagged)

### Second Pass (Unflagged Nodes)
- For each node `i` from 0 to n-1:
  - Skip if node `i` was already flagged in the first pass
  - Reset `min` to 0
  - Scan columns `j` from 0 to i-1:
    - Skip if `cost[j][i]` is `Integer.MAX_VALUE`
    - Track the minimum edge weight found in this column segment
  - If a minimum was found (`min != 0`):
    - Add `min/100 - 1` to the running `count`

### Output
- Print the final `count` value for the test case

## Key Data Dependencies
- The `cost` matrix is populated from input and used in both passes
- The `fl` boolean array tracks which nodes were selected in the first pass
- The first pass only considers edges where the row index is less than the column index
- The second pass only considers edges where the column index is less than the row index, and only for nodes not flagged in the first pass
- The `count` accumulates values from both passes

## Control Flow
- Outer while loop continues until end of input or `n == 0`
- Nested for loops handle matrix initialization and edge reading
- Two separate scanning passes with conditional logic for minimum tracking
- Early termination via `continue` statements when encountering `Integer.MAX_VALUE` entries
