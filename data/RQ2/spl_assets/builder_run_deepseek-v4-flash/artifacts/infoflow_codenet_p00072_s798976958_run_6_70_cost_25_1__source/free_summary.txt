This code reads multiple test cases from standard input. For each case, it reads the number of nodes `n` and edges `m`, then builds an undirected weighted graph from comma-separated edge descriptions. It then attempts to find a minimum spanning tree by iterating through nodes and selecting the cheapest edge from each node to any later node, accumulating a cost based on the edge weights (specifically, `weight/100 - 1`). It also handles nodes that weren't covered in the first pass by checking edges to earlier nodes. Finally, it prints the accumulated cost for each test case, stopping when `n` is 0.
