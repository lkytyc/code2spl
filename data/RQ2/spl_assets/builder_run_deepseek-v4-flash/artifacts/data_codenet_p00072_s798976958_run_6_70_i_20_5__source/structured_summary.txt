## Overview
This program reads multiple test cases from standard input, processes a graph with weighted edges, and outputs a computed count value for each test case. The computation involves finding minimum edge weights in a specific pattern and accumulating values derived from those weights.

## Input
- Multiple test cases are read until end of input
- Each test case begins with an integer `n` (number of nodes)
- If `n` is 0, processing stops
- Next integer `m` specifies number of edges
- Then `m` lines follow, each containing three comma-separated integers: node `a`, node `b`, and edge weight `c`

## Output
- For each test case, a single integer is printed on its own line

## Processing Logic

### Data Structure Initialization
- A 2D array `cost` of size n×n is created
- All entries are initialized to `Integer.MAX_VALUE` (representing no direct edge)

### Edge Reading
- For each of the `m` edges:
  - Parse the three comma-separated values
  - Set `cost[a][b] = c` and `cost[b][a] = c` (undirected graph)

### First Pass (Rows 0 to n-2)
- For each row `i` from 0 to n-2:
  - Find the minimum cost edge in that row among columns `j` from i+1 to n-1
  - Skip entries with value `Integer.MAX_VALUE`
  - Track the minimum value and its coordinates (`ti`, `tj`)
  - If a valid minimum was found (not zero):
    - Add `(min/100 - 1)` to the running count
    - Mark both nodes `ti` and `tj` as "fl" (flagged)

### Second Pass (Unflagged Nodes)
- For each node `i` from 0 to n-1:
  - Skip if node was already flagged in the first pass
  - Find the minimum cost edge in column `i` among rows `j` from 0 to i-1
  - Skip entries with value `Integer.MAX_VALUE`
  - If a valid minimum was found (not zero):
    - Add `(min/100 - 1)` to the running count

### Output
- Print the accumulated count for the test case

## Key Dependencies
- The first pass only considers edges where the row index is less than the column index (upper triangle)
- The second pass only considers edges where the row index is less than the column index (upper triangle), but only for nodes not already processed in the first pass
- The `fl` boolean array tracks which nodes were selected in the first pass
- The count accumulates integer division results from edge weights (each weight divided by 100, minus 1)

## Control Flow
- Outer while loop continues until end of input or `n == 0`
- Nested for loops handle matrix initialization and edge reading
- Two separate scanning passes over the matrix with different iteration patterns
- Conditional checks for `Integer.MAX_VALUE` and zero minimum values control whether contributions are added
