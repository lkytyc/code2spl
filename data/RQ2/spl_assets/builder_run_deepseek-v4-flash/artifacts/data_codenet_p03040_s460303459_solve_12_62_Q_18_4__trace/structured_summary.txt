## Overview
This program implements a data structure that maintains a dynamic multiset of numbers and supports two types of operations: insertion with an associated cost, and queries about the current median and a computed sum. The solution uses two priority queues to maintain the lower and upper halves of the data.

## Input
The program reads from standard input using a custom `InputReader` class. The first integer read is `Q`, the number of operations to process. Each subsequent operation consists of:
- An integer command (`com`), either 1 or 2
- For command 1: a long integer `a` (the value to insert) followed by another long integer (the cost `B` increment)
- For command 2: no additional parameters

## Output
For each command 2 (query operation), the program outputs a line containing two values separated by a space: the current median value and a computed sum.

## Data Structures
- `f`: A max-heap (priority queue with reverse ordering) storing the lower half of the inserted values
- `l`: A min-heap (standard priority queue) storing the upper half of the inserted values
- `fsum`: Running sum of all values currently in heap `f`
- `lsum`: Running sum of all values currently in heap `l`
- `B`: Accumulated sum of the cost values from all insert operations

## Control Flow

### Main Loop
The program processes `Q` operations in a while loop that decrements `Q` after each iteration.

### Insert Operation (com == 1)
When inserting value `a`:
1. If both heaps have equal size:
   - If both are empty, add `a` to heap `f` and update `fsum`
   - Otherwise, compare `a` with the minimum of heap `l` (peek):
     - If `a` is greater than that minimum, move the minimum from `l` to `f`, and insert `a` into `l`. Update both sums accordingly.
     - Otherwise, insert `a` directly into `f` and update `fsum`
2. If heap `f` is larger than heap `l` (by one element):
   - Compare `a` with the maximum of heap `f` (peek):
     - If `a` is greater than or equal to that maximum, insert `a` into `l` and update `lsum`
     - Otherwise, move the maximum from `f` to `l`, insert `a` into `f`, and update both sums

After the insertion logic, the cost value is read and added to `B`.

### Query Operation (com == 2)
When querying:
1. Get the maximum of heap `f` (peek) as the median value `x`
2. If both heaps have equal size, output `x` followed by `(lsum - fsum + B)`
3. If heap `f` is larger, output `x` followed by `(lsum - fsum + x + B)`

## Helper Methods
- `main`: Initializes the input reader and output writer, calls `solve()`, then flushes output
- `tr`: Debug utility that prints objects using deep string conversion and flushes

## InputReader Class
A custom fast input reader that:
- Buffers input from an InputStream
- Provides methods for reading integers, longs, doubles, strings, and arrays
- Handles whitespace skipping and negative numbers
- Throws `InputMismatchException` on invalid input and `NoSuchElementException` when no more input exists

## Key Invariants
- Heap `f` always contains either the same number of elements as heap `l`, or exactly one more
- All elements in `f` are less than or equal to all elements in `l`
- The median is always the maximum element of heap `f`
