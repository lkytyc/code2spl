This code processes a series of queries to maintain a dynamic set of numbers and compute the median along with a cumulative sum adjustment. It uses two priority queues (a max-heap for the lower half and a min-heap for the upper half) to keep track of the median, and for each insertion it updates the sums of both halves. When a query of type 2 is encountered, it outputs the current median and a calculated value based on the difference between the sums of the two halves plus an accumulated offset.
