[DEFINE_WORKER: "Generates a list of string move commands ('index size') that describe how to reorder a list containing s repeats of 1..r by repeatedly finding a target value and moving the block after it to the front, working from r down to 2." getResult]
    [INPUTS]
        <REF> input </REF>: String "External string read by the method; expected to contain two space-separated base-10 integers r and s."
    [END_INPUTS]

    [OUTPUTS]
        <REF> result </REF>: List<String> "A list of move commands formatted as '<index> <size>', where index is a 1-based list position and size is the number of elements moved in the block rotation."
    [END_OUTPUTS]

    [MAIN_FLOW]
        [SEQUENTIAL_BLOCK]
            [COMMAND Parse the first token of input.split(" ") as a base-10 int and store it in r. RESULT r]
            [COMMAND Parse the second token of input.split(" ") as a base-10 int and store it in s. RESULT s]
            [COMMAND Create a new empty ArrayList<String> for result. RESULT result]
            [COMMAND Create a new empty ArrayList<Integer> for v. RESULT v]
            [COMMAND For each ss from 0 to s-1 inclusive, and for each rr from 0 to r-1 inclusive, append rr+1 to v, populating v with s repetitions of the sequence 1..r. RESULT v]
            [COMMAND For each rr from 0 to r-2 inclusive (loop condition rr < r-1), set current = r - rr, count = s - 1, idx = current * s - 2, and start = idx. RESULT current, count, idx, start]
            [COMMAND While count > 0, set found = false, then repeatedly test whether v.get(idx) equals current; after every test, decrement idx unconditionally. This inner scan moves leftward, and the unconditional decrement also executes when a match is found. RESULT found, idx]
            [COMMAND If the scan finds v.get(idx) == current, decrement count, set found = true, compute sz = start - idx, append String.format("%d %d", idx + 1, sz) to result, create a new empty ArrayList<Integer> t, and while sz > 0, decrement sz and remove the element at index idx + 1 in v, adding it to t. If sz is 0, no elements are removed. RESULT result, t, v]
            [COMMAND After the match handling, append all remaining elements of v to t, reassign v = t, set idx = start, decrement start, and then let the scan loop's unconditional idx-- execute so the next search resumes one position left of the new start. RESULT v, idx, start]
            [COMMAND Return result after all rr iterations complete. RESULT result]
        [END_SEQUENTIAL_BLOCK]
    [END_MAIN_FLOW]

    [EXCEPTION_FLOW: The first or second space-separated token in input is not a valid base-10 integer; input.split(" ") preserves a leading empty token, so an input with a leading space causes the first token to be "" and Integer.parseInt("") throws.]
        [LOG "NumberFormatException while parsing r or s from input."]
        [THROW NumberFormatException "Thrown by Integer.parseInt when a token cannot be converted to a base-10 int."]
    [END_EXCEPTION_FLOW]

    [EXCEPTION_FLOW: input contains fewer than two split tokens; for example, whitespace-only input " " yields a zero-length array, while input with a single token yields a one-element array and the access at index 1 fails.]
        [LOG "ArrayIndexOutOfBoundsException while reading input.split(' ')[0] or input.split(' ')[1]."]
        [THROW ArrayIndexOutOfBoundsException "Thrown when the split array does not have the accessed index."]
    [END_EXCEPTION_FLOW]

    [EXCEPTION_FLOW: During the leftward scan for a value equal to current, idx becomes negative before a match is found, or idx + 1 is outside v's bounds during removal; this occurs when the assumed matching element is absent.]
        [LOG "IndexOutOfBoundsException while calling v.get(idx) or v.remove(idx + 1)."]
        [THROW IndexOutOfBoundsException "Thrown when an index is outside the current bounds of the v list."]
    [END_EXCEPTION_FLOW]

[END_WORKER]
