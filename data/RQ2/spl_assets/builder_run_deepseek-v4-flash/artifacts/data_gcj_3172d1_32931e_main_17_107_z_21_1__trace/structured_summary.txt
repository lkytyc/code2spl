## Overview
This program reads test cases from standard input and outputs a computed answer for each case. It processes arrays of integers and determines a minimum number of cuts needed based on specific conditions involving duplicate values and doubling relationships.

## Input
- First line: integer `t` (number of test cases)
- For each test case:
  - First line: two integers `n` (array size) and `d` (target count)
  - Second line: `n` space-separated integers

## Output
- For each test case, a line in the format: `Case #z: answer`
- The answer is always 0, 1, or 2

## Data Structures
- `Pair` class: stores a `long` value and an integer count, sorted in descending order by count
- `array`: sorted array of input values
- `ps`: array of Pair objects representing unique values and their frequencies

## Processing Flow

### Initial Setup
1. Read number of test cases
2. For each test case, read `n` and `d`, then read the array values
3. Sort the array in ascending order

### Special Cases for Single Element Arrays
- If `n==1` and `d==3`: output 2
- If `n==1` and `d==2`: output 1

### Frequency Counting
1. Iterate through sorted array to count consecutive duplicates
2. Create Pair objects for each unique value with its frequency
3. Sort the Pair array by frequency (descending)

### Decision Logic
The program checks conditions in order:

**Case 1: Maximum frequency ≥ d**
- Output 0 (no cuts needed)

**Case 2: d==2 and maximum frequency is 1**
- Output 1 (one cut needed)

**Case 3: d==3 and maximum frequency is 2**
- If the most frequent value is not the largest array element: output 1
- If the most frequent value is the largest array element:
  - If the second most frequent value also has count 2: output 1
  - Otherwise, check if any element is double another element:
    - If found: output 1
    - If not found: output 2

**Case 4: d==3 and maximum frequency is 1**
- Check if any element is double another element:
  - If found: output 1
  - If not found: output 2

### Double-Check Logic
The doubling check iterates through all pairs of array elements (including same index) and checks if either `array[j] == 2*array[i]` or `array[i] == 2*array[j]`. This uses nested loops with an outer label for early termination.

## Key Dependencies
- The frequency count determines which branch is taken
- The doubling check depends on the sorted array values
- The special case for `d==3` with frequency 2 depends on whether the most frequent value is the maximum array element

## Termination
- After processing all test cases, the accumulated output is printed to standard output
- The BufferedReader is closed before printing
