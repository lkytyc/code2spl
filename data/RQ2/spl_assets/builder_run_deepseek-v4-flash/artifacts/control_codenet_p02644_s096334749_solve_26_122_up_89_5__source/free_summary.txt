This code solves a grid-based pathfinding problem where a character can move up to k steps in one of four directions per turn, but can also continue moving in the same direction within the same turn at no extra cost. It precomputes how far the character can move in each direction from every cell (stopping at obstacles), then uses a 0-1 BFS (deque) to find the minimum number of turns needed to reach a target cell, printing -1 if unreachable.
