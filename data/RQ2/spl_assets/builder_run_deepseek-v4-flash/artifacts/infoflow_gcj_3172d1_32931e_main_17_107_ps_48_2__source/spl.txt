[DEFINE_WORKER: "Reads multiple test cases, each containing a list of slice sizes and a target diner count, and determines the minimum number of cuts needed to ensure at least d slices of equal size exist, using frequency analysis and doubling checks." main]
    [INPUTS]
        <REF> args </REF>: String[] "Command-line arguments (unused)"
    [END_INPUTS]

    [OUTPUTS]
        <REF> sb </REF>: StringBuffer "Accumulated output string containing the result for each test case"
    [END_OUTPUTS]

    [MAIN_FLOW]
        [SEQUENTIAL_BLOCK]
            [COMMAND Initialize a BufferedReader to read from standard input, read the first line as an integer t representing the number of test cases, and initialize a StringBuffer to accumulate output. RESULT br, t, sb]
            [COMMAND For each test case z from 1 to t, append the case label 'Case #z: ' to the output buffer. RESULT sb]
            [COMMAND Read the first line of the test case and tokenize it to extract integers n (number of slices) and d (target number of equal slices). RESULT n, d]
            [COMMAND If n equals 1 and d equals 3, append '2' to the output buffer and continue to the next test case. RESULT sb]
            [COMMAND If n equals 1 and d equals 2, append '1' to the output buffer and continue to the next test case. RESULT sb]
            [COMMAND Read the second line of the test case, tokenize it, and parse each token as a long value into an array of size n. RESULT array]
            [COMMAND Sort the array in ascending order. RESULT array]
            [COMMAND Compress the sorted array into an array of Pair objects, where each Pair stores a unique value and its frequency count, and sort the resulting pairs by frequency in descending order. RESULT ps, w]
            [COMMAND If the frequency of the most common value (ps[0].count) is greater than or equal to d, append '0' to the output buffer and continue to the next test case. RESULT sb]
            [COMMAND If d equals 2 and the most common value appears only once, append '1' to the output buffer and continue to the next test case. RESULT sb]
            [COMMAND If d equals 3, the most common value appears twice, and it is not the largest value in the array, append '1' to the output buffer and continue to the next test case. RESULT sb]
            [COMMAND If d equals 3, the most common value appears twice, and it is the largest value in the array, check if the second most common value also appears twice; if so, append '1' to the output buffer and continue to the next test case. RESULT sb]
            [COMMAND If d equals 3, the most common value appears twice, and it is the largest value in the array, search for any pair of values in the array where one is exactly double the other; if found, append '1' to the output buffer and continue to the next test case. RESULT sb, flag]
            [COMMAND If d equals 3, the most common value appears twice, it is the largest value in the array, and no doubling pair was found, append '2' to the output buffer and continue to the next test case. RESULT sb]
            [COMMAND If d equals 3 and the most common value appears only once, search for any pair of values in the array where one is exactly double the other; if found, append '1' to the output buffer and continue to the next test case. RESULT sb, flag]
            [COMMAND If d equals 3, the most common value appears only once, and no doubling pair was found, append '2' to the output buffer and continue to the next test case. RESULT sb]
            [COMMAND After processing all test cases, close the BufferedReader and print the accumulated output buffer to standard output. RESULT sb]
        [END_SEQUENTIAL_BLOCK]
    [END_MAIN_FLOW]

[END_WORKER]
