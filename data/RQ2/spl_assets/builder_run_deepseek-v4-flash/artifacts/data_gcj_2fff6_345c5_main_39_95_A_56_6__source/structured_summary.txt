## Overview
This program determines whether a chocolate bar grid containing chocolate chips can be divided into a specified number of equal portions using horizontal and vertical cuts. It processes multiple test cases and outputs whether each configuration is possible.

## Global Data
- Two 101×101 integer matrices: `A` (raw chip data) and `B` (2D prefix sum)
- Integer variables: `r` (rows), `c` (columns), `h` (horizontal cuts), `v` (vertical cuts)
- Integer variables: `guests` (total portions needed), `chips` (total chip count), `share` (chips per portion)

## Function: `fr` (forward row check)
**Inputs:** `rRemaining` (horizontal cuts still needed), `i` (current row index), `j` (current column index)

**Behavior:**
1. Checks if the total chips in the remaining rows (from row `i` to row `r`) at column `j` equals `(rRemaining + 1) × share`. If not, returns 0 (failure).
2. If `rRemaining` is 0, returns 1 (success - all horizontal divisions found).
3. Otherwise, scans rows from `i+1` to `r-1` looking for a row where the chip count from row `i` to that row at column `j` equals exactly `share`.
4. When found, recursively calls itself with `rRemaining - 1` and the new row index.
5. Returns 0 if no valid row boundary is found.

## Function: `fc` (forward column check)
**Inputs:** `cRemaining` (vertical cuts still needed), `i` (current row index), `j` (current column index)

**Behavior:**
1. Checks if the total chips in the remaining columns (from column `j` to column `c`) at row `i` equals `(cRemaining + 1) × share`. If not, returns 0.
2. If `cRemaining` is 0, returns 1 (success).
3. Otherwise, scans columns from `j+1` to `c-1` looking for a column where the chip count from column `j` to that column at row `i` equals exactly `share`.
4. When found, calls `fr` with `cRemaining - 1`, `i`, and the new column index.
5. Returns 0 if no valid column boundary is found.

## Main Function Flow

### Input Processing
1. Reads number of test cases `t`.
2. For each test case:
   - Reads dimensions `r`, `c` and cut counts `h`, `v`.
   - Calculates `guests = (h+1) × (v+1)`.
   - Initializes `chips` counter to 0.
   - Reads the grid row by row (skipping row 0 which is all zeros).
   - For each cell, sets `A[i][j]` to 1 if character is `@` (chip), else 0.
   - Counts total chips.

### Prefix Sum Construction
- Builds 2D prefix sum matrix `B` where `B[i][j]` = chips in rectangle from (1,1) to (i,j).
- Formula: `B[i][j] = A[i][j] + B[i-1][j] + B[i][j-1] - B[i-1][j-1]`.

### Divisibility Check
- If `chips % guests != 0`, prints "IMPOSSIBLE" immediately.

### Feasibility Search
- Sets `share = chips / guests`.
- Iterates through all possible first cut positions (row `i` from 1 to r-1, column `j` from 1 to c-1).
- For each position where `B[i][j] == share` (first quadrant has exactly one share):
  - Sets `possible = 1`.
  - Calls `fr(h-1, i, j)` to check horizontal divisions.
  - Calls `fc(v-1, i, j)` to check vertical divisions.
  - If both succeed, prints "POSSIBLE" and stops searching.
- If no valid position found, prints "IMPOSSIBLE".

### Output Format
- Each result printed as: `Case #N: POSSIBLE` or `Case #N: IMPOSSIBLE` where N is the test case number starting from 1.

## Key Logic
- The program uses prefix sums to efficiently query chip counts in any rectangular region.
- The `fr` and `fc` functions recursively verify that all required horizontal and vertical cuts can be placed such that every resulting portion contains exactly `share` chips.
- The search only checks the first cut position; subsequent cuts are validated recursively.
