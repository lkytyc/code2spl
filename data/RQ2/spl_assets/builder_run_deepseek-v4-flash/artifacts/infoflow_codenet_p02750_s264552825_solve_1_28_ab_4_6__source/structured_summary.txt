## Function: solve(n, t, ab_list)

### Inputs
- `n`: integer, number of items
- `t`: integer, time limit
- `ab_list`: list of pairs, each pair containing two integers (a, b)

### Processing Steps

**Step 1: Separate items by first component**
- Creates `a0b_list` containing only the second component (b) from all pairs where the first component equals 0
- Creates `apb_list` containing all pairs where the first component is greater than 0

**Step 2: Sort the lists**
- `a0b_list` is sorted in ascending order
- `apb_list` is sorted in descending order based on the ratio `a / (b + 1)` for each pair

**Step 3: Dynamic programming table construction**
- `m` is set to the length of `apb_list`
- Creates a 2D table `dp` with dimensions (m+1) rows and 30 columns, initialized with value `t+1`
- Sets the first column (index 0) of every row to 0
- For each item `i` in `apb_list` (0-indexed) and each column `k` from 1 to 29:
  - Computes `ti` as `dp[i][k-1] + 1`
  - Gets the pair `(a, b)` from `apb_list[i]`
  - Sets `dp[i+1][k]` to the minimum of `dp[i][k]` and `ti + a * ti + b`

**Step 4: Cumulative sum for zero-a items**
- Creates `a0b_list_cum_sum` starting with 0
- For each `b` in `a0b_list`, adds `b + 1` to a running sum and appends to the cumulative sum list

**Step 5: Result computation**
- Initializes `res` to 0
- For each index `k` in the cumulative sum list (representing how many zero-a items are used):
  - For each `p` from 0 to 29:
    - If `dp[m][p] + a0b_list_cum_sum[k]` is less than or equal to `t`:
      - Updates `res` to the maximum of current `res` and `k + p`

### Output
- Returns `res`, the maximum number of items that can be processed within the time limit

## Function: main()

### Inputs
- Reads two integers from standard input: `n` and `t`
- Reads `n` lines, each containing two integers, forming `ab_list`

### Processing
- Calls `solve(n, t, ab_list)`

### Output
- Prints the result from `solve`

## Function: test()

### Processing
- Runs three assertion tests:
  1. `solve(3, 7, [[2, 0], [3, 2], [0, 3]])` must equal 2
  2. `solve(1, 3, [[0, 3]])` must equal 0
  3. `solve(5, 21600, [[2, 14], [3, 22], [1, 3], [1, 10], [1, 9]])` must equal 5

## Program Entry Point

- When executed as the main module, first calls `test()` then calls `main()`

## Key Data Dependencies

- The DP table depends on the sorted order of `apb_list`
- The cumulative sum list depends on the sorted order of `a0b_list`
- The final result depends on both the DP table (for positive-a items) and the cumulative sum (for zero-a items)
- The DP recurrence uses the previous row's value at column `k-1` to compute the current cell
