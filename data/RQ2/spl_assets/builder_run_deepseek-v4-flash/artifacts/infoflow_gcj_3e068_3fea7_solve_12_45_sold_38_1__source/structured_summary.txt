## Inputs
- The program reads from standard input using a `Scanner` wrapped around a `BufferedReader` and `InputStreamReader`.
- The first input token is a long integer `t`, representing the number of test cases.
- For each test case, the program reads an integer `n`, representing the number of items available.
- For each of the `n` iterations, the program reads an integer `d` (the number of preferences for that iteration), followed by `d` integers, each representing an item number (1-based).

## Outputs
- For each of the `n` iterations within each test case, the program prints either:
  - `-1` if no item can be sold (either `d` is zero or all preferred items are already sold).
  - The item number (1-based) that was randomly selected and marked as sold.

## Control Flow

### Main method
- Calls `solve()` and terminates.

### solve method
- Initializes the scanner.
- Reads `t` (number of test cases) and consumes the rest of the line.
- Loops `t` times (outer loop), with loop variable `i2`.

#### Per test case:
- Reads `n` (number of items).
- Creates a boolean array `sold` of size `n`, initialized to `false` (all items unsold).

#### Inner loop (per item):
- Reads `d` (number of preferences for this item).
- Creates an integer array `p` of size `d` to store the raw preference values.
- Creates an `ArrayList<Integer>` named `wants` to store only the preferences that are not yet sold.
- Loops `d` times to read each preference value `x`:
  - Stores `x` in array `p` at position `j`.
  - Checks if item `x-1` (0-based index) is not sold (`!sold[x-1]`).
  - If not sold, adds `x` to the `wants` list.

#### Decision branch:
- If `d == 0`: prints `-1`.
- Else if `wants.size() == 0`: prints `-1`.
- Else:
  - Computes a random index using `Math.floor(wants.size() * Math.random())`.
  - Retrieves the item number at that random index from `wants`.
  - Marks that item as sold by setting `sold[toSell-1] = true`.
  - Prints the selected item number.

## Loops
- Outer loop: iterates `t` times (test cases).
- Middle loop: iterates `n` times (items per test case).
- Inner loop: iterates `d` times (preferences per item).

## Function Calls
- `solve()` is called from `main`.
- `sc.nextLong()`, `sc.nextInt()`, `sc.nextLine()` for input parsing.
- `wants.add(x)` for list operations.
- `wants.size()` to check list size.
- `Math.random()` and `Math.floor()` for random selection.
- `System.out.println()` for output.

## Data Dependencies
- The `sold` array persists across all `n` iterations within a single test case, tracking which items have been sold.
- The `wants` list depends on the current state of the `sold` array.
- The random selection depends on the size of `wants`.
- The `p` array stores raw preferences but is never used after being populated (only `wants` is used for decision-making).
- The `sold` array is updated only when a sale occurs (when `wants` is non-empty).

## Edge Cases
- If `d` is zero, no preferences exist, so `-1` is printed.
- If all preferred items are already sold, `wants` is empty, so `-1` is printed.
- The random selection uses `Math.random()`, which returns a value in [0.0, 1.0), so the index is always within the valid range of `wants`.
