## Overview
This program reads a series of test cases, each containing an array of integers, and computes a maximum value based on a recursive selection process. The output is formatted as "Case #X: Y" for each test case.

## Input
- First line: integer `t` (number of test cases)
- For each test case: integer `n` followed by `n` integers (stored in array `aw`)

## Output
- For each test case: "Case #iii: max" where `max` is the computed maximum value

## Global State
- Static variable `table`: a 2D list structure (ArrayList of ArrayLists of Integers) used to store intermediate results from the recursive function

## Main Control Flow

### Test Case Loop (lines 10-82)
Iterates from 1 to `t` (inclusive), processing one test case per iteration.

### Initial Array Processing (lines 12-20)
- Reads `n` and creates array `aw` of size `n`
- Initializes `table` with `n+1` empty ArrayLists (index 0 through n)
- Reads `n` integers into `aw`

### First Computation Phase (lines 21-24)
- For each index from 1 to `n`, calls `recurse(aw, i)` and stores the result in `table` at position `i`
- Sets `max` to the size of the result at position `n`

### Single-Element Removal Phase (lines 26-49)
- For each index `i` from 0 to `n-1`:
  - Reinitializes `table` with `n` empty ArrayLists
  - Creates new array `aww` of size `n-1` by removing element at position `i` from `aw`
  - Calls `recurse(aww, ii)` for each `ii` from 1 to `n-1`, storing results in `table`
  - Updates `max` if the size of result at position `n-1` is larger

### Double-Element Removal Phase (lines 50-80)
- For each pair of indices `i` and `j` where `i < j`:
  - Reinitializes `table` with `n-1` empty ArrayLists
  - Creates new array `aww` of size `n-2` by removing elements at positions `i` and `j` from `aw`
  - Calls `recurse(aww, ii)` for each `ii` from 1 to `n-2`, storing results in `table`
  - Updates `max` if the size of result at position `n-2` is larger

## Recursive Function: `recurse(int[] aw, int n)`

### Base Case (line 87)
- If `n == 1`: returns a list containing a single element `0`

### Recursive Case (lines 89-113)
- Initializes local variables: `maxlength = -1`, `minweight = 100000000`, `goodindex = -1`, `addon = false`
- **Loop through indices 0 to n-1** (lines 94-107):
  - Retrieves result from `table` at current index
  - Skips if current result length is less than `maxlength`
  - Computes `weight` as sum of `aw[ii]` for each element `ii` in the result
  - If `weight <= 6 * aw[n-1]`: increments length, adds `aw[n-1]` to weight, sets `tempaddon = true`
  - Updates selection logic:
    - If `maxlength == leng`: keeps the one with smaller weight
    - Otherwise: updates all selection variables with current values
- **Build result** (lines 108-112):
  - Copies all elements from `table.get(goodindex)` into result
  - If `addon` is true, appends `n-1` to result
- Returns the result list

## Key Data Dependencies
- `recurse` depends on the global `table` for previously computed results
- The main function depends on `recurse` results to compute `max`
- The weight calculation depends on the original array values and indices stored in result lists
- The condition `weight <= 6 * aw[n-1]` creates a dependency between the current element and all previously selected elements

## Notable Behaviors
- The program performs three passes: full array, all single-element removals, and all double-element removals
- The `table` is reinitialized between different computation phases
- The recursive function uses memoization through the global `table` structure
- The final `max` value represents the largest result size found across all configurations tested
