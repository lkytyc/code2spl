# Structured Description

## Inputs
- Reads an integer `n` from standard input (first value).
- Then reads `n` integers into an array `a` of size up to 100,000.

## Outputs
- Prints a single integer `ans` to standard output.

## Variables
- `n`: number of elements in the array
- `a[100000]`: array of integers
- `i`, `j`: loop indices
- `sum`: running sum accumulator
- `ans`: counter for operations performed
- `sign`: character flag ('p' for positive, 'm' for negative)

## Initialization
- `sum` and `ans` are initialized to 0.
- `sign` is uninitialized until the first non-zero element is found.

## Main Control Flow

### Phase 1: Find First Non-Zero Element
- Loop through array from index 0 to n-1.
- If element is positive: set `sign = 'p'` and break.
- If element is negative: set `sign = 'm'` and break.
- If element is zero: continue to next element.
- If all elements are zero, `sign` remains uninitialized and the loop ends with `i = n`.

### Phase 2: Process Remaining Elements
- Continue loop from current `i` to n-1.
- For each element, add it to `sum`.

#### Branch A: sum equals zero
- Enter inner loop from `j = i+1` to n-1.
- If `sum == a[j]`, continue to next `j`.
- If `sign == 'p'`: increment `sum` by 1, increment `ans` by 1, set `i = j`, break inner loop.
- If `sign == 'm'`: decrement `sum` by 1, increment `ans` by 1, set `i = j`, break inner loop.
- After inner loop: set `i = j` and increment `ans` by 1.

#### Branch B: sum positive and sign is 'p'
- Change `sign` to 'm'.

#### Branch C: sum negative and sign is 'm'
- Change `sign` to 'p'.

#### Branch D: Other cases (sum and sign mismatch)
- If `sign == 'p'`: add `abs(sum) + 1` to `ans`, add `abs(sum) + 1` to `sum`, change `sign` to 'm'.
- If `sign == 'm'`: add `abs(sum) + 1` to `ans`, subtract `abs(sum) + 1` from `sum`, change `sign` to 'p'.

## Helper Function
- `abs(int x)`: returns `-x` if `x < 0`, otherwise returns `x`.

## Data Dependencies
- `sign` depends on the first non-zero element found.
- `sum` accumulates array values and is modified by operations in branches.
- `ans` accumulates counts from operations in branches.
- Loop indices `i` and `j` are modified within loops, affecting subsequent iterations.

## Edge Cases
- If all array elements are zero, `sign` remains uninitialized, and the second loop processes all elements with `sum` staying at 0, potentially entering Branch A repeatedly.
- The inner loop in Branch A may not find a matching condition, in which case `j` ends at `n`, and `i` is set to `n`, terminating the outer loop.
