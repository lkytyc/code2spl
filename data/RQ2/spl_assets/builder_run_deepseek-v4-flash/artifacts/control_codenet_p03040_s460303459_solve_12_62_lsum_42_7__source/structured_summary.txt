## Overview
This program implements a data structure that maintains a dynamic multiset of numbers and supports two types of operations: insertion with an associated cost, and querying for the median along with a computed cost value.

## Input
The program reads from standard input using a custom `InputReader` class. The first integer read is `Q`, the number of operations to process. Each subsequent operation consists of:
- An integer command (`com`), either 1 or 2
- For command 1: a long integer `a` (the value to insert) followed by another long integer (the cost `B` increment)
- For command 2: no additional parameters

## Output
For each command 2 (query operation), the program outputs a line containing two values separated by a space: the current median value and a computed cost value.

## Data Structures
- `f`: A max-heap (priority queue with reverse ordering) storing the smaller half of the inserted values
- `l`: A min-heap (standard priority queue) storing the larger half of the inserted values
- `fsum`: Running sum of all values currently in heap `f`
- `lsum`: Running sum of all values currently in heap `l`
- `B`: Accumulated cost from all insertion operations

## Control Flow

### Main Loop
The program processes `Q` operations in a while loop. For each iteration:
1. Reads the command type
2. If command is 1 (insertion), processes the insertion logic
3. If command is 2 (query), outputs the result

### Insertion Logic (Command 1)
When inserting value `a`:
- **If heaps are balanced** (both have equal size):
  - If both heaps are empty: add `a` to heap `f`, update `fsum`
  - Otherwise, compare `a` with the minimum of heap `l`:
    - If `a` is larger than that minimum: move the minimum from `l` to `f`, add `a` to `l`, update both sums accordingly
    - Otherwise: add `a` directly to `f`, update `fsum`
- **If heap `f` has one more element than heap `l`**:
  - Compare `a` with the maximum of heap `f`:
    - If `a` is greater than or equal to that maximum: add `a` to `l`, update `lsum`
    - Otherwise: move the maximum from `f` to `l`, add `a` to `f`, update both sums

After any insertion, the cost value `B` is incremented by the second long integer read.

### Query Logic (Command 2)
- The median is always the maximum element of heap `f` (peek operation)
- If heaps are balanced (equal sizes): output median and `(lsum - fsum + B)`
- If heap `f` has one more element: output median and `(lsum - fsum + median + B)`

## Helper Methods
- `tr(Object... o)`: Debug utility that prints and flushes the given objects
- `InputReader` class: Custom fast input reader with methods for reading integers, longs, doubles, strings, and arrays

## InputReader Details
- Uses a 1024-byte buffer for efficient reading
- `nextInt()` and `nextLong()` handle optional minus signs and validate digit characters
- Throws `InputMismatchException` on invalid input format
- Throws `NoSuchElementException` when no more input is available
- `hasNext()` skips whitespace and checks for more data

## Main Method
Initializes the input reader with `System.in` and output writer with `System.out`, calls `solve()`, then flushes the output buffer.
