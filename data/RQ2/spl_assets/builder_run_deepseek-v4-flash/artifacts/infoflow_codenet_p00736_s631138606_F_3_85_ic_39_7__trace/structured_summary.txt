# Structured Description

## Function: F(int p, int q, int r, char ft[100], int fc)

### Inputs
- Integer parameters p, q, r (each representing a value 0, 1, or 2)
- Character array ft containing a postfix expression
- Integer fc representing the length of the expression in ft

### Local Variables
- Integer array fit[100] - working copy of the expression
- Integer ic - current length of the working expression
- Integer x - current position index during evaluation
- Integer t - loop counter

### Initialization
- Sets ic to 1
- Initializes all 100 elements of fit to 0
- Copies the input expression from ft into fit, translating each character to a numeric code:
  - 'P' → p
  - 'Q' → q
  - 'R' → r
  - '0' → 0
  - '1' → 1
  - '2' → 2
  - '+' → 3
  - '-' → 4
  - '*' → 5
- After copying, decrements ic by 1 (so ic points to the last valid element)

### Evaluation Loop
- Sets x to 1
- Iterates while x is less than ic

#### Addition Operation (code 3)
- When fit[x] equals 3:
  - If both operands (fit[x-1] and fit[x-2]) are 0, result is 0
  - Else if either operand is 2, result is 2
  - Otherwise result is 1
  - Stores result at position x-2
  - Reduces ic by 2
  - Shifts elements left by 2 positions (from x-1 to ic)
  - Decrements x by 2

#### Unary Minus Operation (code 4)
- When fit[x] equals 4:
  - Replaces fit[x-1] with (2 - fit[x-1])
  - Reduces ic by 1
  - Shifts elements left by 1 position (from x to ic)
  - Decrements x by 1

#### Multiplication Operation (code 5)
- When fit[x] equals 5:
  - If either operand is 0, result is 0
  - Else if both operands are 2, result is 2
  - Otherwise result is 1
  - Stores result at position x-2
  - Reduces ic by 2
  - Shifts elements left by 2 positions (from x-1 to ic)
  - Decrements x by 2

- After processing any operation, increments x by 1

### Output
- Returns fit[1] (the final computed value)

## Function: main(void)

### Inputs
- Reads strings from standard input using scanf with %s format
- Loop continues until a string starting with '.' is entered

### Local Variables
- c - loop counter
- nc - count of pending unary minus operators
- oc - count of pending operators
- fc - count of output expression elements
- txt[100] - input string
- ng[100] - stack for unary minus operators
- op[100] - stack for binary operators
- ft[100] - output postfix expression

### Processing Each Input String

#### Character Classification Loop
- Iterates through each character of the input string

##### Operand Characters (0, 1, 2, P, Q, R)
- Increments fc
- Stores character in ft at position fc
- If there are pending unary minus operators (nc != 0):
  - Pops all unary minus operators from ng stack
  - Appends each to ft (incrementing fc)

##### Plus Operator (+)
- If operator stack is empty or top is '(':
  - Pushes '+' onto operator stack
- Otherwise:
  - Pops all operators from stack, appending each to ft
  - Pushes '+' onto operator stack

##### Multiplication Operator (*)
- If operator stack is empty, top is '+', or top is '(':
  - Pushes '*' onto operator stack
- Otherwise:
  - Pops all operators from stack, appending each to ft
  - Pushes '*' onto operator stack

##### Left Parenthesis '('
- Pushes '(' onto operator stack

##### Right Parenthesis ')'
- Pops operators from stack until '(' is found
- Appends each popped operator to ft
- Removes the '(' from stack

##### Minus Operator (-)
- Pushes '-' onto the unary minus stack (ng)

#### After Processing All Characters
- If operator stack is not empty:
  - Pops all remaining operators, appending each to ft

#### Output of Postfix Expression
- Prints each character of ft from position
