[DEFINE_WORKER: "Evaluates a postfix expression encoded in ft, substituting p, q, and r for P, Q, and R, mapping digits and operators to numeric codes, reducing the expression in place, and returning the final value at fit[1]." F]
    [INPUTS]
        <REF> p </REF>: int "Integer value substituted for the token 'P'."
        <REF> q </REF>: int "Integer value substituted for the token 'Q'."
        <REF> r </REF>: int "Integer value substituted for the token 'R'."
        <REF> ft </REF>: char[100] "Character buffer containing the expression tokens; index 0 is ignored and tokens at indices 1 through fc-1 are processed."
        <REF> fc </REF>: int "Upper bound for token scanning; the mapping loop runs while ic < fc."
    [END_INPUTS]

    [OUTPUTS]
        <REF> result </REF>: int "The evaluated expression result stored in fit[1] after the reduction loop."
    [END_OUTPUTS]

    [MAIN_FLOW]
        [SEQUENTIAL_BLOCK]
            [COMMAND Declare the local array fit and initialize all 100 elements fit[0] through fit[99] to 0; also set ic to 1. RESULT fit]
            [COMMAND Loop while ic < fc. For each iteration, inspect ft[ic] and assign fit[ic] using the encoding 'P' -> p, 'Q' -> q, 'R' -> r, '0' -> 0, '1' -> 1, '2' -> 2, '+' -> 3, '-' -> 4, '*' -> 5; if ft[ic] matches none of these, leave fit[ic] unchanged. Then increment ic by 1. RESULT fit]
            [COMMAND After the mapping loop ends, decrement ic by 1, making ic the index of the last mapped token. RESULT ic]
            [COMMAND Set x to 1. RESULT x]
            [COMMAND Start the outer evaluation loop while x < ic. If fit[x] equals 3, compute the addition result and store it in fit[x-2]: 0 if both fit[x-2] and fit[x-1] are 0, 2 if either is 2, and 1 otherwise. Then decrement ic by 2, shift fit left by two by assigning fit[t]=fit[t+2] for t from x-1 through ic inclusive, and decrement x by 2. RESULT fit]
            [COMMAND Without exiting the loop, independently check whether fit[x] now equals 4, using the state updated by the previous branch. If true, set fit[x-1] to 2 - fit[x-1], decrement ic by 1, shift fit left by one by assigning fit[t]=fit[t+1] for t from x through ic inclusive, and decrement x by 1. RESULT fit]
            [COMMAND Without exiting the loop, independently check whether fit[x] now equals 5, using the state updated by the previous branches. If true, compute the multiplication result and store it in fit[x-2]: 0 if either fit[x-2] or fit[x-1] is 0, 2 if both are 2, and 1 otherwise. Then decrement ic by 2, shift fit left by two by assigning fit[t]=fit[t+2] for t from x-1 through ic inclusive, and decrement x by 2. RESULT fit]
            [COMMAND At the end of the outer loop iteration, increment x by 1, then test x < ic again; repeat until x is not less than ic. RESULT x]
            [COMMAND Return fit[1] as the final evaluated result. RESULT result]
        [END_SEQUENTIAL_BLOCK]
    [END_MAIN_FLOW]

[END_WORKER]
