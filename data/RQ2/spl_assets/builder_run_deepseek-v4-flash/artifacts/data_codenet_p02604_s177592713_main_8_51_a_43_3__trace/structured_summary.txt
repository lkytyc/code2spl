## Overview
This program computes minimum transportation costs for N facilities, where each facility can be assigned to either a horizontal or vertical axis line, and outputs the minimal cost for each possible number of assigned facilities.

## Inputs
- An integer N (number of facilities)
- For each facility i (0 to N-1): three integers X[i], Y[i], P[i] representing x-coordinate, y-coordinate, and weight/cost multiplier

## Outputs
- N+1 lines, each containing a long integer representing the minimum total cost when exactly k facilities are assigned to either axis (k = 0 to N)

## Data Structures
- `X[20]`, `Y[20]`, `P[20]`: coordinate and weight arrays
- `a[20]`: assignment array where 0=unassigned, 1=horizontal, 2=vertical
- `Z[1<<16][16][2]`: precomputed distance table; Z[mask][j][0] = minimum horizontal distance for facility j given mask, Z[mask][j][1] = minimum vertical distance
- `ans[20]`: result array initialized to a very large value (2^60)

## Precomputation Phase
For every possible subset mask (0 to 2^N - 1):
- For each facility j:
  - Initialize Z[mask][j][0] to absolute value of X[j] (distance to origin on x-axis)
  - Initialize Z[mask][j][1] to absolute value of Y[j] (distance to origin on y-axis)
  - For each facility k in the mask (bit k set):
    - Update Z[mask][j][0] to minimum of current value and absolute difference |X[j] - X[k]|
    - Update Z[mask][j][1] to minimum of current value and absolute difference |Y[j] - Y[k]|

## Main Computation Loop
The loop continues while `a[N]` is zero (using a[N] as a sentinel to detect when all combinations have been tried):

1. **Build masks**: Iterate through facilities 0 to N-1:
   - If a[i] == 1, set bit i in horizontal mask `h`
   - If a[i] == 2, set bit i in vertical mask `v`

2. **Count assigned facilities**: Compute `t` = popcount(h | v), which counts how many facilities are assigned to either axis

3. **Calculate cost**: For each facility i:
   - Add P[i] × min(Z[h][i][0], Z[v][i][1]) to running sum
   - This represents the minimum distance (horizontal or vertical) for facility i given the current assignment

4. **Increment assignment counter**: 
   - Starting from index 0, while a[i] == 2, reset to 0 and move to next index
   - Increment the first non-2 value (this implements base-3 counting: 0→1→2→0 with carry)

5. **Update answer**: Set ans[t] = min(ans[t], current sum)

## Popcount Function
Recursive function that counts set bits in an integer:
- Returns 0 if n is 0
- Otherwise returns (n & 1) + popcount(n >> 1)

## Control Flow
- The main loop iterates through all 3^N possible assignments (each facility can be unassigned, horizontal, or vertical)
- The loop terminates when the counter overflows past all N positions (detected by a[N] becoming non-zero)
- The precomputation phase runs once before the main loop

## Key Dependencies
- The cost calculation depends on both the precomputed Z table and the current assignment masks
- The answer for each count t depends on all assignments that produce exactly t assigned facilities
- The Z table depends only on the input coordinates, not on the assignment choices
