## Inputs

The program reads from standard input using `fgets`. The first line contains three integers: `n`, `t`, and `s`. Following that, there are `n` lines, each containing two integers: `a[i]` and `b[i]`.

The input parsing uses a custom `getint()` function that reads digits from a global character pointer `p`. The parsing assumes the input is formatted with single spaces between numbers, and each line ends with a newline character.

## Outputs

The program outputs a single integer to standard output, which represents the maximum value computed by the dynamic programming algorithm.

## Global Variables

- `dp[3001][3001]`: A 2D integer array used for dynamic programming.
- `buf[30]`: A character buffer for reading input lines.
- `p`: A character pointer used for parsing integers from the buffer.

## Function: getint()

This function parses a non-negative integer from the character buffer pointed to by `p`. It reads digits while the current character is `'0'` or greater (i.e., while `*p >= '0'`). For each digit, it accumulates the value using bit shifts and addition: `n = (n << 3) + (n << 1) + (*p++ & 0xf)`. The `& 0xf` converts the ASCII digit to its numeric value. The function returns the parsed integer.

## Main Function Logic

### Initialization and Input Reading

1. Reads the first line into `buf` using `fgets`, with `p` set to point to `buf`.
2. Calls `getint()` to parse `n`, then increments `p` to skip the space.
3. Calls `getint()` to parse `t`, then increments `p` to skip the space.
4. Calls `getint()` to parse `s`.

5. For each index `i` from 1 to `n`:
   - Reads a line into `buf` using `fgets`, with `p` reset to point to `buf`.
   - Calls `getint()` to parse `a[i]`, then increments `p` to skip the space.
   - Calls `getint()` to parse `b[i]`.

### Dynamic Programming Computation

Initializes `ans` to 0.

Uses nested loops:
- Outer loop: `i` from 1 to `n`
- Inner loop: `j` from 1 to `t`

For each `(i, j)` pair:
1. Sets `dp[i][j]` to the maximum of:
   - `dp[i-1][j]` (not using item `i`)
   - `dp[i][j-1]` (using a smaller capacity)
2. Computes `k = j - b[i]` (remaining capacity after using item `i`).
3. If `k >= 0` AND (`s <= k` OR `j <= s`), then:
   - Updates `dp[i][j]` to the maximum of its current value and `dp[i-1][k] + a[i]` (using item `i`).
4. Updates `ans` to the maximum of `ans` and `dp[i][j]`.

### Output

Prints the final value of `ans` followed by a newline.

## Control Flow Branches

- The `getint()` function loops while the current character is a digit (`*p >= '0'`).
- In the main DP loop, there is a conditional check: `if (k >= 0 && (s <= k || j <= s))` which gates whether the item can be used.
- The `max` macro uses a conditional expression to return the larger of two values.

## Data Dependencies

- `dp[i][j]` depends on `dp[i-1][j]`, `dp[i][j-1]`, and potentially `dp[i-1][k]` where `k = j - b[i]`.
- The value of `ans` depends on all computed `dp[i][j]` values.
- Input values `a[i]` and `b[i]` are used in the DP recurrence.
- The condition for using item `i` depends on `s`, `j`, and `k` (which depends on `b[i]`).

## Loops

- The `getint()` function contains a while loop for digit parsing.
- The main function has:
  - A for loop for reading `n` pairs of inputs.
  - Nested for loops for the DP computation (outer over `i`, inner over `j`).

## Function Calls

- `fgets` is called to read input lines.
- `getint()` is called multiple times for parsing integers.
- `printf` is called once at the end to output the result.
