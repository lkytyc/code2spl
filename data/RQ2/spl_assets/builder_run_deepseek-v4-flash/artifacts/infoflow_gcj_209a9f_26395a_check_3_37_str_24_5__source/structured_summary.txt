## Overview
This program reads a binary string, transforms each `1` into the sequence `(1)`, and then removes all occurrences of the adjacent pair `)(` from the resulting string. It processes multiple test cases.

## Inputs
- An integer `T` (number of test cases) read via `scanf("%d", &T)`.
- For each test case, a string `S` (up to 100 characters) read via `scanf("%s\n", S)`.

## Outputs
- For each test case, prints `Case    #<counter>:    <transformed string>` where `<counter>` is the 1-based test case number and `<transformed string>` is the result after processing.

## Global Variables
- `char S[101]`: stores the input string for the current test case.
- `char str[101]`: stores the transformed string during processing.

## Function: `check(const char *S)`
### Purpose
Transforms the input string and removes adjacent `)(` pairs.

### Processing Steps
1. **Initialization**: Sets `top = 0` as an index into the global `str` array.

2. **First loop** (over input characters):
   - Iterates through `S` until null terminator.
   - If current character is `'1'`:
     - Appends `'('` to `str[top]`, increments `top`.
     - Appends `'1'` to `str[top]`, increments `top`.
     - Appends `')'` to `str[top]`, increments `top`.
   - If current character is `'0'` (or anything else):
     - Appends `'0'` to `str[top]`, increments `top`.
   - After loop, null-terminates `str` at position `top`.

3. **Reset**: Sets `top = 0` (though `top` is not used in the second loop).

4. **Second loop** (over `str`):
   - Iterates through `str` until null terminator.
   - Checks if current character is `')'` AND the next character is `'('`.
   - If found:
     - Inner loop shifts all characters from position `i` left by 2 positions (overwriting the `)( ` pair).
     - After shifting, null-terminates `str` at the new end position.
   - **Note**: The loop does not reset `i` after a removal, so it continues scanning from the next position. This means it only removes the first occurrence of `)(` in each pass, but since the loop continues, it will eventually remove all such pairs (though it may miss some due to the non-reset behavior).

### Data Dependencies
- Reads from global `S` (passed as parameter).
- Writes to global `str`.
- The second loop depends on the output of the first loop.

## Main Function
### Control Flow
1. Reads `T` from input.
2. While `T != 0`:
   - Reads a string into `S`.
   - Calls `check(S)`.
   - Increments counter `cnt`.
   - Prints the formatted output with `cnt` and `str`.
   - Decrements `T`.
3. Returns 0.

### Loop Behavior
- The while loop runs exactly `T` times (as read initially), processing one test case per iteration.

## Edge Cases and Limitations
- The input string `S` is limited to 100 characters (buffer size 101).
- The transformed string `str` is also limited to 101 characters, which may overflow if the input contains many `1`s (each `1` becomes 3 characters).
- The removal of `)(` pairs is not fully correct: after removing one pair, the loop continues from the next index without rechecking the newly formed adjacent characters, so some `)(` pairs may remain.
- The `scanf("%s\n", S)` format includes a newline in the format string, which may cause issues with input parsing.
