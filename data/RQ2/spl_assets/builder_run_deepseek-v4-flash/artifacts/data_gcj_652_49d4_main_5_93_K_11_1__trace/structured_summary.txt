## Overview
This program simulates the placement of people into bathroom stalls according to specific selection rules. It processes multiple test cases, each defining a row of stalls and a number of people to place.

## Input
- First line: an integer T representing the number of test cases
- For each test case: a line containing two space-separated integers N and K
  - N: total number of stalls
  - K: number of people to place

## Output
For each test case, prints a line in the format: `Case #i: y z` where i is the test case number (1-based), y is the larger of the two distances for the last placed person, and z is the smaller distance.

## Data Structures
- `stall_occupied`: boolean list of length N+2, where index 0 and index N+1 are always True (representing walls), and indices 1 through N represent actual stalls
- `Ls`: list tracking the number of empty stalls to the left of each position
- `Rs`: list tracking the number of empty stalls to the right of each position
- `Min_s`: list storing the minimum of Ls and Rs for each position
- `Max_s`: list storing the maximum of Ls and Rs for each position

## Initialization
For each test case:
1. Parse N and K from input
2. Create `stall_occupied` with True at both ends and False for all N interior stalls
3. For each position j from 0 to N+1:
   - If occupied (wall or stall): set Ls and Rs to -1
   - If empty: set Ls to j-1 (distance to left wall/occupied stall) and Rs to N-j (distance to right wall/occupied stall)
   - Compute Min_s and Max_s for each position

## Main Loop (K iterations)
For each person placement:

### Selection Phase
1. Find the maximum value in Min_s
2. If multiple positions have this maximum:
   - Among those positions, find the one with the highest Max_s value
   - If still tied, select the leftmost such position
3. If only one position has the maximum Min_s, select that position

### Placement Phase
1. Compute y = max(Ls[idx], Rs[idx]) and z = min(Ls[idx], Rs[idx])
2. Mark the selected stall as occupied
3. Set Ls, Rs, Min_s, and Max_s for that position to -1

### Update Phase (Left side)
- Starting from the position immediately left of the placed stall, move leftward
- Stop when hitting an occupied stall or the left wall
- For each empty stall encountered, update Rs to reflect the new distance to the nearest occupied stall on the right
- Recompute Min_s and Max_s for each updated position

### Update Phase (Right side)
- Starting from the position immediately right of the placed stall, move rightward
- Stop when hitting an occupied stall or the right wall
- For each empty stall encountered, update Ls to reflect the new distance to the nearest occupied stall on the left
- Recompute Min_s and Max_s for each updated position

## Control Flow
- Outer loop iterates through test cases
- Inner loop iterates through K people placements
- Two while loops handle left and right updates after each placement
- Conditional logic handles tie-breaking in stall selection

## Dependencies
- Uses `numpy` for array operations when finding indices of maximum values
- Uses `sys` for stderr output in the eprint function (though eprint is never called in the main logic)
- Uses `raw_input` for reading input (Python 2 style)

## Final Output
After all K placements for a test case, prints the y and z values from the last placement, then flushes stdout.
