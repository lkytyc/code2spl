## Function: bfs

### Inputs
- `sx`, `sy`: integer coordinates representing the starting position
- `spx`, `spy`: integer arrays of equal length representing a sequence of target positions

### Outputs
- Returns `true` if all target positions can be reached in sequence, `false` otherwise

### Local Variables and Initialization
- `size` is set to 10, representing a 10×10 grid
- `spCnt` is initialized to 0, tracking which target position is being processed
- Two movement arrays are defined:
  - `dx`, `dy`: 12 possible knight-like moves (combinations of ±2 in one axis and ±1 in the other)
  - `dx2`, `dy2`: 9 possible moves including staying in place and all 8 adjacent cells (including diagonals)
- A boolean 2D array `park` is created, initially all `false`
- Two queues `queueX` and `queueY` are initialized with the starting coordinates

### Control Flow and Logic

#### Main Loop
- Continues while `queueX` is not empty
- **Early exit condition**: If `spCnt` equals the length of `spx`, all targets have been processed, so returns `true`

#### Marking Blocked Cells
- For the current target position (`spx[spCnt]`, `spy[spCnt]`), marks all cells reachable by the 9 moves in `dx2`/`dy2` as `true` in the `park` array
- Only marks cells that are within the 10×10 grid boundaries (coordinates 0–9 inclusive)

#### Expanding Current Queue
- Creates new empty queues `nx` and `ny`
- Processes all positions currently in `queueX`/`queueY`:
  - For each position, tries all 12 knight moves from `dx`/`dy`
  - A move is valid if:
    - The resulting x-coordinate is between 0 and 9 inclusive
    - The resulting y-coordinate is between 0 and 9 inclusive
    - The resulting cell in `park` is `true` (i.e., it was marked as blocked for this step)
  - Valid moves are added to the new queues `nx` and `ny`

#### Step Transition
- Increments `spCnt` by 1
- Resets `park` to a fresh all-`false` 10×10 array
- Replaces `queueX`/`queueY` with the new queues `nx`/`ny`

#### Termination
- If the main loop exits (queue becomes empty), returns `false`

## Function: main

### Inputs
- Reads from standard input using a `Scanner`

### Control Flow
- Runs an infinite loop that breaks only when both `sx` and `sy` read as 0

#### Per Iteration
1. Reads `sx` and `sy` (starting coordinates)
2. If both are 0, breaks the loop
3. Consumes a line
4. Reads `n` (number of target positions)
5. Creates arrays `spx` and `spy` of length `n`
6. Consumes a line
7. Reads `n` pairs of integers into `spx` and `spy`
8. Consumes a line
9. Calls `bfs(sx, sy, spx, spy)` and prints:
   - `"OK"` if the function returns `true`
   - `"NA"` if the function returns `false`

### Outputs
- Prints `"OK"` or `"NA"` for each test case until termination condition is met
