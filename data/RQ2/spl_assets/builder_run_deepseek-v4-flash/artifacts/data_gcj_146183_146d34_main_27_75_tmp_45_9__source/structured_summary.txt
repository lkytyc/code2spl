## Overview
This program processes multiple test cases, reading pairs of integer coordinates, identifying pairs of points that form segments with opposite-sign coordinate differences, and counting the number of distinct slopes among those segments.

## Inputs
- First line: integer `cases` (number of test cases)
- For each test case:
  - First line: integer `N` (number of points)
  - Next `N` lines: two integers each (x and y coordinates)

## Outputs
- For each test case, prints: `Case #X: Y` where X is the case number (1-based) and Y is either:
  - `1` if no qualifying pairs exist
  - The count of distinct slopes among qualifying pairs

## Data Structures
- Global array `array` of 100,005 structures, each containing two integers (`x` and `y`)
- Local 2D array `input[310][2]` storing point coordinates

## Main Processing Flow

### Reading Phase
1. Read number of test cases
2. For each test case:
   - Read number of points N
   - Read N coordinate pairs into `input` array

### Pair Selection Phase
For each test case:
- Iterate through all pairs of points (i, j) where i < j
- For each pair, compute: `(x_i - x_j) * (y_i - y_j)`
- If this product is negative (meaning the x-difference and y-difference have opposite signs):
  - Store the absolute differences in x and y into the `array` structure
  - Increment pair counter

### Result Computation Phase
- If no pairs were found (`pair == 0`): output `1`
- Otherwise:
  - Sort the `array` using `qsort` with custom comparator
  - Initialize answer to 2
  - Iterate through sorted array, comparing consecutive entries:
    - For entries i-1 and i, compute cross-multiplication: `(x_{i-1} * y_i)` vs `(y_{i-1} * x_i)`
    - If these products differ, increment answer
  - Output the final answer

## Helper Functions

### Comparator Function (`comp`)
- Takes two pointers to `arr` structures
- Computes: `c1 = a.x * b.y` and `c2 = b.x * a.y`
- Returns:
  - 0 if c1 equals c2
  - 1 if c1 > c2
  - -1 if c1 < c2
- Uses `long long int` to avoid overflow

### Absolute Value Function (`abs`)
- Custom implementation (shadows standard library function)
- Returns the absolute value of an integer input
- Handles negative numbers by multiplying by -1

## Control Flow Branches
- Main loop iterates `cases` times
- Nested loops for pair generation (i from 1 to N, j from i+1 to N)
- Conditional branch for negative product check
- Conditional branch for empty pair list
- Loop for counting distinct slopes in sorted array
- Conditional branch for slope comparison

## Data Dependencies
- The `array` contents depend on the input coordinates and the negative-product condition
- The sorting order depends on the comparator's cross-multiplication logic
- The final answer depends on the sorted order and consecutive comparisons
- The answer starts at 2 (minimum for any non-empty set) and increments for each distinct slope found
