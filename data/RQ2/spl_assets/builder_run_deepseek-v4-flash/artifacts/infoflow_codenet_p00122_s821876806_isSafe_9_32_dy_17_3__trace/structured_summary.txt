## Inputs
- Two integers on the first line: `fx` and `fy`, representing starting coordinates (0-9 range expected)
- A single integer `n` on the next line
- A list of integers `splist` on the following line, containing 2*n values

## Processing Flow

### Main Loop
- Continuously reads input until `fx == 0` and `fy == 0`, which terminates the program
- For each non-terminating input set:
  1. Reads `n` and the `splist` of 2*n integers
  2. Builds a safety grid structure
  3. Initializes a queue with the starting position
  4. Calls `isSafe` to determine if a path exists
  5. Prints "OK" if safe, "NA" otherwise

### makeList Generator Function
- Takes `splist` and `n` as parameters
- For each index `i` from 0 to n-1:
  - Extracts a pair of coordinates from `splist` at positions `i*2` and `i*2+1`
  - Creates a list containing: the coordinate pair `[x, y]` and the index `i`
  - Yields this list

### Safety Grid Construction
- For each yielded spring from `makeList`:
  - Creates a list `temp` of all valid neighboring positions
  - For each combination of offsets (-1, 0, 1) in both x and y directions:
    - Computes new coordinates by adding offsets to the spring's coordinates
    - If resulting coordinates are within bounds (0-9 for both x and y), adds `[[new_x, new_y], spring_index]` to `temp`
  - Appends `temp` to the `safe` list

### isSafe Function
- Takes a queue `wfs` and the `safe` list
- Processes items from the queue until empty:
  - Gets an item `flog` containing `[coordinates, index]`
  - Creates `flogArea` list for reachable positions
  - First pattern: for i in (-1, 0, 1) and j in (-2, 2):
    - Computes new coordinates: x = flog[0][0] + j, y = flog[0][1] + i
    - If within bounds, adds `[[new_x, new_y], flog[1] + 1]` to `flogArea`
  - Second pattern: for j in (-1, 0, 1) and i in (-2, 2):
    - Computes new coordinates: x = flog[0][0] + j, y = flog[0][1] + i
    - If within bounds, adds `[[new_x, new_y], flog[1] + 1]` to `flogArea`
  - Checks each position in `safe[flog[1]]`:
    - If that position is in `flogArea`:
      - If `flog[1] == 9`, returns True (success)
      - If `flog[1] < 9`, adds that position to the queue for further processing
- Returns False if queue becomes empty without finding a path

## Outputs
- Prints "OK" if `isSafe` returns True
- Prints "NA" if `isSafe` returns False
- Terminates when input is "0 0"

## Key Data Dependencies
- The `safe` list is indexed by spring number (0 to n-1)
- Each entry in `safe` contains positions reachable from that spring
- The queue starts with `[[fx, fy], -1]` (index -1)
- The function checks positions in `safe[flog[1]]` where `flog[1]` is the current index
- The target is reaching index 9 (the 10th spring)
