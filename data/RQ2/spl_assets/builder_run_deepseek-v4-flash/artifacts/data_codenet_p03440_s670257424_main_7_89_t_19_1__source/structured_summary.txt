## Overview
This program reads a graph with n vertices and m edges, processes union operations to form connected components, and then computes a minimum-cost spanning structure under specific constraints. The output is either a numeric cost, "0", or "Impossible".

## Inputs
- First line: two integers `n` (number of vertices) and `m` (number of edges)
- Second line: `n` integers representing vertex weights stored in array `a`
- Following `m` lines: pairs of integers `x` and `y` representing edges between vertices

## Initialization
- Array `uni` is initialized so that `uni[i] = i` for all vertices, representing each vertex as its own component root
- Array `a` stores the vertex weights

## Union Operations (Main Processing Loop)
For each of the `m` edge inputs, the code performs a union operation with a specific pattern:

**Case 1: When `uni[x] != x` (x is not a root)**
- Saves the current root of `y` as `t`
- Sets `uni[y] = x`
- Follows the chain from `y` to find the actual root, updating `uni[y]` to that root
- Scans all vertices: for any vertex `j` (except `y` itself) whose root equals the saved `t`, updates that vertex's root to the new root of `y`

**Case 2: When `uni[x] == x` (x is a root)**
- Saves the current root of `x` as `t`
- Sets `uni[x] = y`
- Follows the chain from `x` to find the actual root, updating `uni[x]` to that root
- Scans all vertices: for any vertex `j` (except `x` itself) whose root equals the saved `t`, updates that vertex's root to the new root of `x`

## Component Counting
After all unions, counts `num` = number of vertices where `uni[i] == i` (number of distinct component roots)

## Decision Logic Based on Component Count
1. **If `num == 1`**: Output "0" and terminate (single component)
2. **If `num * 2 - 2 > n`**: Output "Impossible" and terminate (not enough vertices to connect components)
3. **If `num * 2 - 2 == n`**: Output the sum of all vertex weights and terminate

## Minimum Cost Computation (for remaining cases)
- Initialize arrays `min` (minimum weight per component) and `minn` (index of vertex achieving that minimum) with infinity and unset values
- For each vertex, if its weight is less than the current minimum for its component root, update both arrays
- Sum up the minimum weights from all components into `ssum`
- Mark the chosen minimum-weight vertices by setting their weights to infinity in array `a`
- Sort array `a` in ascending order
- Add the smallest `(num - 2)` remaining weights to `ssum`

## Output
- Prints the final computed sum `ssum` as a long long integer

## Key Data Dependencies
- The union operations modify `uni` based on edge inputs
- Component count `num` depends on final state of `uni`
- The minimum selection depends on both `uni` (for component assignment) and `a` (for weights)
- The final sum combines component minimums with additional smallest weights from the sorted array
