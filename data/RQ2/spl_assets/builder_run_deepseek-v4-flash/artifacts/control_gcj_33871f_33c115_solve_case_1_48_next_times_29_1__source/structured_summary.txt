# Function: solve_case(in_times, edges)

## Inputs
- `in_times`: A list of integers representing initial time values for components
- `edges`: A list of tuples, each containing two integers representing component connections

## Initialization
- Creates `latencies` list with length equal to number of edges, initialized to 1,000,000
- Converts all edge endpoints from 1-based to 0-based indexing
- Creates `abs_times` list with length equal to `in_times`, initialized to 1,000,000
- For each positive value in `in_times`, copies that value into the corresponding position in `abs_times`

## Processing Negative Times
- Collects all negative values from `in_times` into `pos_times` as tuples of (absolute value, original index)
- Sorts `pos_times` by the absolute value

## Main Processing Loop
- Initializes `current_time` to 0 and `received` to 1
- Continues while `pos_times` is non-empty

### Branch 1: When first pending time equals received count
- Increments `current_time` by 1
- Counts all consecutive entries in `pos_times` with the same time value
- For each such entry, sets `abs_times` at that index to `current_time`
- Removes processed entries from `pos_times`
- Updates `received` by adding the count of newly processed entries

### Branch 2: When first pending time does not equal received count
- Collects all values from `abs_times` that are greater than `current_time`
- Sets `current_time` to the minimum of those values
- Counts how many entries in `abs_times` are less than or equal to `current_time`

## Latency Calculation
- Prepends 0 to `abs_times` (shifting all indices by 1)
- Creates sorted list of (time, component_index) pairs, sorted by time
- For each component (excluding the first/prepended one), in sorted order:
  - Checks each edge to find connections involving this component
  - If the component is the first endpoint (A) and its time is greater than the other endpoint's time, calculates latency as the difference and breaks
  - If the component is the second endpoint (B) and its time is greater than the other endpoint's time, calculates latency as the difference and breaks

## Output
- Returns a space-separated string of all latency values

# Function: main()

## Input Processing
- Reads integer T (number of test cases) from standard input
- For each test case:
  - Reads two integers: number of components and number of edges
  - Reads list of initial time values
  - Reads the specified number of edge tuples

## Output
- Calls `solve_case` for each test case
- Prints "Case #N: result" where N is the 1-based case number

## Control Flow
- Uses a for loop over test cases (1 to T inclusive)
- Uses a nested for loop to read edges
- Calls `main()` at module level to execute the program
