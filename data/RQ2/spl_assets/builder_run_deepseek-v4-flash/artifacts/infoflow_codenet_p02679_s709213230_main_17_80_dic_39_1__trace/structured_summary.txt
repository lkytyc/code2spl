## Overview
This program processes pairs of integers, normalizes them, groups equivalent pairs, and computes a combinatorial result modulo 10^9+7. It appears to count certain combinations of vectors or slopes.

## Input
- First line: integer `n` (number of pairs to process)
- Next `n` lines: each contains two integers `a` and `b`

## Output
- A single integer representing the computed result modulo 10^9+7

## Main Processing Steps

### Input Collection and Normalization
For each of the `n` input pairs:
1. Read integers `a` and `b`
2. Normalize the pair based on special cases:
   - If `a != 0` and `b == 0`: set `a = 1` (keeping `b = 0`)
   - If `a == 0` and `b != 0`: set `b = 1` (keeping `a = 0`)
   - If both are non-zero: divide both by their greatest common divisor
   - If both are zero: leave as-is
3. Apply sign normalization:
   - If both `a` and `b` are negative, negate both
   - If `a` is negative and `b` is positive, negate both
4. Create a string key from the normalized pair
5. Increment counts in two dictionaries: `dic` and `dic1` (both track the same counts)

### Main Computation
Initialize `ans = 1` and an empty dictionary `dic2`.

Iterate through each key `e` in `dic`:
1. Parse the key back into integers `a` and `b`
2. Skip if either `a` or `b` is zero
3. Determine the "reverse" key:
   - If both `a` and `b` are positive: reverse is `(b, -a)`
   - Otherwise: reverse is `(-b, a)`
4. Check if the reverse key exists in `dic1` and hasn't been processed yet (tracked via `dic2`)
5. If the reverse hasn't been processed:
   - Mark both the current key and reverse key as processed in `dic2`
   - Skip to next iteration
6. If the reverse was already processed (or doesn't exist):
   - Compute `n1 = 2^dic[e] mod M` and `n2 = 2^dic1[rev] mod M`
   - Update `ans`:
     - If `n1 == 0`: multiply by `n2`
     - If `n2 == 0`: multiply by `n1`
     - Otherwise: multiply by `(n1 + n2 - 1)`
   - Apply modulo after each multiplication

### Special Case Handling for Zero Components
After the main loop, handle pairs where one component is zero:
- Check for keys `'1 0'` and `'0 1'` in `dic`
- Compute `num` based on which keys exist:
  - Both exist: `num = 2^count('1 0') + 2^count('0 1') - 1`
  - Only `'1 0'`: `num = 2^count('1 0')`
  - Only `'0 1'`: `num = 2^count('0 1')`
- If `num != 0`, multiply `ans` by `num` (with modulo)

### Final Output
Print: `ans - 1 + count of '0 0' pairs`

## Key Data Structures
- `dic`: defaultdict(int) - counts of each normalized pair
- `dic1`: defaultdict(int) - duplicate of `dic` (same counts)
- `dic2`: defaultdict(int) - tracks which keys have been processed in the reverse-pair logic

## Important Control Flow
- The main loop processes each unique normalized pair exactly once for the reverse-pair logic
- Pairs with zero components are excluded from the main loop but handled separately
- The `(0,0)` pair is never normalized and only contributes to the final addition

## Mathematical Operations
- Uses modular exponentiation (pow with mod) for powers of 2
- All multiplications are taken modulo 10^9+7
- The final result subtracts 1 and adds the count of zero-zero pairs
