# Structured Description

## Inputs
- Reads two integers from standard input: `H` (height) and `W` (width), each via separate `scanf("%d", ...)` calls.
- Then reads a grid of characters of size H×W. For each row `i` from 1 to H, it first reads one character `d` (which is typically the newline left from the previous input), then reads W characters `c` into grid cell `l[i][j]`.

## Outputs
- Prints a single integer `ans` to standard output, followed by a newline (via `printf("%d", ans)`).

## Data Structures
- `l[1001][1001]`: character grid storing the input map (rows 1..H, columns 1..W).
- `p[1001][1001]`, `q[1001][1001]`, `r[1001][1001]`, `s[1001][1001]`: integer arrays storing distance values for four directional passes.
- `n[1001][1001]`: integer array storing the minimum of the four directional values for each cell.
- `m`: integer constant set to `H + W`, used as an initial large value for boundary cells.

## Helper Functions
- `max(a, b)`: returns `a` if `a > b`, otherwise returns `b`.
- `min(a, b)`: returns `b` if `a > b`, otherwise returns `a`.

## Control Flow and Processing

### Boundary Initialization
- For each row `i` from 1 to H:
  - Sets `p[i][0]`, `q[i][W+1]`, `r[i][0]`, `s[i][W+1]` all to `m`.
- For each column `j` from 1 to W:
  - Sets `p[0][j]`, `q[0][j]`, `r[H+1][j]`, `s[H+1][j]` all to `m`.

### Pass 1: Top-Left to Bottom-Right (array `p`)
- Loops `i` from 1 to H, `j` from 1 to W.
- If `l[i][j]` is `'#'`, sets `p[i][j] = 0`.
- Otherwise, sets `p[i][j] = min(p[i-1][j], p[i][j-1]) + 1`.

### Pass 2: Top-Right to Bottom-Left (array `q`)
- Loops `i` from 1 to H, `j` from W down to 1.
- If `l[i][j]` is `'#'`, sets `q[i][j] = 0`.
- Otherwise, sets `q[i][j] = min(q[i-1][j], q[i][j+1]) + 1`.

### Pass 3: Bottom-Left to Top-Right (array `r`)
- Loops `i` from H down to 1, `j` from 1 to W.
- If `l[i][j]` is `'#'`, sets `r[i][j] = 0`.
- Otherwise, sets `r[i][j] = min(r[i+1][j], r[i][j-1]) + 1`.

### Pass 4: Bottom-Right to Top-Left (array `s`)
- Loops `i` from H down to 1, `j` from W down to 1.
- If `l[i][j]` is `'#'`, sets `s[i][j] = 0`.
- Otherwise, sets `s[i][j] = min(s[i+1][j], s[i][j+1]) + 1`.

### Final Computation
- Initializes `ans = 0`.
- Loops `i` from 1 to H, `j` from 1 to W:
  - Computes `n[i][j]` as the minimum of `p[i][j]`, `q[i][j]`, `r[i][j]`, and `s[i][j]` (using successive `min` calls).
  - Updates `ans = max(ans, n[i][j])`.

## Data Dependencies
- Each pass depends on previously computed values from adjacent cells in the direction of traversal.
- The final `n` value for each cell depends on all four directional arrays.
- The final answer depends on all cells' `n` values.
