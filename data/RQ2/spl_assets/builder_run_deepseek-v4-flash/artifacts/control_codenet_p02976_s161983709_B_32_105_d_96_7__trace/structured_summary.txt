### Input Handling Utilities
The code defines several input-reading helper functions:
- `LI()` reads a line and converts it to a list of integers.
- `I()` reads a single integer from a line.
- `LS()` reads a line and converts it to a list of character lists.
- `S()` reads a line, strips the newline, and returns it as a list of characters.
- `IR(n)` returns a list of `n` integers read one per line.
- `LIR(n)` returns a list of `n` lines, each parsed as a list of integers.
- `SR(n)` returns a list of `n` lines, each as a character list.
- `LSR(n)` returns a list of `n` lines, each parsed as a list of character lists.

The recursion limit is set to 1,000,000, and a global modulus constant is set to 1,000,000,007.

### Main Dispatch
The script's entry point calls function `B()` when run as the main module.

### Function A
- **Input**: Reads an integer `n` and then a list `a` of `n` integers.
- **Logic**: Computes the bitwise XOR of all elements in `a` into `ans`.
- **Output**: Prints "Yes" if `ans` is zero, otherwise prints "No".

### Function B
- **Input**: Reads two integers `n` and `m` from the first line. Then reads `m` pairs of integers `(a, b)`.
- **Data Structures**:
  - `v`: adjacency list of size `n`, initially empty lists.
  - `f`: degree array of size `n`, initialized to zeros.
  - `dic`: dictionary mapping undirected edges (both directions) to 1.
- **Graph Construction**: For each edge, decrements both endpoints by 1 (converting to 0-based indexing), adds each endpoint to the other's adjacency list, increments their degrees, and records both directed edge pairs in `dic`.
- **BFS Traversal**:
  - Initializes `ans` as an empty list, `d` as a zero array of size `n`, and a deque `q` starting with node 0.
  - `bfs` array marks visited nodes; node 0 is marked visited.
  - While `q` is non-empty, pops node `x`.
  - For each neighbor `y` of `x`:
    - If edge `(x,y)` exists in `dic`, adds `y` to a local list `s`.
    - If `y` is unvisited, marks it visited and pushes it onto `q`.
  - After collecting neighbors in `s`, processes them based on the parity of `len(s)` and the current value of `d[x]`:
    - If `len(s)` is odd:
      - If `d[x]` is non-zero: adds all edges `(x,y)` for `y` in `s` to `ans`, removes those edges from `dic`, and sets `d[x]` to 0.
      - If `d[x]` is zero: adds edges `(x,y)` for all but the last element of `s` to `ans`, removes them from `dic`, sets `d[x]` to 0, then takes the last element `y`, toggles `d[y]`, adds edge `(y,x)` to `ans`, and removes both directed edges from `dic`.
    - If `len(s)` is even:
      - If `d[x]` is zero: adds all edges `(x,y)` for `y` in `s` to `ans`, removes them from `dic`, and sets `d[x]` to 0.
      - If `d[x]` is non-zero: adds edges `(x,y)` for all but the last element of `s` to `ans`, removes them from `dic`, sets `d[x]` to 0, then takes the last element `y`, toggles `d[y]`, adds edge `(y,x)` to `ans`, and removes both directed edges from `dic`.
- **Output**: After BFS, if the sum of `d` is non-zero, prints `-1`. Otherwise, prints each edge in `ans` with 1-based indexing (one edge per line).

### Function C
- **Input**: Reads an integer `n`.
- **Logic**:
  - Creates a list `p` of powers of 2 from 2^0 to 2^99.
  - If `n` is itself a power of 2, prints "No" and exits.
  - If `n+1` is a power of 2, prints "Yes" and prints all edges `(i, i+1)` for `i`
