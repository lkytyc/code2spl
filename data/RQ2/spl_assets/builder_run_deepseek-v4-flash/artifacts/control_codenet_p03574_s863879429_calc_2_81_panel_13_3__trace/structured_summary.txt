# Code Description

## Function: `calc(h, w)`

### Inputs
- Integer `h` representing the number of rows
- Integer `w` representing the number of columns

### Local Data Structures
- A 2D integer array `panel` of size `h` by `w`
- A character array `row` of length `w`

### Phase 1: Grid Initialization
- Loops through each row index `i` from 0 to `h-1`
- For each row, reads a string via `scanf("%s", row)` (assumes input strings have no spaces)
- Loops through each column index `j` from 0 to `w-1`
- If the character at `row[j]` is `#`, sets `panel[i][j]` to `-1`
- Otherwise, sets `panel[i][j]` to `0`

### Phase 2: Neighbor Counting
- Loops through each cell in the grid using nested loops over `i` (rows) and `j` (columns)
- If `panel[i][j]` equals `-1` (a mine), skips to the next cell
- Otherwise, initializes a counter `count` to 0
- Checks all 8 neighboring positions (when within grid bounds) for cells containing `-1`:
  - Upper-left: `(i-1, j-1)` — checked only if `i-1 >= 0` and `j-1 >= 0`
  - Upper: `(i-1, j)` — checked only if `i-1 >= 0`
  - Upper-right: `(i-1, j+1)` — checked only if `i-1 >= 0` and `j+1 < w`
  - Left: `(i, j-1)` — checked only if `j-1 >= 0`
  - Right: `(i, j+1)` — checked only if `j+1 < w`
  - Lower-left: `(i+1, j-1)` — checked only if `i+1 < h` and `j-1 >= 0`
  - Lower: `(i+1, j)` — checked only if `i+1 < h`
  - Lower-right: `(i+1, j+1)` — checked only if `i+1 < h` and `j+1 < w`
- For each valid neighbor that equals `-1`, increments `count`
- After all checks, assigns `count` to `panel[i][j]`

### Phase 3: Output
- Loops through each cell using nested loops over `i` and `j`
- If `panel[i][j]` equals `-1`, prints `#`
- Otherwise, prints the integer value of `panel[i][j]`
- After each row, prints a newline character

### Return Value
- Always returns `0`

## Function: `main()`

### Inputs
- Reads two integers `h` and `w` via `scanf("%d %d", &h, &w)`

### Behavior
- Calls `calc(h, w)` with the read dimensions
- Returns `0`

## Control Flow Summary
- The program reads grid dimensions, then reads `h` strings of length `w` (each representing a row)
- It processes the grid to count adjacent mines for each non-mine cell
- It outputs the processed grid with `#` for mines and numeric counts for other cells
- No loops are infinite; all loops are bounded by `h` and `w`
- No error handling is present for invalid input or mismatched string lengths
