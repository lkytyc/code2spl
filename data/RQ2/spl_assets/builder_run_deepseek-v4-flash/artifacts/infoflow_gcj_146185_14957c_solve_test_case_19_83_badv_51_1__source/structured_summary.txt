## Overview
This program implements an interactive protocol solver that communicates with a judge or external system through standard input/output. It processes multiple test cases, each involving a sequence of card or value exchanges with specific state-dependent logic.

## Inputs
- First line: integer T representing number of test cases
- Subsequent lines: integers read during interactive exchanges, plus lines of space-separated integers read as sets
- Special input value -1 signals termination

## Outputs
- Lines formatted as "X Y" where X is a position/value and Y is a token value
- Debug messages written to stderr with timestamp

## Global Data
- ALLVALS: set of integers 1 through 99
- OT: dictionary mapping 19 to 20 and 20 to 19 (opposite values)

## Helper Functions
- debug(x): writes timestamped debug message to stderr
- read_int(): reads single integer from input
- read_float(): reads single float from input
- read_words(): reads whitespace-separated tokens
- read_ints(): reads line and converts to list of integers
- read_floats(): reads line and converts to list of floats

## Main Function
- Reads T from first input line
- Loops T times, calling solve_test_case() for each iteration

## solve_test_case() Logic

### Phase 1: Initial Value Acquisition (curd < 54)
- Initializes curd to 0
- Loops while curd is less than 54:
  - Reads integer curd from input
  - If curd equals -1, exits program
  - If curd > 36, sets token to 100
  - Otherwise, sets token to random integer between 1 and 99
  - Outputs position (1 + curd mod 18) and token value
  - Flushes output

### Phase 2: Bad Value Collection (curd < 72)
- Continues from previous curd value
- Loops while curd is less than 72:
  - Reads integer curd from input
  - If curd equals -1, exits program
  - Computes v as 1 + (curd mod 18)
  - Outputs v and 0
  - Flushes output
  - Sets offset to 0, or 1 if curd <= 63
  - Reads a line of integers, counts them, adds offset
  - Appends tuple (count + offset, v) to badv list

### Phase 3: Bad Value Processing
- Sorts badv list (by first element of tuples)
- Enters infinite loop:
  - Takes first tuple (i, x) from badv
  - Reads integer curd from input
  - If curd equals -1, exits program
  - Outputs x and random integer between 1 and 99
  - Updates badv[0] to (i+1, x)
  - Re-sorts badv
  - Flushes output
  - If curd equals 95, breaks loop

### Phase 4: Set Collection and Choice Determination
- Initializes lv, rv, choice to None
- Loops while curd is less than 99:
  - Reads integer curd from input
  - If curd equals -1, exits program
  - If lv is not set (falsy):
    - Outputs "19 0"
    - Flushes output
    - Reads line of integers into lv as a set
    - Continues to next iteration
  - If rv is not set (falsy):
    - Outputs "20 0"
    - Flushes output
    - Reads line of integers into rv as a set
    - If choice not yet determined:
      - Sets choice to 19 if len(lv) > len(rv)
      - Otherwise sets choice to 20
    - Continues to next iteration
  - Otherwise (both sets collected):
    - Outputs choice and random integer between 1 and 99
    - Flushes output

### Phase 5: Final Exchange
- Sets choice to OT[choice] (swaps 19↔20)
- Reads integer curd from input
- If curd equals -1, exits program
- Outputs choice and 100
- Flushes output

## Control Flow Summary
- Program exits immediately upon reading -1 at any input point
- Random values are used for tokens in phases 1, 3, and 4
- Phase 2 collects data based on input values and line lengths
- Phase 3 processes collected data in sorted order with updates
- Phase 4 collects two sets and makes a size-based choice
- Phase 5 performs final swap and output

## Data Dependencies
- Phase 2 depends on curd values
