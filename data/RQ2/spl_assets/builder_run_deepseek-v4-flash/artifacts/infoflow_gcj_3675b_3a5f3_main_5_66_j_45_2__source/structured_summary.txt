## Inputs
- Reads an integer `ntests` from standard input, representing the number of test cases.
- For each test case, reads an integer `s` (the number of elements in that case).
- For each of the `s` elements, reads three long integers: `D[i]`, `A[i]`, and `B[i]`.

## Outputs
- For each test case, prints a line in the format: `Case #<test>: <max> <max_no>`
  - `<test>` is the 1-based test case number.
  - `<max>` is the maximum value found among computed lengths.
  - `<max_no>` is the count of positions achieving that maximum.

## Data Structures
- Arrays `D`, `A`, `B`, `M`, `N` are long integer arrays of size `MAXS` (10005).
- Arrays `longm` and `longn` are integer arrays of size `MAXS`.
- `M[i]` is computed as `D[i] + A[i]`.
- `N[i]` is computed as `D[i] - B[i]`.

## Processing Logic

### Per Test Case:
1. Read `s` and populate arrays `D`, `A`, `B`, then compute `M` and `N` for each index.

2. Initialize:
   - `longm[0] = 1`
   - `longn[0] = 1`

3. For each index `i` from 1 to `s-1`:
   - **For `longm[i]`:**
     - If `M[i] == M[i-1]`, then `longm[i] = longm[i-1] + 1`.
     - Otherwise, set `longm[i] = 2` and then look backward from `j = i-2` while `j >= 0` and either `M[j] == M[i]` or `N[j] == N[i-1]`. For each such `j`, increment `longm[i]` and decrement `j`.
   
   - **For `longn[i]`:**
     - If `N[i] == N[i-1]`, then `longn[i] = longn[i-1] + 1`.
     - Otherwise, set `longn[i] = 2` and then look backward from `j = i-2` while `j >= 0` and either `N[j] == N[i]` or `M[j] == M[i-1]`. For each such `j`, increment `longn[i]` and decrement `j`.

4. After computing all `longm` and `longn` values:
   - Initialize `max` as the larger of `longm[0]` and `longn[0]` (using the `getmax` function).
   - Initialize `max_no = 1`.
   - For each index `i` from 1 to `s-1`:
     - Compute `current = getmax(longm[i], longn[i])`.
     - If `current > max`, update `max = current` and reset `max_no = 1`.
     - Else if `current == max`, increment `max_no`.

5. Print the result for the test case.

## Helper Function
- `getmax(a, b)`: Returns `a` if `a > b`, otherwise returns `b`. Used to find the larger of two long integers.

## Control Flow Summary
- Outer loop iterates over test cases (1 to `ntests`).
- Inner loop reads input data for each element.
- A second inner loop computes `longm` and `longn` values with conditional branches and backward-scanning while loops.
- A final loop scans all computed values to find the maximum and count occurrences.
- No recursion or additional function calls beyond `getmax`.

## Data Dependencies
- `M[i]` depends on `D[i]` and `A[i]`.
- `N[i]` depends on `D[i]` and `B[i]`.
- `longm[i]` depends on `M` values at current and previous indices, and on `N` values at earlier indices during backward scans.
- `longn[i]` depends on `N` values at current and previous indices, and on `M` values at earlier indices during backward scans.
- Final `max` and `max_no` depend on all `longm` and `longn` values.
