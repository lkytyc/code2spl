# Structured Description of Code

## Class Overview
The `Main` class contains multiple problem-solving methods (AOJ0144, AOJ0145, AOJ0147) and supporting inner classes. It uses a `Scanner` for input and static imports for `Math` functions and `System.out`.

## Global Fields
- `sc`: A `Scanner` object for reading input
- `vx`, `vy`: Integer arrays representing directional vectors (0,1), (1,0), (0,-1), (-1,0)

## Inner Class: Point

- Constructors: Parameterized (x,y) and default (0,0)
- `toString()`: Returns coordinates in format "(x,y)"
- Static method `ok(x,y,X,Y,min)`: Returns true if x is in range [min, X) and y is in range [min, Y)
- Static method `ok(x,y,X,Y)`: Calls the 5-parameter version with min=0

## Method: AOJ0145
- **Input**: Reads pairs of integers (N times) from scanner
- **Process**: Creates an array of `C0145` objects with upper and down values
- **Output**: Prints `Integer.MAX_VALUE` for each test case
- **Loop**: Continues while scanner has more input

## Inner Class: C0145
- Fields: `upper`, `down` (integers)
- Constructor: Takes two integers and assigns them

## Method: AOJ0147
- **Input**: Reads integers from scanner until EOF, storing them in a queue
- **Initialization**: 
  - Sets MAX to at least 120, updating with maximum input value
  - Creates arrays for num, time, and seat (size 17, initialized to -1)
  - Precomputes num[i] = 5 if i%5==1, otherwise 2
  - Precomputes time[i] = 17*(i%2) + 3*(i%3) + 19
- **Main Loop**: While queue is not empty:
  - Calls `exit()` to free seats whose time has elapsed
  - Calls `find()` to locate available consecutive seats
  - If seats found and time condition met (min >= j*5):
    - Checks if current group matches queue front
    - If match, prints waiting time and removes from queue
    - Occupies seats for current group
    - Increments group counter j
  - Otherwise increments time counter min

## Method: find(seat, n)
- **Purpose**: Finds first contiguous block of n empty seats
- **Process**: Iterates through positions 0 to 17-n, checking if all n consecutive seats are -1
- **Returns**: Starting index if found, otherwise -1

## Method: exit(seat, min, time)
- **Purpose**: Frees seats whose departure time has arrived
- **Process**: For each occupied seat, calculates departure time as idx*5 + time[seat[i]]
- **Returns**: Updated seat array with freed positions set to -1

## Method: disp(seat, min)
- **Purpose**: Debug output showing current seat occupancy
- **Output**: Prints time and seat array contents

## Method: AOJ0144
- **Input**: 
  - First reads N (number of nodes)
  - For each node i (1 to N): reads node ID r, degree k, then k destination nodes
  - Then reads P (number of queries)
  - For each query: reads source s, destination d, and max hops v
- **Graph Representation**: Boolean adjacency matrix R[N+1][N+1]
- **Search Algorithm**: Priority queue-based search (Dijkstra-like)
  - Priority queue ordered by cost (number of hops)
  - Each state tracks: current node, remaining TTL (time-to-live), cost so far
  - Closed list stores best known state for each node
- **Search Process**:
  - Starts with source node, TTL=v, cost=1
  - While queue not empty:
    - Pops lowest-cost state
    - Decrements TTL; skips if TTL becomes 0
    - For each neighbor:
      - If neighbor not in closed list:
        - If neighbor is destination, updates answer
        - Otherwise adds to queue and closed list
      - If neighbor in closed list but new state is better (lower cost OR higher TTL):
        - Updates if destination, otherwise adds to queue and updates closed list
- **Output**: Prints answer (minimum hops) or "NA" if unreachable within TTL
