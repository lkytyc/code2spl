## Function: bfs

### Inputs
- `sx`, `sy`: integer coordinates representing the starting position
- `spx`, `spy`: integer arrays of equal length representing a sequence of target positions

### Outputs
- Returns `true` if all target positions can be reached in sequence
- Returns `false` if the traversal fails before reaching all targets

### Local Variables
- `size` = 10 (fixed grid dimension)
- `spCnt` = 0 (index tracking current target position)
- `dx`, `dy`: arrays of 12 movement offsets (knight-like moves)
- `dx2`, `dy2`: arrays of 9 offsets (3x3 neighborhood including center)
- `park`: 10x10 boolean grid marking blocked cells
- `queueX`, `queueY`: queues for BFS frontier

### Control Flow
1. Initialize queues with starting coordinates
2. **Main loop** (while queue is not empty):
   - If `spCnt` equals the length of `spx`, return `true` (all targets reached)
   - Mark the 3x3 neighborhood around the current target position as blocked in `park`
   - **Inner loop**: Process all cells in current queue:
     - For each cell, try all 12 movement offsets
     - If the resulting position is within bounds (0-9) AND is marked as blocked in `park`, add it to new queues
   - Increment `spCnt`
   - Reset `park` to all false
   - Replace current queues with new queues
3. If loop exits (queue becomes empty), return `false`

### Key Logic
- The BFS only allows movement to cells that are currently marked as blocked (the 3x3 area around the current target)
- After each BFS layer, the target index advances and the blocked area moves to the next target
- The grid is 10x10 with coordinates 0-9 in both dimensions

## Function: main

### Inputs
- Reads from standard input using Scanner

### Outputs
- Prints "OK" if bfs returns true, "NA" if false

### Control Flow
1. **Infinite loop** (while true):
   - Read `sx` and `sy` from input
   - If both are 0, break the loop
   - Read `n` (number of target positions)
   - Read `n` pairs of coordinates into `spx` and `spy` arrays
   - Call `bfs(sx, sy, spx, spy)` and print result

### Data Dependencies
- The main loop reads input in a specific order: start coordinates, then count, then coordinate pairs
- The bfs function depends on the start position and the sequence of target positions
