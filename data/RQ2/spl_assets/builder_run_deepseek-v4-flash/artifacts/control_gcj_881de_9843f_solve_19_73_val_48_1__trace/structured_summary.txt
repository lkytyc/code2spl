## Inputs
- Standard input stream, read using a Scanner
- First integer read is T, the number of test cases
- For each test case, three integers are read: N (number of servers), B (number of broken servers), F (number of queries allowed)
- After each query, a string response is read from input
- After outputting the answer for a test case, an integer is read (expected to be -1 to continue)

## Outputs
- For each test case, outputs F lines of binary strings (each of length N) as queries
- After all queries, outputs a line containing the indices of broken servers, space-separated
- Output is flushed after each query line and after the final answer line

## Control Flow

### Main method
- Creates Scanner for System.in and PrintWriter for System.out
- Instantiates Task and calls solve with test number 1
- Closes the PrintWriter

### Task.solve method
- Reads T from input
- Loops through each test case (t from 1 to T)

#### Query generation phase (for each test case)
- Reads N, B, F
- Creates an empty list to store reply strings
- For each query i (from 0 to F-1):
  - Computes k = 1 shifted left by i (bit mask)
  - For each position j (from 0 to N-1):
    - If (j AND k) equals 0, prints '0'
    - Otherwise prints '1'
  - Prints newline and flushes
  - Reads the reply string and adds it to the reply list

#### Answer computation phase
- Initializes p = 0 (position pointer), first = true (formatting flag), i = 0
- Loop while i < N AND (p + B) < N:
  - Builds a binary string by reading characters at position p from each reply string, from the last reply (F-1) down to the first (0)
  - Converts this binary string to an integer value (val)
  - If val is not equal to i:
    - Loops from i up to (but not including) val:
      - Prints each index, with a space separator before all but the first
      - Marks first as false
  - Increments p
- After the loop, for any remaining indices from i to N-1:
  - Prints each index with proper spacing
- Prints newline and flushes
- Reads next integer from input; if it equals -1, returns from solve (ending all processing)

## Data Dependencies
- The reply strings collected during the query phase are used in the answer computation phase
- The binary value constructed from reply characters at position p determines which indices are reported as broken
- The loop condition depends on N, B, and the current position p
- The final loop handles remaining indices after the main loop terminates

## Key Logic
- The queries use a binary counting pattern where each query i tests bit i of each server index
- The replies indicate which servers responded (0) or failed (1) for each bit pattern
- By reading the reply bits in reverse order (from query F-1 down to 0), a binary number is formed representing the index of the first broken server
- The algorithm identifies broken server indices by comparing expected values with actual values from the replies
- The loop continues until either all N servers are processed or the remaining unprocessed count equals B (the number of broken servers)
