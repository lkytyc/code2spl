# Code Structure Description

## Overview
This Java code contains two classes: `Solution` and `Longest_common_substr`. Both classes have `main` methods and process word lists, but they perform different operations.

## Class: Solution

### Input
- Reads an integer `tc` from standard input representing the number of test cases
- For each test case, reads an integer `noOfWords` representing the number of words
- Reads `noOfWords` strings from standard input

### Processing
- Stores all words in a `TreeSet` (automatically sorted, duplicates removed)
- Creates two iterators over the same set: `wrd1` and `wrd2`
- Initializes counter `c1` to 0

### Control Flow
- Outer loop: iterates through `wrd1` while it has elements
  - Increments `c1` for each word
  - Initializes `c2` to 0 and `result` to 0 for each outer iteration
  - Gets the current word from `wrd1` as `wordOne`
  - Inner loop: iterates through `wrd2` while it has elements
    - Increments `c2` for each word
    - Checks if `c1` is not equal to `c2` (to avoid comparing a word with itself)
    - If different positions, gets `wordTwo` from `wrd2`
    - Nested loops: for each possible substring of `wordTwo` (starting at position `l`, ending at position `k` where `k` starts at `l+2` and goes to the end of the word)
      - Checks if `wordOne` contains that substring and if the substring length is greater than current maximum
      - If yes, updates maximum length and stores the substring as `key`
      - If no, breaks out of the inner substring loop

### Output
- No output is produced by this class

## Class: Longest_common_substr

### Method: printLCSubStr
- **Parameters**: Two strings `X` and `Y`, and their lengths `m` and `n`
- **Purpose**: Computes the length of the longest common substring between two strings
- **Algorithm**: Uses dynamic programming with a 2D array `LCSuff`
  - Initializes a matrix of size (m+1) × (n+1)
  - Fills the matrix where `LCSuff[i][j]` represents the length of the longest common suffix ending at position i in X and j in Y
  - Tracks the maximum length found and its position (row, col)
  - If maximum length is 0, returns 0
  - Otherwise, reconstructs the substring by tracing back through the matrix
  - Returns the length of the longest common substring

### Main Method

#### Input
- Reads an integer `tc` from standard input representing the number of test cases
- For each test case (indexed from 1 to tc):
  - Reads an integer `noOfWords` representing the number of words
  - Reads `noOfWords` strings from standard input

#### Processing
- Stores all words in a `TreeSet` (sorted, no duplicates)
- Creates two iterators over the set: `wrd1` and `wrd2`
- Initializes `c1` to 0 and `result` to 0

#### Control Flow
- Outer loop: iterates through `wrd1` while it has elements
  - Initializes `max` to 0, and empty strings `key1` and `key2`
  - Gets current word as `w1`
  - Checks if `w1` equals `key1`; if so, removes it from the set and returns immediately
  - Inner loop: iterates through `wrd2` while it has elements
    - Gets current word as `w2`
    - Checks if `w2` equals `key2`; if so, removes it from the set and returns immediately
    - Calls `printLCSubStr(w1, w2, w1.length(), w2.length())` to get the longest common substring length
    - If this length is greater than current `max`, updates `key1`, `key2`, and `max`
  - Adds `max` to the running `result` total

#### Output
- For each test case, prints: `"Case #" + i + ": " + result` where `i` is the test case number
