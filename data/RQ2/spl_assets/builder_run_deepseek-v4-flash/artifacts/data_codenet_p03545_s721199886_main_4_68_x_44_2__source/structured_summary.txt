## Inputs
- Reads a single integer `n` from standard input using `scanf`.

## Outputs
- Prints an arithmetic expression in the format: `a op1 b op2 c op3 d = 7`, where `a`, `b`, `c`, `d` are digits derived from the input number, and `op1`, `op2`, `op3` are either `+` or `-` characters.

## Data Extraction
- Extracts four digits from the input number `n`:
  - `a` = thousands digit
  - `b` = hundreds digit
  - `c` = tens digit
  - `d` = units digit

## Main Control Flow

### Initialization
- Sets `cnt = 0`
- Defines an operator array `op` containing `'+'` and `'-'`

### Main Loop (infinite loop with break condition)
- Resets `x`, `op1`, `op2`, `op3` to 0 at the start of each iteration
- Runs an inner loop exactly 3 times (i = 0, 1, 2)

### Inner Loop Logic (3 iterations)
The inner loop builds an expression by applying operations sequentially. The behavior depends on the current value of `cnt`:

**Case 1: `cnt < 3` or `cnt == 4`**
- First operation: `x = a + b`
- If `cnt < 2`:
  - Second operation: `x = x + c`
  - If `cnt == 0`: Third operation: `x = x + d`, `op3` stays 0
  - If `cnt == 1`: Third operation: `x = x - d`, `op3 = 1`
- If `cnt >= 2` (i.e., `cnt == 2` or `cnt == 4`):
  - Second operation: `x = x - c`, `op2 = 1`
  - If `cnt == 2`: Third operation: `x = x + d`
  - If `cnt == 4`: Third operation: `x = x - d`, `op3 = 1`

**Case 2: `cnt == 3`, `cnt == 5`, or `cnt == 6`**
- First operation: `x = a - b`, `op1 = 1`
- If `cnt == 3` or `cnt == 6`:
  - Second operation: `x = x + c`
  - If `cnt == 3`: Third operation: `x = x + d`
  - If `cnt == 6`: Third operation: `x = x - d`, `op3 = 1`
- If `cnt == 5`:
  - Second operation: `x = x - c`, `op2 = 1`
  - Third operation: `x = x + d`

### Loop Termination
- After the inner loop completes, checks if `x == 7`
- If true, breaks out of the outer loop
- If false, increments `cnt` and repeats

## Function Calls
- `sum(a, b)`: Returns `a + b`
- `sub(a, b)`: Returns `a - b`

## Operator Selection
- `op1` is 0 for `+`, 1 for `-` (set to 1 only when first operation is subtraction)
- `op2` is 0 for `+`, 1 for `-` (set to 1 only when second operation is subtraction)
- `op3` is 0 for `+`, 1 for `-` (set to 1 only when third operation is subtraction)

## Final Output
- Prints the expression using the original digits `a`, `b`, `c`, `d` and the selected operators, followed by `=7`

## Data Dependencies
- The loop counter `cnt` determines which combination of operations is tested
- The value of `x` after all three operations determines whether the loop continues
- The operator flags (`op1`, `op2`, `op3`) are set based on which branch was taken during the inner loop
