## Function: bfs

### Inputs
- `sx`, `sy`: integer starting coordinates
- `spx`, `spy`: integer arrays of obstacle coordinates

### Outputs
- Returns `true` if a path exists, `false` otherwise

### Local Variables
- `size` = 10 (grid dimensions)
- `spCnt` = 0 (obstacle index counter)
- `dx`, `dy`: 12-element movement arrays for knight-like moves
- `dx2`, `dy2`: 9-element arrays for marking obstacle areas
- `park`: 10x10 boolean grid (initially all false)
- Two queues for X and Y coordinates

### Control Flow

**Initialization:**
- Creates empty 10x10 boolean grid
- Adds starting coordinates to both queues

**Main loop (while queueX not empty):**
1. **Early exit check:** If `spCnt` equals the length of `spx`, return `true`
2. **Obstacle marking:** For the current obstacle at index `spCnt`, mark all 9 positions in a 3x3 pattern around it as `true` in the park grid (using dx2/dy2 offsets)
3. **Process current queue:** 
   - Create new empty queues `nx` and `ny`
   - While current queue is not empty:
     - Poll coordinates from both queues
     - For each of the 12 movement directions:
       - Calculate next position
       - If next position is within bounds (0-9 for both x and y) AND the park grid at that position is `true`, add to new queues
4. **Update state:**
   - Increment `spCnt`
   - Reset park grid to all `false`
   - Replace current queues with new queues

**Termination:**
- Returns `false` if queue becomes empty before all obstacles processed

### Data Dependencies
- Movement validity depends on both grid bounds and obstacle marking
- Obstacle marking depends on current `spCnt` index
- Queue contents depend on previous iteration's valid moves

## Function: main

### Inputs
- Reads from standard input via Scanner

### Control Flow
1. **Infinite loop** until break condition:
   - Read `sx` and `sy` integers
   - If both are 0, break the loop
   - Read `n` (number of obstacles)
   - Read `n` pairs of obstacle coordinates into arrays
   - Call `bfs` with starting coordinates and obstacle arrays
   - Print "OK" if bfs returns true, "NA" otherwise

### Input Format
- Multiple test cases, each with:
  - Starting X and Y coordinates
  - Integer `n` for obstacle count
  - `n` lines of obstacle X and Y coordinates
- Terminated by line with "0 0"

### Output
- For each test case: prints "OK" or "NA" on separate lines
