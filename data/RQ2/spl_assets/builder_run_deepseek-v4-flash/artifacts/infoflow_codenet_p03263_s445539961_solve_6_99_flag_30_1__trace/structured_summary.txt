# Code Description

## Overview
This program reads a 2D grid of integers, identifies cells with odd values, and outputs a sequence of moves that pairs up odd-valued cells by moving through adjacent cells in a snake-like pattern.

## Input
- Two integers `h` and `w` representing grid dimensions (rows and columns)
- An `h` × `w` grid of integers

## Output
- First line: number of moves (pairs of coordinates)
- Following lines: pairs of coordinates (row, column) in 1-based indexing, with two coordinates per line representing a move from one cell to another

## Main Algorithm

### Data Structures
- 2D integer array `a` storing the grid values
- Lists `x` and `y` storing column and row coordinates respectively for move endpoints
- Boolean `flag` tracking whether an odd cell is currently being carried
- Integer variables `prex` and `prey` storing the previous cell coordinates
- Boolean `odd` indicating whether the current cell value is odd

### Grid Traversal
The grid is traversed in a snake pattern:
- Even-indexed rows (0, 2, 4, ...) are traversed left-to-right (columns 0 to w-1)
- Odd-indexed rows (1, 3, 5, ...) are traversed right-to-left (columns w-1 to 0)

### Cell Processing Logic
For each cell in traversal order:
1. Determine if the cell value is odd or even
2. Apply one of four cases based on current cell parity and `flag` state:
   - **Odd cell + flag true**: Toggle flag to false, record a move from previous cell to current cell, update previous cell to current
   - **Odd cell + flag false**: Toggle flag to true, set previous cell to current (start carrying)
   - **Even cell + flag true**: Record a move from previous cell to current cell, update previous cell to current (continue carrying through even cells)
   - **Even cell + flag false**: Do nothing (no move recorded)

### Move Recording
When a move is recorded, four values are appended to the lists:
- Previous column (`prex`) and previous row (`prey`)
- Current column (`j`) and current row (`i`)

### Output Generation
- Print the number of moves as `x.size() / 2` (each move uses 2 coordinate pairs)
- Iterate through the coordinate lists in pairs:
  - Even indices (0, 2, 4, ...): print row+1, space, column+1, space (no newline)
  - Odd indices (1, 3, 5, ...): print row+1, space, column+1, newline

## Helper Classes

### Scanner Class
Custom scanner with buffered reading:
- `nextInt()`: Parses integers with optional sign, handles overflow checking
- `nextLong()`: Similar to nextInt but for long values
- `next()`: Reads printable character sequences
- `nextLine()`: Reads until newline or carriage return
- `nextFloat()`/`nextDouble()`: Parse via standard library
- Uses `isPrintable()` to identify characters in range '!' to '~'
- Throws `NoSuchElementException` on end of input or I/O errors

### Printer Class
Extends `PrintWriter` for output operations.

## Program Flow
1. Initialize scanner and printer
2. Call `solve()` method
3. Close printer and scanner

## Key Dependencies
- The algorithm depends on the snake-pattern traversal to ensure moves connect adjacent cells
- The `flag` variable tracks whether an odd cell is being "carried" through the grid
- Moves are only recorded when transitioning between cells while carrying an odd value
