## Overview
This program reads a number of test cases, and for each test case reads an integer `n` and outputs a sequence of coordinate pairs representing a path in a grid. The output format is "Case #X:" followed by coordinate pairs.

## Inputs
- First input: integer `t` (number of test cases)
- For each test case: integer `n`

## Outputs
- For each test case, prints "Case #X:" where X is the test case number (starting from 1)
- Then prints a sequence of coordinate pairs, each on its own line, in the format "row column"

## Main Control Flow

### Test Case Loop
- Iterates from `cs = 1` to `cs = t`
- For each test case:
  - Reads integer `n`
  - Stores original value in `sn`
  - Prints "Case #cs:"

### Determining Length `l`
- Initializes `w = 0`
- Loops `i` from 1 to 49:
  - Adds `(1 << (i-1))` to `w`
  - If `w >= n`, sets `l = i` and breaks out of loop

### Building Flag Array
- Loops `i` from `l` down to 1:
  - If `n >= (1 << (i-1)) + (i-1)`:
    - Sets `fl[i] = 1`
    - Subtracts `(1 << (i-1))` from `n`
  - Otherwise:
    - Sets `fl[i] = 0`
    - Decrements `n` by 1

### Output Generation
- Initializes `a = 0` and `w = 0`
- Loops `i` from 1 to `l`:
  - If `fl[i] == 1`:
    - Adds `(1 << (i-1))` to `w`
    - If `a == 0`: prints coordinates (i, 1), (i, 2), ..., (i, i) in increasing column order
    - If `a != 0`: prints coordinates (i, i), (i, i-1), ..., (i, 1) in decreasing column order
    - Toggles `a` (sets `a = 1 - a`)
  - If `fl[i] == 0`:
    - Increments `w` by 1
    - If `a == 0`: prints (i, 1)
    - If `a != 0`: prints (i, i)

### Final Adjustment Loop
- While `w != sn`:
  - Increments `l`
  - If `a == 0`: prints (l, 1)
  - If `a != 0`: prints (l, l)
  - Increments `w`

## Helper Functions (defined but not called in main)
The code defines numerous utility functions that are not invoked by the main program:
- Integer arithmetic: max, min, absolute difference, rounding, ceiling, gcd, lcm, combinations, permutations, factorial, power, digit sum, triangular numbers
- Long long variants of the same arithmetic functions
- Double variants: max, min, absolute difference, swap
- Character swap function
- Comparison functions for qsort (ascending/descending for int, long long, double, string, char)
- Array shuffling function using rand()
- Binary search function for sorted arrays
- Array printing function
- Random permutation generator
- Coordinate compression function using qsort with a struct

## Data Dependencies
- The flag array `fl` determines which rows get full diagonal output versus single coordinate output
- The variable `a` tracks direction (alternating between 0 and 1) and affects both column ordering and which single coordinate is printed
- The value `w` tracks cumulative output count and is compared against the original input `sn`
- The variable `l` is modified in both the flag-building loop and the final adjustment loop
