# Function: get_next_location(num_of_people)

## Input
- `num_of_people`: an integer specifying how many location entries to read.

## Processing
1. Initializes an empty list `coordinates_list` and sets `people_count` to 1.
2. Loops while `people_count` is less than or equal to `num_of_people`:
   - Reads a line of input via `raw_input`.
   - Splits the line into tokens.
   - Parses the first token as integer `x`, second as integer `y`, and third as string `dir`.
   - Applies directional movement:
     - If `dir` equals "N", increments `y` by 1.
     - If `dir` equals "S", decrements `y` by 1.
     - If `dir` equals "E", increments `x` by 1.
     - If `dir` equals "W", decrements `x` by 1.
   - Creates a two-element list `[x, y]` and appends it to `coordinates_list`.
   - Increments `people_count` by 1.
3. Initializes empty lists `next_dest` and `next_dest_count`.
4. Iterates over each coordinate pair in `coordinates_list`:
   - Sets `found` to 0 and `dest_idx` to 0.
   - Iterates over existing entries in `next_dest`:
     - If the current coordinate equals an existing destination, increments the corresponding count in `next_dest_count`, sets `found` to 1, and breaks.
     - Otherwise increments `dest_idx`.
   - If `found` is still 0, appends the coordinate to `next_dest` and appends 1 to `next_dest_count`.
5. Initializes `popular_next_dest` with the first destination and `highest_count` with its count.
6. Iterates over `next_dest_count` starting from index 1:
   - Skips index 0 (already handled).
   - If current count equals `highest_count`, appends the corresponding destination to `popular_next_dest`.
   - If current count is greater than `highest_count`, resets `popular_next_dest` to a new list, updates `highest_count`, and appends the current destination.
7. After counting, if `popular_next_dest` has exactly one element, returns that element.
8. Otherwise, finds the smallest coordinate pair (lexicographically by list comparison) among `popular_next_dest` and returns it.

## Output
- Returns a two-element list `[x, y]` representing the most frequent next location, with ties broken by choosing the smallest coordinate pair.

# Function: generate_test_cases(T)

## Input
- `T`: an integer specifying the number of test cases.

## Processing
1. Sets `count` to 1.
2. Loops while `count` is less than or equal to `T`:
   - Reads a line via `raw_input`.
   - Splits the line into tokens.
   - Parses first token as integer `num_of_people` and second as integer `max_grid_size` (the latter is read but not used).
   - Calls `get_next_location(num_of_people)` and stores the result in `coordinates`.
   - Extracts `x` and `y` from the returned list.
   - Prints `"Case #" + str(count) + ": " + str(x) + " " + str(y)`.
   - Increments `count` by 1.

## Output
- Prints one line per test case in the format `Case #<number>: <x> <y>`.

# Main Execution

## Input
- Reads a single line via `raw_input` and evaluates it as a Python expression using `eval`, then converts to integer with `int`.

## Processing
- Calls `generate_test_cases` with that integer value.

## Output
- The output is produced by `generate_test_cases` as described above.

# Data Dependencies
- `get_next_location` depends on `num_of_people` and reads from standard input.
- `generate_test_cases` depends on `T` and reads from standard input; it calls `get_next_location`.
- The main execution depends on the evaluated input value and calls `generate_test_cases`.

# Control Flow Summary
- Loops: while loops in both functions; nested for loops in `get_next_location` for counting and tie-breaking.
- Branches: directional checks (N/S/E/W), equality and greater-than comparisons for counts, and a final length check for tie-breaking.
- Function calls: `get_next_location` is called from `generate_test_cases`; `generate_test_cases` is called from main.
