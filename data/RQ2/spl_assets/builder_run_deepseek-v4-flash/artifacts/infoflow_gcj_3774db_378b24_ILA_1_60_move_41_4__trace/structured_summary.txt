## Function: ILA(s, t)

### Inputs
- `s`: a string
- `t`: a string

### Outputs
- Returns a string from the `path` list at index `target`

### Data Structures
- `rows`: length of `s` plus 1
- `cols`: length of `t` plus 1
- `dist`: 2D list of size rows × cols, initialized to zeros
- `choice`: 2D list of size rows × cols, initialized to zeros
- `path`: list of strings, size `time + 1`
- `c_s`: list of characters from `s`
- `c_t`: list of characters from `t`
- `suffix`: list of characters, initially empty

### Initialization
- First row of `dist` and `choice` are set: for each column, `dist[0][col] = col` and `choice[0][col] = 'I'`
- First column of `dist` and `choice` are set: for each row, `dist[row][0] = row` and `choice[row][0] = 'D'`

### Main Dynamic Programming Loop
- Nested loops iterate over columns (outer) and rows (inner), both starting from index 1
- For each cell, computes substitution cost: 0 if characters match, 1 otherwise
- Computes minimum of three values:
  - Deletion cost: `dist[row-1][col] + 1`
  - Insertion cost: `dist[row][col-1] + 1`
  - Substitution cost: `dist[row-1][col-1] + subs`
- Stores minimum in `dist[row][col]`
- Sets `choice[row][col]` based on which operation produced the minimum:
  - If equals deletion cost: 'D'
  - Else if equals insertion cost: 'I'
  - Else if substitution cost was 1: 'S'
  - Else (substitution cost was 0): 'N'

### Post-Processing
- `time` = value of `dist[row][col]` after loops complete (last computed cell)
- `target` = integer division of `time` by 2
- `path` initialized with `None` values, size `time + 1`
- `path[0]` = original string `s`
- `path[time]` = original string `t`

### Path Reconstruction Loop
- Runs while `end >= start` (start = 1, end = time - 1)
- Each iteration examines `choice[len(c_s)][len(c_t)]`:
  - **'D' (deletion)**: removes last character from `c_s`, sets `path[start]` to current `c_s` plus `suffix`, increments `start`
  - **'I' (insertion)**: removes last character from `c_t`, sets `path[end]` to current `c_t` plus `suffix`, decrements `end`
  - **'S' (substitution)**: prepends last character of `c_t` to `suffix`, removes last characters from both `c_s` and `c_t`, sets `path[start]` to current `c_s` plus `suffix`, increments `start`
  - **'N' (no change)**: prepends last character of `c_t` to `suffix`, removes last characters from both `c_s` and `c_t` (no path assignment)

### Return Value
- Returns `path[target]`, the string at the middle index of the path

## Function: solve_case(C, J)

### Inputs
- `C`: a string
- `J`: a string

### Outputs
- Returns the result of calling `ILA(C, J)`

## Function: main()

### Inputs
- Reads from standard input:
  - First line: integer `T` (number of test cases)
  - For each test case: a line with two space-separated strings `C` and `J`

### Outputs
- For each test case, prints: `Case #<case_no>: <ans>` where `<ans>` is the result of `solve_case(C, J)`

### Control Flow
- Loops from case 1 to T inclusive
- For each case, splits input line on space to get `C` and `J`
- Calls `solve_case` and prints formatted result

### Function Calls
- `main()` calls `solve_case` for each test case
- `solve_case` calls `ILA` once
- `ILA` uses built-in functions: `len`, `range`, `min`, `list`, `join`, `int`
