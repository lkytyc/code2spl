## Function: modpow

**Inputs:** Three long long integers: `a`, `n`, `p`.

**Output:** A long long integer result.

**Behavior:**
- If `n` is negative, returns 0 immediately.
- Otherwise, performs modular exponentiation: computes `a` raised to the power `n`, modulo `p`, using the fast exponentiation method (binary exponentiation).
- Uses a loop that continues while `n` is greater than 0.
- Inside the loop, if `n` is odd, multiplies the running result by `a` and takes modulo `p`.
- Always squares `a` and takes modulo `p`, then divides `n` by 2 (integer division).
- Returns the final result.

## Main Function

**Input:** Reads a string `s` from standard input using `scanf` with `%s` format (no spaces).

**Output:** Prints a single long long integer to standard output.

### Variable Initialization
- Declares `s` as a character array of size 100005.
- Declares `n` as the length of the input string.
- Declares two arrays `ca` and `cha` of size 100005 for prefix counts.
- Declares two arrays `cc` and `chc` of size 100005 for suffix counts.
- Sets `ca[0]` and `cha[0]` to 0.

### Prefix Counting Loop
- Iterates through the string from index 0 to `n-1`.
- For each character:
  - If it is 'A': increments `ca` at the next position by 1, carries forward `cha` unchanged.
  - If it is '?': carries forward `ca` unchanged, increments `cha` at the next position by 1.
  - Otherwise (any other character): carries forward both `ca` and `cha` unchanged.
- After this loop, `ca[i]` contains the count of 'A' characters in positions 0 through `i-1`, and `cha[i]` contains the count of '?' characters in positions 0 through `i-1`.

### Suffix Counting Loop
- Sets `cc[n]` and `chc[n]` to 0.
- Iterates through the string from index `n-1` down to 0.
- For each character:
  - If it is 'C': increments `cc` at the current position by 1 (relative to the next position), carries forward `chc` unchanged.
  - If it is '?': carries forward `cc` unchanged, increments `chc` at the current position by 1.
  - Otherwise: carries forward both `cc` and `chc` unchanged.
- After this loop, `cc[i]` contains the count of 'C' characters in positions `i` through `n-1`, and `chc[i]` contains the count of '?' characters in positions `i` through `n-1`.

### Main Computation
- Sets `p` to 1000000007 (a prime number).
- Initializes `ans` to 0.
- Iterates through the string from index 0 to `n-1`.
- For each position `i` where the character is either 'B' or '?':
  - Computes a left-side value: `ca[i] * modpow(3, cha[i], p) + cha[i] * modpow(3, cha[i] - 1, p)`, all taken modulo `p`.
  - Computes a right-side value: `cc[i+1] * modpow(3, chc[i+1], p) + chc[i+1] * modpow(3, chc[i+1] - 1, p)`, all taken modulo `p`.
  - Multiplies the left-side value by the right-side value, adds this product to `ans`, and takes modulo `p`.
- Note: When `cha[i]` is 0, `modpow(3, -1, p)` is called, which returns 0 due to the negative exponent check in `modpow`. Similarly for `chc[i+1]` being 0.

### Output
- Prints the final value of `ans` as a long long integer.

## Data Dependencies
- The prefix arrays (`ca`, `cha`) depend on the input string characters up to each position.
- The suffix arrays (`cc`, `chc`) depend on the input string characters from each position to the end.
- The final answer depends on both prefix and suffix counts at each position where the character is 'B' or '?', combined with modular exponentiation results.
