## Function: main

**Inputs:** Reads an integer `t` from standard input, then for each test case reads an integer `N`.

**Outputs:** Prints "Case #i: " for each test case (where i is the 1-based test case number), followed by the result produced by the CodeJam function.

**Control Flow:**
- Reads `t` from standard input.
- Loops from i = 1 to t (inclusive).
- For each iteration, prints the case header, reads `N`, and calls `CodeJam(N)`.
- Returns 0 after all test cases.

## Function: CodeJam

**Inputs:** Receives integer `n` representing the number of words to process. Reads `n` strings from standard input, each up to 50 characters.

**Outputs:** Prints a single integer to standard output.

**Local Data Structures:**
- `tmp[1000][51]`: temporary storage for string swapping
- `word[1000][51]`: stores the input words
- `rw[1000][51]`: stores reversed versions of words
- `match[1000]`: stores prefix-match counts between adjacent words
- `max[1000]`: stores computed maximum values

**Processing Steps:**

1. **Input Reading:** Reads `n` words into the `word` array using scanf with %s.

2. **Initial Copy:** Copies all 1000 rows of `word` into `rw` (including uninitialized entries beyond `n`).

3. **Reversal:** For each of the first `n` words, reverses the characters in `rw[i]` by copying from the end of the original word to the beginning.

4. **Sorting:** Performs bubble sort on the `word` array (first `n` entries) in ascending lexicographic order using strcmp. Uses `tmp` for swapping.

5. **Match Counting:** For each adjacent pair of words (i and i+1, for i from 0 to n-2), counts how many leading characters match between `rw[i]` and `rw[i+1]`. The loop condition uses the minimum length of the two reversed strings. Stops counting at the first mismatch.

6. **Dynamic Programming Calculation:**
   - Sets `max[0] = match[0]` and `max[1] = match[1]`
   - For i from 2 to 999: `max[i] = max[i-2] + match[i]`
   - This effectively sums match values at even indices (0, 2, 4, ...) and odd indices (1, 3, 5, ...) separately.

7. **Output:** Prints the larger of `max[999]` and `max[998]`.

**Key Data Dependencies:**
- The `match` array depends on the reversed words, which depend on the original input words.
- The `max` array depends on the `match` array.
- The final output depends on the last two entries of the `max` array.

**Potential Issues (noted but not modified):**
- The reversal loop copies all 1000 rows initially, including uninitialized memory beyond the actual input count.
- The match counting loop has a precedence issue in its condition (the ternary operator applies to the strlen comparison, not the loop bound).
- The dynamic programming loop runs to 1000 regardless of `n`, using potentially uninitialized match values.
