## Inputs
- Two integers on the first line: `fx` and `fy`, representing starting coordinates (0-9 range expected)
- An integer `n` on the next line
- A list of integers `splist` on the following line, containing 2*n values (pairs of coordinates)

The program loops, reading these inputs repeatedly until both `fx` and `fy` are 0.

## Outputs
- For each test case, prints either "OK" or "NA" based on whether a safe path exists.

## Data Structures
- `safe`: A list of lists, where each inner list contains coordinate-position pairs `[[x,y], index]` representing all valid neighboring cells for each spring position.
- `wfs`: A queue used for breadth-first search traversal.
- `flogArea`: A temporary list storing candidate positions during safety checking.

## Function: makeList(splist, n)
- Takes the flat coordinate list and count `n`
- For each index `i` from 0 to n-1:
  - Extracts a pair of coordinates from `splist` at positions `i*2` and `i*2+1`
  - Creates a list containing: the coordinate pair `[x,y]` and the index `i`
  - Yields this as a generator item

## Function: isSafe(wfs, safe)
- Processes items from the queue until empty
- For each dequeued item `flog`:
  - Extracts position coordinates and index (with index incremented by 1)
  - Generates candidate positions in two patterns:
    - Pattern 1: horizontal offset of ±2 with vertical offset of -1, 0, or 1
    - Pattern 2: vertical offset of ±2 with horizontal offset of -1, 0, or 1
  - Only keeps candidates within 0-9 bounds for both coordinates
  - Checks if any position in `safe[spn]` matches a candidate in `flogArea`
  - If match found:
    - If `spn` equals 9, returns True (success)
    - If `spn` is less than 9, adds the matching position to the queue for further exploration
- Returns False if queue empties without finding a path to index 9

## Main Control Flow
1. Read starting coordinates
2. If both are 0, exit loop
3. Read `n` and the coordinate list
4. Build `safe` list by:
   - Using `makeList` to generate spring positions
   - For each spring, computing all 8 neighboring cells (including diagonals) within bounds
   - Storing these as `[[x,y], index]` pairs
5. Initialize queue with starting position and index -1
6. Call `isSafe` to check if a path exists
7. Print "OK" if safe, "NA" otherwise
8. Repeat from step 1

## Key Logic
- The search attempts to find a sequence of positions where each step moves from one spring position to another, with the index increasing by 1 each time
- Movement patterns allow jumps of 2 in one axis and 1 in the other
- The goal is to reach index 9 (the 10th spring position)
- The starting position has index -1, so the first valid move goes to index 0
- The search is breadth-first, exploring all possible paths through the spring positions
