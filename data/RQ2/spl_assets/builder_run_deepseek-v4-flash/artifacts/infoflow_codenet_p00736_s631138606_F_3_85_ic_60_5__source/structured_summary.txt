# Structured Description

## Function: F

### Inputs
- Integer parameters `p`, `q`, `r` representing possible values for variables P, Q, R
- Character array `ft` (size 100) containing a token sequence
- Integer `fc` representing the number of tokens in `ft`

### Output
- Returns an integer value (the result of evaluating the expression)

### Local Variables
- `fit[100]`: integer array used to store encoded tokens
- `ic`: index counter for the token array
- `x`: current position during evaluation
- `t`: loop counter

### Initialization
- Sets `ic` to 1
- Initializes all elements of `fit` array to 0

### Token Encoding Loop
- Iterates from index 1 up to (but not including) `fc`
- Maps each character in `ft` to an integer code:
  - 'P' → value of `p`
  - 'Q' → value of `q`
  - 'R' → value of `r`
  - '0' → 0
  - '1' → 1
  - '2' → 2
  - '+' → 3
  - '-' → 4
  - '*' → 5
- Increments `ic` after each character processed

### Evaluation Loop
- Decrements `ic` by 1 after the encoding loop
- Sets `x` to 1
- Iterates while `x` is less than `ic`

#### Addition Operation (code 3)
- When `fit[x]` equals 3:
  - If both operands (at positions x-1 and x-2) are 0, result is 0
  - If either operand is 2, result is 2
  - Otherwise, result is 1
  - Stores result at position x-2
  - Reduces `ic` by 2
  - Shifts remaining elements left by 2 positions
  - Decrements `x` by 2

#### Unary Minus Operation (code 4)
- When `fit[x]` equals 4:
  - Replaces the operand at position x-1 with (2 - operand value)
  - Reduces `ic` by 1
  - Shifts remaining elements left by 1 position
  - Decrements `x` by 1

#### Multiplication Operation (code 5)
- When `fit[x]` equals 5:
  - If either operand is 0, result is 0
  - If both operands are 2, result is 2
  - Otherwise, result is 1
  - Stores result at position x-2
  - Reduces `ic` by 2
  - Shifts remaining elements left by 2 positions
  - Decrements `x` by 2

- Increments `x` by 1 at the end of each iteration

### Return Value
- Returns the value stored at `fit[1]` after evaluation completes

## Function: main

### Inputs
- Reads strings from standard input using `scanf("%s", &txt)`

### Outputs
- Prints the token sequence (postfix notation) for each input expression
- Prints the count of variable assignments that produce a result of 2

### Local Variables
- `c`: loop counter
- `nc`: count of unary minus operators
- `oc`: count of operators on stack
- `fc`: count of tokens in final expression
- `txt[100]`: input string
- `ng[100]`: stack for unary minus operators
- `op[100]`: operator stack
- `ft[100]`: final token sequence
- `p`, `q`, `r`: loop variables for truth value assignments
- `ans`: counter for satisfying assignments

### Main Loop
- Continues indefinitely until input string starts with '.'
- For each input string:
  - Resets counters `nc`, `oc`, `fc` to 0

#### Token Processing Loop
- Iterates through each character of the input string

##### Operand Handling
- If character is '0', '1', '2', 'P', 'Q', or 'R':
  - Increments `fc` and stores character in `ft`
  - If there are pending unary minus operators, appends them to `ft` in reverse order

- If character is '+':
  - If operator stack is empty or top is '(':
    - Pushes '+' onto operator stack
  - Otherwise:
    - Pops all operators from stack to `ft`
    - Pushes '+' onto stack
