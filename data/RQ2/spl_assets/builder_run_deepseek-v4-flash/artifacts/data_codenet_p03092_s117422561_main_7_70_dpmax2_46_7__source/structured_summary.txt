# Structured Description

## Inputs
- Reads from standard input using a custom FastScanner class.
- First input: integer N (number of elements).
- Second input: long A.
- Third input: long B.
- Then N integers are read into array p of size N.

## Outputs
- Prints a single long value: dpc[0][N-1] to standard output.

## Main Control Flow

### Initialization
- Creates 5 two-dimensional arrays of size N×N:
  - dpc: long array for costs
  - dpmin: int array for minimum values
  - dpmin2: int array for second minimum values
  - dpmax: int array for maximum values
  - dpmax2: int array for second maximum values

### Diagonal Initialization
- For each index i from 0 to N-1:
  - dpc[i][i] = 0
  - dpmin[i][i] = p[i]
  - dpmax[i][i] = p[i]
  - dpmin2[i][i] = Integer.MAX_VALUE
  - dpmax2[i][i] = -1

### Main Dynamic Programming Loop
- Outer loop: d from 1 to N-1 (inclusive)
- Inner loop: i from 0 to N-d-1 (inclusive)
  - Computes values for interval [i, i+d]

#### Minimum and Second Minimum Update
- If p[i+d] < dpmin[i][i+d-1]:
  - dpmin2[i][i+d] = dpmin[i][i+d-1]
  - dpmin[i][i+d] = p[i+d]
- Else if p[i+d] < dpmin2[i][i+d-1]:
  - dpmin2[i][i+d] = p[i+d]
  - dpmin[i][i+d] = dpmin[i][i+d-1]
- Else:
  - dpmin2[i][i+d] = dpmin2[i][i+d-1]
  - dpmin[i][i+d] = dpmin[i][i+d-1]

#### Maximum and Second Maximum Update
- If p[i+d] > dpmax[i][i+d-1]:
  - dpmax2[i][i+d] = dpmax[i][i+d-1]
  - dpmax[i][i+d] = p[i+d]
- Else if p[i+d] > dpmax2[i][i+d-1]:
  - dpmax2[i][i+d] = p[i+d]
  - dpmax[i][i+d] = dpmax[i][i+d-1]
- Else:
  - dpmax2[i][i+d] = dpmax2[i][i+d-1]
  - dpmax[i][i+d] = dpmax[i][i+d-1]

#### Right Cost Calculation
- Initialize rightcost = 0
- If p[i+d] > dpmax[i][i+d-1]:
  - rightcost = dpc[i][i+d-1]
- Else if p[i+d] > dpmax2[i][i+d-1]:
  - rightcost = dpc[i][i+d-1] + min(A, B)
- Else:
  - rightcost = dpc[i][i+d-1] + B

#### Left Cost Calculation
- Initialize leftcost = 0
- If p[i] < dpmin[i+1][i+d]:
  - leftcost = dpc[i+1][i+d]
- Else if p[i] < dpmin2[i+1][i+d]:
  - leftcost = dpc[i+1][i+d] + min(A, B)
- Else:
  - leftcost = dpc[i+1][i+d] + A

#### Final Cost Assignment
- dpc[i][i+d] = min(leftcost, rightcost)
- Calls debug function with interval indices and computed values

## Helper Functions

### debug Function
- Takes variable number of long arguments
- If DEBUG_FLG is false, returns immediately
- Otherwise prints all arguments separated by spaces, followed by newline

### FastScanner Class
- Reads from System.in using a 1024-byte buffer
- Methods:
  - hasNextByte(): checks if more bytes available, refills buffer if needed
  - readByte(): returns next byte or -1 if none
  - isPrintableChar(int c): returns true if 33 ≤ c ≤ 126
  - skipUnprintable(): skips non-printable characters
  - hasNext(): skips unprintable, then checks for more bytes
  - next(): reads printable characters into a string
  - nextLong(): parses next token as long
  - nextInt(): par
