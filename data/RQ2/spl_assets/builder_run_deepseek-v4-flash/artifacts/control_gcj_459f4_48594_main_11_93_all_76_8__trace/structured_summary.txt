# Structured Description

## Input/Output
- **Input**: Read from standard input. First token is an integer `qq` representing the number of test cases. For each test case, two integers `r` and `c` are read (grid dimensions), followed by `r` strings, each of length `c`, representing the grid characters.
- **Output**: For each test case, prints `Case #<case_number>: <ret>` where `<ret>` is the computed result, then closes output.

## Global State
- Static variables: `br` (BufferedReader), `st` (StringTokenizer), `pw` (PrintWriter), and `par` (integer array used for union-find).

## Main Algorithm (per test case)
1. Read grid dimensions `r` and `c`.
2. Initialize result `ret = 1`.
3. Read the grid into a 2D character array `g`.
4. Iterate over all bitmasks from 1 to `(1 << (r*c)) - 1`, where each bit represents whether a cell is selected.
5. **Pruning**: If the number of set bits in the mask is less than or equal to current `ret`, skip this mask.
6. **Union-Find Setup**: Initialize parent array `par` where each cell is its own parent.
7. **Selection Mapping**: Convert the bitmask into a boolean 2D array `use`, where `use[i][j]` is true if the corresponding bit is set.
8. **Connectivity Check**: Initialize `numNeed = bitCount(mask) - 1`. For each selected cell, attempt to merge with its right and bottom neighbors if they are also selected. Each successful merge decrements `numNeed`. If `numNeed != 0` after all merges, the selected cells are not connected, so skip this mask.
9. **Validity Check**: For each cell `(i, j)` in the grid (as a potential "center" reference point), check if the selected cells satisfy a condition:
   - Create 4 sets (one per quadrant relative to `(i,j)`).
   - For each selected cell `(x,y)`, determine its quadrant index: `idx = 0`; if `x > i`, add 2; if `y < j`, add 1.
   - Add the grid character at `(x,y)` to the corresponding quadrant set.
   - If any quadrant set ends up with more than 1 distinct character, the configuration is invalid for this reference point.
   - If a valid reference point is found (all quadrant sets have size ≤ 1), mark the mask as valid.
10. **Update Result**: If the mask is valid, set `ret = bitCount(mask)`.
11. After all masks, print `ret`.

## Helper Functions
- **`find(x)`**: Union-find find with path compression. Returns the root of `x`.
- **`merge(x, y)`**: Union-find union. Returns true if `x` and `y` were in different sets (successful merge), false otherwise.
- **`exitImmediately()`**: Closes output and terminates the program.
- **`readLong()`, `readDouble()`, `readInt()`**: Parse the next token as the respective numeric type.
- **`nextLine()`**: Reads a line; if null, calls `exitImmediately()`. Resets the tokenizer.
- **`nextToken()`**: Returns the next whitespace-delimited token, reading a new line if necessary.

## Control Flow Summary
- Outer loop over test cases.
- Inner loop over all possible bitmasks (exponential in `r*c`).
- Nested loops for grid traversal, union-find operations, and validity checking.
- Early exits (continue statements) for masks that are too small, disconnected, or invalid.

## Data Dependencies
- The result `ret` depends on the maximum bit count among all valid masks.
- Validity of a mask depends on the grid characters and the connectivity of selected cells.
- The union-find structure is reinitialized for each mask.
