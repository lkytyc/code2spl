## Overview
This program implements a data structure that maintains a dynamic multiset of numbers and supports two types of operations: insertion with an associated cost, and queries about the current median and a computed value based on accumulated sums.

## Input/Output
- **Input**: Read from standard input via a custom `InputReader` class.
- **Output**: Written to standard output via a `PrintWriter`.

## Main Data Structures
- Two priority queues:
  - `f`: A max-heap (reverse order) storing the smaller half of inserted values.
  - `l`: A min-heap storing the larger half of inserted values.
- Accumulator variables:
  - `fsum`: Sum of all values currently in the max-heap `f`.
  - `lsum`: Sum of all values currently in the min-heap `l`.
  - `B`: Accumulated cost values from type-1 operations.

## Control Flow

### Main Loop
The program reads an integer `Q` (number of operations), then processes operations in a loop that decrements `Q` after each iteration.

### Operation Type 1 (Insertion)
Reads two long integers: `a` (the value to insert) and a cost value that gets added to `B`.

**Case: Both heaps have equal size**
- If both heaps are empty: Add `a` to the max-heap `f` and update `fsum`.
- Otherwise, examine the minimum value `x` in the min-heap `l`:
  - If `x < a`: Move `x` from `l` to `f`, and add `a` to `l`. Update both sums accordingly.
  - Otherwise: Add `a` directly to `f` and update `fsum`.

**Case: Heaps have unequal sizes (max-heap has one more element)**
- Examine the maximum value `x` in the max-heap `f`:
  - If `x <= a`: Add `a` directly to `l` and update `lsum`.
  - Otherwise: Move `x` from `f` to `l`, add `a` to `f`, and update both sums.

After the insertion logic, read the cost value and add it to `B`.

### Operation Type 2 (Query)
- Get the maximum value `x` from the max-heap `f` (this is the median).
- If both heaps have equal size: Output `x` followed by `(lsum - fsum + B)`.
- Otherwise (max-heap has one more element): Output `x` followed by `(lsum - fsum + x + B)`.

## Helper Methods
- `tr(Object... o)`: Debug utility that prints and flushes the given objects.

## InputReader Class
A custom fast input reader with the following methods:
- `hasNextByte()`: Checks if more bytes are available, refilling the buffer if needed.
- `readByte()`: Returns the next byte or -1 if end of stream.
- `isSpaceChar(int c)`: Returns true for non-printable ASCII characters (outside 33-126).
- `skip()`: Skips whitespace characters.
- `hasNext()`: Checks if there's another token.
- `next()`: Reads the next token as a string.
- `nextInt()`: Parses the next token as an integer, handling optional minus sign.
- `nextLong()`: Parses the next token as a long, handling optional minus sign.
- `nextDouble()`: Parses the next token as a double.
- `nextIntArray(int n)`: Reads an array of `n` integers.
- `nextLongArray(int n)`: Reads an array of `n` longs.
- `nextCharMap(int n, int m)`: Reads an `n` by `m` character grid.

## Error Handling
- `InputMismatchException` is thrown for invalid numeric input or I/O errors.
- `NoSuchElementException` is thrown when trying to read past the end of input.

## Data Dependencies
- The state of both heaps and their sums (`fsum`, `lsum`) are interdependent and updated together during insertions.
- The query output depends on the current heap sizes, the median value, and the accumulated cost `B`.
- The `B` accumulator is only modified by type-1 operations.
