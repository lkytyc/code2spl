## Overview
This program computes minimum transportation costs for N facilities, where each facility can be assigned to either a horizontal or vertical axis, and the cost depends on distances to assigned axes or to other facilities assigned to the same axis.

## Inputs
- First line: integer N (number of facilities)
- Next N lines: three integers each — X[i], Y[i], P[i] (coordinates and weight for each facility)

## Outputs
- N+1 lines, each containing a long integer: the minimum total cost for using exactly k axes (where k ranges from 0 to N)

## Data Structures
- `X[20]`, `Y[20]`, `P[20]`: coordinate and weight arrays for facilities
- `a[20]`: assignment array where 0 = unassigned, 1 = horizontal, 2 = vertical
- `Z[1<<16][16][2]`: precomputed distance table; Z[mask][j][0] = minimum horizontal distance for facility j given mask of horizontal facilities; Z[mask][j][1] = minimum vertical distance for facility j given mask of vertical facilities
- `ans[20]`: array storing minimum costs for each possible number of axes used

## Precomputation Phase (lines 16-27)
For every possible subset mask (from 0 to 2^N - 1):
- For each facility j:
  - Initialize Z[mask][j][0] to |X[j]| (distance to origin on horizontal axis)
  - Initialize Z[mask][j][1] to |Y[j]| (distance to origin on vertical axis)
  - For each facility k in the mask:
    - Update Z[mask][j][0] to minimum of current value and |X[j] - X[k]|
    - Update Z[mask][j][1] to minimum of current value and |Y[j] - Y[k]|

## Main Enumeration Loop (lines 28-46)
This loop enumerates all possible assignments of facilities to axes using a base-3 counter in array `a[]`:

1. **Build masks**: For each facility i:
   - If a[i] == 1, add bit i to horizontal mask `h`
   - If a[i] == 2, add bit i to vertical mask `v`

2. **Count axes used**: `t = popcount(h | v)` — number of facilities assigned to either axis

3. **Compute cost**: For each facility i:
   - Cost contribution = P[i] × min(Z[h][i][0], Z[v][i][1])
   - This takes the minimum of horizontal distance (given horizontal mask) and vertical distance (given vertical mask)
   - Sum all contributions

4. **Increment counter**: Find rightmost position where a[i] != 2, reset all positions to its right to 0, increment that position (base-3 counting)

5. **Update answer**: ans[t] = min(ans[t], current sum)

## Termination
The loop continues while a[N] == 0, meaning it enumerates all 3^N possible assignments (each facility can be horizontal, vertical, or unassigned).

## Helper Function
`popcount(n)`: recursively counts set bits in integer n; returns 0 if n is 0, otherwise returns (n & 1) + popcount(n >> 1)

## Final Output
Prints ans[0] through ans[N], each on a separate line, representing minimum costs for using 0, 1, 2, ..., N axes respectively.

## Key Dependencies
- The cost calculation depends on both the precomputed Z table and the current assignment masks
- The answer for each axis count depends on all assignments that use exactly that many axes
- The enumeration order is deterministic (base-3 counting), covering all possible assignments exactly once
