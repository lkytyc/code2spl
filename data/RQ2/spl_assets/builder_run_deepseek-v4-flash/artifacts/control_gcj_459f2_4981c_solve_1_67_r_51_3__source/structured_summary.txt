# Structured Description of Code

## Function: solve(B)

### Input
- B: A list of integers representing ball counts at each column position.

### Output
- Returns a tuple containing:
  - Either the string 'IMPOSSIBLE' and None, OR
  - An integer (number of rows in the solution grid) and a list of lists of characters representing the grid.

### Initial Validation
- Checks if the first element (B[0]) or last element (B[-1]) equals 0.
- If either is 0, immediately returns ('IMPOSSIBLE', None).

### Grid Initialization
- Determines C as the length of list B.
- Creates a C×C grid filled with '.' characters.
- Creates a shadowed list of boolean values with length C.
- Sets shadowed[0] to True.
- Decrements B[0] and B[-1] by 1.

### Main Processing Loop
Iterates through each index i from 0 to C-1.

#### Branch 1: Skip Condition
- If B[i] equals 0 AND shadowed[i] is True, skips to next iteration.

#### Branch 2: Unshadowed Position with Balls
- If B[i] is greater than 0 AND shadowed[i] is False:
  - Scans leftward from position i-1 while j >= 1 and shadowed[j] is False.
  - For each such position j, places a backslash character '\' in the grid at row l, column j.
  - Marks shadowed[j] as True.
  - Increments unshadowed_balls counter.
  - Increments l (row counter) and decrements j.

  - **Sub-branch A**: If B[i] <= unshadowed_balls:
    - Calculates excess_balls as (unshadowed_balls - B[i] + 1).
    - Sets j = i.
    - While excess_balls > 1: decrements j, decrements excess_balls, and sets shadowed[j] to False.

  - **Sub-branch B**: If B[i] > unshadowed_balls:
    - Decrements B[i] by (unshadowed_balls + 1).
    - Sets shadowed[i] to True.

#### Branch 3: Shadowed Position with Remaining Balls
- If B[i] is greater than 0 AND shadowed[i] is True:
  - Sets r = B[i].
  - Sets j = i + 1 and l = 1.
  - First while loop: While j < (C-1) AND shadowed[j] is True:
    - Places '/' character at grid[l][j].
    - Increments l and j.

  - Second while loop: While j < (C-1) AND r > 0:
    - Places '/' character at grid[l][j].
    - Sets shadowed[j] to True.
    - Decrements r.
    - Increments l and j.

### Output Grid Construction
- Creates an empty ans list.
- Iterates through grid rows from index 1 to C-1.
- For each row, checks if it contains any '\' or '/' character.
- If found, appends the row to ans.
- If not found, breaks out of the loop.
- Prepends a row of all '.' characters to ans.
- Returns (len(ans), ans).

## Function: main()

### Input
- Reads from standard input:
  - First line: integer T (number of test cases).
  - For each test case:
    - Integer S (appears unused in logic).
    - A line of space-separated integers for B.

### Processing
- For each test case t from 1 to T:
  - Calls solve(B) to get result and grid.
  - Prints "Case #{t}: {result}".
  - If grid is not None/empty:
    - Prints grid rows in reverse order (from last row to first).

### Entry Point
- Checks if __name__ == "__main__" and calls main().

## Key Data Dependencies
- The shadowed array tracks which positions have been affected by ball placement.
- The B array is modified during processing (decremented).
- Grid placement depends on current values of B[i], shadowed status, and position indices.
- The final answer's row count depends on how many grid rows contain non-dot characters.
