# Function: calculate(arr, size)

## Inputs
- `arr`: a list of integers
- `size`: an integer representing the length of the array

## Output
- Returns a string: either `'OK'` or a string representation of an integer index

## Processing Steps

### Step 1: Partition array into even and odd position elements
- Creates `even_arr` with length `size / 2` (integer division)
- Creates `odd_arr` with length `size - len(even_arr)`
- Iterates through the original array using index `i` from 0 to `size-1`
- For each element:
  - If `(i+1) % 2 == 0` (i.e., position is even when counting from 1), places the element into `even_arr`
  - Otherwise (odd position when counting from 1), places the element into `odd_arr`

### Step 2: Sort both arrays
- Sorts `even_arr` in ascending order
- Sorts `odd_arr` in ascending order

### Step 3: Merge and validate sorted order
- Resets both index counters (`eveni` and `oddi`) to 0
- Initializes `last` to -1
- Iterates through positions 0 to `size-1`:
  - **First iteration (i == 0)**: Takes the first element from `odd_arr`, assigns it to `last`, increments `oddi`, and continues to next iteration
  - **For odd indices (i % 2 == 1)**: Takes next element from `even_arr`; if this element is less than `last`, returns `str(i-1)`; otherwise updates `last` and increments `eveni`
  - **For even indices (i % 2 == 0, excluding i==0)**: Takes next element from `odd_arr`; if this element is less than `last`, returns `str(i-1)`; otherwise updates `last` and increments `oddi`

### Step 4: Completion
- If the loop completes without returning, returns the string `'OK'`

## Control Flow Branches
- **Partition loop**: Two branches based on position parity
- **Validation loop**: Three branches:
  - First element special case
  - Even-index position check
  - Odd-index position check
- **Early return condition**: Returns when a sorted element is smaller than the previously placed element

## Data Dependencies
- `even_arr` and `odd_arr` contents depend on original array positions
- Sorting modifies both arrays in-place
- The validation loop depends on the sorted order of both arrays
- The return value depends on the first position where the sorted sequence violates non-decreasing order

# Function: main()

## Inputs
- Reads integer `t` from standard input (number of test cases)

## Processing
- Loops `t` times:
  - Reads integer `size` from standard input
  - Reads a line of space-separated integers into `arr`
  - Calls `calculate(arr, size)` to get the answer

## Output
- For each test case, prints: `Case #<test_case_number>: <answer>`
  - Test case numbers start at 1
  - `<answer>` is the string returned by `calculate`

## Control Flow
- Single loop over test cases
- No conditional branching within the loop

## Data Dependencies
- Each test case's output depends on its own input array and size
- No data shared between test cases
