# Code Description

## Input Processing
- Reads an integer `T` from standard input, representing the number of test cases.
- For each test case, reads an integer `N`, then reads `N` lines, each containing two integers (stored as a list in `M`).
- Uses `raw_input()` for input reading and `map(int, ...)` for conversion.

## Main Function: `solve(N, M)`
Takes the number of points `N` and a list `M` of coordinate pairs. Returns either a list of two integers (the solution) or `None` (indicating impossibility).

### Initialization
- Sets four variables to `None`: `topHigh`, `botHigh`, `topLow`, `botLow`.

### Pairwise Loop
- Iterates over all unordered pairs of indices `(i, j)` where `i < j`.
- For each pair, extracts coordinates: `(a, b)` from point `i` and `(c, d)` from point `j`.
- **Skip condition**: If `a == c` or `b == d` (points share x or y coordinate), the pair is skipped.

### Slope Calculation
- Computes `top = a - c` and `bot = d - b`.
- Determines `wasNeg` as whether `top * bot < 0` (the slope is negative).
- Takes absolute values of `top` and `bot`.

### Branch Based on Vertical Difference
- **If `b - d > 0`** (point i is above point j):
  - If `wasNeg` is true, returns `None` immediately (impossible).
  - Otherwise, updates `topHigh`/`botHigh` if this pair has a larger slope ratio than the current best (using cross-multiplication comparison).

- **If `b - d <= 0`** (point i is at or below point j):
  - If `wasNeg` is true, skips this pair.
  - Otherwise, updates `topLow`/`botLow` if this pair has a larger slope ratio than the current best (using cross-multiplication comparison).

### Post-Loop Decision Logic

#### Case 1: Both `topHigh` and `topLow` are `None`
- Returns `[1, 1]`.

#### Case 2: Only `topHigh` is `None` (no positive-slope pairs found)
- If `botLow == topLow`: returns `[1, 2]`.
- If `topLow > botLow`: returns `[1, ceil(topLow/botLow)]`.
- Otherwise: returns `[ceil(botLow/topLow), 1]`.

#### Case 3: Only `topLow` is `None` (no negative-slope pairs found)
- If `botHigh == topHigh`: returns `[2, 1]`.
- If `botHigh > topHigh`: returns `[ceil(botHigh/topHigh), 1]`.
- Otherwise: returns `[1, ceil(topHigh/botHigh)]`.

#### Case 4: Both `topHigh` and `topLow` are set
- Computes `a = topHigh / botHigh` and `b = topLow / botLow` as floating-point values.
- If `a <= b`: returns `None` (impossible).
- Otherwise, performs a **binary search** on `x` in range `[1, 1e20]`:
  - Computes `mid` as the integer midpoint.
  - Computes `low = b * mid` and `high = a * mid`.
  - If `low` is an integer:
    - If `high > low + 1`: narrows search to `[xMin, mid]`.
    - Else: narrows to `[mid+1, xMax]`.
  - If `low` is not an integer:
    - If `ceil(low) < high`: narrows to `[xMin, mid]`.
    - Else: narrows to `[mid+1, xMax]`.
  - The loop continues while `xMax > xMin`.
  - **Note**: The function does not explicitly return after the loop; the return value is implicit (likely `None` in Python).

## Output Formatting
- For each test case, calls `solve(N, M)`.
- If result is `None`: prints `Case #X: IMPOSSIBLE`.
- Otherwise: prints `Case #X: Y Z` where `Y` and `Z` are the two integers from the result list.

## Global Settings
- Sets recursion limit to 10000 at the start.
- Imports `sys`, `itertools`, `math`, `collections`, and `functools` (though only `sys` and `math` are used).
