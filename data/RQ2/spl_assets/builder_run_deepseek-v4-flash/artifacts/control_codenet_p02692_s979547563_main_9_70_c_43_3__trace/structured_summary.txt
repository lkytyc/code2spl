# Structured Description

## Inputs
- Reads from standard input using a custom FastScanner.
- First integer read is `n`, representing the number of operations to process.
- Next three integers are read as `a`, `b`, and `c` — initial counts for three categories.
- Then `n` strings are read sequentially, each expected to be one of "AB", "BC", or "AC".

## Outputs
- Prints "No" and terminates immediately if any operation cannot be performed.
- Prints "Yes" followed by one character per operation (each on its own line) if all operations succeed.

## Main Control Flow

### Initialization
- Creates a FastScanner wrapping standard input.
- Reads `n`, `a`, `b`, `c` from input.
- Initializes an empty list to store answer characters.

### Main Loop (iterates `n` times)
For each iteration, reads a string `s` and processes it via a switch statement:

#### Case "AB"
- If both `a` and `b` are zero: prints "No" and returns immediately.
- If `a < b`: appends "A" to answer, increments `a`, decrements `b`.
- Otherwise (a >= b): appends "B" to answer, decrements `a`, increments `b`.

#### Case "BC"
- If both `b` and `c` are zero: prints "No" and returns immediately.
- If `b < c`: appends "B" to answer, increments `b`, decrements `c`.
- Otherwise (b >= c): appends "C" to answer, decrements `b`, increments `c`.

#### Default case (handles "AC")
- If both `a` and `c` are zero: prints "No" and returns immediately.
- If `a < c`: appends "A" to answer, increments `a`, decrements `c`.
- Otherwise (a >= c): appends "C" to answer, decrements `a`, increments `c`.

### Completion
- After the loop finishes without early return, prints "Yes".
- Prints each character in the answer list on its own line.

## Helper Class: FastScanner

### Fields
- A BufferedReader for reading input.
- A StringTokenizer for token parsing.

### Constructor
- Takes an InputStream and wraps it in a BufferedReader with an InputStreamReader.

### Methods
- `next()`: Reads a new line if the tokenizer is null or exhausted, then returns the next token.
- `nextInt()`: Parses the next token as an integer.
- `nextLong()`: Parses the next token as a long.
- `nextDouble()`: Parses the next token as a double.
- `nextLine()`: Returns the next line if no tokens remain, otherwise returns the remaining tokens as a line.

## Data Dependencies
- The values of `a`, `b`, and `c` are modified throughout the loop and affect subsequent decisions.
- The choice of which character to append depends on the current values of the two relevant counts.
- The early termination condition depends on both relevant counts being zero simultaneously.

## Edge Cases
- If any operation encounters both relevant counts at zero, the program terminates with "No" without processing remaining input.
- The comparison uses strict less-than (`<`), so ties go to the "else" branch.
- The default case handles any string not matching "AB" or "BC", which includes "AC" but would also catch unexpected input.
