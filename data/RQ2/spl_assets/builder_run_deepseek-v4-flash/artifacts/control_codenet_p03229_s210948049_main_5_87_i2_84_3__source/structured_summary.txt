## Input
- Reads an integer N from standard input.
- Then reads N integers, one per line, into a list A.

## Initialization
- Sorts the list A in ascending order.
- Creates a boolean/flag array `used` of length N, initially all zeros.
- Initializes two output accumulators: `output1` and `output2`, both set to 0.
- Sets up two pairs of indices:
  - First pair: `i1 = 0`, `j1 = N-1`
  - Second pair: `i2 = 0`, `j2 = N-2`
- Sets two flags `f1` and `f2` to True.
- Marks the initial positions as used: indices 0, 0, N-1, and N-2 are all set to 1 in the `used` array.

## First Computation Phase (output1)
- Runs a loop while either `f1` or `f2` is True.
- In each iteration:
  - If `f1` is True, adds `(A[j1] - A[i1])` to `output1`.
  - If `f2` is True, adds `(A[j2] - A[i2])` to `output1`.
  - Advances `i1` to the next unused index (skipping used ones). If `i1` reaches N-1, sets `f1` to False.
  - Marks the new `i1` position as used.
  - Advances `i2` similarly. If `i2` reaches N-1, sets `f2` to False.
  - Marks the new `i2` position as used.
  - If `f1` is still True, adds `(A[j1] - A[i1])` to `output1`.
  - If `f2` is still True, adds `(A[j2] - A[i2])` to `output1`.
  - Decrements `j1` to the next unused index from the top. If `j1` reaches 0, sets `f1` to False.
  - Marks the new `j1` position as used.
  - Decrements `j2` similarly. If `j2` reaches 0, sets `f2` to False.
  - Marks the new `j2` position as used.

## Second Computation Phase (output2)
- Resets indices: `i1 = 0`, `i2 = 1`, `j1 = N-1`, `j2 = N-1`.
- Resets flags `f1` and `f2` to True.
- Reinitializes the `used` array to all zeros.
- Marks initial positions as used: indices 0, 1, N-1, and N-1.

## Second Loop (output2)
- Runs a loop while either `f1` or `f2` is True.
- In each iteration:
  - If `f1` is True, adds `(A[j1] - A[i1])` to `output2`.
  - If `f2` is True, adds `(A[j2] - A[i2])` to `output2`.
  - Decrements `j1` to the next unused index from the top. If `j1` reaches 0, sets `f1` to False.
  - Marks the new `j1` position as used.
  - Decrements `j2` similarly. If `j2` reaches 0, sets `f2` to False.
  - Marks the new `j2` position as used.
  - If `f1` is still True, adds `(A[j1] - A[i1])` to `output2`.
  - If `f2` is still True, adds `(A[j2] - A[i2])` to `output2`.
  - Advances `i1` to the next unused index. If `i1` reaches N-1, sets `f1` to False.
  - Marks the new `i1` position as used.
  - Advances `i2` similarly. If `i2` reaches N-1, sets `f2` to False.
  - Marks the new `i2` position as used.

## Output
- Prints the maximum of `output1` and `output2`.

## Control Flow Notes
- Both loops terminate when both flags become False.
- The flags become False when the corresponding index pointers reach the boundary (0 or N-1) while searching for unused positions.
- The `used` array prevents reusing the same array element in the difference calculations.
- The two phases differ in the initial index assignments and the order of advancing low vs. high indices within the loop.
