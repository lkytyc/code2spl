# Function: get_next_location(num_of_people)

## Input
- `num_of_people`: an integer representing the number of people to process.

## Processing
1. Initializes an empty list `coordinates_list` and sets `people_count` to 1.
2. Loops while `people_count` is less than or equal to `num_of_people`:
   - Reads a line of input via `raw_input`.
   - Splits the line into tokens.
   - Converts the first token to integer `x` and second token to integer `y`.
   - Stores the third token as `dir` (a string).
   - Based on the value of `dir`:
     - If `"N"`, increments `y` by 1.
     - If `"S"`, decrements `y` by 1.
     - If `"E"`, increments `x` by 1.
     - If `"W"`, decrements `x` by 1.
   - Creates a two-element list `[x, y]` and appends it to `coordinates_list`.
   - Increments `people_count` by 1.
3. After the loop, initializes empty lists `next_dest` and `next_dest_count`.
4. Iterates over each coordinate pair in `coordinates_list`:
   - Sets `found` to 0 and `dest_idx` to 0.
   - Iterates over existing entries in `next_dest`:
     - If the current coordinate equals an existing destination, increments the corresponding count in `next_dest_count`, sets `found` to 1, and breaks.
     - Otherwise, increments `dest_idx`.
   - If `found` is still 0, appends the coordinate to `next_dest` and appends 1 to `next_dest_count`.
5. Initializes `popular_next_dest` with the first destination and `highest_count` with the first count.
6. Iterates over `next_dest_count` starting from index 1:
   - Skips index 0 (already handled).
   - If the current count equals `highest_count`, appends the corresponding destination to `popular_next_dest`.
   - If the current count is greater than `highest_count`, resets `popular_next_dest` to a new list, updates `highest_count`, and appends the current destination.
7. After counting, if `popular_next_dest` has exactly one element, returns that element.
8. Otherwise, finds the smallest coordinate pair (by list comparison) among `popular_next_dest` and returns it.

## Output
- Returns a two-element list `[x, y]` representing the most frequent next location (with ties broken by choosing the smallest coordinate pair).

# Function: generate_test_cases(T)

## Input
- `T`: an integer specifying the number of test cases.

## Processing
1. Sets `count` to 1.
2. Loops while `count` is less than or equal to `T`:
   - Reads a line of input via `raw_input`.
   - Splits the line into tokens.
   - Converts the first token to integer `num_of_people` and second token to integer `max_grid_size` (the latter is read but not used).
   - Calls `get_next_location(num_of_people)` and stores the result in `coordinates`.
   - Extracts `x` and `y` from the returned list.
   - Prints a formatted string: `"Case #" + str(count) + ": " + str(x) + " " + str(y)`.
   - Increments `count` by 1.

## Output
- Prints one line per test case with the case number and the computed x and y coordinates.

---

# Top-Level Execution

## Input
- Reads a single line via `raw_input` and evaluates it using `eval` to obtain `T`.

## Processing
- Calls `generate_test_cases(int(T))`.

## Output
- Prints the results for all test cases as described above.

---

# Data Dependencies and Control Flow Summary

- `get_next_location` depends on `num_of_people` and reads `num_of_people` lines of input.
- The direction string determines which coordinate is modified.
- The frequency counting uses nested loops to build unique destinations and their counts.
- Tie-breaking uses list comparison (lexicographic order) to select the smallest coordinate.
- `generate_test_cases` reads two integers per test case but only uses the first; the second (`max_grid_size`) is ignored.
- The main program reads the number of test cases and invokes the test case generator.
