## Function: calc(n, d, a, b, ct)

**Inputs:**
- `n` (integer) — but immediately overwritten with `len(a)`
- `d` (integer) — target value used throughout
- `a` (list of integers) — sorted unique keys
- `b` (list of integers) — corresponding counts for each key in `a`
- `ct` (dictionary) — maps each key to its count

**Outputs:**
- Returns a tuple `(ans, ret)` where `ans` is an integer (minimum computed value) and `ret` is `a[0]` (the first element of list `a`)

**Initialization:**
- `n` is set to `len(a)`
- `ans` is initialized to `d - 1`
- `ret` is set to `a[0]`

**Main loop (outer):**
- Iterates `i` from 0 to `n-1` (over each unique key in `a`)
- For each iteration:
  - Sets `x = a[i]`, `y = b[i]`
  - Initializes `cur_d = 0`, `p = 0`, `cut = 0`

**Inner loop 1 (over j):**
- Iterates `j` from 0 to `d+1` inclusive
- For each `j`:
  - Adds `x` to `p` (so `p` accumulates multiples of `x`)
  - Gets `tmp = ct.get(p, 0)` — count of value `p` in the dictionary
  - Computes `remain_d = d - cur_d`
  - Computes `per_d = p / x` (integer division)
  - Computes `per_cut = per_d - 1`
  - **Nested loop over k:** iterates `k` from 0 to `tmp * per_d - 1`
    - Increments `cur_d` by 1
    - If `(k+1) % per_d != 0`, increments `cut` by 1
    - Computes `xx = d / cur_d` (integer division)
    - If `d % cur_d == 0`, decrements `xx` by 1
    - Updates `ans = min(ans, cut + xx * cur_d)`
    - If `cur_d > d`, breaks out of this nested loop
  - After the nested loop, if `cur_d > d`, breaks out of inner loop 1

**Conditional block (after inner loop 1):**
- If `cur_d < d`:
  - **Inner loop 2:** iterates `j` from `n-1` down to `i+1` (reverse order)
    - For each `j`:
      - If `a[j] > p` OR `a[j] % x != 0`:
        - Computes `tmp = (a[j] / x) * y` (integer division for `a[j]/x`)
        - **Nested loop over k:** iterates `k` from 0 to `tmp - 1`
          - Increments `cur_d` by 1
          - Increments `cut` by 1
          - Computes `xx = d / cur_d` (integer division)
          - If `d % cur_d == 0`, decrements `xx` by 1
          - Updates `ans = min(ans, cut + xx * cur_d)`
          - If `cur_d > d`, breaks out of this nested loop
      - If `cur_d > d`, breaks out of inner loop 2

**Final update (after inner loop 2):**
- Computes `xx = d / cur_d` (integer division)
- If `d % cur_d == 0`, decrements `xx` by 1
- Updates `ans = min(ans, cut + xx * cur_d)`

**Return:**
- Returns `(ans, ret)`

## Function: work(case)

**Inputs:**
- `case` (integer) — case number for output

**Behavior:**
- Reads a line from standard input, splits it, converts to integers `n` and `d`
- Reads another line, splits it, converts each element to integer, stores in list `tmp`
- Creates dictionary `ct` with keys from `tmp`, all initialized to 0
- Counts occurrences of each value in `tmp` into `ct`
- Creates `a` and `b` by sorting `ct.items()` and unpacking into two lists (keys and counts)
