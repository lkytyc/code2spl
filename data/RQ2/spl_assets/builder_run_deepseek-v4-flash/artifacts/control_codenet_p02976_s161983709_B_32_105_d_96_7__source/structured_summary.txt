### Input Handling Utilities
The code defines several input-reading helper functions:
- `LI()` reads a line and converts it to a list of integers.
- `I()` reads a single integer from a line.
- `LS()` reads a line and converts it to a list of characters.
- `S()` reads a line, strips the newline, and returns it as a list of characters.
- `IR(n)`, `LIR(n)`, `SR(n)`, and `LSR(n)` read `n` lines using the corresponding single-line functions.

The recursion limit is set to 1,000,000, and a global modulus constant is defined as 1,000,000,007.

### Function A
- **Input**: Reads an integer `n` and then a list `a` of `n` integers.
- **Processing**: Computes the bitwise XOR of all elements in `a` into `ans`.
- **Output**: Prints "Yes" if `ans` is zero, otherwise prints "No".

### Function B
- **Input**: Reads two integers `n` and `m` (number of vertices and edges). Then reads `m` pairs of integers representing undirected edges.
- **Data Structures**:
  - `v`: adjacency list for the graph.
  - `f`: degree count for each vertex.
  - `dic`: dictionary mapping each undirected edge (stored both directions) to 1.
  - `d`: array tracking parity state for each vertex.
  - `q`: deque for BFS traversal starting from vertex 0.
  - `bfs`: visited flag array.
  - `ans`: list of directed edges to output.
- **Processing**:
  - Builds the graph and degree counts.
  - Performs BFS from vertex 0. For each popped vertex `x`, collects its unvisited neighbors into `s` (those still marked in `dic`).
  - Marks neighbors as visited and enqueues them.
  - Based on the parity of `len(s)` and the current state `d[x]`, selects edges to add to `ans` and updates `dic` and `d`:
    - If `len(s)` is odd and `d[x]` is 1: adds all edges from `x` to each neighbor in `s`, clears those edges from `dic`, sets `d[x]` to 0.
    - If `len(s)` is odd and `d[x]` is 0: adds edges from `x` to all but the last neighbor, clears them, sets `d[x]` to 0, then toggles `d` on the last neighbor and adds a reverse edge from that neighbor to `x`.
    - If `len(s)` is even and `d[x]` is 0: adds all edges from `x` to neighbors, clears them, sets `d[x]` to 0.
    - If `len(s)` is even and `d[x]` is 1: adds edges from `x` to all but the last neighbor, clears them, sets `d[x]` to 0, then toggles `d` on the last neighbor and adds a reverse edge.
- **Output**: If the sum of `d` is non-zero, prints -1. Otherwise, prints each directed edge in `ans` with 1-based indexing.
