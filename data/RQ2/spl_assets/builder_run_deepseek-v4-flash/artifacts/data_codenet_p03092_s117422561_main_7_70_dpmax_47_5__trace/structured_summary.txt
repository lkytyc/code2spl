# Code Description

## Overview
This Java program reads a sequence of integers and computes a minimum cost using dynamic programming. The algorithm processes subarrays of increasing length and maintains statistics about minimum and maximum values within each subarray.

## Input
- First line: integer N (array size)
- Second line: long A (cost parameter)
- Third line: long B (cost parameter)
- Following N lines: integers p[0] through p[N-1]

## Output
- A single long value representing the minimum cost computed for the entire array (dpc[0][N-1])

## Data Structures
- `p`: integer array of size N containing the input values
- `dpc`: 2D long array storing minimum costs for subarrays
- `dpmin`: 2D integer array storing minimum value in each subarray
- `dpmin2`: 2D integer array storing second minimum value in each subarray
- `dpmax`: 2D integer array storing maximum value in each subarray
- `dpmax2`: 2D integer array storing second maximum value in each subarray

## Initialization
For each index i (0 to N-1):
- dpc[i][i] = 0
- dpmin[i][i] = p[i]
- dpmax[i][i] = p[i]
- dpmin2[i][i] = Integer.MAX_VALUE
- dpmax2[i][i] = -1

## Main Dynamic Programming Loop
The algorithm iterates over subarray lengths d from 1 to N-1, and for each starting index i from 0 to N-d-1:

### Updating Minimum Statistics
When adding element p[i+d] to subarray [i, i+d-1]:
- If p[i+d] < dpmin[i][i+d-1]: new minimum becomes p[i+d], old minimum becomes second minimum
- Else if p[i+d] < dpmin2[i][i+d-1]: p[i+d] becomes second minimum
- Otherwise: both minimum values remain unchanged

### Updating Maximum Statistics
When adding element p[i+d] to subarray [i, i+d-1]:
- If p[i+d] > dpmax[i][i+d-1]: new maximum becomes p[i+d], old maximum becomes second maximum
- Else if p[i+d] > dpmax2[i][i+d-1]: p[i+d] becomes second maximum
- Otherwise: both maximum values remain unchanged

### Computing Right Cost
The cost when extending the subarray to the right (adding p[i+d]):
- If p[i+d] > dpmax[i][i+d-1]: cost = dpc[i][i+d-1] (no additional cost)
- Else if p[i+d] > dpmax2[i][i+d-1]: cost = dpc[i][i+d-1] + min(A, B)
- Otherwise: cost = dpc[i][i+d-1] + B

### Computing Left Cost
The cost when extending the subarray to the left (adding p[i]):
- If p[i] < dpmin[i+1][i+d]: cost = dpc[i+1][i+d] (no additional cost)
- Else if p[i] < dpmin2[i+1][i+d]: cost = dpc[i+1][i+d] + min(A, B)
- Otherwise: cost = dpc[i+1][i+d] + A

### Final Cost Assignment
dpc[i][i+d] = min(leftcost, rightcost)

## Debug Function
The `debug` method prints variable-length arguments separated by spaces, but only executes when DEBUG_FLG is true (which is false by default).

## FastScanner Class
A custom scanner that:
- Reads from System.in using a 1024-byte buffer
- Skips non-printable characters (ASCII values outside 33-126)
- Provides methods: hasNext(), next(), nextLong(), nextInt(), nextDouble()
- Throws NoSuchElementException if no more input exists
- Handles IOException during buffer reads by printing stack trace

## Control Flow Summary
- Main loop structure: nested loops over subarray lengths and starting positions
- Conditional branches for updating min/max statistics and computing costs
- The algorithm has O(N²) time complexity due to the nested loops
- No recursion or external function calls beyond the scanner and debug methods
