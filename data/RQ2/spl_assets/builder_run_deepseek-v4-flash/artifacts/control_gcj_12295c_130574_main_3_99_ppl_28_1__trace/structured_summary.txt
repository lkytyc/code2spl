## Inputs
The program reads from standard input using a Scanner. It first reads an integer `t` representing the number of test cases. For each test case, it reads:
- An integer `p` (number of people)
- An integer `q` (grid size)
- For each of the `p` people: an integer coordinate, another integer coordinate (which is transformed), and a direction string (`"N"`, `"S"`, `"E"`, or `"W"`).

## Outputs
For each test case, the program prints a line in the format: `Case #i: x y` where `i` is the 1-based test case number, and `x` and `y` are the coordinates of the chosen point.

## Data Structures
- `Person` class stores four integers: `x`, `y`, `xDir`, `yDir`.
- `ArrayList<Person>` collections store people and candidate points.
- A 2D integer array `b` of size `q` by `q` accumulates counts.

## Control Flow

### Main Loop
The program iterates through each test case from 1 to `t`.

### Person Input Processing
For each person:
- Reads coordinate `b` and computes `a = q - (input value) - 1` (this reverses the y-coordinate).
- Reads direction string `c`.
- Sets direction components:
  - `"N"` → `yDir = -1`
  - `"S"` → `yDir = 1`
  - `"E"` → `xDir = 1`
  - Any other value (treated as `"W"`) → `xDir = -1`
- Creates a `Person` object with these values and adds it to the list.

### Grid Population
For each person in the list:
- If `xDir == 0` (person moves vertically):
  - Iterates from `x + yDir` in steps of `yDir` while staying within bounds `[0, q-1]`.
  - For each such row, increments every column in that row of the grid.
- Otherwise (person moves horizontally):
  - Iterates through all rows.
  - For each row, iterates from `y + xDir` in steps of `xDir` while staying within bounds.
  - Increments each such cell.

### Finding Maximum Count
- Scans the entire grid to find the maximum count value.

### Collecting Candidate Points
- Scans the grid column by column (outer loop over columns, inner loop over rows).
- For each cell equal to the maximum count, stores:
  - `row[num] = q - r - 1` (reverses the row index)
  - `col[num] = c` (column index)
  - Increments `num`.

### Selecting Minimum Sum
- Initializes `min` to the largest possible integer.
- Iterates through collected candidates:
  - If `row[j] + col[j] < min`, updates `min`, clears list `f`, and adds this point.
  - If equal to `min`, adds this point to `f`.

### Selecting Minimum Row
- Initializes `m` to the largest possible integer.
- Iterates through points in `f`:
  - If point's `x` value is less than `m`, updates `m`, clears list `g`, and adds this point.
  - If equal to `m`, adds this point to `g`.

### Selecting Minimum Column
- Starts with first point in `g` as `z`.
- Iterates through remaining points in `g`:
  - If a point's `y` value is less than `z.y`, updates `z` to that point.

### Output
Prints the selected point's `y` coordinate first, then `x` coordinate.

## Key Data Dependencies
- The grid counts depend on all person positions and directions.
- The maximum count depends on the grid.
- Candidate points depend on the maximum count.
- The final selection depends on minimizing sum, then `x`, then `y` (with `x` and `y` being the reversed and original coordinates respectively).

## Loops
- Outer loop over test cases.
- Inner loop over people for input.
- Nested loops for grid population (two different patterns depending on direction).
- Nested loops for finding maximum.
- Nested loops for collecting candidates.
- Single loops for each selection step.

## Function Calls
- `Scanner.nextInt()` and `Scanner.next()` for input.
- `ArrayList` methods: `add`, `clear`, `get`, `size`.
- `Person` constructor.
- `System.out.println` for output.
