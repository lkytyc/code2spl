## Overview
This program simulates the placement of people into bathroom stalls according to a specific selection algorithm. It processes multiple test cases, each defining a row of stalls with occupied endpoints, and determines the final stall chosen after a given number of placements.

## Input
The program reads from standard input:
- First line: an integer T representing the number of test cases
- For each test case: a line containing two integers N and K, where N is the number of available stalls and K is the number of people to place

## Output
For each test case, the program prints a line in the format:
`Case #<case_number>: <y> <z>`
where y and z are the maximum and minimum distances (respectively) from the last placed person to the nearest occupied stall on either side.

## Data Structures
- `stall_occupied`: A boolean list of length N+2, where index 0 and index N+1 are always True (representing walls), and indices 1 through N represent actual stalls
- `Ls`: List tracking the distance from each stall to the nearest occupied stall on its left
- `Rs`: List tracking the distance from each stall to the nearest occupied stall on its right
- `Min_s`: List of minimum values between Ls and Rs for each stall
- `Max_s`: List of maximum values between Ls and Rs for each stall

## Initialization
For each test case:
1. Parse N and K from input
2. Create the stall array with walls at both ends (indices 0 and N+1) and all interior stalls initially unoccupied
3. For each stall position, compute initial Ls and Rs values:
   - For occupied stalls (walls): Ls and Rs are set to -1
   - For unoccupied stalls: Ls equals the distance to the nearest occupied stall on the left, Rs equals the distance to the nearest occupied stall on the right
4. Compute Min_s and Max_s for each stall based on Ls and Rs values

## Main Processing Loop
The program iterates K times to place K people:

### Stall Selection
For each placement:
1. Find the maximum value in Min_s
2. If multiple stalls share this maximum Min_s value:
   - Among those stalls, find the one with the highest Max_s value
   - If still tied, select the leftmost such stall
3. If only one stall has the maximum Min_s value, select that stall directly

### Placement and Update
After selecting stall index `idx`:
1. Record y = max(Ls[idx], Rs[idx]) and z = min(Ls[idx], Rs[idx])
2. Mark the stall as occupied
3. Set Ls[idx], Rs[idx], Min_s[idx], and Max_s[idx] all to -1

### Distance Updates
After placing a person at index `idx`:
1. **Leftward update**: Move left from idx-1 until hitting an occupied stall or the wall:
   - For each unoccupied stall encountered, update its Rs value to be the distance to the newly occupied stall
   - Recalculate Min_s and Max_s for each updated stall
2. **Rightward update**: Move right from idx+1 until hitting an occupied stall or the wall:
   - For each unoccupied stall encountered, update its Ls value to be the distance to the newly occupied stall
   - Recalculate Min_s and Max_s for each updated stall

## Control Flow
- The outer loop iterates through all test cases
- The initialization loop runs N+2 times to set up initial distances
- The main placement loop runs K times
- Within each placement, there are two while loops for updating distances (leftward and rightward)
- The selection logic contains conditional branches for handling ties in Min_s and Max_s values

## Dependencies
- Uses `numpy` for array operations when finding indices of maximum values
- Uses `sys` for standard input/output and error printing
- The `eprint` function is defined but not called in the main logic

## Final Output
After all K placements are complete, the program outputs the y and z values from the last placement, representing the maximum and minimum distances for the final person placed.
