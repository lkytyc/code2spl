## Overview
This program processes pairs of integers, normalizes them, groups equivalent pairs, and computes a combinatorial result modulo 10^9+7. The main computation involves counting subsets of vectors where no two vectors are perpendicular to each other.

## Input
- First line: integer `n` (number of pairs to process)
- Following `n` lines: each contains two integers `a` and `b`

## Output
- A single integer representing the final computed value modulo 10^9+7

## Main Processing Steps

### Input Collection and Normalization
For each of the `n` input pairs:
1. Read integers `a` and `b`
2. Normalize the pair:
   - If `a != 0` and `b == 0`, set `a = 1` (keeping `b = 0`)
   - If `a == 0` and `b != 0`, set `b = 1` (keeping `a = 0`)
   - If both are non-zero, divide both by their greatest common divisor
   - If both are zero, leave as-is
3. Ensure the pair is in a canonical sign form:
   - If both `a` and `b` are negative, negate both
   - If `a` is negative and `b` is positive, negate both
4. Create a string key from the normalized pair and increment counts in two dictionaries (`dic` and `dic1`)

### Main Computation
Initialize `ans = 1` and an empty dictionary `dic2` for tracking processed pairs.

For each unique key `e` in `dic`:
1. Parse the key back into integers `a` and `b`
2. Skip if either `a` or `b` is zero
3. Compute the "reverse" key (perpendicular vector):
   - If both `a` and `b` are positive: reverse key is `(b, -a)`
   - Otherwise: reverse key is `(-b, a)`
4. If the reverse key exists in `dic1` and hasn't been processed yet:
   - Mark both the current key and reverse key as processed in `dic2`
   - Skip further processing for this key
5. If not skipped:
   - Compute `n1 = 2^count(current_key) mod M`
   - Compute `n2 = 2^count(reverse_key) mod M`
   - Update `ans`:
     - If `n1 == 0`: multiply by `n2`
     - If `n2 == 0`: multiply by `n1`
     - Otherwise: multiply by `(n1 + n2 - 1)`
   - Apply modulo after each multiplication

### Handling Axis-Aligned Vectors
Compute `num` based on counts of two special keys:
- `'1 0'` (horizontal vector)
- `'0 1'` (vertical vector)

Logic:
- If both exist: `num = 2^count('1 0') + 2^count('0 1') - 1` (mod M)
- If only `'1 0'` exists: `num = 2^count('1 0')` (mod M)
- If only `'0 1'` exists: `num = 2^count('0 1')` (mod M)
- If neither exists: `num = 0`

If `num != 0`, multiply `ans` by `num` and apply modulo.

### Final Output
Print: `ans - 1 + count('0 0')`

## Key Data Structures
- `dic`: defaultdict(int) - counts of each normalized pair
- `dic1`: defaultdict(int) - duplicate of `dic` (same counts)
- `dic2`: defaultdict(int) - tracks which pairs have been processed with their perpendicular counterparts

## Helper Functions
- `inp()`: reads a single integer
- `inpm()`: reads two space-separated integers
- Various other input helpers (not used in main logic)

## Mathematical Context
The computation appears to count the number of subsets of vectors where no two vectors are perpendicular, using the principle that for each pair of perpendicular directions, you can choose vectors from only one direction (or none). The powers of 2 represent the number of ways to choose subsets from each direction group.
