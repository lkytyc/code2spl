# Code Structure Description

## Function: `len`
- **Input**: A character array `s` with maximum size 1001
- **Output**: Integer representing the length of the string
- **Behavior**: Iterates through the array using a `for` loop until it encounters the null terminator (`'\0'`), then returns the index where the loop stopped

## Main Function

### Inputs
- Reads an integer `t` from standard input (number of test cases)
- For each test case, reads an integer `n` (number of strings to process)

### Variable Declarations
- `s[10001]`: Character array for storing the final result
- `str[101]`: Temporary character array for reading input strings
- `a[n][10001]`: 2D character array for storing processed strings
- `flag`: Integer flag for error detection
- Various loop counters (`i`, `j`, `k`) and temporary variables

### Initialization Phase
- For each test case, initializes all elements of the 2D array `a` to `'#'` using nested loops

### Input Processing Phase
- For each of the `n` strings:
  - Reads a character into `dd` (likely to consume a newline)
  - Reads a string into `str`
  - **Branch 1**: If the first character of `str` is `'*'`:
    - Places the string (including the `*`) at the end of row `j` in array `a`, starting from position 10000 and moving backward
  - **Branch 2**: If the last character of `str` is `'*'`:
    - Places the string at the beginning of row `j` in array `a`, starting from position 0

### Result Construction Phase
- Iterates through columns 0 to 9999 of array `a`
- For each column:
  - Iterates through all `n` rows
  - **Logic**:
    - If a character has already been found in this column (`f==1`) and the current character doesn't match the previously found character (and isn't `'*'` or `'#'`), sets `flag=1` and breaks
    - If the current character is not `'*'` or `'#'` and no character has been found yet in this column, stores it in result array `s` and sets `f=1`
  - If `flag` is set, breaks out of the column loop

### Output Phase
- Adds null terminator to result string `s`
- **Branch**: If `flag==1`, prints `Case #X: *` (indicating conflict)
- **Otherwise**: Prints `Case #X: <result string>`

### Control Flow Summary
- Outer loop: Iterates through test cases
- Middle loops: Process input strings and construct result
- Inner loops: Handle character-by-character comparison
- Early termination: Breaks out of loops when conflict is detected

### Data Dependencies
- Result construction depends on all processed input strings
- The `flag` variable controls whether the final output is the constructed string or an asterisk
- The `len` function is called to determine string lengths for positioning in the array
