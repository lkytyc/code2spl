## Inputs
- The program reads from standard input using a Scanner.
- First two integers read are T (number of test cases) and F (a fixed value that is read but not used in logic).
- For each test case, the program reads character responses from standard input after printing queries.

## Outputs
- The program prints integer queries to standard output (positions to query).
- After each test case, it prints a 5-character string (the solution for that test case).
- The main method reads a single character response after each test case solution is printed.

## Control Flow

### Main Method
- Creates a Scanner on standard input.
- Calls solve() with the Scanner.

### solve() Method
- Reads T and F from input.
- Loops T times (for each test case):
  - Calls solveSingle() and prints the returned string.
  - Reads a single character response (verification result) from input.

### solveSingle() Method
- Initializes a StringBuilder for the solution.
- Creates a list of characters: A, B, C, D, E.
- Creates a HashMap mapping each character to an empty ArrayList of integers.

#### First Phase (Finding First Character)
- Loops 119 times (i from 0 to 118):
  - Calculates position c = i * 5 + 1.
  - Prints c to output.
  - Reads a character response.
  - Adds c to the list associated with that character in the map.

- Iterates through the map entries:
  - For each character whose list size is NOT 24:
    - Appends that character to the solution.
    - Removes it from the chars list.
    - Creates a new map (occ4) for the remaining 4 characters.

#### Second Phase (Finding Second Character)
- Loops 23 times (i from 0 to 22):
  - Calculates position c = i * 5 + 2.
  - Prints c to output.
  - Reads a character response.
  - Adds c to the list for that character in occ4.

- Iterates through occ4 entries:
  - For each character whose list size is NOT 6:
    - Appends that character to the solution.
    - Removes it from chars list.
    - Creates a new map (occ3) for the remaining 3 characters.

#### Third Phase (Finding Third Character)
- Loops 5 times (i from 0 to 4):
  - Calculates position c = i * 5 + 3.
  - Prints c to output.
  - Reads a character response.
  - Adds c to the list for that character in occ3.

- Iterates through occ3 entries:
  - For each character whose list size is NOT 2:
    - Removes that character from chars list.
    - Appends that character to the solution.
    - Calculates askLast = first element of that character's list + 1.
    - Prints askLast to output.
    - Reads a character response (n).
    - Iterates through remaining chars:
      - Appends the first character that is NOT equal to n, then breaks.
    - Appends n to the solution.

#### Return
- Returns the completed solution string.

## Data Dependencies
- The solution string is built incrementally through three nested conditional phases.
- Each phase depends on the character counts from the previous phase.
- The final two characters are determined by the last query response.
- The chars list is progressively reduced as characters are identified.
- The maps track which positions returned which characters at each query level.

## Key Logic
- The algorithm identifies characters by their frequency distribution across query positions.
- At each level, the character with an "unusual" count (not matching the expected pattern) is identified.
- The expected counts are: 24 out of 119 for the first position, 6 out of 23 for the second, 2 out of 5 for the third.
- The last two characters are determined by a final query and elimination.
