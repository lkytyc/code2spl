# Structured Description

## Overview
This program reads text from standard input, converts lowercase letters to uppercase letters, preserves periods, and outputs the transformed text with words separated by single spaces.

## Inputs
- Reads from standard input using a Scanner object
- Processes tokens (words) separated by whitespace
- Continues reading until end of input is reached

## Outputs
- Prints a single StringBuffer containing the transformed text to standard output
- The output has all lowercase letters converted to uppercase
- Periods are preserved as-is
- Original words are separated by single spaces in the output

## Data Structures
- Two string arrays are defined:
  - `b`: contains uppercase letters A through Z (26 elements)
  - `s`: contains lowercase letters a through z (26 elements)
- A StringBuffer field named `max` is used to accumulate the output

## Control Flow

### Main Method
- Creates a new Main object and calls its `run()` method

### Run Method
1. Initializes the uppercase and lowercase letter arrays
2. Initializes the StringBuffer `max` as empty
3. Enters a while loop that continues as long as the Scanner has more tokens

### While Loop (per input token)
- Reads the next token as a string named `min`
- Enters a for loop iterating through each character position in `min`

### For Loop (per character)
- Extracts a single-character substring at the current position
- Checks if the character is a period (`.`):
  - If yes: appends the period to `max`
  - If no: enters an inner for loop searching through the lowercase array

### Inner For Loop (letter matching)
- Iterates through all 26 lowercase letters
- If the current character matches a lowercase letter:
  - Appends the corresponding uppercase letter (from array `b` at the same index) to `max`
  - Continues to the next character in the outer loop

### After Processing Each Token
- Appends a space to `max`

### After While Loop Ends
- Deletes the last character from `max` (removes the trailing space)
- Prints the contents of `max`

## Function Calls
- `scan.hasNext()`: checks for more input tokens
- `scan.next()`: reads the next token
- `min.substring(i, i+1)`: extracts a single character
- `str.equals(...)`: string comparison
- `max.append(...)`: appends to StringBuffer
- `max.delete(...)`: removes characters from StringBuffer
- `System.out.println(max)`: outputs the result

## Data Dependencies
- The output depends entirely on the input tokens read
- The mapping between lowercase and uppercase is fixed by the parallel arrays `s` and `b`
- The index position in array `s` determines which uppercase letter from array `b` is used

## Edge Cases
- Non-letter, non-period characters are ignored (not appended to output)
- Multiple consecutive spaces in input are collapsed to single spaces in output
- The final output has no trailing space
- Empty input produces empty output (the delete operation on an empty StringBuffer would be a no-op)
