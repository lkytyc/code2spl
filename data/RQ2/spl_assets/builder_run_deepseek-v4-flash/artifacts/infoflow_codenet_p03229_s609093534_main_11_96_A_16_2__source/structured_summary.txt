# Code Description

## Input
- Reads an integer `N` from standard input
- Then reads `N` integers into array `A` (maximum size 100,000)

## Output
- Prints a single integer (as a long long) representing the maximum sum of absolute differences between adjacent elements in a rearranged array

## Main Algorithm

### Special Case
- If `N == 2`, the program prints the absolute difference between the two input values and exits immediately

### Sorting
- The array `A` is sorted in ascending order using `qsort` with a custom comparator function `int_sort`
- `int_sort` compares two integers and returns -1, 0, or 1 based on their relative order

### Array B Construction
- Creates array `B` of size 100,000
- Places the smallest element (`A[0]`) at the middle position (`pos = N/2`)
- Uses two pointers: `beg` starting at index 1, `end` starting at `N-1`
- Alternates between two filling modes:
  - Mode 1: Takes elements from the end of sorted array, placing them at positions `pos-offset` and `pos+offset`
  - Mode 0: Takes elements from the beginning of sorted array (after the first element), placing them at positions `pos-offset` and `pos+offset`
- Continues until all elements are placed, incrementing `offset` each iteration

### Array C Construction
- Creates array `C` of size 100,000
- Places the largest element (`A[N-1]`) at the middle position (`pos = N/2`)
- Uses two pointers: `beg` starting at index 0, `end` starting at `N-2`
- Alternates between two filling modes:
  - Mode 1: Takes elements from the end of sorted array (excluding the last), placing them at positions `pos-offset` and `pos+offset`
  - Mode 0: Takes elements from the beginning of sorted array, placing them at positions `pos-offset` and `pos+offset`
- Continues until all elements are placed, incrementing `offset` each iteration

### Sum Calculation
- Computes `sumB`: the sum of absolute differences between consecutive elements in array `B`
- Computes `sumC`: the sum of absolute differences between consecutive elements in array `C`

### Final Output
- Prints the larger of `sumB` and `sumC`

## Control Flow
- Two infinite loops (with break conditions) for array construction
- Conditional logic based on a `flag` variable to alternate between taking from the beginning or end of the sorted array
- Break conditions check if the beginning pointer has passed the end pointer

## Data Dependencies
- Array B construction depends on sorted array A
- Array C construction depends on sorted array A
- Sum calculations depend on arrays B and C respectively
- Final output depends on comparison of both sums
