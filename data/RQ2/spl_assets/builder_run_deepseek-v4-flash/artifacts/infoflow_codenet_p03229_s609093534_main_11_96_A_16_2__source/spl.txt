[DEFINE_WORKER: "Reads N and an array A, sorts A, constructs two symmetric zigzag arrangements B and C around the middle, computes their total adjacent absolute differences, and prints the larger sum (with N == 2 handled as a direct absolute-difference special case)." main]
    [INPUTS]
        <REF> stdin </REF>: standard input stream "Whitespace-separated integers: first N, then N integers to store in A. The code does not validate N; the general path is only well-defined for N at least 3 and at most 100000."
    [END_INPUTS]

    [OUTPUTS]
        <REF> stdout </REF>: standard output stream "For N == 2, prints abs(A[0] - A[1]) followed by a newline. Otherwise prints the larger of sumB and sumC followed by a newline."
        <REF> exit_status </REF>: int "Returns 0 after the selected path completes."
    [END_OUTPUTS]

    [MAIN_FLOW]
        [SEQUENTIAL_BLOCK]
            [COMMAND Declare integer N and integer array A of size 100000. Read one integer from standard input into N; if the read fails, N remains uninitialized. RESULT N]
            [COMMAND For i from 0 to N-1 inclusive, read one integer from standard input into A[i]. No size validation is performed, so N must not exceed 100000 for safe access. RESULT A]
            [COMMAND Test whether N equals 2. If true, follow the special-case alternative flow; if false, continue with the general path below. For N less than 2, the general path would access invalid array indices. RESULT branch_condition]
            [COMMAND Sort the first N elements of A in place in ascending order using qsort with element size sizeof(A[0]) and comparator int_sort. RESULT A]
            [COMMAND Declare integer array B of size 100000. Compute pos = N / 2. Store the sorted minimum A[0] into B[pos]. Initialize beg = 1, end = N - 1, flag = 1, offset = 1. RESULT B]
            [COMMAND Run the first while loop, filling B symmetrically around pos. While true, if flag equals 1, consume from the end of the remaining sorted range: assign A[end--] to B[pos-offset], break if end < beg, then assign A[end--] to B[pos+offset], break if end < beg, and set flag to 0; otherwise consume from the beginning: assign A[beg++] to B[pos-offset], break if end < beg, then assign A[beg++] to B[pos+offset], break if end < beg, and set flag to 1. After each completed iteration, increment offset. Continue until a break occurs. RESULT B]
            [COMMAND Declare integer array C of size 100000. Store the sorted maximum A[N-1] into C[pos]. Initialize beg = 0, end = N - 2, flag = 0, offset = 1. RESULT C]
            [COMMAND Run the second while loop, filling C symmetrically around pos. While true, if flag equals 1, consume from the end of the remaining sorted range: assign A[end--] to C[pos-offset], break if end < beg, then assign A[end--] to C[pos+offset], break if end < beg, and set flag to 0; otherwise consume from the beginning: assign A[beg++] to C[pos-offset], break if end < beg, then assign A[beg++] to C[pos+offset], break if end < beg, and set flag to 1. After each completed iteration, increment offset. Continue until a break occurs. RESULT C]
            [COMMAND Initialize sumB to 0. For i from 1 to N-1 inclusive, add abs(B[i-1] - B[i]) to sumB. RESULT sumB]
            [COMMAND Initialize sumC to 0. For i from 1 to N-1 inclusive, add abs(C[i-1] - C[i]) to sumC. RESULT sumC]
            [COMMAND Skip the preprocessor-disabled #if 0 debug printing block. Compare sumB and sumC; if sumB < sumC, print sumC followed by a newline, otherwise print sumB followed by a newline. RESULT final_output]
            [COMMAND Return 0 from main. RESULT exit_status]
        [END_SEQUENTIAL_BLOCK]
    [END_MAIN_FLOW]

    [ALTERNATIVE_FLOW: N equals 2]
        [SEQUENTIAL_BLOCK]
            [COMMAND Compute the absolute difference between A[0] and A[1]. RESULT special_difference]
            [COMMAND Print special_difference as an integer followed by a newline. RESULT special_output]
            [COMMAND Return 0 from main, skipping all remaining code. RESULT exit_status]
        [END_SEQUENTIAL_BLOCK]
    [END_ALTERNATIVE_FLOW]

[END_WORKER]
