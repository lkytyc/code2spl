# Structured Description

## Overview
This program solves a knapsack-style optimization problem with a time constraint split into two phases. It reads items with two attributes each, computes optimal selections for two separate time intervals, and combines results to find the maximum total value.

## Inputs
- First line: three integers
  - `n`: number of items
  - `t`: total time limit
  - `s`: boundary time separating the two phases
- Next `n` lines: two integers each
  - `as[i]`: value of item `i`
  - `bs[i]`: time cost of item `i`

## Outputs
- A single integer printed to standard output: the maximum total value achievable

## Data Structures
- `dp1`: array of size `s+1`, initialized to -1 except `dp1[0]=0`
- `dp2`: array of size `n+1`, initialized to 0
- `dp3`: array of size `t-s+1`, initialized to -1 except `dp3[0]=0`
- `dp4`: array of size `n+1`, initialized to 0

## Control Flow

### Phase 1: Forward pass (items 0 to n-1)
- Iterate over items in forward order (index `i` from 0 to n-1)
- For each item, iterate over time capacities `j` from `s` down to 0
- If `dp1[j]` is non-negative (reachable state):
  - Check if adding item `i` keeps total time within `s`
  - If so, update `dp1[bs[i]+j]` with the maximum of its current value and `dp1[j] + as[i]`
  - Update `dp2[i+1]` with the maximum of its current value and the newly computed `dp1[bs[i]+j]`

### Post-processing for dp2
- After the forward pass, iterate `i` from 1 to n
- Set `dp2[i]` to the maximum of `dp2[i]` and `dp2[i-1]`

### Phase 2: Backward pass (items n-1 to 0)
- Iterate over items in reverse order (index `i` from n-1 down to 0)
- For each item, iterate over time capacities `j` from `t-s` down to 0
- If `dp3[j]` is non-negative:
  - Check if adding item `i` keeps total time within `t-s`
  - If so, update `dp3[bs[i]+j]` with the maximum of its current value and `dp3[j] + as[i]`
  - Update `dp4[n-i]` with the maximum of its current value and the newly computed `dp3[bs[i]+j]`

### Post-processing for dp4
- After the backward pass, iterate `i` from 1 to n
- Set `dp4[i]` to the maximum of `dp4[i]` and `dp4[i-1]`

### Final combination
- Initialize `max` to 0
- Iterate `i` from 0 to n-1
- For each `i`, compute `dp2[i] + dp4[n-i]` and update `max` if this sum is larger
- Print `max`

## Key Logic
- The problem is split at time boundary `s`
- Phase 1 considers items in original order for the first time segment (capacity `s`)
- Phase 2 considers items in reverse order for the second time segment (capacity `t-s`)
- The `dp2` and `dp4` arrays track the best value achievable using a prefix (for forward) or suffix (for backward) of items
- The final loop combines a prefix solution from phase 1 with a suffix solution from phase 2, ensuring no item is used in both phases

## Function Calls
- `run()`: main logic, called from `main`
- `main(String[] args)`: entry point, creates a `Main` instance and calls `run()`
- `debug(Object... os)`: prints debug information to standard error (not called in main logic)

## Dependencies
- `dp2[i]` depends on `dp1` values computed from items 0 through i-1
- `dp4[n-i]` depends on `dp3` values computed from items n-1 down to i
- The final result depends on both `dp2` and `dp4` arrays
