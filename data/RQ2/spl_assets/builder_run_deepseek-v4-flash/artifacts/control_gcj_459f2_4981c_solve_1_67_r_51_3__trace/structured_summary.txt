# Structured Description of Code

## Function: solve(B)

### Input
- B: A list of integers representing ball counts at each column position.

### Output
- Returns a tuple containing:
  - Either the string 'IMPOSSIBLE' with None as the second element, OR
  - An integer representing the number of rows in the solution grid, and a list of lists (grid) containing characters '.' , '/' , or '\\'.

### Initial Validation
- Checks if the first element (B[0]) or last element (B[-1]) equals zero.
- If either is zero, immediately returns ('IMPOSSIBLE', None).

### Grid Initialization
- Creates a square grid of size C x C (where C is the length of B), initially filled with '.' characters.
- Creates a shadowed list of boolean values, all initially False, with the same length as B.
- Sets shadowed[0] to True.
- Decrements B[0] and B[-1] by 1.

### Main Processing Loop
Iterates through each index i from 0 to C-1:

#### Branch 1: Skip Condition
- If B[i] equals 0 AND shadowed[i] is True, skips to next iteration.

#### Branch 2: Unshadowed with Positive Balls
- If B[i] is greater than 0 AND shadowed[i] is False:
  - Scans leftward from position i-1 while j >= 1 and shadowed[j] is False.
  - For each such position, places '\\' in the grid at row l, column j.
  - Marks those positions as shadowed.
  - Counts how many unshadowed balls were found.
  
  - Sub-branch A: If B[i] is less than or equal to the count of unshadowed balls:
    - Calculates excess balls as (unshadowed_balls - B[i] + 1).
    - Moves leftward from position i, decrementing excess_balls and unshadowing positions until excess_balls equals 1.
  
  - Sub-branch B: Otherwise (B[i] exceeds unshadowed balls):
    - Reduces B[i] by (unshadowed_balls + 1).
    - Marks position i as shadowed.

#### Branch 3: Shadowed with Positive Balls
- If B[i] is greater than 0 AND shadowed[i] is True:
  - Sets r equal to B[i].
  - Scans rightward from position i+1 while j < (C-1) AND shadowed[j] is True.
  - Places '/' characters in the grid at row l, column j for each such position.
  - Then continues scanning rightward while j < (C-1) AND r > 0:
    - Places '/' at row l, column j.
    - Marks position j as shadowed.
    - Decrements r.
    - Increments l and j.

### Output Grid Construction
- Builds answer list by iterating through grid rows from index 1 to C-1.
- For each row, checks if it contains any '/' or '\\' characters.
- Includes rows that contain such characters; stops at the first row that doesn't.
- Prepends a row of all '.' characters to the answer.
- Returns (number of rows in answer, answer grid).

## Function: main()

### Input
- Reads from standard input:
  - First line: integer T (number of test cases).
  - For each test case:
    - An integer S (appears unused in logic).
    - A line of space-separated integers representing B.

### Processing
- For each test case (t from 1 to T):
  - Calls solve(B) to get result and grid.
  - Prints "Case #{t}: {result}" where result is either 'IMPOSSIBLE' or the row count.
  - If grid is not None, prints the grid rows in reverse order (from last row to first).

### Program Entry Point
- Checks if script is run directly (__name__ == "__main__") and calls main().

## Key Data Dependencies
- The shadowed list tracks which positions have been "covered" by ramps.
- The grid stores the visual representation of ramps.
- B is modified in-place during processing (decremented).
- The leftward scan in Branch 2 depends on shadowed status of positions to the left.
- The rightward scan in Branch 3 depends on shadowed status of positions to the right.
- The final grid construction depends on which rows contain ramp characters.
