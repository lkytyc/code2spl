# Code Description

## Program Overview
This is a Java program that reads input, processes it through a dynamic programming algorithm, and outputs a single numeric result. The main computation is performed in the `solve()` method.

## Input Handling
- The program reads from `System.in` by default, or from a string constant `INPUT` if it is non-empty.
- Input is parsed using custom fast I/O methods: `ni()` for integers, `nl()` for longs, `ns()` for strings, `nd()` for doubles, and `nc()` for characters.
- The input parser uses a buffered byte array (`inbuf`) with methods `readByte()`, `skip()`, and `isSpaceChar()` to handle tokenization.
- Whitespace is defined as any character outside the ASCII range 33–126.

## Main Program Flow
1. The `main` method initializes the input stream and output writer.
2. It calls `solve()` to perform the core computation.
3. After `solve()` completes, the output is flushed.
4. If the `INPUT` string is non-empty, timing information is printed via `tr()`.

## Core Algorithm (`solve()` method)

### Inputs
- Reads three integers: `n`, `A`, and `B`.
- Reads an array `P` of `n` integers.
- Each element of `P` is decremented by 1 (converting from 1-based to 0-based indexing).

### Dynamic Programming Table
- A 2D array `dp` of size `(n+1) × (n+1)` is created.
- All entries are initialized to `Long.MAX_VALUE / 2` (a large sentinel value representing infinity).

### DP Transition Rules
The DP table is filled using nested loops over indices `i` and `j` from 0 to `n`:

1. **Base case**: When both `i` and `j` are 0, `dp[0][0]` is set to 0.

2. **Match case**: If both `i-1 ≥ 0` and `j-1 ≥ 0`, and `P[i-1] == j-1`, then `dp[i][j]` is set to `dp[i-1][j-1]` (no cost added).

3. **Otherwise** (non-match case):
   - If `i-1 ≥ 0`, consider transitioning from `dp[i-1][j]` and add cost `B` if `P[i-1] ≤ j`, otherwise add cost `A`. Take the minimum with the current value.
   - If `j-1 ≥ 0`, consider transitioning from `dp[i][j-1]` with no additional cost. Take the minimum with the current value.

### Output
- After filling the DP table, the program prints `dp[n][n]` as the final result.

## Helper Methods

### Input Parsing Methods
- `eof()`: Checks if the end of the input stream has been reached by peeking ahead.
- `readByte()`: Reads the next byte from the input buffer, handling buffer refills.
- `skip()`: Skips whitespace characters and returns the first non-whitespace byte.
- `ns()`: Reads a string token.
- `ns(int n)`: Reads up to `n` characters as a char array.
- `nm(n, m)`: Reads an `n × m` character grid.
- `na(n)`: Reads an array of `n` integers.
- `ni()`: Reads an integer, handling negative numbers.
- `nl()`: Reads a long integer, handling negative numbers.

### Debug/Utility
- `tr(Object... o)`: Prints debug output only when the `INPUT` string is non-empty.

## Data Dependencies
- The DP computation depends on the input values `n`, `A`, `B`, and the array `P`.
- Each `dp[i][j]` value depends on previously computed values at `dp[i-1][j-1]`, `dp[i-1][j]`, and `dp[i][j-1]`.

## Control Flow
- The program uses nested loops for DP table filling.
- Conditional logic determines which transition rule applies based on index bounds and the match condition.
- The `main` method has a try-catch structure for exception handling, though no explicit exceptions are thrown in the main flow.
