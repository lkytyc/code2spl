## Function: solve(n, t, ab_list)

### Inputs
- `n`: integer, number of items
- `t`: integer, time limit
- `ab_list`: list of pairs, each pair containing two integers (a, b)

### Processing Steps

**Step 1: Separate items by first component**
- Creates `a0b_list` containing only the second component (b) from all pairs where the first component equals 0
- Creates `apb_list` containing all pairs where the first component is greater than 0

**Step 2: Sort the lists**
- `a0b_list` is sorted in ascending order
- `apb_list` is sorted in descending order based on the ratio `a / (b + 1)` for each pair

**Step 3: Dynamic programming table construction**
- `m` is set to the length of `apb_list`
- Creates a 2D table `dp` with dimensions (m+1) × 30, initialized with value `t+1`
- Sets the first column (index 0) of every row to 0
- For each item `i` in `apb_list` (0 to m-1) and each count `k` from 1 to 29:
  - Computes `ti` as `dp[i][k-1] + 1`
  - Extracts `a` and `b` from the current item
  - Updates `dp[i+1][k]` as the minimum of `dp[i][k]` and `ti + a*ti + b`

**Step 4: Cumulative sum for zero-a items**
- Creates `a0b_list_cum_sum` starting with 0
- For each `b` in `a0b_list`, adds `b + 1` to the running sum and appends to the cumulative list

**Step 5: Result computation**
- Initializes `res` to 0
- For each possible count `k` from 0 to length of `a0b_list_cum_sum` minus 1:
  - For each possible count `p` from 0 to 29:
    - If `dp[m][p] + a0b_list_cum_sum[k]` is less than or equal to `t`:
      - Updates `res` to the maximum of current `res` and `k + p`

### Output
- Returns `res`, the maximum total number of items that can be processed within the time limit

## Function: main()

### Inputs
- Reads two integers from standard input: `n` and `t`
- Reads `n` lines, each containing two integers, forming `ab_list`

### Processing
- Calls `solve(n, t, ab_list)` with the parsed inputs

### Output
- Prints the result returned by `solve`

## Function: test()

### Behavior
- Contains three assertion statements testing the `solve` function with specific inputs:
  1. `solve(3, 7, [[2, 0], [3, 2], [0, 3]])` should return 2
  2. `solve(1, 3, [[0, 3]])` should return 0
  3. `solve(5, 21600, [[2, 14], [3, 22], [1, 3], [1, 10], [1, 9]])` should return 5

## Program Entry Point

- When executed as the main module, calls `test()` first, then calls `main()`
- If any test assertion fails, the program will terminate with an assertion error before reaching `main()`
