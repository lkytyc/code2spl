## Inputs
The program reads from standard input. It first reads an integer `T` representing the number of test cases. For each test case, it reads an integer `n` followed by `n` pairs of long integers, each pair representing two values stored in a two-column array `A`.

## Outputs
For each test case, the program outputs a line in the format `Case #X: Y` where `X` is the test case number (starting from 1) and `Y` is the size of a set `S` computed during processing.

## Data Structures
- `A`: A 2D long array of size `n × 2` storing the input pairs.
- `S`: A set of lists of integers, where each list represents an ordering of indices.
- `S3`: A set of long values containing the value 1 and all values from both columns of `A`.
- `S2`: A temporary set of long values used to check uniqueness of computed scores.
- `B`: A list of `Temp` objects, each holding an index and a computed score.
- `C`: A list of integers representing indices in sorted order.

## Control Flow

### Main Loop
The program iterates through each test case from 1 to `T`.

### Input Processing
For each test case:
1. Reads `n`.
2. Initializes `A`, `S`, and `S3`.
3. Adds the constant value 1 to `S3`.
4. Reads all `n` pairs into `A` and adds each value from both columns to `S3`.

### Nested Loops for Score Generation
The program executes four nested loops:
- Outer loop over each value `a` in `S3`
- Second loop over each value `b` in `S3`
- Third loop over `c` from 1 to 2
- Fourth loop over `d` from 1 to 2

For each combination of `(a, b, c, d)`:
1. Creates empty lists `B` and `C`, and empty set `S2`.
2. For each index `i` from 0 to `n-1`, computes a score: `A[i][0] * a * c + A[i][1] * b * d`.
3. Adds this score to both list `B` (as a `Temp` object with the index) and set `S2`.
4. Checks if `S2` has size equal to `n`. If not (meaning duplicate scores exist), skips this combination.
5. If all scores are unique, sorts list `B` using the natural ordering of `Temp` objects (by score ascending).
6. Builds list `C` by extracting indices from the sorted `B`.
7. Adds `C` to set `S`.

### Output
After all nested loops complete, prints the size of set `S` for the current test case.

## Function Calls
- `Scanner.nextInt()` and `Scanner.nextLong()` for input reading.
- `Collections.sort()` for sorting the list of `Temp` objects.
- `Set.add()` and `Set.size()` operations.
- `List.add()` operations.

## Comparison Logic
The `Temp` class implements `Comparable<Temp>` with a `compareTo` method that:
- Returns -1 if this object's score is less than the other's score
- Returns 1 if this object's score is greater than the other's score
- Returns 0 if scores are equal

## Data Dependencies
- The set `S3` depends on all input values plus the constant 1.
- The scores computed in the nested loops depend on the current values of `a`, `b`, `c`, `d`, and the input array `A`.
- The contents of `S` depend on which combinations produce unique scores and the resulting sorted order of indices.
- The final output depends on the size of `S`, which accumulates unique index orderings across all valid combinations.

## Termination
The program terminates after processing all `T` test cases and closing the scanner.
