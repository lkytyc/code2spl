# Code Description

## Overview
This program solves a Rock-Paper-Scissors tournament problem. It reads multiple test cases, each containing a set of robot programs (strings of R, P, S characters), and determines a single winning sequence of moves that beats all robots, or reports "IMPOSSIBLE" if no such sequence exists.

## Input
- First line: integer T (number of test cases)
- For each test case:
  - Integer A (number of robots)
  - A lines, each containing a string of characters from {R, P, S} representing a robot's cyclic move pattern

## Output
- For each test case: "Case #i: " followed by either:
  - A string of moves (R, P, S) that beats all robots
  - "IMPOSSIBLE" if no such string exists

## Main Control Flow
1. Read T from standard input
2. Loop through each test case (i from 1 to T):
   - Read A (number of robots)
   - Read each robot's pattern string C[j] and store its length L[j]
   - Print "Case #i: " prefix
   - Call solve(A, C, L)

## Function: solve(A, C, L)
Builds the answer string character by character:

### Initialization
- ans = empty string
- pos = 0 (current position index)
- isAlive = list of A booleans, all initially True

### Main Loop (while True)
1. **Check termination**: If no robots are alive, print ans and return
2. **Collect possibilities**: For each alive robot i:
   - Determine its move at position pos % L[i]
   - Mark that move (R, S, or P) as possible
   - Track which robots predict each move (predR, predS, predP lists)
   - If all three moves are possible simultaneously, print "IMPOSSIBLE" and return
3. **Handle single-move cases**:
   - Only R possible: append "P" to ans, print ans, return
   - Only S possible: append "R" to ans, print ans, return
   - Only P possible: append "S" to ans, print ans, return
4. **Length limit**: If ans length reaches 500, print "IMPOSSIBLE" and return
5. **Handle two-move cases**:
   - R and S possible: kill all S-predicting robots, append "R" to ans
   - R and P possible: kill all R-predicting robots, append "P" to ans
   - S and P possible: kill all P-predicting robots, append "S" to ans
6. Increment pos and continue loop

## Function: isCycleCorrect(A, C, L, ans)
Verification function (not called in main flow):
- For each robot i, checks if ans beats the robot's pattern
- Compares moves at each position using modulo arithmetic
- Returns False if robot beats ans at any position
- Returns True only if all robots are beaten by ans

## Data Dependencies
- Each robot's move at position pos is C[i][pos % L[i]]
- Answer character at position pos is ans[pos % len(ans)]
- Robot survival depends on previous answer characters
- The possibilities dictionary tracks which moves appear among alive robots at current position

## Key Logic
- Rock (R) beats Scissors (S)
- Scissors (S) beats Paper (P)
- Paper (P) beats Rock (R)
- When two moves are possible, the answer chooses the move that beats one of them, eliminating those robots
- When only one move is possible, the answer chooses the move that beats it, completing the solution
