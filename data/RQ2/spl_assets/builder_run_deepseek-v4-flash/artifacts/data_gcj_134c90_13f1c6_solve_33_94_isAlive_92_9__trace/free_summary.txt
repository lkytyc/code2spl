This code solves a rock-paper-scissors tournament problem. It reads multiple test cases, each with a number of players and their move patterns (strings of R, P, S). For each case, it tries to construct a sequence of moves that beats all players, eliminating players whose moves lose to the current answer sequence. If a single move can beat all remaining players, it outputs that sequence; if no valid sequence exists within 500 moves, it prints "IMPOSSIBLE".
