## Function: bfs

### Inputs
- `sx`, `sy`: integer coordinates representing the starting position
- `spx`, `spy`: integer arrays of equal length representing a sequence of target positions

### Outputs
- Returns `true` if all target positions can be reached in sequence, `false` otherwise

### Local Variables and Initialization
- `size` is set to 10, representing a 10×10 grid
- `spCnt` is initialized to 0, tracking how many target positions have been processed
- Two movement arrays are defined:
  - `dx`, `dy`: 12 possible knight-like moves (combinations of ±2 in one axis and ±1 in the other)
  - `dx2`, `dy2`: 9 possible moves including staying in place and all 8 adjacent cells (including diagonals)
- A boolean 2D array `park` is created with all cells initially `false`
- Two queues `queueX` and `queueY` are initialized with the starting coordinates

### Control Flow

#### Main Loop
- Continues while `queueX` is not empty
- At the start of each iteration, checks if `spCnt` equals the length of `spx`; if so, returns `true` immediately

#### Target Marking Phase
- For the current target position (`spx[spCnt]`, `spy[spCnt]`), marks all cells reachable by the 9 moves in `dx2`/`dy2` as `true` in the `park` array
- Only marks cells that are within the 10×10 grid boundaries (coordinates 0–9 inclusive)

#### Position Expansion Phase
- Creates two new empty queues `nx` and `ny`
- Processes all positions currently in `queueX`/`queueY`:
  - For each position, tries all 12 knight moves from `dx`/`dy`
  - A move is valid if the resulting coordinates are within the 10×10 grid AND the destination cell in `park` is `true`
  - Valid destinations are added to the new queues

#### State Update
- Increments `spCnt` by 1
- Resets `park` to a fresh all-`false` 10×10 array
- Replaces `queueX`/`queueY` with the new queues `nx`/`ny`

### Termination
- Returns `true` if all targets are processed successfully
- Returns `false` if the queue becomes empty before all targets are processed

## Function: main

### Inputs
- Reads from standard input using a `Scanner`

### Control Flow
- Runs an infinite loop until explicitly broken
- Reads `sx` and `sy` as integers
- If both are 0, breaks the loop
- Reads `n` as the number of target positions
- Reads `n` pairs of integers into arrays `spx` and `spy`
- Calls `bfs(sx, sy, spx, spy)` and prints `"OK"` if it returns `true`, otherwise prints `"NA"`

### Data Dependencies
- The input format expects: starting x, starting y, then n, then n pairs of x,y coordinates
- The loop continues processing multiple test cases until a 0 0 input is encountered
