# Code Description

## Function: `calc(h, w)`

### Inputs
- Integer parameters `h` (height) and `w` (width)
- Reads `h` lines of strings from standard input, each of length `w`, using `scanf("%s", row)`

### Local Data Structures
- A 2D integer array `panel` of dimensions `h` × `w`
- A character array `row` of length `w` used as a temporary buffer for reading input

### Processing Steps

#### Step 1: Input Parsing (lines 6–20)
- Loops over each row index `i` from 0 to `h-1`
- For each row, reads a string into `row`
- Loops over each column index `j` from 0 to `w-1`
- If the character at `row[j]` is `#`, sets `panel[i][j]` to `-1`
- Otherwise, sets `panel[i][j]` to `0`

#### Step 2: Neighbor Counting (lines 21–64)
- Nested loops iterate over all cells in `panel`
- For each cell:
  - If the cell value is `-1` (a mine), skips to the next cell
  - Otherwise, initializes a counter `count` to 0
  - Checks all 8 neighboring positions (up-left, up, up-right, left, right, down-left, down, down-right)
  - For each neighbor that is within bounds and has value `-1`, increments `count`
  - After checking all neighbors, assigns `count` to `panel[i][j]`

#### Step 3: Output (lines 65–79)
- Nested loops iterate over all cells in `panel`
- For each cell:
  - If value is `-1`, prints `#`
  - Otherwise, prints the numeric value
- After each row, prints a newline character

### Return Value
- Always returns `0`

## Function: `main()`

### Inputs
- Reads two integers `h` and `w` from standard input using `scanf("%d %d", &h, &w)`

### Processing
- Calls `calc(h, w)`

### Return Value
- Always returns `0`

## Control Flow Summary
- Three sequential nested-loop phases: input reading, neighbor counting, and output
- Conditional branches for mine detection (`#` vs. other characters)
- Boundary checks for all 8 neighbor positions to avoid array out-of-bounds access
- No loops other than the three main nested-loop structures
- No recursive calls or external function calls other than `scanf` and `printf`
