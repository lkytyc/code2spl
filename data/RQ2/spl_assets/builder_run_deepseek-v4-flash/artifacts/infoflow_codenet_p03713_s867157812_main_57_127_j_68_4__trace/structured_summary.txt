# Code Description

## Overview
This program reads two integers representing the height and width of a rectangle, then calculates the minimum possible difference in area when dividing the rectangle into three rectangular pieces using straight cuts.

## Input
- Two integers `h` and `w` read from standard input via `scanf("%d %d", &h, &w)`

## Output
- A single long long integer printed with `printf("%lld\n", ans)` representing the minimum difference between the largest and smallest of the three rectangular areas

## Helper Functions

### descending_compare
- Takes two void pointers to integers
- Returns -1 if first integer is greater than second, 0 if equal, 1 if first is less than second
- Used for descending order sorting

### ascending_compare
- Takes two void pointers to integers
- Returns -1 if first integer is less than second, 0 if equal, 1 if first is greater than second
- Used for ascending order sorting

### lower_bound
- Takes an integer array, array size, and a key value
- Performs a binary search to find the first position where the array value is greater than or equal to the key
- Returns the index of the lower bound, or the array size if no such position exists
- Uses a modified binary search with specific loop termination conditions

### gcd
- Recursive function computing greatest common divisor of two unsigned long integers
- Base case: returns x when y equals 0
- Recursive cases: calls itself with (y, x % y) when x > y, otherwise with (x, y % x)

### factorial
- Computes factorial of an integer using a loop from x down to 2
- Returns the product as a long long

## Main Function Logic

### Initialization
- Declares variables for height, width, an array of three long long values for square areas, minimum and maximum values, and answer initialized to 10^13

### First Loop (Horizontal Cuts)
- Iterates `i` from 1 to h-1
- For each iteration:
  - Sets square[0] to the area of the top piece: i * w
  - Sets square[1] to the area of the bottom-left piece: (h-i) * (w/2)
  - Sets square[2] to the area of the bottom-right piece: (h-i) * (w - w/2)
  - Finds minimum and maximum of these three areas
  - Updates answer if the difference (max - min) is smaller than current answer
  - Then sets square[1] to (h-i)/2 * w and square[2] to ((h-i) - (h-i)/2) * w
  - Again finds min/max and updates answer if smaller

### Second Loop (Vertical Cuts)
- Iterates `i` from 0 to w-1
- For each iteration:
  - Sets square[0] to the area of the left piece: i * h
  - Sets square[1] to the area of the right-top piece: (w-i) * (h/2)
  - Sets square[2] to the area of the right-bottom piece: (w-i) * (h - h/2)
  - Finds minimum and maximum of these three areas
  - Updates answer if the difference is smaller
  - Then sets square[1] to (w-i)/2 * h and square[2] to ((w-i) - (w-i)/2) * h
  - Again finds min/max and updates answer if smaller

### Final Output
- Prints the computed minimum answer

## Data Dependencies
- The answer depends on the input values h and w
- Each iteration's calculations depend on the current loop variable and the input dimensions
- The min/max calculations depend on the three computed square areas
- The final answer is the minimum over all iterations of the max-min differences

## Control Flow
- Two main loops: one for horizontal cuts (i from 1 to h-1), one for vertical cuts (i from 0 to w-1)
- Within each loop iteration, there are two sets of area calculations and min/max determinations
- Conditional updates to the answer variable when a smaller difference is found
- The helper functions (descending_compare, ascending_compare, lower_bound, gcd, factorial) are defined but not called from main
