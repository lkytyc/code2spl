## Overview
This program processes a series of queries that maintain a sorted array of numbers and track a cumulative sum. It supports two types of operations: inserting a value with an associated weight, and querying the median along with a computed cost.

## Inputs
- First input: an integer `q` representing the number of queries.
- Each query begins with an integer `x`:
  - If `x == 1`, two additional integers follow: `y` (the value to insert) and `z` (a weight to add to a running total).
  - If `x != 1` (any other value), no additional input is read for that query.

## Outputs
- For each query where `x != 1`, the program outputs two space-separated values: the current median value and a computed sum.

## Data Structures
- An array `a` of up to 200,005 elements stores the inserted values in sorted order.
- A variable `b` accumulates the sum of all `z` values from insertion queries.
- Variables `n` tracks the current number of elements in the array.

## Control Flow

### Main Loop
The program iterates `q` times, processing one query per iteration.

### Insertion Operation (x == 1)
1. Reads values `y` and `z`.
2. If the array is empty (`n == 0`), places `y` at index 0.
3. Otherwise, performs an insertion sort:
   - Starts from the last element and moves backward.
   - Shifts elements greater than `y` one position to the right.
   - When finding an element less than or equal to `y`, inserts `y` after it and stops.
   - If all existing elements are greater than `y`, places `y` at the beginning (index 0).
4. Increments `n` by 1.
5. Adds `z` to the running total `b`.

### Query Operation (x != 1)
1. Computes the median index as `(n - 1) / 2` and retrieves the median value `m` from the sorted array.
2. Initializes the answer `ans` to the current value of `b`.
3. Iterates through all elements in the array:
   - For each element, computes the absolute difference between the median and that element.
   - Adds this absolute difference to `ans`.
4. Prints the median value `m` and the computed `ans`.

## Key Dependencies
- The array must remain sorted for the median calculation to be correct.
- The value of `b` accumulates across all insertion queries and is used as the base for the query answer.
- The median index calculation depends on the current count `n`.

## Edge Cases
- When `n == 0` and a query operation occurs, the code would access `a[-1]` (undefined behavior), though this scenario is not explicitly guarded.
- When inserting into an empty array, the special case handles it directly.
- The insertion loop has a potential issue: if the loop completes without finding a position (all elements greater than `y`), the final check `if (j == 0)` places `y` at index 0, but this only triggers when the loop reaches the first element.
