[DEFINE_WORKER: "Builds an n x n coordinate maze, converts the input S/E move string into a path, then repeatedly shuffles the move list and regenerates a candidate path until no directed edge at the same step index matches the original path, and prints the accepted shuffled move string." ownWay]
    [INPUTS]
        <REF> s </REF>: str "Original string of move characters 'S' and 'E' with length 2*n-2; 'S' increments the y-coordinate and 'E' increments the x-coordinate."
        <REF> n </REF>: int "Dimension of the n x n maze grid; determines path length and movement bounds."
    [END_INPUTS]

    [OUTPUTS]
        <REF> printed_output </REF>: stdout "Prints the accepted shuffled move string joined into one string."
    [END_OUTPUTS]

    [MAIN_FLOW]
        [SEQUENTIAL_BLOCK]
            [COMMAND Create an empty list maze. For i from 0 to n-1 inclusive, append a new empty row; within that row, for j from 0 to n-1 inclusive append a new empty cell; then for k=0 append i and for k=1 append j, so maze[i][j] becomes [i, j]. RESULT maze]
            [COMMAND Convert string s into a list of characters l using list(s), and initialize c_l as an empty list. RESULT l, c_l]
            [COMMAND Build c_l as a nested path container with one path entry containing 2*n-1 points. For each point j from 0 to 2*n-2 inclusive, append a point initialized to [0,0]. RESULT c_l]
            [COMMAND Set x=0 and y=0. Copy maze[0][0][0] into c_l[0][0][0] and maze[0][0][1] into c_l[0][0][1] to set the starting point. RESULT x, y, c_l]
            [COMMAND For i from 0 to 2*n-3 inclusive, process original move l[i]: if l[i] is 'S', increment y, then store maze[x][y][0] into c_l[0][i+1][0] and maze[x][y][1] into c_l[0][i+1][1]; if l[i] is 'E', increment x, then store maze[x][y][0] into c_l[0][i+1][0] and maze[x][y][1] into c_l[0][i+1][1]. If l[i] is neither, make no position update. RESULT c_l]
            [COMMAND Set check to True, then shuffle l in place using random.shuffle(l), and initialize c_l1 as an empty list. RESULT check, l, c_l1]
            [COMMAND Build c_l1 as a nested path container with one path entry containing 2*n-1 points initialized to [0,0]. Set x1=0 and y1=0, copy maze[0][0][0] into c_l1[0][0][0] and maze[0][0][1] into c_l1[0][0][1], then for i from 0 to 2*n-3 inclusive process shuffled move l[i]: if 'S', increment y1 and store maze[x1][y1] into c_l1[0][i+1]; if 'E', increment x1 and store maze[x1][y1] into c_l1[0][i+1]. RESULT c_l1, x1, y1]
            [COMMAND While check is true: set check to False; for i from 0 to 2*n-3 inclusive, compare c_l[0][i] and c_l1[0][i] and also c_l[0][i+1] and c_l1[0][i+1]; if both point pairs are equal, set check back to True. RESULT check]
            [COMMAND Within the while loop, if check is true: shuffle l in place with random.shuffle(l), reset c_l1 to an empty list, rebuild c_l1 with 2*n-1 points initialized to [0,0], set x1=0 and y1=0, set c_l1[0][0] from maze[0][0], and recompute the path through the newly shuffled l using the same S/E increments and maze assignments as before. RESULT l, c_l1]
            [COMMAND After the while loop exits, print ''.join(l) to output the accepted shuffled move string. RESULT printed_output]
        [END_SEQUENTIAL_BLOCK]
    [END_MAIN_FLOW]

[END_WORKER]
