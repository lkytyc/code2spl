## Overview
This code computes a combinatorial value for each node in a tree, based on counting certain arrangements of the tree's nodes. The main function reads a tree from standard input, calls the solve function, and prints one integer per node.

## Input
- An integer `n` representing the number of nodes (read from standard input)
- `n-1` lines, each containing two integers representing an undirected edge between nodes (1-indexed in input, converted to 0-indexed internally)

## Output
- `n` lines, each containing one integer (the computed value for each node, in order from node 0 to node n-1)

## Main Function Flow
1. Reads `n` from input
2. Reads `n-1` edges, converting each to 0-indexed form
3. Calls `solve(n, edge_list)`
4. Prints each result on its own line

## Solve Function Details

### Precomputation
- Computes factorials modulo 1,000,000,007 for values 0 through n-1
- Computes inverse factorials modulo the same modulus using Fermat's little theorem (via modular exponentiation)

### Graph Construction
- Builds an adjacency list `g` from the edge list
- Performs a breadth-first search starting from node 0 to:
  - Establish a traversal order
  - Set parent pointers for each node (node 0 has itself as parent)
  - Build a children list for each node

### First Computation Pass (count_children_res)
- Processes nodes in reverse BFS order
- For leaf nodes (no children): result is 0
- For internal nodes: result equals (number of children) + (sum of results from all children)

### Second Computation Pass (assign_children_res)
- Processes nodes in reverse BFS order
- For leaf nodes: result is 1
- For internal nodes: computes a product involving:
  - Factorial of the node's count_children_res value
  - For each child: the child's assign_children_res value multiplied by the inverse factorial of (child's count_children_res + 1)
  - All multiplications are done modulo 1,000,000,007

### Third Computation Pass (assign_parents_res)
- Sets node 0's value to 1
- Processes remaining nodes in BFS order
- For each node, computes a value based on:
  - Its parent's assign_children_res value
  - Modular inverse of its own assign_children_res value
  - Various factorial and inverse factorial terms involving count_children_res values for the node and its parent
  - The parent's assign_parents_res value
  - All operations modulo 1,000,000,007

### Final Result Computation
- Node 0's result equals its assign_children_res value
- For each other node, computes a product involving:
  - Factorial of (n-1)
  - For each child: child's assign_children_res value times inverse factorial of (child's count_children_res + 1)
  - The node's assign_parents_res value
  - Inverse factorial of (n-1 - count_children_res of the node)
  - All modulo 1,000,000,007

## Execution
When run as the main program, it first executes the test function (which will raise an assertion error if any test fails), then proceeds to read input and produce output.
