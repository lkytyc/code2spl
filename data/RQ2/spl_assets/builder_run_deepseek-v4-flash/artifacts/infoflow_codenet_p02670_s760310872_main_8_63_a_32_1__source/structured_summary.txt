## Inputs
- An integer `n` read from standard input, representing the size of an n×n grid.
- A sequence of `n*n` long integers read from standard input, one per iteration.

## Initialization
- A 2D array `a` of size 501×501 is declared.
- The grid is filled with sequential integers from 1 to n², row by row.
- Variables: `k` starts at 1 and increments for each grid cell; `cnt` starts at 0.

## Main Processing Loop
The program iterates `n*n` times, reading one integer `p` per iteration. For each `p`, it performs one of the following actions:

### Case 1: Top row (p in range 1 to n)
- Sets `a[0][p-1]` to 0.

### Case 2: Bottom row (p in range n²-n+1 to n²)
- Sets `a[n-1][n-(n*n)+p-1]` to 0.

### Case 3: Rightmost column (p divisible by n)
- Sets `a[(p/n)-1][n-1]` to 0.

### Case 4: Leftmost column (p mod n equals 1)
- Sets `a[p/n][0]` to 0.

### Case 5: Interior cells (all other cases)
- Sets `a[p/n][(p%n)-1]` to 0.
- Computes four distances:
  - `m[0]` = number of rows above the current row (i)
  - `m[1]` = number of rows below the current row (n-1-i)
  - `m[2]` = number of columns to the left (j)
  - `m[3]` = number of columns to the right (n-1-j)
- For each of these four directions, counts how many cells in that direction are already set to 0 and subtracts that count from the corresponding `m` value.
- Sorts the four `m` values in ascending order.
- Adds the smallest value to `cnt`.

## Output
- After processing all `n*n` inputs, prints the accumulated value of `cnt` as a long integer.

## Key Data Dependencies
- The grid `a` is initialized before any input processing.
- Each input value `p` determines which grid cell is zeroed.
- The count `cnt` accumulates based on the minimum of four directional distances to already-zeroed cells, but only for interior cells.
- The `compare_int` function is used as a comparator for `qsort` to sort the four distance values.
