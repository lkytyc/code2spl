# Code Description

## Class Structure
The code defines a `Main` class containing the primary logic, and a separate `FastScanner` class for efficient input parsing.

## Main Class Fields
- `isDebug`: A boolean flag set to `false`, controlling whether input comes from a file or standard input.
- `fileName`: A string set to `"input.txt"`, used only when debug mode is enabled.
- `sc`: A `FastScanner` instance used for reading input.

## Main Method
The `main` method creates a new `Main` instance and calls its `m()` method, which may throw `IOException`.

## Method `m()`
- Records the start time.
- Initializes the scanner: if `isDebug` is true, reads from a file named `input.txt`; otherwise reads from standard input.
- Calls `solve()`.
- If debug mode is enabled, prints a debug header and the elapsed time in milliseconds.

## Method `solve()`
This method contains the core algorithm.

### Constants
- `INF`: Set to half of `Integer.MAX_VALUE`.
- `MOD`: Set to 1,000,000,007.

### Input
- Reads a single string `S` from the scanner.

### Precomputation Arrays
- Creates integer arrays `sumA`, `sumC`, and `sumQ`, each of length `S.length() + 1`.
- Creates a long array `pow3` of length `S.length() + 1`.

### Power of 3 Precomputation
- Sets `pow3[0] = 1`.
- Loops from index 1 through `S.length()`, computing each value as the previous value multiplied by 3, then taking modulo `MOD`.

### Prefix Sum Construction
- Loops from index 1 through `S.length()`.
- For each position, copies the previous prefix sums for A, C, and Q counts.
- If the character at position `i-1` (0-based) is 'A', increments `sumA[i]`.
- If the character is 'C', increments `sumC[i]`.
- If the character is '?', increments `sumQ[i]`.

### Main Counting Loop
- Initializes `ans` to 0.
- Loops `i` from 2 through `S.length() - 1` (inclusive), representing potential middle positions of a pattern.

#### Case: Current character is 'B'
- Computes a contribution for the pattern A...B...C where all '?' are treated as 'A', 'B', or 'C' appropriately:
  - Multiplies the count of 'A's before position `i` by the count of 'C's after position `i`.
  - Multiplies by `pow3[total question marks]` (all possible assignments of '?' anywhere).
  - Adds to `ans` modulo `MOD`.
- If there is at least one '?' in the entire string:
  - Computes contribution for A...B...? where the '?' after position `i` becomes 'C':
    - Multiplies 'A' count before `i` by '?' count after `i`.
    - Multiplies by `pow3[total question marks - 1]`.
    - Adds to `ans`.
  - Computes contribution for ?...B...C where the '?' before position `i` becomes 'A':
    - Multiplies '?' count before `i` by 'C' count after `i`.
    - Multiplies by `pow3[total question marks - 1]`.
    - Adds to `ans`.
- If there are at least two '?' in the entire string:
  - Computes contribution for ?...B...? where both '?' become 'A' and 'C' respectively:
    - Multiplies '?' count before `i` by '?' count after `i`.
    - Multiplies by `pow3[total question marks - 2]`.
    - Adds to `ans`.
