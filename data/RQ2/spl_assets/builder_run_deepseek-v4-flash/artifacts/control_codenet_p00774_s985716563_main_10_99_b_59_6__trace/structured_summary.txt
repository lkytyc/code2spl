## Overview
This program processes multiple test cases of a 5-column grid game, calculating scores based on matching adjacent values in columns. It reads input values, processes them through repeated scoring and collapsing rounds, and outputs the total score for each test case.

## Inputs
- Integer `n` representing the number of rows to process (read via `scanf`)
- For each of `n` rows, 5 integer values are read (one per column)
- The process repeats for multiple test cases until `n` is 0

## Outputs
- For each test case, a single integer representing the total accumulated score

## Data Structures
- `a[5][20]`: Main game grid with 5 columns and up to 20 rows
- `b[5][10]`: Temporary marker grid for matched cells
- `n`: Number of active rows
- `m`: Round counter (initialized to 11)
- `point`: Accumulated score

## Main Processing Loop
The program runs while `n` is non-zero, processing each test case:

### Initialization Phase
1. Reset `point` to 0
2. Clear the entire `a` array (all 5×20 cells set to 0)
3. Read `n` rows of 5 values each, storing them in `a` with reversed row order (row `n-1-i`)

### Scoring Rounds (11 iterations)
Each round consists of three phases:

#### Phase 1: Clear marker array
- Reset all cells in `b` to 0

#### Phase 2: Detect and score matches
For each column `i` (0 to n-1), check for consecutive matching values:

**Case A**: First three values match (a[0]==a[1]==a[2], non-zero)
- If all five match: score = value × 5, mark all 5 cells
- If first four match: score = value × 4, mark first 4 cells
- Otherwise: score = value × 3, mark first 3 cells

**Case B**: Middle three values match (a[1]==a[2]==a[3], non-zero)
- If last four match: score = value × 4, mark cells 1-4
- Otherwise: score = value × 3, mark cells 1-3

**Case C**: Last three values match (a[2]==a[3]==a[4], non-zero)
- Score = value × 3, mark cells 2-4

#### Phase 3: Remove marked cells and collapse
1. Zero out all cells in `a` that are marked in `b`
2. Perform a collapse operation repeated `n` times:
   - For each column, scan for zero values
   - When a zero is found, shift all values below it up by one position
   - This effectively removes empty cells and compacts remaining values upward

### Round Counter
- Decrement `m` after each round
- Process continues while `m > 0` (exactly 11 rounds per test case)

## Helper Function
- `min(a, b)`: Returns the smaller of two integers (defined but not used in main logic)

## Termination
- After processing all rounds, print the accumulated `point` value
- Read next `n` value
- Exit when `n` equals 0

## Key Behavioral Notes
- The collapse operation may access array indices beyond the logical data range (up to index 10 in the shift loop)
- The scoring logic only considers non-zero values
- Multiple matches in the same column are not possible due to the if-else chain structure
- The collapse operation is performed `n` times regardless of whether any cells were actually removed
