## Inputs
- Reads an integer `n` from standard input using a fast scanner.
- Then reads `n*n` integers from standard input, one per cell of an `n` by `n` grid, in row-major order.

## Initialization
- Creates an `n` by `n` integer matrix `m`.
- Creates a list of adjacency lists `graph` with `n*n` entries.
- Creates boolean arrays `exist` (initialized to all `true`) and `possible` (initialized to all `false`), each of size `n*n`.
- Creates a `HashSet` called `set` and a queue.
- Initializes a counter `count` to 0 and a flag `flag` to `true` (though `flag` is never used after initialization).

## Grid Construction and Graph Building
- Iterates over all grid positions `(i, j)` from `(0,0)` to `(n-1, n-1)`.
- For each position, assigns the current value `x` (starting at 1 and incrementing by 1 each step) to matrix cell `m[i][j]`.
- If the cell is on the border (first row, last row, first column, or last column), the value `x` is added to the `set`.
- Builds adjacency relationships for the current cell value `x`:
  - Adds a self-loop if `x - 1 > i*n`.
  - Adds a right neighbor if `x + 1 <= n*(i+1)`.
  - Adds an upward neighbor if `x - n > 0`.
  - Adds a downward neighbor if `x + n <= n*n`.
- Reads the next integer `p` from input and adds it to the queue.

## Main Processing Loop
- Processes the queue until it is empty:
  - Dequeues a value `a`.
  - Marks `exist[a-1]` as `false` (meaning this cell has been "removed" or processed).
  - If `a` is in the border set, marks `possible[a-1]` as `true`.
  - If `possible[a-1]` is `true`:
    - Propagates `possible` to all neighbors of `a` in the graph (sets `possible[w-1] = true` for each neighbor `w`).
  - Otherwise (if `possible[a-1]` is `false`):
    - Checks all neighbors `w` of `a`; if any neighbor has both `possible[w-1] == true` and `exist[w-1] == false`, then:
      - Sets `possible` to `true` for indices `a-2`, `a-1-n`, `a`, `a-1+n`, and `a-1`.
      - Decrements `count` by 1.
      - Breaks out of the neighbor loop.
    - Increments `count` by 1.
    - Performs a bounds check on indices `a-2`, `a-1-n`, `a`, and `a-1+n` (checking if any are within valid range).
    - If any of these indices are valid and correspond to cells that are both `exist == false` and `possible == true`, then sets `possible` to `true` for indices `a-2`, `a-1-n`, `a`, `a-1+n`, and `a-1`.

## Output
- Prints the final value of `count` to standard output.

## Helper Class: FastScanner
- Provides fast input reading from `System.in`.
- Uses a 1024-byte buffer.
- Methods:
  - `hasNextByte()`: checks if more bytes are available, refilling buffer if needed.
  - `readByte()`: returns next byte or -1 if end of stream.
  - `isPrintableChar(int c)`: returns true for ASCII values 33-126.
  - `hasNext()`: skips non-printable characters and checks for more input.
  - `next()`: reads a string of printable characters.
  - `nextLong()`: parses a long integer, handling optional minus sign and validating digits.
  - `nextInt()`: calls `nextLong()` and checks integer range.
  - `nextDoutble()`: parses a double (note the typo in method name).
