# Code Description

## Function: solve(int T)

### Inputs
- Reads an integer `U` from standard input using `scanf("%d", &U)`.
- Then reads exactly 10,000 pairs of strings `M` and `R` from standard input using `scanf("%s %s", M, R)`.

### Local Data Structures
- `MC[26]`: An integer array initialized to 10 for all 26 elements. This tracks the minimum leading digit observed for each letter.
- `O[26]`: An integer array initialized to 0 for all 26 elements. This tracks which letters have been observed.
- `out[10]`: A character array used to build the output string.
- `R[U]` and `M[U]`: Character arrays to store the two input strings per iteration.
- `lr` and `lm`: Integer variables storing string lengths.

### Processing Loop
- A `while` loop runs exactly 10,000 times (counter `i` from 0 to 9999).
- For each iteration:
  - Reads string `M` and string `R`.
  - Computes lengths of both strings.
  - Marks the last character of `R` as observed by setting `O[R[lr-1]-'A'] = 1`.
  - If both strings have the same length:
    - Marks the first character of `R` as observed.
    - Updates `MC` for the first character of `R` to the minimum of its current value and the numeric value of the first character of `M` (converted from character to integer by subtracting `'0'`).

### Output Construction
- After the loop, iterates through all 26 letters (index `i` from 0 to 25).
- For each letter that was observed (`O[i]` is non-zero), places that letter into the `out` array at position `MC[i] % 10`.
- Prints the result as `Case #%d: %s` with the test case number `T` and the `out` string.

## Function: main()

### Inputs
- Reads an integer `T` from standard input.

### Control Flow
- Stores the original value of `T` in `_T`.
- Runs a `while` loop that executes `T` times (decrementing `T` each iteration).
- For each iteration, calls `solve(_T - T)`.
  - When `T` equals the original value, `_T - T` equals 0.
  - When `T` reaches 0, the loop ends.

### Output
- Returns 0 upon completion.

## Data Dependencies
- The `MC` array values depend on the minimum digit observed from the first character of `M` when string lengths match.
- The `O` array depends on which letters appear as first or last characters of `R`.
- The final output string depends on both `MC` and `O` arrays.
- The test case number passed to `solve` depends on the loop counter in `main`.
