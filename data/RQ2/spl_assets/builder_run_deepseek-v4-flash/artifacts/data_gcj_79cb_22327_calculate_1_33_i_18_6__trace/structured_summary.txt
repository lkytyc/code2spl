# Function: calculate(arr, size)

## Inputs
- `arr`: a list of integers
- `size`: an integer representing the length of the array

## Outputs
- Returns a string: either `'OK'` or a string representation of an integer index

## Processing Steps

### Step 1: Partition array into even and odd index positions
- Creates `even_arr` with length `size / 2` (integer division)
- Creates `odd_arr` with length `size - len(even_arr)`
- Iterates through the original array using index `i` from 0 to `size-1`
- If `(i+1) % 2 == 0` (i.e., 1-based even position, meaning 0-based odd index), stores `arr[i]` in `even_arr`
- Otherwise (1-based odd position, meaning 0-based even index), stores `arr[i]` in `odd_arr`

### Step 2: Sort both arrays
- Sorts `even_arr` in ascending order
- Sorts `odd_arr` in ascending order

### Step 3: Merge and check ordering
- Resets both index counters (`eveni` and `oddi`) to 0
- Initializes `last` to -1
- Iterates through positions 0 to `size-1`:
  - **First iteration (i == 0)**: Takes the first element from `odd_arr`, sets it as `last`, increments `oddi`, and continues to next iteration
  - **Odd index positions (i % 2 == 1)**: Takes next element from `even_arr`. If this element is less than `last`, returns `str(i-1)`. Otherwise updates `last` and increments `eveni`
  - **Even index positions (i % 2 == 0, excluding i==0)**: Takes next element from `odd_arr`. If this element is less than `last`, returns `str(i-1)`. Otherwise updates `last` and increments `oddi`

### Step 4: Completion
- If the loop completes without returning, returns the string `'OK'`

## Control Flow Branches
- Branch based on whether `(i+1) % 2 == 0` in the first loop
- Branch based on whether `i == 0` in the second loop
- Branch based on whether `i % 2 == 1` in the second loop
- Early return branches when sorted values are out of order

## Data Dependencies
- `even_arr` and `odd_arr` depend on the original `arr` and `size`
- The second loop depends on the sorted versions of both arrays
- The return value depends on the first position where the merged sequence violates non-decreasing order

# Function: main()

## Inputs
- Reads from standard input:
  - First line: integer `t` (number of test cases)
  - For each test case:
    - First line: integer `size` (array length)
    - Second line: space-separated integers forming the array

## Outputs
- Prints to standard output: `Case #N: result` where N is the test case number (1-based) and result is the return value from `calculate`

## Processing Steps
1. Reads `t` from input
2. Loops `t` times:
   - Reads `size`
   - Reads and parses the array
   - Calls `calculate(arr, size)`
   - Prints formatted result

## Control Flow
- Loop over test cases (0 to t-1)
- Function call to `calculate` for each test case

## Data Dependencies
- Each test case's output depends solely on its own input array and size
- No state is shared between test cases
