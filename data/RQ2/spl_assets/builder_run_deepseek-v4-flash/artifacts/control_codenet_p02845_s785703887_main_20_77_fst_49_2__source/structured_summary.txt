## Program Overview
This is a Java program that reads a sequence of integers and computes a combinatorial count based on how the sequence values can be assigned to three tracked state variables. The program uses modular arithmetic with a modulus of 1,000,000,007.

## Input
- First line: an integer N (number of values to process)
- Following N lines: integer values (one per line)

## Output
- A single integer representing the computed answer modulo 1,000,000,007

## Main Algorithm

### Initialization
- Three state variables are initialized to -1: `fst`, `snd`, `thd`
- A counter variable `answer` is initialized to 1
- A constant MOD is set to 1,000,000,007

### Main Loop (iterates N times)
For each input value `val`:

**Case 1: val equals 0**
- If `fst` is -1, set `fst` to 1
- Otherwise, if `snd` is -1, set `snd` to 1
- Otherwise, if `thd` is -1, set `thd` to 1
- No multiplication occurs in this branch

**Case 2: val is non-zero**
The program checks conditions in order:
1. If all three variables equal `val`: increment `fst` by 1, multiply answer by 3
2. If `fst` and `snd` both equal `val`: increment `fst` by 1, multiply answer by 2
3. If `snd` and `thd` both equal `val`: increment `snd` by 1, multiply answer by 2
4. If `thd` and `fst` both equal `val`: increment `fst` by 1, multiply answer by 2
5. If only `fst` equals `val`: increment `fst` by 1 (no multiplication)
6. If only `snd` equals `val`: increment `snd` by 1 (no multiplication)
7. If only `thd` equals `val`: increment `thd` by 1 (no multiplication)

After any non-zero value processing, the three variables are reordered:
- `fst` becomes the maximum of the three
- `thd` becomes the minimum of the three
- `snd` becomes the middle value

### Final Adjustment
After processing all N values:
- If both `snd` and `thd` are negative: multiply answer by 3
- If only `thd` is negative: multiply answer by 6
- Otherwise (all three non-negative): multiply answer by 6

All multiplications are followed by modulo operation with 1,000,000,007.

## Scanner Class
A custom scanner utility that:
- Wraps a BufferedReader with StringTokenizer
- Provides methods: `next()`, `nextInt()`, `nextLong()`, `nextDouble()`, `nextIntArray(n)`, `nextLongArray(n)`
- Implements Closeable interface
- Uses lazy tokenization: reads new lines only when current token stream is exhausted

## Data Dependencies
- The state variables (`fst`, `snd`, `thd`) maintain cumulative state across iterations
- The answer variable accumulates multiplicative factors based on state transitions
- The reordering step after each non-zero value creates dependencies between the three state variables

## Control Flow
- Single main loop with conditional branching based on input values and current state
- No nested loops in the main algorithm
- Scanner methods use a while loop for token retrieval when needed
