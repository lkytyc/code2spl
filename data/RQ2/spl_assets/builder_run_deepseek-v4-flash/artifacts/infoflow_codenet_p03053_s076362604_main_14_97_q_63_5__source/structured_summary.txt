# Structured Description

## Inputs
- Reads two integers from standard input: `H` (height) and `W` (width), each via separate `scanf("%d", ...)` calls.
- Then reads a grid of characters of size H×W. For each row `i` from 1 to H, it first reads one character `d` (which is discarded), then reads W characters `c` into a 2D character array `l[i][j]` for columns 1 through W.

## Outputs
- Prints a single integer `ans` to standard output, followed by a newline.

## Data Structures
- `l[1001][1001]`: character grid storing the input, indexed from (1,1) to (H,W).
- `p[1001][1001]`, `q[1001][1001]`, `r[1001][1001]`, `s[1001][1001]`: integer arrays storing distance-like values computed in four different directional passes.
- `n[1001][1001]`: integer array storing the minimum of the four computed values for each cell.
- `m`: integer initialized to `H + W`, used as a large sentinel value for boundary initialization.

## Initialization
- `m` is set to `H + W`.
- Boundary cells for all four arrays are initialized to `m`:
  - For rows 1..H: `p[i][0]`, `q[i][W+1]`, `r[i][0]`, `s[i][W+1]` are set to `m`.
  - For columns 1..W: `p[0][j]`, `q[0][j]`, `r[H+1][j]`, `s[H+1][j]` are set to `m`.

## Main Computation

### Pass 1 (array `p`): top-left to bottom-right
- Loop `i` from 1 to H, `j` from 1 to W.
- If `l[i][j]` is `'#'`, set `p[i][j] = 0`.
- Otherwise, set `p[i][j] = min(p[i-1][j], p[i][j-1]) + 1`.

### Pass 2 (array `q`): top-right to bottom-left
- Loop `i` from 1 to H, `j` from W down to 1.
- If `l[i][j]` is `'#'`, set `q[i][j] = 0`.
- Otherwise, set `q[i][j] = min(q[i-1][j], q[i][j+1]) + 1`.

### Pass 3 (array `r`): bottom-left to top-right
- Loop `i` from H down to 1, `j` from 1 to W.
- If `l[i][j]` is `'#'`, set `r[i][j] = 0`.
- Otherwise, set `r[i][j] = min(r[i+1][j], r[i][j-1]) + 1`.

### Pass 4 (array `s`): bottom-right to top-left
- Loop `i` from H down to 1, `j` from W down to 1.
- If `l[i][j]` is `'#'`, set `s[i][j] = 0`.
- Otherwise, set `s[i][j] = min(s[i+1][j], s[i][j+1]) + 1`.

### Combining Results
- For each cell (i,j) from 1..H and 1..W:
  - `n[i][j]` is set to the minimum of `p[i][j]` and `q[i][j]`.
  - Then `n[i][j]` is updated to the minimum of itself and `r[i][j]`.
  - Then `n[i][j]` is updated to the minimum of itself and `s[i][j]`.
  - `ans` is updated to the maximum of its current value and `n[i][j]`.

## Helper Functions
- `max(a, b)`: returns `a` if `a > b`, otherwise returns `b`.
- `min(a, b)`: returns `b` if `a > b`, otherwise returns `a`.

## Control Flow Summary
- The program uses nested loops for grid processing in four directional orders.
- Conditional checks on `l[i][j] == '#'` determine whether a cell is treated as an obstacle (value 0) or as a distance accumulation point.
- The final answer is the maximum value found across all cells in the combined minimum array `n`.

## Data Dependencies
- Each pass depends on previously computed values
