## Inputs
- Reads an integer N from standard input, representing the number of values to process.
- Then reads N integer values from standard input, one per iteration.

## Outputs
- Prints a single long integer value to standard output, representing the computed answer modulo 1,000,000,007.

## Main Control Flow

### Initialization
- Sets MOD to 1,000,000,007.
- Initializes three integer variables: fst, snd, thd, all set to -1.
- Initializes answer to 1.

### Main Loop (iterates N times)
For each input value `val`:

**Case 1: val equals 0**
- If fst is -1, set fst to 1.
- Otherwise, if snd is -1, set snd to 1.
- Otherwise, if thd is -1, set thd to 1.
- No changes to answer in this case.

**Case 2: val is non-zero**
- Checks equality conditions in this order:
  1. If all three (fst, snd, thd) equal val: increment fst by 1, multiply answer by 3, take modulo.
  2. Else if fst and snd both equal val: increment fst by 1, multiply answer by 2, take modulo.
  3. Else if snd and thd both equal val: increment snd by 1, multiply answer by 2, take modulo.
  4. Else if thd and fst both equal val: increment fst by 1, multiply answer by 2, take modulo.
  5. Else if only fst equals val: increment fst by 1.
  6. Else if only snd equals val: increment snd by 1.
  7. Else if only thd equals val: increment thd by 1.
- After the equality checks, reorder the three variables:
  - Save old values of fst, snd, thd.
  - Set fst to the maximum of the three old values.
  - Set thd to the minimum of the three old values.
  - Set snd to the middle value (computed as sum minus max minus min).

### Final Adjustment
- If both snd and thd are negative (less than 0): multiply answer by 3, take modulo.
- Otherwise (if only thd is negative, or neither is negative): multiply answer by 6, take modulo.

### Output
- Prints the final answer value.

## Helper Class: Scanner
- Wraps a BufferedReader and StringTokenizer for input parsing.
- `next()`: Reads next token, fetching a new line if needed.
- `nextInt()`, `nextLong()`, `nextDouble()`: Parse respective numeric types.
- `nextIntArray(n)`, `nextLongArray(n)`: Read arrays of specified length.
- `close()`: Closes the underlying BufferedReader.

## Data Dependencies
- The answer variable depends on the sequence of input values and the state of fst, snd, thd.
- The state of fst, snd, thd evolves based on each input value and the equality checks.
- The final answer depends on the final state of snd and thd after all inputs are processed.
