# Code Structure Description

## Overview
This Java code contains two classes: `Solution` and `Longest_common_substr`. Both classes have `main` methods and process word lists from standard input.

## Class: Solution

### Input
- Reads an integer `tc` from standard input representing the number of test cases
- For each test case, reads an integer `noOfWords` representing the number of words
- Reads `noOfWords` words from standard input, one per line

### Processing
- Stores all words in a `TreeSet` (automatically sorted, duplicates removed)
- Creates two iterators over the same set: `wrd1` and `wrd2`
- Initializes counter `c1` to 0

### Control Flow
- Outer loop: iterates through all words using `wrd1` iterator
  - Increments `c1` for each word
  - Initializes `c2` to 0 and `result` to 0 for each outer iteration
  - Retrieves current word as `wordOne`
  - Inner loop: iterates through all words using `wrd2` iterator
    - Increments `c2` for each word
    - Checks if `c1 != c2` (different positions in iteration)
    - If different positions, retrieves `wordTwo`
    - Nested loops over substrings of `wordTwo`:
      - Outer substring loop: `l` from 0 to `wordTwo.length()-2`
      - Inner substring loop: `k` from `l+2` to `wordTwo.length()`
      - Checks if `wordOne` contains the substring and if substring length exceeds current max
      - If condition met, updates `max` and `key` with the substring
      - If condition not met, breaks out of inner loop

### Output
- No output is produced by this class

## Class: Longest_common_substr

### Method: printLCSubStr
**Parameters:** Two strings `X` and `Y`, and their lengths `m` and `n`

**Processing:**
- Creates a 2D array `LCSuff` of size (m+1) × (n+1)
- Initializes variables: `len=0`, `row=0`, `col=0`
- Double loop through the array:
  - First row/column set to 0
  - If characters match, sets cell to diagonal value + 1
  - Tracks maximum length and its position
  - If characters don't match, sets cell to 0
- If no common substring found (len=0), returns 0
- Otherwise, reconstructs the substring by tracing back through the array
- Returns the length of the longest common substring

### Main Method

**Input:**
- Reads integer `tc` for number of test cases
- For each test case, reads `noOfWords` and then that many words

**Processing:**
- Stores words in a `TreeSet`
- Creates two iterators over the set
- Initializes `c1=0` and `result=0`

**Control Flow:**
- Outer loop using `wrd1` iterator:
  - Initializes `max=0`, `key1=""`, `key2=""`
  - Gets current word as `w1`
  - Checks if `w1` equals `key1`; if so, removes from set and returns
  - Inner loop using `wrd2` iterator:
    - Gets current word as `w2`
    - Checks if `w2` equals `key2`; if so, removes from set and returns
    - Calls `printLCSubStr` with both words
    - If returned count exceeds current max, updates `key1`, `key2`, and `max`
  - Adds `max` to running `result` total

**Output:**
- Prints "Case #i: result" for each test case, where `i` is the test case number (1-based)

## Key Data Dependencies
- The `TreeSet` ensures words are processed in sorted order
- Both iterators reference the same set, so they iterate over the same elements
- The `printLCSubStr` method depends on both input strings and their lengths
- The result accumulation depends on the maximum common substring length found for each word pair comparison

## Notable Behaviors
- The `Solution` class computes substring matches but produces no output
- The `Longest_common_substr` class has early termination conditions based on key comparisons
- Both classes use `TreeSet` which removes duplicate words and sorts remaining words alphabetically
- The substring search in `Solution` uses a break statement that may prematurely exit the inner loop
