[DEFINE_WORKER: "Reads test cases from standard input, stores each test case's words in a TreeSet, and attempts an unused longest-common-substring comparison using iterators; because the second iterator is not reset and no result is output, the method effectively only consumes input." main]
    [INPUTS]
        <REF> args </REF>: String[] "Command-line arguments; unused by the method."
    [END_INPUTS]

    [OUTPUTS]
    [END_OUTPUTS]

    [MAIN_FLOW]
        [SEQUENTIAL_BLOCK]
            [COMMAND Create a BufferedReader br wrapping an InputStreamReader over System.in. RESULT br]
            [COMMAND Read the first line from br using br.readLine() and parse it as an int named tc. RESULT tc]
            [COMMAND For each integer i from 0 to tc-1 inclusive, execute the test-case body. RESULT test_case_loop]
            [COMMAND Within the test-case loop over i, read the next line from br and parse it as int noOfWords. RESULT noOfWords]
            [COMMAND Within the test-case loop over i, create a new TreeSet<String> named set, which sorts its elements lexicographically and removes duplicates. RESULT set]
            [COMMAND Within the test-case loop over i, for each j from 0 to noOfWords-1 inclusive, read a word from br and add it to set. RESULT words_loaded]
            [COMMAND Within the test-case loop over i, create iterators wrd1 and wrd2 from set and initialize int c1 to 0; wrd2 is created once here and will not be reset between later outer-while iterations. RESULT iterators_created]
            [COMMAND Within the test-case loop over i, while wrd1.hasNext(), increment c1, set c2 to 0, set wordOne to wrd1.next(), and set result to 0. RESULT outer_while]
            [COMMAND Within the outer while loop, while wrd2.hasNext(), increment c2; if c1 != c2, set wordTwo to wrd2.next(); otherwise skip reading wordTwo and skip the substring search for that iteration. Because wrd2 is not reset, this inner while loop may be exhausted after the first outer iteration. RESULT inner_while]
            [COMMAND Within the inner while loop when c1 != c2, initialize max to 0 and key to the empty string before searching wordTwo. RESULT max_key_initialization]
            [COMMAND Within the inner while loop when c1 != c2, for each l from 0 to wordTwo.length()-2 inclusive, and for each k from l+2 to wordTwo.length() inclusive, use the short-circuit condition wordOne.contains(wordTwo.substring(l,k)) && (k-l > max); if true, update max to k-l and key to that substring; otherwise break out of the k loop. RESULT substring_search]
            [COMMAND After all nested loops for the test case, do not output or use max, key, result, or any computed comparison; the method produces no observable output. RESULT no_output]
        [END_SEQUENTIAL_BLOCK]
    [END_MAIN_FLOW]

    [ALTERNATIVE_FLOW: Inside the inner while loop, when c1 == c2 for the current iteration]
        [SEQUENTIAL_BLOCK]
            [COMMAND Do not call wrd2.next(), do not assign wordTwo, and do not execute the substring search; c2 is still incremented, so the counter becomes misaligned with the iterator position. RESULT skipped_self_comparison]
        [END_SEQUENTIAL_BLOCK]
    [END_ALTERNATIVE_FLOW]

    [ALTERNATIVE_FLOW: Inside the substring loops, when the current substring is not contained in wordOne or when k-l is not greater than max]
        [SEQUENTIAL_BLOCK]
            [COMMAND Break out of the inner k loop immediately due to the else clause. RESULT break_substring_search]
        [END_SEQUENTIAL_BLOCK]
    [END_ALTERNATIVE_FLOW]

    [EXCEPTION_FLOW: Any call to br.readLine() throws an I/O error]
        [LOG "IOException is propagated from main because the method declares throws IOException."]
        [THROW IOException "I/O error while reading from standard input."]
    [END_EXCEPTION_FLOW]

    [EXCEPTION_FLOW: A line read by br.readLine() is not a valid integer when used with Integer.parseInt, including a null line at end of stream]
        [LOG "NumberFormatException is thrown by Integer.parseInt and is not caught by the method."]
        [THROW NumberFormatException "Invalid integer input for tc or noOfWords."]
    [END_EXCEPTION_FLOW]

[END_WORKER]
