## Overview
This code computes a combinatorial value for each node in a tree, based on counting certain arrangements of the tree's structure. The main function reads a tree from standard input, calls the solve function, and prints one integer per node.

## Input
- An integer `n` representing the number of nodes (read from standard input)
- `n-1` lines, each containing two integers representing an undirected edge between nodes (converted from 1-based to 0-based indexing)

## Output
- `n` lines, each containing an integer result for the corresponding node (0-indexed internally, printed in order)

## Precomputation
- Factorials are computed modulo 1,000,000,007 for values from 0 to n-1
- Inverse factorials are computed using Fermat's little theorem (modular inverse via exponentiation with MOD-2)

## Graph Construction
- An adjacency list `g` is built from the edge list
- A breadth-first traversal starting from node 0 establishes:
  - A traversal order (BFS order)
  - Parent pointers for each node (root has itself as parent)
  - Children lists for each node

## First Computation: Count Children Results
For each node processed in reverse BFS order:
- Leaf nodes (no children) get value 0
- Internal nodes get: number of children + sum of their children's count values

This produces a value representing the total number of descendants in the subtree (including the node itself minus one).

## Second Computation: Assign Children Results
For each node processed in reverse BFS order:
- Leaf nodes get value 1
- Internal nodes compute: factorial of their count value, multiplied by each child's assign value, multiplied by the inverse factorial of (child's count + 1), all modulo MOD

## Third Computation: Assign Parents Results
- Root node gets value 1
- For each non-root node in BFS order:
  - Uses the parent's assign children value
  - Multiplies by the modular inverse of the node's own assign children value
  - Multiplies by factorial of (node's count + 1)
  - Multiplies by inverse factorial of (parent's count)
  - Multiplies by parent's assign parents value
  - Multiplies by factorial of (n - node's count - 2)
  - Multiplies by inverse factorial of (n - parent's count - 1)
  - All modulo MOD

## Final Result Computation
- For the root: result equals its assign children value
- For each non-root node:
  - Starts with factorial of (n-1)
  - Multiplies by each child's assign children value and inverse factorial of (child's count + 1)
  - Multiplies by the node's assign parents value
  - Multiplies by inverse factorial of (n - 1 - node's count)
  - All modulo MOD

## Control Flow
- The main function reads input, calls solve, and prints results
- A test function validates the solution against four hardcoded test cases
- The test function runs before main when the script is executed directly

## Data Dependencies
- Each computation stage depends on the previous stage's results
- The count values depend on subtree structure
- The assign children values depend on count values and children's assign values
- The assign parents values depend on parent relationships and multiple factorial/inverse factorial combinations
- Final results combine assign children, assign parents, and factorial terms
