# Code Description

## Function: solve(kase)

### Inputs
- Reads from standard input: four integers R, C, H, V on one line
- Then reads R lines, each containing C characters (grid rows)
- Parameter `kase` is the current test case number

### Data Structures
- `cakes`: 2D list of characters representing the grid
- `chips`: 2D list for counting chips per final piece
- `chip_rows`: list of length R, counts chips per row
- `chip_cols`: list of length C, counts chips per column
- `hcuts`: list of horizontal cut positions (starts with 0)
- `vcuts`: list of vertical cut positions (starts with 0)

### Initial Processing
1. Reads grid dimensions and cut counts
2. Reads the grid character by character
3. Counts total chips (`@` characters) and accumulates row/column chip counts

### Early Termination Checks
- If total chips = 0: prints "POSSIBLE" and returns
- If total chips is not divisible by (H+1)*(V+1): prints "IMPOSSIBLE" and returns

### Chip Distribution Calculation
- `parts` = (H+1) * (V+1) total pieces
- `piece_chip` = chips per piece (integer division)
- `rows_chips` = chips per horizontal band
- `cols_chips` = chips per vertical band

### Horizontal Cut Determination
- Iterates through rows, accumulating chip counts
- If accumulated count equals `rows_chips`: records cut position, resets counter
- If accumulated count exceeds `rows_chips`: prints "IMPOSSIBLE" and returns
- If accumulated count is less: continues to next row

### Vertical Cut Determination
- Same logic as horizontal cuts, but iterates through columns
- Uses `cols_chips` as the target count

### Piece Verification
- For each of the H horizontal bands and V vertical bands:
  - Counts chips in each resulting piece
  - If any piece count ≠ `piece_chip`: prints "IMPOSSIBLE" and returns

### Output
- Prints "Case #kase: POSSIBLE" if all checks pass
- Prints "Case #kase: IMPOSSIBLE" if any check fails

## Function: main()

### Inputs
- Reads integer T (number of test cases)

### Control Flow
- Loops through test cases 1 to T
- Calls solve(kase) for each test case

## Program Entry Point
- Checks if script is run directly (`__name__ == '__main__'`)
- Calls main() function

## Key Dependencies
- Uses `raw_input()` for input reading (Python 2 style)
- Uses `xrange()` for loops (Python 2 style)
- Grid characters: '@' represents a chip, other characters are non-chips
