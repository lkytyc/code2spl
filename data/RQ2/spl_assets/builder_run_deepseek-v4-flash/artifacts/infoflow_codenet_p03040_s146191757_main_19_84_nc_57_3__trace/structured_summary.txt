## Overview
This program processes a sequence of operations involving adding weighted values and querying a current position. It maintains a dynamic set of values with multiplicities and tracks a "current" value that can shift left or right as new values are added, using heaps to efficiently find candidate new positions.

## Input
- First line: integer `q` (number of operations)
- Next `q` lines: each contains either:
  - Type 1: three integers `(1, a, b)` — add value `a` with weight `b`
  - Type 2: two integers `(2, 0, 0)` — query current state

## Output
- For each type 2 operation, a line with two space-separated integers: the current value `x` and the total accumulated weight `xl + xr + bt`

## Initialization
- Reads all operations into list `aa`
- Sets `bt` to the weight from the first operation
- Sets `m = 2^20` (unused in logic)
- Creates a frequency dictionary `c` with sentinel values at negative and positive infinity
- Sets initial current value `x` from the first operation's `a` value
- Initializes left/right heaps (`lq`, `rq`) with infinity sentinels
- Initializes counters: `xl`, `xr` (accumulated distances), `lc`, `rc` (counts on each side)

## Main Processing Loop
Iterates through operations after the first one:

### Type 2 (Query)
- Appends formatted string `"{x} {xl+xr+bt}"` to results

### Type 1 (Add)
- Updates `bt` by adding the new weight `b`
- If `a == x`: increments frequency of `x` and continues
- Otherwise:
  - Increments frequency of `a`
  - If this is the first occurrence of `a`, pushes it onto the appropriate heap:
    - If `a < x`: push `-a` onto left heap (negated for max-heap behavior)
    - If `a > x`: push `a` onto right heap (min-heap)

#### When adding a value less than current `x`:
- Updates `xl` by adding `x - a`
- Increments `lc`
- Computes current total `t = xl + xr`
- Looks at the largest value on the left heap (`nx = -lq[0]`)
- Computes the distance `s = x - nx`
- Computes new total `nt` if moving current to `nx`:
  - `nt = xl - lc*s + xr + (rc+xc)*s`
- If `nt <= t` (moving improves or ties):
  - Updates `xl` and `xr` accordingly
  - Adjusts counts (`lc`, `rc`)
  - Pushes old `x` onto right heap
  - Sets `x = nx`
  - Pops from left heap

#### When adding a value greater than current `x`:
- Updates `xr` by adding `a - x`
- Increments `rc`
- Computes current total `t = xl + xr`
- Looks at smallest value on right heap (`nx = rq[0]`)
- Computes distance `s = nx - x`
- Computes new total `nt` if moving current to `nx`:
  - `nt = xl + (lc+xc)*s + xr - rc*s`
- If `nt < t` (strictly better):
  - Updates `xl` and `xr`
  - Adjusts counts
  - Pushes old `x` onto left heap (negated)
  - Sets `x = nx`
  - Pops from right heap

## Data Dependencies
- `c` dictionary tracks multiplicities of all values
- `lq` and `rq` heaps maintain candidate values on each side of current `x`
- `xl`, `xr` accumulate weighted distances from current position
- `lc`, `rc` count distinct values on each side
- `bt` accumulates total weight from all type 1 operations
- `x` is the current "median-like" position that shifts based on cost comparisons

## Key Behavior
The algorithm maintains a current position `x` and adjusts it when adding new values would reduce the total weighted distance. The decision to move uses a cost comparison between staying and moving to the nearest candidate on the appropriate side. The heaps ensure efficient access to nearest candidates.
