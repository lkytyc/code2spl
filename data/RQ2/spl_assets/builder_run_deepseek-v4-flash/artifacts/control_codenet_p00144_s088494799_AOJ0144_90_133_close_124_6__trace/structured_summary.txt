# Structured Description of Code

## Class Overview
The `Main` class contains multiple problem-solving methods (AOJ0144, AOJ0145, AOJ0147) and supporting data structures. It uses a `Scanner` for input and static imports for `Math` functions and `System.out`.

## Global Fields
- `sc`: A `Scanner` object for reading input
- `vx`, `vy`: Integer arrays representing directional vectors (right, down, left, up)

## Nested Class: Point
- **Fields**: `x`, `y` (integers)
- **Constructors**: 
  - Parameterized constructor with x, y coordinates
  - Default constructor setting coordinates to (0,0)
- **Methods**:
  - `toString()`: Returns coordinates in format "(x,y)"
  - Static `ok(x, y, X, Y, min)`: Returns true if x is in range [min, X) and y is in range [min, Y)
  - Static `ok(x, y, X, Y)`: Calls the 5-parameter version with min=0

## Main Method
- Creates a new `Main` instance and calls `AOJ0144()`

## Method: AOJ0145
- **Input**: Reads integer N, then N pairs of integers (upper, down values)
- **Processing**: Creates an array of `C0145` objects with the input values
- **Output**: Prints `Integer.MAX_VALUE` for each test case
- **Loop**: Continues while scanner has more input

## Nested Class: C0145
- **Fields**: `upper`, `down` (integers)
- **Constructor**: Takes two integers and assigns them to fields

## Method: AOJ0147
- **Input**: Reads integers until end of input, storing them in a queue
- **Initialization**: 
  - Sets MAX to at least 120, updating with maximum input value
  - Creates arrays for group numbers, times, and seats (17 seats initialized to -1)
  - Precomputes group sizes: 5 if index mod 5 equals 1, otherwise 2
  - Precomputes service times using formula: 17*(i%2) + 3*(i%3) + 19
- **Main Loop**: Processes groups while queue is not empty
  - Calls `exit()` to free seats whose time has elapsed
  - Calls `find()` to locate available consecutive seats
  - If seats found and minimum time condition met:
    - Checks if current group matches queue front
    - If match, prints waiting time and removes from queue
    - Occupies seats for current group
    - Increments group counter
  - Otherwise increments time counter

## Method: find(seat, n)
- **Purpose**: Finds first position with n consecutive empty seats
- **Logic**: Iterates through positions 0 to 17-n, checking if all n seats are empty (-1)
- **Returns**: Starting index if found, otherwise -1

## Method: exit(seat, min, time)
- **Purpose**: Frees seats whose service time has completed
- **Logic**: For each occupied seat, calculates exit time as group index*5 + service time; if current time >= exit time, sets seat to -1
- **Returns**: Updated seat array

## Method: disp(seat, min)
- **Purpose**: Debug output showing current time and seat occupancy
- **Output**: Prints time followed by all 17 seat values

## Method: AOJ0144
- **Input**: 
  - First line: N (number of nodes)
  - For each node: node ID, degree k, then k neighbor IDs
  - Then P (number of queries)
  - Each query: source, destination, max hops (v)
- **Processing**: 
  - Builds adjacency matrix R
  - For each query, performs a modified Dijkstra/BFS search using priority queue
  - Uses `C0144` objects with fields: current node, remaining TTL, cost
  - Maintains a `close` array to track best known states for each node
  - Expands nodes while TTL > 0
  - Updates answer when destination reached
- **Output**: For each query, prints minimum cost or "NA" if unreachable

## Nested Class: C0144
- **Fields**: `now` (current node), `ttl` (remaining hops), `c` (cost)
- **Constructor**: Takes three integers
- **compareTo**: Orders by cost (ascending), returns 0 if equal

## Key Data Dependencies
- AOJ0147: Group sizes and times depend on group index; seat availability depends on time progression
- AOJ0144: Path finding depends on adjacency matrix, TTL constraints, and cost accumulation
