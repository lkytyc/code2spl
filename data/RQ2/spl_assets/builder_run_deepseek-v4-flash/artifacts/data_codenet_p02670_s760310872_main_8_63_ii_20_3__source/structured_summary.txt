## Inputs
- An integer `n` read from standard input, representing the size of an `n x n` grid.
- A sequence of `n*n` long integers read from standard input, one per iteration.

## Initialization
- A 2D array `a` of size 501x501 is declared.
- A variable `k` is initialized to 1 and used to fill the grid with sequential integers from 1 to `n*n` in row-major order (row 0 gets 1..n, row 1 gets n+1..2n, etc.).
- Variables `p` (for input values), `cnt` (accumulator, initialized to 0), and `m` (an array of 5 longs) are declared.

## Main Processing Loop
The program iterates `n*n` times, reading one long integer `p` each iteration. Based on the value of `p`, it performs one of several actions:

### Case 1: Top row (p in range 1 to n)
- Sets `a[0][p-1]` to 0.

### Case 2: Bottom row (p in range n*n-n+1 to n*n)
- Sets `a[n-1][n-(n*n)+p-1]` to 0.

### Case 3: Rightmost column (p divisible by n)
- Sets `a[(p/n)-1][n-1]` to 0.

### Case 4: Leftmost column (p mod n equals 1)
- Sets `a[p/n][0]` to 0.

### Case 5: Interior cells (all other cases)
- Computes row index `i = p/n` and column index `j = (p%n)-1`.
- Sets `a[i][j]` to 0.
- Initializes array `m` with four values: `i`, `n-1-i`, `j`, `n-1-j`.
- Counts zeros in four directions from cell (i,j):
  - Upward: iterates rows 0 to i-1 in column j, decrementing `m[0]` for each zero found.
  - Downward: iterates rows n-1 down to i+1 in column j, decrementing `m[1]` for each zero found.
  - Leftward: iterates columns 0 to j-1 in row i, decrementing `m[2]` for each zero found.
  - Rightward: iterates columns n-1 down to j+1 in row i, decrementing `m[3]` for each zero found.
- Sorts the first four elements of `m` in ascending order using `qsort` with the comparison function `compare_int`.
- Takes the smallest value `mm = m[0]` and adds it to `cnt`.

## Comparison Function
- `compare_int` subtracts the second long value from the first, returning the difference (used for ascending sort).

## Output
- After all `n*n` iterations, prints the accumulated value `cnt` as a long integer.

## Control Flow Summary
- The program has a single main loop with conditional branches based on the position of `p` in the grid.
- The interior-cell case contains four inner loops (for counting zeros in each direction) and a call to `qsort`.
- No other function calls are made besides `scanf`, `printf`, and `qsort`.
