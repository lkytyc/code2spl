## Overview
This program reads a graph with n vertices and m edges, processes union operations to form connected components, and then computes a minimum-cost result based on the number of components formed.

## Inputs
- First line: two integers `n` (number of vertices) and `m` (number of edges)
- Next `n` lines: integer values `a[i]` for each vertex (costs)
- Next `m` lines: pairs of integers `x` and `y` representing edges between vertices

## Initialization
- Arrays `uni` and `a` are declared with size `n`
- `a[i]` stores the cost for vertex `i`
- `uni[i]` is initialized to `i` for all vertices (each vertex starts as its own component representative)

## Union Operations
For each of the `m` edges (x, y):
- If `uni[x] != x` (x is not a root):
  - Save the current representative of `y` as `t`
  - Set `uni[y] = x`
  - Follow the chain from `y` to find the actual root and update `uni[y]` to that root
  - Scan all vertices: if a vertex `j` (not equal to `y`) has `uni[j] == t`, update it to the new root of `y`
- Otherwise (x is a root):
  - Save the current representative of `x` as `t`
  - Set `uni[x] = y`
  - Follow the chain from `x` to find the actual root and update `uni[x]` to that root
  - Scan all vertices: if a vertex `j` (not equal to `x`) has `uni[j] == t`, update it to the new root of `x`

## Component Counting
- Count `num` as the number of vertices where `uni[i] == i` (roots/components)

## Decision Logic
1. If `num == 1` (single component): print `0` and exit
2. If `num * 2 - 2 > n`: print `Impossible` and exit
3. If `num * 2 - 2 == n`: print the sum of all `a[i]` values and exit

## Minimum Cost Calculation
- Initialize arrays `min` and `minn` with size `n`
- Set all `min[i]` to a large sentinel value (`inf`)
- For each vertex `i`: if `min[uni[i]] > a[i]`, update `min[uni[i]]` to `a[i]` and `minn[uni[i]]` to `i`
- Initialize `ssum` (sum) to 0
- Set `tnum = num - 2`
- For each vertex `i`:
  - If `min[i]` is not the sentinel value, add `min[i]` to `ssum` and set `a[minn[i]]` to the sentinel value
- Sort array `a` in ascending order using `qsort`
- Add the first `tnum` elements of the sorted array to `ssum`

## Output
- Print `ssum` as a long long integer

## Key Data Dependencies
- The union operations modify the `uni` array, which determines component membership
- The minimum cost calculation depends on both the component structure (`uni`) and vertex costs (`a`)
- The final sum combines per-component minimum costs with additional smallest costs from the sorted array
