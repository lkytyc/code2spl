[DEFINE_WORKER: "Reads grid dimensions, a straight-line movement budget, and 1-based start/end coordinates; runs a direction-indexed BFS over the char grid to compute the minimum movement cost from start to end while avoiding '@' cells, and prints -1 if the destination remains unreachable." main]
    [INPUTS]
    [END_INPUTS]

    [OUTPUTS]
    [END_OUTPUTS]

    [MAIN_FLOW]
        [SEQUENTIAL_BLOCK]
            [COMMAND Read three integer tokens from sc into n, m, and k, representing the number of grid rows, number of grid columns, and the straight-line movement budget. RESULT n, m, k]
            [COMMAND Allocate two int arrays of length 2 named start and end, initially filled with zeros. RESULT start, end]
            [COMMAND Loop i from 0 to 1 inclusive with condition i < 2, read an integer from sc, subtract 1, and assign the result to start[i], converting the start coordinate from 1-based to 0-based. RESULT start]
            [COMMAND Loop i from 0 to 1 inclusive with condition i < 2, read an integer from sc, subtract 1, and assign the result to end[i], converting the end coordinate from 1-based to 0-based. RESULT end]
            [COMMAND Allocate a 2D character array in with dimensions n rows and m columns, so in is a char[n][m] grid. RESULT in]
            [COMMAND Loop i from 0 to n-1 with condition i < n, read the next line from sc and convert it with toCharArray(), assigning the resulting char array to in[i]. RESULT in]
            [COMMAND Set inf to the integer cast of 1e9, which is 1000000000, as the unreachable/infinity sentinel. RESULT inf]
            [COMMAND Allocate a 3D integer array dist with dimensions n by m by 4, representing distance values for each cell and each incoming direction; all elements default to 0. RESULT dist]
            [COMMAND For every 2D array i in dist, for every 1D array j in i, call Arrays.fill(j, inf) so every dist cell is initialized to the infinity sentinel. RESULT dist]
            [COMMAND Initialize an empty LinkedList q that will hold int[] BFS states. RESULT q]
            [COMMAND Add the initial state to q as a new int[] {start[0], start[1], k, -1, 0}, representing start coordinates, remaining straight-line budget k, direction -1 meaning no previous direction, and distance 0. RESULT q]
            [COMMAND Set dist[start[0]][start[1]][0], dist[start[0]][start[1]][1], dist[start[0]][start[1]][2], and dist[start[0]][start[1]][3] all to 0, marking the start cell as reachable with distance 0 for every direction index. RESULT dist]
            [COMMAND Define dx = {0, 1, 0, -1} and dy = {1, 0, -1, 0}, representing the four neighbor directions east, south, west, and north. RESULT dx, dy]
            [COMMAND While q is not empty, poll an int[] cur from q and unpack x = cur[0], y = cur[1], curK = cur[2], dir = cur[3], and curDist = cur[4]. RESULT x, y, curK, dir, curDist]
            [COMMAND Within the while loop, for each direction i from 0 to 3 inclusive with condition i < 4, compute the neighbor coordinates xx = x + dx[i] and yy = y + dy[i]. RESULT xx, yy]
            [COMMAND Within the while loop and the for loop over directions i, if xx < 0 or xx >= n or yy < 0 or yy >= m or dist[xx][yy][i] != inf or in[xx][yy] == '@', continue to the next direction, skipping this out-of-bounds, already-visited, or obstacle neighbor. RESULT none]
            [COMMAND Within the while loop and the for loop over directions i, build a candidate next state nxt = {xx, yy, curK - 1, i, 0}, with coordinates, decremented remaining budget, direction i, and temporary distance 0. RESULT nxt]
            [COMMAND Within the while loop and the for loop over directions i, if nxt[2] < 0, meaning the straight-line budget was exhausted by this move, set nxt[2] = k - 1 and dist[xx][yy][i] = curDist + 1. RESULT nxt, dist]
            [COMMAND Within the while loop and the for loop over directions i, if nxt[2] is not negative and dir equals i, meaning the move continues in the previous direction, set dist[xx][yy][i] = curDist. RESULT dist]
            [COMMAND Within the while loop and the for loop over directions i, if nxt[2] is not negative and dir does not equal i, meaning the move changes direction, set dist[xx][yy][i] = curDist + 1 and nxt[2] = k - 1. RESULT nxt, dist]
            [COMMAND Within the while loop and the for loop over directions i, set nxt[4] = dist[xx][yy][i] and add the completed nxt state to q. RESULT q]
            [COMMAND After the while loop terminates, initialize ans = inf. RESULT ans]
            [COMMAND Loop i from 0 to 3 inclusive with condition i < 4, update ans = Math.min(ans, dist[end[0]][end[1]][i]) to find the minimum distance among all directions at the end cell. RESULT ans]
            [COMMAND Print ans if ans != inf, otherwise print -1, using pw.println(ans == inf ? -1 : ans). RESULT printed output]
