# Structured Description

## Inputs
- Three integers `n`, `m`, `k` are read from standard input, representing grid height, grid width, and a movement parameter.
- Two coordinate pairs are read: `start` (two integers, each decremented by 1) and `end` (two integers, each decremented by 1), representing zero-based grid positions.
- A character grid of size `n` by `m` is read line by line. Each cell contains a character; `'@'` denotes an obstacle.

## Outputs
- A single integer is printed to standard output: the minimum cost to reach the end cell from the start cell, or `-1` if unreachable.

## Initialization
- A 3D distance array `dist` of size `n` × `m` × 4 is created and all entries are set to a large sentinel value (`1e9`).
- A queue (linked list) is initialized with the start state: coordinates `(start[0], start[1])`, remaining movement count `k`, direction `-1` (no direction), and distance `0`.
- All four direction-specific distances at the start cell are set to `0`.

## Movement Directions
- Four movement directions are defined: right, down, left, up, corresponding to index values 0, 1, 2, 3.

## Main Search Loop
- While the queue is not empty, a state is dequeued containing: x-coordinate, y-coordinate, remaining movement count `curK`, current direction `dir`, and current distance `curDist`.
- For each of the four possible directions:
  - Compute the next cell coordinates.
  - Skip if the next cell is out of bounds, already visited in that direction, or contains an obstacle (`'@'`).
  - Create a candidate next state with remaining movement count `curK - 1` and the new direction.
  - If the remaining movement count becomes negative:
    - Reset it to `k - 1`.
    - Set the distance for that cell and direction to `curDist + 1`.
  - Otherwise (remaining count is non-negative):
    - If the new direction equals the current direction, set the distance to `curDist` (no additional cost).
    - If the new direction differs from the current direction, set the distance to `curDist + 1` and reset the remaining movement count to `k - 1`.
  - Update the candidate state's distance field with the computed distance and enqueue it.

## Final Answer Computation
- After the search completes, the minimum distance among all four directions at the end cell is computed.
- If the minimum is still the sentinel value, print `-1`; otherwise print the minimum distance.

## Helper Components
- A custom scanner class (`MScanner`) wraps a `BufferedReader` and `StringTokenizer` to provide token-based input reading.
- The scanner supports reading integers, longs, doubles, characters, strings, lines, and arrays, with optional shuffling and sorting for arrays.
- Shuffle methods randomly permute integer or long arrays.
- The main entry point initializes the scanner and output writer, calls the main logic, and flushes output.

## Data Dependencies
- The distance value for a state depends on the current distance, the direction change, and the remaining movement count.
- The remaining movement count is decremented on each move and reset when a direction change occurs or when it would become negative.
- The visited condition depends on the direction index, so the same cell can be visited multiple times with different directions.
