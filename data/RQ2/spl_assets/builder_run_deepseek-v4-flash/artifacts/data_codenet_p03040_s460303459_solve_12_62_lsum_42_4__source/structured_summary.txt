## Overview
This program implements a data structure that maintains a dynamic multiset of numbers and supports two types of operations: insertion with an associated cost, and queries about the current median and a computed sum. The core logic uses two priority queues to maintain the lower and upper halves of the inserted values.

## Input
The program reads from standard input using a custom `InputReader` class. The first integer read is `Q`, the number of operations to process. Each subsequent operation consists of:
- An integer command (`com`), either 1 or 2
- For command 1: a long integer `a` (the value to insert) followed by another long integer (stored in `B`)
- For command 2: no additional parameters

## Output
For each command 2, the program outputs a line containing two values separated by a space: the current median value and a computed sum.

## Data Structures
- `f`: A max-heap (priority queue with reverse ordering) storing the lower half of inserted values
- `l`: A min-heap (standard priority queue) storing the upper half of inserted values
- `fsum`: Running sum of all values currently in heap `f`
- `lsum`: Running sum of all values currently in heap `l`
- `B`: Accumulated sum of the second long values from all type-1 operations

## Control Flow

### Main Loop
The program processes `Q` operations in a while loop that decrements `Q` after each iteration.

### Type 1 Operation (Insertion)
When `com == 1`:
1. Reads value `a` to insert
2. If heaps are balanced (equal sizes):
   - If both heaps are empty: add `a` to heap `f`, update `fsum`
   - Otherwise: compare `a` with the minimum of heap `l` (peek)
     - If `a` is larger: move the minimum from `l` to `f`, insert `a` into `l`, update both sums accordingly
     - Otherwise: insert `a` directly into `f`, update `fsum`
3. If heap `f` is larger (unbalanced):
   - Compare `a` with the maximum of heap `f` (peek)
     - If `a` is at least as large: insert `a` into `l`, update `lsum`
     - Otherwise: move the maximum from `f` to `l`, insert `a` into `f`, update both sums
4. Reads the second long value and adds it to `B`

### Type 2 Operation (Query)
When `com == 2`:
1. Gets the maximum of heap `f` (peek) as the median value `x`
2. If heaps are balanced (equal sizes): outputs `x` and `(lsum - fsum + B)`
3. If heap `f` is larger: outputs `x` and `(lsum - fsum + x + B)`

## Helper Methods
- `tr(Object... o)`: Debug utility that prints and flushes the deep string representation of arguments

## InputReader Class
A custom fast input reader with methods:
- `hasNextByte()`: Checks if more bytes are available, refills buffer if needed
- `readByte()`: Returns next byte or -1 if end of stream
- `isSpaceChar(int c)`: Returns true for non-printable ASCII characters (outside 33-126)
- `skip()`: Skips whitespace characters
- `hasNext()`: Checks if there's another token
- `next()`: Reads next token as string
- `nextInt()`: Parses next token as integer, handling optional minus sign
- `nextLong()`: Parses next token as long, handling optional minus sign
- `nextDouble()`: Parses next token as double
- `nextIntArray(int n)`: Reads array of n integers
- `nextLongArray(int n)`: Reads array of n longs
- `nextCharMap(int n, int m)`: Reads n strings of length m as character array

## Error Handling
- `InputMismatchException`: Thrown on I/O errors or invalid numeric characters
- `NoSuchElementException`: Thrown when trying to read past available input

## Main Method
Initializes the input reader with `System.in` and output writer with `System.out`, calls `solve()`, then flushes the output.
