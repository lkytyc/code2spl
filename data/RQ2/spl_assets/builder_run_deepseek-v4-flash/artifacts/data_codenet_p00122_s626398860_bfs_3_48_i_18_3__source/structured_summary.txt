## Function: bfs

### Inputs
- `sx`, `sy`: integer coordinates representing the starting position
- `spx`, `spy`: integer arrays of equal length representing a sequence of target positions

### Outputs
- Returns `true` if all target positions can be reached in sequence
- Returns `false` if the traversal fails before reaching all targets

### Local Variables
- `size = 10`: fixed grid dimension (10x10)
- `spCnt`: counter tracking how many target positions have been processed
- `dx`, `dy`: arrays of 12 movement offsets (knight-like moves)
- `dx2`, `dy2`: arrays of 9 offsets for marking a 3x3 area around a target
- `park`: 10x10 boolean grid marking blocked cells
- `queueX`, `queueY`: queues for BFS frontier

### Control Flow
1. Initialize queues with starting position
2. **Main loop** (while queue is not empty):
   - If `spCnt` equals the length of `spx`, return `true` (all targets reached)
   - Mark a 3x3 area around the current target position as blocked in `park`
   - **Inner loop 1**: Process all positions in current queue:
     - For each position, try all 12 movement offsets
     - If a move stays within bounds (0-9) and lands on a blocked cell, add to new queues
   - Increment `spCnt`
   - Reset `park` to all false
   - Replace current queues with new queues
3. If queue becomes empty before all targets reached, return `false`

### Key Logic
- The BFS only allows moves that land on cells marked as blocked (the 3x3 area around the current target)
- After processing each target, the grid is reset, so the next target's 3x3 area is the only valid landing zone
- Movement uses 12 specific offsets that resemble knight moves but with extended ranges

## Function: main

### Inputs
- Reads from standard input via Scanner

### Outputs
- Prints "OK" if `bfs` returns true, "NA" otherwise

### Control Flow
1. **Infinite loop** (while true):
   - Read `sx` and `sy` from input
   - If both are 0, break the loop
   - Read `n` (number of target positions)
   - Read `n` pairs of coordinates into `spx` and `spy` arrays
   - Call `bfs` with these parameters and print result
2. Loop continues until termination condition met

### Data Dependencies
- The `bfs` function depends on the arrays and starting coordinates passed from `main`
- `main` reads all input values sequentially from the scanner
