# Code Description

## Input Handling Function: `readline()`

**Purpose:** Reads a line from standard input and returns it as a dynamically allocated string.

**Input:** Reads from `stdin` using `fgets`.

**Output:** Returns a pointer to a null-terminated string containing the line read (without the trailing newline character).

**Behavior:**
- Allocates an initial buffer of 1024 bytes.
- Reads input in a loop using `fgets`, appending to the buffer.
- If the buffer fills up without finding a newline, the buffer size is doubled using `realloc`.
- The loop terminates when either:
  - `fgets` returns NULL (end of input or error), or
  - A newline character is found in the data.
- After the loop, if the last character is a newline, it is replaced with a null terminator.
- If no newline was found (end of file without newline), a null terminator is appended after the existing data.
- The buffer is shrunk to exactly fit the data using `realloc` before returning.

**Edge Cases:**
- If `realloc` fails during buffer expansion, the function breaks out of the loop and returns whatever data was read so far.
- If the initial `malloc` fails, the function will crash when accessing `data`.

## Main Function

**Input:** Command-line arguments (not used in the logic).

**Output:** Prints results to stdout in the format `Case #N: POSSIBLE` or `Case #N: IMPOSSIBLE`.

### Variable Declarations
- `u_w`: Unsigned integer used as a case counter (starts at 1).
- `T`: Integer representing the number of test cases.
- `str`: Character pointer for reading input lines.
- `retStr`: Character pointer for storing the result string.

### Control Flow

1. **Read number of test cases:**
   - Calls `readline()` to get a line.
   - Parses it as an integer into `T` using `sscanf`.
   - Frees the allocated string.

2. **Process each test case in a loop:**
   - The loop continues while `T-- != 0` (decrements T after checking).
   - For each test case:
     - Declares local variables: `R`, `C`, `H`, `V` (dimensions and cut parameters), loop counters `i`, `j`, `k`, `l`, `m`.
     - Declares `Waffle[10]`: Array of character pointers (max 10 rows).
     - Declares `ChocChipCount[10]`: Array of integers for chocolate chip counts per row.
     - Initializes all `ChocChipCount` entries to 0.

3. **Read grid dimensions:**
   - Calls `readline()` and parses four integers: `R` (rows), `C` (columns), `H` (horizontal cuts), `V` (vertical cuts).
   - Frees the string.

4. **Read the waffle grid:**
   - For each row `i` from 0 to `R-1`:
     - Calls `readline()` to get the row string.
     - Stores it in `Waffle[i]`.
     - Counts occurrences of `'@'` (chocolate chips) in that row and stores the count in `ChocChipCount[i]`.
