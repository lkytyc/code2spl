## Function: FindNewWord(w_list)

**Input:** A list of strings (words), all of the same length.

**Output:** Either a new string (word) or the string "-".

**Behavior:**
- Sorts the input list alphabetically in place.
- Determines the common word length L from the first word.
- Returns "-" immediately if there is only one word or if all words have length 1.
- Groups words by their first character, recording the starting index of each group in `prefix_index`.
- Iterates through character positions from index 1 up to L-1:
  - Collects all distinct letters appearing at that position across all words into `available_letters`.
  - For each group of words sharing the same prefix (based on previous character positions):
    - Collects the distinct letters appearing at the current position within that group.
    - Computes `remaining_letters` as letters present globally at this position but absent from this group.
    - If any remaining letters exist, picks one and constructs a candidate word by taking the group's prefix up to the current position and appending that letter. Sets a found flag and breaks out.
  - If no candidate found at this position, updates `prefix_index` to reflect finer grouping based on the current character and continues to the next position.
- If no candidate was found after all positions, returns "-".
- If a candidate was found, appends the remaining characters from the first word (positions after the candidate's length up to L) to complete the word, then returns it.

**Key data dependencies:**
- `prefix_index` tracks group boundaries and is updated each iteration.
- `available_letters` is recomputed each position.
- `curr_word` accumulates the candidate prefix.

## Function: solve_jam()

**Input:** Reads from standard input:
- First line: integer T (number of test cases).
- For each test case: a line with two integers N and L, followed by N lines each containing a word.

**Output:** Returns a list of strings, one per test case, each being the result of FindNewWord for that test case.

**Behavior:**
- Loops T times.
- For each iteration, reads N and L, then reads N words into `w_list`.
- Calls FindNewWord(w_list) and appends the result to the output list.
- Returns the output list.

## Function: save_output(output)

**Input:** A list of strings.

**Output:** Prints to standard output.

**Behavior:**
- Iterates through the list with an index.
- Prints each value formatted as "Case #<index+1>: <value>".

## Main Execution Flow

1. Calls solve_jam() to read input and compute results.
2. Passes the returned list to save_output() to print results.

## Control Flow Summary

- **Branches:** Early return in FindNewWord for single word or length-1 words; break conditions when a candidate is found; return "-" when no candidate exists.
- **Loops:** Character position loop (positions 1 to L-1), group iteration loop, inner word iteration within groups, test case loop in solve_jam, output printing loop.
- **Function calls:** FindNewWord called from solve_jam; deepcopy used to copy prefix_index; solve_jam and save_output called at top level.
