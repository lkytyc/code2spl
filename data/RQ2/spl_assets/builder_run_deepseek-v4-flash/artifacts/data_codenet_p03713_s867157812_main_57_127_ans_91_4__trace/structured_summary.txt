# Code Description

## Overview
This program reads two integers representing the height and width of a rectangle, then determines the minimum possible difference between the largest and smallest areas when dividing the rectangle into three rectangular pieces using straight cuts.

## Input
- Two integers read via `scanf`: `h` (height) and `w` (width)

## Output
- A single long long integer representing the minimum difference between the maximum and minimum areas among the three pieces

## Helper Functions

### descending_compare
- Takes two void pointers to integers
- Returns -1 if first value is greater, 0 if equal, 1 if first value is smaller
- Used for descending order sorting

### ascending_compare
- Takes two void pointers to integers
- Returns -1 if first value is smaller, 0 if equal, 1 if first value is greater
- Used for ascending order sorting

### lower_bound
- Parameters: integer array `a`, size `n`, and search key
- Performs a binary search to find the first position where the value is greater than or equal to the key
- Uses a custom loop condition checking mid-point relationships
- Returns the index of the first element >= key, or `n` if none exists

### gcd
- Recursive function computing greatest common divisor
- Base case: if second parameter is 0, returns first parameter
- If first > second, recurses with `gcd(y, x % y)`
- Otherwise recurses with `gcd(x, y % x)`

### factorial
- Computes factorial of input integer
- Uses a loop from the input value down to 2
- Multiplies accumulated result by each value
- Returns long long result

## Main Function Logic

### Initialization
- Declares variables for height (`h`), width (`w`), an array `square[3]` for three areas, min/max tracking variables, and answer variable initialized to 10^13

### First Loop (Horizontal Cuts)
- Iterates `i` from 1 to `h-1`
- For each iteration:
  - **First configuration**: 
    - `square[0]` = area of top piece (i × w)
    - `square[1]` = area of bottom-left piece ((h-i) × floor(w/2))
    - `square[2]` = area of bottom-right piece ((h-i) × ceil(w/2))
  - **Second configuration**:
    - `square[0]` remains the same
    - `square[1]` = area of bottom-left piece (floor((h-i)/2) × w)
    - `square[2]` = area of bottom-right piece (ceil((h-i)/2) × w)
  - For each configuration:
    - Finds minimum and maximum among the three areas
    - Updates answer if the difference (max - min) is smaller than current answer

### Second Loop (Vertical Cuts)
- Iterates `i` from 0 to `w-1`
- For each iteration:
  - **First configuration**:
    - `square[0]` = area of left piece (i × h)
    - `square[1]` = area of right-top piece ((w-i) × floor(h/2))
    - `square[2]` = area of right-bottom piece ((w-i) × ceil(h/2))
  - **Second configuration**:
    - `square[0]` remains the same
    - `square[1]` = area of right-top piece (floor((w-i)/2) × h)
    - `square[2]` = area of right-bottom piece (ceil((w-i)/2) × h)
  - For each configuration:
    - Finds minimum and maximum among the three areas
    - Updates answer if the difference is smaller than current answer

### Output
- Prints the final minimum difference as a long long integer

## Key Data Dependencies
- The answer depends on all possible split positions in both horizontal and vertical directions
- Each split position generates two possible configurations (splitting the remaining rectangle either horizontally or vertically)
- The minimum difference is tracked across all configurations
- All area calculations use explicit casting to long long to prevent overflow
