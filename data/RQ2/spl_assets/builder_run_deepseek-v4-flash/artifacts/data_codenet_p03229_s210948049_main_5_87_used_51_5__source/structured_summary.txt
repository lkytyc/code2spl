## Input
- Reads an integer N from standard input.
- Then reads N integers, one per line, into a list A.

## Initial Processing
- Sorts the list A in ascending order.
- Creates a boolean/flag array `used` of length N, initialized to all zeros.

## Output Variables
- Two accumulators: `output1` and `output2`, both initialized to 0.
- The final result printed is the maximum of these two accumulators.

## First Computation (output1)
- Initializes four index pointers:
  - `i1 = 0` (left pointer for first pair)
  - `i2 = 0` (left pointer for second pair)
  - `j1 = N-1` (right pointer for first pair)
  - `j2 = N-2` (right pointer for second pair)
- Marks positions 0, 0, N-1, and N-2 as used.
- Two flags `f1` and `f2` are set to True, controlling whether each pair is still active.

### Loop structure for output1:
- While either flag is True:
  - If f1 is True, add (A[j1] - A[i1]) to output1.
  - If f2 is True, add (A[j2] - A[i2]) to output1.
  - Advance i1: while the current i1 position is used, increment i1. If i1 reaches N-1, set f1 to False and stop advancing. Mark the new i1 position as used.
  - Advance i2: while the current i2 position is used, increment i2. If i2 reaches N-1, set f2 to False and stop advancing. Mark the new i2 position as used.
  - If f1 is still True, add (A[j1] - A[i1]) to output1.
  - If f2 is still True, add (A[j2] - A[i2]) to output1.
  - Decrement j1: while the current j1 position is used, decrement j1. If j1 reaches 0, set f1 to False and stop. Mark the new j1 position as used.
  - Decrement j2: while the current j2 position is used, decrement j2. If j2 reaches 0, set f2 to False and stop. Mark the new j2 position as used.

## Second Computation (output2)
- Resets pointers:
  - `i1 = 0`, `i2 = 1`
  - `j1 = N-1`, `j2 = N-1`
- Resets both flags to True.
- Reinitializes the `used` array to all zeros.
- Marks positions 0, 1, N-1, and N-1 as used.

### Loop structure for output2:
- While either flag is True:
  - If f1 is True, add (A[j1] - A[i1]) to output2.
  - If f2 is True, add (A[j2] - A[i2]) to output2.
  - Decrement j1: while the current j1 position is used, decrement j1. If j1 reaches 0, set f1 to False and stop. Mark the new j1 position as used.
  - Decrement j2: while the current j2 position is used, decrement j2. If j2 reaches 0, set f2 to False and stop. Mark the new j2 position as used.
  - If f1 is still True, add (A[j1] - A[i1]) to output2.
  - If f2 is still True, add (A[j2] - A[i2]) to output2.
  - Advance i1: while the current i1 position is used, increment i1. If i1 reaches N-1, set f1 to False and stop. Mark the new i1 position as used.
  - Advance i2: while the current i2 position is used, increment i2. If i2 reaches N-1, set f2 to False and stop. Mark the new i2 position as used.

## Output
- Prints the larger of output1 and output2.

## Key Behavioral Notes
- The algorithm processes pairs of (left index, right index) from the sorted array.
- The `used` array prevents reusing the same array position in multiple pairs.
- The two computations differ in their initial pointer assignments and the order of advancing left vs. right pointers.
- The loop terminates when both flags become False, which happens when pointers reach the boundaries (0 or N-1) while searching for unused positions.
- The algorithm assumes N is at least 2 (since it initializes j2 = N-2 in the first computation).
