## Overview
This program processes multiple test cases of a 5-column grid game, calculating scores based on matching adjacent values in columns. It reads input values, processes them through repeated scoring and collapsing rounds, and outputs the total score for each test case.

## Inputs
- Integer `n` representing the number of rows to process (read via `scanf`)
- For each of `n` rows, 5 integer values are read (one per column)
- The outer loop continues while `n` is non-zero, reading a new `n` after each test case

## Outputs
- For each test case, prints the total accumulated `point` value as an integer

## Data Structures
- `a[5][20]`: Main game grid with 5 columns and up to 20 rows
- `b[5][10]`: Temporary marker grid for matched cells
- `n`: Number of active rows
- `m`: Round counter (initialized to 11)
- `point`: Accumulated score

## Initialization
- The `a` array is zeroed for all 20 rows and 5 columns
- Input values are read into `a[j][n-1-i]`, meaning the first input row goes to the bottom of the grid (row index `n-1`), and subsequent rows fill upward

## Main Processing Loop (while `m > 0`)
Each iteration of this loop represents one game round:

### Step 1: Reset Marker Grid
- All elements of `b` are set to 0

### Step 2: Score Detection
For each column `i` (from 0 to n-1), the program checks for consecutive matching non-zero values:

**Case 1**: If columns 0, 1, 2 match and are non-zero:
- If columns 2, 3, 4 also match: Score = value × 5, mark all 5 cells in column
- If only columns 2, 3 match: Score = value × 4, mark cells 0-3
- Otherwise: Score = value × 3, mark cells 0-2

**Case 2**: If columns 1, 2, 3 match and are non-zero (but case 1 didn't apply):
- If columns 3, 4 also match: Score = value × 4, mark cells 1-4
- Otherwise: Score = value × 3, mark cells 1-3

**Case 3**: If columns 2, 3, 4 match and are non-zero (but cases 1 and 2 didn't apply):
- Score = value × 3, mark cells 2-4

### Step 3: Remove Marked Cells
- For each marked cell in `b`, set the corresponding cell in `a` to 0 and reset the marker

### Step 4: Collapse Columns
- Performs `n` passes of shifting cells downward
- For each column, if a cell is 0, all cells above it shift down by one position
- This effectively compacts non-zero values toward the bottom of each column

### Step 5: Decrement Round Counter
- `m` is decremented by 1

## Helper Function
- `min(a, b)`: Returns the smaller of two integers (though not called in the main logic)

## Termination
- After 11 rounds of processing, the total score is printed
- A new `n` is read; if non-zero, the entire process repeats for the next test case
- Program ends when `n` is 0

## Key Behavioral Notes
- The grid has 5 columns but the row count varies per test case
- The collapse operation may shift values beyond the original `n` rows, but the array is sized to accommodate this
- Scoring only occurs for non-zero values, and matches must be consecutive in the column
- The program processes exactly 11 rounds regardless of whether matches are found
