# Structured Description of Code

## Overview
This is a Java program with a `Main` class that reads two integers from standard input, performs a dynamic programming computation, and prints a result. The program includes a custom scanner class and several utility methods.

## Inputs
- Two integers read from standard input: `n` and `m`
- Read via the `MyScanner.nextInt()` method in the `run()` method

## Outputs
- A single integer printed to standard output (the final computed value)
- If `m > 200000`, the program returns early without printing anything

## Main Control Flow

### `run()` Method
1. Creates a `MyScanner` instance
2. Reads integer `n` from input
3. Reads integer `m` from input
4. Sets constant `M` to 998244353
5. **Early exit condition**: If `m > 200000`, immediately returns without output

### Dynamic Programming Initialization
- Creates a 2D array `dp` with dimensions [2][m]
- Creates a 1D array `sum` of length `m`
- Sets initial values:
  - `dp[0][0] = 1`
  - `dp[0][1] = 1`
  - `sum[0] = 1`
  - `sum[1] = 2`

### Initial Loop (Fibonacci-like computation)
- Iterates from `i = 2` to `i < m`
- For each iteration:
  - `dp[0][i] = (dp[0][i-1] + dp[0][i-2]) % M`
  - `sum[i] = (sum[i-1] + dp[0][i]) % M`
- After loop, stores `last = dp[0][m-1]`

### Main Iterative Loop
- Iterates from `i = 1` to `i < n`
- For each iteration:
  - Creates new array `next` of length `m`
  - Sets `next[0] = sum[0]`
  - Inner loop from `j = 1` to `j < m`:
    - `next[j] = (next[j-1] + sum[j]) % M`
  - Updates `last = sum[m-1]`
  - Replaces `sum` with `next`

### Final Output
- Prints the value of `last` to standard output

## Helper Methods (Not Called in Main Flow)

### `debug(Object... o)`
- Prints array representation of arguments using `Arrays.deepToString`

### `debug2(int[][] array)`
- Prints a 2D integer array row by row without spaces between elements

### `inner(int h, int w, int limH, int limW)`
- Returns boolean indicating if coordinates are within bounds

### `swap(int[] x, int a, int b)`
- Swaps elements at positions `a` and `b` in array `x`

### `lower_bound(int a[], int k)`
- Binary search returning first index where `a[index] >= k`

### `upper_bound(int a[], int k)`
- Binary search returning first index where `a[index] > k`

### `gcd(long a, long b)`
- Recursive Euclidean algorithm for greatest common divisor

### `lcm(long a, long b)`
- Computes least common multiple using gcd

### `palindrome(String s)`
- Checks if string is a palindrome by comparing characters from both ends

## MyScanner Inner Class

### `nextInt()`
- Reads characters from `System.in`
- Skips non-digit characters (except minus sign)
- Handles negative numbers recursively
- Parses digits until non-digit encountered
- Returns -1 on exception

### `nextDouble()`
- Parses next token as double

### `nextLong()`
- Parses next token as long

### `next()`
- Reads until whitespace, returns string
- Returns null on exception

### `nextIntArray(int n)`
- Creates and returns array of `n` integers

### `nextInt2dArray(int n, int m)`
- Creates and returns 2D array of integers

### `nextDoubleArray(int n)`
- Creates and returns array of `n` doubles

### `nextLongArray(int n)`
- Creates and returns array of `n` longs

### `nextCharField(int n, int m)`
- Reads `n` strings and converts to character array

## Data Dependencies
- The `sum` array values depend on previous `dp` values
- Each iteration of the main loop depends on the previous `sum` array
- The final output `last` depends on the last computed `sum` value
- All computations use modulo `M = 998244353`
