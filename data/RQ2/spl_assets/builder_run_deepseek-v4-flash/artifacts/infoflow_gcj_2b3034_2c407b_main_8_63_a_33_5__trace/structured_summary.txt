# Code Structure Description

## Function: `len`
- **Input**: A character array `s` with maximum size 1001
- **Output**: Integer representing the length of the string (number of characters before the null terminator)
- **Behavior**: Iterates through the array using a for loop with an empty body, incrementing index `i` until it finds the null character `'\0'`, then returns `i`

## Main Function

### Inputs
- Reads an integer `t` from standard input (number of test cases)
- For each test case, reads an integer `n` (number of strings)
- Reads `n` strings, each preceded by a character read (likely to consume newline)

### Variable Declarations
- `t`: number of test cases
- `n`: number of strings per test case
- `i`, `j`, `k`: loop counters
- `s`: character array of size 10001 (accumulates the result)
- `str`: character array of size 101 (temporary storage for each input string)
- `a`: 2D character array of size `n` × 10001, initialized with `'#'` characters
- `flag`: integer flag for error detection
- `dd`: character variable for consuming whitespace

### Processing Logic

#### Initialization Phase
- For each test case, initializes the 2D array `a` with `'#'` characters in all positions

#### String Input and Placement
- For each of the `n` strings:
  - Reads a character into `dd` (likely to consume newline)
  - Reads a string into `str`
  - **If the string starts with `'*'`** (prefix pattern):
    - Places the string characters (including the `'*'`) into row `j` of array `a`, starting from position 10000 and moving backwards
    - The string is placed right-aligned in the array
  - **If the string ends with `'*'`** (suffix pattern):
    - Places the string characters (including the `'*'`) into row `j` of array `a`, starting from position 0 and moving forward

#### Pattern Merging
- Iterates through columns 0 to 9999 of the 2D array
- For each column position:
  - Checks all `n` rows at that column position
  - If a non-`'*'`, non-`'#'` character is found:
    - If it's the first such character found at this position, appends it to result string `s`
    - If a character was already found at this position and a different non-`'*'`, non-`'#'` character appears, sets `flag` to 1 (conflict detected)
  - If conflict detected, breaks out of the column loop

#### Output
- Terminates the result string `s` with null character
- If `flag` is 1 (conflict found): prints `Case #i: *`
- Otherwise: prints `Case #i: s` (the merged pattern)

### Control Flow Summary
- Outer loop: iterates through test cases (1 to `t`)
- Middle loop: iterates through input strings (0 to `n-1`)
- Inner loop for initialization: fills array with `'#'` (0 to 10000)
- Pattern placement loops: either forward or backward depending on `'*'` position
- Merging loop: iterates through columns (0 to 9999), with inner loop through rows (0 to `n-1`)
- Early termination: breaks from merging when conflict is detected

### Data Dependencies
- Result string `s` is built incrementally during the merging phase
- The `flag` variable controls whether the final output is the merged string or an asterisk
- The position of `'*'` in each input string determines whether it's treated as a prefix or suffix pattern
- The 2D array `a` stores all patterns aligned either left or right based on `'*'` position
