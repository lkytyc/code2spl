### Function: areInConflict(x, y)
- **Inputs:** Two integers, x and y.
- **Behavior:** Converts both integers to their binary string representations (without leading zeros), then reverses each string so the least significant bit is at index 0. It iterates over the shorter of the two binary strings. If at any position both strings have a '1' at the same index, it returns True (indicating a conflict). Otherwise, it returns False.
- **Output:** Boolean value (True if both numbers have a 1 bit in the same position, False otherwise).

### Function: solve(x, y)
- **Inputs:** Two integers, x and y (can be positive, negative, or zero).
- **Output:** A string representing a sequence of directional moves ('E', 'W', 'N', 'S') or the string "IMPOSSIBLE".

#### Steps:
1. **Store original values:** Saves original x and y as origX and origY.
2. **Take absolute values:** Sets x = max(x, -x) and y = max(y, -y), so both become non-negative.
3. **Parity check:** If x % 2 equals y % 2 (both even or both odd), returns "IMPOSSIBLE".
4. **Compute power-of-two bounds:**
   - For x: x1 is the smallest power of 2 greater than or equal to x (starting from 1, doubling until >= x). x2 = x1 - x.
   - For y: y1 is the smallest power of 2 greater than or equal to y. y2 = y1 - y.
5. **Branch 1 (direct representation):** If areInConflict(x, y) is False:
   - Builds binary strings of x and y (reversed).
   - Creates a result list of length equal to the maximum length of the two binary strings.
   - For each bit position in x's binary string, if the bit is '1', sets result[i] = "E".
   - For each bit position in y's binary string, if the bit is '1', sets result[i] = "N".
6. **Branch 2 (x decomposition):** If the first branch fails, checks if all three conditions hold: not areInConflict(x2, x1), not areInConflict(x2, y), and not areInConflict(x1, y). If true:
   - Builds binary strings for x1, x2, and y (all reversed).
   - Creates result list sized to max length of these three strings.
   - Sets "E" for bits in x1, "W" for bits in x2, and "N" for bits in y.
7. **Branch 3 (y decomposition):** If previous branches fail, checks if not areInConflict(y2, y1), not areInConflict(y2, x), and not areInConflict(y1, x). If true:
   - Builds binary strings for y1, y2, and x (all reversed).
   - Creates result list sized to max length of these three strings.
   - Sets "E" for bits in x, "N" for bits in y1, and "S" for bits in y2.
8. **Branch 4 (both decompositions):** If all previous fail, checks six non-conflict conditions involving x1, x2, y1, y2. If all true:
   - Builds binary strings for x1, x2, y1, y2 (all reversed).
   - Creates result list sized to max length of these four strings.
   - Sets "E" for bits in x1, "W" for bits in x2, "N" for bits in y1, and "S" for bits in y2.
9. **Fallback:** If none of the branches succeed, returns "IMPOSSIBLE".
10. **Sign adjustment:**
    - If original x was negative (x != origX), swaps all "E" and "W" in the result list.
    - If original y was negative (y != origY), swaps all "N" and "S" in the result list.
11. **Return:** Joins the result list into a string and returns it.

### Main Program Flow
- Reads an integer T from standard input (number of test cases).
- Loops T times:
  - Reads a line with two integers x and y.
  - Calls solve(x, y) and prints the result in the format "Case #<case_number>: <result>".
