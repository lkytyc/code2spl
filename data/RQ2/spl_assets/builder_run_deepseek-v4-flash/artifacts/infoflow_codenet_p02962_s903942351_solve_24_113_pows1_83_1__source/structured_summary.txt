## Inputs
- Reads two strings from standard input: first string `s`, then string `t`.
- Each string is read as a list of characters, with trailing newline removed if present.

## Preprocessing
- Maps each lowercase letter to a numeric value: 'a' → 1, 'b' → 2, ..., 'z' → 26.
- Converts both input strings into lists of these numeric values.
- Sets base `b = 10` and two moduli: `mod1 = 1000000007` and `mod2 = 1000000009`.

## Precomputed Powers
- Computes powers of the base for both moduli:
  - `pownt1 = b^nt mod mod1`, `invnt1 = inverse of pownt1 mod mod1`
  - `powns1 = b^ns mod mod1`, `invns1 = inverse of powns1 mod mod1`
  - Same for mod2.

## Binary Search Setup
- Initializes `l = 0` and `r = ns + 2`.
- Performs binary search while `r > l + 1`.

## Binary Search Iteration
For each midpoint `m`:
- Computes `n = m * nt` (total length of repeated `t`).
- Creates array `st` of length `nt`, all entries set to `m` (number of times each character of `t` repeats).
- Computes `ms = n // ns` and `rs = n - ms * ns`.
- Creates array `ss` of length `ns` where the first `rs` entries are `ms + 1` and the rest are `ms` (distribution of how many times each character of `s` repeats to reach length `n`).

## Hash Computation for `t` (target hash)
- Computes two rolling hashes (`h1` for mod1, `h2` for mod2) for the repeated `t` string of length `n`.
- For each character `ti` at position `i` in `t`:
  - Computes `pow1 = b^((n-i)*mod1) mod mod1` (effectively `b^(n-i)` mod mod1).
  - Computes `pows1 = pownt1^st[i] mod mod1`.
  - Adds `ti * pow1 * (pows1 - 1) * inverse(pows1 * (1 - invnt1)) mod mod1` to `h1`.
  - Same for mod2.

## Hash Computation for `s` (candidate hash)
- Computes initial hashes `k1` and `k2` for the repeated `s` string of length `n`.
- Iterates over `ns` positions:
  - If `ss[i]` is 0, breaks (no more characters).
  - For each `si` at position `i`:
    - Computes `pow1 = b^((n-i)*mod1) mod mod1`.
    - Computes `pows1 = powns1^ss[i] mod mod1`.
    - Adds `si * pow1 * (pows1 - 1) * inverse(pows1 * (1 - invns1)) mod mod1` to `k1`.
    - Same for mod2.

## Sliding Window Check
- Sets `k = 0`.
- Iterates `j` from `rs` to `ns + rs - 1`:
  - If `(h1, h2) == (k1, k2)`, sets `l = m` and breaks out of the loop.
  - Otherwise, updates the rolling hash:
    - `i = j % ns` (current position in `s`).
    - `si = s[i]`, `sk = s[k]`.
    - Updates `k1`: subtract `sk * p1 mod mod1`, add `si`, multiply by `b`, take mod.
    - Same for `k2`.
    - Increments `k`.
- If the loop completes without a match, sets `r = m`.

## Output
- After binary search completes:
  - If `l == ns + 1`, prints `-1`.
  - Otherwise, prints `l`.

## Key Dependencies
- The solution uses double hashing (two moduli) to reduce collision probability.
- The binary search finds the maximum number of repetitions of `t` that can be embedded in a cyclic repetition of `s`.
- The rolling hash updates allow checking all cyclic shifts of `s` against the target hash in O(ns) time per binary search step.
