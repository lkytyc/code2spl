## Overview
This program computes minimum transportation costs for N facilities, where each facility can be assigned to either a horizontal or vertical axis, and the cost depends on distances to assigned axes or to other facilities assigned to the same axis.

## Inputs
- First line: integer N (number of facilities)
- Next N lines: three integers each — X[i], Y[i], P[i] (coordinates and weight for each facility)

## Outputs
- N+1 lines, each containing a long integer: the minimum total cost when exactly k facilities are assigned to the horizontal axis, for k = 0 to N

## Data Structures
- Arrays X[20], Y[20], P[20]: facility coordinates and weights
- Array a[20]: assignment state for each facility (0 = unassigned, 1 = horizontal, 2 = vertical)
- 3D array Z[1<<16][16][2]: precomputed distances; Z[mask][j][0] = minimum horizontal distance for facility j given the set of horizontal facilities in mask; Z[mask][j][1] = minimum vertical distance similarly
- Array ans[20]: stores minimum cost for each count of horizontal assignments

## Initialization
- Reads N and facility data
- Initializes ans[0] through ans[N] to a very large value (1<<60)

## Precomputation Phase (lines 16-27)
For every possible subset mask (0 to 2^N - 1) and every facility j:
- Initialize Z[mask][j][0] to |X[j]| (distance to origin on x-axis)
- Initialize Z[mask][j][1] to |Y[j]| (distance to origin on y-axis)
- For each facility k in the mask, update:
  - Z[mask][j][0] = min(current, |X[j] - X[k]|)
  - Z[mask][j][1] = min(current, |Y[j] - Y[k]|)

This precomputes, for any subset of facilities assigned to an axis, the minimum distance from each facility to either the origin or any facility in that subset.

## Main Enumeration Loop (lines 28-46)
Iterates through all possible assignments of facilities to axes using a counter-like mechanism on array a[]:

1. **Build masks**: For each facility i:
   - If a[i] == 1, add bit i to horizontal mask h
   - If a[i] == 2, add bit i to vertical mask v

2. **Count assigned facilities**: t = popcount(h | v) — number of facilities assigned to either axis

3. **Compute cost**: For each facility i:
   - cost contribution = P[i] * min(Z[h][i][0], Z[v][i][1])
   - This takes the minimum of: distance to horizontal axis (given horizontal set h) and distance to vertical axis (given vertical set v)
   - Sum all contributions

4. **Update answer**: ans[t] = min(ans[t], current_sum)

5. **Increment counter**: 
   - Find first position i where a[i] != 2
   - Reset all preceding positions to 0
   - Increment a[i] by 1
   - This generates all ternary sequences (0, 1, 2) of length N

6. **Termination**: Loop ends when a[N] becomes non-zero (all positions have been cycled through)

## Helper Function
- popcount(n): recursively counts set bits in integer n (returns 0 for n=0, otherwise adds least significant bit to popcount of n>>1)

## Final Output
Prints ans[0] through ans[N], each on its own line, representing the minimum total cost for exactly 0, 1, 2, ..., N facilities assigned to the horizontal axis.

## Key Logic
- The program explores all 3^N possible assignments (each facility: unassigned, horizontal, or vertical)
- For each assignment, it computes the total cost where each facility pays its weight times the minimum distance to either axis system
- The precomputed Z table makes distance calculations O(1) per facility per assignment
- The answer tracks the best cost for each possible count of horizontal assignments
