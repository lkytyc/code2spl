This program reads a number of test cases, each containing a damage threshold and a string of 'S' (shoot) and 'C' (charge) commands. It calculates the minimum number of adjacent swaps needed to reduce the total damage (where each 'S' deals damage equal to the current charge level, and each 'C' doubles the charge) to be at or below the threshold. If it's impossible, it outputs "IMPOSSIBLE"; otherwise, it outputs the minimum swap count for each case.
