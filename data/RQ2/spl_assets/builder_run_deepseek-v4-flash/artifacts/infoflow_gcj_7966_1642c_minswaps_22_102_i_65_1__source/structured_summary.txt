# Code Description

## Overview
This program reads a series of test cases, each containing a damage threshold and a string of characters ('S' and 'C'), and determines the minimum number of adjacent swaps needed to reduce the total damage to at most the threshold. If impossible, it reports "IMPOSSIBLE".

## Input
- First line: integer `n` (number of test cases)
- For each test case:
  - Integer `d` (damage threshold)
  - String `p` (up to 30 characters, consisting of 'S' and 'C')

## Output
- For each test case: `Case #X: result` where X is the case number (1-based) and result is either the minimum number of swaps or "IMPOSSIBLE"

## Main Function Control Flow
1. Reads number of test cases `n`
2. Loops `n` times (for loop with index `i`)
3. For each iteration:
   - Reads damage threshold `d`
   - Reads string `p`
   - Calls `minswaps(p, d, strlen(p))`
   - Prints result: "IMPOSSIBLE" if return value is -1, otherwise prints the swap count

## minswaps Function

### Base Case (len == 2)
Handles two-character strings with specific logic:
- "SC": returns 0 (no swaps needed)
- "SS": returns -1 if `d < 2`, otherwise 0
- "CS": returns 1 if `d < 2`, otherwise 0
- Any other combination: returns 0

### General Case (len > 2)

**Initialization:**
- Sets initial strength = 1, damage = 0
- Allocates integer array `a` of size `len` to track strength values

**First Loop (computing damage and strength array):**
- Iterates through each character in string `p`
- For 'S': adds current strength to damage, stores strength in array `a`
- For 'C': doubles the strength, stores new strength in array `a`

**Early Exit:**
- If computed damage is already ≤ threshold `d`, returns 0

**Main Swap Loop:**
- Uses a while loop with flag variable
- Starts from the end of the string (index `len-1`)
- Inner while loop continues while damage exceeds threshold and index > 0:
  - Finds the rightmost 'S' character
  - If character before it is also 'S', moves left
  - Otherwise (character before is 'C'):
    - Swaps them (S moves left, C moves right)
    - Updates damage: subtracts old strength value at position `i`, then adds new strength value at position `i-1`
    - Updates strength array values based on position (special handling for position 0)
    - Increments swap counter
  - Breaks if at position 1 and previous character is 'S'

**Termination:**
- Outer while loop continues until no more beneficial swaps can be made (flag remains 1)
- Frees allocated array
- Returns swap count if damage ≤ threshold, otherwise returns -1

## Data Dependencies
- The strength array `a` tracks cumulative strength values that depend on the sequence of 'C' characters
- Damage calculation depends on both the strength values and positions of 'S' characters
- Swap operations modify both the string and the strength array, affecting subsequent damage calculations
- The algorithm processes from right to left, prioritizing swaps that reduce damage most effectively
