## Overview
This program reads a number of test cases and for each test case reads an integer representing the number of opponent moves, then determines a single counter-move based on the first character of each opponent move string.

## Input
- First integer `t`: number of test cases
- For each test case:
  - Integer `n`: number of opponent moves to read
  - If `n == 1`: one line of input (the opponent's move)
  - If `n > 1`: `n` lines of input (opponent moves)

## Output
For each test case, prints: `Case #X: Y` where X is the test case number (1-based) and Y is either a counter-move string or "IMPOSSIBLE".

## Main Method Control Flow
1. Creates a Scanner reading from standard input
2. Reads integer `t` for number of test cases
3. Loops from `i = 1` to `t` inclusive:
   - Reads integer `n`
   - Calls `play(i, n, in)` method

## Play Method Logic

### Variables
- `result`: string accumulator for output
- `R`, `P`, `S`: boolean flags initially all `true`
- `j`: loop counter starting at 1

### Branch 1: When n == 1
1. Reads one line of input as `input`
2. Appends `input` to `result` three times consecutively
3. Checks first character of `input`:
   - If 'P': appends "S" to result
   - If 'R': appends "P" to result
   - If 'S': appends "R" to result
4. Result is the input repeated 3 times plus one counter-character

### Branch 2: When n > 1
1. Loops while `j <= n`:
   - If at least one of R, P, or S is still `true`:
     - Reads one line as `input`
     - Checks first character:
       - If 'P': sets both R and P to `false`
       - If 'R': sets both R and S to `false`
       - If 'S': sets both S and R to `false`
   - Increments `j`
2. After loop, determines result:
   - If R is `true`: result = "P"
   - Else if P is `true`: result = "S"
   - Else if S is `true`: result = "R"
   - Else (all false): result = "IMPOSSIBLE"

## Data Dependencies
- The boolean flags R, P, S are modified based on the first character of each input line
- The flags are only updated when at least one flag is still `true`
- The final result depends on which flags remain `true` after processing all inputs
- For n == 1, the result depends entirely on the first character of the single input line

## Key Behavioral Notes
- For n > 1, only the first character of each input line matters
- The loop for n > 1 reads all n lines but only processes them while at least one flag is true
- The counter-move logic for n > 1 selects based on which single flag remains true
- For n == 1, the output is always the input repeated 3 times plus one additional character
- The program does not validate that input lines are non-empty before accessing character at index 0
