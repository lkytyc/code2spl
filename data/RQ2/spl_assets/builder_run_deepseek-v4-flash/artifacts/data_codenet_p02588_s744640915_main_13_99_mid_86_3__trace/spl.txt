[DEFINE_WORKER: "Reads integer n and n decimal strings, converts each string to a 10^9-scaled integer, normalizes values divisible by 100000, builds sorted divisors of 100000000, and counts qualifying previous values using gcd and divisor-indexed frequencies before printing the total." main]
    [INPUTS]
    [END_INPUTS]

    [OUTPUTS]
    [END_OUTPUTS]

    [MAIN_FLOW]
        [SEQUENTIAL_BLOCK]
            [COMMAND Read the long long integer n from standard input using scanf with the format string "%lld". RESULT n]
            [COMMAND Declare long long variables i, j, and k, a character buffer s of size 100, and a long long array a of size 200005. RESULT a]
            [COMMAND For each index i starting at 0 while i is less than n, read a string token into s, set a[i] to 0, and set k to 0. RESULT a]
            [COMMAND In the same outer i loop, for each character index j starting at 0 while s[j] is not the null character, if s[j] is not '.', update a[i] as 10 * a[i] + (long long int)(s[j] - '0') and increment k when k is greater than 0; otherwise set k to 1 at the decimal point. RESULT a]
            [COMMAND Still in the same outer i loop, after the character scan, if k equals 0, set k to 1. RESULT k]
            [COMMAND Still in the same outer i loop, while k is less than 10, multiply a[i] by 10 and increment k; if k is already at least 10, leave a[i] unchanged by this scaling loop. RESULT a]
            [COMMAND Declare q as long long int and set q to 100000. RESULT q]
            [COMMAND For each index i starting at 0 while i is less than n, using q equal to 100000, if a[i] modulo q is greater than 0, set a[i] to -1; otherwise set a[i] to a[i] divided by q. RESULT a]
            [COMMAND Set q to 100000000, declare a long long array b of size 10004, and set j to 0. RESULT b]
            [COMMAND For each divisor candidate i starting at 1 while i*i is less than or equal to q, if q modulo i is zero, assign b[j] to i and increment j. RESULT b]
            [COMMAND After that ascending divisor loop, which stops when i*i would exceed q, decrement i once; then if i*i equals q, decrement i once more. RESULT i]
            [COMMAND Starting from the adjusted i value, for each i descending while i is greater than 0, if q modulo i is zero, assign b[j] to q divided by i and increment j. RESULT b]
            [COMMAND Declare long long variables min, mid, and max; declare a long long array c of size 10004; then for each index i starting at 0 while i is less than j, set c[i] to 0. RESULT c]
            [COMMAND Declare ans as long long int and set ans to 0. RESULT ans]
            [COMMAND Declare l as long long int. RESULT l]
            [COMMAND For each index i starting at 0 while i is less than n, if a[i] is less than 0, skip the rest of the current iteration and continue with the next i. RESULT a]
            [COMMAND In the same outer iteration over i, compute l as q divided by gcd(q, a[i]), where gcd is the greatest common divisor function. RESULT l]
            [COMMAND In the same outer iteration over i, after computing l, set min to -1 and max to j to prepare the binary search. RESULT max]
            [COMMAND In the same outer iteration over i, while max minus min is greater than 1, set mid to (max + min) / 2 using C integer division; if b[mid] is less than l, set min to mid; otherwise set max to mid. RESULT max]
            [COMMAND After the binary search in the same outer iteration over i, add c[max] to ans. RESULT ans]
            [COMMAND Still in the same outer iteration over i, after updating ans, for each k starting at 0 while k is less than j, if a[i] modulo b[k] is zero, increment c[k]. RESULT c]
            [COMMAND After all iterations, print ans to standard output using printf with the format string "%lld\n". RESULT ans]
            [COMMAND Return 0 from main. RESULT return_value]
        [END_SEQUENTIAL_BLOCK]
    [END_MAIN_FLOW]

[END_WORKER]
