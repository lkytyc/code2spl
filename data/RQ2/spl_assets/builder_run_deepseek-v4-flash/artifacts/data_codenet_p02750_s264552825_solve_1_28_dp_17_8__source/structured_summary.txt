## Function: solve(n, t, ab_list)

### Inputs
- `n`: integer representing number of items
- `t`: integer representing a time limit
- `ab_list`: list of pairs, each pair containing two integers (a, b)

### Processing Steps

**Step 1: Partition items**
- Creates `a0b_list` containing only the second element (b) from pairs where the first element (a) equals 0
- Creates `apb_list` containing only pairs where the first element (a) is greater than 0

**Step 2: Sort lists**
- Sorts `a0b_list` in ascending order
- Sorts `apb_list` in descending order based on the ratio `a / (b + 1)`

**Step 3: Dynamic programming table**
- Sets `m` to the length of `apb_list`
- Creates a 2D table `dp` with dimensions (m+1) × 30, initialized with value `t+1`
- Sets the first column (index 0) of every row to 0

**Step 4: Fill DP table**
- For each item `i` in `apb_list` (0 to m-1):
  - For each count `k` from 1 to 29:
    - Computes `ti` as `dp[i][k-1] + 1`
    - Extracts `a` and `b` from the current item
    - Updates `dp[i+1][k]` as the minimum of:
      - Current value `dp[i][k]`
      - `ti + a * ti + b`

**Step 5: Cumulative sums for zero-a items**
- Creates `a0b_list_cum_sum` starting with 0
- For each `b` in `a0b_list`, adds `b + 1` to the running sum and appends to the cumulative list

**Step 6: Find maximum result**
- Initializes `res` to 0
- For each index `k` in the cumulative sum list (0 to length of `a0b_list_cum_sum` - 1):
  - For each `p` from 0 to 29:
    - If `dp[m][p] + a0b_list_cum_sum[k]` is less than or equal to `t`:
      - Updates `res` to the maximum of current `res` and `k + p`

### Output
- Returns `res`, an integer representing the maximum count achievable

## Function: main()

### Inputs
- Reads two integers from standard input: `n` and `t`
- Reads `n` lines, each containing two integers, forming `ab_list`

### Processing
- Calls `solve(n, t, ab_list)`

### Output
- Prints the result from `solve`

## Function: test()

### Processing
- Runs three assertion tests:
  1. `solve(3, 7, [[2, 0], [3, 2], [0, 3]])` should return 2
  2. `solve(1, 3, [[0, 3]])` should return 0
  3. `solve(5, 21600, [[2, 14], [3, 22], [1, 3], [1, 10], [1, 9]])` should return 5

## Program Entry Point

- When executed as main module, first runs `test()` then calls `main()`
