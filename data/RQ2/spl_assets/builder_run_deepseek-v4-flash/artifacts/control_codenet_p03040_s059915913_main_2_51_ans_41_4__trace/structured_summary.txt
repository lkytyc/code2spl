## Overview
This program processes a series of queries that maintain a sorted array of numbers and track a cumulative sum. It supports two types of operations: inserting a value with an associated weight, and querying the median along with a computed cost.

## Inputs
- First input: an integer `q` representing the number of queries to process.
- Each query begins with an integer `x`:
  - If `x == 1`, two additional integers follow: `y` (the value to insert) and `z` (a weight to add to a running total).
  - If `x` is any other value, no additional input is read for that query.

## Outputs
- For each query where `x != 1`, the program outputs two space-separated values: the current median value and a computed answer (both as long long integers).

## Data Structures
- An array `a` of size 200005 stores the inserted values in sorted (non-decreasing) order.
- A variable `b` accumulates the sum of all `z` values from insertion queries.
- Variables `n` tracks the current number of elements in the array.

## Control Flow

### Main Loop
The program iterates `q` times, processing one query per iteration.

### Insertion Operation (x == 1)
1. Reads values `y` and `z`.
2. If the array is empty (`n == 0`), places `y` at index 0.
3. Otherwise, performs an insertion sort:
   - Starts from the last element and moves backward.
   - Shifts elements greater than `y` one position to the right.
   - When an element less than or equal to `y` is found, inserts `y` after it and breaks.
   - If all existing elements are greater than `y`, places `y` at the beginning (index 0).
4. Increments `n` by 1.
5. Adds `z` to the running total `b`.

### Query Operation (x != 1)
1. Computes the median index as `(n - 1) / 2` and retrieves the median value `m` from the array.
2. Initializes `ans` with the current value of `b`.
3. Iterates through all elements in the array, computing the absolute difference between `m` and each element, and adds this difference to `ans`.
4. Prints the median value `m` and the computed `ans`.

## Key Data Dependencies
- The array `a` maintains sorted order across all insertions.
- The value `n` determines both the median index and the loop bounds for the query operation.
- The variable `b` accumulates weights from all insertion queries and is used as the base for the query answer.
- The median value `m` depends on the current sorted array and the count `n`.

## Edge Cases
- When `n == 0` and a query operation occurs, the code would access `a[-1]` (undefined behavior), though this scenario is not explicitly guarded.
- When inserting into a non-empty array, the insertion logic handles both the case where the new value belongs at the end and where it belongs at the beginning.
- The median calculation uses integer division, so for even-sized arrays it selects the lower of the two middle elements.
