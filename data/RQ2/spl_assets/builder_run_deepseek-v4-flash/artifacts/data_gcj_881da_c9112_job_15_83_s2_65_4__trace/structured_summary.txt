# Structured Description

## Overview
This program reads a series of test cases, each containing an integer `n` and a string of characters (consisting of 'E' and 'S'). It processes the string to generate and print a new string of 'E' and 'S' characters based on the pattern of runs in the input.

## Global Variables
- `moves[50000]`: An integer array used to store run lengths of consecutive identical characters.
- `in_str[100000]`: A character array used to store the input string for each test case.

## Function: `main()`
### Input
- Reads an integer `t` from standard input, representing the number of test cases.

### Processing
- Loops from `i = 1` to `t` (inclusive).
- For each iteration:
  - Prints `"Case #i: "` (where `i` is the current test case number).
  - Calls the `job()` function.
  - Prints a newline character.

### Output
- Prints formatted case headers and results for each test case.

## Function: `job()`
### Local Variables
- `ggg`: Character initialized to the XOR of 'E' and 'S'.
- `n`: Integer for the input size.
- `goodp`: Integer initialized to -1.
- `movesp`: Integer initialized to 0 (tracks the current position in the `moves` array).
- `cur`: Character initialized to 'E'.

### Input
- Reads an integer `n` and a string `in_str` from standard input.

### Processing Steps

#### Step 1: Adjust `n`
- Multiplies `n` by 2 and subtracts 2 (so `n = 2 * original_n - 2`).

#### Step 2: Build Run-Length Array
- Sets `moves[0] = 0`.
- Loops from `i = 0` to `n-1`:
  - If the current character `in_str[i]` differs from `cur`:
    - Toggles `cur` by XORing with `ggg`.
    - Sets `moves[movesp + 1] = 1`.
    - Increments `movesp`.
  - Otherwise (characters match):
    - Increments `moves[movesp]`.
    - Checks a condition based on `moves[0]` and index parity:
      - If `moves[0]` is non-zero and `i` is even, OR if `moves[0]` is zero and `i` is odd, then sets `goodp = movesp`.

#### Step 3: Determine Parity
- Sets `parity = movesp`.
- If `moves[0]` is not zero, increments `parity`.

#### Step 4: Output Generation (Even Parity Case)
- If `parity` is even:
  - Computes `En` as the sum of `moves[i]` for even indices `i` from 0 to `movesp`.
  - If `moves[0] == 0`:
    - Prints 'E' `En` times.
    - Prints 'S' `(n - En)` times.
  - Otherwise (if `moves[0] != 0`):
    - Prints 'S' `(n - En)` times.
    - Prints 'E' `En` times.
