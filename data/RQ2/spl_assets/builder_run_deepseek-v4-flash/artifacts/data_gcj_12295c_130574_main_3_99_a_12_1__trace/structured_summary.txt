## Inputs
The program reads from standard input using a Scanner. It first reads an integer `t` representing the number of test cases. For each test case, it reads:
- An integer `p` (number of people)
- An integer `q` (grid size)
- For each of the `p` people: an integer coordinate, another integer coordinate (transformed), and a direction string (`"N"`, `"S"`, `"E"`, or `"W"`)

## Outputs
For each test case, the program prints a line in the format: `Case #i: x y` where `i` is the 1-based test case number, and `x` and `y` are the coordinates of the chosen point.

## Data Structures
- `Person` class stores four integers: `x`, `y`, `xDir`, `yDir` (direction components)
- `ArrayList<Person>` collections store people and candidate points
- A 2D integer array `b` of size `q × q` accumulates counts

## Control Flow

### Main Loop
- Outer loop iterates `t` times (test cases)
- Inner loop reads `p` people and their data

### Direction Mapping
For each person, the direction string is converted to directional components:
- `"N"` → `yDir = -1`
- `"S"` → `yDir = 1`
- `"E"` → `xDir = 1`
- `"W"` (default/else) → `xDir = -1`

### Coordinate Transformation
The second input coordinate is transformed: `a = q - input_value - 1`. This effectively flips the y-axis.

### Grid Population
For each person, the program increments cells in the grid `b`:
- If `xDir == 0` (person moves vertically): increments all cells in rows from `x + yDir` to the grid boundary (inclusive of direction), across all columns
- Otherwise (person moves horizontally): increments all cells in columns from `y + xDir` to the grid boundary, across all rows

### Finding Maximum
- Scans the entire `q × q` grid to find the maximum count value

### Collecting Max Points
- Iterates through the grid column by column, then row by row
- Records all positions where the count equals the maximum
- Stores transformed row coordinate (`q - r - 1`) and column coordinate

### Tie-Breaking (First Criterion)
- Among all max-count points, finds those with the minimum sum of `row + col`
- Maintains a list `f` of points with this minimum sum

### Tie-Breaking (Second Criterion)
- Among points in `f`, finds those with the minimum `x` value
- Maintains a list `g` of points with this minimum x

### Final Selection
- From list `g`, selects the point with the smallest `y` value
- Prints the selected point's `y` and `x` coordinates

## Key Dependencies
- The grid `b` depends on all person data
- The maximum count depends on grid `b`
- Candidate points depend on the maximum count
- Final selection depends on successive tie-breaking criteria

## Edge Cases
- If multiple points share the same maximum count, tie-breaking proceeds through three criteria in order: minimum sum, then minimum x, then minimum y
- The direction mapping uses an else clause for `"W"`, so any unrecognized direction defaults to west movement
