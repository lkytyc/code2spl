## Function: gcd

**Inputs:** Two `long long int` values, `a` and `b`.

**Output:** Returns the greatest common divisor of `a` and `b` as a `long long int`.

**Behavior:** Computes the remainder of `a` divided by `b`. While this remainder is greater than zero, it reassigns `a` to the old `b`, `b` to the old remainder, and recomputes the remainder. When the loop exits, it returns the current value of `b`, which is the GCD.

## Main Function

### Inputs
- Reads a single `long long int` value `n` from standard input.
- Then reads `n` strings (each stored in a character array `s` of size 100) from standard input.

### Output
- Prints a single `long long int` value `ans` followed by a newline.

### Data Structures
- `a[200005]`: Array of `long long int` to store processed numeric values from input strings.
- `b[10004]`: Array of `long long int` to store divisors of 100,000,000.
- `c[10004]`: Array of `long long int` used as counters for divisors.

### Processing of Input Strings
For each of the `n` input strings:
1. Initialize `a[i]` to 0 and `k` to 0.
2. Iterate through each character of the string until the null terminator.
   - If the character is not a decimal point, multiply current `a[i]` by 10 and add the numeric digit value. If `k` is already greater than 0, increment `k`.
   - If the character is a decimal point, set `k` to 1.
3. After processing all characters, if `k` is still 0, set `k` to 1.
4. Multiply `a[i]` by 10 repeatedly until `k` reaches 10 (i.e., pad the number to have exactly 10 decimal places worth of digits).

### Normalization Step
- Set `q` to 100,000.
- For each `a[i]`:
  - If `a[i]` is not divisible by `q` (remainder > 0), set `a[i]` to -1 (marking it as invalid).
  - Otherwise, divide `a[i]` by `q`.

### Divisor Generation
- Set `q` to 100,000,000.
- Generate all divisors of `q`:
  - First loop: For `i` from 1 up to the square root of `q`, if `i` divides `q` evenly, store `i` in array `b` and increment index `j`.
  - After the loop, decrement `i` by 1. If `i * i` equals `q`, decrement `i` again.
  - Second loop: For `i` down to 1, if `i` divides `q` evenly, store `q / i` in array `b` and increment `j`. This adds the larger divisors in descending order.

### Counting and Answer Computation
- Initialize all elements of array `c` to 0.
- Initialize `ans` to 0.
- For each valid `a[i]` (not equal to -1):
  - Compute `l` as `q` divided by the GCD of `q` and `a[i]`.
  - Perform a binary search on array `b` (which is sorted ascending) to find the smallest index `max` such that `b[max] >= l`.
  - Add `c[max]` to `ans`.
  - Then, for every divisor `b[k]` in the divisor list, if `a[i]` is divisible by `b[k]`, increment `c[k]`.

### Final Output
- Print the accumulated `ans` value.

### Control Flow Summary
- Loops: Input reading loop (n iterations), character processing loop (per string), normalization loop (n iterations), divisor generation loops (two loops), counting loop (n iterations), inner divisor-checking loop (j iterations per valid input).
- Branches: Check for decimal point, check for digit vs. decimal, check for divisibility, check for invalid values, binary search comparisons.
- Function calls: `gcd` is called once per valid input value during the counting phase.
