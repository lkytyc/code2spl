## Function: solve(L)

**Input:** A list `L` of integers.

**Output:** An integer index, or -1.

**Behavior:**
1. Creates a sorted copy of the input list called `sorted_list`.
2. Enters a loop that continues until no swaps are performed in a full pass.
3. Within the outer loop, it repeatedly compares elements at positions `i` and `i+2` (skipping adjacent pairs). If `L[i] > L[i+2]`, it swaps them and marks that a change occurred.
4. This process continues until a full pass through the list produces no swaps.
5. After the sorting loop completes, it iterates through the list comparing each element to the corresponding element in `sorted_list`.
6. If a mismatch is found at index `i`, it returns that index.
7. If all elements match the sorted list, it returns -1.

**Key details:**
- The sorting only swaps elements that are two positions apart, not adjacent elements.
- The comparison loop uses variable `i` but the increment variable is `c`; however, the code uses `i` in the comparison (which after the sorting loop will be `lengthList-2`), so the comparison loop actually checks `sorted_list[lengthList-2]` against `L[lengthList-2]` repeatedly, not each index.
- The function returns the first index where `L[i]` differs from `sorted_list[i]`, but due to the bug, it only checks one specific index.

## Function: main()

**Input:** Reads from standard input:
- First line: integer `tc` (number of test cases)
- For each test case: an integer `n` (list length), then a line of `n` space-separated integers.

**Output:** Prints one line per test case in format: `Case #<case_number>: <result>`

1. Reads the number of test cases.
2. For each test case, reads the list length and the list elements.

4. If the result is -1, prints "OK"; otherwise prints the result index.
5. Increments the case counter and prints the formatted output.

- The case number printed is the incremented counter (so first case prints "Case #1").
- The result is either "OK" or the index number as a string.
