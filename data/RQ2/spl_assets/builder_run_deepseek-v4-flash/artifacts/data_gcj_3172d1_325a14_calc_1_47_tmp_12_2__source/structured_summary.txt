## Function: calc(n, d, a, b, ct)

**Inputs:**
- `n` – integer (overwritten inside function)
- `d` – integer, target value
- `a` – list of integers (keys from a dictionary)
- `b` – list of integers (values corresponding to keys in `a`)
- `ct` – dictionary mapping integers to their counts

**Outputs:**
- Returns a tuple `(ans, ret)` where `ans` is an integer (minimum computed value) and `ret` is `a[0]` (first element of list `a`)

**Behavior:**
1. Overwrites `n` with the length of list `a`
2. Initializes `ans = d - 1` and `ret = a[0]`
3. Iterates over each index `i` from 0 to n-1 (outer loop)
   - Sets `x = a[i]`, `y = b[i]`
   - Initializes `cur_d = 0`, `p = 0`, `cut = 0`
   - Inner loop over `j` from 0 to d+1:
     - Adds `x` to `p`
     - Gets `tmp = ct.get(p, 0)` (count of value `p` in dictionary, default 0)
     - Computes `remain_d = d - cur_d`
     - Computes `per_d = p / x` (integer division)
     - Computes `per_cut = per_d - 1`
     - Inner-inner loop over `k` from 0 to `tmp * per_d - 1`:
       - Increments `cur_d` by 1
       - If `(k+1) % per_d != 0`, increments `cut` by 1
       - Computes `xx = d / cur_d` (integer division)
       - If `d % cur_d == 0`, decrements `xx` by 1
       - Updates `ans = min(ans, cut + xx * cur_d)`
       - If `cur_d > d`, breaks out of this loop
     - If `cur_d > d`, breaks out of the `j` loop
   - After the `j` loop, if `cur_d < d`:
     - Iterates `j` from n-1 down to i+1 (reverse loop):
       - If `a[j] > p` OR `a[j] % x != 0`:
         - Computes `tmp = (a[j] / x) * y` (integer division)
         - Inner loop over `k` from 0 to tmp-1:
           - Increments `cur_d` and `cut` by 1 each
           - Computes `xx = d / cur_d`
           - If `d % cur_d == 0`, decrements `xx` by 1
           - Updates `ans = min(ans, cut + xx * cur_d)`
           - If `cur_d > d`, breaks
       - If `cur_d > d`, breaks out of reverse loop
   - After reverse loop, computes `xx = d / cur_d`
   - If `d % cur_d == 0`, decrements `xx` by 1
   - Updates `ans = min(ans, cut + xx * cur_d)`
4. Returns `(ans, ret)`

**Control flow notes:**
- Multiple nested loops with break conditions based on `cur_d` exceeding `d`
- Integer division used throughout (Python 2 semantics)
- The `ret` value is never modified after initialization

## Function: work(case)

**Inputs:**
- `case` – integer, case number

**Behavior:**
1. Reads a line from standard input, splits it, converts to integers `n` and `d`
2. Reads another line, splits into integers, stores in list `tmp`
3. Creates dictionary `ct` with keys from `tmp`, all initialized to 0
4. Counts occurrences of each value in `tmp` into `ct`
5. Creates sorted list of `(key, value)` pairs from `ct`, unpacks into lists `a` and `b`
6. Calls `calc(n, d, a, b, ct)` to get `ans` and `ret`
7. Prints `Case #<case>: <ans>`

---

## Main block

**Behavior:**
1. Reads integer `T` from standard input
2. Loops `i` from 0 to T-1, calling `work(i+1)` for each iteration

**Data dependencies:**
- `work` depends on standard input for all data
- `calc` depends on `a`, `b`, `ct` which come from the input dictionary
