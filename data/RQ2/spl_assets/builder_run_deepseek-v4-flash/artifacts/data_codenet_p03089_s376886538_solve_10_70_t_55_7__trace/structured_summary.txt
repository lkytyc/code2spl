## Class and Fields

The `Main` class contains an input stream, an output writer, an input string constant, a static modulus value, and a large infinity constant. It also has buffer fields for byte-level input reading.

## Main Entry Point

The `main` method creates a new `Main` instance and calls its `run` method. The `run` method sets up the input stream (either from standard input or from the `INPUT` string if it is non-empty), initializes the output writer, records the start time, calls `solve`, flushes output, and optionally prints timing information if using the test input string.

## Input Parsing Methods

The class provides several input-reading utilities:
- `readByte` reads a single byte from the input buffer, handling buffer refills and end-of-stream conditions
- `isSpaceChar` determines if a character is whitespace (outside ASCII 33-126)
- `skip` advances past whitespace characters
- `ns` reads a string token
- `ni` reads an integer, handling optional negative signs
- `nl` reads a long integer
- `nd` reads a double
- `nc` reads a single character
- `na` reads an array of integers
- `ns(int n)` reads a fixed-length character array
- `nm` reads a 2D character array

## Core Algorithm (solve method)

### Input
- Reads an integer `n` representing the size of an array
- Reads `n` integers into array `a`

### Initialization
- Creates a boolean array `seen` of size `n`, all initially false
- Creates an empty ArrayList `ans` for storing results
- Sets target value `t` to 1
- Sets left boundary `l` to 0 and right boundary `r` to n-1

### Main Loop
The algorithm enters an infinite loop with the following structure:

**Inner scanning loop (labeled `outer`):**
- Iterates from index n-1 down to 0
- Skips indices already marked as seen
- If the current index is less than the left boundary `l`, outputs -1 and returns
- If the value at the current index equals the target `t`:
  - Marks this index as seen
  - Adds the value to the answer list
  - Checks if all indices after this one are already seen
  - If all subsequent indices are seen, breaks out of the inner loop
  - Otherwise, increments `t` and restarts the scan from the end (by setting `i = n` and continuing)

**Post-scan validation:**
- If the last element (index n-1) is not seen, outputs -1 and returns

**Boundary adjustment:**
- Scans from the end to find the first unseen index
- If found, updates `t` to the value at the next index, sets `r` to this position, and finds the leftmost contiguous unseen block by scanning backward until hitting a seen element
- If no unseen elements exist (flag remains true), breaks the main loop

### Output
- Prints each element of the answer list on its own line

## Control Flow Summary

The algorithm attempts to build a sequence by repeatedly finding the next required value (starting from 1) scanning from right to left, marking elements as used, and adjusting boundaries. It fails with -1 output when:
- The scan position falls below the left boundary
- The rightmost element remains unseen after a scan pass

The algorithm terminates successfully when all elements have been marked as seen, outputting the collected values in order.
