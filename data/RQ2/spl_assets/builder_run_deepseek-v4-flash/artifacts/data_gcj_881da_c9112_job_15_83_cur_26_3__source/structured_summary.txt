# Structured Description

## Overview
This program reads a series of test cases, each containing an integer `n` and a string of characters (either 'E' or 'S'). It processes the string to generate a new string of 'E' and 'S' characters, which is printed as output for each test case.

## Global Variables
- `moves[50000]`: An integer array used to store counts of consecutive identical characters.
- `in_str[100000]`: A character array used to store the input string.

## Function: `main()`
### Input
- Reads an integer `t` from standard input, representing the number of test cases.

### Processing
- Loops from `i = 1` to `t` (inclusive).
- For each iteration:
  - Prints `"Case #i: "` (where `i` is the current test case number).
  - Calls the `job()` function.
  - Prints a newline character.

### Output
- For each test case, prints a formatted case header followed by the result from `job()` and a newline.

## Function: `job()`
### Local Variables
- `ggg`: Character initialized to the XOR of 'E' and 'S'.
- `n`: Integer for the input size.
- `goodp`: Integer initialized to -1.
- `movesp`: Integer initialized to 0.
- `cur`: Character initialized to 'E'.

### Input
- Reads an integer `n` and a string `in_str` from standard input.

### Processing
1. **Size Adjustment**: Multiplies `n` by 2 and subtracts 2, storing the result back into `n`.
2. **Initialization**: Sets `moves[0]` to 0.
3. **Main Loop** (iterates `i` from 0 to `n-1`):
   - If the current character in `in_str` differs from `cur`:
     - Toggles `cur` by XORing it with `ggg`.
     - Sets `moves[movesp+1]` to 1.
     - Increments `movesp`.
   - Otherwise (characters match):
     - Increments `moves[movesp]`.
     - If a parity condition is met (based on `moves[0]` and `i` parity), updates `goodp` to `movesp`.
4. **Parity Calculation**:
   - Sets `parity` to `movesp`.
   - If `moves[0]` is non-zero, increments `parity`.
5. **Branch on Parity**:
   - **If `parity` is even**:
     - Computes `En` as the sum of `moves[i]` for even indices from 0 to `movesp`.
     - If `moves[0]` equals 0:
       - Prints 'E' `En` times, then 'S' `(n - En)` times.
     - Otherwise:
       - Prints 'S' `(n - En)` times, then 'E' `En` times.
   - **If `parity` is odd**:
     - Initializes `s1`, `s2`, `e1`, `e2` to 0.
     - Computes:
       - `e1` as sum of `moves[i]` for even indices from 0 to `goodp-1`.
       - `s1` as sum of `moves[i]` for odd indices from 1 to `goodp-1`.
       - `e2` as sum of `moves[i]` for even indices from `2*((goodp+1)/2)` to `movesp`.
       - `s2` as sum of `moves[i]` for odd indices from `2*(goodp/2)+1` to `movesp`.
     - If `moves[0]` equals 0:
       - Prints 'E' `(e1+1)` times, then 'S' `(s1+s2)` times, then 'E' `(e2-1)` times.
     - Otherwise:
       - Prints 'S' `(s1+1)` times, then 'E' `(e1+e2)` times, then 'S' `(s2-1)` times.

### Output
- Prints a sequence of 'E' and 'S' characters to standard output (no newline; newline is added by `main()`).

## Control Flow Summary
- The program uses a loop over test cases in `main()`.
- Within `job()`, there is a single loop over the input string characters.
- Conditional branches occur based on:
  - Character comparison in the main loop.
  - Parity of `movesp`
