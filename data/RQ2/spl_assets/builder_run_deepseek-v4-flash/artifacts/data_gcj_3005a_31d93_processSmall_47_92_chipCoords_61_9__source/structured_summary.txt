## Overview
This program reads a series of test cases from standard input, processes each one to determine if a certain grid configuration is possible, and outputs a verdict for each case.

## Input Format
- First line: an integer `t` representing the number of test cases
- For each test case:
  - A line containing two integers: `R` (rows) and `C` (columns), separated by a space
  - `R` subsequent lines, each containing `C` characters (the grid)

## Output Format
For each test case (numbered 1 through `t`), the program outputs:
- `Case #N: POSSIBLE` if the case passes the processing check
- `Case #N: IMPOSSIBLE` otherwise

## Main Control Flow
1. Read the number of test cases `t`
2. For each test case:
   - Read the header line and extract `R` and `C`
   - Read `R` grid lines and store them along with the header in a case list
3. Iterate through all stored cases, calling `processCase` for each
4. Print the verdict based on the boolean result

## Data Storage
- `caseList`: A list of lists, where each inner list contains:
  - Index 0: The header line (R and C values as a string)
  - Indices 1 through R: The grid rows as strings

## Process Case Function
- Parses the header line into an integer array of size 4
- Checks a precondition: if `R < 10`, `C < 10`, and the third and fourth values are both 1
- If the precondition passes, calls `processSmall`; otherwise returns `false`

## Process Small Function
### Input
- An integer array containing the parsed header values
- The case list containing grid data

### Grid Scanning
- Iterates through each cell of the grid
- Identifies positions containing the `@` character
- Stores these positions as coordinate pairs in three parallel structures:
  - `chipCoords`: Array of [row, column] pairs
  - `xCoords`: List of row indices
  - `yCoords`: List of column indices

### Quadrant Analysis
- For every possible split point (x, y) in the grid:
  - Counts chips in four quadrants relative to the split point:
    - `bottomLeft`: chips with row ≤ x and column ≤ y
    - `bottomRight`: chips with row ≤ x and column > y
    - `topleft`: chips with row > x and column < y
    - `topright`: chips with row > x and column ≥ y
  - If all four quadrant counts are equal, returns `true` immediately

### Return Value
- Returns `true` if any split point yields equal quadrant counts
- Returns `false` if no such split point exists

## Error Handling
- Catches `IOException` from input reading operations
- Prints stack trace on error

## Key Dependencies
- The `processCase` function depends on the header values being correctly parsed
- The `processSmall` function depends on the grid data being properly stored in the case list
- The main function depends on both processing functions to determine output
