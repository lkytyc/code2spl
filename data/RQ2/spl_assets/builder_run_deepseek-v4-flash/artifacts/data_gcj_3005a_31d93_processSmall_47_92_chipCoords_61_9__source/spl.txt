[DEFINE_WORKER: "Scans the grid rows from caseList using rchv as row and column dimensions to locate '@' cells, then checks whether any split point (x, y) places the same number of chips in all four surrounding quadrants." processSmall]
    [INPUTS]
        <REF> rchv </REF>: int[] "Array where rchv[0] is the number of grid rows and rchv[1] is the number of grid columns."
        <REF> caseList </REF>: List<String> "List of strings where the string at index i+1 represents grid row i; each character is either '@' or another grid character."
    [END_INPUTS]

    [OUTPUTS]
        <REF> result </REF>: boolean "Returns true if some split point (x, y) yields equal counts in all four quadrants, otherwise false."
    [END_OUTPUTS]

    [MAIN_FLOW]
        [SEQUENTIAL_BLOCK]
            [COMMAND Initialize three empty lists: chipCoords for int[] coordinate pairs, xCoords for x indices, and yCoords for y indices. RESULT chipCoords]
            [COMMAND For each row index i from 0 to rchv[0]-1 inclusive, read row as caseList.get(i+1) and split row into individual characters; then for each column j from 0 to rchv[1]-1 inclusive, if split[j] equals '@', create an int[2] coords with coords[0]=i and coords[1]=j, add i to xCoords, add j to yCoords, and add coords to chipCoords. RESULT chipCoords]
            [COMMAND For each split point x from 0 to rchv[0]-1 inclusive and y from 0 to rchv[1]-1 inclusive, initialize four counters topright=0, topleft=0, bottomLeft=0, bottomRight=0; then for each z from 0 to chipCoords.size()-1, classify chipCoords.get(z) using the following boundaries: if chipX <= x and chipY <= y increment bottomLeft; else if chipX <= x and chipY > y increment bottomRight; else if chipX > x and chipY < y increment topleft; else increment topright. RESULT quadrantCounts]
            [COMMAND After counting for the current split point, evaluate the short-circuit condition bottomRight == bottomLeft && bottomLeft == topleft && topleft == topright; if it is true, trigger the alternative flow that returns true immediately. RESULT equalCountsFound]
            [COMMAND If all split points are checked and none satisfies the equal-count condition, return false from processSmall. RESULT falseResult]
        [END_SEQUENTIAL_BLOCK]
    [END_MAIN_FLOW]

    [ALTERNATIVE_FLOW: At the current split point (x, y), the four quadrant counts are all equal: bottomRight == bottomLeft && bottomLeft == topleft && topleft == topright.]
        [SEQUENTIAL_BLOCK]
            [COMMAND Return true immediately from processSmall, skipping all remaining split points. RESULT trueResult]
        [END_SEQUENTIAL_BLOCK]
    [END_ALTERNATIVE_FLOW]

[END_WORKER]
