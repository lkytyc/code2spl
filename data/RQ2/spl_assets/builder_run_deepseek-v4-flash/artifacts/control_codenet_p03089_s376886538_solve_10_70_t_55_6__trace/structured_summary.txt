## Class and Fields

The `Main` class contains an input stream, an output writer, an input string constant, a static modulus value, and a large infinity constant. It also has buffer fields for byte-level input reading.

## Main Entry Point

The `main` method creates a new `Main` instance and calls its `run` method. The `run` method sets up the input stream (either from standard input or from the `INPUT` string if it is non-empty), initializes the output writer, records the start time, calls `solve`, flushes output, and optionally prints timing information if using the test input string.

## Input Parsing Methods

The class provides several input-reading utilities:
- `readByte` reads a single byte from the input buffer, handling buffer refills and end-of-stream conditions
- `isSpaceChar` determines if a character is whitespace (outside ASCII range 33-126)
- `skip` advances past whitespace characters
- `ns` reads a string token
- `ni` reads an integer, handling optional negative signs
- `nl` reads a long integer
- `nd` reads a double
- `nc` reads a single character
- `na` reads an array of integers
- `ns(int n)` reads a fixed-length character array
- `nm` reads a 2D character array

## Core Algorithm in `solve`

### Input Reading
The method reads an integer `n` representing the size of an array, then reads `n` integers into array `a`.

### State Initialization
- A boolean array `seen` of size `n` is created, all initially false
- An `ArrayList` named `ans` is created to store output values
- Three integer variables are initialized: `t = 1`, `l = 0`, `r = n-1`

### Main Processing Loop
The algorithm enters an infinite `while(true)` loop with the following structure:

**Inner scanning loop (labeled `outer`):**
- Iterates from index `n-1` down to `0`
- Skips indices already marked as seen
- If the current index `i` is less than `l`, prints `-1` and returns
- If `a[i]` equals the current target value `t`:
  - Marks this index as seen
  - Adds the value to the answer list
  - Checks if all indices after `i` are already seen (by scanning from `i+1` to `n-1`)
  - If all subsequent indices are seen, breaks out of the inner loop
  - Otherwise, increments `t` and restarts the scan from the end (sets `i = n`)

**Post-scan validation:**
- If the last element (`n-1`) is not seen, prints `-1` and returns

**Finding next segment:**
- Scans from the end to find the first unseen index
- If found, updates `t` to the value at the next index (`a[i+1]`), sets `r` to this index, and scans backward from this index to find the leftmost contiguous unseen block (updating `l`)
- If all elements are seen, breaks out of the main loop

### Output
After the main loop completes, the method prints each value in the `ans` list on its own line.

## Control Flow Summary

The algorithm processes the array by repeatedly finding the rightmost occurrence of the current target value, marking it and everything to its right as processed, then moving to the next target. It outputs `-1` if the sequence cannot be completed according to the constraints. The output is either `-1` or a sequence of integers from the array.
