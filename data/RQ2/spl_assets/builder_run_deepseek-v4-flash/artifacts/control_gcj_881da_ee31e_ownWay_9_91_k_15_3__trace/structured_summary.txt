# Code Description

## Input
- The program reads an integer `T` from standard input, representing the number of test cases.
- For each test case, it reads:
  - An integer `N` (the grid size)
  - A string `s` containing `2*N - 2` characters, each being either 'S' or 'E'

## Output
- For each test case, the program prints `Case #<number>:` followed by a space, then a string of `2*N - 2` characters (either 'S' or 'E') on the same line.

## Main Function
- Reads `T` and loops through each test case.
- For each test case, reads `N` and the string `s`.
- Prints the case header.
- Calls `ownWay(s, N)`.

## ownWay Function

### Maze Construction
- Creates a 3D list `maze` of size `N x N x 2`.
- Each cell `maze[i][j]` contains `[i, j]` — the row and column coordinates.

### Original Path Tracking
- Converts input string `s` to a list `l`.
- Creates a 3D list `c_l` of size `1 x (2*N-1) x 2` initialized to zeros.
- Starts at position (0,0) and records the coordinates at each step:
  - For 'S' (South), increments the y-coordinate.
  - For 'E' (East), increments the x-coordinate.
- Records the position after each move in `c_l`.

### Random Path Generation Loop
- Sets `check = True`.
- Shuffles the list `l` randomly.
- Creates a new tracking structure `c_l1` (same dimensions as `c_l`).
- Tracks the path of the shuffled list from (0,0), recording coordinates after each move.

### Collision Checking
- Enters a `while check` loop:
  - Sets `check = False`.
  - Compares consecutive positions between the original path (`c_l`) and the shuffled path (`c_l1`).
  - If any consecutive pair of positions (both start and end of a move) match between the two paths, sets `check = True`.
  - If a collision is found, reshuffles `l` and rebuilds `c_l1` from scratch, then repeats the check.

### Output
- Prints the final shuffled list `l` as a joined string.

## Key Behaviors
- The program attempts to find a random permutation of the original 'S'/'E' sequence that does not share any edge with the original path (no two consecutive positions match).
- The algorithm uses random shuffling with rejection sampling — it keeps reshuffling until a non-overlapping path is found.
- The maze coordinates are used only for position tracking; the actual grid structure is not otherwise used.
- The program uses `eval(input())` for integer input, which is unsafe but functional for numeric input.
- The loop `for i in range(1)` creates single-element lists, effectively making `c_l` and `c_l1` 2D structures with one row.
