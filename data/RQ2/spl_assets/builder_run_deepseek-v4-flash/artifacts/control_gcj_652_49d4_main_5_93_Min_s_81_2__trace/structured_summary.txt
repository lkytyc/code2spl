## Overview
This program simulates the placement of people into bathroom stalls according to specific selection rules. It processes multiple test cases, each defining a row of stalls and a number of people to place.

## Input
- First line: an integer T representing the number of test cases
- For each test case: a line containing two space-separated integers N and K
  - N: total number of stalls
  - K: number of people to place

## Output
For each test case, prints a line in the format: `Case #i: y z`
- i: test case number (1-based)
- y: the larger of the two distances for the last person placed
- z: the smaller of the two distances for the last person placed

## Data Structures
- `stall_occupied`: boolean list of length N+2, where index 0 and N+1 are always True (boundary walls), and indices 1 through N represent actual stalls
- `Ls`: list tracking distance to nearest occupied stall on the left for each position
- `Rs`: list tracking distance to nearest occupied stall on the right for each position
- `Min_s`: list of minimum values between Ls and Rs at each position
- `Max_s`: list of maximum values between Ls and Rs at each position

## Initialization Phase
For each test case:
1. Parse N and K from input
2. Create stall_occupied with True at both ends and False for all N interior stalls
3. For each position from 0 to N+1:
   - If occupied (boundary): set Ls and Rs to -1
   - If empty: set Ls to (position - 1) and Rs to (N - position)
   - Compute Min_s and Max_s from these values

## Main Placement Loop
Repeats K times, once per person:

### Selection Process
1. Find the maximum value in Min_s
2. If multiple positions share this maximum:
   - Among those positions, find the one with the highest Max_s value
   - If still tied, select the leftmost such position
3. If only one position has the maximum Min_s, select that position directly

### Placement and Update
For the selected position idx:
1. Compute y = max(Ls[idx], Rs[idx]) and z = min(Ls[idx], Rs[idx])
2. Mark the stall as occupied
3. Set Ls[idx], Rs[idx], Min_s[idx], Max_s[idx] all to -1
4. Update leftward: scan positions to the left until hitting an occupied stall, updating Rs for each empty stall to reflect the new distance to the just-placed person
5. Update rightward: scan positions to the right until hitting an occupied stall, updating Ls for each empty stall similarly

## Control Flow Details
- The leftward update loop continues while position > 0 and stops when encountering an occupied stall
- The rightward update loop continues while position < N+2 and stops when encountering an occupied stall
- Both update loops recalculate Min_s and Max_s for each affected position

## Dependencies
- Uses numpy for array operations when finding indices of maximum values
- Uses raw_input() for reading (Python 2 style)
- Uses xrange() for loops (Python 2 style)
- Output is flushed after each test case

## Termination
The program completes after processing all T test cases, with the final y and z values from the last placement in each case being printed.
