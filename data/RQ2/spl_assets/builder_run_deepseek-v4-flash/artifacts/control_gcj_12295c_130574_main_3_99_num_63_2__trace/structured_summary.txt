## Inputs
The program reads from standard input using a Scanner. It first reads an integer `t` representing the number of test cases. For each test case, it reads:
- An integer `p` (number of people)
- An integer `q` (grid size)
- For each of the `p` people: an integer coordinate, another integer coordinate (transformed), and a direction string (`"N"`, `"S"`, `"E"`, or `"W"`)

## Outputs
For each test case, the program prints a line in the format: `Case #i: x y` where `i` is the 1-based test case number, and `x` and `y` are the coordinates of the chosen point.

## Data Structures
- `Person` class stores four integers: `x`, `y`, `xDir`, `yDir` (direction components)
- `ArrayList<Person>` collections store person objects
- A 2D integer array `b` of size `q` by `q` tracks grid cell counts
- Integer arrays `row` and `col` store candidate coordinates

## Control Flow

### Main Loop
The program iterates through each test case from 1 to `t`.

### Person Input Processing
For each person:
1. Reads coordinate `b` and computes `a = q - inputValue - 1`
2. Reads direction string `c`
3. Sets direction components:
   - `"N"`: yDir = -1, xDir = 0
   - `"S"`: yDir = 1, xDir = 0
   - `"E"`: xDir = 1, yDir = 0
   - Any other value (treated as `"W"`): xDir = -1, yDir = 0
4. Creates a Person object with these values

### Grid Population
For each person, the program increments cells in the grid `b`:
- If xDir is 0 (vertical movement): iterates from the person's y position plus yDir, moving in the yDir direction until reaching grid boundary, incrementing all cells in each affected row
- If xDir is non-zero (horizontal movement): iterates through all rows, and for each row, moves from the person's x position plus xDir in the xDir direction, incrementing cells

### Maximum Finding
The program scans the entire grid to find the maximum cell value.

### Candidate Collection
The program collects all grid positions where the cell value equals the maximum. For each such position, it stores:
- `row[num]` = q - rowIndex - 1 (transformed row coordinate)
- `col[num]` = columnIndex

### Tie-Breaking Logic
1. First, among all candidates, finds those with the minimum sum of row + col coordinates
2. From those, finds candidates with the minimum row (x) value
3. From those, selects the one with the minimum column (y) value

### Output
Prints the selected coordinates in the format `Case #i: y x` (note the order: column first, then row).

## Function Calls
- `Scanner.nextInt()` and `Scanner.next()` for input reading
- `ArrayList.add()` for collection management
- `ArrayList.clear()` for resetting collections
- `ArrayList.size()` for iteration bounds
- `ArrayList.get()` for element access
- `System.out.println()` for output

## Data Dependencies
- The grid `b` depends on all person positions and directions
- The maximum value depends on the grid contents
- Candidate coordinates depend on the maximum value
- The final selection depends on tie-breaking criteria applied sequentially
