# Code Structure Description

## Overview
This Java code contains two classes: `Solution` and `Longest_common_substr`. Both classes have `main` methods and read input from standard input using a `BufferedReader`.

## Class: Solution

### Input
- Reads an integer `tc` representing the number of test cases
- For each test case, reads an integer `noOfWords` representing the number of words
- Reads `noOfWords` strings (words) from standard input

### Processing
- Creates a `TreeSet<String>` to store the words (automatically sorted and deduplicated)
- Creates two iterators (`wrd1` and `wrd2`) over the same set
- Initializes a counter `c1` to 0

### Control Flow
- Outer loop: iterates through the set using `wrd1` iterator
  - Increments `c1` for each word
  - Initializes `c2` to 0 and `result` to 0 for each outer iteration
  - Inner loop: iterates through the set using `wrd2` iterator
    - Increments `c2` for each word
    - Checks if `c1 != c2` (to avoid comparing a word with itself)
    - If different positions, retrieves `wordTwo` from the second iterator
    - Nested loops: iterates through substrings of `wordTwo`
      - Outer substring loop: `l` from 0 to `wordTwo.length()-2`
      - Inner substring loop: `k` from `l+2` to `wordTwo.length()`
      - Checks if `wordOne` contains the substring and if the substring length exceeds current maximum
      - If condition met, updates `max` and `key` variables
      - If condition not met, breaks out of inner loop

### Output
- No output is produced by this class

## Class: Longest_common_substr

### Method: printLCSubStr
- **Parameters**: Two strings `X` and `Y`, and their lengths `m` and `n`
- **Purpose**: Computes the length of the longest common substring between two strings
- **Algorithm**: Uses dynamic programming with a 2D array `LCSuff`
  - Initializes a matrix of size `(m+1) x (n+1)`
  - Fills the matrix:
    - First row and column set to 0
    - If characters match, adds 1 to the diagonal value
    - Tracks the maximum length and its position (row, col)
    - If characters don't match, sets cell to 0
  - If maximum length is 0, returns 0
  - Otherwise, reconstructs the substring by tracing back through the matrix
- **Return**: The length of the longest common substring (as an integer)

### Main Method

#### Input
- Reads an integer `tc` representing the number of test cases
- For each test case (loop from 1 to `tc` inclusive):
  - Reads an integer `noOfWords`
  - Reads `noOfWords` strings into a `TreeSet`

#### Processing
- Creates two iterators over the set
- Initializes `c1` to 0 and `result` to 0
- Outer loop: iterates through the set
  - Initializes `max` to 0, `key1` and `key2` to empty strings
  - Gets next word `w1`
  - Checks if `w1` equals `key1`; if so, removes from set and returns
  - Inner loop: iterates through the set with second iterator
    - Gets next word `w2`
    - Checks if `w2` equals `key2`; if so, removes from set and returns
    - Calls `printLCSubStr` to get the longest common substring length between `w1` and `w2`
    - If the count exceeds current `max`, updates `key1`, `key2`, and `max`
  - Adds `max` to the running `result` total

#### Output
- For each test case, prints: `"Case #" + i + ": " + result`

## Key Data Dependencies
- The `TreeSet` ensures words are processed in sorted order
- Both iterators reference the same set, so the second iterator continues from where it left off across outer loop iterations
- The `result` variable accumulates the maximum common substring lengths for each word compared against all subsequent words
- The `key1` and `key2` variables track the pair of words that produced the current maximum
