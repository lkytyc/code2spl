# Structured Description

## Class: UnionFind
- **Input**: Constructor takes an integer `n` representing the number of elements.
- **State**: Maintains an integer array `Parent` where negative values indicate a root and the absolute value represents the size of the set.
- **Methods**:
  - `root(int A)`: Recursively finds the root of element `A`, with path compression (sets parent to root during traversal).
  - `size(int A)`: Returns the size of the set containing `A` by negating the parent value at the root.
  - `connect(int A, int B)`: Unions the sets containing `A` and `B`. Returns `false` if already connected, otherwise merges by size (larger set becomes parent) and returns `true`.

## Class: Main

### Static Fields
- `scan`: FastScanner instance for input.
- `scanner`: Standard Scanner instance.
- `rand`: Random instance.
- `mod`: Constant 1000000007.
- `eps`: Constant 0.0000000001.
- `big`: Integer.MAX_VALUE.

### Utility Methods
- `modlcm(a, b)`: Returns `a * b * modint(gcd(a,b), mod)`.
- `gcd(a, b)`: Recursive Euclidean algorithm; returns `a` if `b` is 0, otherwise recurses with `(b, a % b)`.
- `lcm(a, b)`: Returns `a * b / gcd(a, b)`.
- `max(a, b)`, `min(a, b)`: Integer max/min.
- `lmax(a, b)`, `lmin(a, b)`: Long max/min using Math functions.
- `factorial(i)`: Recursive factorial; returns 1 for input 1, otherwise `i * factorial(i-1)`.

### Main Method
- **Input**: Reads a single string `str` from the fast scanner.
- **Logic**: Iterates through each character of `str`:
  - Sets a boolean flag `b` to `true` when character `'C'` is encountered.
  - If `b` is `true` and the current character is `'F'`, prints "Yes" and exits.
- **Output**: If no `'F'` appears after a `'C'`, prints "No".

### Search/Bound Methods
- `lower_bound(a[], key)`: Binary search on sorted array; returns the leftmost index where the element is less than `key`.
- `upper_bound(a[], key)`: Binary search on sorted array; returns the leftmost index where the element is less than or equal to `key`.

### Number Theory Methods
- `isPrime(n)`: Returns `true` for `n == 2`; returns `false` for `n < 2` or even numbers; checks odd divisors up to the square root.
- `upper_division(a, b)`: Integer division rounding up; returns `a/b` if divisible, otherwise `a/b + 1`.
- `lupper_division(a, b)`: Long version of `upper_division`.
- `modpow(x, n, mo)`: Modular exponentiation using binary exponentiation; multiplies result by `x` when the current bit is set, squares `x` each iteration.
- `modint(a, m)`: Extended Euclidean algorithm to compute modular inverse of `a` modulo `m`; returns a value in range `[0, m)`.

### Array Methods
- `setArray(a)`: Reads `a` integers from input and returns them as an array.
- `lsetArray(a)`: Reads `a` longs from input and returns them as an array.
- `printArray(que)`: Prints array elements separated by spaces, with a newline after the last element.
- `doublesort(a[][])`: Sorts a 2D integer array by the first column.
- `ldoublesort(a[][])`: Sorts a 2D long array by the first column.
- `revch(ch[])`: Returns a new character array with elements in reverse order.
- `revint(ch[])`: Returns a new integer array with elements in reverse order.

### Graph Algorithm
- `warshall_floyd(v[][], n)`: Performs Floyd-Warshall all-pairs shortest path on an `n x n` adjacency matrix, updating each cell with the minimum path through intermediate nodes.

### String Method
- `reverce(str)`: Returns a new string with characters in reverse order.
