# Structured Description

## Input Format
- The program reads from standard input using a BufferedReader.
- First input is an integer `qq` representing the number of test cases.
- For each test case, two integers `r` and `c` are read, representing grid dimensions.
- Then `r` strings are read, each of length `c`, representing the grid characters.

## Output Format
- For each test case, the program outputs a line: `Case #<case_number>: <result>`
- The result is an integer representing the maximum size of a valid subset of cells.

## Main Control Flow

### Initialization
- Static BufferedReader, StringTokenizer, and PrintWriter are initialized.
- The number of test cases `qq` is read.

### Test Case Loop
- For each test case (from 1 to `qq`):
  - Reads grid dimensions `r` and `c`.
  - Initializes `ret` to 1.
  - Reads the grid into a 2D character array `g`.

### Grid Reading
- For each row `i` from 0 to r-1:
  - Reads a string token.
  - For each column `j` from 0 to c-1, stores the character at position `g[i][j]`.

### Main Search Loop (Subset Enumeration)
- Iterates over all bitmasks from 1 to (1 << (r*c)) - 1.
- Each bitmask represents a subset of grid cells (bit set = cell selected).
- **Pruning condition**: If the number of set bits in the mask is less than or equal to the current best `ret`, skip this mask.

### Subset Processing
For each mask that passes the pruning check:
1. **Initialize Union-Find**: Creates a parent array `par` of size r*c, with each element pointing to itself.
2. **Build usage grid**: Converts the bitmask into a 2D boolean array `use`, where `use[i][j]` is true if the corresponding bit is set.
3. **Count required connections**: Sets `numNeed` to (number of set bits - 1).

### Connectivity Check
- Iterates through all cells in the grid.
- For each selected cell, checks its right neighbor and bottom neighbor:
  - If the neighbor is also selected and merging them succeeds (they were in different components), decrements `numNeed`.
- After processing all cells, if `numNeed` is not 0, the subset is not connected (a tree), so skip this mask.

### Validity Check (Color Constraint)
- If the subset is connected, checks validity:
  - For each cell `(i,j)` in the grid (as a potential "root" or reference point):
    - Initializes 4 sets (`all[0]` through `all[3]`), each representing a quadrant relative to `(i,j)`.
    - For each selected cell `(x,y)`:
      - Determines its quadrant index:
        - If `x > i`, sets bit 2 (value 2).
        - If `y < j`, sets bit 1 (value 1).
      - Adds the character `g[x][y]` to the corresponding quadrant set.
      - If any quadrant set has size >= 2, marks `good` as false and breaks.
    - If all quadrant sets have size at most 1, the subset is valid.
  - If any reference cell `(i,j)` makes the subset valid, the subset passes.

### Update Best Result
- If the subset is both connected and valid, updates `ret` to the number of set bits in the mask.

### Output
- After the mask loop completes, prints the final `ret` value for the test case.

## Helper Functions

### find(x)
- Union-Find find operation with path compression.
- Returns the root of the set containing `x`.

### merge(x, y)
- Union-Find merge operation.
- Finds roots of `x` and `y`.
- If they are already in the same set, returns false.
- Otherwise, sets parent of one root to the other and returns true.

### Input Helper Functions
- `readInt()`: Reads and parses an integer from the token stream.
- `readLong()`: Reads and parses a long.
- `readDouble()`: Reads and parses a double.
- `nextToken()`: Reads the next whitespace-delimited token, refreshing the tokenizer when needed.
- `nextLine()`: Reads a full line; if null (EOF), calls `exitImmediately()`.

### exitImmediately()
- Closes the PrintWriter and terminates the program with exit code 0.

## Data Dependencies
- The result `ret` depends on the grid characters and the connectivity/validity checks.
- The validity check depends on the relative positions of selected cells and their characters.
