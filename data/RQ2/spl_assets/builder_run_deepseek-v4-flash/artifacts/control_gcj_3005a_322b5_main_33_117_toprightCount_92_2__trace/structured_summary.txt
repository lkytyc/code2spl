# Structured Description

## Inputs
- Standard input is read line by line.
- First line contains an integer T, the number of test cases.
- Each test case begins with a line containing four integers: R, C, H, V (rows, columns, horizontal cuts, vertical cuts).
- Following that are R lines, each representing a row of a waffle grid with C characters. The character '@' represents a chocolate chip; other characters represent empty cells.

## Outputs
- For each test case, prints: `Case #<case_number>: <result>` where case_number starts at 1 and increments, and result is either "POSSIBLE" or "IMPOSSIBLE".

## Global Data
- A 1000x1000 integer array G is declared but never used in the code.
- Global variables targetX and targetY are declared but never used.

## Helper Function: readline()
- Allocates a buffer starting at 1024 bytes.
- Reads from stdin using fgets into the current buffer position.
- Continues reading until either:
  - fgets returns NULL (end of input)
  - The accumulated data length is less than buffer size minus 1
  - The last character read is a newline
- If buffer fills up, doubles the buffer size using realloc.
- After reading completes:
  - If the last character is a newline, replaces it with a null terminator.
  - Otherwise, appends a null terminator at the end (incrementing data length).
- Shrinks the buffer to exactly fit the data length using realloc.
- Returns the allocated string.

## Main Function Logic

### Initialization
- Reads T (number of test cases) from first input line.
- Sets case counter u_w to 1.

### Test Case Loop
- Loops while T decrements and is not zero.

### Per Test Case Setup
- Declares local variables: R, C, H, V (dimensions and cut counts).
- Declares Waffle array (up to 10 strings) and ChocChipCount array (up to 10 integers).
- Initializes all ChocChipCount entries to 0.
- Reads R, C, H, V from input line.
- For each row i from 0 to R-1:
  - Reads the waffle row string.
  - Counts '@' characters in that row and stores count in ChocChipCount[i].

### Feasibility Check
- Sets retStr to "IMPOSSIBLE" initially.
- Loops over possible horizontal cut positions i from 1 to R-1, but only while retStr is still "IMPOSSIBLE".

#### Horizontal Split Evaluation
- Computes topCount = sum of ChocChipCount[0] through ChocChipCount[i-1].
- Computes bottomCount = sum of ChocChipCount[i] through ChocChipCount[R-1].
- If topCount != bottomCount, skips this horizontal cut position (continue).

#### Vertical Split Evaluation (when horizontal split is balanced)
- Loops over possible vertical cut positions k from 1 to C-1.
- For each vertical cut:
  - Computes topleftCount by counting '@' in rows 0 to i-1 and columns 0 to k-1.
  - Computes toprightCount as sum of ChocChipCount[0] through ChocChipCount[i-1], then subtracts topleftCount.
  - If topleftCount == toprightCount:
    - Computes bottomleftCount by counting '@' in rows i to R-1 and columns 0 to k-1.
    - Computes bottomrightCount as sum of ChocChipCount[i] through ChocChipCount[R-1], then subtracts bottomleftCount.
    - If bottomleftCount == bottomrightCount:
      - Sets retStr to "POSSIBLE" and breaks out of vertical loop.

### Output
- Prints "Case #<u_w>: <retStr>" for the current test case.
- Increments u_w.

## Control Flow Summary
- Outer loop: iterates through test cases.
- Inner loop 1: iterates over possible horizontal cut positions.
- Inner loop 2: iterates over possible vertical cut positions.
- Nested loops: count chips in quadrants for each cut combination.
- Early termination: breaks out of loops when a valid configuration is found.

## Data Dependencies
- ChocChipCount values depend on reading waffle rows.
- topCount and bottomCount depend on ChocChipCount and horizontal cut position.
- Quadrant counts depend on waffle grid contents and both cut positions.
- The final result depends on finding at least one valid combination of horizontal and vertical cuts where all four quadrants have equal chip counts.
