# Structured Description

## Overview
This program reads a sequence of integers, processes them to track a running sum, and counts the number of adjustments needed to keep the sum from crossing zero in a specific pattern. The final count is printed.

## Inputs
- An integer `n` (number of elements)
- `n` integers stored in array `a` (size 100000)

## Outputs
- A single integer `ans` printed to stdout

## Functions
- `abs(int x)`: Returns the absolute value of `x`. If `x < 0`, returns `-x`; otherwise returns `x`.

## Main Program Flow

### Initialization
- Declares integer variables: `n`, array `a[100000]`, loop counters `i` and `j`, `sum = 0`, `ans = 0`
- Declares character variable `sign`

### Input Reading
- Reads `n` via `scanf`
- Reads `n` integers into array `a` using a for loop from `i=0` to `i<n`

### First Pass - Determine Initial Sign
- Loops through array from `i=0` to `i<n`
- If `a[i] > 0`: sets `sign = 'p'` (positive) and breaks
- If `a[i] < 0`: sets `sign = 'm'` (negative) and breaks
- If `a[i] == 0`: continues to next element
- If all elements are zero, `sign` remains uninitialized

### Main Processing Loop
Continues from the current `i` value (where the first non-zero was found, or from `n` if all zeros) to `i<n`:

1. **Add current element to sum**: `sum += a[i]`

2. **If sum equals zero**:
   - Inner loop from `j=i+1` to `j<n`:
     - If `sum == a[j]`: continue (skip)
     - If `sign == 'p'`: increment `sum` by 1, increment `ans` by 1, set `i = j`, break
     - If `sign == 'm'`: decrement `sum` by 1, increment `ans` by 1, set `i = j`, break
   - After inner loop: set `i = j`, increment `ans` by 1

3. **If sum > 0 and sign is 'p'**: change sign to 'm'

4. **If sum < 0 and sign is 'm'**: change sign to 'p'

5. **Otherwise (sum and sign mismatch)**:
   - If `sign == 'p'`: add `abs(sum)+1` to `ans`, add `abs(sum)+1` to `sum`, change sign to 'm'
   - If `sign == 'm'`: add `abs(sum)+1` to `ans`, subtract `abs(sum)+1` from `sum`, change sign to 'p'

### Output
- Prints the final value of `ans`

## Key Data Dependencies
- `sum` is modified throughout the loop and affects branching decisions
- `sign` determines which adjustment direction is taken
- `ans` accumulates the count of adjustments
- `i` is modified both by the outer loop increment and by assignments from inner loop breaks
- `j` is used in the inner loop and its final value is assigned to `i`

## Control Flow Branches
- Initial sign detection: three-way branch (positive, negative, zero)
- Main loop: checks for sum being zero, positive with 'p' sign, negative with 'm' sign, or mismatch cases
- Inner loop: checks if sum equals current array element, then branches on sign value
- Absolute value function: two-way branch on sign of input

## Edge Cases
- All zeros in array: `sign` remains uninitialized, main loop processes all elements with sum always zero
- Single element array
- Large values that could cause integer overflow in `sum` or `ans`
