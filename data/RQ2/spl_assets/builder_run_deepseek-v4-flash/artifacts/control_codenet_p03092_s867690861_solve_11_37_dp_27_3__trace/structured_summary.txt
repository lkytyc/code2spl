# Code Description

## Program Overview
This is a Java program that reads input, processes it through a dynamic programming algorithm, and outputs a single numeric result. The main computation occurs in the `solve()` method.

## Input/Output
- **Input**: Read from `System.in` (or from a hardcoded `INPUT` string if non-empty)
- **Output**: A single long value printed to `System.out` via a `PrintWriter`

## Main Program Flow

### `main` Method
1. Records start time
2. Sets up input stream: uses `System.in` if `INPUT` is empty, otherwise uses a `ByteArrayInputStream` wrapping the `INPUT` string
3. Creates a `PrintWriter` for output
4. Calls `solve()`
5. Flushes output
6. If `INPUT` is non-empty, prints execution time

### `solve` Method
1. **Reads three integers**: `n`, `A`, `B` from input
2. **Reads array `P`**: An array of `n` integers
3. **Decrements each element** of `P` by 1 (converting to 0-based indexing)
4. **Initializes DP table**: Creates a 2D array `dp` of size `(n+1) × (n+1)`, filling all entries with `Long.MAX_VALUE / 2` (a large sentinel value)
5. **Fills DP table** using nested loops:
   - For each cell `(i, j)` where `i` and `j` range from 0 to `n`:
     - **Base case**: If `i == 0` and `j == 0`, set `dp[0][0] = 0`
     - **Match case**: If both `i-1 >= 0` and `j-1 >= 0` and `P[i-1] == j-1`, set `dp[i][j] = dp[i-1][j-1]` (no cost for matching)
     - **Otherwise**: 
       - If `i-1 >= 0`, consider `dp[i-1][j] + (P[i-1] <= j ? B : A)` as a candidate
       - If `j-1 >= 0`, consider `dp[i][j-1]` as a candidate
       - Take the minimum of these candidates
6. **Outputs** `dp[n][n]` as the final answer

## Input Parsing Utilities

### `ni()` - Read Integer
- Skips whitespace characters
- Handles optional negative sign
- Accumulates digits into an integer
- Returns the parsed integer when a non-digit is encountered

### `nl()` - Read Long
- Similar to `ni()` but returns a `long` value

### `ns()` - Read String
- Skips whitespace, then reads characters until whitespace is found
- Returns the accumulated string

### `ns(int n)` - Read Fixed-Length Character Array
- Reads up to `n` characters or until whitespace
- Returns a character array (possibly truncated)

### `nm(int n, int m)` - Read Character Matrix
- Reads `n` rows, each of length `m` characters
- Returns a 2D character array

### `na(int n)` - Read Integer Array
- Reads `n` integers and returns them as an array

### `nd()` - Read Double
- Parses a string as a double

### `nc()` - Read Character
- Skips whitespace and returns the next character

## Low-Level Input Handling

### `readByte()`
- Reads one byte from the input stream
- Uses a buffer (`inbuf`) of 1024 bytes
- Throws `InputMismatchException` if end of stream is reached
- Returns -1 if no more data is available

### `isSpaceChar(int c)`
- Returns `true` if character is outside ASCII range 33-126 (i.e., whitespace or control characters)

### `skip()`
- Reads bytes until a non-whitespace character is found
- Returns the first non-whitespace byte

### `eof()`
- Checks if end of file has been reached
- Uses stream marking/resetting to peek ahead without consuming input
- Returns `true` if only whitespace remains or an IOException occurs

## Helper Method
### `tr(Object... o)`
- Only prints debug output if the `INPUT` string is non-empty (debug mode)
- Uses `Arrays.deepToString` for array formatting
