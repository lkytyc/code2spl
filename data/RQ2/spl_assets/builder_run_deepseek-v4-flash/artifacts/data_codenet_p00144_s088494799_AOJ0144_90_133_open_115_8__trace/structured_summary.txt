# Structured Description of Code

## Class Overview
The `Main` class contains multiple problem-solving methods (AOJ0144, AOJ0145, AOJ0147) and supporting data structures. It uses a `Scanner` for input and static imports for `Math` functions and `System.out`.

## Global Fields
- `sc`: A `Scanner` object for reading input
- `vx`, `vy`: Integer arrays representing directional vectors (right, down, left, up)

## Nested Class: Point
- Fields: `x`, `y` (integers)
- Constructors: 
  - Parameterized constructor with x, y coordinates
  - Default constructor initializing to (0,0)
- Methods:
  - `toString()`: Returns coordinates in format "(x,y)"
  - Static `ok(x, y, X, Y, min)`: Returns true if x is in range [min, X) and y is in range [min, Y)
  - Static `ok(x, y, X, Y)`: Calls the 5-parameter version with min=0

## Main Method
- Creates a new `Main` instance and calls `AOJ0144()`

## Method: AOJ0145
- **Input**: Reads integer N, then N pairs of integers (upper, down values)
- **Processing**: Creates an array of `C0145` objects with the input values
- **Output**: Prints `Integer.MAX_VALUE` for each test case
- **Loop**: Continues while scanner has more input

## Nested Class: C0145
- Fields: `upper`, `down` (integers)
- Constructor: Takes two integers and assigns them to fields

## Method: AOJ0147
- **Input**: Reads integers until end of input
- **Initialization**: 
  - Creates a linked list queue of input values
  - Sets MAX to 120 initially, then updates to maximum of current MAX and each input value
  - Creates arrays for num, time, and seat (size 17, initialized to -1)
- **Pre-computation**: 
  - For each index i from 0 to MAX-1:
    - num[i] = 5 if i%5==1, otherwise 2
    - time[i] = 17*(i%2) + 3*(i%3) + 19
- **Main Loop**: 
  - Uses variables j (group counter) and min (time counter)
  - While queue is not empty:
    - Calls `exit()` to remove groups whose time has expired
    - Calls `find()` to locate available seats for group j
    - If seats found and min >= j*5:
      - Checks if the first queue element matches j
      - If match, prints max(0, min - j*5) and removes from queue
      - Occupies seats for group j
      - Increments j
    - Otherwise increments min

## Method: find(seat, n)
- **Purpose**: Finds first contiguous block of n empty seats
- **Logic**: 
  - Iterates through positions 0 to 16-n
  - For each position, checks if n consecutive seats are all -1 (empty)
  - Returns the starting index if found, otherwise returns -1

## Method: exit(seat, min, time)
- **Purpose**: Removes groups whose stay has ended
- **Logic**: 
  - For each seat position:
    - If seat is occupied (not -1), calculates exit time as idx*5 + time[seat[idx]]
    - If current time (min) >= exit time, sets seat to -1
  - Returns the updated seat array

## Method: disp(seat, min)
- **Purpose**: Debug/display method
- **Output**: Prints current time and seat occupancy status

## Method: AOJ0144
