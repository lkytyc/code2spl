## Overview
This program reads multiple test cases, each containing rectangle dimensions and a perimeter budget, then computes the maximum possible total perimeter achievable by adding decorative strips to some rectangles without exceeding the budget.

## Inputs
- First line: integer `T` (number of test cases)
- For each test case:
  - First line: integers `N` (number of rectangles) and `P` (perimeter budget)
  - Next `N` lines: pairs of integers `w` and `h` (width and height of each rectangle)

## Outputs
- For each test case: `Case #X: Y` where X is the test case number (1-based) and Y is a floating-point number with 6 decimal places representing the maximum achievable total perimeter.

## Data Structures
- Arrays allocated per test case:
  - `w`, `h`: integer arrays of size N for rectangle dimensions
  - `min_add`: integer array of size N for minimum additional perimeter per rectangle
  - `max_add`: double array of size N for maximum additional perimeter per rectangle
  - `best_min`, `best_max`: double arrays of size N for tracking best cumulative minimum and maximum additions

## Processing Logic

### Per Test Case Initialization
1. Read `N` and `P`, store original `P` in `P_orig`
2. Allocate all arrays
3. Initialize `total` to 0

### Rectangle Processing Loop (j from 0 to N-1)
For each rectangle:
- Read width and height
- Compute base perimeter: `circ = (w + h) * 2`
- Subtract `circ` from `P` (remaining budget)
- Add `circ` to `total` (base perimeter sum)
- Compute `min_add[j]` = 2 × (minimum of width and height)
- Compute `max_add[j]` = 2 × √(w² + h²)

### Dynamic Programming Selection Loop (j from 0 to N-1)
For each rectangle index `j`:
- Initialize `min1 = 0`, `max1 = 0`, `k1 = -1`
- Inner loop over previous rectangles `k` (0 to j-1):
  - Check if `best_min[k] + min_add[j] < P` (feasible) and `best_max[k] > max1` (better)
  - If so, update `k1`, `min1`, `max1` with values from rectangle `k`
- Compute `best_min[j] = min1 + min_add[j]`
- Compute `best_max[j] = max1 + max_add[j]`
- If `best_min[j] <= P` and `best_max[j] > best_valid`, update `best_valid`

### Final Calculation
- If `best_valid > P`, cap it at `P`
- Output: `total + best_valid` formatted to 6 decimal places

## Key Dependencies
- `best_min[j]` depends on `best_min[k]` from previous rectangles
- `best_max[j]` depends on `best_max[k]` from previous rectangles
- The selection of previous rectangle `k` depends on both feasibility (`best_min[k] + min_add[j] < P`) and optimality (`best_max[k] > max1`)

## Helper Function
- `dpr`: Debug print function that takes a format string and variable arguments, but has its actual printing code disabled (inside `#if 0` block), so it always returns 0 without producing output.

## Memory Management
- All arrays are freed at the end of each test case iteration
- Program exits with status 0 after processing all test cases
