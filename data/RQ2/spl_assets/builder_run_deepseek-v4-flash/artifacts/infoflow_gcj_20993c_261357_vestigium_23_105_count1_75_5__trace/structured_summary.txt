## Program Overview
This program reads multiple square matrices from standard input, computes a trace value and duplicate detection metrics for each matrix, and outputs formatted results.

## Input
- First integer `t`: number of test cases
- For each test case:
  - Integer `n`: matrix dimensions (n×n)
  - `n²` integers: matrix elements read row by row

## Output
For each test case, one line printed to standard output with format:
`Case #X:  K R C`
Where X is a case counter, K is the trace, R is the row duplicate metric, and C is the column duplicate metric.

## Main Function Control Flow
1. Creates a Scanner for standard input
2. Reads test case count `t`
3. Loops `t` times (while loop with post-decrement)
4. For each iteration:
   - Reads matrix size `n`
   - Creates n×n integer array
   - Nested loops fill the matrix from input
   - Calls `vestigium(a, n)` function

## Vestigium Function Logic

### Trace Calculation
- Initializes `k = 0`
- Single loop sums diagonal elements: `k += a[i][i]` for all `i` from 0 to n-1

### Matrix Transposition
- Creates new n×n array `b`
- Nested loops assign `b[i][j] = a[j][i]`, effectively transposing the original matrix

### Row Duplicate Detection
- Sorts each row of matrix `a` using `Arrays.sort()`
- For each row, iterates through adjacent pairs:
  - If adjacent elements are equal, increments `repeat` counter
  - Tracks maximum `repeat` value in `count`
  - Resets `repeat` to 0 after each row if it was positive
- After processing all rows, sets `r = count + 1`

### Column Duplicate Detection
- Sorts each row of transposed matrix `b` (which represents original columns)
- Same adjacent-pair comparison logic as rows
- Tracks maximum in `count1`
- After processing, sets `c = count1 + 1`

### Output Logic
- Initializes `counter = 1`
- Four conditional branches based on whether row duplicates (`count`) and column duplicates (`count1`) were found:
  1. Both zero: prints `count` and `count1` directly (both 0)
  2. Both non-zero: prints `r` and `c` (both incremented values)
  3. Only row duplicates: prints `r` and `count1` (0)
  4. Only column duplicates: prints `count` (0) and `c`
- Each branch increments `counter` after printing

## Data Dependencies
- Matrix `a` is modified in-place by sorting (original input order lost)
- Matrix `b` depends on original `a` values before sorting
- `count` and `count1` depend on sorted array comparisons
- Output values depend on the duplicate detection results

## Notable Behavior
- The `counter` variable is local to the function and resets to 1 for each matrix, so all test cases print "Case #1"
- The duplicate count logic counts consecutive equal elements after sorting, which may overcount if multiple duplicates exist in a row
- The `+1` adjustment to `r` and `c` means even a single duplicate pair results in value 2
