# Function: get_next_location(num_of_people)

## Input
- `num_of_people`: an integer representing the number of people to process.

## Processing
1. Initializes an empty list `coordinates_list` and sets `people_count` to 1.
2. Loops while `people_count` is less than or equal to `num_of_people`:
   - Reads a line of input via `raw_input("")`.
   - Splits the input string by whitespace into three parts: x-coordinate, y-coordinate, and direction.
   - Converts x and y to integers.
   - Based on the direction string:
     - "N": increments y by 1.
     - "S": decrements y by 1.
     - "E": increments x by 1.
     - "W": decrements x by 1.
   - Creates a two-element list `[x, y]` and appends it to `coordinates_list`.
   - Increments `people_count` by 1.

3. After the loop, initializes two empty lists: `next_dest` (unique coordinates) and `next_dest_count` (frequency counts).

4. Iterates over each coordinate pair in `coordinates_list`:
   - Sets `found` to 0 and `dest_idx` to 0.
   - Iterates over existing entries in `next_dest`:
     - If the current coordinate equals an existing destination, increments the corresponding count in `next_dest_count`, sets `found` to 1, and breaks.
     - Otherwise, increments `dest_idx`.
   - If `found` is still 0, appends the coordinate to `next_dest` and appends 1 to `next_dest_count`.

5. Initializes `popular_next_dest` with the first unique destination and sets `highest_count` to the first count.

6. Iterates over `next_dest_count` starting from index 1:
   - Skips the first element (index 0) via a continue.
   - If the current count equals `highest_count`, appends the corresponding destination to `popular_next_dest`.
   - If the current count is greater than `highest_count`, resets `popular_next_dest` to an empty list, updates `highest_count`, and appends the current destination.

7. If `popular_next_dest` has exactly one element, returns that element.

8. Otherwise (multiple destinations tied for highest count):
   - Sets `smallest_number` to the first destination in `popular_next_dest`.
   - Iterates over the remaining destinations, comparing them lexicographically (list comparison) and keeping the smallest.
   - Returns the smallest destination.

## Output
- Returns a two-element list `[x, y]` representing the most frequent next location, with ties broken by choosing the lexicographically smallest coordinate pair.

# Function: generate_test_cases(T)

## Input
- `T`: an integer specifying the number of test cases.

## Processing
1. Sets `count` to 1.
2. Loops while `count` is less than or equal to `T`:
   - Reads a line of input via `raw_input("")`.
   - Splits the input into two integers: `num_of_people` and `max_grid_size`.
   - Calls `get_next_location(num_of_people)` and stores the result in `coordinates`.
   - Extracts x and y from the returned list.
   - Prints `"Case #" + str(count) + ": " + str(x) + " " + str(y)`.
   - Increments `count` by 1.

## Output
- Prints one line per test case in the format: `Case #<number>: <x> <y>`.

# Top-Level Execution

## Input
- Reads a single line via `eval(raw_input(""))` to obtain the number of test cases `T`.

## Processing
- Calls `generate_test_cases(int(T))`.

## Output
- Prints the results for all test cases as described above.

# Data Dependencies and Control Flow Summary

- The main program depends on user input for `T`.
- `generate_test_cases` depends on user input for each test case's parameters and on the return value of `get_next_location`.
- `get_next_location` depends on user input for each person's starting coordinates and direction.
- Control flow in `get_next_location` includes:
  - A while loop for reading people's data.
  - Four independent if statements for direction handling (not mutually exclusive).
  - Nested loops for counting frequency of destinations.
  - A loop for finding the highest count and handling ties.
  - A final loop for selecting the smallest coordinate among ties.
- The tie-breaking uses Python's list comparison, which compares element-by-element (x first, then y).
