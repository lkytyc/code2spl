# Code Description

## Overview
This Java program reads test cases from standard input, separates input numbers into odd-indexed and even-indexed arrays, sorts each array, and checks whether the combined sequence would be non-decreasing if the arrays were interleaved. It reports the first position where the ordering fails, or indicates success.

## Input
- First integer: number of test cases
- For each test case:
  - An integer `n` (size of the sequence)
  - `n` subsequent integers (the sequence elements)

## Output
For each test case, one line:
- `Case #X: OK` if the interleaved sorted sequence is valid
- `Case #X: Y` where Y is the index of the first violation

## Main Control Flow

### Test Case Loop
- Iterates `m` from 0 to `numberOfTests - 1`
- Reads `n` for each test case

### Array Size Determination
- If `n` is odd: `a = n/2 + 1`, `b = n/2`
- If `n` is even: `a = n/2`, `b = n/2`
- Creates `oddArray` of size `a` and `evenArray` of size `a` (note: evenArray is also sized `a`, not `b`)

### Input Reading Loop
- Iterates `i` from 0 to `n-1`
- If `i` is even: stores value in `oddArray` at position `c`, increments `c`
- If `i` is odd: stores value in `evenArray` at position `d`, increments `d`

### Sentinel Value
- Sets the last element of `evenArray` to `Integer.MAX_VALUE`

### Sorting
- Creates a `Solution` instance
- Calls `sort(oddArray)` and `sort(evenArray)` (merge sort)

### Validation Loop
- Iterates `h` from 0 to `oddArray.length - 1`
- Checks if `oddArray[h] <= evenArray[h]`
  - If true and `h` is the last index: breaks (success)
  - If true and `evenArray[h] <= oddArray[h+1]`: continues
  - If true but `evenArray[h] > oddArray[h+1]`: prints failure at position `2*h + 1`, increments `x`, breaks
  - If false (`oddArray[h] > evenArray[h]`): prints failure at position `2*h`, increments `x`, breaks
- Uses try-finally block (finally is empty)

### Result Reporting
- If `x == 0` (no failure found): prints `Case #X: OK`

## Merge Sort Implementation

### Public `sort` Method
- Stores input array in instance field `array`
- Stores array length in `length`
- Creates `tempMergArr` of same length
- Calls `doMergeSort(0, length - 1)`

### Recursive `doMergeSort` Method
- If `lowerIndex < higherIndex`:
  - Computes middle index
  - Recursively sorts left half
  - Recursively sorts right half
  - Merges the two halves

### `mergeParts` Method
- Copies range from `array` to `tempMergArr`
- Uses three pointers: `i` (left half start), `j` (right half start), `k` (output position)
- While both halves have elements: copies smaller value to `array[k]`
- Copies remaining elements from left half if any

## Data Dependencies
- `oddArray` and `evenArray` contents depend on input values and their original positions
- Validation results depend on sorted order of both arrays
- The sentinel `Integer.MAX_VALUE` in `evenArray` ensures the last odd element comparison succeeds

## Notable Behaviors
- `evenArray` is allocated with size `a` (same as oddArray), which may be larger than needed for even-indexed elements
- The sentinel value fills the unused last slot
- The validation assumes `oddArray` and `evenArray` have the same length
- The try-finally block has no functional effect
