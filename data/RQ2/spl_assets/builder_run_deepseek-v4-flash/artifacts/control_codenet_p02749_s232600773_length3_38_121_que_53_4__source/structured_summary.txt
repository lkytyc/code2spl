# Structured Description

## Input
- Reads a single integer `n` from standard input (number of vertices).
- Reads `n-1` lines, each containing two integers `a` and `b`, representing an undirected edge between vertices `a` and `b` (1-indexed input, converted to 0-indexed internally).

## Output
- Prints a single line containing `n` space-separated integers, representing the assigned value for each vertex (1-indexed positions).
- If no valid assignment exists, prints `-1` and terminates.

## Main Function Logic

### Graph Construction
- Creates an adjacency list `g` with `n` empty lists.
- For each of the `n-1` edges, adds each endpoint to the other's adjacency list (undirected graph).

### Breadth-First Search (BFS)
- Calls the `bfs` function starting from vertex 0.
- Returns:
  - `dis`: distance array from vertex 0 to all vertices.
  - `cnt_odd`: count of vertices at odd distance from vertex 0.
  - `cnt_even`: count of vertices at even distance from vertex 0 (including vertex 0 itself).

### Assignment Strategy
- Initializes `ans` as an array of zeros of length `n`.

#### Case 1: Small Color Class
- If `min(cnt_even, cnt_odd) <= n//3`:
  - Creates a `check` array of all ones (length `n`).
  - If `cnt_even <= cnt_odd`:
    - Assigns values `3, 6, 9, ...` (multiples of 3) to vertices at even distances, marking those values as used in `check`.
    - Fills remaining unassigned vertices with the smallest unused values (1, 2, 4, 5, 7, 8, ...).
  - If `cnt_even >= cnt_odd`:
    - Same logic but assigns multiples of 3 to vertices at odd distances instead.
  - Prints the result and returns.

#### Case 2: Larger Color Classes
- If `min(cnt_even, cnt_odd) > n//3`:
  - Creates `check` array of all ones.
  - If `cnt_even <= cnt_odd`:
    - Assigns multiples of 3 to even-distance vertices while `3*x <= n`.
    - Remaining even-distance vertices are stored in `remain`.
    - Creates two deques:
      - `que_1`: contains numbers congruent to 1 modulo 3 (1, 4, 7, ...).
      - `que_2`: contains numbers congruent to 2 modulo 3 (2, 5, 8, ...).
    - For each vertex in `remain`, calls `length3` to assign values.
    - Fills any remaining zero entries in `ans` from `que_1` first, then `que_2`.
  - If `cnt_even > cnt_odd`:
    - Same logic but assigns multiples of 3 to odd-distance vertices instead.

## Helper Function: bfs(n, g)
- Performs BFS from vertex 0.
- Tracks visited vertices and distances.
- Counts vertices at even and odd distances.
- Returns distance array, odd count, and even count.

## Helper Function: length3(s, n, g, ans, que_1, que_2)
- Performs BFS from vertex `s` up to distance 3.
- Collects vertices at exactly distance 3 from `s` into `see`.
- Examines already-assigned values among vertices in `see`:
  - Counts how many have values congruent to 1 modulo 3 (`check1`).
  - Counts how many have values congruent to 2 modulo 3 (`check2`).
- Branching logic:
  - If both `check1 > 0` and `check2 > 0`: prints `-1` and exits.
  - If only `check1 > 0`: assigns `s` a value from `que_2`, and assigns unassigned vertices in `see` values from `que_1`.
  - If only `check2 > 0`: assigns `s` a value from `que_1`, and assigns unassigned vertices in `see` values from `que_2`.
  - If neither: chooses the larger remaining queue to assign to `s`, and the other queue for vertices in `see`.
- Returns updated `ans`, `que_1`, `que_2`.
