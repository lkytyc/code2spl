This code processes a series of queries to maintain a dynamic set of numbers and compute the median along with a cumulative sum adjustment. It uses two priority queues (a max-heap for the lower half and a min-heap for the upper half) to keep track of the median, and tracks the sum of elements in each half. For each query, it either inserts a new number with an associated value (updating the heaps and sums accordingly) or outputs the current median and a computed value based on the difference between the sums of the two halves plus a running total.
