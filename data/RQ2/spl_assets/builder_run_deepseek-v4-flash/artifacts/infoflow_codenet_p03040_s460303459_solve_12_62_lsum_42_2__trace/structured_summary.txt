## Overview
This program implements a data structure that maintains a dynamic multiset of long integers and supports two types of operations: insertion with an associated cost, and queries about the current median and a computed sum. The core logic uses two priority queues to maintain the lower and upper halves of the data.

## Input
The program reads from standard input using a custom `InputReader` class. The first integer read is `Q`, the number of operations to process. Each subsequent operation consists of:
- An integer command (`com`), either 1 or 2
- For command 1: a long integer `a` to insert, followed by another long integer (stored in `B`)
- For command 2: no additional parameters

## Output
For each command 2, the program outputs a line containing two values separated by a space: the current median value and a computed sum.

## Data Structures
- `f`: A max-heap (priority queue with reverse ordering) storing the lower half of inserted values
- `l`: A min-heap (standard priority queue) storing the upper half of inserted values
- `fsum`: Running sum of all elements in heap `f`
- `lsum`: Running sum of all elements in heap `l`
- `B`: Accumulated sum of the second parameter from all insert operations

## Control Flow

### Main Loop
The program processes `Q` operations in a while loop that decrements `Q` after each iteration.

### Insert Operation (com == 1)
When inserting value `a`:
1. If both heaps have equal size:
   - If both are empty, add `a` to heap `f` and update `fsum`
   - Otherwise, compare `a` with the minimum of heap `l`:
     - If `a` is larger, move the minimum from `l` to `f`, insert `a` into `l`, and update both sums accordingly
     - Otherwise, insert `a` directly into `f` and update `fsum`
2. If heap `f` is larger (by one element):
   - Compare `a` with the maximum of heap `f`:
     - If `a` is greater or equal, insert `a` into `l` and update `lsum`
     - Otherwise, move the maximum from `f` to `l`, insert `a` into `f`, and update both sums

After the insertion logic, the second long integer from input is added to `B`.

### Query Operation (com == 2)
The median is always the maximum of heap `f` (variable `x`). The output depends on heap sizes:
- If heaps are equal size: output `x` and `(lsum - fsum + B)`
- If heap `f` is larger: output `x` and `(lsum - fsum + x + B)`

## Helper Methods
The `InputReader` class provides methods for reading primitive types from an input stream:
- `nextInt()`: Parses integers, handling optional minus signs and throwing exceptions on invalid input
- `nextLong()`: Similar to `nextInt()` but for long values
- `next()`: Reads a string token
- `hasNext()`: Checks for available input
- Internal byte-reading methods handle buffering and whitespace skipping

## Exception Handling
- `InputMismatchException` is thrown for invalid numeric input or I/O errors
- `NoSuchElementException` is thrown when attempting to read past available input

## Program Entry
The `main` method initializes the input reader and output writer, calls `solve()`, then flushes the output buffer.
