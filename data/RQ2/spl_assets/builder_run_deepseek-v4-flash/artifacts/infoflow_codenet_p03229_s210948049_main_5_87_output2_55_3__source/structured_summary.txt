## Input
- Reads an integer N from standard input.
- Then reads N integers, one per line, into a list A.

## Initial Processing
- Sorts the list A in ascending order.
- Creates a boolean/flag array `used` of length N, initialized to all zeros.

## Output Variables
- Two accumulators: `output1` and `output2`, both initialized to 0.
- The final result printed is the maximum of these two accumulators.

## First Computation (output1)
- Initializes two pairs of indices:
  - Pair 1: i1 = 0 (smallest), j1 = N-1 (largest)
  - Pair 2: i2 = 0, j2 = N-2 (second largest)
- Marks all four initial indices as used.
- Two active flags: f1 and f2, both initially True.

### Loop for output1
- Continues while either f1 or f2 is True.
- In each iteration:
  1. If f1 is True, adds (A[j1] - A[i1]) to output1.
  2. If f2 is True, adds (A[j2] - A[i2]) to output1.
  3. Advances i1 to the next unused index (incrementing from current position). If i1 reaches N-1, sets f1 to False.
  4. Marks the new i1 as used.
  5. Advances i2 similarly. If i2 reaches N-1, sets f2 to False.
  6. Marks the new i2 as used.
  7. If f1 is still True, adds (A[j1] - A[i1]) to output1 again.
  8. If f2 is still True, adds (A[j2] - A[i2]) to output1 again.
  9. Advances j1 to the previous unused index (decrementing from current position). If j1 reaches 0, sets f1 to False.
  10. Marks the new j1 as used.
  11. Advances j2 similarly. If j2 reaches 0, sets f2 to False.
  12. Marks the new j2 as used.

## Second Computation (output2)
- Resets indices:
  - Pair 1: i1 = 0, j1 = N-1
  - Pair 2: i2 = 1, j2 = N-1
- Resets flags f1 and f2 to True.
- Resets the `used` array to all zeros.
- Marks all four initial indices as used.

### Loop for output2
- Continues while either f1 or f2 is True.
- In each iteration:
  1. If f1 is True, adds (A[j1] - A[i1]) to output2.
  2. If f2 is True, adds (A[j2] - A[i2]) to output2.
  3. Advances j1 to the previous unused index (decrementing). If j1 reaches 0, sets f1 to False.
  4. Marks the new j1 as used.
  5. Advances j2 similarly. If j2 reaches 0, sets f2 to False.
  6. Marks the new j2 as used.
  7. If f1 is still True, adds (A[j1] - A[i1]) to output2 again.
  8. If f2 is still True, adds (A[j2] - A[i2]) to output2 again.
  9. Advances i1 to the next unused index (incrementing). If i1 reaches N-1, sets f1 to False.
  10. Marks the new i1 as used.
  11. Advances i2 similarly. If i2 reaches N-1, sets f2 to False.
  12. Marks the new i2 as used.

## Output
- Prints the maximum of output1 and output2.

## Key Data Dependencies
- Both computations depend on the sorted array A.
- The `used` array tracks which indices have been consumed in each computation.
- The index advancement logic depends on the `used` array state.
- The flags f1 and f2 control whether each pair continues to contribute to the sum.
- The order of operations differs between the two computations: output1 advances low indices first, then high indices; output2 advances high indices first, then low indices.
