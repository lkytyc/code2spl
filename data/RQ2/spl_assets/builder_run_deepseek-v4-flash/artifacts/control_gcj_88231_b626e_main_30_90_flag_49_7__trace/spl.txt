[DEFINE_WORKER: "Reads N test cases; for each integer, prints the integer unchanged if it has no decimal digit 4, otherwise prints the integer formed by replacing every digit 4 with 3 and the difference between the original and that replacement." main]
    [INPUTS]
    [END_INPUTS]

    [OUTPUTS]
    [END_OUTPUTS]

    [MAIN_FLOW]
        [SEQUENTIAL_BLOCK]
            [COMMAND Initialize N to 0, then read the first integer from stdin into N; if scanf does not successfully read an integer, leave N at 0. RESULT N]
            [COMMAND Set j to 1 and enter a for loop that repeats while j <= N (inclusive); each iteration processes test case number j. RESULT j]
            [COMMAND Within the for loop, initialize flag to 0 and num to 0, then read an integer from stdin into num; if scanf fails, num remains 0. RESULT num_and_flag]
            [COMMAND Within the for loop, scan num's decimal digits by setting temp=num and repeating: four=temp%10; if four==4 set flag=1 and break; then set temp=temp/10, continuing while temp!=0. This uses C remainder semantics, so negative remainders are never equal to 4. RESULT flag]
            [COMMAND Within the for loop, if flag is still 0, print "Case #%d: %d\n" with j and num, then continue to the next iteration. RESULT none]
            [COMMAND Within the for loop, if flag is 1, execute the transformed-output path described in the alternative flow for flag equals true. RESULT none]
            [COMMAND After the for loop exits, return 0 from main. RESULT none]
        [END_SEQUENTIAL_BLOCK]
    [END_MAIN_FLOW]

    [ALTERNATIVE_FLOW: flag is true, meaning the digit scan found at least one decimal digit equal to 4 in num]
        [SEQUENTIAL_BLOCK]
            [COMMAND Within the flag-true branch, count the decimal digits of num by initializing temp=num and count=0, then incrementing count and dividing temp by 10 until temp becomes 0. RESULT count]
            [COMMAND Within the flag-true branch, fill integer array a of length count with the decimal digits of num in least-significant-first order by repeatedly storing temp%10 into a[i++] and dividing temp by 10 until temp becomes 0. RESULT digits_array_a]
            [COMMAND Within the flag-true branch, build integer array b of length count from a by setting b[k]=3 when a[k]==4 and b[k]=a[k] otherwise, for k from 0 to count-1. RESULT mapped_array_b]
            [COMMAND Within the flag-true branch, reconstruct temp1 from the mapped digits by iterating i from count-1 down to 0 and setting temp1 = temp1*10 + b[i]; this forms the number with every digit 4 replaced by 3. RESULT temp1]
            [COMMAND Within the flag-true branch, print "Case #%d: %d %d\n" using the current j, temp1, and num-temp1. RESULT none]
        [END_SEQUENTIAL_BLOCK]
    [END_ALTERNATIVE_FLOW]

[END_WORKER]
