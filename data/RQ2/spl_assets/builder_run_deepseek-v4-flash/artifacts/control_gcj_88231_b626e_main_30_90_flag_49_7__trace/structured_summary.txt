# Structured Description of Code

## Overview
This program processes a series of test cases, each containing an integer. For each integer, it checks whether the digit 4 appears in the number. If it does, the program splits the number into two positive integers such that neither contains the digit 4, and their sum equals the original number. If the number does not contain the digit 4, it simply outputs the number as-is.

## Inputs
- First input: an integer `N` representing the number of test cases.
- Following `N` lines: each contains an integer `num` to be processed.

## Outputs
- For each test case `j` (1-indexed):
  - If the number contains the digit 4: prints `Case #j: A B` where `A` and `B` are two numbers that sum to the original number, and neither contains the digit 4.
  - If the number does not contain the digit 4: prints `Case #j: num` (the original number alone).

## Function: `fun(int n)`
- **Purpose**: Determines if a number contains the digit 4.
- **Input**: Integer `n`.
- **Logic**: 
  - Loops while `n` is non-zero.
  - Extracts the last digit using modulo 10.
  - If the digit equals 4, returns 1 (true).
  - Otherwise, removes the last digit by integer division by 10.
- **Output**: Returns 1 if digit 4 is present, otherwise returns 0.
- **Note**: This function is defined but not called in the main program.

## Function: `find(int n)`
- **Purpose**: Finds the position (from the right, 0-indexed) of the first occurrence of digit 4 in a number.
- **Input**: Integer `n`.
- **Logic**:
  - Loops while `n` is non-zero.
  - Extracts the last digit.
  - If the digit equals 4, returns the current count (position).
  - Otherwise, removes the last digit and increments count.
- **Output**: Returns the position of the first digit 4 from the right (0-indexed).
- **Note**: This function is defined but not called in the main program.

## Main Program Flow

### Initialization
- Declares integer `N` and reads it from standard input.
- Declares loop counters `j` and `k`.

### Main Loop (for each test case)
- Iterates `j` from 1 to `N` inclusive.
- For each iteration:
  - Declares local variables: `flag2`, `flag`, `num`, `num1`, `num2`, `temp`, `four`, `prime`.
  - Reads integer `num` from standard input.
  - Sets `temp = num` and `prime = 1`.

### Digit 4 Detection
- Enters a while loop that continues while `temp` is non-zero.
- Extracts the last digit of `temp` using modulo 10.
- If the digit equals 4:
  - Sets `flag = 1`.
  - Breaks out of the loop.
- Otherwise, removes the last digit by dividing `temp` by 10.

### Branch: Number Contains Digit 4 (flag is true)
- Declares local variables `k`, `count`, `i`.
- Sets `temp = num`.
- Uses a do-while loop to count the number of digits:
  - Increments `count`.
  - Divides `temp` by 10.
  - Continues while `temp` is non-zero.
- Declares array `a` of size `count`.
- Sets `temp = num`.
- Uses a do-while loop to extract digits into array `a`:
  - Stores `temp % 10` at index `i`.
  - Increments `i`.
  - Divides `temp` by 10.
  - Continues while `temp` is non-zero.
  - Note: This stores digits in reverse order (least significant first).

### Digit Replacement
- Declares array `b` of size `count`.
- Loops `k` from 0 to `count-1`:
  - If `a[k]` equals 4, sets `b[k] = 3`.
  - Otherwise, sets `b[k] = a[k]`.

### Number Reconstruction
- Declares `temp1 = 0`.
- Loops `i` from `count-1` down to 0:
  - Multiplies `temp1` by 10 and adds `b[i]`.
  - This reconstructs the number with all 4s replaced by 3s, in correct digit order.
