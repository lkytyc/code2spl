# Code Description

## Function: solve(int T)

### Inputs
- Reads an integer `U` from standard input using `scanf("%d", &U)`.
- Then reads exactly 10,000 pairs of strings `M` and `R` from standard input using `scanf("%s %s", M, R)`.

### Local Data Structures
- `MC[26]`: An integer array initialized to 10 for all 26 elements. This tracks the minimum leading digit observed for each letter.
- `O[26]`: An integer array initialized to 0 for all 26 elements. This tracks which letters have been observed.
- `out[10]`: A character array used to build the output string.
- `R[U]` and `M[U]`: Character arrays to store the two input strings per iteration.
- Integer variables `lr` and `lm` store string lengths.

### Processing Loop (10,000 iterations)
For each iteration:
1. Reads strings `M` and `R`.
2. Computes lengths of both strings.
3. Marks the last character of `R` as observed by setting `O[R[lr-1]-'A'] = 1`.
4. If the lengths of `M` and `R` are equal:
   - Marks the first character of `R` as observed.
   - Updates `MC` for that first character to the minimum of its current value and the first digit of `M` (converted from character to integer).

### Output Construction
- Iterates through all 26 letters (index 0 to 25).
- For each letter that was observed (`O[i]` is non-zero), places that letter into the `out` array at position `MC[i] % 10`.
- Prints the result as `Case #%d: %s` with the case number `T` and the `out` string.

## Function: main()

### Inputs
- Reads an integer `T` from standard input.

### Control Flow
- Stores the original value of `T` in `_T`.
- Loops `T` times using a while loop that decrements `T` each iteration.
- In each iteration, calls `solve(_T - T)`.
  - When `T` equals `_T` (first iteration), the argument is 0.
  - When `T` reaches 0 (last iteration), the argument is `_T - 1`.

### Output
- Returns 0 after all iterations complete.

## Data Dependencies
- The `out` array is not explicitly null-terminated before printing, so its contents depend on the values written during the loop and any uninitialized positions.
- The `MC` array values are used as indices into `out` via modulo 10 operation.
- The `O` array determines which letters get written to `out`.

## Key Behavioral Notes
- The function assumes exactly 10,000 input pairs will be provided regardless of the value of `U`.
- The output string length is not explicitly set; it relies on the `%s` format specifier reading until a null character, which may not be present in the `out` array.
