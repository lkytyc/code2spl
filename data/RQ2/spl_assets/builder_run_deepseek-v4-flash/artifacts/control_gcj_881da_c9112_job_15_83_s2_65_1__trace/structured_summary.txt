# Structured Description

## Overview
This program reads a series of test cases, each containing an integer and a string, and outputs a transformed string based on the input. The transformation involves analyzing character patterns in the input string and generating a new string of 'E' and 'S' characters.

## Global Variables
- `moves[50000]`: An integer array used to store counts of consecutive identical characters in the input string.
- `in_str[100000]`: A character array used to store the input string for each test case.

## Function: `main()`
### Input
- Reads an integer `t` from standard input, representing the number of test cases.

### Processing
- Loops through each test case from 1 to `t`.
- For each test case, prints "Case #i: " (where `i` is the test case number).
- Calls the `job()` function to process the current test case.
- Prints a newline after each test case.

### Output
- For each test case, prints "Case #i: " followed by the output of `job()` and a newline.

## Function: `job()`
### Local Variables
- `ggg`: Character initialized to the XOR of 'E' and 'S' (which is a control character).
- `n`: Integer for the length of the input string (doubled and reduced by 2).
- `goodp`: Integer tracking a position, initialized to -1.
- `movesp`: Integer tracking the current position in the `moves` array, initialized to 0.
- `cur`: Character tracking the current expected character, initialized to 'E'.

### Input
- Reads an integer `n` and a string `in_str` from standard input.
- Recalculates `n` as `n*2 - 2`.

### Processing
1. Initializes `moves[0]` to 0.
2. Loops through each character of `in_str` from index 0 to `n-1`:
   - If the current character differs from `cur`:
     - Toggles `cur` using XOR with `ggg`.
     - Sets `moves[movesp+1]` to 1 and increments `movesp`.
   - Otherwise (character matches `cur`):
     - Increments `moves[movesp]`.
     - Updates `goodp` to `movesp` if a parity condition is met (based on `moves[0]` and the loop index parity).

3. Sets `parity` to `movesp`, and increments it if `moves[0]` is non-zero.

4. **If `parity` is even:**
   - Calculates `En` as the sum of `moves` at even indices (0, 2, 4, ... up to `movesp`).
   - If `moves[0]` is 0:
     - Prints 'E' `En` times, then 'S' `(n - En)` times.
   - Otherwise:
     - Prints 'S' `(n - En)` times, then 'E' `En` times.

5. **If `parity` is odd:**
   - Initializes four counters: `s1`, `s2`, `e1`, `e2` to 0.
   - Sums `moves` at even indices before `goodp` into `e1`.
   - Sums `moves` at odd indices before `goodp` into `s1`.
   - Sums `moves` at even indices from `2*((goodp+1)/2)` to `movesp` into `e2`.
   - Sums `moves` at odd indices from `2*(goodp/2)+1` to `movesp` into `s2`.
   - If `moves[0]` is 0:
     - Prints 'E' `(e1 + 1)` times (loop from -1 to e1-1).
     - Prints 'S' `(s1 + s2)` times.
     - Prints 'E' `(e2 - 1)` times (loop from 1 to e2-1).
   - Otherwise:
     - Prints 'S' `(s1 + 1)` times (loop from -1 to s1-1).
     - Prints 'E' `(e1 + e2)` times.
     - Prints 'S' `(s2 - 1)` times (loop from 1 to s2-1).

### Output
- Prints a sequence of 'E' and 'S' characters to standard output based on the logic above.
