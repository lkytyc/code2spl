## Overview
This program implements an online algorithm that maintains a dynamic multiset of numbers and answers queries about the median and a cost metric. It processes a sequence of operations: inserting numbers with associated costs, and querying the current median along with a computed value.

## Input
The program reads from standard input using a custom `InputReader` class. The first integer read is `Q`, the number of operations to process. Each subsequent operation begins with an integer command:
- Command `1`: Insert operation, followed by a long integer value `a` and a long integer cost `B`
- Command `2`: Query operation, with no additional parameters

## Output
For each query operation (command `2`), the program outputs a line containing two values separated by a space: the current median value and a computed cost value.

## Data Structures
- `f`: A max-heap (priority queue with reverse ordering) storing the smaller half of inserted values
- `l`: A min-heap (standard priority queue) storing the larger half of inserted values
- `fsum`: Running sum of all values currently in heap `f`
- `lsum`: Running sum of all values currently in heap `l`
- `B`: Accumulated sum of all costs from insert operations

## Control Flow

### Main Loop
The program processes `Q` operations in a while loop that decrements `Q` after each iteration.

### Insert Operation (command 1)
The insertion logic maintains the invariant that heap `f` contains either the same number of elements as heap `l`, or exactly one more element.

**Case: `f.size() == l.size()`**
- If both heaps are empty: Add `a` to heap `f` and update `fsum`
- Otherwise, examine the minimum element `x` in heap `l`:
  - If `x < a`: Move `x` from `l` to `f`, add `a` to `l`. Update sums: `lsum` increases by `a - x`, `fsum` increases by `x`
  - Otherwise: Add `a` directly to `f` and update `fsum`

**Case: `f.size() != l.size()`** (meaning `f` has one more element)
- Examine the maximum element `x` in heap `f`:
  - If `x <= a`: Add `a` directly to `l` and update `lsum`
  - Otherwise: Move `x` from `f` to `l`, add `a` to `f`. Update sums: `lsum` increases by `x`, `fsum` changes by `a - x`

After the heap operations, add the cost `B` to the running total.

### Query Operation (command 2)
- Get the maximum element `x` from heap `f` (this is the median)
- If `f.size() == l.size()`: Output `x` and `(lsum - fsum + B)`
- Otherwise (f has one more element): Output `x` and `(lsum - fsum + x + B)`

## Helper Methods
The `InputReader` class provides methods for reading primitive types from an input stream:
- `hasNextByte()`: Checks if more bytes are available, handling buffer refills
- `readByte()`: Returns the next byte or -1 if end of stream
- `isSpaceChar(int c)`: Returns true for non-printable ASCII characters (outside range 33-126)
- `skip()`: Advances past whitespace characters
- `hasNext()`: Checks if there's another token
- `next()`: Reads the next string token
- `nextInt()`: Parses the next integer, handling optional minus sign
- `nextLong()`: Parses the next long integer, handling optional minus sign
- `nextDouble()`: Parses the next double
- `nextIntArray(int n)`: Reads an array of n integers
- `nextLongArray(int n)`: Reads an array of n long integers
- `nextCharMap(int n, int m)`: Reads an n×m character grid

## Error Handling
- `InputMismatchException` is thrown for invalid numeric input or I/O errors
- `NoSuchElementException` is thrown when attempting to read past the end of input

## Main Method
The `main` method initializes the input reader with `System.in`, creates a `PrintWriter` for `System.out`, calls `solve()`, and flushes the output buffer.

## Additional Utilities
A `tr` method is defined for debugging purposes, which prints arrays using deep string conversion and flushes output.
