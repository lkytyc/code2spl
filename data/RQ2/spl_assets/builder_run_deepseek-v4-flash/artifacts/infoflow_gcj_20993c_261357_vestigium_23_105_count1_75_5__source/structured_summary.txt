## Program Overview
This program reads multiple square matrices from standard input, computes a trace and duplicate detection metric for each, and outputs formatted results. It processes a variable number of test cases.

## Input
- First integer `t`: number of test cases
- For each test case:
  - Integer `n`: matrix dimensions (n×n)
  - `n²` integers: matrix elements read row by row

## Output
For each test case, one line printed to standard output with format:
`Case #<case_number>:  <trace> <row_metric> <column_metric>`

## Main Control Flow
1. Read test case count `t`
2. Loop `t` times (decrementing `t` each iteration):
   - Read matrix size `n`
   - Allocate n×n integer array
   - Read all matrix elements via nested loops
   - Call `vestigium(a, n)` function
3. Program ends after all test cases processed

## vestigium Function Logic

### Trace Calculation
- Initialize `k = 0`
- Loop through diagonal elements `a[i][i]` for `i = 0` to `n-1`
- Accumulate sum into `k`

### Matrix Transposition
- Create new n×n array `b`
- For each position `[i][j]`, assign `b[i][j] = a[j][i]`
- This creates the transpose of the original matrix

### Row Duplicate Detection
- Sort each row of matrix `a` in ascending order using `Arrays.sort()`
- For each row, compare adjacent elements:
  - If equal, increment `repeat` counter
  - Track maximum `repeat` value in `count`
- Reset `repeat` to 0 after each row if it was positive
- After processing all rows, set `r = count + 1`

### Column Duplicate Detection
- Sort each row of transposed matrix `b` in ascending order
- Apply same adjacent-element comparison logic
- Track maximum duplicates in `count1`
- After processing, set `c = count1 + 1`

### Output Formatting Logic
Initialize `counter = 1` (note: this is reset for each function call)

Four conditional branches:
1. **No duplicates anywhere** (`count1 == 0 && count == 0`): Output trace, `count`, `count1` (both 0)
2. **Duplicates in both rows and columns**: Output trace, `r`, `c`
3. **Duplicates only in rows** (`count1 == 0 && count != 0`): Output trace, `r`, `count1` (0)
4. **Duplicates only in columns** (`count1 != 0 && count == 0`): Output trace, `count` (0), `c`

## Data Dependencies
- `k` depends only on diagonal elements of original matrix
- `count` depends on sorted rows of original matrix
- `count1` depends on sorted rows of transposed matrix
- Output values depend on both duplicate counts and trace
- The `counter` variable is always 1 when used (not incremented across test cases)

## Notable Behavior
- The duplicate counting logic counts consecutive equal elements after sorting, so it detects any repeated values in a row/column
- The `+1` adjustment to `r` and `c` means these values are always at least 1
- The output format includes an extra space after the colon
- The counter variable does not persist across test cases, so all cases print as "Case #1"
