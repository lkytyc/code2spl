[DEFINE_WORKER: "Reads directed graph test cases until EOF and, for each query, uses a priority-queue search with a remaining-hop bound to find and print the shortest path length in nodes from source to destination, or NA if no path is found." AOJ0144]
    [INPUTS]
    [END_INPUTS]

    [OUTPUTS]
    [END_OUTPUTS]

    [MAIN_FLOW]
        [SEQUENTIAL_BLOCK]
            [COMMAND While the scanner sc has more tokens, process each test case until EOF. RESULT test_case_loop]
            [COMMAND Read integer N as the number of nodes in the current test case. RESULT N]
            [COMMAND Initialize a boolean adjacency matrix R of size (N+1) by (N+1) with all entries false. RESULT R]
            [COMMAND For i from 1 to N inclusive, read the current graph row: r is the source node and k is the number of outgoing edges. RESULT r,k]
            [COMMAND Within the current graph row, for j from 0 to k-1 inclusive, read a destination node t and set R[r][t] to true. RESULT R]
            [COMMAND After reading all rows, read integer P as the number of queries for this test case. RESULT P]
            [COMMAND For each query index qi from 0 to P-1, process the following query steps. RESULT query_loop]
            [COMMAND For the current query, read s as the source node, d as the destination node, and v as the path allowance, and initialize ans to -1. RESULT s,d,v,ans]
            [COMMAND For the current query, create an empty priority queue open of C0144 states and add the starting state new C0144(s, v, 1). RESULT open]
            [COMMAND For the current query, create a C0144 array close of length N+1, initially all null. RESULT close]
            [COMMAND While open is not empty, poll the next state now from open. RESULT now]
            [COMMAND Within the open search loop, decrement now.ttl by 1; if the decremented ttl equals 0, skip the rest of the current iteration and continue with the next state in open; otherwise use the decremented ttl in the following neighbor scan. RESULT pruned]
            [COMMAND Within the open search loop for each state now, iterate j from 1 to N inclusive and test whether R[now.now][j] is true. RESULT neighbor_candidate]
            [COMMAND Within the neighbor scan, if R[now.now][j] is true and close[j] is null and j equals d, set ans to now.c + 1 if ans is -1, otherwise keep min(ans, now.c + 1), and continue without enqueuing j. RESULT ans]
            [COMMAND Within the neighbor scan, if R[now.now][j] is true and close[j] is null and j is not d, add new C0144(j, now.ttl, now.c + 1) to open and store that state in close[j]. RESULT open, close]
            [COMMAND Within the neighbor scan, if R[now.now][j] is true and close[j] is not null and the improvement condition (now.c + 1 < close[j].c or now.ttl > close[j].ttl) holds and j equals d, set ans to now.c + 1 if ans is -1, otherwise keep min(ans, now.c + 1), and continue without enqueuing j. RESULT ans]
            [COMMAND Within the neighbor scan, if R[now.now][j] is true and close[j] is not null and the improvement condition (now.c + 1 < close[j].c or now.ttl > close[j].ttl) holds and j is not d, add new C0144(j, now.ttl, now.c + 1) to open and store that state in close[j]. RESULT open, close]
            [COMMAND After the open search loop ends for the current query, if ans is at least 0 print ans, otherwise print NA. RESULT printed_output]
        [END_SEQUENTIAL_BLOCK]
    [END_MAIN_FLOW]

[END_WORKER]
