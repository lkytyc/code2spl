# Structured Description of Code

## Class Overview
The `Main` class contains multiple problem-solving methods (AOJ0144, AOJ0145, AOJ0147) and supporting inner classes. It uses a `Scanner` for input and static imports for `Math` functions and `System.out`.

## Global Fields
- `sc`: A `Scanner` object for reading input
- `vx`, `vy`: Integer arrays representing directional vectors (0,1,0,-1) and (-1,0,1,0) respectively

## Inner Class: Point
- Fields: `x`, `y` (integers)
- Constructors: Parameterized (x,y) and default (0,0)
- `toString()`: Returns formatted string "(x,y)"
- Static method `ok(x,y,X,Y,min)`: Returns true if x is in range [min, X) and y is in range [min, Y)
- Static method `ok(x,y,X,Y)`: Calls the 5-parameter version with min=0

## Inner Class: C0145
- Fields: `upper`, `down` (integers)
- Constructor: Takes two integers and assigns to fields

## Inner Class: C0144
- Fields: `now`, `ttl`, `c` (integers)
- Constructor: Takes three integers and assigns to fields
- Implements `Comparable<C0144>`: Compares based on `c` field only (lower `c` comes first)

## Method: main
- Creates a new `Main` instance and calls `AOJ0144()`

## Method: AOJ0145
- Loops while scanner has more input
- Reads integer N
- Initializes answer to `Integer.MAX_VALUE`
- Creates array of N `C0145` objects, reading two integers for each
- Prints the answer (always `Integer.MAX_VALUE` as printed)

## Method: AOJ0147
- Creates a `LinkedList<Integer>` for queue
- Sets MAX to 120 initially
- Reads all integers from input, updating MAX to the maximum value seen, and adds each to queue
- Creates arrays: `num` (size MAX), `time` (size MAX), `seat` (size 17)
- Fills `seat` array with -1
- For each index i from 0 to MAX-1:
  - `num[i]` = 5 if i%5==1, otherwise 2
  - `time[i]` = 17*(i%2) + 3*(i%3) + 19
- Initializes j=0, min=0
- While queue is not empty:
  - Calls `exit(seat, min, time)` to free seats
  - Calls `find(seat, num[j])` to find available space
  - If space found AND min >= j*5:
    - Gets first element from queue
    - If j equals that element, prints max(0, min - j*5) and removes from queue
    - Occupies seats from temp to temp+num[j]-1 with value j
    - Increments j
  - Otherwise: increments min

## Method: find
- Parameters: `seat` array, integer `n`
- Loops i from 0 to 17-n
- For each i, checks if n consecutive seats (i to i+n-1) are all -1
- Returns first i where all are free, otherwise returns -1

## Method: exit
- Parameters: `seat` array, integer `min`, `time` array
- For each seat index 0 to 16:
  - If seat is -1, skips
  - Otherwise, calculates exit time as idx*5 + time[seat[i]]
  - If min >= exit time, sets seat to -1
- Returns the modified seat array

## Method: disp
- Parameters: `seat` array, integer `min`
- Prints min followed by "m : " and all seat values separated by spaces

## Method: AOJ0144
- Loops while scanner has more input
- Reads integer N
- Creates boolean matrix R of size (N+1) x (N+1), all false
- For each i from 1 to N:
  - Reads r and k
  - For j from 0 to k-1: reads a value and sets R[r][value] = true
- Reads integer P
- For each of P queries:
  - Reads s, d, v
  - Initializes ans = -1
  - Creates PriorityQueue of C0144 objects
  - Adds initial state: C0144(s, v, 1)
  - Creates close array of C0144 objects (size N+1)
  - While queue is not empty:
    - Poll
