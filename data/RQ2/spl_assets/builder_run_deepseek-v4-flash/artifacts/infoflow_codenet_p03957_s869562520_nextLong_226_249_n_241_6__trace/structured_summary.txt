# Structured Description

## Class: UnionFind
- **Input**: Constructor takes an integer `n` representing the number of elements.
- **State**: Maintains an integer array `Parent` where negative values indicate a root node and the absolute value represents the size of that set.
- **Operations**:
  - `root(int A)`: Recursively finds the root of element `A`, applying path compression by updating the parent of each visited node to point directly to the root.
  - `size(int A)`: Returns the size of the set containing `A` by negating the parent value of the root.
  - `connect(int A, int B)`: Unions the sets containing `A` and `B`. Returns `false` if they are already in the same set, otherwise merges them using union-by-size (larger set becomes parent of smaller set) and returns `true`.

## Class: Main

### Static Fields
- `scan`: A `FastScanner` instance for fast input reading.
- `scanner`: A standard `Scanner` instance.
- `rand`: A `Random` instance.
- `mod`: Constant value 1000000007.
- `eps`: Constant value 0.0000000001.
- `big`: Constant value equal to `Integer.MAX_VALUE`.

### Static Utility Methods
- `modlcm(a, b)`: Computes `a * b * modint(gcd(a,b), mod)`.
- `gcd(a, b)`: Recursively computes the greatest common divisor; returns `a` when `b` is zero.
- `lcm(a, b)`: Computes least common multiple as `a * b / gcd(a, b)`.
- `max(a, b)` / `min(a, b)`: Return the larger/smaller of two integers.
- `lmax(a, b)` / `lmin(a, b)`: Return the larger/smaller of two longs using `Math.max`/`Math.min`.
- `factorial(i)`: Recursively computes factorial; base case returns 1 when `i` equals 1.

### Main Method
- **Input**: Reads a single string `str` from the fast scanner.
- **Logic**: Iterates through each character of the string. Sets a boolean flag `b` to `true` when the character `'C'` is encountered. If the flag is already `true` and the current character is `'F'`, prints `"Yes"` and terminates the program.
- **Output**: If the loop completes without finding `'C'` followed by `'F'`, prints `"No"`.

### Additional Static Methods
- `lower_bound(a[], key)`: Binary search on a sorted integer array; returns the leftmost index where the value is less than `key`.
- `upper_bound(a[], key)`: Binary search on a sorted integer array; returns the leftmost index where the value is less than or equal to `key`.
- `isPrime(n)`: Returns `true` if `n` is 2, `false` if `n` is less than 2 or even, otherwise checks divisibility by odd numbers up to the square root.
- `upper_division(a, b)`: Integer division that rounds up; returns `a/b` if divisible, otherwise `a/b + 1`.
- `lupper_division(a, b)`: Long version of `upper_division`.
- `setArray(a)`: Reads `a` integers from the fast scanner and returns them as an array.
- `lsetArray(a)`: Reads `a` longs from the fast scanner and returns them as an array.
- `reverce(str)`: Reverses a string by iterating from the last character to the first and concatenating.
- `printArray(que)`: Prints an integer array with spaces between elements and a newline after the last element.
- `doublesort(a[][])`: Sorts a 2D integer array by the first column in ascending order.
- `ldoublesort(a[][])`: Sorts a 2D long array by the first column in ascending order.
- `modpow(x, n, mo)`: Computes `x^n` modulo `mo` using fast exponentiation (binary exponentiation).
- `revch(ch[])`: Returns a new character array with elements in reverse order.
- `revint(ch[])`: Returns a new integer array with elements in reverse order.
- `warshall_floyd(v[][], n)`: Performs the Floyd-Warshall algorithm on an `n x n` adjacency matrix, updating each cell to the minimum path distance.
- `modint(a, m)`: Computes the modular inverse of `a` modulo `m` using the extended Euclidean algorithm.
