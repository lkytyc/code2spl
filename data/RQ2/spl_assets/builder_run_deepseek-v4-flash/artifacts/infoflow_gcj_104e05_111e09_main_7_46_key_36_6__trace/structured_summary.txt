# Code Structure Description

## Overview
This Java file contains two classes: `Solution` and `Longest_common_substr`. Both classes have `main` methods and process word lists from standard input.

## Class: Solution

### Input
- Reads an integer `tc` from standard input representing the number of test cases
- For each test case, reads an integer `noOfWords` representing the number of words
- Reads `noOfWords` strings from standard input

### Processing
- Stores all words in a `TreeSet` (automatically sorted, duplicates removed)
- Creates two iterators over the same set
- Uses a counter `c1` to track position in the first iterator
- For each word from the first iterator, uses a second iterator to compare against other words
- Uses a counter `c2` to track position in the second iterator
- Only processes pairs where `c1 != c2` (different positions)
- For each valid pair, attempts to find the longest common substring between the two words
- The substring search iterates through all possible substrings of the second word and checks if they are contained in the first word
- Tracks the maximum length substring found and stores it in `key`

### Output
- No output is produced by this class

### Notable Behavior
- The second iterator is never reset between iterations of the outer loop
- The `result` variable is declared but never used
- The `key` variable is assigned but never used
- The inner substring search has a `break` statement that exits the inner loop when a substring is not found

## Class: Longest_common_substr

### Method: printLCSubStr
**Parameters:** Two strings `X` and `Y`, and their lengths `m` and `n`

**Processing:**
- Creates a 2D dynamic programming table `LCSuff` of size (m+1) × (n+1)
- Fills the table using standard longest common substring algorithm:
  - First row and column are initialized to 0
  - If characters match, takes diagonal value plus 1
  - If characters don't match, sets value to 0
- Tracks the maximum length found and its position (row, col)
- If maximum length is 0, returns 0
- Otherwise, reconstructs the substring by tracing back through the table
- Returns the length of the longest common substring

### Main Method

**Input:**
- Reads an integer `tc` from standard input representing the number of test cases
- For each test case, reads an integer `noOfWords`
- Reads `noOfWords` strings from standard input

**Processing:**
- Stores all words in a `TreeSet`
- Creates two iterators over the set
- For each word from the first iterator:
  - Initializes `max` to 0 and empty strings `key1` and `key2`
  - Checks if current word equals `key1`; if so, removes it and returns immediately
  - Iterates through all words from the second iterator:
    - Checks if current word equals `key2`; if so, removes it and returns immediately
    - Calls `printLCSubStr` to find longest common substring length between the two words
    - Updates `max`, `key1`, and `key2` if a longer substring is found
  - Adds `max` to running total `result`

**Output:**
- Prints "Case #i: result" for each test case, where `i` is the test case number (starting from 1)

### Notable Behavior
- The second iterator is never reset between iterations of the outer loop
- The `return` statements inside the loops cause immediate termination of the entire program when triggered
- The duplicate-check logic using `key1` and `key2` appears to be an incomplete or incorrect deduplication mechanism
