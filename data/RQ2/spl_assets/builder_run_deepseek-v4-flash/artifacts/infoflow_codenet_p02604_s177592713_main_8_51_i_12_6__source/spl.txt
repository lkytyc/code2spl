[DEFINE_WORKER: "Reads N weighted points, precomputes subset-wise minimum horizontal and vertical coordinate distances, enumerates all ternary assignments to compute the minimum weighted cost for every possible selected count, and prints the resulting N+1 answers." main]
    [INPUTS]
    [END_INPUTS]

    [OUTPUTS]
        <REF> return_value </REF>: int "0 indicating successful completion of main."
    [END_OUTPUTS]

    [MAIN_FLOW]
        [SEQUENTIAL_BLOCK]
            [COMMAND Declare N, X, Y, P, a, Z, and ans; initialize ans[0] to 1L<<60 and the remaining ans entries to 0 via partial initialization; read one integer from standard input into N. RESULT N, ans]
            [COMMAND For each i from 0 to N-1, read three integers from standard input into X[i], Y[i], and P[i], and set ans[i+1] to 1L<<60. RESULT X, Y, P, ans]
            [COMMAND For each mask i from 0 to (1<<N)-1 and each j from 0 to N-1, initialize Z[i][j][0] to abs(X[j]) and Z[i][j][1] to abs(Y[j]). RESULT Z]
            [COMMAND Within the same nested mask i and point j loops, for each k from 0 to N-1, if bit k of mask i is set, update Z[i][j][0] to min(Z[i][j][0], (long)abs(X[j]-X[k])) and Z[i][j][1] to min(Z[i][j][1], (long)abs(Y[j]-Y[k])). RESULT Z]
            [COMMAND With a treated as a zero-initialized base-3 counter, while sentinel a[N] is zero, reset h and v to 0 and for each i from 0 to N-1 set bit i in h when a[i] is 1 and set bit i in v when a[i] is 2. RESULT h, v]
            [COMMAND For the current ternary state, compute t as the popcount of h|v and compute sum as the sum over i from 0 to N-1 of (long)P[i] times min(Z[h][i][0], Z[v][i][1]). RESULT t, sum]
            [COMMAND Advance the base-3 counter: start at index 0, while a[index] is 2 set a[index] to 0 and advance the index, then increment the first non-2 digit by 1. RESULT a]
            [COMMAND Update ans[t] to min(ans[t], sum); repeat the while loop until a[N] becomes nonzero, thereby enumerating all 3^N assignments. RESULT ans]
            [COMMAND For each i from 0 to N inclusive, print ans[i] on its own line using printf with the %ld format. RESULT stdout]
            [COMMAND Return 0 from main. RESULT return_value]
        [END_SEQUENTIAL_BLOCK]
    [END_MAIN_FLOW]

[END_WORKER]
