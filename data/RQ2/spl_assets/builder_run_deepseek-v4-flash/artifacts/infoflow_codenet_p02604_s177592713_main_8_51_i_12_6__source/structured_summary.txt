## Overview
This program computes minimum transportation costs for N facilities, where each facility can be assigned to either a horizontal or vertical axis, and the cost depends on distances to assigned axes.

## Inputs
- First line: integer N (number of facilities, max 20)
- Next N lines: three integers each - X[i], Y[i], P[i] representing x-coordinate, y-coordinate, and weight of facility i

## Outputs
- N+1 lines, each containing a long integer: the minimum total cost for using exactly k axes (where k ranges from 0 to N)

## Data Structures
- `X[20]`, `Y[20]`, `P[20]`: coordinate and weight arrays
- `a[20]`: assignment array where 0=unassigned, 1=horizontal, 2=vertical
- `Z[1<<16][16][2]`: precomputed distance table; Z[mask][j][0] = minimum horizontal distance for facility j given mask of horizontal facilities, Z[mask][j][1] = minimum vertical distance
- `ans[20]`: array storing minimum costs for each count of axes used

## Precomputation Phase (lines 16-27)
For every possible subset mask (0 to 2^N - 1) and every facility j:
- Initialize Z[mask][j][0] to absolute value of X[j] (distance to origin on x-axis)
- Initialize Z[mask][j][1] to absolute value of Y[j] (distance to origin on y-axis)
- For each facility k in the mask, update Z to be the minimum of current value and distance from facility j to facility k's coordinate

## Main Enumeration Loop (lines 28-46)
Iterates through all possible assignments using a base-3 counter in array `a`:
- Each position can be 0 (unassigned), 1 (horizontal), or 2 (vertical)
- Loop continues until a[N] becomes non-zero (all combinations exhausted)

For each assignment:
1. Build bitmasks `h` (horizontal facilities) and `v` (vertical facilities)
2. Count total axes used: `t = popcount(h|v)` - number of distinct facilities assigned to either axis
3. Compute total cost: for each facility i, add P[i] × min(horizontal distance from Z[h][i][0], vertical distance from Z[v][i][1])
4. Update ans[t] with minimum of current value and computed sum
5. Increment the base-3 counter (find rightmost non-2 digit, increment it, reset digits to its right to 0)

## Helper Function
`popcount(n)`: recursively counts set bits in integer n (returns 0 for n=0, otherwise adds least significant bit and recurses on n>>1)

## Final Output
Prints ans[0] through ans[N], each on its own line, representing minimum cost for using exactly that many axes.

## Key Dependencies
- The cost calculation depends on both the precomputed Z table and the current assignment masks
- The Z table depends only on input coordinates and is computed once before the main loop
- The enumeration order ensures all 3^N possible assignments are visited exactly once
