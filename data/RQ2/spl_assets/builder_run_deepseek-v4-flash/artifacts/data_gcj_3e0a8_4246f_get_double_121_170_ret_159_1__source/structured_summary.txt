# Structured Description

## Overview
This program reads multiple test cases from standard input, processes each one using a dynamic programming approach, and outputs a result for each case. The program includes custom input parsing functions for integers and doubles, as well as helper functions for finding maximum and minimum values.

## Inputs
- The program reads from standard input using custom parsing functions.
- First input: an integer `t` representing the number of test cases.
- For each test case:
  - An integer `n` representing the size of the problem.
  - A sequence of `n` integers stored in array `w`.

## Outputs
- For each test case, the program prints: `Case #X: Y` where X is the test case number (1-based) and Y is an integer result.

## Data Structures
- `par` structure: contains two integer fields `x` and `y` (defined but not used in the main logic).
- `w`: integer array of size `n` storing input values.
- `c`: 2D integer array of size `n` by `n`, initialized to zero.

## Main Control Flow

### Test Case Loop
- Iterates `t` times using loop variable `i`.

### Per Test Case Processing
1. Reads integer `n`.
2. Declares arrays `w` and `c` of size `n`.
3. Initializes all elements of `c` to zero using `memset`.
4. Reads `n` integers into array `w`.

### Dynamic Programming Initialization
- Sets `c[0][0]` equal to `w[0]`.
- For each column `j` from 1 to n-1: sets `c[0][j]` to the minimum of `w[j]` and `c[0][j-1]`.

### Diagonal Computation
- For each row `j` from 1 to n-1:
  - If `c[j-1][j-1]` equals -1, then `c[j][j]` is set to -1.
  - Otherwise, if `c[j-1][j-1]` is greater than `w[j] * 6`, then `c[j][j]` is set to -1.
  - Otherwise, `c[j][j]` is set to `c[j-1][j-1] + w[j]`.

### Off-Diagonal Computation
- For each row `j` from 1 to n-1:
  - For each column `k` from `j+1` to n-1:
    - If both `c[j-1][k-1]` and `c[j][k-1]` are -1, then `c[j][k]` is set to -1.
    - If only `c[j-1][k-1]` is -1:
      - If `c[j][k-1]` is greater than `w[k] * 6`, then `c[j][k]` is set to -1 (note: the code uses `==` instead of `=`, which is a bug; the value is not actually assigned).
      - Otherwise, `c[j][k]` is set to `c[j][k-1] + w[k]`.
    - If only `c[j][k-1]` is -1:
      - If `c[j-1][k-1]` is greater than `w[k] * 6`, then `c[j][k]` is set to -1 (same `==` bug).
      - Otherwise, `c[j][k]` is set to `c[j-1][k-1] + w[k]`.
    - If neither is -1:
      - Computes `tmp` as the minimum of `c[j-1][k-1]` and `c[j][k-1]`.
      - If `tmp` is greater than `w[k] * 6`, then `c[j][k]` is set to -1.
      - Otherwise, `c[j][k]` is set to `tmp + w[k]`.

### Result Extraction
- Iterates through rows `j` from 0 to n-1:
  - If `c[j][n-1]` equals -1, breaks out of the loop.
- Prints the value of `j` (the first row index where the last column is -1, or `n` if no such row exists).

## Helper Functions

### max(a, b)
- Returns `a` if `a > b`, otherwise returns `b`.

### min(a, b)
- Returns `a` if `a < b`, otherwise returns `b`.
