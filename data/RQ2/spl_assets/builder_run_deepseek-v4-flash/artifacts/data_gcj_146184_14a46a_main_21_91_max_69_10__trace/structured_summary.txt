# Code Description

## Global Variables and Types
- `N`: integer, number of moles
- `Mole`: struct with two integer fields `c` and `j`
- `arr`: array of 305 `Mole` structures

## Functions

### Abs(int a)
- Returns the absolute value of integer `a`
- If `a < 0`, returns `-1 * a`; otherwise returns `a`

### gcd(int a, int b)
- Recursive function computing greatest common divisor
- Base case: if `b == 0`, returns `a`
- Otherwise, calls itself with `gcd(b, a % b)`

## Main Function

### Input Processing
- Reads integer `T` (number of test cases)
- For each test case `t` from 1 to T:
  - Initializes `ans = 1`
  - Reads `N` (number of moles)
  - Reads `N` pairs of integers into `arr[i].c` and `arr[i].j` for i from 1 to N

### Core Logic
- Initializes `flag = 0` and `flag_big = -1`
- Iterates through consecutive pairs of moles (i from 1 to N-1, j = i+1):
  - If both `c` and `j` values of mole i are less than or equal to those of mole j, skips to next pair
  - If both `c` and `j` values of mole i are greater than or equal to those of mole j, sets `flag = 1` and breaks
  - Otherwise, computes:
    - `a` = difference in `c` values (j's c minus i's c)
    - `b` = difference in `j` values (i's j minus j's j)
  - If `flag_big` is unset (-1), determines its value:
    - If `a > 0`, sets `flag_big = 1`
    - Otherwise, sets `flag_big = 0`
  - If `flag_big == 1`:
    - If `a < 0`, sets `flag = 1` and breaks
    - Otherwise, updates `max` to the larger of current `max` and `b/a`
  - If `flag_big == 0`:
    - If `a > 0`, sets `flag = 1` and breaks
    - Otherwise, updates `max` to the larger of current `max` and `b/a`

### Output Generation
- If `flag` is set (non-zero), prints "Case #t: IMPOSSIBLE"
- Otherwise:
  - If `flag_big == -1` (no conflicting pairs found), sets `ans_c = 1` and `ans_j = 1`
  - If `flag_big == 1`, sets `ans_j = 1` and `ans_c = floor(max + 1)`
  - If `flag_big == 0`, sets `ans_c = 1` and `ans_j = floor(max + 1)`
  - Prints "Case #t: ans_c ans_j"

## Key Data Dependencies
- The `max` variable accumulates the maximum ratio `b/a` across all processed pairs
- The `flag_big` variable determines which branch of the ratio calculation is used
- The final answer depends on `flag_big` and `max` values
- The `flag` variable controls whether the result is "IMPOSSIBLE" or a valid pair

## Control Flow Summary
- Outer loop over test cases
- Inner loop over consecutive mole pairs
- Early termination via `break` when impossible conditions detected
- Conditional branching based on comparison of mole properties and computed ratios
