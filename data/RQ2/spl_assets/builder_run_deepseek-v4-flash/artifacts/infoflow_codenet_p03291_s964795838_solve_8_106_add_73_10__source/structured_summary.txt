# Code Description

## Class Structure
The code defines a `Main` class containing the primary logic, and a separate `FastScanner` class for efficient input parsing.

## Main Class Fields
- `isDebug`: A boolean flag set to `false`, controlling whether input comes from a file or standard input.
- `fileName`: A string set to `"input.txt"`, used only when debug mode is enabled.
- `sc`: A `FastScanner` instance used for reading input.

## Main Method
The `main` method creates a new `Main` instance and calls its `m()` method.

## Method `m()`
- Records the start time.
- Initializes the scanner: if `isDebug` is true, reads from a file input stream using `fileName`; otherwise reads from standard input.
- Calls `solve()`.
- If debug mode is enabled, prints a debug header and the elapsed time in milliseconds.

## Method `solve()`
This is the core computational method.

### Constants
- `INF`: Set to half of the maximum integer value.
- `MOD`: Set to 1,000,000,007.

### Input
- Reads a single string `S` from the scanner.

### Precomputation Arrays
- `sumA`, `sumC`, `sumQ`: Integer arrays of length `S.length() + 1`, storing prefix counts of characters 'A', 'C', and '?' respectively.
- `pow3`: Long array of length `S.length() + 1`, storing powers of 3 modulo `MOD`.

### Power of 3 Computation
- `pow3[0]` is initialized to 1.
- A loop from index 1 to `S.length()` computes each subsequent power of 3 by multiplying the previous value by 3 and taking modulo `MOD`.

### Prefix Sum Construction
- A loop from index 1 to `S.length()` copies previous prefix values, then increments the appropriate prefix counter based on the character at position `i-1` in the string:
  - If the character is 'A', increments `sumA[i]`.
  - If the character is 'C', increments `sumC[i]`.
  - If the character is '?', increments `sumQ[i]`.

### Main Counting Loop
- Initializes `ans` to 0.
- Iterates `i` from 2 to `S.length() - 1` (inclusive), examining the character at position `i-1` (0-indexed).

#### Case: Character at position `i-1` is 'B'
- Computes contributions to `ans` using prefix sums:
  1. **A-C combination**: Count of 'A' before position `i` multiplied by count of 'C' after position `i`, multiplied by `pow3[total question marks]`. This accounts for all ways to replace '?' characters.
  2. **A-? combination** (if at least 1 question mark exists): Count of 'A' before position `i` multiplied by count of '?' after position `i`, multiplied by `pow3[total question marks - 1]`.
  3. **?-C combination** (if at least 1 question mark exists): Count of '?' before position `i` multiplied by count of 'C' after position `i`, multiplied by `pow3[total question marks - 1]`.
  4. **?-? combination** (if at least 2 question marks exist): Count of '?' before position `i` multiplied by count of '?' after position `i`, multiplied by `pow3[total question marks - 2]`.
- Each intermediate product is taken modulo `MOD` before adding to `ans`, and `ans` is kept modulo `MOD`.
