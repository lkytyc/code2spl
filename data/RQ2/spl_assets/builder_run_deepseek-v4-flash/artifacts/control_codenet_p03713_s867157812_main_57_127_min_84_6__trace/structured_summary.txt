# Code Description

## Overview
This program reads two integers representing the height and width of a rectangle, then calculates the minimum possible difference between the largest and smallest areas when dividing the rectangle into three rectangular pieces using straight cuts.

## Input
- Two integers `h` and `w` read from standard input via `scanf("%d %d", &h, &w)`.

## Output
- A single long long integer printed with `printf("%lld\n", ans)` representing the minimum difference between the largest and smallest piece areas.

## Helper Functions

### descending_compare
- Takes two void pointers to integers.
- Returns -1 if first integer is greater than second, 0 if equal, 1 otherwise.
- Used for descending order sorting.

### ascending_compare
- Takes two void pointers to integers.
- Returns -1 if first integer is less than second, 0 if equal, 1 otherwise.
- Used for ascending order sorting.

### lower_bound
- Takes an integer array, its length, and a key value.
- Performs a binary search to find the first position where the array value is greater than or equal to the key.
- Returns the index of that position, or the array length if no such position exists.
- Uses a custom loop condition checking mid-point relationships.

### gcd
- Recursive function computing greatest common divisor of two unsigned long integers.
- Base case: returns x when y equals 0.
- Recursive cases: calls itself with (y, x % y) when x > y, otherwise with (x, y % x).

### factorial
- Computes factorial of an integer using a loop from x down to 2.
- Returns the product as a long long.

## Main Function Logic

### Initialization
- Declares integer variables `h` and `w` for dimensions.
- Declares array `square[3]` to store three piece areas.
- Declares `min`, `max`, and `ans` variables.
- Initializes `ans` to 10,000,000,000,000 (a large sentinel value).

### First Loop (Horizontal Cuts)
- Iterates `i` from 1 to h-1.
- For each `i`:
  - **Case 1**: Cuts horizontally at position `i`, then splits the remaining bottom portion vertically.
    - `square[0]` = area of top piece (i × w)
    - `square[1]` = area of bottom-left piece ((h-i) × (w/2))
    - `square[2]` = area of bottom-right piece ((h-i) × (w - w/2))
    - Finds min and max among the three areas.
    - Updates `ans` if the difference (max - min) is smaller.
  - **Case 2**: Cuts horizontally at position `i`, then splits the remaining bottom portion horizontally.
    - `square[0]` remains the same as Case 1.
    - `square[1]` = area of bottom-left piece ((h-i)/2 × w)
    - `square[2]` = area of bottom-right piece ((h-i - (h-i)/2) × w)
    - Finds min and max among the three areas.
    - Updates `ans` if the difference is smaller.

### Second Loop (Vertical Cuts)
- Iterates `i` from 0 to w-1.
- For each `i`:
  - **Case 1**: Cuts vertically at position `i`, then splits the remaining right portion vertically.
    - `square[0]` = area of left piece (i × h)
    - `square[1]` = area of top-right piece ((w-i) × (h/2))
    - `square[2]` = area of bottom-right piece ((w-i) × (h - h/2))
    - Finds min and max among the three areas.
    - Updates `ans` if the difference is smaller.
  - **Case 2**: Cuts vertically at position `i`, then splits the remaining right portion horizontally.
    - `square[0]` remains the same as Case 1.
    - `square[1]` = area of top-right piece ((w-i)/2 × h)
    - `square[2]` = area of bottom-right piece ((w-i - (w-i)/2) × h)
    - Finds min and max among the three areas.
    - Updates `ans` if the difference is smaller.

### Final Output
- Prints the minimum difference found in `ans`.
