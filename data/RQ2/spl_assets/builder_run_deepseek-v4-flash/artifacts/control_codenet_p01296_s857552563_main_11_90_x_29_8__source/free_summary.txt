This code processes multiple test cases, each describing a set of dominoes placed on a grid. Each domino occupies two adjacent cells (either horizontally or vertically) and is identified by a unique number. The program builds a graph where cells are nodes and edges connect adjacent cells belonging to different dominoes. It then performs a bipartite check on this graph by alternating between two sets of cells, following both adjacency edges and the paired cell of each domino. If any conflict is found where a cell would need to be in both sets, the answer is "No"; otherwise, it outputs "Yes" for each test case. The results for all test cases are printed, one per line.
