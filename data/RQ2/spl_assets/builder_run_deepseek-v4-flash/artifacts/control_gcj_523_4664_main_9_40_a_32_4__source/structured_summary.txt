## Overview
This program implements an interactive binary search guessing game. It reads a number of test cases, and for each test case, it attempts to guess a hidden number within a given range using feedback from the user.

## Inputs
- First line: an integer `t` representing the number of test cases.
- For each test case:
  - A line with two space-separated integers representing the lower and upper bounds of the search range.
  - A line with an integer `n` representing the maximum number of guesses allowed.
  - During the guessing loop, each guess is followed by a line of feedback from the user.

## Outputs
- For each guess made, the program prints the guessed number to standard output.
- The program terminates early if it receives feedback indicating a wrong answer.

## Constants
Four string constants are defined inside the main method:
- `TOO_BIG` – indicates the guess was too high.
- `TOO_SMALL` – indicates the guess was too low.
- `CORRECT` – indicates the guess was correct.
- `WRONG_ANSWER` – indicates an invalid response or failure condition.

## Control Flow

### Main Loop
1. Read the number of test cases `t`.
2. For each test case (indexed from 1 to `t`):
   - Parse the lower and upper bounds from the input line. The lower bound is incremented by 1 after parsing.
   - Read the maximum number of guesses `n`.
   - Enter a guessing loop that runs at most `n` times.

### Guessing Loop
- The loop condition checks `n-- > 0`, meaning it executes `n` times and decrements `n` after each check.
- Inside the loop:
  - If the lower bound equals the upper bound, the guess is that value.
  - Otherwise, the guess is the midpoint: `(upperBound - lowerBound) / 2 + lowerBound`.
  - The guess is printed to standard output.
  - The program reads a line of feedback and trims whitespace.
  - Based on the feedback:
    - If `TOO_BIG`, the upper bound is set to `guess - 1`.
    - If `TOO_SMALL`, the lower bound is set to `guess + 1`.
    - If `CORRECT`, the loop breaks immediately.
    - If any other feedback (including `WRONG_ANSWER`), the program returns from the main method, terminating execution.

## Helper Function
A separate function `guessNumber` is defined but never called from the main method. It performs the same midpoint calculation as the inline logic in the main loop:
- If the bounds are equal, it returns the lower bound.
- Otherwise, it returns `(upperBound - lowerBound) / 2 + lowerBound`.

## Data Dependencies
- The lower and upper bounds are updated based on feedback from each guess.
- The number of remaining guesses (`n`) is decremented after each iteration.
- The loop terminates when either the correct answer is found, the guess limit is exhausted, or invalid feedback is received.

## Edge Cases
- If the bounds converge to a single value, that value is guessed directly.
- If the guess limit is reached without finding the correct answer, the loop exits naturally and the program moves to the next test case.
- The program does not explicitly handle cases where the bounds become invalid (e.g., lower bound exceeding upper bound) beyond the feedback logic.
