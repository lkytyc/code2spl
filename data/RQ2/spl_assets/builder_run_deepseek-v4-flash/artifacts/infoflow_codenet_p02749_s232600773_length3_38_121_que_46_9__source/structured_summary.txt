# Structured Description

## Input
The program reads from standard input. It first reads a single integer `n` representing the number of nodes in a tree. Then it reads `n-1` lines, each containing two integers `a` and `b` representing an undirected edge between nodes `a` and `b` (1-indexed in input, converted to 0-indexed internally).

## Output
The program prints a single line containing `n` space-separated integers, which are the assigned values for each node (1-indexed positions). Alternatively, it may print `-1` and terminate early if no valid assignment exists.

## Main Function Logic

### Graph Construction
- Creates an adjacency list `g` with `n` empty lists.
- For each of the `n-1` edges, adds both directions to the adjacency list.

### Breadth-First Search (bfs function)
- Performs BFS starting from node 0.
- Computes distance `dis` from node 0 to all other nodes.
- Counts nodes at even distances (`cnt_even`, starting at 1 for node 0) and odd distances (`cnt_odd`, starting at 0).
- Returns the distance array, odd count, and even count.

### Assignment Strategy
The program attempts to assign values 1 through `n` to nodes such that certain modular constraints are satisfied based on graph distances.

#### Case 1: Small Color Class
If `min(cnt_even, cnt_odd) <= n//3`:
- Assigns multiples of 3 (3, 6, 9, ...) to all nodes in the smaller distance parity class.
- Assigns remaining numbers (1, 2, 4, 5, 7, 8, ...) to the other nodes in order.
- Prints the result and returns.

#### Case 2: Larger Color Classes
If both parity classes are larger than `n//3`:
- Assigns multiples of 3 to nodes in the smaller parity class while possible (while `3*x <= n`).
- Nodes in that class that cannot receive multiples of 3 are collected in `remain`.
- Creates two deques:
  - `que_1`: contains numbers congruent to 1 modulo 3 (1, 4, 7, ...)
  - `que_2`: contains numbers congruent to 2 modulo 3 (2, 5, 8, ...)
- For each node in `remain`, calls the `length3` function to assign values to that node and its distance-3 neighbors.

### length3 Function
For a given starting node `s`:
- Performs BFS up to distance 3 from `s`.
- Collects all nodes at exactly distance 3 in list `see`.
- Examines already-assigned values among these distance-3 nodes:
  - Counts how many have values ≡ 1 mod 3 (`check1`)
  - Counts how many have values ≡ 2 mod 3 (`check2`)
- Based on these counts, assigns values:
  - If both types exist: prints -1 and exits.
  - If only type 1 exists: assigns a value from `que_2` to `s`, and values from `que_1` to unassigned distance-3 nodes.
  - If only type 2 exists: assigns a value from `que_1` to `s`, and values from `que_2` to unassigned distance-3 nodes.
  - If neither type exists: chooses the larger remaining queue to assign to `s`, and the other queue for distance-3 nodes.
- Returns updated `ans`, `que_1`, and `que_2`.

### Final Assignment
After processing all `remain` nodes:
- For any remaining unassigned nodes, assigns values from `que_1` first, then `que_2`.
- Prints the final assignment.

## Helper Functions
- `inp()`: reads a single integer.
- `inpm()`: reads multiple integers from a line.
- `inpl()`: reads a line and returns a list of integers.
- Various other input helpers are defined but not used in the main logic.

## Control Flow
- Early termination with `-1` occurs when:
  - Both types of modular values are found among distance-3 neighbors.
  - Required queues are empty when values need to be assigned.

## Data Dependencies
- The BFS distances determine which nodes receive multiples of 3.
- The `length3` function depends on the current state of `ans`, `que_1`, and `que_2`.
- Queue contents are consumed (via pop) as values are assigned.
