## Inputs
The program reads from standard input using a Scanner. It first reads an integer `t` representing the number of test cases. For each test case, it reads:
- An integer `p` (number of people)
- An integer `q` (grid size)
- For each of the `p` people: an integer coordinate, another integer coordinate (transformed), and a direction string

## Outputs
For each test case, the program outputs a line in the format: `Case #i: x y` where `i` is the test case number (1-based), and `x` and `y` are the coordinates of the chosen point.

## Data Structures
- `Person` class stores four integers: `x`, `y`, `xDir`, `yDir`
- `ArrayList<Person>` collections store person objects
- A 2D integer array `b` of size `q x q` accumulates counts

## Control Flow

### Main Loop
The program iterates through `t` test cases using a for loop from 1 to `t`.

### Person Input Processing
For each person (loop from 0 to `p-1`):
1. Reads integer `b` (stored as y-coordinate)
2. Reads integer and computes `a = q - input - 1` (stored as x-coordinate)
3. Reads direction string `c`
4. Sets direction components:
   - "N": yDir = -1, xDir = 0
   - "S": yDir = 1, xDir = 0
   - "E": xDir = 1, yDir = 0
   - Any other value (treated as "W"): xDir = -1, yDir = 0
5. Creates a Person object with these values

### Grid Population
For each person in the list:
- If xDir is 0 (person moves vertically):
  - Iterates from `x + yDir` in steps of `yDir` while within bounds [0, q-1]
  - For each such row, increments all columns in that row
- If xDir is non-zero (person moves horizontally):
  - Iterates through all rows
  - For each row, iterates from `y + xDir` in steps of `xDir` while within bounds
  - Increments those specific cells

### Maximum Finding
Scans the entire `q x q` grid to find the maximum count value.

### Candidate Collection
Iterates through the grid column by column (outer loop over columns, inner loop over rows):
- When a cell equals the maximum, stores:
  - `row[num] = q - r - 1` (transformed row coordinate)
  - `col[num] = c` (column coordinate)
  - Increments counter `num`

### First Filter (Minimum Sum)
Iterates through collected candidates:
- Tracks minimum value of `row[j] + col[j]`
- When a new minimum is found, clears the list and adds the current candidate
- When equal to current minimum, appends to the list

### Second Filter (Minimum X)
Iterates through the filtered list:
- Tracks minimum `x` value
- When a new minimum is found, clears the list and adds the current candidate
- When equal, appends to the list

### Final Selection
Starts with first element of the remaining list, then iterates through the rest:
- If a later element has smaller `y`, selects that one instead

### Output
Prints the selected point's `y` coordinate followed by `x` coordinate.

## Key Dependencies
- The transformed x-coordinate depends on the input value and `q`
- Direction components determine which cells get incremented in the grid
- The final selection depends on the maximum count, then minimum sum of coordinates, then minimum x, then minimum y
- The row coordinate transformation (`q - r - 1`) reverses the row index when storing candidates
