## Inputs
- The program reads from standard input using a Scanner.
- First input is an integer `t` representing the number of test cases.
- For each test case, it reads an integer `c` (the size of arrays), followed by `c` integers stored in array `b`.

## Outputs
- For each test case, the program prints either:
  - `Case #X: IMPOSSIBLE` if no valid solution is found.
  - `Case #X: N` followed by `N` lines of strings (each string consists of characters `.`, `/`, and `\`), where `N` is the number of lines in the solution.

1. The `main` method creates a Scanner, reads the number of test cases `t`, and loops from 0 to `t-1`, calling `solve(sc, i+1)` for each test case.

## solve Method Logic
1. Initializes `result` to `false`.
2. Reads integer `c` and creates arrays `b` and `r` of size `c`.
3. Fills `b` with input values and initializes all elements of `r` to 1.
4. Creates array `d` of size `c` (unused in the logic).
5. Creates an empty list `l` to store output strings.
6. Enters an infinite `while(true)` loop:
   - Sets `result = true`.
   - Checks if all elements of `b` equal corresponding elements of `r`. If so, sets `result = false` and breaks out of the loop.
   - Otherwise, initializes variables: `cl = 0`, `last = 0`, array `z` of size `c`, `good = false`, empty string `s`, and array `rr` of size `c` (all zeros by default).
   - Iterates through indices `i` from 0 to `c-1`:
     - If `b[i] > 0`:
       - Sets `want = b[i]`.
       - Iterates `j` from `last` to `c-1`:
         - If `r[j] == 0`, appends `.` to `s` and continues.
         - Otherwise, subtracts `r[j]` from `want`.
         - If `j > i` and `j > 0` and `j < c-1`: sets `z[j] = -1`, adds `r[j]` to `rr[j-1]`, sets `good = true`, appends `/` to `s`.
         - Else if `j < i` and `j > 0` and `j < c-1`: sets `z[j] = 1`, adds `r[j]` to `rr[j+1]`, sets `good = true`, appends `\` to `s`.
         - Otherwise: appends `.` to `s` and adds `r[j]` to `rr[j]`.
         - If `want <= 0`, sets `last = j+1` and breaks out of the inner loop.
   - After the inner loop completes, assigns `r = rr`.
   - Adds string `s` to list `l`.
   - If `good` is `false`, breaks out of the while loop.
7. After the while loop:
   - If `result` is `false`, prints `Case #X: IMPOSSIBLE`.
   - Otherwise:
     - Creates a string of `c` periods and adds it to list `l`.
     - Prints `Case #X: ` followed by the size of list `l`.
     - Prints each string in list `l` on a separate line.

## Key Data Dependencies
- Array `b` holds the target values read from input.
- Array `r` holds current values, initially all 1s, updated each iteration.
- Array `rr` accumulates new values for `r` based on movement rules.
- Array `z` tracks direction but is never read after being set.
- Variable `last` tracks the position in the inner loop across iterations of the outer loop.
- Variable `good` indicates whether any movement occurred in the current iteration.
- List `l` accumulates output strings for each iteration.
