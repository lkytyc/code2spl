# Code Description

## Overview
This program reads a sequence of N triples of positive integers, computes a dynamic programming maximum-sum path through the triples with the constraint that consecutive selections cannot come from the same column, and outputs the maximum possible sum.

## Inputs
- First input: an integer N (number of triples)
- Then N lines, each containing three integers: A[i], B[i], C[i]

## Outputs
- A single integer: the maximum achievable sum

## Validation and Early Termination
- If reading N fails (scanf returns ≤ 0), the program exits with status 1
- If N ≤ 0 or N > 10^5, the program exits with status 1
- For each triple, if reading the three values fails (fewer than 3 values read), the program exits with status 1
- Each value A[i], B[i], C[i] must be in the range (0, 10^4]; otherwise, the program exits with status 1

## Memory Allocation
- Three integer arrays A, B, C are allocated, each of size N
- No explicit check is performed on the malloc return values

## Main Processing Loop
For each index i from 0 to N-1:
- **First iteration (i=0):** The sums are initialized directly to A[0], B[0], C[0] respectively, and these become the reference values
- **Subsequent iterations (i ≥ 1):** 
  - sumA = A[i] + max(ref_B, ref_C) — cannot pick from column A consecutively
  - sumB = B[i] + max(ref_C, ref_A) — cannot pick from column B consecutively
  - sumC = C[i] + max(ref_A, ref_B) — cannot pick from column C consecutively
  - The new sums become the reference values for the next iteration

## Final Maximum Selection
The program determines the maximum of the three final sums (sumA, sumB, sumC) using nested conditional branches:
- If sumA ≥ sumB, then compare sumA with sumC; the larger becomes SUM
- Otherwise (sumB > sumA), compare sumB with sumC; the larger becomes SUM
- A third branch exists but is unreachable given the first two conditions cover all cases

## Output
The final SUM value is printed as an integer followed by a newline.

## Key Data Dependencies
- Each sum at position i depends on the corresponding input value at position i and the maximum of the two other sums from position i-1
- The reference values (ref_A, ref_B, ref_C) carry forward the previous iteration's sums
- The final output depends on all three final sums, which in turn depend on all input values through the dynamic programming recurrence
