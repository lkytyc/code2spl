## Function: fill_bathroom

### Inputs
- `n_case`: zero-based case index used for output labeling
- `stalls`: total number of bathroom stalls
- `users`: number of people to place in stalls

### Outputs
- Prints to stdout: `Case #<n_case+1>: <max_crit2> <max_crit1>` where max_crit2 and max_crit1 are the final values from the last iteration of the user placement loop.

### Data Structures
- `stalls_occupancy`: integer array of size `stalls`, initialized to all zeros (0 = empty, 1 = occupied)
- `ls`: integer array of size `stalls`, tracks distance to nearest occupied stall on the left
- `rs`: integer array of size `stalls`, tracks distance to nearest occupied stall on the right

### Initialization
- All three arrays are allocated with `malloc`
- `stalls_occupancy` is zeroed with `memset`
- `ls[i]` is initialized to `i` (distance from left edge)
- `rs[i]` is initialized to `stalls - i - 1` (distance from right edge)

### Main Loop (for each user, `users` iterations)
For each user placement:
1. Reset `pos` to 0, `max_crit1` to 0, `max_crit2` to 0
2. Scan all stalls from left to right:
   - For each empty stall (`stalls_occupancy[j] == 0`):
     - Compute `crit1 = MIN(ls[j], rs[j])` (smaller distance)
     - Compute `crit2 = MAX(ls[j], rs[j])` (larger distance)
     - Selection logic:
       - If `crit1 >= max_crit1` AND `crit2 > max_crit2`: select this stall (update pos, max_crit1, max_crit2)
       - Else if `crit1 > max_crit1`: select this stall (update pos, max_crit1, max_crit2)
       - Note: the first condition takes priority; the second is only checked if the first fails
3. Mark selected stall as occupied: `stalls_occupancy[pos] = 1`
4. Update `ls` array for stalls to the right of `pos`:
   - Walk right from `pos+1` until an occupied stall or end of array
   - For each empty stall encountered, set `ls[i]` to the running counter (starting at 0), incrementing after each assignment
   - When an occupied stall is hit, set its `ls` value to the counter, increment, then break
5. Update `rs` array for stalls to the left of `pos`:
   - Walk left from `pos-1` until an occupied stall or beginning of array
   - For each empty stall encountered, set `rs[i]` to the running counter (starting at 0), incrementing after each assignment
   - When an occupied stall is hit, set its `rs` value to the counter, increment, then break

### Memory Management
- All three arrays are freed at the end of the function

### Output Format
- Prints the case number (1-based) and the final `max_crit2` and `max_crit1` values from the last user placement iteration

## Function: main

### Inputs
- Reads from stdin: first an integer `T` (number of test cases)
- For each test case, reads two integers: `stalls` and `users`

### Control Flow
- Loops `T` times, calling `fill_bathroom(i, stalls, users)` for each case
- Returns 0 on completion

### Data Dependencies
- `stalls` and `users` are passed directly to `fill_bathroom`
- The case index `i` is passed as `n_case`
