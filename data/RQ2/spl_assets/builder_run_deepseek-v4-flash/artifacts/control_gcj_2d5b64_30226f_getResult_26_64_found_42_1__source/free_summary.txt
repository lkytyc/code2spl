This code reads a number of test cases, and for each case, it takes two integers r and s, builds a list containing s repetitions of the sequence 1 through r, and then performs a series of list rearrangements to sort the list into the order 1,1,...,1,2,2,...,2,...,r,r,...,r. It outputs the number of rearrangement operations needed and each operation as a pair of indices.
