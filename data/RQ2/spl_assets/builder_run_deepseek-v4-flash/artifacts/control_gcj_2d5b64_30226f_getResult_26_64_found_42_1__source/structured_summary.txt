## Inputs
- The program reads from standard input using a Scanner.
- First line: an integer `numOfCases` representing the number of test cases.
- For each test case: a single line containing two integers separated by a space, representing values `r` and `s`.

## Outputs
- For each test case, the program outputs:
  - A line in the format `Case #N: M` where N is the 1-based test case number and M is the size of the result list.
  - Then M lines, each containing two integers separated by a space (the operation steps).

## Main Control Flow
1. Read `numOfCases` from first input line.
2. Loop from 0 to `numOfCases - 1`:
   - Read the next input line (containing `r` and `s`).
   - Create a `TestCase` object with `r` and `s`.
   - Call `getResult()` to compute the result list.
   - Print the case header with result size.
   - Print each result string on its own line.

### getResult() Method

#### Initialization
- Creates an empty result list (List of Strings).
- Creates an empty list `v` of integers.

#### Building Initial List
- Nested loop: for `ss` from 0 to `s-1`, for `rr` from 0 to `r-1`:
  - Add value `rr + 1` to list `v`.
- This creates a sequence: [1,2,...,r, 1,2,...,r, ...] repeated `s` times.

#### Main Processing Loop
- Outer loop: for `rr` from 0 to `r-2` (i.e., `r-1` iterations):
  - Set `current = r - rr` (starts at `r`, decreases each iteration).
  - Set `count = s - 1`.
  - Set `idx = current * s - 2`.
  - Set `start = idx`.

#### Inner While Loop (while count > 0)
- Inner search loop (while not found):
  - Check if `v.get(idx) == current`.
  - If match found:
    - Decrement `count`.
    - Set `found = true`.
    - Compute `sz = start - idx`.
    - Add formatted string `"%d %d"` with `idx + 1` and `sz` to result.
    - Create temporary list `t`.
    - While `sz > 0`: decrement `sz`, remove element at position `idx + 1` from `v` and add to `t`.
    - Append all remaining elements of `v` to `t`.
    - Set `v = t`.
    - Set `idx = start`.
    - Decrement `start`.
  - Decrement `idx` (whether found or not, after the found block executes).

#### Return
- Returns the result list of operation strings.

## Data Dependencies
- The `v` list is modified during processing and its state affects subsequent iterations.
- The `idx` and `start` variables track positions in the list and are updated based on matches found.
- The `count` variable controls how many matches are needed per outer iteration.
- The `sz` value depends on the difference between `start` and `idx` when a match is found.
