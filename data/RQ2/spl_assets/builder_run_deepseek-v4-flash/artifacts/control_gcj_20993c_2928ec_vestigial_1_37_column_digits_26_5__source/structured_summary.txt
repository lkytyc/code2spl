# Structured Description

## Function: vestigial(pinax)

### Input
- `pinax`: A 2D list (matrix) of integers. The function assumes the matrix is square, using the length of the first row as the size.

### Output
- Returns a list of three integers: `[trail, same_row_counter, sumC]`

### Processing Steps

1. **Initialization**
   - Determines `size` as the length of the first row of the input matrix.
   - Initializes an empty `result` list.
   - Initializes `row_digits` as an empty list.
   - Initializes `column_digits` as a list of `size` empty lists.
   - Sets `same_row_counter` to 0.
   - Sets `same_column_counter` to a list of `size` zeros.
   - Sets `trail` to 0.

2. **Main Loop (rows and columns)**
   - Iterates over each row index from 0 to size-1.
   - Clears `row_digits` at the start of each row iteration.
   - For each row, iterates over each column index from 0 to size-1.

3. **Diagonal Trace Calculation**
   - When `row == column`, adds the diagonal element `pinax[row][row]` to `trail`.

4. **Row Duplicate Detection**
   - Checks if `len(row_digits) == column` (this condition is true only when processing the first occurrence of a value in a row).
   - If true, iterates through existing `row_digits`:
     - If the current value is not found in `row_digits`, appends it.
     - If the current value is found in `row_digits`, increments `same_row_counter` and stops searching.

5. **Column Duplicate Detection**
   - For each column, iterates through existing values in `column_digits[column]`:
     - If the current value is not found, appends it to that column's list.
     - If the current value is found, sets `same_column_counter[column]` to 1 and stops searching.

6. **Summation**
   - After all rows are processed, sums all values in `same_column_counter` into `sumC`.

7. **Result Assembly**
   - Appends `trail`, `same_row_counter`, and `sumC` to the result list in that order.

### Key Behavioral Notes
- `same_row_counter` counts the total number of duplicate values found within each row (across all rows).
- `same_column_counter` is a binary indicator per column (0 or 1), where 1 means a duplicate was found in that column.
- The row duplicate detection logic only triggers when `len(row_digits) == column`, which means it only checks for duplicates at specific positions in the row processing.

## Function: main()

### Input
- Reads from standard input:
  - First line: number of test cases (integer).
  - For each test case:
    - A line with the matrix size (integer).
    - `size` lines, each containing `size` space-separated integers.

### Processing
- For each test case:
  - Reads the matrix size.
  - Initializes `pinax` as a list of `size` empty lists.
  - Populates each row by reading a line, splitting it, converting to integers, and assigning to `pinax[j]`.
  - Calls `vestigial(pinax)` to get the result.
  - Prints the result in the format: `Case #<index>: <trail> <same_row_counter> <sumC>`

### Output
- Prints one line per test case with the case number (0-based) and the three computed values.

## Control Flow Summary
- The main function loops over test cases.
- The vestigial function uses nested loops over rows and columns.
- Conditional branches exist for:
  - Diagonal element detection (row == column).
  - Row duplicate detection (based on list length comparison).
  - Column duplicate detection (based on value comparison).
- No recursion or external function calls other than `vestigial` from `main`.
