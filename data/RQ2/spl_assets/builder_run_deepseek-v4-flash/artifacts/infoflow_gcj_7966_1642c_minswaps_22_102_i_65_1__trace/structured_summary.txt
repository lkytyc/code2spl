# Code Description

## Overview
This program reads a series of test cases, each containing a damage threshold and a string of characters ('S' and 'C'), and determines the minimum number of adjacent swaps needed to reduce the total damage to at most the threshold. If impossible, it reports "IMPOSSIBLE".

## Input
- First line: integer `n` (number of test cases)
- For each test case:
  - Integer `d` (damage threshold)
  - String `p` (up to 30 characters, consisting of 'S' and 'C')

## Output
- For each test case: `Case #X: result` where X is the case number (1-based) and result is either the minimum swap count or "IMPOSSIBLE"

## Main Function Control Flow
1. Reads number of test cases `n`
2. Loops `n` times:
   - Reads damage threshold `d` and string `p`
   - Calls `minswaps(p, d, strlen(p))`
   - If result is -1, prints "IMPOSSIBLE"; otherwise prints the result

## minswaps Function

### Base Case (len == 2)
Handles two-character strings with specific logic:
- "SC": returns 0 (no swaps needed)
- "SS": returns -1 if d < 2, otherwise 0
- "CS": returns 1 if d < 2, otherwise 0
- Any other combination: returns 0

### General Case (len > 2)

#### Initialization
- Sets initial strength = 1, damage = 0
- Allocates integer array `a` of size `len`
- Iterates through string:
  - For 'S': adds current strength to damage, stores strength in array
  - For 'C': doubles strength, stores new strength in array

#### Early Exit
- If calculated damage ≤ threshold `d`, returns 0 immediately

#### Swap Loop
- Starts from the end of the string (index len-1)
- Uses a flag-based outer loop that continues until no more swaps are possible
- Inner loop runs while damage exceeds threshold and index > 0:
  - Finds the rightmost 'S' character
  - If the character before it is also 'S', moves left
  - Otherwise, swaps the 'S' with the preceding 'C':
    - Updates the string characters
    - Adjusts damage: subtracts the value at current position, updates array values, adds new value
    - Increments swap counter
  - Special break condition when at position 1 with 'S' at position 0

#### Final Check
- Frees allocated memory
- Returns swap count if damage ≤ threshold, otherwise returns -1

## Data Dependencies
- The array `a` tracks strength values at each position
- Damage calculation depends on both the string pattern and strength progression
- Array updates after swaps maintain consistency with the modified string
- The swap operation modifies both the string and the strength array

## Key Logic
- Damage accumulates by adding current strength for each 'S'
- Strength doubles for each 'C'
- Swapping 'CS' to 'SC' reduces damage by moving a shot earlier in the sequence
- The algorithm greedily swaps the rightmost possible 'CS' pair to maximize damage reduction per swap
