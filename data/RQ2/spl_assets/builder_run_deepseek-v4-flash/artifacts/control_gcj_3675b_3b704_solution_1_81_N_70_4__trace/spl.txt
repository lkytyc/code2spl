[DEFINE_WORKER: "Reads sign records as (d, a, b), converts each to (d + a, d - b), then scans the resulting list with a stateful anchor-matching algorithm to return the maximum consecutive run size and the number of runs attaining that size." solution]
    [INPUTS]
        <REF> number_of_signs </REF>: int "Number of sign records to read from standard input."
    [END_INPUTS]

    [OUTPUTS]
        <REF> result </REF>: tuple of two ints "Returns (maximum_set_size, number_of_maximum_set_sized): the largest run size found and the number of runs attaining that size."
    [END_OUTPUTS]

    [MAIN_FLOW]
        [SEQUENTIAL_BLOCK]
            [COMMAND Initialize an empty list named a_to_b. RESULT a_to_b]
            [COMMAND For each i from 0 to number_of_signs - 1 inclusive, read one line with raw_input, split it into d, a, and b, convert each to int, and append (d + a, d - b) to a_to_b. RESULT a_to_b]
            [COMMAND Initialize N = None, M = None, maximum_set_size = 1, number_of_maximum_set_sized = 0, current_set_size = 1; pop the first tuple from a_to_b into a_for_comparision and b_for_comparision; set is_finish = False. RESULT state_variables]
            [COMMAND While not is_finish and len(a_to_b) > 0, enter the outer loop; inside it, for each index and tuple from enumerate(a_to_b), set is_finish = True if index is the last index, unpack a and b from the tuple, and execute the matching N/M state branch described below. RESULT state_variables]
            [COMMAND Within the inner loop, when N is not None and M is None, if a differs from a_for_comparision, set M = b and b_for_comparision = b; then increment current_set_size by 1. RESULT state_variables]
            [COMMAND Within the inner loop, when M is not None and N is None, if b differs from b_for_comparision, set N = a and a_for_comparision = a; then increment current_set_size by 1. RESULT state_variables]
            [COMMAND Within the inner loop, when both M and N are not None, if both a differs from a_for_comparision and b differs from b_for_comparision, finalize the current run: if current_set_size > maximum_set_size, set maximum_set_size = current_set_size and number_of_maximum_set_sized = 1; elif current_set_size == maximum_set_size, increment number_of_maximum_set_sized by 1. Then set current_set_size = 1, N = None, M = None, set a_to_b = a_to_b[index:] so the current tuple and all later tuples are kept, and break out of the inner loop; the two assignments immediately after the break are unreachable and ignored. Otherwise, increment current_set_size by 1. RESULT state_variables]
            [COMMAND Within the inner loop, when both N and M are None and both a equals a_for_comparision and b equals b_for_comparision, set a_for_comparision = a if N is None, set b_for_comparision = b if M is None, increment current_set_size by 1, and continue to the next tuple. RESULT state_variables]
            [COMMAND Within the inner loop, when both N and M are None and a equals a_for_comparision but b differs from b_for_comparision, set N = a and a_for_comparision = N if N is None, set b_for_comparision = b, and increment current_set_size by 1. RESULT state_variables]
            [COMMAND Within the inner loop, when both N and M are None and b equals b_for_comparision but a differs from a_for_comparision, set M = b and b_for_comparision = b if M is None, set a_for_comparision = a, and increment current_set_size by 1. RESULT state_variables]
            [COMMAND Within the inner loop, when both N and M are None and both a and b differ from their comparison anchors, use lookahead to the next tuple: if len(a_to_b) > index, which is always true for an active enumerated index, check whether a equals the next tuple's first element; if so, set N and a_for_comparision to that first element and M = b_for_comparision; otherwise set M and b_for_comparision to the next tuple's second element and N = a_for_comparision; in either case increment current_set_size by 1. RESULT state_variables]
            [COMMAND After the outer loop exits, return the tuple (maximum_set_size, number_of_maximum_set_sized). RESULT return_value]
        [END_SEQUENTIAL_BLOCK]
    [END_MAIN_FLOW]

    [EXCEPTION_FLOW: raw_input() is called but no input line is available before number_of_signs lines have been read.]
        [LOG "EOF reached while reading sign records."]
        [THROW EOFError "raw_input() cannot read a line because end of input was reached."]
    [END_EXCEPTION_FLOW]

    [EXCEPTION_FLOW: An input line does not contain exactly three whitespace-separated tokens, or any of d, a, or b cannot be converted to int.]
        [LOG "Invalid sign record while building a_to_b."]
        [THROW ValueError "split or int conversion fails on the raw_input line."]
    [END_EXCEPTION_FLOW]

    [EXCEPTION_FLOW: number_of_signs is 0 or negative, making a_to_b empty before the initialization pop.]
        [LOG "Attempting to pop from an empty list during initialization."]
        [THROW IndexError "a_to_b.pop(0) fails because a_to_b has no elements."]
    [END_EXCEPTION_FLOW]

    [EXCEPTION_FLOW: In the lookahead branch, the current index is the last index, so a_to_b[index + 1] is accessed while executing the always-true len(a_to_b) > index path.]
        [LOG "Lookahead index out of range while trying to seed the next run."]
        [THROW IndexError "Accessing a_to_b[index + 1] fails because that element does not exist."]
    [END_EXCEPTION_FLOW]

[END_WORKER]
