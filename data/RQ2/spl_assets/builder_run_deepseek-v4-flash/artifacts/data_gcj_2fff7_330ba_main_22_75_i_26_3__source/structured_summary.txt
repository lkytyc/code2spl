## Overview
This program reads multiple test cases, each containing rectangle dimensions, and computes the maximum possible perimeter increase achievable by adding decorative elements to the rectangles, subject to a budget constraint.

## Inputs
- First line: integer `T` (number of test cases)
- For each test case:
  - First line: integers `N` (number of rectangles) and `P` (available perimeter budget)
  - Next `N` lines: pairs of integers `w` and `h` (width and height of each rectangle)

## Outputs
- For each test case, prints: `Case #X: Y` where X is the test case number (1-based) and Y is a floating-point value with 6 decimal places representing the total perimeter including the best achievable additional decoration.

## Data Structures
- Arrays allocated per test case:
  - `w`, `h`: integer arrays for rectangle dimensions
  - `min_add`: integer array for minimum additional perimeter per rectangle
  - `max_add`: double array for maximum additional perimeter per rectangle
  - `best_min`, `best_max`: double arrays for cumulative minimum and maximum additional perimeters

## Main Processing Logic

### Per Test Case Initialization
1. Read `N` and `P`, store original `P` in `P_orig`
2. Allocate all arrays of size `N`
3. Initialize `total` to 0

### Rectangle Input Loop
For each rectangle `j` (0 to N-1):
- Read width and height
- Compute base circumference: `circ = (w + h) * 2`
- Subtract `circ` from `P` (remaining budget)
- Add `circ` to `total`
- Compute `min_add[j]` = 2 × (smaller of width and height)
- Compute `max_add[j]` = 2 × sqrt(width² + height²)

### Dynamic Programming Selection
For each rectangle `j` (0 to N-1):
- Initialize `min1 = 0`, `max1 = 0`, `k1 = -1`
- Search all previous rectangles `k` (0 to j-1):
  - If `best_min[k] + min_add[j] < P` AND `best_max[k] > max1`:
    - Update `k1 = k`, `min1 = best_min[k]`, `max1 = best_max[k]`
- Set `best_min[j] = min1 + min_add[j]`
- Set `best_max[j] = max1 + max_add[j]`
- If `best_min[j] <= P` AND `best_max[j] > best_valid`:
  - Update `best_valid = best_max[j]`

### Final Calculation
- If `best_valid > P`, cap it at `P`
- Print total perimeter: `total + best_valid`

## Key Dependencies and Constraints
- The selection logic ensures that the minimum additional perimeter for any chosen sequence stays within the remaining budget `P`
- The maximum additional perimeter is tracked to find the best achievable value
- The final result cannot exceed the original budget `P` plus the base perimeters
- The `dpr` function is a debug print stub that does nothing (its body is disabled with `#if 0`)

## Memory Management
- All arrays are freed at the end of each test case iteration
- Program exits with status 0 after all test cases
