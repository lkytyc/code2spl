[DEFINE_WORKER: "Reads multiple test cases; for each, it reads an integer array and computes the maximum size of the list returned by the external recurse function over the original array and over every array obtained by deleting one or two elements, then prints the maximum as Case #iii: max." main]
    [INPUTS]
        <REF> args </REF>: String[] "Command-line arguments; not used by this method."
    [END_INPUTS]

    [OUTPUTS]
    [END_OUTPUTS]

    [MAIN_FLOW]
        [SEQUENTIAL_BLOCK]
            [COMMAND Initialize a Scanner over a BufferedReader over an InputStreamReader on standard input, then read the next line and parse it as the integer t, the number of test cases. RESULT t]
            [COMMAND For each integer iii from 1 to t inclusive, execute the following test-case processing steps and print one output line for that test case. RESULT test_case_loop]
            [COMMAND Within each test case, read integer n from the scanner, create int array aw of length n, reset the external table to a new ArrayList<ArrayList<Integer>>, add one empty ArrayList to table, then for each i from 0 to n-1 inclusive read aw[i] from the scanner and append an empty ArrayList to table. RESULT aw]
            [COMMAND Within each test case, for each i from 1 to n inclusive, call recurse(aw, i) and store the returned ArrayList<Integer> in table at index i. RESULT table]
            [COMMAND Within each test case, set max to table.get(n).size(), the size of the original array's computed list for length n. RESULT max]
            [COMMAND Within each test case, for each single-deletion index i from 0 to n-1 inclusive, reset table to a new ArrayList<ArrayList<Integer>> containing n empty ArrayLists, create int array aww of length n-1 containing aw with the element at index i removed, and for each k from 1 to n-1 inclusive call recurse(aww, k) and store the result in table at index k. RESULT table]
            [COMMAND Within each test case, for each single-deletion iteration, set tempmax to table.get(n-1).size(), and if tempmax is greater than current max, update max to tempmax. RESULT max]
            [COMMAND Within each test case, for each pair of deletion indices i and j with i from 0 to n-1 inclusive and j from i+1 to n-1 inclusive, reset table to a new ArrayList<ArrayList<Integer>> containing n-1 empty ArrayLists, create int array aww of length n-2 containing aw with the elements at indices i and j removed, and for each k from 1 to n-2 inclusive call recurse(aww, k) and store the result in table at index k. RESULT table]
            [COMMAND Within each test case, for each double-deletion iteration, set tempmax to table.get(n-2).size(), and if tempmax is greater than current max, update max to tempmax. RESULT max]
            [COMMAND Within each test case, print the line obtained by concatenating "Case #", the current test-case number iii, ": ", and max. RESULT stdout]
        [END_SEQUENTIAL_BLOCK]
    [END_MAIN_FLOW]
