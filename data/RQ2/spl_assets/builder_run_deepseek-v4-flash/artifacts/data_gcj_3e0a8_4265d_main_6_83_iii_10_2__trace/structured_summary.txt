## Overview
This Java program reads a series of test cases, each containing an array of integers, and computes a maximum value based on a recursive selection process. The program uses a static table to store intermediate results and performs multiple passes over the input array with elements removed.

## Input
- First line: integer `t` (number of test cases)
- For each test case: integer `n` (array size), followed by `n` integers on subsequent lines

## Output
- For each test case: `Case #X: Y` where X is the test case number and Y is the computed maximum

## Global State
- Static variable `table`: an `ArrayList<ArrayList<Integer>>` used to store intermediate results from the recursive function

## Main Method Flow

### Initial Setup
1. Creates a Scanner reading from standard input
2. Reads the number of test cases `t`
3. Loops through each test case (index `iii` from 1 to `t`)

### Per Test Case Processing
1. Reads array size `n`
2. Creates integer array `aw` of size `n`
3. Initializes `table` with one empty ArrayList, then adds `n` more empty ArrayLists (total `n+1` entries)
4. Reads `n` integers into `aw`

### First Computation Pass
- For each index `i` from 1 to `n`:
  - Calls `recurse(aw, i)` and stores result at `table.set(i, ...)`
- Sets `max` to the size of `table.get(n)`

### Second Pass (Remove One Element)
- For each index `i` from 0 to `n-1`:
  - Reinitializes `table` with `n` empty ArrayLists
  - Creates new array `aww` of size `n-1` by removing element at position `i` from `aw`
  - For each index `ii` from 1 to `n-1`:
    - Calls `recurse(aww, ii)` and stores result
  - Gets size of `table.get(n-1)` as `tempmax`
  - Updates `max` if `tempmax` is larger

### Third Pass (Remove Two Elements)
- For each pair of indices `i` and `j` where `i < j`:
  - Reinitializes `table` with `n-1` empty ArrayLists
  - Creates new array `aww` of size `n-2` by removing elements at positions `i` and `j` from `aw`
  - For each index `ii` from 1 to `n-2`:
    - Calls `recurse(aww, ii)` and stores result
  - Gets size of `table.get(n-2)` as `tempmax`
  - Updates `max` if `tempmax` is larger

### Output
- Prints the case number and final `max` value

## Recursive Function: `recurse(int[] aw, int n)`

### Parameters
- `aw`: the input array
- `n`: the number of elements to consider (1-indexed position)

### Return Value
- An ArrayList of integers representing selected indices

### Logic
1. **Base case** (`n == 1`): Returns a list containing just `0`

2. **Recursive case**:
   - Initializes tracking variables:
     - `maxlength` = -1 (best length found)
     - `minweight` = 100000000 (minimum weight for best length)
     - `goodindex` = -1 (index of best result)
     - `addon` = false (whether to add current element)
   
   - **Loop** through indices `i` from 0 to `n-1`:
     - Gets `result` from `table.get(i)` (previously computed)
     - Gets `leng` = size of that result
     - **Skip condition**: If `leng < maxlength`, continue to next iteration
     - Computes `weight` by summing `aw[ii]` for each index `ii` in the result
     - **Conditional addition**: If `weight <= 6 * aw[n-1]`:
       - Increments `leng` by 1
       - Adds `aw[n-1]` to weight
       - Sets `tempaddon` to true
     - **Selection logic**:
       - If `maxlength == leng`: keeps the one with smaller `weight`
       - Otherwise: updates all tracking variables with current values
   
   - **Build result**: Copies all indices from `table.get(goodindex)` into result
   - **Conditional append**: If `addon` is true, appends `n-1` to result
