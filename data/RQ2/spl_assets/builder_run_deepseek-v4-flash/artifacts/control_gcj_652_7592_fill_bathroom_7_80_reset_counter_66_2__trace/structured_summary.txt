## Function: fill_bathroom

### Inputs
- `n_case`: integer case number (zero-based)
- `stalls`: total number of bathroom stalls
- `users`: number of people to place

### Outputs
- Prints to stdout: `Case #<n_case+1>: <max_crit2> <max_crit1>` where max_crit2 and max_crit1 are the final values from the last iteration of the user placement loop.

### Data Structures
- `stalls_occupancy`: integer array of size `stalls`, initialized to all zeros (0 = empty, 1 = occupied)
- `ls`: integer array of size `stalls`, tracks distance to nearest occupied stall on the left
- `rs`: integer array of size `stalls`, tracks distance to nearest occupied stall on the right

### Initialization
- Allocates memory for all three arrays
- Initializes `stalls_occupancy` to all zeros
- Initializes `ls[i] = i` and `rs[i] = stalls - i - 1` for all indices (distances to the walls)

### Main Loop (for each user)
For each of the `users` iterations:
1. Reset `pos`, `max_crit1`, `max_crit2` to 0
2. Scan all stalls to find the best empty stall:
   - For each empty stall `j`, compute:
     - `crit1 = MIN(ls[j], rs[j])` (smaller distance)
     - `crit2 = MAX(ls[j], rs[j])` (larger distance)
   - Selection criteria (in order):
     - If `crit1 >= max_crit1` AND `crit2 > max_crit2`: select this stall
     - Else if `crit1 > max_crit1`: select this stall
   - This means the stall with the largest `crit1` is chosen; ties broken by larger `crit2`
3. Mark the selected stall as occupied (`stalls_occupancy[pos] = 1`)
4. Update `ls` array for stalls to the right of `pos`:
   - Walk right from `pos+1` until an occupied stall or end of array
   - For each empty stall encountered, set `ls[i]` to the running counter (0, 1, 2, ...)
   - When an occupied stall is hit, set its `ls` value to the counter, increment, then stop
5. Update `rs` array for stalls to the left of `pos`:
   - Walk left from `pos-1` until an occupied stall or beginning of array
   - For each empty stall encountered, set `rs[i]` to the running counter (0, 1, 2, ...)
   - When an occupied stall is hit, set its `rs` value to the counter, increment, then stop

### Final Output
After all users are placed, prints the last computed `max_crit2` and `max_crit1` values.

## Function: main

### Inputs
- Reads integer `T` from stdin (number of test cases)
- For each test case, reads two integers: `stalls` and `users`

### Control Flow
- Loops `T` times
- For each iteration, calls `fill_bathroom(i, stalls, users)` with the zero-based case index

### Outputs
- Returns 0 on successful completion

## Key Behavioral Notes
- The selection algorithm always picks the stall with the maximum minimum-distance-to-neighbor, breaking ties by maximum maximum-distance
- The update logic after placing a user correctly recalculates distances for affected stalls
- The final printed values are from the last user placement, not the best values overall
- Memory is properly freed before printing the result
