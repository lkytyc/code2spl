## Overview
This program reads a set of items, each with a weight and value, and computes the maximum total value that can be selected without exceeding a given weight capacity. The solution exploits the fact that all item weights fall into one of four consecutive integer values.

## Input
- First line: integer `n` (number of items) and long `W` (weight capacity)
- Next `n` lines: each contains a long weight `w` and long value `v`
- The first item's weight is read separately and used as a baseline

## Output
- A single long integer representing the maximum total value achievable within the weight limit

## Data Structures
- Four ArrayLists of Long values, indexed 0 through 3, storing item values grouped by weight category
- A 2D array `sum` where `sum[i][j]` holds the cumulative sum of the top `j` values from category `i`

## Processing Steps

### 1. Input Reading and Categorization
- Read `n` and `W`
- Read the first item's weight `w1` and value `v1`
- Add `v1` to the list at index 0
- For each remaining item (indices 1 to n-1):
  - Read weight `w` and value `v`
  - Compute the difference `w - w1` (which will be 0, 1, 2, or 3)
  - Add `v` to the corresponding list at that index

### 2. Sorting
- Sort each of the four lists in descending order (highest values first)

### 3. Prefix Sum Construction
- For each category `i` (0 to 3):
  - Create a prefix sum array of size (list size + 1)
  - Fill positions 1 through list size with the sorted values
  - Convert to cumulative sums (position j contains sum of first j values)

### 4. Brute-Force Enumeration
- Initialize answer to 0
- Nested loops iterate over all possible counts from each category:
  - `i` from 0 to size of list 0
  - `j` from 0 to size of list 1
  - `k` from 0 to size of list 2
  - `l` from 0 to size of list 3
- For each combination:
  - Calculate total weight: `w1*i + (w1+1)*j + (w1+2)*k + (w1+3)*l`
  - If total weight exceeds `W`, skip this combination
  - Otherwise, compute total value as sum of prefix sums from all four categories
  - Update answer if this total value is larger

### 5. Output
- Print the final maximum value

## Control Flow
- Main method creates input reader, output writer, and solver instance
- Solver processes all items and outputs the result
- Input reader uses buffered reading with tokenization; throws InputMismatchException on read errors

## Key Dependencies
- The weight difference calculation assumes all weights are within 3 units of the first item's weight
- The prefix sums allow O(1) lookup of the best value for any count from a category
- The four nested loops have complexity proportional to the product of the four list sizes
