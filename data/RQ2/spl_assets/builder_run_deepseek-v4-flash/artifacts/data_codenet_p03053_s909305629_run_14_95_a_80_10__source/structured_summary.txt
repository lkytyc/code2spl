# Structured Description

## Program Overview
This program reads a grid of characters representing black (`#`) and white (`.`) cells, then simulates a process where black cells spread to adjacent white cells in four directions (up, down, left, right) simultaneously in discrete time steps. The output is the number of time steps required for all cells to become black, minus one.

## Input
- First line: two integers `h` and `w` representing the grid height and width.
- Following `h` lines: each contains a string of length `w` consisting of `.` and `#` characters.

## Output
- A single integer printed to standard output, representing the number of time steps needed for all cells to become black (with the initial state counted as step 0).

## Main Data Structures
- `a`: 2D character array of size `h` × `w` storing the grid state.
- `blackar`: 2D integer array of size `h*w` × 2, storing coordinates of black cells.
- `p`: index tracking the current position in `blackar`.
- `maxp`: boundary index for the current "wave" of black cells.
- `p2`: index for appending newly blackened cells.
- `max`: counter for time steps.

## Initialization Phase
1. Read `h` and `w` from input.
2. Allocate the grid array and supporting arrays.
3. For each row `i` from 0 to `h-1`:
   - Read the row string and convert to character array.
   - For each column `j` from 0 to `w-1`:
     - If the character is `#`, record its coordinates in `blackar` at index `p` and increment `p`.

## Processing Phase (BFS-like Spread)
1. Set `maxp` to the initial count of black cells (`p`).
2. Set `p2` to the same initial count.
3. Reset `p` to 0.
4. Enter a while loop that continues while `p < h*w`:
   - Set a flag `hap` to 0 (though this flag is never used in the logic).
   - Inner for loop: iterate `p` from its current value up to `maxp`:
     - For each black cell at coordinates `(i, j)`:
       - Check up neighbor (`i-1`): if within bounds and currently `.`, change to `#`, record its coordinates in `blackar` at index `p2`, increment `p2`.
       - Check left neighbor (`j-1`): if within bounds and currently `.`, change to `#`, record coordinates, increment `p2`.
       - Check down neighbor (`i+1`): if within bounds and currently `.`, change to `#`, record coordinates, increment `p2`.
       - Check right neighbor (`j+1`): if within bounds and currently `.`, change to `#`, record coordinates, increment `p2`.
   - After the inner loop completes, update `maxp` to `p2` (the new boundary for the next wave).
   - Increment `max` (time step counter).

## Termination and Output
- The while loop terminates when `p` reaches `h*w`, meaning all cells have been processed.
- After the loop, subtract 1 from `max` to get the final answer.
- Print the answer using a `PrintWriter` and flush the output.

## Control Flow Details
- The outer while loop condition `p < h*w` ensures processing continues until all cells have been visited.
- The inner for loop processes only the cells that were black at the start of the current wave (from `p` to `maxp`).
- The `max` counter increments once per complete wave, representing one time step.
- The final subtraction of 1 accounts for the initial state being step 0.

## Function Calls
- `main`: starts a new thread with a 16 MB stack size.
- `run`: contains the main logic.
- `Scanner.next()`: reads whitespace-delimited tokens from standard input.
- `PrintWriter.println()` and `PrintWriter.flush()`: output the result.

## Unused Code
- The `FastScanner` class is defined but never instantiated or used in the program.
- The `hap` variable is declared and set to 0 but never read or modified.
- The `atmp` array is allocated but never used.

## Edge Cases
- If the grid has no black cells initially, the while loop will not execute (since `p` starts at 0 and `maxp` is 0), `max` remains 0, and after subtracting 1, the output would be -1.
- If all cells are initially black, the inner loop processes all cells in the first wave, `max` becomes 1
