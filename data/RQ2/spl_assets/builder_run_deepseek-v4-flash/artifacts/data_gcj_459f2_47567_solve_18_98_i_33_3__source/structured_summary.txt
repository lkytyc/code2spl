## Inputs
- The program reads from standard input using a Scanner.
- First input is an integer `t` representing the number of test cases.
- For each test case, it reads an integer `c` (the size of arrays), followed by `c` integers stored in array `b`.

## Outputs
- For each test case, the program prints either:
  - `Case #X: IMPOSSIBLE` if no valid solution is found.
  - `Case #X: N` followed by `N` lines of strings (each string consists of characters `.`, `/`, or `\`), where `N` is the number of rows in the solution.

## Main Control Flow
1. The `main` method creates a Scanner, reads the number of test cases `t`, and loops from 0 to `t-1`, calling `solve(sc, i+1)` for each test case.

## solve Method Logic
1. Initializes `result` to `false`.
2. Reads integer `c` and creates two arrays of size `c`: `b` (input values) and `r` (initialized to all 1s).
3. Creates array `d` of size `c` (unused in the logic).
4. Creates a list `l` to store output strings.
5. Enters an infinite `while(true)` loop:
   - Sets `result = true`.
   - Checks if all elements of `b` equal corresponding elements of `r`. If so, breaks out of the loop.
   - Otherwise, initializes variables: `cl` (unused), `last = 0`, array `z` of size `c` (unused), `good = false`, empty string `s`, and array `rr` of size `c` (all zeros by default).
   - Iterates through indices `i` from 0 to `c-1`:
     - If `b[i] > 0`:
       - Sets `want = b[i]`.
       - Iterates through indices `j` from `last` to `c-1`:
         - If `r[j] == 0`, appends `.` to `s` and continues.
         - Otherwise, subtracts `r[j]` from `want`.
         - If `j > i` and `j > 0` and `j < c-1`: sets `z[j] = -1`, adds `r[j]` to `rr[j-1]`, sets `good = true`, appends `/` to `s`.
         - Else if `j < i` and `j > 0` and `j < c-1`: sets `z[j] = 1`, adds `r[j]` to `rr[j+1]`, sets `good = true`, appends `\` to `s`.
         - Else: appends `.` to `s` and adds `r[j]` to `rr[j]`.
         - If `want <= 0`, sets `last = j+1` and breaks out of inner loop.
   - After the inner loop completes, assigns `r = rr`.
   - Adds string `s` to list `l`.
   - If `good` is `false`, breaks out of the while loop.
6. After the while loop:
   - If `result` is `false`, prints `Case #X: IMPOSSIBLE`.
   - Otherwise:
     - Creates a string of `c` periods and adds it to list `l`.
     - Prints `Case #X: <size of l>`.
     - Prints each string in `l` on its own line.

## Key Data Dependencies
- Array `r` is updated each iteration based on the previous `r` values and the logic in the inner loop.
- The `last` variable tracks the position in the inner loop across different `i` iterations within the same outer loop pass.
- The `good` flag determines whether any movement occurred in the current pass.
- The `result` flag is set to `true` only if all `b[i] == r[i]` at the start of a while-loop iteration.

## Unused/Dead Code
- Static fields `all` and `l` are declared but never used in the `solve` method.
- The `find` method and `Node` class are defined but never called.
- Array `d` is created but never used.
- Variable `cl` is declared but never used.
- Array `z` is written to but never read.

## Termination Conditions
- The while loop terminates when either:
  - `result` becomes `true` (all `b[i] == r[i]`), or
  - `good` is `false` after a pass (no movement occurred).
