# Structured Description of Code

## Function: vestigial(pinax)

### Input
- `pinax`: A 2D list (matrix) of integers, assumed to be square (equal number of rows and columns).

### Output
- Returns a list of three integers: `[trail, same_row_counter, sumC]`

### Processing Steps

1. **Initialization**
   - `size` is set to the length of the first row of `pinax` (number of columns, assumed equal to number of rows).
   - `result` is initialized as an empty list.
   - `row_digits` is initialized as an empty list.
   - `column_digits` is initialized as a list of `size` empty lists.
   - `same_row_counter` is initialized to 0.
   - `same_column_counter` is initialized to a list of `size` zeros.
   - `trail` is initialized to 0.

2. **Main Loop (rows and columns)**
   - For each `row` from 0 to `size-1`:
     - Clear `row_digits` (delete all its contents).
     - For each `column` from 0 to `size-1`:
       - **Diagonal check**: If `row == column`, add `pinax[row][row]` to `trail`.
       - **Row duplicate check**: If the current length of `row_digits` equals `column`:
         - Iterate `i` from 0 to `len(row_digits)`:
           - If `i` equals `len(row_digits)`, append `pinax[row][column]` to `row_digits` and break.
           - Else if `row_digits[i]` equals `pinax[row][column]`, increment `same_row_counter` by 1 and break.
       - **Column duplicate check**: For each `i` from 0 to `len(column_digits[column])`:
         - If `i` equals `len(column_digits[column])`, append `pinax[row][column]` to `column_digits[column]` and break.
         - Else if `column_digits[column][i]` equals `pinax[row][column]`, set `same_column_counter[column]` to 1 and break.

3. **Summation**
   - After the main loop, `sumC` is computed by summing all elements of `same_column_counter`.

4. **Result Construction**
   - Append `trail` to `result`.
   - Append `same_row_counter` to `result`.
   - Append `sumC` to `result`.
   - Return `result`.

### Key Behaviors
- `trail` accumulates the sum of the main diagonal elements.
- `same_row_counter` counts the total number of duplicate values found within each row (only checked when the row_digits list length matches the current column index).
- `same_column_counter` marks each column as having a duplicate (set to 1) if any duplicate is found in that column; `sumC` is the count of columns with at least one duplicate.

## Function: main()

### Input
- Reads from standard input:
  - First line: integer `testCases` (number of test cases).
  - For each test case:
    - First line: integer `size` (matrix dimension).
    - Next `size` lines: each contains `size` space-separated integers.

### Processing
- For each test case:
  - Creates `pinax` as a list of `size` empty lists.
  - Populates each row of `pinax` by reading a line, splitting it, converting to integers, and assigning to the corresponding row.
  - Calls `vestigial(pinax)` to get the result.
  - Prints output in format: `Case #<index>: <trail> <same_row_counter> <sumC>` where `<index>` is the zero-based test case number.

### Output
- Prints one line per test case to standard output.

## Control Flow Summary
- Two nested loops in `vestigial` iterate over all matrix elements.
- Conditional branches handle diagonal detection, row duplicate detection, and column duplicate detection.
- A final loop sums the column duplicate flags.
- `main` uses a loop over test cases and a nested loop to read matrix rows.
