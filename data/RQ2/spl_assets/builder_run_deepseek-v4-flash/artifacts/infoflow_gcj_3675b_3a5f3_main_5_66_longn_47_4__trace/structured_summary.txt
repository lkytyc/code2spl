## Inputs
- Reads an integer `ntests` from standard input, representing the number of test cases.
- For each test case, reads an integer `s` (the number of elements in that case).
- For each of the `s` elements, reads three long integers: `D[i]`, `A[i]`, and `B[i]`.

## Outputs
- For each test case, prints a line in the format: `Case #<test>: <max> <max_no>`
  - `<test>` is the 1-based test case number.
  - `<max>` is the maximum value found among computed lengths.
  - `<max_no>` is the count of positions achieving that maximum.

## Data Structures
- Arrays `D`, `A`, `B`, `M`, `N` are long integer arrays of size `MAXS` (10005).
- Arrays `longm` and `longn` are integer arrays of size `MAXS`.
- Scalar variables: `ntests`, `test`, `s`, `i`, `j`, `max`, `max_no`.

## Computed Values
- For each index `i` (0-based):
  - `M[i] = D[i] + A[i]`
  - `N[i] = D[i] - B[i]`

## Control Flow

### Main Loop (test cases)
- Iterates `test` from 1 to `ntests` inclusive.

### Per-Test-Case Processing

#### Input Reading
- Reads `s`.
- Loops `i` from 0 to `s-1`, reading three values into `D[i]`, `A[i]`, `B[i]`, then computing `M[i]` and `N[i]`.

#### Initialization
- Sets `longm[0] = 1` and `longn[0] = 1`.

#### Length Computation Loop (i from 1 to s-1)
For each `i`, two independent computations occur:

**For `longm[i]`:**
- If `M[i] == M[i-1]`, then `longm[i] = longm[i-1] + 1`.
- Otherwise:
  - Initialize `longm[i] = 2`.
  - Set `j = i-2`.
  - While `j >= 0` AND (`M[j] == M[i]` OR `N[j] == N[i-1]`):
    - Increment `longm[i]`.
    - Decrement `j`.

**For `longn[i]`:**
- If `N[i] == N[i-1]`, then `longn[i] = longn[i-1] + 1`.
- Otherwise:
  - Initialize `longn[i] = 2`.
  - Set `j = i-2`.
  - While `j >= 0` AND (`N[j] == N[i]` OR `M[j] == M[i-1]`):
    - Increment `longn[i]`.
    - Decrement `j`.

#### Maximum Finding
- Initializes `max = getmax(longm[0], longn[0])` and `max_no = 1`.
- Loops `i` from 1 to `s-1`:
  - Computes `current = getmax(longm[i], longn[i])`.
  - If `current > max`: sets `max = current`, resets `max_no = 1`.
  - Else if `current == max`: increments `max_no`.

#### Output
- Prints the formatted result for the current test case.

## Function Calls
- Calls `getmax(a, b)` which returns the larger of two long integers `a` and `b`. If `a > b`, returns `a`; otherwise returns `b`.

## Data Dependencies
- `M[i]` depends on `D[i]` and `A[i]`.
- `N[i]` depends on `D[i]` and `B[i]`.
- `longm[i]` depends on `M` values at indices `i`, `i-1`, and potentially earlier indices (via the backward while loop), and also on `N` values at index `i-1` and earlier.
- `longn[i]` depends on `N` values at indices `i`, `i-1`, and potentially earlier indices, and also on `M` values at index `i-1` and earlier.
- The final `max` and `max_no` depend on all `longm` and `longn` values.

## Edge Cases
- If `s == 1`, the length computation loop is skipped; `max` is `getmax(1,1) = 1` and `max_no = 1`.
- The backward while loops can potentially scan back to index
