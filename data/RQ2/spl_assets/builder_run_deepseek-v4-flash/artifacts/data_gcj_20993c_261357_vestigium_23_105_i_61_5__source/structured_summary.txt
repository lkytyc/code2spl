## Program Overview
This program reads multiple square matrices from standard input, computes a trace and duplicate detection metrics for each matrix, and outputs formatted results.

## Input
- First integer `t`: number of test cases
- For each test case:
  - Integer `n`: matrix dimension
  - `n × n` integers: matrix elements read row by row

## Output
For each test case, one line in the format:  
`Case #<caseNumber>: <trace> <rowDuplicates> <columnDuplicates>`

## Main Function Control Flow
1. Creates a Scanner for standard input
2. Reads test case count `t`
3. Loops `t` times (decrementing `t` each iteration):
   - Reads matrix dimension `n`
   - Creates `n × n` integer array
   - Nested loops read all matrix elements
   - Calls `vestigium(a, n)` with the matrix and dimension

## Vestigium Function Logic

### Trace Calculation
- Initializes `k = 0`
- Loops through diagonal elements `a[i][i]` for `i = 0` to `n-1`
- Accumulates sum into `k`

### Matrix Transposition
- Creates new `n × n` array `b`
- Nested loops assign `b[i][j] = a[j][i]` to create transpose

### Row Duplicate Detection
- Sorts each row of matrix `a` using `Arrays.sort()`
- For each row, compares adjacent elements after sorting
- Counts consecutive duplicates using `repeat` counter
- Tracks maximum duplicate count in `count` variable
- Resets `repeat` to 0 after each row if duplicates were found

### Column Duplicate Detection
- Sorts each row of transposed matrix `b` (equivalent to sorting columns of original)
- Uses same adjacent comparison logic
- Tracks maximum duplicate count in `count1` variable

### Output Logic
- Sets `r = count + 1` and `c = count1 + 1`
- Uses a `counter` variable initialized to 1 (note: this is not incremented per test case in the calling code, so it remains 1 for all cases)
- Four conditional branches determine output format:
  1. If both `count` and `count1` are 0: outputs `k`, `count`, `count1`
  2. If both are non-zero: outputs `k`, `r`, `c`
  3. If only `count1` is 0: outputs `k`, `r`, `count1`
  4. If only `count` is 0: outputs `k`, `count`, `c`

## Data Dependencies
- Matrix `a` is modified in-place by sorting rows
- Transposed matrix `b` is derived from original matrix before sorting
- Trace calculation uses original matrix before any sorting
- Duplicate counts depend on sorted versions of rows and columns

## Notable Behavior
- The `counter` variable is local to `vestigium` and always starts at 1 for each call
- The output format includes extra spaces after the colon
- Row and column duplicate counts are incremented by 1 when non-zero (via `r` and `c` variables)
- The duplicate detection counts consecutive equal elements after sorting, which identifies any repeated values in a row/column
