## Overview
This program computes minimum transportation costs for N facilities, where each facility can be assigned to either a horizontal or vertical axis, and the cost depends on distances to assigned axes or to other facilities assigned to the same axis.

## Inputs
- First line: integer N (number of facilities)
- Next N lines: three integers each - X[i], Y[i], P[i] representing x-coordinate, y-coordinate, and weight of facility i

## Outputs
- N+1 lines, each containing a long integer: the minimum total cost for using exactly k axes (where k ranges from 0 to N)

## Data Structures
- Arrays X, Y, P, a: size 20 each, storing coordinates, weights, and assignment states
- Z[1<<16][16][2]: 3D array storing minimum distances for each subset of facilities (bitmask), each facility, and each axis type (0=horizontal, 1=vertical)
- ans[20]: array storing minimum costs for each possible number of used axes

## Initialization
- Reads N and facility data
- Initializes ans[0] through ans[N] to a very large value (1<<60)
- For each subset mask (0 to 2^N - 1) and each facility j:
  - Initializes Z[mask][j][0] to absolute value of X[j] (distance to origin on x-axis)
  - Initializes Z[mask][j][1] to absolute value of Y[j] (distance to origin on y-axis)
  - For each facility k in the subset, updates these distances to the minimum of current value and distance to facility k

## Main Computation Loop
Iterates through all possible assignments using a counter array `a` (base-3 counter where 0=unassigned, 1=horizontal, 2=vertical):

1. **Build bitmasks**: 
   - `h` = bitmask of facilities assigned to horizontal axis (a[i]==1)
   - `v` = bitmask of facilities assigned to vertical axis (a[i]==2)

2. **Count used axes**: `t` = popcount of (h|v), representing how many distinct axes are used

3. **Compute total cost**: For each facility i:
   - Cost contribution = P[i] × min(Z[h][i][0], Z[v][i][1])
   - This represents: weight × minimum distance to either the horizontal axis (considering facilities in h) or vertical axis (considering facilities in v)

4. **Update answer**: ans[t] = minimum of current ans[t] and computed sum

5. **Increment counter**: Advances the base-3 counter `a` (skipping over trailing 2's, incrementing the next digit)

## Termination
The loop continues until the counter `a[N]` becomes non-zero (i.e., all possible assignments have been tried)

## Final Output
Prints ans[0] through ans[N], representing minimum costs for using 0, 1, 2, ..., N axes respectively

## Key Functions
- **popcount(n)**: Recursively counts set bits in integer n (returns 0 for n=0, otherwise adds least significant bit to popcount of n>>1)
- **min(a,b)**: Macro returning the smaller of two values

## Control Flow
- Nested loops for Z array initialization (subset × facility × subset members)
- Single while loop enumerating all 3^N possible assignments
- Inner loops for building bitmasks and computing costs
- Final loop for output
