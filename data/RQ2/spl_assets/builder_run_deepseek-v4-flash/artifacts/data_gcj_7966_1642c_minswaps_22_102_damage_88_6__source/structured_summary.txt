# Code Description

## Overview
This program reads a number of test cases, each containing a damage threshold and a string of characters ('S' for shoot and 'C' for charge), then calculates the minimum number of adjacent swaps needed to reduce the total damage to at most the threshold. If impossible, it reports "IMPOSSIBLE".

## Input
- First line: integer `n` (number of test cases)
- For each test case:
  - An integer `d` (maximum allowed damage)
  - A string `p` (up to 30 characters, consisting of 'S' and 'C')

## Output
- For each test case: `Case #X: result` where X is the case number (1-based) and result is either the minimum swap count or "IMPOSSIBLE"

## Main Function Logic
1. Reads the number of test cases `n`
2. Loops through each test case:
   - Reads the damage threshold `d`
   - Reads the string `p`
   - Calls `minswaps(p, d, strlen(p))`
   - Prints the result with case numbering

## minswaps Function Logic

### Base Case (len == 2)
Handles two-character strings directly:
- "SC": returns 0 (already valid)
- "SS": returns -1 if d < 2, otherwise 0
- "CS": returns 1 if d < 2, otherwise 0
- Any other combination: returns 0

### General Case (len > 2)

**Initialization:**
- Sets initial strength = 1, damage = 0
- Allocates an integer array `a` of size `len` to track strength values

**First Pass - Calculate Damage and Strength Array:**
- Iterates through the string:
  - For 'S': adds current strength to damage, stores strength in array
  - For 'C': doubles the strength, stores new strength in array

**Early Exit:**
- If damage is already ≤ d, returns 0 (no swaps needed)

**Swap Loop:**
- Uses a flag-based loop that continues until no more beneficial swaps can be made
- Starts from the end of the string and works backward
- Finds the rightmost 'S' character
- If the character before it is also 'S', moves left
- If the character before it is 'C', performs a swap:
  - Swaps the 'S' and 'C' positions
  - Updates damage: subtracts the strength value at the 'S' position, then adds the new strength value after the swap
  - Updates the strength array values for the swapped positions
  - Increments swap counter
- Breaks out of inner loop if at position 1 and both characters are 'S'

**Final Check:**
- After the loop, if damage ≤ d, returns the swap count
- Otherwise returns -1 (impossible)

## Key Data Dependencies
- The strength array `a` tracks the damage contribution of each position
- Damage is updated incrementally during swaps rather than recalculated
- The swap operation modifies both the string and the strength array
- The loop termination depends on whether damage still exceeds the threshold

## Control Flow Summary
- Main loop: iterates over test cases
- First pass loop: computes initial damage and strength values
- Outer while loop: continues until no swaps are possible or damage is acceptable
- Inner while loop: finds and performs swaps from right to left
- Break condition: stops when reaching the leftmost position with consecutive 'S' characters
