# Code Structure Description

## Overview
This Java program reads test cases from standard input, processes each one to find a pair of integers (x, y) that satisfies a specific ordering condition relative to a set of input points, and outputs the result for each test case.

## Input Processing
- The program reads an integer T from standard input representing the number of test cases.
- For each test case, it reads an integer N representing the number of points.
- It then reads N lines, each containing two integers (x, y) that define a point.

## Main Control Flow
- The main method iterates through each test case (loop from 1 to T).
- For each test case, it calls the solve method and prints "Case #i: " followed by the result.
- After processing all test cases, the output buffer is flushed.

## solve Method
- Reads N from input.
- Creates a list of P objects (points) from the input.
- Calls getRes with the count and list of points.
- Returns the result string.

## getRes Method (Core Logic)
This method determines whether a valid pair (x, y) exists and computes it.

### Point Pair Analysis
- Iterates through all pairs of points (i, j) where j > i.
- For each pair, computes differences d1 = p1.a - p2.a and d2 = p1.b - p2.b.
- If both differences are zero OR both are positive, sets hasDup flag to true and breaks.
- If both differences are non-zero and at least one is positive:
  - If d1 is negative, adds a fraction (|d1|/|d2|) to the "positive" set (pfracs).
  - If d2 is negative, adds a fraction (|d1|/|d2|) to the "negative" set (nfracs).

### Fraction Sets
- Uses TreeSet collections to store fractions (F objects) in sorted order.
- Fractions are reduced to lowest terms using GCD.

### Decision Logic
- If duplicate points or same-direction differences were found, returns "IMPOSSIBLE".
- Gets the smallest fraction from pfracs (above) and largest from nfracs (below).
- If both sets are non-empty and above ≤ below, returns "IMPOSSIBLE".
- If both sets are empty, returns "1 1".
- If only below exists (no above), computes y based on the fraction and returns "1 (y+1)".
- If only above exists (no below), computes x based on the fraction and returns "(x+1) 1".
- If both exist, computes a common denominator, finds the difference, and returns "x (x+1)" where x is computed from the fraction difference.

### Arithmetic Operations
- For single-set cases: computes ceiling division of denominator by numerator, then adds 1.
- For both-set case: computes least common denominator, scales numerators, subtracts, and computes ceiling division of 2*LCD by the difference.

## check Method (Validation)
- Returns true immediately if result is "IMPOSSIBLE".
- Otherwise, parses the result into x and y integers.
- Computes v[i] = point.a * x + point.b * y for each point.
- Creates a copy of v, sorts the copy, and checks if the sorted version equals the original.
- If not equal, calls debug to print the arrays.
- Returns whether the arrays are equal.

## Helper Classes

### P Class
- Simple data holder with two integer fields (a, b).
- Constructor initializes both fields.

### F Class (Fraction)
- Stores numerator (num) and denominator (denum).
- Constructor reduces the fraction using GCD.
- Implements Comparable interface.
- compareTo method compares fractions by cross-multiplying with common denominator.

## Helper Methods
- gcd: Recursive Euclidean algorithm for greatest common divisor.
- debug: Prints array contents to standard output.

## Data Dependencies
- The result depends on all input points.
- The fraction sets depend on pairwise differences between points.
- The final output depends on the relationship between the two fraction sets.
- The check method validates the computed result against the original points.
