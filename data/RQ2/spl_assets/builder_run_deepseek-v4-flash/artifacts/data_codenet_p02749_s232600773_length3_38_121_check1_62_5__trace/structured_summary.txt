# Structured Description

## Input
- Reads a single integer `n` from standard input (number of vertices).
- Reads `n-1` lines, each containing two integers `a` and `b`, representing an undirected edge between vertices `a` and `b` (1-indexed input, converted to 0-indexed internally).

## Output
- Prints a single line containing `n` space-separated integers, representing the assigned value for each vertex (1-indexed positions).
- If no valid assignment exists, prints `-1` and terminates.

## Main Function Flow

### Graph Construction
- Creates an adjacency list `g` of size `n`.
- For each of the `n-1` edges, adds both directions to the adjacency list.

### Breadth-First Search (BFS)
- Calls `bfs(n, g)` starting from vertex 0.
- Returns:
  - `dis`: distance array from vertex 0
  - `cnt_odd`: count of vertices at odd distance
  - `cnt_even`: count of vertices at even distance (including vertex 0)

### First Branch: Small Color Class
- If `min(cnt_even, cnt_odd) <= n//3`:
  - Creates a `check` array of size `n` initialized to 1.
  - If `cnt_even <= cnt_odd`:
    - Assigns values `3, 6, 9, ...` (multiples of 3) to vertices at even distances.
    - Marks corresponding positions in `check` as 0.
    - Fills remaining unassigned vertices with the smallest available numbers (1, 2, 4, 5, 7, 8, ...) in order.
  - If `cnt_even >= cnt_odd`:
    - Same logic but assigns multiples of 3 to vertices at odd distances instead.
  - Prints the result and returns.

### Second Branch: Larger Color Classes
- If `min(cnt_even, cnt_odd) > n//3`:
  - Creates `check` array initialized to 1.
  - If `cnt_even <= cnt_odd`:
    - Assigns multiples of 3 to even-distance vertices while `3*x <= n`.
    - Vertices that cannot receive multiples of 3 are added to `remain` list.
    - Creates two deques:
      - `que_1`: contains numbers congruent to 1 mod 3 (1, 4, 7, ...)
      - `que_2`: contains numbers congruent to 2 mod 3 (2, 5, 8, ...)
    - For each vertex in `remain`, calls `length3` to assign values.
    - Fills any remaining unassigned vertices by popping from `que_1` first, then `que_2`.
  - If `cnt_even > cnt_odd`:
    - Same logic but assigns multiples of 3 to odd-distance vertices instead.

## Helper Function: bfs(n, g)
- Performs BFS from vertex 0.
- Tracks visited vertices and distances.
- Counts vertices at even and odd distances.
- Returns distance array and both counts.

## Helper Function: length3(s, n, g, ans, que_1, que_2)
- Performs BFS from vertex `s` up to distance 3.
- Collects vertices at exactly distance 3 from `s` into `see` list.
- Examines values already assigned to vertices in `see`:
  - Counts how many have values ≡ 1 mod 3 (`check1`)
  - Counts how many have values ≡ 2 mod 3 (`check2`)
- Branching logic:
  - If both `check1 > 0` and `check2 > 0`: prints -1 and exits.
  - If only `check1 > 0`: assigns `s` a value from `que_2`, assigns unassigned vertices in `see` values from `que_1`.
  - If only `check2 > 0`: assigns `s` a value from `que_1`, assigns unassigned vertices in `see` values from `que_2`.
  - If neither: chooses based on which queue is longer:
    - If `que_1` is longer: assigns `s` from `que_2`, assigns `see` vertices from `que_1`.
    - Otherwise: assigns `s` from `que_1`, assigns `see` vertices from `que_2`.
- Returns updated `ans`, `que_1`, `que_2`.
- Prints -1 and exits if required queue is empty.
