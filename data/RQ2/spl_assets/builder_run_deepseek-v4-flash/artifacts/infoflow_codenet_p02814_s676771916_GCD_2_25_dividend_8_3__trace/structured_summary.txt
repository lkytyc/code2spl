# Structured Description

## Function: GCD

**Inputs:** Two long integers, `a` and `b`.

**Output:** Returns a long integer representing the greatest common divisor of `a` and `b`.

**Control Flow:**
- First, the function determines which input is larger. If `a >= b`, then `a` becomes the dividend and `b` becomes the divisor. Otherwise, `b` becomes the dividend and `a` becomes the divisor.
- The function then enters an infinite loop.
- Inside the loop, if the divisor equals 1, the function immediately returns 1.
- Otherwise, it computes the remainder of dividing the dividend by the divisor.
- If the remainder is 0, the loop breaks.
- If the remainder is non-zero, the dividend is set to the old divisor, and the divisor is set to the remainder, then the loop repeats.
- After the loop breaks, the function returns the current divisor value.

**Data Dependencies:** The function uses only its two input parameters and local variables. The result depends entirely on the values of `a` and `b`.

## Function: main

**Inputs:** 
- Reads two long integers from standard input: `n` and `m`.
- Then reads `n` additional long integers into an array `a`.

**Outputs:** Prints a single long integer to standard output and returns 0.

**Control Flow and Processing:**

1. **Array Declaration:** Declares an array `a` of size `n` (variable-length array).

2. **Input Loop:** A for loop runs from index 0 to `n-1`, reading each value into `a[i]`.

3. **LCM Calculation:**
   - Initializes `lcm_all` to the first element of the array (`a[0]`).
   - A for loop runs from index 1 to `n-1`.
   - For each iteration, it computes the least common multiple (LCM) of the current `lcm_all` and `a[i]` using the formula: `(lcm_all / GCD(lcm_all, a[i])) * a[i]`.
   - After each LCM update, if the result exceeds 3,000,000,000, it caps `lcm_all` at exactly 3,000,000,000.

4. **Half Calculation:** Computes `half` as `lcm_all / 2` (integer division).

5. **Validation Loop:**
   - A for loop runs from index 0 to `n-1`.
   - For each element `a[i]`, it checks whether `half % a[i]` equals `a[i] / 2`.
   - If this condition fails for any element, the program prints "0" and terminates immediately (returns 0).

6. **Final Calculation:**
   - Computes `mod` as `m % lcm_all`.
   - Computes `ans` as `m / lcm_all` (integer division).
   - If `mod >= half`, increments `ans` by 1.

7. **Output:** Prints the final value of `ans` followed by a newline.

**Data Dependencies:**
- The LCM calculation depends on all array elements and the GCD function.
- The validation loop depends on the computed `half` and each array element.
- The final answer depends on `m`, `lcm_all`, and `half`.
- The program terminates early (printing 0) if the validation condition fails for any array element.

**Function Calls:** The main function calls the GCD function multiple times within the LCM calculation loop.
