# Structured Description

## Input
- Reads a single integer `n` from standard input (number of vertices).
- Reads `n-1` lines, each containing two integers `a` and `b` representing an undirected edge between vertices `a` and `b` (1-indexed in input, converted to 0-indexed internally).

## Output
- Prints a single line containing `n` space-separated integers, representing the assigned value for each vertex (1-indexed positions).
- If no valid assignment exists, prints `-1` and terminates.

## Main Function Logic

### Graph Construction
- Creates an adjacency list `g` of size `n`.
- For each of the `n-1` edges, adds both directions to the adjacency list.

### Breadth-First Search (BFS)
- Calls the `bfs` function starting from vertex 0.
- Returns:
  - `dis`: distance array from vertex 0 to all vertices.
  - `cnt_odd`: count of vertices at odd distance from vertex 0.
  - `cnt_even`: count of vertices at even distance from vertex 0 (including vertex 0 itself).

### First Branch: Small Color Class
- If `min(cnt_even, cnt_odd) <= n//3`:
  - Initializes `check` array of size `n` with all 1s (indicating available numbers).
  - If `cnt_even <= cnt_odd`:
    - Assigns multiples of 3 (3, 6, 9, ...) to vertices at even distance from vertex 0, in order of vertex index.
    - Marks these numbers as used in `check`.
    - Fills remaining unassigned vertices with the smallest available numbers (1, 2, 4, 5, ...) in order of vertex index.
  - If `cnt_even >= cnt_odd`:
    - Assigns multiples of 3 to vertices at odd distance from vertex 0.
    - Fills remaining vertices with smallest available numbers.
  - Prints the result and returns.

### Second Branch: Larger Color Classes
- If `min(cnt_even, cnt_odd) > n//3`:
  - Initializes `check` array with all 1s.
  - If `cnt_even <= cnt_odd`:
    - Iterates through vertices at even distance from vertex 0.
    - Assigns multiples of 3 (3*x) while `3*x <= n`, incrementing `x`.
    - Vertices that cannot receive a multiple of 3 are added to `remain` list.
  - If `cnt_even > cnt_odd`:
    - Same process but for vertices at odd distance from vertex 0.
  - Creates two deques:
    - `que_1`: contains numbers congruent to 1 modulo 3 (1, 4, 7, ...).
    - `que_2`: contains numbers congruent to 2 modulo 3 (2, 5, 8, ...).
  - For each vertex in `remain`, calls the `length3` function to assign values.
  - After processing all remaining vertices, fills any still-unassigned vertices by popping from `que_1` first, then `que_2`.
  - Prints the result.

## Helper Function: bfs(n, g)
- Performs BFS from vertex 0.
- Uses a deque for traversal.
- Tracks visited vertices and distances.
- Counts vertices at even and odd distances.
- Returns distance array, odd count, and even count.

## Helper Function: length3(s, n, g, ans, que_1, que_2)
- Performs BFS from vertex `s` up to distance 3.
- Collects vertices at exactly distance 3 from `s` into `see` list.
- Examines the current assigned values (`ans`) of vertices in `see`:
  - Counts how many have values congruent to 1 modulo 3 (`check1`).
  - Counts how many have values congruent to 2 modulo 3 (`check2`).
- Branching logic:
  - If both `check1 > 0` and `check2 > 0`: prints `-1` and exits.
  - If only `check1 > 0`: assigns `s` a value from `que_2` (congruent to 2 mod 3), and assigns unassigned vertices in `see` values from `que_1`.
  - If only `check2 > 0`: assigns `s` a value from `que_1`, and assigns unassigned vertices in `see` values from `que_2`.
