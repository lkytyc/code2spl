# Code Structure Description

## Overview
This program reads a 2D grid of integers, processes cells with odd values, and outputs a sequence of coordinate pairs representing movements between odd-valued cells.

## Input
- Two integers: height `h` and width `w` of a grid
- A grid of `h` rows × `w` columns containing integer values

## Output
- First line: number of coordinate pairs (half the size of the collected coordinate list)
- Following lines: pairs of coordinates, each coordinate printed as `(row+1) (column+1)` with space separation

## Main Processing Logic

### Grid Reading
- Reads height and width from input
- Populates a 2D integer array `a` with grid values

### Coordinate Collection
- Maintains two lists: `x` (column coordinates) and `y` (row coordinates)
- Uses a boolean flag `flag` to track state
- Tracks previous coordinates in `prex` and `prey`

### Traversal Pattern
- Iterates through rows from top to bottom
- For even-indexed rows (0-based): traverses columns left to right
- For odd-indexed rows: traverses columns right to left (snake pattern)

### Cell Processing
For each cell, determines if the value is odd:
- **Odd value with flag true**: Toggles flag to false, records a coordinate pair from previous position to current position, updates previous position
- **Odd value with flag false**: Toggles flag to true, updates previous position without recording
- **Even value with flag true**: Records a coordinate pair from previous position to current position, updates previous position
- **Even value with flag false**: No action taken

### Output Generation
- Prints the count of coordinate pairs (list size divided by 2)
- Iterates through the coordinate lists in pairs
- For even indices: prints row+1, space, column+1 without newline
- For odd indices: prints row+1, space, column+1 with newline

## Helper Classes

### Scanner Class
- Custom scanner using BufferedReader
- `nextInt()`: Parses integers with optional sign, handles overflow checks
- `nextLong()`: Similar to nextInt but for long values
- `next()`: Reads printable character sequences
- `nextLine()`: Reads until newline or carriage return
- `close()`: Closes the underlying reader

### Printer Class
- Extends PrintWriter for output operations

## Data Dependencies
- The flag state and previous coordinates depend on all previously processed cells
- Coordinate recording depends on both current cell parity and flag state
- Output format depends on position in the coordinate list (even/odd index)
