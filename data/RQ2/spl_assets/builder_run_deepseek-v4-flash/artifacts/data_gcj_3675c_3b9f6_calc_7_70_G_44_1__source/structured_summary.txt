## Overview
This program processes multiple test cases, each involving a set of M items with associated values and a graph-like structure defined by two parent indices per item. It computes a result R through an iterative process that distributes values along the graph until a termination condition is met.

## Input
- First line: integer T (number of test cases)
- For each test case:
  - First line: integer M (number of items)
  - Next M lines: two integers per line (r1[i], r2[i]), each decremented by 1 after reading
  - Next M lines: one long long integer per line (G[i])

## Output
For each test case, prints "Case #t: " followed by the computed integer R.

## Data Structures
- r1, r2: integer arrays of size M (parent indices, 0-based after decrement)
- G: long long array of size M (initial values)
- f: long long array of size M (flow values, initialized to 0)
- M, S, R: integers (M = item count, S = sum of G, R = result accumulator)
- g, s: integers (g = selected index, s = accumulated flow counter)

## Initialization
- Read M
- Allocate arrays r1, r2, G, f
- Read r1[i], r2[i] pairs and decrement each by 1
- Read G[i] values, initialize f[i] = 0, accumulate S = sum of all G[i]
- Set f[0] = 1
- Set s = 1

## Main Processing Loop
The loop continues while s <= S:

1. **Find minimum ratio**: 
   - Initialize n = INT_MAX
   - For each j from 0 to M-1, if f[j] > 0, compute G[j] / f[j] (integer division) and track the minimum value in n, storing the index in g

2. **If n > 0**:
   - Add n to R
   - For each j where f[j] > 0, subtract f[j] * n from G[j] and from S

3. **Update graph values**:
   - Add G[g] to G[r1[g]] and G[r2[g]]
   - Store a = f[g]
   - Add a to s

4. **Check termination**:
   - If s > S, free all arrays and print R, then return

5. **Update flow**:
   - Set f[g] = 0
   - Add a to f[r1[g]] and f[r2[g]]

## Termination
The loop ends when either:
- s > S (checked inside loop, triggers early return)
- s <= S becomes false (loop condition fails)

In both cases, arrays are freed and R is printed.

## Main Function
- Reads T
- For each test case t from 1 to T:
  - Prints "Case #t: "
  - Calls calc()
- Returns EXIT_SUCCESS

## Key Dependencies
- The computation of n depends on current values of G and f
- The update of G depends on the selected index g and its parent indices
- The flow update depends on the same selected index g
- The termination condition depends on s and S, both of which are modified during processing
- The result R accumulates the minimum ratios found during each iteration
