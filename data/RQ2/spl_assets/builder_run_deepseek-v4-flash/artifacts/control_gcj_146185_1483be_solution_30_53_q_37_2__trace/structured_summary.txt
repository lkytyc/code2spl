## Inputs
- First integer `t` specifies the number of test cases.
- For each test case:
  - An integer `numOfElem` specifies the number of elements/edges.
  - Then `numOfElem` pairs of integers are read, each representing a connection between two nodes (1-indexed, converted to 0-indexed internally).
  - Then `numOfElem` integers are read into an array `startElem`.

## Processing per Test Case

### Graph Construction
- A graph is built as a map from node indices to lists of edge indices.
- For each pair (x, y) read:
  - Both x and y are decremented by 1 to convert to 0-indexed.
  - If either node is not yet in the graph map, it is added with an empty linked list.
  - The current edge index `i` (from 0 to numOfElem-1) is appended to both node x's list and node y's list.

### Initial Value Array
- The `startElem` array is filled with `numOfElem` integers read from input.

### Solution Determination
- If node 0 is not present in the graph, the solution is simply `startElem[0]`.
- Otherwise, the `solution` method is called with the graph, `numOfElem`, and `startElem`.

## Solution Method Logic

### Initialization
- A visited set is created and node 0 is added to it.
- A queue is initialized.
- The result starts as `startElem[0]`.
- All edges connected to node 0 (from `graph.get(0)`) are added to the queue, except edge index 0 itself.

### Traversal Loop
- While the queue is not empty:
  - Dequeue an edge index `next`.
  - For each node `neighbor` connected to that edge (from `graph.get(next)`):
    - If the neighbor is already in the visited set, set a flag `acyclic` to true.
    - Otherwise:
      - Add `startElem[neighbor]` to the result.
      - Add the neighbor to the queue.
      - Add the neighbor to the visited set.

### Return Value
- If the `acyclic` flag was set (meaning a cycle was detected):
  - Return 0 if the accumulated result equals 0, otherwise return -1.
- If no cycle was detected, return the accumulated result.

## Output
- For each test case, output: `Case #<test_case_number>: <result>`
- The test case number starts at 1.
- If the result is -1, output "UNBOUNDED" instead of the number.
- Otherwise, output the numeric result.

## Control Flow Summary
- Outer loop iterates over test cases.
- Inner loop builds the graph from edge pairs.
- Another loop reads the start values.
- Conditional check determines whether to call the solution method or use the direct value.
- The solution method uses a queue-based traversal with cycle detection and accumulates values from the start array.
