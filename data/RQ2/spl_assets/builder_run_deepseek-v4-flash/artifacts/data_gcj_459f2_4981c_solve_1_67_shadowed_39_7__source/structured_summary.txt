# Structured Description of Code

## Function: solve(B)

### Input
- B: A list of integers representing ball counts at each column position.

### Output
- Returns a tuple containing:
  - Either the string 'IMPOSSIBLE' with None as the second element, OR
  - An integer representing the number of rows in the solution grid, and a list of lists (the grid itself).

### Initial Validation
- Checks if the first element (B[0]) or last element (B[-1]) equals zero.
- If either is zero, immediately returns ('IMPOSSIBLE', None).

### Grid Initialization
- Determines C as the length of the input list B.
- Creates a C×C grid filled with '.' characters.
- Creates a shadowed list of boolean values, all initially False, with the first position set to True.
- Decrements B[0] and B[-1] by 1.

### Main Processing Loop
Iterates through each index i from 0 to C-1:

#### Branch 1: Skip Condition
- If B[i] equals 0 AND shadowed[i] is True, skips to next iteration.

#### Branch 2: Unshadowed Position with Balls
- If B[i] is greater than 0 AND shadowed[i] is False:
  - Initializes unshadowed_balls counter to 0.
  - Sets j to i-1 and l to 1.
  - While loop: While j >= 1 AND shadowed[j] is False:
    - Places '\' character at grid[l][j].
    - Marks shadowed[j] as True.
    - Increments unshadowed_balls, l, and decrements j.
  - After the while loop:
    - If B[i] <= unshadowed_balls:
      - Calculates excess_balls as (unshadowed_balls - B[i] + 1).
      - Sets j to i.
      - While excess_balls > 1:
        - Decrements j and excess_balls.
        - Sets shadowed[j] to False.
    - Else (B[i] > unshadowed_balls):
      - Subtracts (unshadowed_balls + 1) from B[i].
      - Sets shadowed[i] to True.

#### Branch 3: Shadowed Position with Remaining Balls
- If B[i] is greater than 0 AND shadowed[i] is True:
  - Sets r to B[i].
  - Sets j to i+1 and l to 1.
  - First while loop: While j < (C-1) AND shadowed[j] is True:
    - Places '/' at grid[l][j].
    - Increments l and j.
  - Second while loop: While j < (C-1) AND r > 0:
    - Places '/' at grid[l][j].
    - Sets shadowed[j] to True.
    - Decrements r, increments l and j.

### Result Construction
- Creates an empty ans list.
- Iterates through grid rows from index 1 to C-1:
  - Checks if row contains any '\' or '/' characters.
  - If yes, appends row to ans.
  - If no, breaks out of loop.
- Prepends a row of all '.' characters to ans.
- Returns (len(ans), ans).

## Function: main()

### Input
- Reads T (number of test cases) from standard input.

### Processing
- Loops through test cases from 1 to T:
  - Reads S (unused variable) from input.
  - Reads B_raw as space-separated strings.
  - Converts B_raw to list of integers B.
  - Calls solve(B) to get res and grid.
  - Prints "Case #{t}: {res}" format.
  - If grid is not None:
    - Prints grid rows in reverse order (from last row to first).
    - Each row printed as concatenated characters.

### Entry Point
- Checks if script is run directly (__name__ == "__main__").
- Calls main() if true.

## Key Data Dependencies
- The shadowed list tracks which positions have been processed.
- The grid accumulates ramp characters ('\' and '/') during processing.
- The B list is modified in-place during solve() execution.
- The final answer depends on which rows contain ramp characters.
