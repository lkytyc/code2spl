## Overview
This program implements an interactive protocol solver that communicates with a judge or external system through standard input/output. It processes multiple test cases, each involving a sequence of card or token exchanges with specific rules based on numeric thresholds.

## Input/Output Interface
- **Input**: Read from standard input, consisting of integers, floats, words, or lines depending on the helper function used
- **Output**: Written to standard output as formatted pairs of integers (card position and token value)
- **Debug output**: Written to standard error with timestamp prefix

## Helper Functions
- `debug(x)`: Writes timestamped debug message to standard error
- `read_int()`: Reads and returns a single integer from input
- `read_float()`: Reads and returns a single float from input
- `read_words()`: Reads a line and splits into word list
- `read_ints()`: Reads a line and converts all words to integers
- `read_floats()`: Reads a line and converts all words to floats

## Global Constants
- `ALLVALS`: Set of integers from 1 to 99
- `OT`: Dictionary mapping 19 to 20 and 20 to 19 (opposite values)

## Main Function
- Reads total number of test cases `T` from first input line
- Iterates through test cases 1 through T, calling `solve_test_case()` for each

## solve_test_case() Function

### Phase 1: Initial Token Selection (curd < 54)
- Initializes `curd` to 0
- Loops while `curd` is less than 54:
  - Reads new `curd` value from input
  - If `curd` equals -1, exits program immediately
  - If `curd` is greater than 36, sets token to 100
  - Otherwise, sets token to random integer between 1 and 99
  - Outputs card position as `1 + (curd % 18)` and the token value
  - Flushes output buffer

### Phase 2: Bad Value Collection (curd < 72)
- Continues from previous `curd` value
- Loops while `curd` is less than 72:
  - Reads new `curd` value; exits if -1
  - Computes card position `v` as `1 + (curd % 18)`
  - Outputs card position `v` with token value 0
  - Flushes output
  - Sets offset to 1 if `curd` is less than or equal to 63, otherwise 0
  - Reads a line of integers, counts them, adds offset, and appends `(count + offset, v)` to `badv` list
- Sorts `badv` list after collection completes

### Phase 3: Bad Value Processing Loop
- Enters infinite loop:
  - Takes first element `(i, x)` from sorted `badv` list
  - Reads new `curd` value; exits if -1
  - Outputs card position `x` with random token between 1 and 99
  - Updates first element of `badv` to `(i+1, x)` and re-sorts
  - Flushes output
  - Breaks loop when `curd` equals 95

### Phase 4: Left/Right Value Determination (curd < 99)
- Initializes `lv`, `rv`, and `choice` to None
- Loops while `curd` is less than 99:
  - Reads new `curd` value; exits if -1
  - If `lv` is not set (falsy):
    - Outputs card position 19 with token 0
    - Flushes output
    - Reads integers into set `lv`
    - Continues to next iteration
  - If `rv` is not set (falsy):
    - Outputs card position 20 with token 0
    - Flushes output
    - Reads integers into set `rv`
    - If `choice` is not set, assigns 19 if `len(lv) > len(rv)`, otherwise 20
    - Continues to next iteration
  - Otherwise (both sets established):
    - Outputs card position `choice` with random token between 1 and 99
    - Flushes output

### Phase 5: Final Selection
- After loop exits (curd >= 99):
  - Sets `choice` to its opposite value using `OT` dictionary
  - Reads one more `curd` value; exits if -1
  - Outputs card position `choice` with token value 100
  - Flushes output

## Control Flow Summary
- Program exits immediately whenever input value -1 is encountered
