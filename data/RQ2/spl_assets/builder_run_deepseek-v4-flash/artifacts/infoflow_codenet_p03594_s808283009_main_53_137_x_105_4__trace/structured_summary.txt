## Program Overview
This program reads three integers from standard input and generates a grid coloring based on those values. It assigns one of four colors to each cell in a grid while ensuring that cells within a certain Manhattan distance constraint do not share the same color.

## Input
- Three integers read from standard input in order:
  - `h`: number of rows in the grid
  - `w`: number of columns in the grid
  - `d`: a distance parameter

## Output
- A grid of `h` rows, each containing `w` characters, where each character is one of: `R`, `Y`, `G`, or `B`
- Each row is terminated by a newline character

## Data Structures
- A 2D integer array `ans` of size `h × w` stores color indices (0-3) for each cell, initialized to -1
- A boolean array `not` of size 4 tracks which colors are forbidden for the current cell
- A character array `c` maps color indices to output characters: index 0→'R', 1→'Y', 2→'G', 3→'B'

## Main Algorithm

### Grid Initialization
- All cells in the `ans` array are initialized to -1

### Cell Processing (row-major order)
For each cell at position `(i, j)`:
1. Create a boolean array `not` with all entries initially false
2. Check four diagonal directions from the current cell, each extending distance `d`:

   **Direction 1: Down-right diagonal**
   - Start at `(x=j+d, y=i)`
   - Iterate while `y <= i+d`, decrementing `x` and incrementing `y` each step
   - Skip if `x >= w` or `y >= h`
   - If the visited cell already has a color, mark that color as forbidden

   **Direction 2: Up-right diagonal**
   - Start at `(x=j+d, y=i)`
   - Iterate while `y >= i-d`, decrementing both `x` and `y` each step
   - Skip if `x >= w` or `y < 0`
   - If the visited cell already has a color, mark that color as forbidden

   **Direction 3: Down-left diagonal**
   - Start at `(x=j-d, y=i)`
   - Iterate while `y <= i+d`, incrementing `x` and incrementing `y` each step
   - Skip if `x < 0` or `y >= h`
   - If the visited cell already has a color, mark that color as forbidden

   **Direction 4: Up-left diagonal**
   - Start at `(x=j-d, y=i)`
   - Iterate while `y >= i-d`, incrementing `x` and decrementing `y` each step
   - Skip if `x < 0` or `y < 0`
   - If the visited cell already has a color, mark that color as forbidden

3. Assign the first color index (0-3) that is not marked as forbidden to the current cell

### Output Generation
- Iterate through all cells in row-major order
- For each cell, output the character corresponding to its color index
- If a cell somehow has no assigned color (index -1), default to color 0 ('R')
- Output a newline after each row

## Helper Functions

### `log2(double a)`
- Computes the integer part of the base-2 logarithm of the input value
- Not called in the main program flow

### `gcd(long a, long b)`
- Computes the greatest common divisor using the Euclidean algorithm
- Not called in the main program flow

### `distance(int i1, int j1, int i2, int j2)`
- Computes Manhattan distance between two points
- Not called in the main program flow

### `Pair` class
- Stores an integer and a double value
- Implements `Comparable` with comparison based on first value, then second value
- Provides a string representation showing both values
- Not used in the main program flow

## Input Handling
- Uses a custom `FastReader` class with buffered reading
- The `nextInt()` method parses the next whitespace-delimited token as an integer
- The reader handles potential `IOException` by printing stack traces

## Output Handling
- Uses a static `sop` method that prints objects to standard output without a newline
- The main output loop explicitly adds newline characters after each row
