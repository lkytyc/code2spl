# Code Description

## Function: `len`

**Input:** A character array `s` with maximum size 1001.

**Output:** Returns an integer representing the length of the string.

**Behavior:** Iterates through the character array using a for loop with an empty body, incrementing index `i` until it encounters the null terminator (`'\0'`). Returns the final value of `i`, which is the string length.

## Function: `main`

**Input:** Reads from standard input:
- First reads an integer `t` (number of test cases)
- For each test case, reads an integer `n` (number of strings)
- Then reads `n` strings, each preceded by a character (which is read but not used)

**Output:** For each test case, prints either `Case #X: *` or `Case #X: <result_string>` where X is the test case number.

## Variables

- `t`: Number of test cases
- `n`: Number of strings per test case
- `s`: Character array of size 10001 used to build the result
- `str`: Character array of size 101 for reading input strings
- `a`: 2D character array of size n×10001, initialized with '#' characters
- `flag`: Integer flag indicating if a conflict was found
- `i`, `j`, `k`: Loop counters
- `dd`: Character variable for reading the preceding character

## Main Control Flow

### Test Case Loop (lines 11-61)
For each test case from 1 to `t`:

1. **Read `n`** (number of strings)

2. **Initialize array `a`** (lines 15-17): Fill all positions in the n×10001 array with '#' characters using nested loops.

3. **Read and process each string** (lines 19-35):
   - Read a character into `dd` (consumes whitespace)
   - Read a string into `str`
   - **If string starts with '*'** (line 23): Place the string (including the '*') at the end of row `j` in array `a`, starting from position 10000 and moving backward. The string is placed in reverse order.
   - **Else if string ends with '*'** (line 30): Place the string (including the '*') at the beginning of row `j` in array `a`, starting from position 0 and moving forward.

4. **Build result string** (lines 36-55):
   - Iterate through columns 0 to 9999
   - For each column, check all rows:
     - If a non-'*', non-'#' character is found and `f` is 0, add it to result string `s` and set `f` to 1
     - If `f` is already 1 and a different non-'*', non-'#' character is found, set `flag` to 1 and break
   - If `flag` is set, break out of the column loop

5. **Terminate result string** (line 56): Add null terminator to `s`

6. **Output** (lines 57-60):
   - If `flag` is 1: Print `Case #X: *`
   - Otherwise: Print `Case #X: <s>`

## Key Data Dependencies

- The result string `s` is built character by character based on the contents of array `a`
- The flag variable controls whether the result is valid or should be replaced with '*'
- The position of '*' in input strings determines whether they're placed at the beginning or end of their row in array `a`
- The comparison logic in the result-building phase checks for consistency across all rows at each column position

## Edge Cases and Special Behavior

- Strings starting with '*' are placed right-aligned (ending at position 10000)
- Strings ending with '*' are placed left-aligned (starting at position 0)
- The '#' character serves as a placeholder for empty positions
- The '*' character is treated as a wildcard that can match any character
- If conflicting characters are found at the same position across different rows, the result is marked as invalid ('*')
