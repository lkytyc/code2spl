# Function: vestigial(pinax)

## Input
- `pinax`: A 2D list (matrix) where each row is a list of integers. The matrix is assumed to be square (number of rows equals number of columns).

## Output
- Returns a list of three integers: `[trace, row_duplicates, column_duplicates]`

## Processing Steps

### Initialization
- Determines `size` as the length of the first row of the input matrix
- Initializes an empty `result` list
- Initializes `row_digits` as an empty list
- Initializes `column_digits` as a list of `size` empty lists
- Sets `same_row_counter` to 0
- Sets `same_column_counter` to a list of `size` zeros
- Sets `trail` to 0

### Main Loop (rows and columns)
Iterates through each row (0 to size-1) and within each row, iterates through each column (0 to size-1):

#### Trace Calculation
- When `row == column`, adds the diagonal element `pinax[row][row]` to `trail`

#### Row Duplicate Detection
- Clears `row_digits` at the start of each row iteration
- For each cell, if the current length of `row_digits` equals the current column index:
  - Checks if the current value already exists in `row_digits`
  - If it's a new value (not found), appends it to `row_digits`
  - If it's a duplicate (found in `row_digits`), increments `same_row_counter` by 1

#### Column Duplicate Detection
- For each cell, checks if the current value already exists in `column_digits[column]`
- If it's a new value, appends it to that column's list
- If it's a duplicate, sets `same_column_counter[column]` to 1

### Final Calculation
- Sums all values in `same_column_counter` to get `sumC`
- Appends `trail`, `same_row_counter`, and `sumC` to the result list

## Function: main()

### Input
- Reads an integer `testCases` from standard input
- For each test case:
  - Reads an integer `size` from standard input
  - Initializes `pinax` as a list of `size` empty lists
  - For each row, reads a line of space-separated integers and converts them to a list of integers

### Processing
- Calls `vestigial(pinax)` for each test case

### Output
- Prints for each test case: `"Case #" + test_case_number + ": " + trace + " " + row_duplicates + " " + column_duplicates`

## Control Flow Summary
- Two nested loops iterate through the matrix (rows outer, columns inner)
- Conditional branches check for diagonal elements, row duplicates, and column duplicates
- The function returns after processing all rows and columns
- The main function loops through all test cases sequentially
