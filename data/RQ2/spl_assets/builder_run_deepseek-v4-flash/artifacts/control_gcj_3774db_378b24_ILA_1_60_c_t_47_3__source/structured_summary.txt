## Function: ILA(s, t)

### Inputs
- `s`: a string
- `t`: a string

### Outputs
- Returns a string from the `path` list at index `target`

### Data Structures
- `rows`: length of `s` plus 1
- `cols`: length of `t` plus 1
- `dist`: 2D list of size rows × cols, initialized to zeros
- `choice`: 2D list of size rows × cols, initialized to zeros
- `path`: list of strings, size `time + 1`
- `c_s`: list of characters from `s`
- `c_t`: list of characters from `t`
- `suffix`: list of characters, initially empty

### Initialization
- First row of `dist` and `choice` are set: `dist[0][col] = col` and `choice[0][col] = 'I'` for each column
- First column of `dist` and `choice` are set: `dist[row][0] = row` and `choice[row][0] = 'D'` for each row

### Main Computation (Dynamic Programming)
- Nested loops iterate over columns (outer) and rows (inner), both starting from index 1
- For each cell, computes substitution cost (`subs` = 0 if characters match, else 1)
- Computes minimum of three values:
  - Deletion cost: `dist[row-1][col] + 1`
  - Insertion cost: `dist[row][col-1] + 1`
  - Substitution cost: `dist[row-1][col-1] + subs`
- Stores minimum in `dist[row][col]`
- Records the operation choice:
  - If minimum equals deletion cost: choice = 'D'
  - Else if minimum equals insertion cost: choice = 'I'
  - Else if substitution cost was 1: choice = 'S'
  - Else (characters matched): choice = 'N'

### Post-Processing
- `time` = value at bottom-right of `dist` matrix (edit distance)
- `target` = integer division of `time` by 2
- `path` array initialized with `None` values, size `time + 1`
- `path[0]` = original string `s`
- `path[time]` = original string `t`

### Path Reconstruction Loop
- Runs while `end >= start` (start = 1, end = time - 1)
- Each iteration examines `choice[len(c_s)][len(c_t)]`:
  - **'D' (deletion)**: removes last character from `c_s`, stores joined string in `path[start]`, increments `start`
  - **'I' (insertion)**: removes last character from `c_t`, stores joined string in `path[end]`, decrements `end`
  - **'S' (substitution)**: prepends last character of `c_t` to `suffix`, removes last characters from both `c_s` and `c_t`, stores joined string in `path[start]`, increments `start`
  - **'N' (no change)**: prepends last character of `c_t` to `suffix`, removes last characters from both `c_s` and `c_t` (no path update)

### Return Value
- Returns `path[target]`, the intermediate string at the halfway point of the edit path

## Function: solve_case(C, J)

### Inputs
- `C`: a string
- `J`: a string

### Outputs
- Returns the result of calling `ILA(C, J)`

### Behavior
- Single function call delegating to `ILA`

---

## Function: main()

### Inputs
- Reads from standard input:
  - First line: integer `T` (number of test cases)
  - For each test case: a line with two space-separated strings `C` and `J`

### Outputs
- Prints to standard output: `Case #N: result` for each test case, where N is the case number (1-indexed) and result is the return value from `solve_case`

### Control Flow
- Loops from case 1 to T inclusive
- For each case, splits input line on space to get `C` and `J`
- Calls `solve_case(C, J)` and prints formatted result

### Program Entry
- Calls `main()` at module level
