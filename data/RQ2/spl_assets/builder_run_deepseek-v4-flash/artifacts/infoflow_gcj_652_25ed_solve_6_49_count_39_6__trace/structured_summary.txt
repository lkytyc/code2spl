## Overview
This program solves a problem involving splitting a length `N` interval into smaller intervals over `K` steps, tracking the largest interval at each step. It uses a priority queue and a hash map to efficiently process intervals in descending order of size.

## Input
- First line: integer `T` (number of test cases)
- For each test case: two long integers `N` and `K` on a single line

## Output
For each test case, prints: `Case #X: L R` where `X` is the test case number (1-indexed), `L` is the larger half of the final interval, and `R` is the smaller half.

## Data Structures
- `PriorityQueue<Long>`: stores negative interval lengths (so the largest positive length is at the head)
- `HashMap<Long, Long>`: maps interval length to the count of intervals with that length

## Algorithm Flow

### Initialization
- For each test case, the queue is initialized with `-N` and the count map is initialized with `{N: 1}`
- `ans` is initialized to 0

### Main Loop
The loop continues until a break condition is met:

1. **Extract current interval**: Poll the queue to get the largest interval length (`cur`), and retrieve its count (`rest`) from the map

2. **Check termination conditions**:
   - If `K <= 1`: the current interval is the answer; break
   - Otherwise, subtract `rest` from `K`
   - If `K <= 0` after subtraction: the current interval is the answer; break

3. **Split the interval**:
   - `large = cur / 2` (integer division)
   - `small = (cur - 1) / 2` (integer division)
   - For each of `large` and `small`:
     - If the length already exists in the map, add `rest` to its count
     - Otherwise, add the negative length to the queue and set its count to `rest`

### Output Calculation
After the loop breaks, the answer is printed as:
- `ans / 2` (integer division) for the left value
- `(ans - 1) / 2` (integer division) for the right value

## Key Behaviors
- The priority queue uses negative values to simulate a max-heap (largest positive length is polled first)
- The count map tracks how many intervals of each length exist, allowing batch processing of identical intervals
- The loop processes intervals in descending order of size, splitting each into two halves
- The algorithm terminates when `K` is consumed or when the current interval is the `K`-th one to be processed

## Dependencies
- The count map and priority queue are kept synchronized: every length in the map has a corresponding entry in the queue, and vice versa
- The value of `K` is decremented by the count of the current interval before splitting, ensuring correct ordering of interval processing
