# Code Description

## Overview
This program implements an interactive number-guessing game where the program asks a series of yes/no questions to determine a hidden number. The program uses a binary search strategy after first determining the number of digits in the target number.

## Global Constants and Helper Functions

### Mathematical Helper Functions
- **Integer functions**: `max`, `min`, `zt` (absolute difference), `round`, `ceil`, `gcd`, `lcm`, `nCr`, `nHr`, `fact`, `pow`, `dsum` (digit sum), `dsumb` (digit sum in base b), `sankaku` (triangular number)
- **Long long variants**: `llmax`, `llmin`, `llzt`, `llround`, `llceil`, `llgcd`, `lllcm`, `llnCr`, `llnHr`, `llfact`, `llpow`, `lldsum`, `lldsumb`, `llsankaku`
- **Double variants**: `dbmax`, `dbmin`, `dbzt`

### Sorting Comparison Functions
- Integer ascending/descending: `sortfncsj`, `sortfnckj`
- Long long ascending/descending: `llsortfncsj`, `llsortfnckj`
- Double ascending/descending: `dbsortfncsj`, `dbsortfnckj`
- String ascending/descending: `strsortfncsj`, `strsortfnckj`
- Character ascending/descending: `chsortfncsj`, `chsortfnckj`

### Other Utility Functions
- `shuffledget`: Reads n integers from stdin in shuffled order using a Fisher-Yates shuffle with random seed from time
- `search`: Binary search returning the insertion point for value x in sorted array a of size n
- `prarr`: Prints an integer array with spaces between elements, followed by newline

### Data Structure
- `sd` struct: Contains integer fields `val` and `node`
- `sdsortfnc`: Comparison function for sorting `sd` structs by `val` field

## Main Program Logic

### Variable Declarations
- Long long variables: `i`, `j`, `w`, `fl`, `dg`, `st`, `fi`, `te`
- Boolean 2D array `mem[16][2]` initialized to false
- Character arrays `s[8]` and `t[8]` for storing responses

### Phase 1: Digit Count Determination
The program loops from i=9 down to i=0 (10 iterations):

1. **First question per iteration**: Asks "? 10^i" (powers of 10 from 10^9 down to 10^0)
   - Reads response string `s`
   - If response starts with 'Y', sets `mem[i][0] = true`
   - Otherwise, sets flag bit 2 in `fl` (fl |= 2)

2. **Second question per iteration**: Asks "? (10^(i+1)) - 1" (numbers like 999...9)
   - Reads response string `t`
   - If response starts with 'Y', sets `mem[i][1] = true`
   - Otherwise, sets flag bit 1 in `fl` (fl |= 1)

### Phase 2: Determine Digit Count (dg)
Based on the flag value `fl`:

- **If fl == 1**: Only the second type of question got 'N' responses. Loop from i=9 down to 0:
  - Find first i where `mem[i][1]` is false, set `dg = i` and break
  - If all are true (i reaches 0), print "! 1" and exit

- **If fl == 2**: Only the first type of question got 'N' responses. Loop from i=0 to 9:
  - Find first i where `mem[i][0]` is false, set `dg = i` and break

- **If fl == 3**: Both types got 'N' responses. Loop from i=0 to 9:
  - Find first i where both `mem[i][0]` and `mem[i][1]` are true, set `dg = i` and break
