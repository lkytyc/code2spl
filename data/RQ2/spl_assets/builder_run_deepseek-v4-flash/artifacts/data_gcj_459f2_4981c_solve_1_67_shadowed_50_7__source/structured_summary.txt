# Structured Description of Code

## Function: solve(B)

### Input
- B: A list of integers representing ball counts at each column position.

### Output
- Returns a tuple containing:
  - Either the string 'IMPOSSIBLE' and None, OR
  - An integer (number of rows in the solution grid) and a list of lists (the grid representation)

### Initial Validation
- Checks if the first element (B[0]) or last element (B[-1]) equals 0
- If either is 0, immediately returns ('IMPOSSIBLE', None)

### Grid Initialization
- Creates a square grid of size C × C (where C = length of B)
- All cells initially filled with '.' characters
- Creates a shadowed tracking list of booleans, same length as B
- Marks position 0 as shadowed
- Decrements B[0] and B[-1] by 1

### Main Processing Loop
Iterates through each position i from 0 to C-1:

#### Branch 1: Skip Condition
- If B[i] equals 0 AND position i is shadowed, skips to next iteration

#### Branch 2: Unshadowed Position with Balls
- If B[i] > 0 AND position i is NOT shadowed:
  - Scans leftward from position i-1 while positions are unshadowed and index >= 1
  - Places '\' characters in grid at increasing row indices (l starts at 1)
  - Marks each visited position as shadowed
  - Counts unshadowed_balls encountered
  - If B[i] <= unshadowed_balls:
    - Calculates excess_balls = unshadowed_balls - B[i] + 1
    - While excess_balls > 1, moves leftward, decrementing excess and un-shadowing positions
  - Else (B[i] > unshadowed_balls):
    - Reduces B[i] by (unshadowed_balls + 1)
    - Marks position i as shadowed

#### Branch 3: Shadowed Position with Remaining Balls
- If B[i] > 0 AND position i IS shadowed:
  - Sets r = B[i]
  - First while loop: scans rightward through consecutive shadowed positions, placing '/' characters
  - Second while loop: continues rightward while r > 0 and position < C-1
    - Places '/' characters
    - Marks positions as shadowed
    - Decrements r

### Output Grid Construction
- Builds answer list by iterating through grid rows from index 1 to C-1
- Includes a row only if it contains at least one '\' or '/' character
- Stops including rows at first empty row
- Prepends a row of all '.' characters to the answer
- Returns (number of rows, answer grid)

## Helper Functions

### lay_right_ramp(i, grid, shadowed)
- Empty function (pass statement only)

### lay_left_ramp(i, grid, shadowed)
- Empty function (pass statement only)

## Function: main()

### Input Processing
- Reads integer T (number of test cases) from standard input
- Loops through each test case t from 1 to T:
  - Reads integer S (unused in logic)
  - Reads space-separated string values and converts to integer list B
  - Calls solve(B) to get result and grid

### Output Formatting
- Prints "Case #{t}: {result}" where result is either 'IMPOSSIBLE' or the row count
- If grid exists, prints grid rows in reverse order (from bottom to top)
- Each row printed as concatenated characters

## Program Entry Point
- Checks if script is run directly (__name__ == "__main__")
- Calls main() function

## Key Data Dependencies
- B list is modified during solve() execution
- shadowed list tracks which positions have been processed
- grid accumulates ramp characters based on shadowed status and ball counts
- The final answer depends on which grid rows contain ramp characters
