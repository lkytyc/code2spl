# Code Description

## Function: `calc(h, w)`

### Inputs
- Integer parameters `h` (height) and `w` (width)
- Reads `h` lines of strings from standard input, each of length `w`, using `scanf("%s", row)`

### Local Data Structures
- A 2D integer array `panel` of dimensions `h` × `w`
- A character array `row` of length `w` used as a temporary buffer for reading input

### Processing Steps

#### Step 1: Input Parsing
- Loops over each row index `i` from 0 to `h-1`
- For each row, reads a string into `row`
- Loops over each column index `j` from 0 to `w-1`
- If the character at `row[j]` is `#`, sets `panel[i][j]` to `-1` (representing a mine)
- Otherwise, sets `panel[i][j]` to `0`

#### Step 2: Mine Counting
- Loops over each cell in the `panel` array
- If a cell contains `-1` (a mine), skips it (continues to next cell)
- For non-mine cells, initializes a counter `count` to 0
- Checks all 8 neighboring cells (up-left, up, up-right, left, right, down-left, down, down-right) with boundary checks:
  - Up-left: only if `i-1 >= 0` and `j-1 >= 0`
  - Up: only if `i-1 >= 0`
  - Up-right: only if `i-1 >= 0` and `j+1 < w`
  - Left: only if `j-1 >= 0`
  - Right: only if `j+1 < w`
  - Down-left: only if `i+1 < h` and `j-1 >= 0`
  - Down: only if `i+1 < h`
  - Down-right: only if `i+1 < h` and `j+1 < w`
- For each valid neighbor that contains `-1`, increments `count`
- Assigns the final `count` value to `panel[i][j]`

#### Step 3: Output Generation
- Loops over each cell in the `panel` array
- If a cell contains `-1`, prints `#`
- Otherwise, prints the numeric value stored in the cell
- After each row, prints a newline character

### Return Value
- Always returns `0`

## Function: `main()`

### Inputs
- Reads two integers from standard input: `h` and `w`

### Processing
- Calls `calc(h, w)` with the read dimensions

### Return Value
- Always returns `0`

## Control Flow Summary
- Three nested loop structures in `calc`: input reading, mine counting, and output
- Conditional branches for mine detection, boundary checking, and output formatting
- No recursive calls or external function calls other than standard I/O functions
