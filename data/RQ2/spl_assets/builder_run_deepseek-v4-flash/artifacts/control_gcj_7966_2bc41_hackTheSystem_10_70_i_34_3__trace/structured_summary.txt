# Structured Description

## Inputs
- The program reads an integer `numberOfCases` from standard input.
- For each case, it reads a line containing two space-separated values: a shield value (parsed as a long integer) and a code string.
- The `hackTheSystem` method receives an array of two strings: `softwareToHack[0]` is the shield value as a string, and `softwareToHack[1]` is the code string.

## Outputs
- For each test case, the program prints `Case #i: result` where `i` is the zero-based case index and `result` is either:
  - A number of movements (as a string)
  - The string `"IMPOSSIBLE"`

## Global/Static Variables
- `shootDamage`: long, initialized to 1
- `shootCounter`: long, initialized to 0
- `shield`: long, set from input
- `code`: String, set from input
- `damage`: long, initialized to 0
- `movements`: long, initialized to 0
- `lastIterableElement`: int, set to code length minus 1

## Initial Computation
- The method iterates through each character of the code string.
- For each `'S'` character: adds current `shootDamage` to `damage` and increments `shootCounter`.
- For each `'C'` character: multiplies `shootDamage` by 2.

## Early Exit Conditions
- If `damage` is less than or equal to `shield`, returns `movements` (which is 0 at this point).
- If `shootCounter` is greater than `shield`, returns `"IMPOSSIBLE"`.

## Main Processing Loop
- Uses nested loops with indices `i` and `j`, both starting from the last index of the code string and decrementing.
- The outer loop iterates `i` from the last index down to 0.
- The inner loop iterates `j` from the second-to-last index down to 0.

### Loop Conditions and Actions
1. **If both `code.charAt(j)` and `code.charAt(i)` are `'S'`**: decrements `i` and continues to the next outer iteration.

2. **If `code.charAt(i)` is `'C'`**: divides `shootDamage` by 2, decrements `i`, decrements `lastIterableElement`, and continues to the next outer iteration.

3. **If `code.charAt(j)` is `'C'` and `code.charAt(i)` is `'S'`**:
   - Increments `movements`
   - Reduces `damage` by `shootDamage / 2`
   - Converts the code string to a character array
   - If `damage` is now less than or equal to `shield`, returns the current `movements` value
   - Swaps the characters at positions `j` and `i` in the character array
   - Converts the character array back to a string and updates `code`
   - If `i` equals `lastIterableElement`: divides `shootDamage` by 2, and if `i` is greater than 0, decrements `i`
   - Otherwise: increments `i` and increments `j` by 2

## Final Return
- If the loops complete without returning early, the method returns the current `movements` value.

## Main Method Flow
- Reads number of test cases
- Stores all cases in a 2D array
- Processes each case sequentially, calling `hackTheSystem` and printing the formatted result

## Data Dependencies
- The `damage` value depends on `shootDamage` and the sequence of `'S'` and `'C'` characters.
- The `shootDamage` value changes during processing when `'C'` characters are encountered or when swaps occur.
- The `movements` counter tracks the number of swaps performed.
- The `lastIterableElement` tracks a boundary for the processing logic.
- The code string is modified during processing through character swaps.
