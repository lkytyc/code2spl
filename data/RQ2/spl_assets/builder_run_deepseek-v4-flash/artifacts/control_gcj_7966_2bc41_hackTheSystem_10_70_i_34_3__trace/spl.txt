[DEFINE_WORKER: "Calculates the minimum number of adjacent swaps needed to reduce the total damage from 'S' attacks (doubled by 'C' charges) to at most the shield's strength, or returns 'IMPOSSIBLE' if the number of attacks exceeds the shield." hackTheSystem]
    [INPUTS]
        <REF> softwareToHack </REF>: String[] "An array where the first element is the shield strength as a string, and the second element is the code string containing 'S' (shoot) and 'C' (charge) characters."
    [END_INPUTS]

    [OUTPUTS]
        <REF> result </REF>: String "The minimum number of swaps required to make the total damage less than or equal to the shield, or the string 'IMPOSSIBLE' if the number of 'S' characters exceeds the shield."
    [END_OUTPUTS]

    [MAIN_FLOW]
        [SEQUENTIAL_BLOCK]
            [COMMAND Initialize shootDamage to 1, shootCounter to 0, shield by parsing the first element of softwareToHack as a long, code to the second element of softwareToHack, damage to 0, movements to 0, sizeScript to code.length() - 1, and lastIterableElement to sizeScript. RESULT initial_state]
            [COMMAND Iterate through each character of code from index 0 to code.length() - 1. If the character is 'S', add shootDamage to damage and increment shootCounter. If the character is 'C', multiply shootDamage by 2. RESULT initial_damage_calculation]
            [COMMAND Check if damage is less than or equal to shield. If true, return the string representation of movements. RESULT early_return_zero_movements]
            [COMMAND Check if shootCounter is greater than shield. If true, return the string 'IMPOSSIBLE'. RESULT impossible_check]
            [COMMAND Iterate with i from sizeScript down to 0. Within this outer loop, iterate with j from sizeScript - 1 down to 0. RESULT outer_and_inner_loop_start]
            [COMMAND Within the inner loop over j, check if the character at index j of code is 'S' and the character at index i of code is 'S'. If true, decrement i and continue to the next iteration of the inner loop. RESULT skip_ss_pair]
            [COMMAND Within the inner loop over j, check if the character at index i of code is 'C'. If true, divide shootDamage by 2, decrement i, decrement lastIterableElement, and continue to the next iteration of the inner loop. RESULT handle_charge_at_i]
            [COMMAND Within the inner loop over j, check if the character at index j of code is 'C' and the character at index i of code is 'S'. If true, increment movements, subtract shootDamage divided by 2 from damage, and convert code to a character array. RESULT process_swap_condition]
            [COMMAND Within the swap condition, check if damage is now less than or equal to shield. If true, return the string representation of movements. RESULT early_return_after_swap]
            [COMMAND Within the swap condition, swap the characters at indices j and i in the character array, convert it back to the string code, and then check if i equals lastIterableElement. If true, divide shootDamage by 2 and decrement i if i is greater than 0. If false, increment i and add 2 to j. RESULT perform_swap_and_adjust_indices]
            [COMMAND After the outer loop completes, return the string representation of movements. RESULT final_return]
        [END_SEQUENTIAL_BLOCK]
    [END_MAIN_FLOW]

[END_WORKER]
