## Input
The program reads from standard input. The first line contains two integers: `n` (number of items) and `s` (a target position). The next `n` lines each contain two integers: a position value and a priority/weight value.

## Output
The program prints a single integer result.

## Data Structures
- `a`: list of all input pairs
- `x`: list of position values extracted from input pairs
- `p`: list of priority/weight values extracted from input pairs
- `d`: a mutable copy of the priority list `p`
- `e`: a defaultdict of lists (initialized but not used in the logic)
- `sk`: a set used to track certain indices during processing

## Initial Checks
- If the first position `x[0]` is greater than `s`, the program returns `x[-1] - s` (the difference between the last position and `s`).
- If the last position `x[-1]` is less than `s`, the program returns `s - x[0]` (the difference between `s` and the first position).

## Main Processing Loop
The program initializes:
- `r = 0` (accumulator for result)
- `i = 0` (left index)
- `j = n-1` (right index)
- `d` as a copy of `p`
- `sk` as an empty set

### First While Loop (i < j)
This loop continues while `i` is less than `j`. Inside:
- If `x[i] > s`, break out of the loop.
- If `x[j] < s`, break out of the loop.
- If `d[i] >= d[j]`:
  - Add `d[j]` to `d[i]`
  - Decrement `j`
  - If `j >= 0` and `d[j] < d[j+1]`, set `d[j] = d[j+1]` and add `i` to `sk`
- Otherwise (if `d[i] < d[j]`):
  - Add `d[i]` to `d[j]`
  - Increment `i`
  - If `i < n` and `d[i] < d[i-1]`, set `d[i] = d[i-1]` and add `i` to `sk`

### Position Adjustment After First Loop
After the first loop, the program sets `t = s`.

- If `i == j`:
  - Add `abs(x[i] - s)` to `r`
  - Set `t = x[i]`
  - Decrement `i` and increment `j`
- Otherwise:
  - If `x[i] > s`:
    - Add `abs(x[j] - s)` to `r`
    - Set `t = x[j]`
    - Decrement `i` and increment `j`
  - Otherwise:
    - Add `abs(x[i] - s)` to `r`
    - Set `t = x[i]`
    - Decrement `i` and increment `j`

### Second While Loop (i >= 0 or j < n)
This loop continues while either index is within bounds:
- If `i < 0`: add `abs(x[-1] - t)` to `r` and break
- If `j >= n`: add `abs(x[0] - t)` to `r` and break
- If `i` is in `sk`:
  - Set `d[i-1] = d[i]`
  - Decrement `i`
  - Continue to next iteration
- If `j` is in `sk`:
  - Set `d[j+1] = d[j]`
  - Increment `j`
  - Continue to next iteration
- If `d[i] >= d[j]`:
  - Add `abs(x[i] - t)` to `r`
  - Set `t = x[i]`
  - Decrement `i`
- Otherwise:
  - Add `abs(x[j] - t)` to `r`
  - Set `t = x[j]`
  - Increment `j`

## Final Output
The program prints the accumulated result `r` from the main function.
