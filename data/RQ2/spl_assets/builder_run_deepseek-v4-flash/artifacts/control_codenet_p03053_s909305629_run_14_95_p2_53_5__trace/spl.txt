[DEFINE_WORKER: "Reads an H x W grid, records all initial '#' cells, performs a layer-by-layer BFS expansion that changes adjacent '.' cells to '#', and prints the number of completed expansion rounds minus one; because the outer loop runs until the queue index reaches H*W, unreachable '.' cells cause non-termination." run]
    [INPUTS]
    [END_INPUTS]

    [OUTPUTS]
    [END_OUTPUTS]

    [MAIN_FLOW]
        [SEQUENTIAL_BLOCK]
            [COMMAND Create Scanner sc bound to System.in, then read the next two whitespace-separated tokens and parse them as int values h and w. RESULT sc, h, w]
            [COMMAND Allocate char grid a as new char[h][w], int array atmp as new int[h], coordinate array blackar as new int[h*w][2], and set max = 0 and p = 0. RESULT a, atmp, blackar, max, p]
            [COMMAND For each row index i from 0 to h-1, read the next token from sc, convert it to a char array, and assign it to a[i]. RESULT a[i], i]
            [COMMAND Within the row loop over i, for each column index j stored as a char initialized to 0, while j < w and incrementing j by 1 after each iteration (this char counter causes an infinite loop if w > 65535), if a[i][j] == '#', store i in blackar[p][0], store j in blackar[p][1], and increment p. RESULT blackar, p]
            [COMMAND After all rows are read, set maxp = p, set p2 = p, and reset p = 0. RESULT maxp, p2, p]
            [COMMAND Enter the outer while loop with condition p < h*w; this is the actual termination condition, not p < maxp, so if h*w == 0 the loop is skipped. RESULT p]
            [COMMAND Inside the outer while loop, declare unused int hap = 0, then run an inner for loop with no initialization, continuing while p < maxp and incrementing p each iteration; for each iteration, load i = blackar[p][0] and j = blackar[p][1], and for each of the four neighbors in order up, left, down, and right, when the neighbor is within the grid, if a[neighbor] == '.', change it to '#', store the neighbor's coordinates in blackar[p2], and increment p2. RESULT p, p2, a, blackar]
            [COMMAND After the inner for loop completes, set maxp = p2 and increment max. If no new cells were enqueued and p is still less than h*w, p does not advance and the outer while loop repeats forever. RESULT maxp, max]
            [COMMAND After the outer while loop exits, subtract 1 from max and assign ans = max. RESULT max, ans]
            [COMMAND Create PrintWriter out for System.out, print ans with println, and flush out. RESULT out]
        [END_SEQUENTIAL_BLOCK]
    [END_MAIN_FLOW]

    [EXCEPTION_FLOW: The input has fewer than two whitespace-separated tokens before the grid rows.]
        [LOG "The scanner attempts to read a token after the input is exhausted."]
        [THROW NoSuchElementException "Thrown by Scanner when input is exhausted."]
    [END_EXCEPTION_FLOW]

    [EXCEPTION_FLOW: The first or second input token is not a valid integer.]
        [LOG "The integer parser receives a token that is not a valid int."]
        [THROW NumberFormatException "Thrown when a non-integer token is parsed as int."]
    [END_EXCEPTION_FLOW]

    [EXCEPTION_FLOW: h or w is negative.]
        [LOG "An array is allocated with a negative dimension."]
        [THROW NegativeArraySizeException "Thrown when attempting to create an array with a negative length."]
    [END_EXCEPTION_FLOW]

[END_WORKER]
