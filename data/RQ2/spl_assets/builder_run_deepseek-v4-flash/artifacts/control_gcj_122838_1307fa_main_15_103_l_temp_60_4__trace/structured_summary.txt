# Code Description

## Overview
This program processes multiple test cases, each containing two arrays of integers, and computes a total count based on comparisons between elements of the two arrays within a specified tolerance.

## Helper Functions

### min(a, b)
- **Input**: Two integers
- **Output**: Returns the smaller of the two values
- **Logic**: If `a > b`, returns `b`; otherwise returns `a`

### max(a, b)
- **Input**: Two integers
- **Output**: Returns the larger of the two values
- **Logic**: If `a > b`, returns `a`; otherwise returns `b`

## Main Function

### Input Processing
- Reads an integer `t` representing the number of test cases
- For each test case (indexed by `m` from 1 to `t`):
  - Reads two integers `n` and `k`
  - Declares arrays `a[n]`, `b[n]`, and four boundary arrays `l_a[n]`, `l_b[n]`, `r_a[n]`, `r_b[n]`
  - Initializes all boundary arrays so each element equals its index position
  - Reads `n` integers into array `a`
  - Reads `n` integers into array `b`

### Boundary Array Computation
For each index `i` from 0 to n-1:
- **Left boundary for array a** (`l_a[i]`): Starting from position `i`, moves leftward while elements in `a` are less than or equal to `a[i]`. Stops when finding an element greater than `a[i]` or reaching position -1. Stores the stopping position.
- **Left boundary for array b** (`l_b[i]`): Same process using array `b` and comparing against `b[i]`
- **Right boundary for array a** (`r_a[i]`): Starting from position `i`, moves rightward while elements in `a` are less than or equal to `a[i]`. Stops when finding an element greater than `a[i]` or reaching position `n`. Stores the stopping position.
- **Right boundary for array b** (`r_b[i]`): Same process using array `b` and comparing against `b[i]`

### First Counting Loop
- Initializes `tot` (long long) to 0
- For each index `i` from 0 to n-1:
  - For each index `j` from `i` to `r_a[i] - 1`:
    - Checks if `l_b[j] < i`
    - If true, checks if the difference `a[i] - b[j]` is within the range `[-k, k]`
    - If both conditions hold, adds to `tot` the product of:
      - `(i - max(l_a[i], l_b[j]))` — the left span
      - `(min(r_a[i], r_b[j]) - j)` — the right span

### Second Counting Loop
- For each index `i` from 0 to n-1:
  - For each index `j` from `i+1` to `r_b[i] - 1`:
    - Checks if `l_a[j] < i`
    - If true, checks if the difference `a[j] - b[i]` is within the range `[-k, k]`
    - If both conditions hold, adds to `tot` the product of:
      - `(i - max(l_b[i], l_a[j]))` — the left span
      - `(min(r_b[i], r_a[j]) - j)` — the right span

### Output
- Prints `Case #m: tot` where `m` is the test case number (1-based) and `tot` is the accumulated count

## Control Flow Summary
- Outer loop iterates through test cases
- Nested loops compute boundary arrays for each position
- Two separate double-nested loops accumulate the final count
- Conditional checks within inner loops filter which index pairs contribute to the total

## Data Dependencies
- Boundary arrays depend on the input arrays `a` and `b`
- The final count depends on boundary arrays, input arrays, and the tolerance value `k`
- The second counting loop depends on results from the first loop only through the shared `tot` accumulator
