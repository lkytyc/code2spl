## Overview
This program reads a sequence of non-negative integers and computes a count modulo 10^9+7 based on pattern-matching rules applied to the sequence. It appears to count certain combinatorial structures (possibly permutations or orderings) consistent with the input sequence.

## Input
- First line: a single integer `n` (sequence length)
- Second line: `n` space-separated integers (the sequence `a`)

## Output
- A single integer: the computed count modulo 10^9+7, or `0` if the sequence is invalid

## Initial Validation
1. If the first element `a[0]` is not 0, output `0` and terminate.
2. If `n == 1`:
   - If `a[0] == 0`, output `3`
   - Otherwise, output `0`
3. If `n == 2`:
   - If `a[1] == 0`, output `3`
   - If `a[1] == 1`, output `6`
   - Otherwise (including when `a[1]` is neither 0 nor 1), output `0`

## Main Processing (for n ≥ 3)
### Initial State Setup
Three cases are checked based on the first three elements:

**Case 1:** `a[1] == 0` and `a[2] == 0`
- Set `x = 1`, `y = 1`, `z = 1`, `res = 1`

**Case 2:** `a[1] == 0` and `a[2] == 1`
- Set `x = 2`, `y = 1`, `z = 0`, `res = 2`

**Case 3:** `a[1] == 1` and `a[2] == 2`
- Set `x = 3`, `y = 0`, `z = 0`, `res = 1`

**Otherwise:** Output `0` and terminate.

### Iterative Processing
For each index `i` from 3 to `n-1`, examine `a[i]` against current values of `x`, `y`, `z`:

1. If `a[i] == x` and `a[i] != y`: increment `x` by 1
2. If `a[i] == x` and `a[i] == y` and `a[i] != z`: multiply `res` by 2 (mod MOD), increment `x` by 1
3. If `a[i] == x` and `a[i] == y` and `a[i] == z`: multiply `res` by 3 (mod MOD), increment `x` by 1
4. If `a[i] == y` and `a[i] != z`: increment `y` by 1
5. If `a[i] == y` and `a[i] == z`: multiply `res` by 2 (mod MOD), increment `y` by 1
6. If `a[i] == z`: increment `z` by 1
7. Otherwise: output `0` and terminate

### Final Adjustment
After processing all elements:
- If `y == 0`: multiply `res` by 3 (mod MOD)
- Otherwise: multiply `res` by 6 (mod MOD)

Output the final `res` value.

## Key Variables
- `x`, `y`, `z`: tracking counters that evolve based on sequence values
- `res`: accumulating result (modulo 10^9+7)
- `MOD`: constant 10^9+7

## Control Flow
- Early termination with output `0` occurs at multiple validation points
- The main loop processes elements sequentially with no branching back
- The program uses `exit()` for early termination rather than returning from main

## Dependencies
- Uses `sys.stdin.readline` for input (or a provided function)
- Uses `sys.stdout.write` for output
- Sets recursion limit to 10^6 (though no recursion is used)
