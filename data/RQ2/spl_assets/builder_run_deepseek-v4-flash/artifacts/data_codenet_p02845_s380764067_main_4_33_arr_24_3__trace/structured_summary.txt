# Program Description

## Overview
This program reads a sequence of numbers and counts the number of ways to arrange them according to specific rules, then outputs the result modulo 1,000,000,007.

## Input
- First line: an integer `n` (number of elements to process)
- Following `n` lines: long integers read sequentially

## Output
- Prints `0` if the first number is not zero
- Otherwise, prints `(ans * 3) % mod` where `mod = 1,000,000,007`

## Main Processing Logic

### Initialization
- Sets `mod` to 1,000,000,007
- Creates a `FastScanner` for input reading
- Reads integer `n`
- Creates a 3-element long array `arr` initialized to zeros
- Reads the first long value `ff`

### First Value Check
- If `ff` is not equal to 0, prints `0` and terminates immediately

### Main Loop (runs `n-1` times)
For each subsequent input value `a`:
1. Initializes `fi` (found index) to -1 and `cnt` (count) to 0
2. Scans through the 3-element array `arr`:
   - If `arr[j]` equals the current input `a`:
     - Increments `cnt`
     - If this is the first match (`fi == -1`):
       - Increments `arr[j]` by 1
       - Sets `fi` to `j`
3. Multiplies `ans` by `cnt`
4. Takes `ans` modulo `mod`

### Final Output
- Prints `(ans * 3) % mod`

## Data Dependencies
- `arr` array tracks counts of previously seen values (initialized with `arr[0] = 1` before the loop)
- `ans` accumulates the product of match counts
- The current input value `a` determines which array elements match

## Control Flow
- Early termination if first value is non-zero
- Nested loops: outer loop processes each input, inner loop checks the 3-element array
- Conditional logic within inner loop for first-match handling

## Helper Class: FastScanner
Provides buffered input reading with tokenization:
- `next()`: Returns next token, reinitializing tokenizer if needed
- `nextLine()`: Returns next line or remaining tokens
- `nextLong()`, `nextInt()`, `nextDouble()`: Parse tokens to primitive types
- `nextIntArray(n)`, `nextLongArray(n)`: Read arrays of specified size
- Throws `RuntimeException` on IO errors
